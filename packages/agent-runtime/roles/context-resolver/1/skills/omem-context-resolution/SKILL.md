# Resolve material membership

1. Read task.input_source in full. List existing groups and compare their descriptions; search inside plausible groups to identify the agreement, activity or system being discussed.
2. If a short message refers to an earlier decision, read that earlier original before selecting a group. Shared names and lexical resemblance are clues, not membership. Keep different projects, events and time periods apart.
3. Choose matched only when the source concerns the selected groups. A mention of another project for comparison does not automatically put the entire source into that project. Use ambiguous when the evidence leaves several plausible objects; state what the user needs to distinguish. If no existing group fits, use unrelated and retain the original for ordinary learning.
4. In independent_review, check the proposed membership against originals in a separate session. Do not inherit the first investigator's conclusions. Explain a disagreement in terms the user can resolve.
5. Submit a filing decision with known context IDs and a concise explanation. Do not write facts, modify groups or create actions. A correct filing decision still requires subsequent extraction and evidence review for memory updates.
