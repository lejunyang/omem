# omem 是什么

omem 是一个跑在你自己机器上的个人助理。它深度接入飞书，把消息、文档、会议和代码放进同一个库，带着出处回答问题、记住约定、跟进事项；派给它的任务由多个 Agent 协作完成，编码有多角度评审把关。理解和写作交给你已经安装的 Agent（Codex、Claude Code、Gemini CLI 等），omem 负责存储、索引、调度和权限。

## 几个基本概念

**原件**是依据：一份文档、一个群的聊天、一个代码文件、一个网页。原件只保留最新版，聊天按追加保存，删除留墓碑。

**空间**把领域分开：个人、项目、代码仓库、学习、通用。检索默认在当前空间和它的相关空间里，互相调用的仓库、同一项目的几个空间可以关联起来。

**派生知识**都引用原件：

- **Wiki** 是 Markdown 页面，整个知识库是一个 Git 仓库，每次修改都有历史；
- **记忆**是事实、约定、决定、人物和偏好，被更正时保留版本链；
- **事项**是待办、等待回复和持续关注的事，有时间线和期限。

**Agent** 做理解和写作。omem 通过 ACP（Agent Client Protocol）或命令行调用它们，给它们一组 MCP 工具（检索、读原件、写记忆和事项……），所有写入都经过工具，按空间和角色限定权限，记录在运行里。

```text
文件 / 代码仓库 / 网页 / 飞书文档 / 聊天
            │  保存、采集
            ▼
   原件 + 索引（全文 / 向量）      记忆      事项      Wiki（Git）
            └──────────────┬──────────────────────────────┘
                     omem 工具（MCP）
                           │
           Agent：Codex / Claude Code / Gemini CLI …
                           │
          回答 · 页面 · 记忆 · 事项 · 代码改动（都引用原件）
```

## 功能一览

| 模块 | 能做什么 |
| --- | --- |
| [飞书](../features/lark) | 自动存下消息、文档、知识库、日程和妙记；会议旁听与提醒；进度、提问、确认都是卡片；盯群、多个机器人分工、同事 @ 时先把关 |
| [原件与空间](../features/sources)、[问答](../features/ask)、[Wiki](../features/wiki) | 文档、聊天、代码一个上下文；回答和 Wiki 引用到原文行，引用可以一层层点开；Wiki 按问题组织，原件变了自动检查 |
| [记忆](../features/memory)、[事项](../features/items)、[学习与进步](../features/learning) | 记忆有版本链和质量检查；随口说的事记成事项，跟到收尾；纠正一次就是规矩，每晚复盘提出改进 |
| [Agent 与技能](../features/agents)、[多 Agent 协作](../features/collaboration)、[规则](../features/rules) | 约三十个内置角色可改说明、换模型、挂技能；长任务多个 Agent 接力；中途随时插话，连发自动排队；一句话写规则让事件触发任务 |
| [编码](../features/coding) | 在常驻机器上交办，五个评审项从不同角度审、循环修复；需求拆成变更点；网页版 VS Code 看代码 |
| [插件](../features/plugins) | 档案、技能、工具、数据和页面打成一个包；内置英语练习，自己的插件写一份清单就能用 |
| [多台设备](../features/devices) | 一台常驻、别的电脑查看和整理；借用别的设备上的 Agent |

继续看 [安装与第一次使用](./getting-started)。
