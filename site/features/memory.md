# 记忆

**记忆是从日常对话、群聊和文档里提炼出来、以后办事还用得上的核心结论：事实、约定、决定、人物、偏好和经验。** 与普通 AI 记忆库最大的不同在于：omem 的每条记忆都贴着原话出处，**被纠正时不覆盖旧记录而是保留版本演变链**，并且拥有写入前规则拦截、写入后独立模型盲评复核、每两小时自动归档目录的全自动治理机制。

## 1. 三个核心特色：版本链、自动质检、三层目录树

### 被纠正时不覆盖，保留完整版本链（`supersede`）

在真实项目里，预算、排期和接口口径经常变。当你对助理说“不对，项目 A 的预算改成 120 万了”：
- 助理不会偷偷把旧的“100 万”删掉或改写，而是调用 `supersede(old, new)`：将旧记忆标记为**“已被更正”**并指向新记忆。
- 因此，无论你问**“现在预算定的是多少”**，还是追问**“最早是怎么约定的、哪天谁改的”**，助理都能沿着版本链连同当时的对话出处一起准确答出。

### 质量不靠人工逐条盯：写入前拦截 + 独立模型盲评 + 夜间做梦

记忆记多了最怕掺进废话、流水账和错误结论。omem 用四层自动化机制保持记忆库干净：

| 治理阶段 | 具体做什么 |
| --- | --- |
| **1. 写入前确定性拦截** | 每次调用 `remember` / `supersede` 先过代码规则：凡是**带免责套话（“可能/待确认”）、超长（>400 字，应拆开或写进 Wiki）、单纯转述原件标题、“某天某人说了什么”的事件流水账、助理自己的工作汇报、无来源或与已有记忆重复**，直接拒绝写入并把修改指导作为工具错误退回给模型 |
| **2. 每小时独立模型盲评（`memory-reviewer`）** | 新写入的 Agent 记忆每小时交给独立的复核模型（看不到是哪个模型写的）盲评，执行**保留、改写、拆分或撤回**。开启复核后，只有本人写入或经复核保留的偏好与经验才会注入后续运行的常驻提示 |
| **3. 每晚“做梦”整合（`dreamer`）** | 每晚自动巡检近期与历史记忆（约两周把全库轮巡一遍）：合并重复记忆、处理前后冲突与过期条目，并优先排查白天收到负面表情或被你纠正过的回答所关联的记忆 |
| **4. 多模型影子对比（“记忆 → 质量”）** | 可配置 `memory.compare` 让其他模型在后台对同一批材料做影子写入（不实际生效），在 **记忆 → 质量** 页面（或 `omem memories stats`）按模型直观对比写入数、被拒原因与盲评通过率 |

### 自动维护的三层目录树

每条记忆在空间内都有一个清晰的目录路径（如 `工作/项目A/发布`，最多三层），呈现在记忆页左侧：
- **写时选目录，定时自动整理**：助理写入时按目录说明归类，拿不准的先放“未归档”；`memory-organizer` 每两小时自动将未归档记忆归位，每周审视一次整体结构（拆分过满的目录、合并过小的目录、补齐目录说明）。
- **拖拽移动与跨目录标签**：你可以在网页上直接拖拽记忆换目录、重命名合并或删除目录；**标签（Tags）**则专门用来串联跨目录的同一人物或同一季度事项。

## 2. 记忆是怎么记下、又是怎么被用上的？

### 四种写入来源

1. **对话里顺手记**：你随口说的约定、偏好或纠正，不用专门说“记住”，助理回答时自动记下，并在当轮回复底部列出。
2. **日常采集整理（`ingest`）**：新采集的飞书群聊、文档和会议记录自动分批提炼为记忆与事项。
3. **存量材料精读（`omem digest`）**：在原件页批量整理历史群聊和旧文档时，可将提炼出的排查经验直接存为指定 Agent 档案的**专属记忆**。
4. **事项收尾沉淀**：复杂事项解决收尾时，除了生成 `cases/…` 案例页，还会自动记下一条指向该案例页的经验记忆。

### 两种召回方式：对话前自动带上 + 任务中主动检索

- **被动召回（不用助理先想起来去查）**：开启向量检索后，每次你发新消息或启动办事任务前，系统会自动计算相似度（开启重排时由 `bge-reranker-v2-m3` 逐条打分把关），把**最相关的最多 5 条记忆**直接附进本轮上下文；不够相关则一条不加，绝不硬塞噪音。
- **常驻偏好与角色专属经验**：
  - **你的偏好**（如“回答先给结论”“周报用表格”）：对话常驻最多 60 条，后台任务按相关性带最多 16 条。
  - **Agent 专属记忆**：当你纠正某个特定角色或档案（如“以后评审先看错误处理”）时，这条经验只属于该 Agent（`agent` 字段隔离），在它上场工作时自动带上（不超过 12 条时全带，超出时只带和这次任务相近的并附上目录提示），不会污染其他角色的上下文。
  - **任务只带相近的经验**：后台任务和交办开始时，共享的偏好与经验按和任务的相近程度挑，最多 8 条，不够相近的一条也不带（门槛是 `memory.lessonFloor`，默认 0.55）。每条经验后面带着编号 `mem:<id>`，Agent 用到时照常引用，发现哪条不对可以直接更正。
- **主动检索与点击溯源**：助理在调查过程中也会随时调用 `recall` / `search` 按目录或关键词查记忆；记忆正文里指向的案例页、原件行号和其他记忆均可直接点开。

## 补充说明：召回统计与不足信号

- **记忆 → 召回**：清晰统计每条记忆在回答与办事运行中被“自动带上”“按任务挑选”和“助手主动查询”的次数与实际引用率（后台整理时的读取单列，不掺入使用统计）。
- **记忆 → 不足**：自动汇总助理回答说“没找到依据”、被你当场纠正、收到飞书负面表情、运行失败以及被复核撤回的记录，供夜间“做梦”和复盘针对性补齐知识缺口（详见 [学习与进步](./learning)）。
