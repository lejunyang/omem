# 记忆

<Shot src="memory" caption="记忆按目录分层，每条带类型、复核状态和来源" />

记忆是从材料和对话里提炼出来、以后还用得上的东西：事实、约定、决定、人物、偏好和经验。每条都引用它的来源（原件的某几行、某次对话），点开就能看到原话。

## 怎么记下来

- **对话里顺手记**：你随口说的约定和偏好，不用说“记住”，助理回答时会记下，并在回答末尾列出这次记了什么。
- **材料整理**：新采集的群聊、文档交给助理整理，写成记忆和事项。
- **整理一大批旧材料**：原件页“整理”，先“分级”再“精读整理”，写成主题页、案例页、标注和记忆；可以选一个 Agent，把排查经验写成它的专属记忆。
- **排查结束**：事项经过几轮进展才结束时，过程写成案例页，再记一条经验指向它，下次遇到类似问题能召回。

## 用的时候

- **自动带上**：开了向量检索后，你每发一条消息，和它足够相近的记忆（最多 5 条）会附在这一轮里，助理不用先想起来去查；不够相近就什么都不加。
- **主动查**：助理也会按需检索记忆，和原件、Wiki 一起用。
- **记忆里的链接**：指向的案例页、其他页面、原件行和别的记忆都能点，在当前页的引用抽屉里打开。

## 改的时候不覆盖

被更正时，旧版本标记为“已被更正”并链接到新版本。“之前怎么约定的”和“现在是什么”都答得出，也能看到是哪次对话改的。

## 目录

每条记忆在空间里有一个目录（如 `工作/项目A/发布`，最多三层），记忆页左侧是目录树。

- 助理按目录说明选目录，没有合适的才新建并写一句说明；拿不准的先放“未归档”，之后由整理目录的运行归档，每周再看一遍结构（拆太满的、并太小的、补说明）。
- 可以拖到别的目录、改名（改成已有的就合并）、删除目录（记忆上移一层）。
- 标签只用来串起跨目录的东西（同一个人、同一个季度）。

## 质量

记忆多了容易乱，omem 不靠你逐条看：

- **写入前**：确定性检查把免责式、超长、转述原件、事件复述、无来源、重复的退回，告诉模型怎么改。
- **写入后**：每小时由复核模型盲评，保留、改写或撤回；可以再挂几个模型做对比，在“记忆 → 质量”里按模型比较。
- **每晚整理**（新装默认开）：合并重复、处理冲突和过期。
- **不足**：“记忆 → 不足”列出回答说没找到、被你纠正、收到负面表情的回答、失败的运行、被撤回的记忆，每晚整理时逐条看能不能补。

这些怎样让助理越用越好，见 [学习与进步](./learning)。

## 专属记忆

纠正某个 Agent 时（“以后评审先看错误处理”），记成它的专属记忆，只在它工作时带上。见 [Agent 与技能](./agents)。
