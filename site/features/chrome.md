# 浏览器扩展：拾取走查、录制与调试

omem 的 Chrome 扩展（位于仓库 `chrome/` 目录）把你的日常浏览器和 omem 直接连起来，主要解决三类事：
1. **「拾取」做前端 UI 走查与素材收集**：点一下页面元素就能看 CSS 样式、量间距、截整页长图，带着精准的 DOM 路径一键发给 omem 提问或存为原件。
2. **「录制」与「演示」教助手做网页操作**：在自己的浏览器里把后台操作做一遍、标出重点元素，直接上传给 omem 提炼成可复用的技能或关注经验。
3. **免调试提示条的开发者工具（DevTools）**：提供网络请求筛选、接口 Mock、资源搜索、用户状态切换与居中设备模拟，且**默认不触发 Chrome 烦人的“已开始调试此浏览器”顶部横幅**。

## 1. 安装与连接 omem

在仓库根目录下构建扩展：

```bash
pnpm install --filter omem-chrome
pnpm --filter omem-chrome run build
```

打开 Chrome 的 `chrome://extensions`，开启右上角**开发者模式**，点击**「加载已解压的扩展程序」**并选择 `chrome/dist` 目录。

- **连接多台 omem**：打开扩展侧边栏（<kbd>Alt+Shift+S</kbd>），在顶部「连接 omem」里可保存并随时切换多条连接——支持**本机**、**远程服务器地址**，以及**经已登录节点中继的配对设备**。连接时在弹出的 omem 确认页核对确认码并点「允许」，扩展就会拿到专属令牌（可随时在 omem **账号 → 命令行与 MCP** 中撤销），并在顶部下拉框选择要发往哪个可写空间。

## 2. 拾取（<kbd>Alt+Shift+X</kbd>）：截图、看样式、量间距、带 DOM 问 omem

前端走查页面发现样式不对，或者网上看到几段资料想合在一起问助手时，按 <kbd>Alt+Shift+X</kbd>（或点工具栏扩展图标选「拾取」）：

| 操作手势 | 效果 |
| --- | --- |
| **悬停并单击元素** | 实时高亮外边距（Margin）、内边距（Padding）与内容区；单击锁定后，浮层直接列出与默认值不同的**字体、字号/行高、字重、颜色、尺寸、内外边距、边框、圆角、背景与阴影** |
| **按住 <kbd>Shift</kbd> 点另一个元素** | **实时测量两个元素之间的像素间距**（分离时量外间隙，嵌套时量四边内距，未对齐时直接标出相差几像素） |
| **按住 <kbd>Alt</kbd> 点击页面** | 临时把点击交还给网页本身（例如先点开一个下拉菜单，松开 <kbd>Alt</kbd> 再去拾取菜单里的选项） |
| **框选区域 / 可视区 / 整页长图** | 支持自由框选或截整页（自动逐屏滚动拼接，吸顶导航栏只保留在第一屏，不会每屏重复出现）；按 <kbd>Enter</kbd> 确认记入「拾取篮」 |

### 在侧边栏「拾取篮」（<kbd>Alt+Shift+S</kbd>）里组合提问

- 每条拾取记录都带有编号、高亮标注缩略图和来源页面。
- 在底部输入框写问题或修改要求时，输入 `#`（或点记录上的「引用」）即可把某条元素记录作为引用块插进正文。
- 点**「问 omem」**（助手回答直接在侧边栏显示）或**「存为原件」**（存为笔记与图片原件）时，扩展会自动附带该元素的**精确 CSS 选择器路径、`id / class / data-* / aria-*` 属性、文本内容与精简后的 HTML 结构**（超大容器自动只取首尾与子元素计数）——编码 Agent 拿到就能直接定位到代码组件，不用猜你说的是页面上哪个按钮！也支持点「复制为 Markdown」贴到别处。

## 3. 录制与演示：在自己的浏览器里做一遍，教给助手

你不需要打开远程桌面，直接在自己当前登录好的 Chrome 里就能把操作流程教给 omem：

1. **「录制」（固定操作流程 → 提炼成技能）**：
   - 在扩展侧边栏切到**「录制」**，写一句要教什么（如“去商户后台查退款单状态”），点「开始录制」。
   - 照常点击、填表、切换标签页；遇到需要跟助手交代判断标准的地方，点**「加标记 → 在页面上指出」**，点一下那个元素写一句“可退金额大于 0 才能退”。（密码、验证码、卡号输入框只记动作绝不记内容；请求里的 Cookie/Token 自动脱敏为占位符）。
   - 点「停止」后可删掉点错的多余步骤，点**「整理成技能」**上传给 omem——助手会复述步骤、和你确认可变参数与成功标志后保存为技能。
2. **「演示」（跨网页查看 + 飞书回人 → 提炼成关注经验或技能）**：
   - 在侧栏顶部点**「演示」**（也可在 omem 关注页或飞书里发 `/演示 要教什么`），把你在浏览器里的「拾取」标记、「录制」片段以及你这段时间在飞书群里回复同事的消息**按时间合成为一条完整时间线**交给助手，让它学会“遇到这类群消息该去哪个页面看哪个数字、怎么回复对方”。

## 4. 为什么默认不连 Chrome 调试接口（CDP）？

只要扩展连接了 Chrome 的 `chrome.debugger`（CDP 接口），Chrome 就会在所有浏览器窗口顶部强制挂一条无法隐藏的黄条：「已开始调试此浏览器」。

为了不打扰你日常上网，omem 扩展**默认不连接 CDP**，而是用页面注入脚本实现了核心调试能力：
- **免 CDP 即可用**：DevTools 里的网络请求面板、**Fetch / XHR 接口 Mock**（授权站点后从页面首屏第一个请求即生效，不打开 DevTools 也生效）、请求调用栈追踪、资源搜索、用户状态切换与**居中设备模拟器**。
- **按需开启「CDP 增强」**：只有当你需要使用“禁用缓存”“网络限速”或“在原页面直接启用设备模拟”这三项强依赖 CDP 的功能时，才在扩展右上角或面板工具栏打开**「CDP 增强」**开关，用完随手关掉，顶部黄条即刻消失。
