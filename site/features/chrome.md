# 浏览器扩展

omem 助手的 Chrome 扩展（仓库里的 `chrome/`）。两类用途：调试网页（DevTools 里的网络面板、Mock、设备模拟、切换登录状态），以及截图和 UI 走查用的「拾取」。

## 安装

```bash
pnpm install --filter omem-chrome
pnpm --filter omem-chrome run build
```

打开 `chrome://extensions`，开启开发者模式，「加载已解压的扩展程序」选仓库里的 `chrome/dist`。

## 拾取：截图、看样式、量间距

走查一个页面或收集素材时，点工具栏的 omem 图标，在「拾取」一栏选元素、区域、可视区或整页；也可以按 `Alt+Shift+X` 直接开始选元素。

- 悬停元素能看到它的外边距、内边距和内容区。单击选中后，旁边列出字体、字号与行高、字重、颜色、尺寸、内外边距、边框、圆角、背景和阴影，只列和默认值不同的项。
- 按住 `Shift` 再点别的元素，量它和选中元素之间的距离：分开时量间隙，包含时量四边的内距，没对齐时量差了几像素。
- 想先操作页面（比如展开下拉菜单再去选里面的项）时按住 `Alt`，点击会交给页面。
- 按 `Enter` 记下。截图默认带上高亮和距离线，工具条上的「标注」可以关掉。整页截图会逐屏滚动拼起来，固定在顶部的导航只保留在第一屏。

记下的内容在「拾取篮」里（popup 里的按钮或 `Alt+Shift+S`，在浏览器侧边栏打开）：

- 每条有编号、缩略图、来自哪个页面。点开看大图、元素的完整样式和间距，写一句说明，或复制图片、下载。
- 底部的输入框用来写需求或问题：点记录上的「引用」，或输入 `#` 选一条，把它作为引用块插进正文，前后接着写。草稿会自动保存。
- 「复制为 Markdown」把正文和引用到的记录（页面、元素样式、间距、说明）整理成一段文字。直接发给 omem 处理的入口还在做。

截图和记录只存在这个浏览器里（扩展自己的存储），不上传。

## 为什么默认不连调试接口

扩展只要用到 Chrome 的调试接口（CDP），Chrome 就会在所有窗口顶部显示「已开始调试此浏览器」，扩展没有办法隐藏。所以默认不连接，大部分功能换成不需要它的做法：

- Mock 由注入页面的脚本改写 fetch 和 XHR 的结果，图片、脚本这类请求不在范围内。在面板里给站点授权后，从页面加载的第一个请求就生效，不打开 DevTools 也生效。
- 请求的调用栈只记录 fetch 和 XHR 发起的。
- 资源搜索只搜 DevTools 能读到的资源。
- 禁用缓存、网络限速和「在原页面启用」设备模拟需要调试接口，默认置灰。前两项可以用 DevTools 自带 Network 面板的同名开关；设备模拟可以用居中模拟器。

需要完整能力时，在 popup 右上角或面板工具栏打开「CDP 增强」，用完再关掉，提示条随之消失。
