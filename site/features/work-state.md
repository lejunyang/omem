# 工作近况与人物卡

一件工作常常要持续几天到几周。助手白天替你做判断——巡检要不要提醒你、“有人找你”时该深入去查还是只做转述、会后哪些待办落到你头上、群里遇到卡点该拉谁协助——**前提是它得知道你这几周到底在忙什么、对面说话的人是谁。**

omem 每晚（默认 `02:50`）自动根据事实材料，在你的 Wiki 个人空间里维护两类页面：**工作近况（`state/work`）**与**人物卡（`people/`）**。你可以直接在网页上查看和修改。

## 1. 工作近况（`state/work`）

后台会读取你最近几周（默认 21 天）发过言的会话、打开或分享过的文档、编码交办与分支、进行中的事项和参加的会议（若当晚没有新材料则不调用模型），整理出五节内容：

| 小节 | 内容说明 |
| --- | --- |
| **摘要** | 3–6 行极简总览：每行对应一条正在推进的线，写明走到哪一步、下一步是什么或卡在哪里 |
| **在推进的事** | 每条线的目标、阶段、截止时间、关联的会话 / 文档 / 代码分支 / 事项（全部带原文引用）与下一步 |
| **最近活跃** | 近期高频参与的会话、文档与编码交办 |
| **要追踪的对象** | 你在“本人补充”里点名要盯的单据或对象，由助手调用数据目录里的对应技能查出最新状态写回此处 |
| **本人补充（永不覆盖）** | **你自己手写的部分**：例如内部系统简称、要追踪哪个平台单据及用哪个技能查、对近况的直接更正（如“项目 A 已暂停”）。**每晚自动整理时，这一节会一字不改地原样保留** |

## 2. 人物卡（`people/<名字>-<邮箱前缀>`）

后台按最近几周与你私聊、`@` 你、或在你发言前后活跃在同群的频率，挑出你常打交道且有新消息的同事（默认每晚最多更新 8 人），每人维护一页人物卡：

- **只记有依据的工作事实**：写明对方属于哪个团队、负责哪块业务、**通常找你要什么、你通常找他要什么、你们之间正在办的事、他习惯什么样的答复节奏**，以及这类事可以找他或他的哪个机器人。
- **句句带引用，绝不写主观评价或私事**：每一条结论都引用具体的聊天原件行；同一个人的多张旧卡会自动合并，旧路径保留别名可正常打开。
- **严格私有**：工作近况与人物卡**只存放在你的个人空间**，群里的访客提问（`guest`）绝对读不到。

## 3. 它们在哪些场景发挥作用？

| 运行场景 | 自动注入什么上下文 | 带来的实际效果 |
| --- | --- | --- |
| **日常与助手对话** | 近况摘要（新会话首轮及近况更新后首轮）；在群里对话时，自动带上该群内有人物卡的成员简介 | 问“接下来先忙哪个”或讨论群内问题时，不用从头交代项目背景和群友职责 |
| **有人找你（分诊与协查）** | 近况摘要 + 发送人的人物卡摘要 | 分诊能立刻认出对方是哪个合作方的负责人、找你问的是不是你手头的主线工作，拟出的回复贴合你们平时的协作关系 |
| **定时巡检** | 你此刻的状态（正在开的会、刚发过言的会话）+ 近况摘要 | 你正在某个群里聊这件事时，巡检不会重复发通知打扰你；优先提醒和主线工作相关的变化 |
| **会后纪要与协同建议** | 近况摘要 + 相关人物卡 | 准确判断会上哪些决定落到你的哪条工作线上；遇到你和助手都处理不了的跨团队卡点（需他人拍板或赋权），**按人物卡主动建议该把谁拉进群**（拉人仍须你在卡片上批准） |

## 补充说明：设置与手动触发

进入 **设置 → 定时任务 → 每晚整理工作近况和人物卡**，你可以：
- 开启/关闭定时整理、修改每晚运行时间（默认 `02:50`）或点**“立即运行”**；
- 调整回看最近几天的材料（默认 21 天）、每晚最多更新几张人物卡（默认 8 张），以及是否将近况自动带入日常对话和后台判断。
