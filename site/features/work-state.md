# 工作近况与人物卡

一件工作常常要做几天到几周。助手白天替你做的判断——巡检要不要提醒你、有人找你时先查还是只转述、会后哪些事和你有关、对话里怎么回答——都要知道你这几周在推进什么、对面是谁。omem 每晚把这些整理成 Wiki 个人空间里的两类页面，你可以直接看和改。

## 工作近况

个人空间的 `state/work`：

- **摘要**：三到六行，每行一条在推进的线，到了哪一步、下一步或卡在哪。
- **在推进的事**：每条线写目标、阶段、截止时间、相关的会话 / 文档 / 代码分支 / 事项（都带引用）、下一步。
- **最近活跃**：最近的会话、文档、编码交办。
- **要追踪的对象**：你在“本人补充”里提到要追踪的东西，现在的状态。
- **本人补充**：你自己写的部分，比如内部系统是什么、要追踪哪个单子和怎么查、对近况的更正（“项目 A 已经暂停”）。每晚整理时这一节一字不改。

整理用的材料是事实：最近几周（默认 21 天）你说过话的会话、打开过或发过链接的文档、编码交办和分支、打开的事项、会议、你让助手做过的事。没有新材料的晚上不调用模型。

要追踪的东西怎么查，写成数据目录里的技能（`library/_skills`）：整理时有对应的技能就照着查一遍状态，写回近况。

## 人物卡

个人空间的 `people/<名字>`，每个常打交道的人一页：哪个团队、负责什么、通常找你要什么、你通常找他要什么、和他之间在办的事、他要什么样的答复、这类事可以找他或他的机器人。每条都引用原消息，只记工作上的事实，不记评价和私事。

“常打交道”按最近几周的私聊、@ 你的次数、你说话前后他在群里的发言算。每晚只更新有新消息的人，最多 8 人（可改）。

人物卡和近况只在你的个人空间：群里的访客提问读不到。

## 用在哪里

| 地方 | 带上什么 |
| --- | --- |
| 和助手对话 | 近况摘要（新会话开始时，以及近况更新后的第一轮）；在群里时，这个群里有人物卡的人 |
| 巡检 | 此刻（在开的会、刚说过话的会话）和近况摘要 |
| 有人找你 | 分诊和处理的材料里有近况摘要，“发送人”后面是对方人物卡的那句话 |
| 会后说明 | 近况摘要：判断会上哪些事落在你手上的哪条线上 |

一件事你和助手都处理不了（要别的团队拍板、要别人的权限），助手会按人物卡建议拉谁进来；拉人进群照旧要你在卡片上批准。

## 设置

设置 → 定时任务 → “每晚整理工作近况和人物卡”：开关、时间（默认 02:50）、立即运行；下面可以改看最近几天、每晚最多更新几张人物卡，以及要不要把近况带进对话和后台判断。
