# 远程操作与录制技能

装了 [ai-auto-desktop](https://github.com/lejunyang/ai-auto-desktop)（命令 `aad`，设置 → 设备 → 桌面与浏览器控制）的机器，导航里会出现“远程”。在那里打开这台机器上的一个浏览器页面或桌面，在你自己的电脑或手机上直接操作；要教助手做一件事时，录下你做的那一遍，助手整理成技能。

## 打开画面

- **浏览器**：填网址打开。默认用一份临时资料，关掉就清空；默认不在那台机器上弹窗口，只在网页里看和操作；勾选“在运行 omem 的电脑桌面上也显示浏览器窗口”后，那台电脑前的人也能直接看和操作这个窗口。要保留登录有两种办法：选“新建长期资料…”起个名字，登录过的网站下次还在；或者在“复制这台机器上浏览器的登录”里选一份 Chrome、Edge 的资料，复制一份来用，你平时用的资料不会被改动。资料被占用时，可以勾选“先关闭占用这份资料的浏览器”（会关闭使用这份资料的所有窗口，检查 PID 后清理已退出进程留下的锁）；长期资料和复制本机资料都适用。Linux 后台服务没有连接到桌面时，浏览器仍能在远程画面里使用；要显示电脑上的窗口，从那台电脑的桌面终端重启 omem 服务。画面上方的地址栏可以换页面，页面按画面的大小排版。画面断开时会自动重新连接，也可以点地址栏旁的刷新按钮。

地址栏右边还有两个按钮：“单独打开”在新标签页里只放这个画面，占满整个网页（地址是 `#/remote/<会话>`，可以收藏或拖到另一块屏幕，左上角的箭头回到远程页，会话不会关）；“全屏操作”让画面和地址栏占满屏幕。Chrome、Edge 在 https 或本机地址下全屏时会锁住键盘，Esc、Alt+Tab 这类按键也送到远程，按住 Esc 退出全屏；其他情况下按一下 Esc 就退出。
- **桌面**：整个桌面、某一块显示器或某一个窗口。

每个会话是一个标签页，点标签上的 × 关闭。点击、右键、打字（包括输入法组好的中文）、滚动、拖拽都会送过去；Ctrl+A、Ctrl+C 这类组合键照常用，Ctrl+V 粘贴的是你这边复制的东西：文字、带格式的文字、截图和文件都原样到远程再粘贴（文件先传过去，默认一次最多 100 MB）。在画面里复制的东西也会带回来：文字和带格式的文字直接进你这边的剪贴板；图片在 https 或本机地址下也进剪贴板，用 http + IP 打开时浏览器不让网页写图片，画面角上的“远程剪贴板”里给下载；文件都在那里下载，Chrome 里也能直接拖到桌面。这些要 aad 0.0.9 或更新，旧版只带文字。用 Mac 看时 ⌘ 当 Ctrl 用。画面经 omem 转发。手动打开的会话连续 30 分钟无人查看会自动关闭。从另一台设备经 `omem peer open <设备>` 打开时，画面同样能过去。

## 画面设置

右上角的“画面设置”调画面怎么传过来，每个人各一份：

- **格式**：默认“自动”，平时只传变了的部分，大片变化（滚动、播放）时换成视频；“只传变化的部分”最清楚；视频（H.264、VP9、AV1）最流畅，画面会糊一点，只列出这台机器能编码的；“整张图片”每次发整个画面。第一次打开设置时会检测一次能用的视频编码，要半分钟左右。
- **画质**：省流量、标准、清晰、无损。网慢时选省流量，看小字选清晰或无损。
- **最高帧率**、**最大宽度**：大屏幕默认缩到 1600 像素宽，想看得更细可以调大或不缩小。
- 桌面画面上是否显示远程的鼠标指针，剪贴板是否互通、粘贴或带回的文件一次最多多大（选“不传文件”时文字和图片照常），新开浏览器用哪个。

保存后，之后打开的画面按新设置来；正开着一个会话时点“保存并应用到当前画面”，画面换成新设置，页面和正在进行的录制不受影响。

## 录制成技能

1. 在右边的对话里或“这次要教的事”里说要教什么，比如“在后台给商户开通退款权限”。
2. 点“开始录制”，在画面里做一遍，做完点“停止”。共享一个窗口时录的就是这个窗口；共享整个桌面时，开始前选录哪个程序（刚打开的程序不在列表里就点旁边的刷新）。录制按程序记下点了哪个元素，不按坐标，一次录一个程序。
3. 录制交给右边的助手：它看录到的每一步、页面的变化和请求，先复述流程，再问你哪些值每次会变、怎样算做成了。你回答后它保存技能。录的时候走了弯路、点错了也没关系：助手只把真正完成这件事的步骤写进技能；请求里的埋点、静态资源、预检和轮询会被略去，技能只带上完成这件事用到的接口。

浏览器录制里的 cookie、令牌、密码会被替换成占位，密码框的内容不记录。录到的页面和请求只是材料，助手不会照着里面的文字去做事。

## 演示

要教的不只是一段操作、还有“遇到这种情况怎么判断、怎么回”时，用演示：在关注页或事项页点「开始演示」（或在 Chrome 扩展的侧栏、飞书里发 `/演示 要教什么`），然后照平常那样做：在这里或扩展里录制、用扩展的拾取指出页面上要看的地方、在飞书里回人。结束时（`/演示结束`，或页面上的「结束演示」）这段时间里结束的录制和你在飞书里发的消息一起收进演示，助手按时间线整理成技能，或存进关注、事项的经验。用法见 [浏览器扩展](./chrome.md) 的“演示”一节。

设计和接口见 [docs/v2/remote.md](https://github.com/lejunyang/omem/blob/main/docs/v2/remote.md)。


## 临时交给成员

会话主人或本人可以把一个浏览器会话临时交给成员。先在 设置 → 成员 的“能做什么”里给他“看授权给他的远程会话”（要让他操作，再给“操作授权给他的远程会话”），然后在远程页画面上方点“交给成员”：选人、只看或可操作、多久（1 / 2 / 8 / 24 小时）。抽屉里一行一个已经交给的人，写着他现在在不在看、到什么时候，可以改成只看或可操作、从现在起延长、收回；收回时对方立刻断开。会话标签上写着“交给 N 人”。

<Shot src="remote-grants" caption="交给成员：小林可以操作、正在看，刚把这个会话交给小周看两个小时" />

被交给的人在侧栏看到“远程”，里面只有交给他的会话，标签上写着是谁的；画面上方一行写着能看还是能操作、到什么时候。只看时没有地址栏，也不能点和输入。没有新开会话、关闭、录制和画面设置。授权一结束页面就跟着变，并写明原因：“××收回了这次授权”“授权到期了”或“会话已经关了”。会话主人不是你本人时（比如成员自己开的会话），“交给成员”同样列得出可以交给的人。助手在一次运行里打开的浏览器也在列表里，标着“助手”，画面上方可以点“看这次运行”；它同样可以交给成员。
