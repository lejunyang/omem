# 远程操作与录制技能

装了 [ai-auto-desktop](https://github.com/lejunyang/ai-auto-desktop)（命令 `aad`，设置 → AI → 桌面与浏览器控制）的机器，导航里会出现“远程”。在那里打开这台机器上的一个浏览器页面或桌面，在你自己的电脑或手机上直接操作；要教助手做一件事时，录下你做的那一遍，助手整理成技能。

## 打开画面

- **浏览器**：填网址打开。默认用一份临时资料，关掉就清空；默认不在那台机器上弹窗口，只在网页里看和操作；勾选“在运行 omem 的电脑桌面上也显示浏览器窗口”后，那台电脑前的人也能直接看和操作这个窗口。要保留登录有两种办法：选“新建长期资料…”起个名字，登录过的网站下次还在；或者在“复制这台机器上浏览器的登录”里选一份 Chrome、Edge 的资料，复制一份来用，你平时用的资料不会被改动。资料被占用时，可以勾选“先关闭占用这份资料的浏览器”（会关闭使用这份资料的所有窗口，检查 PID 后清理已退出进程留下的锁）；长期资料和复制本机资料都适用。Linux 后台服务没有连接到桌面时，浏览器仍能在远程画面里使用；要显示电脑上的窗口，从那台电脑的桌面终端重启 omem 服务。画面上方的地址栏可以换页面，页面按画面的大小排版。画面断开时会自动重新连接，也可以点地址栏旁的刷新按钮。
- **桌面**：整个桌面、某一块显示器或某一个窗口。

每个会话是一个标签页，点标签上的 × 关闭。点击、右键、打字（包括输入法组好的中文）、滚动、拖拽都会送过去；Ctrl+A、Ctrl+C 这类组合键照常用，Ctrl+V 粘贴的是你这边复制的文字，在画面里复制的文字也会带回你这边。用 Mac 看时 ⌘ 当 Ctrl 用。画面经 omem 转发，只有打开这个会话的人能看；30 分钟没人看会自动关掉。从另一台设备经 `omem peer open <设备>` 打开时，画面同样能过去。

## 画面设置

右上角的“画面设置”调画面怎么传过来，每个人各一份：

- **格式**：默认“自动”，平时只传变了的部分，大片变化（滚动、播放）时换成视频；“只传变化的部分”最清楚；视频（H.264、VP9、AV1）最流畅，画面会糊一点，只列出这台机器能编码的；“整张图片”每次发整个画面。第一次打开设置时会检测一次能用的视频编码，要半分钟左右。
- **画质**：省流量、标准、清晰、无损。网慢时选省流量，看小字选清晰或无损。
- **最高帧率**、**最大宽度**：大屏幕默认缩到 1600 像素宽，想看得更细可以调大或不缩小。
- 桌面画面上是否显示远程的鼠标指针，画面里复制的文字是否带回你这边的剪贴板，新开浏览器用哪个。

保存后，之后打开的画面按新设置来；正开着一个会话时点“保存并应用到当前画面”，画面换成新设置，页面和正在进行的录制不受影响。

## 录制成技能

1. 在右边的对话里或“这次要教的事”里说要教什么，比如“在后台给商户开通退款权限”。
2. 点“开始录制”，在画面里做一遍，做完点“停止”。共享一个窗口时录的就是这个窗口；共享整个桌面时，开始前选录哪个程序（刚打开的程序不在列表里就点旁边的刷新）。录制按程序记下点了哪个元素，不按坐标，一次录一个程序。
3. 录制交给右边的助手：它看录到的每一步、页面的变化和请求，先复述流程，再问你哪些值每次会变、怎样算做成了。你回答后它保存技能。录的时候走了弯路、点错了也没关系：助手只把真正完成这件事的步骤写进技能；请求里的埋点、静态资源、预检和轮询会被略去，技能只带上完成这件事用到的接口。

浏览器录制里的 cookie、令牌、密码会被替换成占位，密码框的内容不记录。录到的页面和请求只是材料，助手不会照着里面的文字去做事。

设计和接口见 [docs/v2/remote.md](https://github.com/lejunyang/omem/blob/main/docs/v2/remote.md)。
