# 远程操作与录制技能

安装了 [ai-auto-desktop](https://github.com/lejunyang/ai-auto-desktop)（命令 `aad`，运行 `omem setup desktop` 或在 **设置 → 设备 → 桌面与浏览器控制** 一键安装）之后，omem 左侧导航会出现**“远程”**。

它解决两件事：
1. **随时用电脑或手机远程操作常驻机器上的浏览器或桌面**（保留长期登录态、双向同步剪贴板与文件）。
2. **不用写繁琐的操作文档，你亲手做一遍给助手看（“录制”或“演示”），助手就能把它提炼成可复用的技能、关注经验或接口审批规则。**

## 1. 把操作教给助手：录制、演示与生成接口审批规则

### ① 录制成技能（适合固定系统的操作流程）

想教助手在内部后台给商户开通权限、填某张表或查某张单据：
1. 在“远程”页右侧对话框填一句**“这次要教的事”**（如“在后台给商户开通退款权限”），点**“开始录制”**（也可以直接在自己电脑的 [Chrome 扩展](./chrome) 侧边栏里点录制）。
2. 在画面里照平常那样做一遍，做完点**“停止”**。
   - **按语义元素记录，不按死坐标乱点**：系统记录的是点了哪个 DOM/界面元素、填了哪个输入框、页面发生了什么变化以及发出了哪些网络请求（即使你中途走弯路点错了，助手也会自动剔除无用步骤，并过滤掉埋点、静态资源和轮询请求）。
   - **敏感信息自动脱敏**：密码框、验证码只记“填了”不记内容；请求里的 Cookie 和 Token 自动替换为占位符。
3. 停止后，右侧的助手会按内置技能 `skill-from-recording` **先向你复述一遍流程，问清哪些参数每次会变、看到什么标志算成功**，经你确认后直接保存为标准技能。

### ② 演示（适合“看页面状态 + 判断 + 在飞书里回人”的综合处理）

有些值班工作不是纯点击，而是**“群里有人报障 → 你去后台看一眼某个数字 → 判断能不能退 → 回到飞书群里答复对方”**。这类跨端判断用**“演示”**来教：
1. 在关注页、事项页、Chrome 扩展侧栏顶部点**「开始演示」**（或在飞书里发 `/演示 要教什么`）。
2. 照常处理：用扩展的「拾取」指一下后台页面上看的关键位置（写一句“看这里，可退金额大于 0 才能退”并点「记进演示」），需要录一段点击就用「录制」，然后直接在飞书群里照常回复同事。
3. 点**「结束演示」**（或发 `/演示结束`）：omem 会把这一段时间内的**拾取标记、浏览器录制和你在飞书里发出的真实消息按时间排成一条完整时间线**交给助手，提炼成技能或直接写进该「关注」的专属排查经验里，下次遇到同类报障照着办。

### ③ 从录制里一句话圈出“需要审批的敏感接口”

录完一次网页操作后，如果其中某一步（比如第 3 步点了“取消订单”）很敏感，你希望以后 Agent 自动调用该接口前必须先经人工批准：
- 直接对助手说：**“刚才那个取消订单的接口要审批”**。
- 助手会从录制记录里精准找出那条请求，自动把动态单号通配为 `POST /api/v1/orders/*/cancel`，并生成一张确认卡片（列出域名、路径、操作步骤及在录制中命中的次数）。你点**“启用”**后，该规则立即加入 **设置 → 安全 → 操作规则**。

## 2. 在浏览器里打开远程浏览器或桌面

在“远程”页，你可以随时新建标签页打开常驻机器上的画面（经 `omem peer open <设备>` 连接的远程设备同样可用）：

| 模式 | 核心特性与登录态复用 |
| --- | --- |
| **远程浏览器** | • **默认后台无窗口运行**：只在你的网页画面里显示和操作（也可勾选“在运行 omem 的电脑桌面上也显示窗口”）<br/>• **三种资料模式**：默认用**临时资料**（关掉即清空）；可选**新建长期资料**（如 `remote/profiles/后台`，登录过一次单点登录下次直接复用，Agent 跑 `desktop-control` 技能时也共用同一份长期资料）；或勾选**复制本机 Chrome / Edge 的已有资料**（支持自动关闭正占用该资料的旧窗口）<br/>• **独立全屏**：地址栏右侧支持“单独打开”（新标签页铺满整个浏览器，可拖到副屏）与“全屏操作”（自动锁定键盘，把 `Esc` / `Alt+Tab` 等快捷键原样送往远程，长按 `Esc` 退出） |
| **远程桌面** | 可选择共享**整个桌面、某一块显示器或某一个指定程序窗口**；录制整个桌面时可在开始前选择针对哪个程序记录元素 |

### 顺畅的键鼠、中文输入法与双向剪贴板

- **键鼠与输入法**：点击、右键、滚动、拖拽以及本机输入法组好的中文直接送达；Mac 上打开时 <kbd>⌘ Cmd</kbd> 自动映射为 <kbd>Ctrl</kbd>。
- **双向剪贴板与文件直传（需 `aad 0.0.9+`）**：
  - **粘进去（本机 → 远程）**：按 <kbd>Ctrl V</kbd> 可把本机复制的纯文本、富文本、截图甚至**最大 100 MB 的文件**原样传过去并粘贴。
  - **带回来（远程 → 本机）**：在远程画面里复制的文字和图片（HTTPS 或 localhost 下）直接进你本机的剪贴板；在远程复制的文件可在画面角落的“远程剪贴板”里一键下载或直接拖到本机桌面。
- **自适应画面设置**：右上角“画面设置”默认采用**“自动”模式**（静止或局部小改动时只传高清增量图块，大面积滚动或播放时自动切换为 H.264 / VP9 / AV1 视频流），也可手动调节画质（省流量 / 标准 / 清晰 / 无损）、帧率与最大宽度，并一键应用到当前开着的会话。手动打开的会话连续 30 分钟无人查看会自动关闭。

## 3. 多人协作：把会话临时交给同事，或给成员开独立浏览器

<Shot src="remote-grants" caption="把远程浏览器临时交给成员：小林拥有可操作权限且正在查看，小周拥有 2 小时只读查看权限，随时可调整或一键收回" />

- **把浏览器会话临时交给同事（协助登录或排查）**：当你（或正在跑任务的 Agent）打开了一个远程浏览器会话，需要让某位同事帮忙扫个码、看一眼现象或操作两步时，点画面上方的**“交给成员”**——选人、选**“只看”**或**“可操作”**（可操作的浏览器需在打开时勾选“给成员用”）、选有效时长（1 / 2 / 8 / 24 小时）。对方在侧栏“远程”里只能看到这一个授权给他的标签页；你在抽屉里能实时看到他是否在看，随时可延长、降为只读或**一键收回（收回即刻断开连接）**。
- **给成员开他自己的远程浏览器**：在 **设置 → 成员 → 能做什么** 里授予成员“用自己的远程浏览器”后，成员可以打开属于他自己的远程浏览器并保存他自己的长期登录资料（你可以把 `#/remote?profile=后台&url=https://…` 直接发给他去登录）。
- **严格的内网安全隔离**：无论是成员自己的远程浏览器，还是勾选了“给成员用”交给同事操作的浏览器，**宿主都会强制拦截对运行 omem 那台机器自身地址（`localhost`、`127.0.0.1`、本机局域网 IP 及指向它们的域名）的一切访问**，且成员永远无法打开远程桌面或借用你本机的浏览器资料。
