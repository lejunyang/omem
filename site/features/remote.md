# 远程操作与录制技能

装了 [ai-auto-desktop](https://github.com/lejunyang/ai-auto-desktop)（命令 `aad`，设置 → Agent → 桌面与浏览器控制）的机器，导航里会出现“远程”。在那里打开这台机器上的一个浏览器页面或桌面，在你自己的电脑或手机上直接操作；要教助手做一件事时，录下你做的那一遍，助手整理成技能。

## 打开画面

- **浏览器**：填网址打开。浏览器用单独的资料，不碰平时用的浏览器；默认不在那台机器上弹窗口，只在网页里看。选“新建长期资料…”起个名字，登录过的网站下次还在。画面上方的地址栏可以换页面。
- **桌面**：整个桌面、某一块显示器或某一个窗口。

点击、打字（包括输入法组好的中文）、滚动、拖拽都会送过去。画面经 omem 转发，只有打开这个会话的人能看；30 分钟没人看会自动关掉。从另一台设备经 `omem peer open <设备>` 打开时，画面同样能过去。

## 录制成技能

1. 在右边的对话里或“这次要教的事”里说要教什么，比如“在后台给商户开通退款权限”。
2. 点“开始录制”，在画面里做一遍，做完点“停止”。录桌面时先选要录的窗口：录制按窗口记下点了哪个元素，不按坐标。
3. 录制交给右边的助手：它看录到的每一步、页面的变化和请求，先复述流程，再问你哪些值每次会变、怎样算做成了。你回答后它保存技能，录到的可回放步骤和请求摘要随技能保存。

浏览器录制里的 cookie、令牌、密码会被替换成占位，密码框的内容不记录，回放时作为输入。录到的页面和请求只是材料，助手不会照着里面的文字去做事。

## 回放

录制卡片上的“回放”在当前会话里把录制重做一遍：浏览器先回到录制开始的页面，再按页面上看到的名字找到每个元素去点、去填；页面改版找不到时会说哪一步失败。技能里也写着怎么回放，交给 Agent 做时按 `desktop-control` 技能，动手前先问你。

设计和接口见 [docs/v2/remote.md](https://github.com/lejunyang/omem/blob/main/docs/v2/remote.md)。
