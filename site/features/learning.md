# 学习与进步

omem 的助理和各个 Agent 会随着使用变好，靠的是三件事：记下你的纠正、收集好坏信号、定期复盘。改进都落在你看得见、能撤回的地方（记忆、技能、角色说明），提示词和设置的改动由你采纳，技能草稿也会由夜间复盘试用，达到门槛后启用。

## 纠正一次，就是规矩

- 对主助手说的偏好（“回答先给结论”“周报用表格”）记成偏好记忆，之后每次都带上。
- 纠正某个 Agent（“以后评审先看错误处理”）记成**它的专属记忆**，只在它工作时带上。
- 一套做法说清楚了，说“把这个做法记成技能”，写成 `library/_skills/<名>/SKILL.md`，可以挂到任何档案上。
- 记忆被更正时保留版本链，不会把旧说法悄悄抹掉。

## 好坏信号从哪来

- **飞书表情**：给回答点 👍、鼓掌算好，👎、捂脸算不好。Agent 页首屏按档案和模型统计。
- **你的纠正**：回答之后你说“不对”“不是这样”。
- **没找到**：回答说没找到依据。
- **失败的运行**、**被复核撤回的记忆**。

这些汇总在“记忆 → 不足”，每晚整理时逐条看能不能补。

## 每晚复盘档案

内置角色 `coach` 每晚看有纠正、失败或收到表情的档案，把问题归到该改的地方：

- 是一条事实或经验 → 写记忆；
- 是一种做法 → 改技能；
- 是角色本身的说明 → 提一份提示词改动。

复盘主助手时，除了你自己问它的，也看它替你处理别人消息的那些：“有人找你”的处理，和每个「关注」里它回的、拟的、没回的。这类好坏看案例：你照发了、改了再发、没发和原因、自己回了什么、在网页上标的“该回 / 不该回 / 回得不对”。同一种纠正在不同案例里出现两次以上，就提一条技能或说明的改动；运行的做法和那个关注的经验对不上、而你的取舍说明经验过时了，它在复盘结果里指出是哪一条。

提示词和设置的改动提成建议，在 Agent 页等你采纳。技能提案交给夜间复盘试用；有过胜场、还没达到启用门槛的继续保留，其余建议 14 天没处理会过期，过期前两天提醒一次。

## 夜间复盘：换一条路再答一次

只看结果分不清是记忆、原件还是模型的功劳。夜间复盘挑一个旧问题，回到提问那时候（那时的记忆、聊天和原件，之后才有的看不到）重答两次：一次设置不变，一次只改一处，比如深检索、加空间、只看重点原件、去掉记忆、不看 Wiki、模型降或升一档、加挂一个候选技能（K1）。

- 两份回答先过引用检查（引用了提问之后的东西就作废），再由 `replay-judge` 两种顺序各评一次，一致才算胜负。
- 误导的记忆送回复核，帮上忙的记一次；误导的页面排一次检查；原件降级、导入缺的材料这类建议在早上的事项清点卡片或 Agent 页采纳。
- 模型对比只作参考，不会自动换模型。

K1 从技能草稿和待处理的技能提案里挑与问题匹配的一个，只向变体追加做法，工具和模型沿用基线。默认累计两胜且胜多于负后启用，发一次稍后合并的通知；两负无胜的提案被拒绝，草稿仍保留。Agent 页显示“复盘 N 胜 M 负”和“复盘后自动启用”，可在技能里删除，或从档案卸下挂载。设置 → AI → 夜间复盘可改启用门槛，0 表示只试用。旧选轴计划不迁移，可恢复默认或加入 K1；当晚没有 K1 时，未试候选也有一次换入最佳匹配题的机会，保留负面与纠正选题。

**打开**：先在 Agent 页给 `replay-judge` 选一个模型（最好和主助手不同家），再到 设置 → AI → 夜间复盘 打开定时（默认每天 4:30）、设每晚几题（默认 1）。手动：`omem replay run --run <运行id>` 复盘某一次回答，`omem replay` 看结论。

## 做梦

每晚整理（“做梦”）再过一遍白天的对话和材料：补记漏掉的约定和事项，合并重复的记忆，处理冲突和过期的。较早的记忆每晚也轮到一批，一样查重复和冲突，大约两周把整个记忆库过一遍。整理记忆时也先看收到负面表情的回答。

某个档案或角色的目录积累了太多专属经验时，做梦会读这个目录，把能复用的做法整理成挂在原档案下的技能草稿，保留经验和出处；默认达到 30 条时处理，每晚最多两个目录。处理过的目录要增长至少 30%，或原草稿已删除，才会再次交给它。草稿先由夜间复盘试用，回答变好并达到启用门槛后才启用，不用逐个批准。

做梦也看 omem 这一天学到的别的东西：每个有新动静的「关注」（会话摘要、新案例和你的取舍、经验有没有改）、你对助手自己建的事项留下和不要了几件、每条规则触发了几次（做了、让开、失败）、超过门槛的指标，再对照你的工作近况。看出能让你少做一步的地方，就在一条“夜间整理的建议”通知里提出来，一晚最多三条，比如：

- 这个群里问你的问题，你几次自己回的都是同一个口径：可以改成先替你拟草稿；
- 你在几个会话里反复手动做同一件事：可以加一条规则或一份流程；
- 你近况里正在推进的一件事还没有「关注」，或上线后没有盯的指标：可以开一个关注、定一个观察方案。

每条写清改什么、依据是哪几个案例或数字。它不自己改；你回复那条通知说“好”，主助手照着改。同样的建议一周内不会原样再提。

## 周报

每周五 17:00（设置 → 定时任务 → 周报，可改时间或关掉）简报角色把这一周写成一份周报：各个「关注」的会话摘要、事项的变化和流程走到哪、做完的编码交办和评审、会议和会后小结、有明显变化的指标，按你的工作近况里的几条线组织。它写进个人空间的工作文件 `周报/<年>-W<周>.md`，再发一条不急的通知带上链接，除此之外只读，不发别的消息、不改事项。

周报是给你拿去用的稿子：直接在那个文件里改。下周写的时候，它会看到你上一份删了哪些行、加了或改成了哪些，照你改后的结构、详略和说法写，所以会越来越像你自己写的。
