# 学习与进步

omem 的助理和各个 Agent 会随着使用变好，靠的是三件事：记下你的纠正、收集好坏信号、定期复盘。改进都落在你看得见、能撤回的地方（记忆、技能、角色说明），提示词和技能的改动要你采纳才生效。

## 纠正一次，就是规矩

- 对主助手说的偏好（“回答先给结论”“周报用表格”）记成偏好记忆，之后每次都带上。
- 纠正某个 Agent（“以后评审先看错误处理”）记成**它的专属记忆**，只在它工作时带上。
- 一套做法说清楚了，说“把这个做法记成技能”，写成 `library/_skills/<名>/SKILL.md`，可以挂到任何档案上。
- 记忆被更正时保留版本链，不会把旧说法悄悄抹掉。

## 好坏信号从哪来

- **飞书表情**：给回答点 👍、鼓掌算好，👎、捂脸算不好。Agent 页首屏按档案和模型统计。
- **你的纠正**：回答之后你说“不对”“不是这样”。
- **没找到**：回答说没找到依据。
- **失败的运行**、**被复核撤回的记忆**。

这些汇总在“记忆 → 不足”，每晚整理时逐条看能不能补。

## 每晚复盘档案

内置角色 `coach` 每晚看有纠正、失败或收到表情的档案，把问题归到该改的地方：

- 是一条事实或经验 → 写记忆；
- 是一种做法 → 改技能；
- 是角色本身的说明 → 提一份提示词改动。

提示词和技能的改动提成建议，在 Agent 页等你采纳；14 天没处理会过期，过期前两天提醒一次。

## 夜间复盘：换一条路再答一次

只看结果分不清是记忆、原件还是模型的功劳。夜间复盘挑一个旧问题，回到提问那时候（那时的记忆、聊天和原件，之后才有的看不到）重答两次：一次设置不变，一次只改一处，比如深检索、加空间、只看重点原件、去掉记忆、不看 Wiki、模型降或升一档。

- 两份回答先过引用检查（引用了提问之后的东西就作废），再由 `replay-judge` 两种顺序各评一次，一致才算胜负。
- 误导的记忆送回复核，帮上忙的记一次；误导的页面排一次检查；原件降级、导入缺的材料这类建议在早上的事项清点卡片或 Agent 页采纳。
- 模型对比只作参考，不会自动换模型。

**打开**：先在 Agent 页给 `replay-judge` 选一个模型（最好和主助手不同家），再到 设置 → Agent → 夜间复盘 打开定时（默认每天 4:30）、设每晚几题（默认 1）。手动：`omem replay run --run <运行id>` 复盘某一次回答，`omem replay` 看结论。

## 做梦

每晚整理（“做梦”）再过一遍白天的对话和材料：补记漏掉的约定和事项，合并重复的记忆，处理冲突和过期的。整理记忆时也先看收到负面表情的回答。
