# 学习与进步

**omem 的主助手和各个专职 Agent 会随着你的使用越变越顺手。** 它不是靠难以捉摸的黑盒微调，而是靠三件透明、可撤回的事：**当场记下你的纠正、自动收集好坏信号、每晚回放复盘与“做梦”提炼。** 所有的改进都落在你看得见的记忆、技能和角色说明里。

## 1. 纠正一次，就成了它的规矩

你在日常使用中随口给出的一次纠正，会按性质存进不同的持久层：

| 你说的话 | 沉淀到哪里 | 什么时候生效 |
| --- | --- | --- |
| “回答先给结论”“周报统一用表格” | **偏好记忆**（个人或空间级） | 此后每次对话和相关任务都会常驻带上 |
| “不对，退款口径改成按实付比例分摊了” | **版本化事实记忆**（`supersede`） | 旧说法标为“已被更正”并链向新说法，历史与现状都答得出 |
| “以后评审先看错误处理”“写方案别列空泛风险” | **对应 Agent 的专属记忆** | 只在那个内置角色或自定义档案上场时带上，不干扰其他角色 |
| “把刚才这套排查步骤记成技能” | **技能文件**（`library/_skills/<名>/SKILL.md`） | 可挂载给任何 Agent 档案按需读取；也可以通过浏览器扩展[录制或演示](./chrome)直接生成技能 |

## 2. 好坏信号自动收集（不用专门填反馈表）

omem 在日常运行中自动收集五类质量信号，汇总在 **记忆 → 不足** 页面：
1. **飞书表情反馈**：对回答点 👍、鼓掌记为好；点 👎、捂脸记为不好（在 Agent 页首屏按档案与模型实时统计好评率）。
2. **你的当场纠正**：回答发出后你紧接着说“不对”“不是这样”，或在编码评审、草稿卡片上选了“不发 / 结论不对 / 太啰嗦”。
3. **回答后的对话走势（`outcome-reviewer`）**：回答发出一天后回扫整段对话，自动识别哪些回答真正解决了问题、哪些被追问补充或被别人接手了。
4. **未找到依据**：助理回答“没找到相关资料”。
5. **运行失败与被复核撤回的记忆**。

## 3. 三套夜间自进化机制：做梦、档案复盘、A/B 回放盲评

每到夜里空闲时段，omem 会启动三套互补的后台运行，把白天的教训转化成改进建议：

### ① 每晚“做梦”（`dreamer`）：清理记忆、提炼技能、建议少做一步

- **记忆去重与经验升格为技能**：重读白天的对话与材料，补记遗漏的约定和事项，合并重复与冲突的记忆；当某个角色或档案的某个目录下积累了超过 30 条专属经验时，自动将可复用的做法提炼为一份**技能草稿**。
- **主动提最多 3 条减负建议**：结合你白天在各个「关注」里的取舍、对自动建事项的去留、规则触发情况和越界指标，在一条“夜间整理的建议”通知里提出最多 3 条可落地的改进（每条带具体案例或数字依据）：
  - *“这个群里问你的问题，你连续几次自己回的都是同一口径 → 建议改为先替你拟草稿”*
  - *“你在几个会话里反复手动查同一件事 → 建议加一条规则或一份流程”*
  - *“你正在推进的某条工作线还没有盯群关注或观测指标 → 建议开启关注或观测方案”*
  它绝不擅自修改设置；你只需对那条通知回复一句**“好”**，主助手就会照着改好。

### ② 档案复盘（`coach`）：把问题归因到记忆、技能或提示词

内置角色 `coach` 每晚专门检查白天收到过纠正、负面表情或运行失败的 Agent 档案（包括主助手在“有人找你”和各个群「关注」里拟稿与被拒的案例）：
- 属于**缺一条事实或经验** → 补充记忆；
- 属于**某类操作步骤不对**（同类纠正在不同案例出现 2 次以上） → 起草技能修改；
- 属于**角色本身的职责说明不清** → 起草一份角色提示词或设置改动建议，放在 **Agent 页**（以及早上的“今天”卡片）等你点“采纳”。

### ③ 夜间 A/B 回放盲评（`replay-judge`）：用真题检验到底谁帮上了忙

只看一次回答的结果，分不清到底是记忆、原件定级、Wiki、技能还是模型本身的功劳。**夜间复盘（Replay）**会挑一道白天被纠正或有代表性的旧问题，**把时间拨回提问那一刻**（只看当时已有的记忆、聊天和原件，严格剔除提问之后才产生的资料），重答两次：
- **基线组 vs 单变量实验组**：一次保持原设置不变，另一次**只改变一个变量**（例如：加深检索、去掉某条记忆、不看某页 Wiki、更换模型档位，或**挂载一份新提议的技能草稿 `K1`**）。
- **正反双序盲评**：两份回答先过时间线引用校验，再交给独立的 `replay-judge`（建议配置与主助手不同家族的模型）按正反两种顺序各盲评一次，两次结论一致才判胜负。
- **优胜劣汰自动闭环**：
  - 被证实**误导回答的记忆**直接送回复核撤回，误导的 Wiki 页面排期重检；
  - **技能草稿（`K1`）实测转正**：新提炼的技能草稿在回放盲评中**默认累计两胜且胜多于负后自动启用**（两负无胜则淘汰），无需你逐个手动审批技能代码！你可以在 Agent 页看到每个技能的“复盘 N 胜 M 负”战绩，随时一键停用或运行 `omem replay run --run <运行id>` 手动复盘。

## 4. 越写越像你的周五自动周报 & 间隔重复学习（FSRS）

- **会学你改稿风格的周报**：默认每周五 `17:00`（可在 **设置 → 定时任务 → 周报** 调整），简报角色会按你的工作线，把本周的关注摘要、事项与流程进展、编码交办与评审、会议小结和关键指标变化，写成个人空间的 `周报/<年>-W<周>.md`。你直接在这个文件里删改定稿；**下周五它再写时，会自动对比你上一篇删了什么、改成了什么句式，照着你改后的结构和详略来写**。
- **FSRS 间隔重复记忆卡**：对于需要你自己背下来的知识（如业务术语、架构要点或[英语练习](./english)里反复答错的表达），在原件页点“生成卡片”或对助理说“每天 8 张卡，晚上九点提醒我”。你可以在网页**“学习”**页或飞书里发 `/review` 按 FSRS 记忆曲线复习，支持与 Anki（制表符文本）双向导入导出。
