# 插件与英语练习

有些事不适合一问一答：出一组题、一次提交、看完结果再出下一组。这类强交互放在插件的页面里做。

## 英语练习

侧栏“英语练习”是内置的第一个插件：

1. 选一个场景（餐厅点餐、工作邮件、面试……，也可以自己写）和侧重点，点“开始”。
2. 陪练按你现在的水平出一组题：中文选英文、英文选中文、听音选意、句子填空、听写、句子翻译。听力题用浏览器朗读，可以慢速重放。
3. 做完点“提交这一组”。选择、填空、听写当场判分并给出答案；翻译由陪练打分，指出具体问题，给更自然的说法。
4. 陪练点评这一组，同时在后台往题库里补题：答错的知识点换个问法，薄弱点多放一些。
5. 点“下一组”，omem 按你的水平、薄弱和该复习的知识点从题库里挑一组，马上就有，不用等陪练。题库里没有这个场景的题时，由陪练现出。随时可以在下面说“太难了”“多来点听力”“这个词怎么用”。

右上角“设置”里可以改出题方式（题库 / 陪练每组现出）、每组题数、朗读口音和语速、每天目标题数。右侧是学习情况：今天完成了目标的多少，词汇、语法、听力、翻译、阅读各自的等级（A1–C2），近 14 天每天做了多少题，以及薄弱的单词、短语和语法点。每道题的作答都记下来，下次出题时陪练会先看这些。

你明确说过的偏好（比如“想多练商务场景”）陪练会记住；反复答错的词可以加成复习卡，在“学习”页按记忆曲线复习。

陪练是 Agent 页里的 `english-tutor`，和其他档案一样可以改说明、换模型、挂技能；出题要求在技能 `english-item-writing` 里，改它就能调整题目风格。

## 插件是什么

一个插件把一类事需要的东西放在一起：Agent 档案、技能、工具、数据和自己的页面。插件页面在隔离的框架里运行，拿不到你的登录令牌，只能读写这个插件自己的数据、和它自己的 Agent 对话。设计见仓库里的 `docs/v2/plugins.md`。

## 自己做一个插件

在数据目录（默认 `~/.omem`）建 `plugins/<id>/`，写一个清单和一个档案就够了：

```yaml
# ~/.omem/plugins/journal/plugin.yaml
id: journal
name: 每日复盘
agents: [coach]          # 档案在 agents/coach.md
tools: [recall, remember]
page: { title: 每日复盘 }
settings:
  - { key: tone, label: 语气, type: select, options: [温和, 直接], default: 温和 }
```

重启后侧栏出现“每日复盘”。没有自己的页面时，omem 给它一个默认页：和它的 Agent 对话，Agent 可以发一张表单让你填（文字、单选、多选、1–5 打分），也可以画柱状图、折线图给你看。设置项在页面右上角的“设置”里改。侧栏里插件的图标由插件自己定（`icon`），不喜欢就在设置 → 插件里点图标换一个。

插件也可以带代码：`server.ts` 注册自己的工具，`services` 声明一个常驻进程（比如每秒采一次机器状态、截屏、连设备），页面通过 omem 和它保持 WebSocket 连接实时显示。带代码的插件第一次出现、或者代码改过之后，要在设置 → 插件里点“信任并运行”才会运行；那里也能看服务在不在跑、最近输出了什么，随时撤销信任。会在机器上动手的工具（点击、输入）可以标成每次都要你批准。

## 在飞书里

在飞书里让插件的 Agent 出题（比如 `/as english-tutor 来一组面试的题`），它会把题放进练习页的一个新会话，回一个链接给你。在设置 → 渠道里填了“网页地址”，这个链接在飞书里能直接打开，通知卡片里的“打开链接”也一样。
