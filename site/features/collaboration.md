# 多 Agent 协作与会话

一件事交给助理之后，它不一定一轮做完：可能要调查、写代码、请另一个 Agent 看一眼、等某人回复。这一页讲这些事情是怎么往前走的，以及你在中途怎么插手。

## 长任务开一个工作会话

复杂的、要好几个 Agent 的事，主助手会开一个独立的工作会话（在飞书里是一个话题）：

1. 主助手把任务交给合适的 Agent（调查的、写文档的、编码的……）。
2. 话题里有一张进度卡，原地更新：第几轮、谁在做什么、最近一步、运行记录的链接。
3. 一轮做完，报告交回主助手。主助手**接手**：能推进的自己续一轮或换一个 Agent，这时只更新进度卡，不发消息；完成或卡住才找你，回复下面折叠着完整报告。
4. 自动推进有上限（你上次说话后默认最多连续 6 次，设置 → AI → 自动推进 可改），不会无止境地跑下去。

编码交办停下时也一样：发起的助理会主动告诉你结果和下一步。

### 话题里发什么

设置 → AI → 过程消息：

- **多 Agent 工作的话题里**：默认“只在完成和卡住时发”。只有这几种时候发消息：工作做完；要你决定或卡住（助手问你、交办失败、到了自动推进的上限）；你在话题里说了话（回答你的那一条照常发）。主助手只是接着交办的那几轮，回复留在网页的工作会话里，每轮的报告和过程在运行页。改成“全部发”就是每轮都发。
- **思考气泡**：默认“只在回答我的消息时”，你自己发的消息，回答它的那一轮有气泡；交办出去的 Agent、主助手看报告、唤醒、规则触发的运行都不显示。也可以改成“全部”或“关”，关掉时只有“处理中”的表情和最后的回答。

### 交办时把工具借给对方

主助手交办前会看对方档案有哪些工具。做完这件事要用、对方又没有的（比如读某张表），主助手要么自己先做好那一步，要么在这一轮把工具借给它（`extra_tools`），省得它每轮回头找主助手代做。只能借主助手这次自己能用的；以你的身份写飞书、在群里发消息、再交办给别人的工具借不出去，这类步骤由对方把内容交回给主助手来做。借出的工具只在这一轮有效，照样按你的权限和这件事的空间范围检查。

## Agent 之间互相请教

一个 Agent 做到一半需要别人的专长时，可以直接问另一个档案（`ask_agent`），比如主助手问报警分析的档案“这类告警以前是怎么处理的”。被问的 Agent 用自己的工具、技能和记忆去查，答案只回到提问的那一轮，由提问的一方决定怎么用；要它真正接手一件事，就交给它做下一轮。

## 中途随时插一句

- **任务进行中补要求**：一轮还在跑的时候你再发消息，它马上收到（Codex 后端直接交进正在进行的这一轮；其他后端在它下一次调用 omem 工具时），不打断、不另开一轮。比如它在查资料时你说“只看 9 月以后的”，它马上就照着改。
- **编码交办中补要求**：运行页的“补充给编码 Agent”或对助手说，编码 Agent 这一轮就收到，最晚在跑检查之前。
- **叫停**：“停止”停下这一轮，不再自动续轮，工作区保留。

## 消息自动排队

- 几秒内连发的几条消息合并成一轮处理。
- 分享群聊、合并转发、图片或文件后再补一句说明时，会多等十几秒，和后面的说明一起处理。
- 一轮没赶上的消息，照常排成下一轮。
- **每个会话一次只处理一轮，不同会话并行**；对话和后台任务用不同的并发槽，生成 Wiki、整理材料不会拖慢你的对话。
- 失败或停下的运行点“重试”，接着原来的会话和工作区做，已经发过的消息不会再发。

## 等一会儿再做

“半小时后看看 CI 结果”“小王发了发布单就检查回滚方案”：助理设一个定时或等消息的唤醒，到时候在原会话里接着做，没变化不打扰你。

## 事件自动触发

不用你开口也能开始一件事：在 [规则](./rules) 里写“遇到什么就做什么”，或在 设置 → 定时任务 里排定时的工作（简报、巡检、周报、夜间复盘）。

## 同时在办的事互相知道

后台常常有好几路在办事：巡检、“有人找你”的处理、盯群、唤醒、规则触发的 Agent。omem 记下每一路在办什么（哪个群和话题、哪条消息、哪件事项），让它们互相知道：

- **不各答一遍**：一路开始时会看到同时在办同一个会话、同一条消息或同一件事项的其他运行，以及它们的结论，先看对方做到哪再动手。
- **你插手了，后台不照发**：后台那一路发通知、发群消息或交出回答之前，如果你在它的范围里说过话（同一个群或话题、回复了触发它的那条消息、在别的会话里谈了同一件事），先把你的话交给它再看一遍：它可能改写，也可能就不发了。它还在跑时你说的话，会在它下一次调用工具时送到。
- **一件事在几个会话里**：助理记事项时会把事项和所在的会话关联起来。之后在任一会话里谈这件事，它都知道别的会话说到哪了；事项页“在这些会话里进行”列出这些会话和正在为它跑的运行。
- **接手**：你直接问助理一件后台正在查的事，它可以停下后台那一路，拿到已经查到的东西接着答，不用重查。
