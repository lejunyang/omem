# 会议

**开会时，omem 的机器人可以进会替你做四件事：完整记录转写与会中聊天、替你听着有没有人点你的名、在会中按呼叫或会议性质实时查资料，以及会后直接推进落到你头上的待办。** 机器人入会前可按规则先发卡片问你，所有参会人都能清楚看到它在会里。

## 1. 怎么让机器人进会

有三种方式触发机器人入会：

1. **按规则：当你自己入会时**：在 [规则](./rules) 页新建触发为“会议 · 我入会时”的规则，或直接对助手说一句话：
   > “我加入标题带‘评审’、三人以上的会议时，问我要不要把机器人拉进去，记录会议，有人问到我时提醒我。”
   omem 通过你的 `lark-cli` 登录感知你入会，按**会议标题、在会人数或日程受邀人数、参会人**匹配条件，支持设为**始终询问**、**直接加入**或**满足条件时询问**（例如“30 人及以上先问我，否则直接进”）。
2. **按规则：群里有人发起会议时（你不在场也能记）**：触发选“会议 · 群里有人发起时”（或“两种都算”）。只要机器人在那个项目群里，群友发起会议时即使你没空参会，它也能先发卡问你（或直接进会）替你把整场会听完记下。
3. **会中直接邀请**：在飞书会议里直接把 omem 的机器人邀请进来（你自己邀请的直接进，同事邀请的会先发卡片请你确认）。

## 2. 会中能做什么：记录、旁听、叫它查、主动查

机器人进会后不会乱发消息刷屏，所有动作都围绕你的上下文展开：

| 会中能力 | 怎么工作 |
| --- | --- |
| **完整记录** | 实时收集语音转写、会中聊天文字、人员进出和会中共享的文档链接，存为一份会议原件；会后自动合并飞书妙记并提炼记忆与事项 |
| **旁听与点名提醒** | 旁听 Agent 默认每 5 分钟（或攒满 60 行）看一段新发言，先由**决策模型预筛**（无关段落不起大模型），把点你名的、要你表态的、分给你的事记下来；同一会话默认连看 8 段后自动轮换上下文 |
| **叫它查（被动问答）** | 参会人在会中聊天输入机器人的名字（或你设的“助理”等称呼，开启后口头说出也算），决策模型确认是在提问后，主助手立刻按你的权限查代码、文档、数据和日志，用 **2–3 句话（200 字内）带依据**作答 |
| **主动查（`meeting-assist`）** | 开启“会上主动查”并选定会议性质后：**问题排查会**自动去查现象对应的代码逻辑、近期改动和指标；**需求评审会**自动去查现有实现与历史决定，指出方案里没说清的点 |

> **安全把关（默认先给你看）**：无论是在会上回答别人的提问，还是主动查出的结论，**默认都先发私聊卡片给你看**，你点“发到会里”机器人才会在会中聊天发出（也可设为直接发，或限制“只有我问才答”、每场最多回答 5 次）。会中随时可在聊天里发 `/ai 停` 暂停当场回答。

## 3. 会后怎么收尾：不复述流水账，直接推进待办

你自己在场听过的会，助手不会再给你发一篇冗长的流水账复述，而是按你的角色直接干活：

- **落到你头上的事逐件推进**：写清做什么、谁提的、何时要，能先做的直接做掉（记入事项并设提醒、查好背景资料、起草回复消息），在纪要里告诉你“已做好什么、还差你哪一步”，需要你点头的直接给按钮。
- **自动同步工作线与改期**：若这场会关联了正在推进的事项或[工作线](./work-lines)，会上敲定的决定、新截止时间会直接更新到事项时间线上并带原话通知你（还在商量是否延期的则列为待定问题）。
- **听会与临时沟通极简处理**：你只是旁听了解的会，只给几句同你手头工作相关的要点；几分钟的临时沟通只写一句结论；没有任何需要你知道的新信息就不发通知。你离会时机器人自动跟着离会。

## 补充说明：权限与会议设置要求

- **飞书会议需开启 AI 纪要**：飞书未向机器人开放原始音频流，机器人依靠飞书会议的实时文字转写工作。因此会议本身需开启**“AI 纪要”**和**“允许智能体加入”**（若进会时未开 AI 纪要，omem 会提示你并在半小时内每分钟自动重试，你在会中补开即可）。
- **一键检查权限**：保存会议规则后，规则页会自动检查 `lark-cli` 个人登录和机器人应用所需的飞书权限（如接收群消息、获取会议基本信息等），缺失的权限直接给出申请或扫码授权链接。
