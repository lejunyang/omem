# 英语练习

侧栏“英语练习”是内置的第一个[插件](./plugins)：按场景出一组题，一次提交，当场判分点评，按你的水平和薄弱点出下一组。

## 一组题怎么做

1. 选一个场景（餐厅点餐、工作邮件、面试……，也可以自己写）和侧重点，点“开始”。
2. 陪练按你现在的水平出一组题：中文选英文、英文选中文、听音选意、句子填空、听写、句子翻译。听力题用浏览器朗读，可以慢速重放。
3. 做完点“提交这一组”。选择、填空、听写当场判分并给出答案；翻译由陪练打分，指出具体问题，给更自然的说法。
4. 陪练点评这一组，同时在后台往题库里补题：答错的知识点换个问法，薄弱点多放一些。
5. 点“下一组”，omem 按你的水平、薄弱和该复习的知识点从题库里挑一组，马上就有，不用等陪练。题库里没有这个场景的题时，由陪练现出。

随时可以在下面说“太难了”“多来点听力”“这个词怎么用”。

## 水平怎么算

每道题的作答都记下来：题目、技能、等级、知识点、你的答案、对错和错误类型。

- 词汇、语法、听力、翻译、阅读各有一个分数，按题目难度和你的得分涨落，折算成 A1–C2 等级。
- **薄弱点**：见过两次以上、正确率不到六成或最近一次答错的单词、短语和语法点。
- **该复习的**：答对过、隔了一段时间没见的知识点，连对次数越多间隔越长。

右侧是学习情况：今天完成了目标的多少、各项等级、近 14 天每天做了多少题、薄弱点。下次出题时陪练先看这些。

## 设置

右上角“设置”：出题方式（从题库挑 / 陪练每组现出）、每组题数、朗读口音和语速、每天目标题数。

## 和其他功能一起用

- 你明确说过的偏好（“想多练商务场景”）陪练会记住。
- 反复答错的词可以加成复习卡，在“学习”页按记忆曲线（FSRS）复习；聊天里 `/review` 也能复习，可与 Anki 互相导入导出。
- 陪练是 Agent 页里的 `english-tutor`，和其他档案一样可以改说明、换模型、挂技能；出题要求在技能 `english-item-writing` 里，改它就能调整题目风格。
- 在飞书里说 `/as english-tutor 来一组面试的题`，它把题放进练习页的新会话，回一个链接给你。
