# 飞书

**omem 用“双身份”无缝融入你的飞书日常：用你本人的身份（`lark-cli`）只读采集你能看到的资料，用机器人的身份（飞书应用）在群里和私聊里为你干活。** 你不用手动把聊天记录和文档搬进知识库，也不用切出飞书去另一个网页提问——材料自己进来，问题在飞书里问，结果和待拍板的事变成交互卡片回到飞书。

## 核心设计：双身份与安全边界

| 身份 | 怎么接入 | 负责做什么 | 安全与权限边界 |
| --- | --- | --- | --- |
| **机器人**（租户应用身份） | `omem setup` 扫码一步创建或绑定已有应用，走官方 SDK 长连接，**无需公网地址** | 回答提问、展示思考气泡与进度卡、发按钮/表单交互卡、入会旁听、在群里 @ 人或加表情 | 只有你（和获准成员）能指挥它；未登记的同事 @ 它自动进入受限的**访客模式** |
| **你本人**（`lark-cli` 个人登录） | `omem setup` 扫码登录，支持每 10 分钟增量轮询 | 读取群聊、私聊、话题、云文档、知识库、日程和妙记，转化为本地原件 | **默认严格只读**；外界消息与文档一律只当材料、不当指令；极少数写操作必须由你亲手发起或批准 |

## 四大能力板块

| 章节 | 核心功能 |
| --- | --- |
| [机器人与卡片](./lark-bot) | 原生思考气泡与进度卡片；提问、表单、图表、方案对比、编码评审与每日“今天”卡片；表情反馈；引用自动转飞书链接与免登录只读分享 |
| [消息、文档与知识库](./lark-capture) | 按会话类型决定“只存”还是“存并整理”；文档连同内嵌图片、画板、表格本地化保存；知识库按目录树爬取，或由 `kb-scout` 按你的方向自动发现并每晚增量阅读 |
| [会议](./lark-meetings) | 你入会或群里开会时按规则询问是否拉机器人进会；记录转写、会中聊天和共享文档；有人点你名或呼叫助理时即时查库协查，会后推进待办 |
| [群里的协作](./lark-groups) | **有人找你**（先过滤、小模型分诊、主助手查清背景并附回复草稿）、**关注**（按问题盯群）、多个机器人分工转交、访客把关、私聊 `/ai` 指令 |

想要让飞书事件自动触发任务（例如“报警群发卡片就开话题排查”“我进评审会就问要不要带机器人”），还可以配合 [规则](./rules) 使用。

## 3 步完成接入

在终端运行 `omem setup` → 选择 **渠道**：

1. **配置飞书机器人**：可绑定已有应用，或直接扫码**一步建好新应用**（自动开启机器人能力、长连接事件 `im.message.receive_v1`、卡片回调 `card.action.trigger` 及所需权限）。扫码人自动登记为这台 omem 的主人。
2. **授权个人只读采集**：按提示用 `lark-cli` 扫码登录你自己的飞书，顺手开启每 10 分钟一次的自动采集。
3. **填写网页地址（推荐）**：在网页 **设置 → 设备 → 网页地址** 填一个你在飞书里能访问的地址（局域网 IP、VPN 地址或域名）。填好后，卡片上的“打开链接”、回答里的内部引用只读分享、插件练习页都能在飞书内直接点开。

> **权限检查与补齐**：随时可在 **设置 → 渠道 → 飞书机器人** 的“机器人权限与事件”中检查缺失的权限，点“扫码更新”一键补齐（企业租户下新权限可能需要管理员审批并在后台发版）。

## 补充说明：什么时候会以你的个人身份写飞书？

Agent **没有任何可以擅自以你个人身份对外发消息、发邮件或发日程邀请的工具**。仅在以下五种由你明确发起或批准的场景下，宿主才会调用你的个人身份执行写操作，且每次均记入 `audit_events` 审计日志：

1. **新建或修改飞书文档**：你让助理“整理成一篇飞书文档”或复制文档时，默认写进你的个人文档库；改已有文档时只做局部块级替换，不整篇覆盖。若目标在共享知识库或他人文件夹，必须先发审批卡到你私聊，你批准后才执行（支持按单个文档或整个知识库节点一次授权、后续复用）。
2. **修改表格、多维表格、云空间文件与任务**：仅放行 `lark-cli` 标为 `write` 的常规操作，拒绝删除、清空等高风险操作；改你自己的文件直接执行，改他人的文件或任务每次先发私聊卡片请你批准。日历、邮件、聊天记录和妙记始终只读。
3. **把 omem 自己的机器人拉进群**：你在规则里配置了“拉机器人进群”或“转发到”，且目标群里还没有该机器人时。
4. **把指定的同事或机器人拉进群**：你开口让助理“把小王拉进项目群”时，助理先发审批卡到你私聊，列出所有群名与人员，你点批准后一次性拉完（只拉 omem 自己或群里见过的熟面孔机器人默认直接拉并告知你，也可在 **设置 → 代你回复 → 拉人进群** 改为全部需批准）。
5. **你亲手发出的私聊代回**：僅在你开启了 **设置 → 代你回复 → 私聊指令** 且亲自在私聊里打出 `/ai` 或 `/ai拉群`，或为“有人找你”开启了带署名的私聊回复时（企业限制 `lark-cli` 发私聊时可切换为经豆包云端会话代发并只读核对）。

## 其他聊天渠道：Telegram、QQ / 微信与插件渠道

除了飞书，你也可以在 `omem setup` 中开启：
- **Telegram**：配置环境变量 `OMEM_TELEGRAM_TOKEN` 与你的 Chat ID，私聊、群、论坛话题各对应一个独立会话。
- **QQ / 微信**：通过 OneBot v11 兼容桥（如 NapCat、LLOneBot）接入，每个私聊或群对应一个会话。
- **插件渠道**：插件可通过 `api.channel` 接入 Matrix 等其他聊天平台（在 **设置 → 渠道** 查看状态并绑定本人 ID）。

这些渠道共享同一套斜杠命令（`/new`、`/as`、`/model` 等）与会话机制；飞书特有的交互卡片、个人文档/知识库采集与会议旁听则仅在飞书渠道提供。
