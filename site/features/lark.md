# 飞书

飞书分两种身份：**机器人**（指挥助理、在群里回答）和**本人采集**（用 lark-cli 以你的身份读取，默认只读）。

## 机器人

`omem setup` → 渠道 → 飞书机器人：绑定已有应用，或扫码一步建好应用（机器人能力、长连接事件、卡片回调和所需权限），不需要公网地址。

- 回答时先加“处理中”表情，再发一张进度卡片，实时显示步骤和正在写的答案，完成后原地变成答案。
- 可以回复或开话题回复、@ 人、发 Markdown、图片、文件和带按钮或表单的卡片；别人点了按钮，会作为新消息回到原来的会话。
- 提问、评审结果、编码进度都用卡片；免打扰时段的普通通知早上补发。
- 可以再加几个机器人，各配一个 Agent 档案，在同一个群里互相 @ 着讨论。
- 给回答加表情就是反馈：👍、鼓掌算好，👎、捂脸算不好，OK、DONE、+1 只算“收到”。Agent 页按档案和模型统计（默认只看你的），夜里复盘会先看收到负面表情的回答。
- 设置 → 渠道 → 机器人权限与事件：检查应用缺的权限和事件订阅，一键申请或扫码补齐；改了事件订阅要在开发者后台发布新版本。

## 回答里的引用

飞书打不开 omem 自己的引用，发出去前逐条换掉：

- 句子里的引用保留文字、链到原处；跟在句末的换成 ①② 小链接，段落不再以一串标题结尾。
- 飞书文档和网页链到原文；群聊里的那句话直接打开飞书会话并定位到那条消息。
- 代码、工作文件、记忆、Wiki 页面这类 omem 自己的东西，发送时复制成一个**只读分享**：打开不用登录，只能看到这条消息引用的那几处，里面再提到的东西点不开。

分享链接放在“网页地址”（设置 → 渠道）上，没填就不生成，这类引用直接省略。默认长期有效；设置 → 分享 改新分享的有效期，看每个分享来自哪次运行、被打开几次，随时撤销。只复制这次运行能读的空间：访客回答不会带出你的个人空间。

## 访客与私聊指令

- **访客提问**（默认关）：没登记的同事 @ 机器人时，先判断回答、拒绝还是不理；回答只读群所在的空间，不读你的个人空间。群里被拒绝的请求会给你发一张只有你看得见的卡片，同意后由助理接着处理。
- **私聊指令**（默认关）：在你和别人的私聊里发 `/ai [要求]`，助理读最近的私聊把事情处理掉，以你的身份回复并署名；`/ai拉群` 建一个你、对方和机器人的群接着处理。这是 omem 仅有的以你身份发消息的地方，只在你亲手发指令时发生。

## 读取你的飞书

- **消息**：每个群或私聊存成一份聊天原件，按类型设“保存并整理 / 与我有关时整理 / 只保存 / 不读取”；图片和文件下载保存。
- **文档**：图片、画板、附件下载到本地，内嵌表格读成表格；链接的文档一并读进来；知识库可以按目录树逐层爬取。
- **历史**：在原件页点“回溯历史”，或 `omem lark backfill`。
- **日程和妙记**也会读进来。

## 写飞书文档

让助理“整理成一篇飞书文档”：它以你的身份新建、追加、改写或移动文档；放进别人也在用的知识库或文件夹时，每次都先把位置发给你批准。

## Telegram 与 QQ / 微信

`omem setup` 的渠道部分开启。QQ / 微信经 OneBot v11 兼容桥接入，命令与飞书相同。
