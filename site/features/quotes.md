# 引用与修改点

在审查编码交办的代码差异（Diff）、阅读评审报告，或者查看右侧抽屉里点开的原件与代码时，你经常会看到几处相互关联的地方，想放在一起追问助手，或者攒起来让编码 Agent 下一轮一并改掉。

## 划选文字后的两个动作

在页面上用鼠标选中任意一段代码或文字，旁边会立刻弹出两个按钮：

| 按钮 | 做什么用 | 怎么配合工作 |
| --- | --- | --- |
| **1. 加入提问** | 把这段内容按 `[1]`、`[2]` 顺序编号放进**提问抽屉**（自动附带所属文件名与精确行号） | 点抽屉右上角的**“缩小”**（或按 <kbd>Esc</kbd>），抽屉会收成右下角一个可自由拖动的悬浮小图标；你可以继续翻看其他文件、再划选第 `[2]`、`[3]` 段加进来，最后点开图标在输入框里用 `[1] 和 [2] 这里的字段为什么不一致？` 一次性提问（提问只读当前交办材料，不会乱改代码） |
| **2. 加入修改点** | 把这段位置记为**下一轮要改的一条具体要求** | 每处可以顺手写一句“这里要怎么改”。等你把整份 Diff 和评审意见看完，点悬浮图标里的“修改点”（或回到交办概览页底部的修改框），就能把攒下的所有修改点和勾选为“改”的评审问题合并在一起，点**“开始修改”**一次交给编码 Agent |

> **自动防丢**：你划选攒下的引用和修改点按运行 ID 独立保存在当前浏览器本地，中途刷新页面或切换标签页都不会丢失，正式发送或提交修改后自动清空。
