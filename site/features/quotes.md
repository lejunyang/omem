# 引用与修改点

<Shot src="review-quotes" caption="两段引用编号后一起提问；抽屉可以缩小成图标，继续选别处" />

在运行页的差异、任务、评审，以及从运行页打开的原件或代码抽屉里，选中一段文字，会出现两个按钮：

- **加入提问**：引用按 [1]、[2] 编号放进提问抽屉，带上文件和行号。点“缩小”（或按 Esc），抽屉变成右下角可拖动的图标，继续选别处再加入；点图标展开，问题里用 [1]、[2] 指代。回答只读这次交办的材料，不改代码，同一个运行沿用一个问答会话。
- **加入修改点**：攒成下一轮要改的内容，每处可以写一句要怎么改。点图标里的“修改点”，和评审里定为“改”的问题一起“开始修改”；概览里的修改框也会带上它们。

引用存在这台电脑的浏览器里，按运行分开，刷新后还在，发送后清空。
