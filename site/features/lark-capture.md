# 消息、文档与知识库

omem 用你的 lark-cli 登录读飞书，默认每 10 分钟一次。读进来的都是[原件](./sources)：之后的问答、Wiki、记忆和事项都从这里引用。只读，不会改动你的消息和文档。

## 消息

每个群或私聊存成一份聊天原件，按追加保存：第一次往前读 72 小时，之后只拉上次之后的新消息，包括话题里的回复。回复别人的消息会带上被引用的那句，图片和文件下载保存，消息里的飞书文档链接读成原件。

会话分四类，每类决定存不存、整不整理：

| 类型 | 默认 |
| --- | --- |
| 单聊（人） | 保存并整理 |
| 机器人单聊 | 只保存 |
| 普通群、话题群 | 与我有关时整理（你发言、被 @、参与的话题有新消息时） |
| 免打扰的会话 | 不读取 |

单个会话可以在 设置 → 渠道 里单独改；订阅的会话按“保存并整理”。omem 机器人自己的私聊和它在群里发的消息不会被采集。

“整理”是把新内容交给助理，写成记忆和事项：同空间的材料等 30 秒合并成一批，每批最多 40 份。

### 历史

- 新会话里要整理的（单聊、订阅的群）默认再往前补 30 天。
- 任何会话都可以在原件页点“回溯历史”，或 `omem lark backfill --name 报警 --days 0` 一次安排一批，或对助理说“把名字带‘报警’的群全部历史读进来，图片附件也补上”。
- 回溯在单独的后台循环里按设定速度读，被限流时自动放慢；按月存成“群名（2026-09 历史）”原件。

## 文档

- 文档里的图片、画板、视频和附件下载到本地，原件页不用登录飞书就能看；内嵌的电子表格读成表格，同步块读出原文，多维表格保留链接。
- 文档里链接的其他飞书文档一并读进来（默认往下两层），链接换成本地原件。
- 你最近打开过的飞书文档（默认 7 天内）每次采集先读，没在聊天里出现过的文档也能进来。
- **更新**：在文档上次修改后 7 天、1 个月、3 个月、半年、一年各检查一次，改过的才重新读并整理。
- **只存一份**：同一篇文档从 /docx/ 和 /wiki/ 两种链接进来，落到同一份原件。

## 知识库

- **发一个链接**：知识库页面的子页面跟着读（从这篇往下两层，一次最多 100 篇）。
- **按目录爬**：“把这个知识库按目录读进来，每天读 200 篇”，或 `omem lark wiki-crawl`。原件页按 知识库 → 节点 → 文档 的层级展示，看到过但没读的节点是灰色的，点“采集”读进来。
- **让它自己发现**：原件 → 知识库 列出你在飞书里能看到的所有知识库（每周日更新）。在那里写一句方向，比如“我负责项目 A 的退款；行政和活动类不用读”，内置角色 `kb-scout` 逐个提议放进哪个空间、要不要新建空间、优先级和关注程度；你采纳、改目标或不读。之后每晚从已归入的知识库共读 30 篇（可改），空间里已有的不重复读。

读进来的知识库可以在目录上整体定关注程度（“这个知识库都是历史资料”），见 [原件与空间](./sources#关注程度)。

## 日程和妙记

日程读前一天到未来一周；妙记读总结、待办和逐字稿。会议本身的记录见 [会议](./lark-meetings)。

## 自动归到对的空间

采集来的材料先看你手动指定的归属，再按 规则 → 归档规则 的条件（标题、正文、网址、采集渠道、知识库目录）匹配，没命中的交给归档角色判断，拿不准的放个人空间。见 [原件与空间](./sources#归档规则)。
