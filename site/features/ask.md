# 问答：带依据的回答

<Shot src="ask-citations" caption="回答里的引用贴在论断旁边，点开到原文那一行" />

在飞书里问，或在网页的“今日”“问答”里问，也可以直接交代事情。助理用 omem 的工具检索原件、读原文、查记忆，再回答。

## 一个上下文

文档、群聊、代码、网页、会议、笔记都是同一个库里的[原件](./sources)，一次检索同时覆盖它们，Wiki、记忆和事项也在里面：

- “退款金额现在怎么算？”需求文档里的规则、群里后来改的口径、代码里的实现，回答把三处都引上，并指出哪处已经过时；
- 原件有关注程度，过时的段落带着标注，回答会照着“以哪份为准”来说；
- 按空间（项目、仓库、个人）隔开，互相调用的仓库、同一项目的几个空间关联起来一起查；
- 可以再开重排：本地的 bge-reranker-v2-m3 把问题和前 20 条候选逐条对读、重新排序，公开中文检索集上排序更准（nDCG@10 86.6 → 91.6），每次检索多几秒 CPU（设置 → 检索，`omem setup rerank` 下载模型）。

## 回答的样子


- **引用贴着论断**：每个事实后面是它的出处，点开看到那几行原话；引用可以一层层打开（Wiki 页里引用的原件、记忆的来源）。
- **相关记忆自动带上**：开了向量检索后，和这句话足够相近的事实、约定、人物、决定（最多 5 条）会附在这一轮里，助理不用先想起来去查；开着重排时，由重排模型判断相关不相关。
- **顺手记下**：你随口说的计划、承诺、在等谁回复，助理回答时会记成记忆或事项，并在回答末尾列出。
- **问你和给你选项**：遇到非你决定不可的事，它用卡片问你，你答完它在同一轮继续；回答以建议结尾时附上下一步按钮，点一下就等于你说了那句话。
- **表单、图表和可以点的页面**：一次问好几件事、用数字说话、给你试几个方案，见下一节。
- **看它记了什么**：那一轮下面列出这次新建或更新的记忆、事项、页面和规则，点开就是。

## 表单、图表和可以点的页面

文字说不清的时候，助理会换一种方式给你看、问你：

- **一张表问完**：要问的不止一件事时，它给你一张表：文字、数字、单选多选、1–5 打分、日期、开关；几个方案并排挑一个（各自的要点和代价写在卡片上）；一批条目逐条“通过 / 不通过”并写备注；几件事排个先后；按列填几行数据。某些题按前面的回答才出现。表单跟在它的那条回复下面，提交前检查必填项；不想填也可以直接回一句话。你提交的内容回到同一个会话，它照着接着做。

<Shot src="ask-form" caption="上线方式在方案卡片里挑，日期用日历选，退款规则逐条通过或不通过" />

- **把数据画出来**：数据、对比、进度放在回答下面：指标卡片、柱状 / 折线 / 饼图（“看数据”展开成表格）、可以按列排序的表格、方案对比、时间线。数据来自它查到的记录，不是估的。

<Shot src="ask-view" caption="过去两周的退款：指标、每天的趋势和两种上线方式的对比" />

- **可以点的页面**：设计方案、界面改动、交互细节这类要试过才好判断的，它写一个小页面放在问题里：几种做法并排、开关能拨、状态能切。你试完在页面里选一个，选择直接交回给它；改过的页面保留每一版，可以翻回去对比，也能全屏。页面在沙箱里运行，不能联网，也读不到 omem 的数据和你的登录状态。

<Shot src="ask-page" caption="退款进度页的两种做法：切状态看差别，在页面里点“选 A”或“选 B”" />

- **替你去问别人**：你说“去问一下小李周四能不能评审”，助理会把问题只发给小李（ta 的通知和飞书私聊，写明是谁的助手在问），小李回答后回到你的会话。只能问看得到这个空间的人；你没让它问的，它不会自己去问。
- **在飞书里**：表单直接在卡片里填（排序和表格这类卡片填不了的，给网页链接），表格和图表是飞书卡片自己的组件，可以点的页面在卡片里是截图（运行 omem 的机器装了浏览器时）加“打开交互页”。在设置 → 渠道打开“飞书网页应用”，并在飞书开发者后台给机器人的应用加上网页应用能力后，这些链接在飞书侧边栏里打开，不用再登录一次。

## 常见问法

- “之前怎么约定的？现在是什么？”——记忆的版本链让两个都答得出。
- “依据在哪？”——回答里的引用直接指到原文行。
- “feature/refund 上退款金额怎么算的？”——按分支上的版本查代码。
- “这个仓库的整体架构是什么？”——读代码和 Wiki 回答，给出修改入口。

## 用嘴说

配好语音模型（设置 → AI → 语音）后，输入框旁边多两个按钮：

- **麦克风**：点一下开始说，再点一下停，说的话转成文字填进输入框，改好再发。
- **波形**：和助理实时语音对话。它能查你的原件、记忆、事项和 Wiki，回答时说出依据的文档名；只读，不会替你改东西或发消息。对话结束后记录会保存下来。

## 斜杠命令

不经过模型，直接执行：`/new 任务` 开新会话，`/topic 任务` 在飞书里开话题，`/as 档案 任务` 交给某个 Agent 档案，`/review` 复习卡片，`/help` 看全部。

## 用 ID 找记录

在全局搜索（<kbd>Ctrl K</kbd>）粘贴运行、原件、记忆、事项等的 id，就会先显示精确命中；搜索仍在进行时保留“搜索中”，其他结果查到后继续追加。直接粘贴 id 即可，也兼容回答底部的整行信息。

运行页的搜索同样先按 id 查找，再追加标题和任务中的匹配；保留当前的空间、类型和状态筛选。
