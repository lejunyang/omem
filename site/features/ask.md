# 问答：带依据的回答

<Shot src="ask-citations" caption="回答里的引用贴在论断旁边，点开到原文那一行" />

在飞书里问，或在网页的“工作”页右栏或“问答”里问，也可以直接交代事情。助理用 omem 的工具检索原件、读原文、查记忆，再回答。

## 一个上下文

文档、群聊、代码、网页、会议、笔记都是同一个库里的[原件](./sources)，一次检索同时覆盖它们，Wiki、记忆和事项也在里面：

- “退款金额现在怎么算？”需求文档里的规则、群里后来改的口径、代码里的实现，回答把三处都引上，并指出哪处已经过时；
- 原件有关注程度，过时的段落带着标注，回答会照着“以哪份为准”来说；
- 按空间（项目、仓库、个人）隔开，互相调用的仓库、同一项目的几个空间关联起来一起查；
- 可以再开重排：本地的 bge-reranker-v2-m3 把问题和前 20 条候选逐条对读、重新排序，公开中文检索集上排序更准（nDCG@10 86.6 → 91.6），每次检索多几秒 CPU（设置 → 检索与记忆，`omem setup rerank` 下载模型）。
- 向量模型和重排模型都在本机运行。机器上有 osdk 时由 osdk 下载并锁定版本，之后离线加载；没有 osdk 才在第一次使用时自己从 Hugging Face 下载。设置 → 检索与记忆 里各有一行写明模型现在从哪里来、是不是还在下载。
- **看回答有没有用**：回答发出几小时后，按同一个会话或群里之后大家说的话，标成解决了、被追问、被纠正、别人接手了或看不出；没人接话的单算。运行页的“回复发出后”写着是谁标的、依据哪几句话，标错了你可以改；夜间复盘和 coach 重看时也会纠正。数据页“做得怎么样”里有这张表。
- **不发空话**：回复里只有“我核对一下”“收到，我看看”，或只有“可能”“建议进一步确认”而没有结论时，先退回给它重写一次，发出来的是结果和依据，或一句说清缺什么信息的话。它已经定了之后回来（唤醒、交办）时，“我稍后看”照常发。

## 回答的样子


- **引用贴着论断**：每个事实后面是它的出处，点开看到那几行原话；引用可以一层层打开（Wiki 页里引用的原件、记忆的来源）。
- **相关记忆自动带上**：开了向量检索后，和新消息或回答、办事任务足够相近的各类记忆（含偏好与经验，最多 5 条，提示里已有的不重复）会附在这一轮里，助理不用先想起来去查；开着重排时，由重排模型判断相关不相关。
- **顺手记下**：你随口说的计划、承诺、在等谁回复，助理回答时会记成记忆或事项，并在回答末尾列出。
- **问你和给你选项**：遇到非你决定不可的事，它用卡片问你，你答完它在同一轮继续；回答以建议结尾时附上下一步按钮，点一下就等于你说了那句话；飞书卡片上还有输入框，可以在选的那一项后面补一句，或者不选、直接写你要它做的。
- **表单、图表和可以点的页面**：一次问好几件事、用数字说话、给你试几个方案，见下一节。
- **看它记了什么**：那一轮下面列出这次新建或更新的记忆、事项、页面和规则，点开就是。
- **带上截图和文件**：网页对话里直接粘贴截图或文件，也可以拖进来、点输入框左边的按钮选；它们排在输入框上方，正文里出现 `[图片1]`、`[文件1]` 这样的引用，点上方的某一个就在光标处再引用它一次。助理拿到的是这些文件本身，用自己的工具打开看。

## 表单、图表和可以点的页面

文字说不清的时候，助理会换一种方式给你看、问你：

- **一张表问完**：要问的不止一件事时，它给你一张表：文字、数字、单选多选、1–5 打分、日期、开关；几个方案并排挑一个（各自的要点和代价写在卡片上）；一批条目逐条“通过 / 不通过”并写备注；几件事排个先后；按列填几行数据。某些题按前面的回答才出现。表单跟在它的那条回复下面，提交前检查必填项；不想填也可以直接回一句话。你提交的内容回到同一个会话，它照着接着做。

<Shot src="ask-form" caption="上线方式在方案卡片里挑，日期用日历选，退款规则逐条通过或不通过" />

- **把数据画出来**：数据、对比、进度放在回答下面：先是一句结论（图标标出达成、需要关注还是故障），再是一排指标（变化带箭头，越少越好的指标上升显示红色，可带最近的走势）、柱状 / 横向条形 / 折线 / 面积 / 饼图（画成数得出来的样子：柱是一格一格的梯级，排行是一排短刻度，构成是一百根刻度的表盘，图下一行写“一格是多少”；悬停看这一处所有的值，“看数据”展开成表格）、可以按列排序的表格、方案对比、时间线。条目多、几类信息混在一起时，用带彩色标签和链接的清单（决定、检查结果、产物）、几列成对的值（分支、轮次、负责人）、收起的依据和截图聚合起来。飞书里是回复后的一张卡片，用卡片自己的组件画成同样的版式。数据来自它查到的记录，不是估的。
- **确认卡片**：流程卡住、轮到你、方案等你确认这类卡片，标题写是哪一段、副标题写是哪件事，状态是右边的彩色标签（卡住了、N 项要你定），要你定的那一节单独标出，长的依据收起；网页上同一张卡是同样的布局。回答以后标签换成结果。

<Shot src="ask-view" caption="过去两周的退款：指标、每天的趋势和两种上线方式的对比" />

- **可以点的页面**：设计方案、界面改动、交互细节这类要试过才好判断的，它写一个小页面放在问题里：几种做法并排、开关能拨、状态能切。你试完在页面里选一个，选择直接交回给它；改过的页面保留每一版，可以翻回去对比，也能全屏。页面在沙箱里运行，不能联网，也读不到 omem 的数据和你的登录状态。

<Shot src="ask-page" caption="退款进度页的两种做法：切状态看差别，在页面里点“选 A”或“选 B”" />

- **替你去问别人**：你说“去问一下小李周四能不能评审”，助理会把问题只发给小李（ta 的通知和飞书私聊，写明是谁的助手在问），小李回答后回到你的会话。只能问看得到这个空间的人；你没让它问的，它不会自己去问。
- **在飞书里**：表单直接在卡片里填（排序和表格这类卡片填不了的，给网页链接），表格和图表是飞书卡片自己的组件，卡片画不了的（可以点的页面、排序、表格）只给“打开交互页”“打开填写”链接。在设置 → 渠道 → 飞书机器人 打开“飞书网页应用”，并在飞书开发者后台给机器人的应用加上网页应用能力后，这些链接在飞书侧边栏里打开，不用再登录一次。

## 常见问法

- “之前怎么约定的？现在是什么？”——记忆的版本链让两个都答得出。
- “依据在哪？”——回答里的引用直接指到原文行。
- “feature/refund 上退款金额怎么算的？”——按分支上的版本查代码。
- “这个仓库的整体架构是什么？”——读代码和 Wiki 回答，给出修改入口。

## 用嘴说

配好语音模型（设置 → 后端与模型 → 语音）后，输入框旁边多两个按钮：

- **麦克风**：点一下开始说，再点一下停，说的话转成文字填进输入框，改好再发。
- **波形**：和助理实时语音对话。它能查你的原件、记忆、事项和 Wiki，回答时说出依据的文档名；只读，不会替你改东西或发消息。对话结束后记录会保存下来。

## 斜杠命令

不经过模型，直接执行：`/new 任务` 开新会话，`/topic 任务` 在飞书里开话题，`/as 档案 任务` 交给某个 Agent 档案，`/review` 复习卡片，`/help` 看常用命令，`/help all` 看完整清单。

## 用 ID 找记录

在全局搜索（<kbd>Ctrl K</kbd>）粘贴运行、原件、记忆、事项等的 id，就会先显示精确命中；搜索仍在进行时保留“搜索中”，其他结果查到后继续追加。直接粘贴 id 即可，也兼容回答底部的整行信息。

运行页的搜索同样先按 id 查找，再追加标题和任务中的匹配；保留当前的空间、类型和状态筛选。

后端名、启动命令的文件名或自定义别名都能当命令。后端有多份登录时可以按提示指定 key 或设备。发 `/codex astra xhigh` 切换本会话的 AI，或用 `/强` 选一个组。后面接中文任务或换行写任务，这个选择只用一轮。`/ai off` 恢复会话默认，用 `/ai save codex astra xhigh` 保存默认。成员的选择只影响自己，保存时会检查 AI 规则。
