# 问答：带依据的回答

<Shot src="ask-citations" caption="回答里的引用贴在论断旁边，点开到原文那一行" />

在飞书里问，或在网页的“今日”“问答”里问，也可以直接交代事情。助理用 omem 的工具检索原件、读原文、查记忆，再回答。

## 一个上下文

文档、群聊、代码、网页、会议、笔记都是同一个库里的[原件](./sources)，一次检索同时覆盖它们，Wiki、记忆和事项也在里面：

- “退款金额现在怎么算？”需求文档里的规则、群里后来改的口径、代码里的实现，回答把三处都引上，并指出哪处已经过时；
- 原件有关注程度，过时的段落带着标注，回答会照着“以哪份为准”来说；
- 按空间（项目、仓库、个人）隔开，互相调用的仓库、同一项目的几个空间关联起来一起查。

## 回答的样子


- **引用贴着论断**：每个事实后面是它的出处，点开看到那几行原话；引用可以一层层打开（Wiki 页里引用的原件、记忆的来源）。
- **相关记忆自动带上**：开了向量检索后，和这句话足够相近的事实、约定、人物、决定（最多 5 条）会附在这一轮里，助理不用先想起来去查。
- **顺手记下**：你随口说的计划、承诺、在等谁回复，助理回答时会记成记忆或事项，并在回答末尾列出。
- **问你和给你选项**：遇到非你决定不可的事，它用卡片问你，你答完它在同一轮继续；回答以建议结尾时附上下一步按钮，点一下就等于你说了那句话。
- **看它记了什么**：那一轮下面列出这次新建或更新的记忆、事项、页面和规则，点开就是。

## 常见问法

- “之前怎么约定的？现在是什么？”——记忆的版本链让两个都答得出。
- “依据在哪？”——回答里的引用直接指到原文行。
- “feature/refund 上退款金额怎么算的？”——按分支上的版本查代码。
- “这个仓库的整体架构是什么？”——读代码和 Wiki 回答，给出修改入口。

## 斜杠命令

不经过模型，直接执行：`/new 任务` 开新会话，`/topic 任务` 在飞书里开话题，`/as 档案 任务` 交给某个 Agent 档案，`/review` 复习卡片，`/help` 看全部。
