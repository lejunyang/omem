# 规则

**规则就是用一句话告诉 omem：“遇到什么情况，就自动去做什么”。** 无论是值班群收到报警卡片、你加入了一场评审会议、某张飞书表格被人加了一行、GitHub 合并请求有新提交，还是每天固定时间写周报，都可以建成规则自动运转。

<Shot src="rules" caption="规则页：用自然语言一句话生成触发条件与动作，确定性条件由宿主直接秒判，不消耗大模型" />

## 1. 一句话编译成“触发 + 条件 + 动作”

在侧栏**“规则”**页点新建（或直接在聊天里对助理说，助理建的规则默认先停用，并弹出确认卡片让你核对后点**“启用规则”**）：

- *“报警群里小王发报警卡片时，在卡片下开话题交给 `alert-analyst` 分析，需要关注就 `@` 值班人”*
- *“值班群里我被 `@` 就把机器人拉进去，并优先采集这个群”*
- *“我加入标题带‘评审’的会议时，问我要不要把机器人拉进去记录”*
- *“工作日 18:00 把今天的进展追加到本周周报”*

系统会自动把你的原话拆解为三部分，且支持保存前点**“用最近的消息试一试”**看哪些历史消息会命中：

| 组成部分 | 支持的能力 |
| --- | --- |
| **1. 触发源** | • **飞书新消息 / 被 `@` / 入群 / 卡片**<br/>• **会议**（我入会时 / 机器人所在群有人发起会议时）<br/>• **飞书文档或表格变化**（文档编辑、评论 `@` 机器人、电子表格/多维表格**按新增或修改的行**逐行触发）<br/>• **外部对象状态变化**（如事项挂载的 GitHub PR 合并、关闭，或有新提交/新评论“有更新”）<br/>• **omem 内部事件**（运行结束/失败、评审完成、流程阶段变化、插件信号）<br/>• **定时触发**（按你设定的时区定时执行） |
| **2. 匹配条件** | 群名、发送人、邮箱、关键词、是否本人修改、工作表名与行号、对象状态等**确定性条件由 omem 宿主直接秒判，不花一分钱模型额度**；写不成正则的语义条件才交给决策模型（快且省）或通用模型判断，跑顺后还能一键“固化”为确定性条件 |
| **3. 执行动作** | • **交给指定 Agent 档案**（可选开话题回复、静默排查、指定专用 AI 或开启完全访问）<br/>• **先跑只读预查脚本 + 90 秒快速通道（“帮你回复”）**<br/>• **拉机器人进群 / 拉机器人入会旁听**<br/>• **转发消息**（转到指定群或某人，支持**“先等另一个会话的新消息再转回”**）<br/>• **延时等待 / 让 AI 中途判断要不要继续 / 在本机执行自定义脚本**（默认先发卡请你或指定人批准） |

## 2. 90 秒快速通道：只读预查 + 快模型“帮你回复”

值班群和答疑群里，很多报障其实只需要跑一两条固定的只读查询脚本（比如按单号或 UID 查一下状态）就能立刻给结论，根本不用每次都让重型 Agent 从头翻代码。

<Shot src="probes" caption="预查库：管理只读查询脚本（Node / Python / Bash），支持正则提取消息参数并贴示例消息当场试跑" />

<Shot src="rule-first-look" caption="交给 Agent 动作中的“帮你回复”：先跑预查脚本，再由快模型 90 秒内给出结论，答不了才转深查" />

1. **保存预查脚本（Probes）**：在 **规则 → 预查** 页签里，把常用的只读查询存成 Node、Python 或 Bash 脚本（可配置正则从消息里自动提取 UID/单号传给脚本，支持当场贴一条消息“试跑”；当助手发现自己处理同类消息总在重复跑同样几条查询时，也会把代码发给你问要不要存成预查）。
2. **开启“帮你回复”（First-Look）**：在规则的“交给 Agent”动作（或群「关注」）里打开**“帮你回复”**并勾选预查脚本：
   - **秒级预查 + 90 秒快判**：规则触发时，宿主先自动跑完预查脚本，把消息和查询结果交给便宜的快模型在 90 秒内看一眼；
   - **四路分流**：**能直接答的**立刻给出结论；**要你拍板的**只私下提醒你；**进退群/例行提醒/别人已答完的**直接静默略过；**快模型拿不准的**才连同预查结果一起转交给原定的主 Agent 深入调查。
   - **灵活的投递与接力**：第一条结论默认私聊发给你（也可设为发到群里，或在群里发一张**仅你可见**的卡片，你点“发给大家”才公开；觉得快模型答得不够深，点卡上的**“接着查”**即可让深查 Agent 接手）。

## 3. 群聊防打扰设计：别人在处理时不添乱

为了让规则在真实工作群里不讨人嫌，omem 内置了全套避让机制：

- **等一等再动手 & 有人回过就跳过**：可设“等 10 分钟没人回应再处理”，以及“我已在讨论里 / 已有人回复就跳过”；群里有人直接 `@` 机器人提问时，规则自动让开，由机器人直接回答。
- **静默排查模式**：Agent 在后台默默读完讨论、查完资料，自己判断有没有把握：没结论就保持安静，有明确结论或需要追问关键缺失信息时才在话题里冒泡；你一旦在话题里插话，它就自动停下让给你。
- **连续报警自动并入同一会话**：一阵报警连着刷屏时，规则默认开启**“处理中再次触发时并入同一会话”**——复用同一个 Agent 上下文，可选“合并成一条回复一起下结论”或“复用前面查到的资料依次分别回复”，绝不重复起十几个进程查同一件事。

## 4. 特色进阶用法：盯表格逐行触发、等验证码自动转回、以成员身份运行

### 盯飞书表格与文档变化（逐行比对）

触发选**“文档变化”**并贴上飞书文档、电子表格或多维表格链接：
- **电子表格与多维表格按行触发**：每次有人修改表格，omem 会与上一版逐行比对，**每一个新增或改动的数据行单独触发一次规则**（条件里可直接用工作表名、行号、是新增还是修改，并勾选“排除我自己的改动”；只改单元格样式不触发）。
- **回写防死循环**：规则交给 Agent 查完后，既可以在群里找到对应消息回复并 `@` 填表人，也可以调用 `lark_write` 把结果填回表格——**规则自己回写表格产生的改动绝不会再次触发该规则**。

### 等一条消息再转发（例如自动帮同事转回验证码）

规则动作支持**“等某个会话的新消息 → 转发到触发的会话”**组合：
- 例如你设一条规则并勾选**“快速检查（每分钟）”**：当指定群或同事私聊找你要测试环境验证码时，规则先去盯“验证码通知机器人”的私聊会话（每 10 秒看一次，最多等 5 分钟），一抓到新发来的那条验证码消息，立刻自动转回给刚才问你要的人。

### 以多位团队成员各自的身份批量运行

遇到“每周五查每个人在研发平台上的合并请求汇总周报”这类需要用到成员各自账号权限的事，在规则的“交给 Agent”里选**“以谁的身份运行”**并勾选成员：
- 保存后，机器人会先发卡片询问每位成员是否同意授权；
- 规则触发时，助手依次切换（`act_as`）为每位已同意成员的身份，在隔离环境里用他自己的平台凭据和飞书连接执行查询或写他自己的文件（写他人文件仍会私聊请该成员批准），所有操作均记入审计日志，成员可随时在账号页撤回授权。

## 补充说明：规则静默统计与改动撤回

- **一眼看清哪些规则常年空转**：每条规则下方都会统计近 7 天和 30 天的触发次数与“安静结束”次数；周五周报也会把频繁触发却大多安静结束的规则列出来并附上原因，方便你调优条件。
- **AI 修改规则/技能随时可一键撤回**：每当主助手按你的吩咐修改了某条规则、技能或关注设置，你都会收到一条带**前后完整 diff 对照**的通知，在通知或对照页上点一下即可一键撤回。
