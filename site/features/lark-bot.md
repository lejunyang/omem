# 机器人与卡片

在飞书里私聊机器人，或在群里 `@` 它，就是在和 omem 的主助手对话。**它不是只会吐纯文本的聊天框：思考过程实时可见，所有需要你拍板、填表、看图或审批的事都做成交互卡片，点一下按钮就在同一轮继续。**

## 1. 实时可见的思考过程与进度

- **即刻响应与思考气泡**：收到消息先自动加上“处理中”表情；Agent 的工具调用步骤与思考片段实时显示在飞书原生的**思考气泡**里（不支持气泡的场景自动发进度卡片，完成后原地变为最终答案）。
- **长任务独立话题**：多 Agent 协作的长任务或大型编码交办会自动在话题内维护一张**原地更新的进度卡**，只在做完、卡住或需要你决定时才发消息提醒你（见 [多 Agent 协作](./collaboration)）。
- **图文自动合并**：飞书限制 `@` 机器人与发文件不能在同一条消息。你在 `@` 机器人时附带的图片，以及 `@` 完 **2 分钟内**紧接着发出的图片或文件，会自动合并进同一轮处理；私聊里先发文件也会多等十几秒，和你随后的说明一起处理。
- **运行溯源脚注**：每条回答底部带有 `id r… · codex · gpt-6.1-sol · low` 标记。复制这一行到网页 <kbd>Ctrl K</kbd>，就能直接打开那次运行的完整工具调用记录。

## 2. 交互卡片：点按钮就是回答

卡片头保持清爽：标题写明事项，副标题标明归属，右上角用彩色标签标出状态（如“等你确认”“卡住了”“N 项要你定”），长依据与技术细节默认折叠。在群里发出的待办卡片会自动在开头 `@` 指定处理人。

| **提问与表单卡** | 助理遇到非你拍板不可的取舍。短选项排成自适应按钮，长选项按编号完整列出；需要一次问多项时直接内嵌表单（输入、下拉、日期、勾选）。你点选或回一句话后，Agent **在原运行同一轮继续** |
| **早上一张“今天”** | 每天早上（默认 `09:30`）汇总工作日简报、等你处理的事项、各条工作线的现状与新下一步、夜间提议的新线/指标及自动收尾清点，逐项勾选一次提交（关掉“今天”时则单独发“事项清点”卡） |

| **数据图表与交互页** | 回答附带表格或图表时，直接渲染为飞书原生图表与分页表格；若 Agent 生成了供你试点的沙箱交互小页面，卡片提供“打开交互页”按钮 |
| **草稿确认与文档审批** | 盯群或“有人找你”处于草稿模式时，拟好的回复先发给你点“发送”；修改共享飞书文档前先列出改动摘要请你一次批准 |
| **下一步建议与跨人询问** | 回答以建议结尾时附上快捷按钮，点一下就等于你说了那句话；同事的助手替 ta 问你进展时，私聊收到卡片，答复直接回传给对方 |
| **入会确认与访客把关** | 会议规则命中时问你是否拉机器人进会；未登记同事在群里 `@` 机器人被拦下时，发一张**仅你可见**的卡片，点“同意这次”即可放行 |

## 3. 回答里的引用与免登录只读分享

飞书客户端打不开 omem 内部的 `src:` 或 `mem:` 链接，因此 omem 在发出消息前会自动把引用转换成飞书能直接打开的形式：

- **嵌在句子里的引用**（如“按[《差旅报销制度》]第 3 条”）：保留文字并直接链到飞书云文档或外部网页原处；跟在句末的引用统一变成紧凑的 `(1)` `(2)` 编号链接。
- **群聊原话引用**：直接调起飞书会话并定位到当时那条消息。
- **代码、记忆与 Wiki 引用 → 只读分享快照**：对于存在 omem 本地库里的代码行、排查记录、记忆或 Wiki 段落，发送时自动打包成一个带随机令牌的**只读分享链接**（需在 **设置 → 设备** 配置好网页地址）。群里同事点开无需登录，**只能看到这条消息引用的那几行上下文**，无法翻阅其他空间内容；你可在 **设置 → 分享** 查看打开次数、设有效期或随时撤销。

## 4. 点个表情就是反馈

给机器人的回答贴一个飞书表情，omem 就会记下你的评价：
- **正向反馈**（👍、鼓掌）：记为有帮助，在 Agent 页按档案和模型统计好评率。
- **负向反馈**（👎、捂脸）：
  - 对**回答**点负面表情：夜间复盘（`replay-judge` / `coach`）和记忆整理会优先排查这一轮哪里出了问题。
  - 对**普通通知**点负面表情：助手自动学出一条限定场景的“不再提醒”忽略规则（紧急提醒不受影响）。
  - 对**“做完告诉我”的工具汇报**点负面表情：该工具立即退回“每次先问我”，连续批准计数归零。
- **已阅确认**（OK、DONE、+1）：记为已收到；对事项提醒贴 `DONE` 还会直接将该事项标记为已完成。

## 5. 常用斜杠命令

斜杠命令由宿主直接解析，不消耗模型回合（带任务的命令随后直接启动对应 AI）：

| 命令 | 作用 |
| --- | --- |
| `/new [任务]` | 归档当前上下文，开新会话并立即执行任务（不带任务则开空白会话） |
| `/topic [AI] <任务>` | 在飞书群聊或私聊主界面，以当前消息为根开启**独立话题**并执行任务（支持顺手指定 AI，如 `/topic codex astra xhigh 整理方案`） |
| `/跟进 [AI] <任务>` | 开启由固定 AI 持续协调的长任务；在工作话题内发 `/跟进` 可查状态、暂停、加预算或换 AI |
| `/as <档案> [任务]` | 把任务交给指定的专门 Agent 档案处理 |
| `/agent <后端>` / `/model <模型> [effort=…]` | 切换本会话的后端、模型或思考强度（加 `save` 保存为个人默认；`/ai off` 恢复默认；也可直接发 `/强` 或后端自定义别名） |
| `/watch <档案> [范围] [none\|draft\|auto]` | 让指定 Agent 档案长期盯这个群（见 [群里的协作](./lark-groups)） |
| `/help` / `/help all` | 查看最常用的 5 个命令 / 查看完整命令清单 |

## 补充说明与进阶设置

### 在飞书侧边栏免登打开 omem（飞书网页应用）

如果你希望点击卡片上的“打开填写”“打开交互页”“在网页上查看”时，直接在飞书桌面端右侧边栏（或手机飞书全屏）免登录打开，而不是跳出到外部浏览器：
1. 进入 **设置 → 渠道 → 飞书机器人**，开启 **飞书网页应用**。
2. 按页面提示，在飞书开发者后台为该机器人应用开启“网页应用”能力：桌面端与移动端主页填 `<网页地址>/lark/`，安全设置的“重定向 URL”加上 `<网页地址>/lark/`，H5 可信域名加上对应域名，然后发布新版本。

### 群里发言的细则与权限控制

- **精准 `@` 人与 `@` 其他机器人**：机器人可按姓名或邮箱 `@` 群成员（重名时自动核对当前群成员列表，不在群内的人自动跳过）；也能从群近期历史提及中认出其他机器人的身份并直接 `@` 它协作。
- **加急与仅部分人可见**：应用内加急（`urgent`）和群内“仅指定人可见”的卡片（`only_to`）**默认禁止 Agent 调用**；只有你在当轮对话里明确要求，或在规则中勾选了“允许加急 / 允许只给部分人看”时才会放行。
- **后续消息自动跟人走**：唤醒复查、交办完成汇报等后续消息默认发回发起时的原话题；若你后来在另一个话题或私聊里回复、接手了这件事，后续消息会自动切到新位置（原话题被删或机器人退群时自动兜底发到你私聊）。

### 免打扰、不急通知汇合与提醒效果统计

- **跨端已读同步与提问自动过期**：推到飞书的通知在网页端不计入未读红点；你在飞书里已读、回过表情或点过按钮，网页自动标为已读。超过 7 天无人回答（`asks.staleDays`）、所属交办已结束或你已跳过话题的提问卡片会自动变为“已失效”。
- **不急的通知攒着一起发**：后台整理完、查清结论等无需你立刻动手的普通通知，默认先留在网页，到 `09:30`、`13:30`、`18:30`（可在 **设置 → 通知与打扰 → 通知时间** 修改）合并成一张清单推送；你离开飞书会议时也会立即放出。若决策模型看你近期消息确认你已知晓该结论，则直接略过飞书推送。
- **思考气泡开关**：在 **设置 → 通知与打扰 → 过程消息** 中，可将思考气泡设为“只在回答我的消息时显示”（默认）、“全部运行都显示”或“关闭”。
- **低效提醒自动识别**：在 **数据 → omem 自己 → 提醒** 中，系统会统计近 30 天各会话通知的反应（已处理、先已知道、只看、没看、反感）。对累计发满 8 条却从未处理过的会话，可一键设为免提醒（被点名或限时事项除外）。
