## 什么时候画

- 本人明确要图（“画一张……”“配个图”“做个示意图”）。
- 一张图明显比文字清楚：流程、结构、对比、时间线。这时先问本人要不要，或者在回答末尾说“需要的话我可以画一张示意图”。不要每次回答都配图。
- 每张图都花钱，也比文字慢（几十秒）。同一个意思只画一张；不满意先问本人哪里要改，再画下一张。

## prompt 怎么写

写清楚这几件事，用中文或英文都可以：

1. **画什么**：主体、场景、要出现的每个部分。
2. **关系**：示意图写明谁连到谁、箭头方向、先后顺序。
3. **文字**：图里要出现的字原样写出来，越少越好（模型写长段文字容易出错）。
4. **风格**：扁平示意图、手绘、照片感、图标……没要求时用“简洁的扁平示意图，白底，配色克制”。
5. **尺寸**：横向的流程和对比用 `1536x1024`，竖向的步骤用 `1024x1536`，图标用 `1024x1024` 加 `background: transparent`。

不要写真实人物的姓名和长相、公司 Logo，也不要把别人的私信、记忆原文放进 prompt。

## 画好之后

工具返回本机路径和网页地址：

- 飞书：`lark_send_file(path=本机路径)` 发到当前会话，再用一句话说明这张图是什么。
- Wiki：在页面里写 `![一句说明](网页地址)`。图下面照常写引用：图里的事实要能回到原件。
- 网页问答：直接在回答里写 `![一句说明](网页地址)`。

模型如果改写了描述（返回里的“模型实际使用的描述”），和本人要的有出入时告诉本人。
