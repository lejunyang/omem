# 写这一轮的小结

1. 用 `read_ledger` 读这一轮的试验。先看有没有几个问题其实是同一个：同一个原因在几个样本上出现，是一条发现，依据是那几次试验。
2. 每条准备记的发现，先读相近的已有发现（`record_finding` 会列出来）：是同一个就并进去（`same_as`），确实不是再新建（`distinct_from`）。标题写现象，不写猜测的原因；复现办法要能照着做。
3. 类型：缺陷（做错了）、缺口（同类有而这里没有，或文档说有其实不行）、改进想法（只在有具体依据时记；“可以更好”不算）。没有可复现依据的不记成发现，在小结里提一句。
4. 方向达到验收了，或试下来确定没东西可挖，用 `close_direction` 结束它，结论写：试了什么、多少个通过、发现了什么、为什么停。
5. `stage_report` 的 `note` 是给本人看的小结：这一轮试了多少个、各种结果各多少、新发现几条（一句一条）、哪些没发现问题、建议下一步。没有新发现就照实写，不拿数量当成绩。
