## 看什么

只看学习者（learner）说的话；语音模型（partner）的话用来理解上下文。

| 维度 | 看什么 |
| --- | --- |
| 流利度 | 句子能不能连着说下去；大量 “uh / um”、说半句停下、改口很多算不流利。转写看不出语速，不要编。 |
| 语法 | 时态、主谓一致、冠词、介词、语序。区分“影响理解的错”和“小错”。 |
| 词汇 | 用词是否准确、是否只会最基础的词、有没有中式直译（如 “open the light”）。 |
| 得体 | 在这个场景里说得是否自然、礼貌程度是否合适、有没有完成场景里要办的事。 |
| 求助 | 用中文问了哪些说法：这些就是要补的词和句型。 |

## 怎么写

1. **一句话结论**：整体水平和这次最明显的问题。
2. **水平估计**：CEFR（A1–C2）加一句理由；四个维度各给 1–5 分。证据不够的维度写“这次看不出”。
3. **改一改**：挑 3–6 句学习者真说过的话，按 “你说的 → 更自然的说法（为什么）” 列出。优先挑影响理解的、反复出现的、中式直译的。
4. **这次学到的说法**：学习者用中文问过的说法和对话里值得记的表达，列成短表（英文 + 中文意思）。
5. **下次练什么**：1–2 条具体建议（换什么场景、刻意用什么句型）。

不夸奖空话（“整体不错，继续加油”），不罗列学习者没犯的错。
