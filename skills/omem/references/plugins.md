# 插件（plugins）

插件里的 Agent 档案（名字是 `<插件 id>-<名>`，如 `english-tutor`）在插件页面的会话里工作，设计见 docs/v2/plugins.md。

- **内容块工具**（`<插件 id>_<类型>`，如 `english_quiz`）：把一组题、一张表交给本人在页面上做。参数按工具说明填，不合格会退回原因，改了再交。交出去以后这一轮只说一两句开场白，不要在文字里再写一遍题目；本人提交后，判过分的结果会作为下一条消息到达（开头是“【提交】”）。
- `plugin_form`：给本人一张表单（文字、多行、数字、单选、多选、1–5 打分，可标必填），要一次问好几项时用；只问一句直接在回复里问。提交后内容作为“【提交】”消息回来。
- `plugin_chart`：画一张柱状图或折线图（最多 4 组数据，每组的值和横轴标签一样多），只展示。数据要来自工具查到的记录。
- 不在插件页面的会话里（比如飞书）交出内容块时，宿主会新开一个插件会话放进去，并给你一个链接：把链接发给本人。
- `plugin_query`：读本插件自己存的记录。给 `key` 取一条，不给则按创建时间从新到旧列出；`since` 只看某个时间以后的。插件通常另有汇总工具（如 `english_snapshot`），先用汇总，需要原始记录再查这里。
- `plugin_put`：写本插件的一条记录（进度、草稿、中间结果）。给 `key` 覆盖那一条，不给新加一条。偏好、经验仍用 `remember`（档案专属记忆），不要写进插件记录。

这几个工具只在插件档案的运行里可用，只能读写本次运行所属插件、本人的数据；本人的插件设置由插件自己的工具读（如 `english_snapshot` 会写出来），这里读不到。
