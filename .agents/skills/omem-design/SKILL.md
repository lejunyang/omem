# omem 网页实现

1. 页面在 `web/src/views`，公共组件在 `web/src/components`，样式 token 在 `web/src/styles.css`。新增颜色先加 token（同时给深色值），不要在组件里写死色值。
2. 用 `<script setup lang="ts">`，数据走 `web/src/api.ts`，全局状态在 `web/src/store.ts`。实时更新订阅 `onServerEvent`。
3. 正文用 `Markdown.vue` 渲染（marked + DOMPurify + highlight.js + 懒加载 mermaid）。`src:` / `mem:` / `msg:` 链接和 `path:行号` 会变成引用，点击后由 `CitationDrawer` 逐层展示；`[[slug]]` 是 Wiki 链接。
   文档引用高亮按完整 Markdown 块切分（`lib/cited-document.ts`），不能直接从引用行切开表格、列表、引用块或代码围栏；引用位于块内时高亮整个块，原文行号模式仍定位精确行。
4. 阅读区限宽（正文约 760px），标题用衬线体，元信息小号灰色；按钮组用 gap。空状态说明现状并给一个能执行的动作。
5. 表单控件用 `components/UiSelect`（下拉）、`UiCheckbox`（勾选 / switch）、`UiSegmented`（少量互斥选项）、`UiDateTime`（日期时间），确认和输入用 `lib/dialog` 的 `confirmDialog` / `promptDialog`；不用原生 select、checkbox、datetime-local、confirm、prompt。弹层用 Teleport 到 body，自带键盘操作和 Esc。放在标签、胶囊或一句话里的选择（成员的空间角色）用 `UiSelect` 的 `variant="inline"`：没有边框，只有文字和小箭头，和胶囊同高；不要把带边框的下拉塞进 20px 高的 `.badge`。
   空间等可多选的范围也用 `UiSelect`，传 `multiple` 与数组；选项显示名称，ID 放 hint，保存仍用 ID。选中后保持展开，再点取消，Esc 关闭；说明清空后的范围，不让人手写逗号分隔的 ID。
   文本输入继续使用原生 input / textarea 和 Vue v-model；入口统一 `.use(compositionGuard)`（`lib/composition.ts`），插件 iframe 的独立 Vue 入口也要接入。组合输入期间的键盘事件在捕获阶段隔离，不触发回车发送、弹窗确认、选项导航或全局快捷键；只取消同次确认回车引起的表单提交，不取消输入法按键的默认行为。用 `node scripts/check-composition.ts` 回归。
6. 大列表和长文本（原件列表、长原件、聊天、运行、记忆）用 `components/VirtualList`（动态行高，跟随最近的滚动容器，`scrollToIndex` 定位）；加载中用 `components/Skeleton`，和“没有数据”的空状态分开。聊天类原件用 `components/ChatView`（解析见 `lib/chat.ts`）。
7. 浏览器直接加载的 `/api/...` 地址（`<img>`、下载链接）要经 `api.ts` 的 `authUrl` 带上令牌，否则从其他设备打开时加载不出来；普通请求走 `get` / `post`，401 时会提示填写令牌。
8. 所有可点击元素可键盘操作；弹层 Esc 关闭并归还焦点；不依赖 hover 才能看到关键操作。≤860px 侧栏折叠，≤760px 单列。
9. 改完运行 `pnpm run typecheck`，并用 `node scripts/screens.ts <url> <dir>` 截 1440 和 390 宽度检查，不能横向溢出。

同一页面的几类对象（Agent 档案 / 技能、任务规则 / 归档规则 / 流程）用列表顶部的标签切换，不在侧栏加二级菜单。

列表加详情的页面（任务规则、流程定义）用同一个骨架：左边 300px 的列表列，顶部是标签和 ＋，条目是名字、两行以内的说明和一行灰色的概况；右边是选中的那一项，没选中时是居中的说明和一个能执行的动作。窄屏列表在上（最高 36vh），详情在下。不要把列表做成一张张带边框的卡片再把编辑器接在下面。

一串有先后的阶段（事项的流程，`components/ItemFlow`）用阶段条：按顺序排一排细条，只用四种颜色——完成 `--ok`、进行中 `--accent`、等本人或卡住 `--warn`、未到 `--line-strong`，跳过和待复核用文字说。细条下面是阶段名和一行小字（用时、等了多久），窄屏换行，不横向滚动。要本人动手的那一段单独一块（`--warn-soft` 底）写明要做什么并带按钮，不放进阶段条里；点阶段只切换下面的说明和依据。不给每个阶段画带边框的格子。

一串按时间发生的事（工作线的关键变化，`components/WorkTimeline`）用点线：从左往右旧到新，一条细线连着空心的点，点的颜色说是什么变化（风险和改期 `--warn`、定下的范围和决定 `--accent`、结果和解除 `--ok`、其余 `--muted`），最新的一个实心；点上方一行小字写日期（今天 / 昨天 / 11 月 9 日，`lib/work.ts` 的 `dayLabel`）和种类，下面最多三行写这件事。还没发生的（下一步）接在后面，点和线都是虚线、字是灰的。放不下时在卡片里横向滚动（窄屏也是，页面本身不横向溢出）、打开时停在最新一端、还有内容的那边渐隐。每个点是按钮，点开在右侧的详情（`components/WorkSheet`：原因、风险、下一步、来源，Esc 先关引用再关它）。和阶段条分开用：阶段条是有先后的固定几段，点线是陆续发生的事。

几周的近况（“最近忙这些”）分四栏：本周 · 至今 N 天、上周、2 周前、3 周前，每栏一个日历小图标加粗的标题和几行字，栏之间用虚线竖线隔开，没有内容的栏写“暂无进展”并变灰；窄屏两栏一行。人的列表一行一个：首字圆头像（底色取分类色，同名同色）、名字、行尾一个灰底胶囊写这个人做什么。群的列表行尾放 `Sparkline` 画最近 14 天每天的消息数，列表下一行小字说明它是什么。要本人处理的总数用暖色胶囊（`--warn-soft` 底、`--warn` 字）写“共 N 条需要你确认”，放在页面顶上，点它跳到列这些事的地方。围绕一个对象提问的侧栏（`components/LineAsk`）在宽屏是页面右侧可收起的一列，窄屏是全屏抽屉，带两三个现成的问题。

一条线的三段（进行中 / 观察中 / 已结束）：卡片头部的状态点，观察中用 `--accent` 的空心点写“观察中 · 到 12/05”（`lib/work.ts` 的 `shortDay`）。工作页上观察中的线不用大卡片，放在进行中的下面一组小卡（左边一道 `--accent` 竖线，标题、观察到哪天、现状两行、还挡着它的东西写成小胶囊：越过门槛的指标和没结的问题用 `--warn-soft`，其余灰底，没有就一句灰字“没有新问题”）；已结束的再往下，默认收起，点开是搜索框和按月分组的单行列表（勾或叉、名字、小结第一句或结束原因、行尾灰字“结束 · 哪天”），“查看更多”往前翻。线的页面在标题下面放一条说明带：观察中 `--accent-soft` 底，写到哪天和“没有新问题会自动结束”，带“现在结束 / 回到进行中”；已结束 `--sunken` 底，写哪天、为什么，下面是收尾小结，带“重新打开”。结束、放弃、先观察从头部“收尾”打开的小弹窗选，下面还有没结的事时用 `confirmDialog` 问“一起结束 N 件”。

设置页是例外：分类多，放在页内左侧按“知识 / AI 与任务 / 渠道与协作 / 系统”分组（`Settings.vue` 的 `NAV`），右侧是当前分类的卡片目录（从渲染出的卡片标题读出，新卡片以 `<strong>` 开头就会进目录）；窄屏时分类变成横向滚动的一行，目录隐藏。新增设置放进已有分类的一张卡片里，卡片标题不超过 24 个字。

说明文字：一个功能的说明超过一行时用 `components/HelpText`（`lead` 用于分类开头的一段，显示两行）——开头一句说它是什么，其余在 ⓘ 的悬浮层里（悬停、聚焦或点开）。所以第一句要能单独读懂，不要以“在……里”这类铺垫开头。字段下的一句提示仍用 `.hint`，不收起。

正文里的表格由 `lib/doc-layout.ts` 的 `sizeTables` 定列宽（`Markdown` 组件渲染后调用）：不要给 `.prose table` 另写宽度；飞书文档的高亮块、分栏用 `.doc-callout`、`.doc-grid` / `.doc-col`（`styles.css`）。

按钮用 `styles.css` 的 `.btn` 变体：实心的 `.primary`（深色）、`.accent`、`.danger-fill`（红色，危险确认），描边的 `.danger`（红字）、`.ghost`。通用悬停只在原底色上叠一层 `--hover`（`background-image`），不要在组件里给 `.btn:hover` 写 `background: var(--hover)`；新的实心按钮放进 `styles.css`，悬停和另外三种一样变淡（`opacity`），否则悬停时会变成浅底白字。

确认弹窗保持短标题，详细说明放 `message`。`DialogHost` 内容区负责长链接换行和限高滚动，操作按钮留在内容区外；检查手机和较矮视口，不能靠横向裁切隐藏溢出。

Agent 档案和任务选型的后端、模型、强度使用 `AiDefaults`：可用后端排在前面，同等情况下 ACP 优先；模型与强度自动检测，有选项用 UiSelect，没有可选项再用输入框。检测明确不支持强度时显示“该模型不支持”。内置角色的默认 AI 在档案页设置，设置页管理后端和任务选型偏好。技能目录使用可折叠的文件列表，手机上放在编辑器上方并限高滚动；切换文件前处理未保存的修改。

从很多项里选一批、且这些项有分组时（Agent 档案的 omem 工具），不用一个长下拉逐个加：用 `components/ToolPicker` 的做法——已选的显示成可移除的小标签，“按分组选择”展开一个面板，分组一行一个，勾分组名是整组、展开后逐个勾，面板里可搜索，并把结果按文件里的写法原样显示出来（`group:<分组>`、`-<排除的工具>`、工具名），让本人看得出它和档案文件是一回事。

代码改动统一用 `components/DiffFile`（新旧行号、未改动代码可上下展开，行带 `data-line`）。差异的排列（上下 / 左右）用 `lib/diffLayout` 的全局设置，不在组件里各存一份；改动文件多时配 `components/DiffTree`。运行详情里选中文字后“加入提问 / 加入修改点”：可引用的区域加 `data-quotable`，标题放 `data-ask-label`，行号放 `data-line`；引用进 `lib/quotes` 按运行编号保存，提问走 `AskAboutRun`（`basket`，可缩小到 `QuoteDock`），修改点走 `FixBasket`。回答只读，同一运行沿用一个问答会话。条件写不出来的设置（评审档位、评审项）在条件编辑器下面放一句话说明，由 AI 判断。

配置项不让人手写 JSON：有序清单（如排队兜底）一行一项，用 UiSelect 选后端 / 模型 / 强度，带上移和移除；数值有常用档位的用 UiSelect 列出档位。`styles.css` 已把 `.stack` / `.card` / `.field` 里直接的 `<p>` 外边距清零，间距由 gap 决定；textarea 全局只能纵向拖动。卡片里的长标题、长路径、长 id 要能换行或省略（网格子项加 `min-width: 0`），路径只显示最后一级、悬停看全路径。

保存设置后的提示只说实际发生的事：`PUT /api/settings` 返回的 `restart` 不为空才提示重启，并写出是哪几项。新增只在启动时读取的设置要加进 `src/server/http.ts` 的 `atStartup` 清单。选中文字的颜色在 `styles.css` 的 `::selection` 统一设定（浅底深字），不要在组件里另设。

图表和成排的数字只有一种画法：`packages/plugin-sdk/charts.ts`（组件块的 `chart` / `metric` 也用它）。页面里用 `components/charts/` 的组件，不在页面里手写条形、小柱或 SVG：

- 画法是“可数的单位”：读的人会数的那个单位本身就是一个记号。柱是一格一格的梯级（一格一个单位，值大时一格是 1 / 2 / 5 × 10ⁿ 个，最高的柱二三十到四十来格，每五格加粗，柱顶写数；超过六十根才退回细实心柱）；横向排行是一排竖的短刻度，数写在行尾；折线逐点画点（连续的日期里周末空心），底线上一天一根刻度，最高点和最后一点放大写数；面积是每个点一根从底到线的发丝线，峰值那根加深；构成是一百根放射刻度的表盘（一根 1%），名字和占比写在环外；指标是大号数字，上面一行小号加字距的灰色标签，小走势同样是发丝线加末尾的点。图下一行更小、加字距的灰字写读法（“一格 = 5 单 · 每五格加粗”）。只有一两行的小表不画刻度，画数字加一根细条。
- 选哪种：几项比大小、排行、名字长、每行要能点开明细用 `RankBars`（`items` 带链接；同一单位的几列并排给 `series`，每列一个色相、行尾写数和列名；别的单位的列给 `extras`，写成行尾的文字）；按天、按周的数量用 `BarChart`（几类加起来看合计用 `stack`，`caption` 写“一根一天”）；走势用 `TrendChart`（看量用 `area`）；构成用 `ShareChart`，最多八块；一排关键数字用 `MetricRow`（`link` 打开明细）；数字旁边的小走势用 `Sparkline`。别的形状用 `Chart` 传整个 spec。
- 颜色分三种用途：一组数据用青瓷蓝的明度阶 `--chart-seq-1`…`--chart-seq-4`（记号用 3，加重和关键点用 4）；几组数据用分类色 `--chart-1`…`--chart-8`（低饱和的墨绿、赭黄、蓝、陶土、青、淡紫、橄榄、梅红，相邻两色色相和明度都拉开），按顺序分配，不跳着用，并在图上直接写名字；`--chart-accent`（橙红）只标“要看的那一个”：`highlight`、单组的最高点、超过目标线的格。同一个东西在几张图里要同色时（数据页的场景），给 series 一个固定的 `slot`。表示好坏的状态仍用 `--ok` / `--danger`，不和图表色混用。新增颜色先加 token、浅色深色各一份，并重新做色盲检查（相邻两色、前四色两两之间）。
- 标注：数直接写在图上，几条线在线尾写“数 名字”，堆叠柱在最后一根旁边写各类的名字，放不下才用图例。标题加粗，下面一行灰字写单位和“一个记号是什么”；轴标签、类别名用更小的字号、加字距、灰色。除了发丝线不加边框和底色。
- 动效：图第一次进入视口时画一遍（梯级一格格长上去、柱与柱错开，折线像笔画出来、点随后冒出，发丝线从左到右立起，表盘顺时针扫一圈，大数字从 0 数上去），一秒左右，不循环、不弹跳；悬停时被指的那根柱、那条线保持，其余变淡，线图有跟着走的读数线。`prefers-reduced-motion`、`[data-chart-still]`、`<html data-chart-motion="off">`、`setChartMotion(false)` 都会关掉；截图脚本用 `reducedMotion: "reduce"` 截画完的样子。
- 不用：象形图、关系图、流向图、雨滴图、3D、渐变填充、循环动画；不画两个纵轴（量级不同就分两张图）；不为装饰加网格。
- 图表要有文字等价物：排行每行有 `aria-label`，柱、线、表盘可以用方向键逐个看并有“看数据”表格，正在数的数字有写死终值的 `aria-label`。页面背景不是 `--panel` 时，在容器上设 `--chart-surface`（点的描边和空心点用它）。

插件页面（`plugins/<id>/web`，沙箱 iframe）不另做一套样式：引入 `web/src/styles.css` 和 `web/src/components` 里不依赖主站状态的组件（`UiSegmented`、`UiCheckbox`、`UiSelect`、`Skeleton`、`Icon`），主按钮用 `.btn.primary`（深色），输入用 `.input` / `.textarea`；普通 HTML 页面引入 `/plugins/_sdk/omem.css`。只补主站没有的类。

异步详情、列表和二次请求（评审、归档记录等）要按请求序号和当前选择核对后再写状态；错误提示、加载状态和轮询计时器也要核对。切换时立即清掉上一项详情，避免把旧内容挂在新标题下。
