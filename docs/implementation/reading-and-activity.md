# 阅读、材料处理与变化记录（2026-10-01）

知识库与其他页面统一使用完整主菜单；组件预览只保留 `#/design` 直达入口。原始材料的筛选目录移入页面左栏，小屏放在正文上方。

段末引用按目标类型、材料/文章键和行范围/章节去重。同一文件的不同范围保留；重复名称补充行号。固定版本由该文章的依赖快照解析。同一目标在不同段落仍可重复出现，因为分别支撑不同论断。代码上下展开按钮与代码块保留间距。

共享引用弹窗保存每层滚动；异步正文高度恢复时重试定位，不让加载中的短内容覆盖已保存的位置。个人知识弹窗缓存各层组件，保留已展开的代码范围；关闭全部后释放。URL 深链保留路径，不持久保存滚动位置。

变更历史用于回答“哪份内容、哪些行或章节发生变化”。材料比较读取完整固定版本；新知识发布记录前后知识版本和变动章节。前端采用 jsdiff 的标准差异算法，显示增删和上下文。早期知识记录缺少版本关联，无法追补可信 diff，明确展示此限制。不会改写旧日志。恢复只支持原始材料，仍创建新版本。

通知是变化与提醒的收件箱。已读仅改变消息阅读状态，不批准判断、不完成事项、不取消未来提醒。详情仅显示实际存在的内容差异、证据与外部发送记录，不显示空回执或内部对象 ID。

“学习流程”改名为“材料处理”：新材料和来源变化进入提炼、独立核验及受影响记忆复查队列；它不是英语学习或记忆卡复习。页面显示材料名、后台配置状态、结果和失败原因。接口仍最多返回 200 条，优先运行中和需处理记录，其次已处理结果，最后等待任务；筛选数量只是当前返回范围，不冒充全部队列统计。原文保存不代表模型已处理成功。

能力与连接页进入或切换 Agent 时自动探测，有加载、失败和重试状态；仅发现能力，不生成正文。服务访问令牌与 Agent/飞书凭据分开解释，本地未启用访问保护时无需填写。认证机制没有改变。

验证：新增 HTTP 版本比较和已读不改变原文断言；浏览器检查覆盖实际引用范围、三层返回滚动、目录位置、变化 diff 和三个视口。项目全量检查及最终仓库知识更新结果以本轮 verification.json 为准。
