# 仓库材料进入个人记忆

`osdk run dev` 明确传入本仓库目录，在个人 Store 中幂等捕获仓库材料并恢复 `.repo-review/knowledge` 中的文章。已有个人材料、事项、配置不替换；启动不调用生成式模型。移除面向用户的 `dev:review` 任务，隔离 review 数据库仍用于生成与检索验收。

迁移沿用材料 key 和内容摘要。旧文章需要的原文，从已有 review 运行数据补入，然后重新捕获当前文件作为 head。文章历史按固定依赖版本恢复，不把历史复核视作当前有效；缺失的旧原文仍不可用，前端不得跳转到新版本冒充旧依据。已有有效知识不被历史导入覆盖。历史引用解析按对应 source 查找，避免每条引用扫描全库历史。

验证：`osdk run check` 的 352 个测试、类型检查及构建通过；新增行为检查覆盖个人材料保留、重复导入不产生新 revision、来源变化后的失效与旧原文可读。统一入口的真实仓库浏览器检查另见 `unified-knowledge-reading.md`。
