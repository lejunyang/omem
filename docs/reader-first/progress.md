## 已有的一条个人流程

- 普通助手自主调查：重用固定材料工作区、原生 skill、只读 MCP 和 ACP，可搜索、补读、查记忆和历史；代码导航按需要使用。网页显示综合回答与实际命中，可取消、重试、继续追问和打开固定引用。
- 原件换版与记忆更新：先暂停旧记忆，再抽取、独立复核并更新同一记忆。已有事项回执进入提取背景，避免同一委托再次执行。
- 日常事项：交办、等待、改期、延后、完成、取消和站内提醒。通知已读不等于完成；没有外部回复监听。

上一轮真实 Traex 从头验收第四次运行退出 0：读书会预算 80→120 元更新同一记忆；等待只建一个事项，纯查询不改事项；服务重启后提醒一次，延后到新检查时间，重复轮询不重复，完成后不提醒，后台学习不重建事项。时间检查使用真实提醒逻辑和注入验收时钟，不代表等待至未来日期。前三轮失败保留，不用后续成功覆盖。详见[个人流程](assistant-memory-flow.md)。

网页真实首题与同会话追问完成、未降级且未创建事项，固定代码范围、返回焦点和三档宽度已检查。仍有回答偏长、测试清单重复主线、简单问题约一分钟以上的问题。后续要改进短答案、按需展开和耗时，不能强制每题调查所有工具。原生 CLI 可能读取祖先指令，当前不能宣称完整文件系统隔离。

## 检索与阅读基础及已知缺口

保存单位、检索单位和讲解单位已分开：原件保留版本，Markdown 块、TS/Vue 完整方法与会话保留背景，知识文章按读者问题组织。派生讲解可直接参与搜索和回答，引用仍回固定原文。曾独立复核且引用依据未变的旧解释可作为“待复核背景”，不冒充重新复核的当前文章。

先前 `68677fa` 冻结库的[人工报告](../../.repo-review/knowledge/verification/unified-retrieval.md)为十题五条可用、四条部分可用、一条未命中核心；该轮[自动报告](../../.repo-review/knowledge/verification/history/2026-10-02T11-40-54-649Z-5d18829d.json)总结果 failed，六条预期路径搜索仅两条满足。这些是当时观察，不是本轮通过率，也不是无偏评测。旧题目后来已进入调研材料，更不能伪称新问题。

主要缺口仍是：长问题可能漏明确方法本体；主题相关但不能回答的调研或宽泛说明靠前；混合文档的一种用途不足以描述每一段；跨文件业务链缺少系统扩展。中文 cross-encoder 的对照有收益也有退步，继续保持可选。Agent 后续补查成功不等于第一轮检索已经好用。
