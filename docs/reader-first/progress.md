## 正在进行：三项检索改造

新增可重建的检索单位：原件按 Markdown 块或 TS/Vue 符号定位，讲解段落保留固定文章与原件引用，已应用记忆和当前事项保留状态。全文排序改为 ICU 分词后的 FTS5 BM25；中文 BGE 在带上下文的单位上索引，预处理身份与旧 Fragment 向量隔离。顶部搜索可选择概念、实现、背景或跟进用途，知识搜索、原生 Agent 工具和助手接入同一检索接口。助手收到派生讲解和原始依据两个独立字段，补查可以指定用途。

这还是实施状态，不是最终质量结论。已修复候选先截断后筛范围的问题，以及首次结构投影阻塞 HTTP 启动的问题。结构单位、段落解释、固定行范围、来源变更、向量身份和助手上下文检查通过；完整 check 退出 0（372 项测试、类型和构建）。实际 dev 搜索与引用在 1440/768/390px 检查，无页面错误或横向溢出；预览保留引用标签并复用递归弹窗。中文 BGE 四类同义问题通过，但真实整库的新单位索引仍需完成，不能用这四例代表整体相关性。下一步是提交实现、用真实 Traex 更新受影响知识，再统一检查中文 HTTP 问题、Agent 补查与助手回答。不能继承旧报告的通过数。具体设计见 [检索改造](retrieval-redesign.md)。

首轮真实中文 HTTP 对照发现，AST 叶节点会让完整方法名落到局部变量，丢掉控制流。已保留函数/方法整体，将局部变量留在所属操作内；完整定义优先于仅带父级名称的嵌套条目。新预处理为 structure-icu-v3，重新索引，旧固定原件不变。完整 check 再次退出 0（373 项）；受影响材料与六篇指南正在真实模型更新，存在一次 ACP 超时，需重试并如实保留记录。初步中文问题仍出现无关旧说明，最终质量不能由结构修复或模型复核替代。

## 2026-10-02：检索候选降噪

已用 ICU 中文词分割替换全句相邻双字；短字面查找保留完整词。词法候选先检查正文概念覆盖，标题只允许打开有限入口。知识回溯只匹配正文章节；记忆别名与文章标题仍能回到原文。只做一次词法/向量融合，向量尾部有分数和相对门槛，标识符不存在时返回空。知识页面排序复用正文相关性并保留实际检索分数。

检查通过：本轮锁定依赖、完整类型/363 项测试/构建退出 0。真实 BGE 中文四类同义问题、可选重排器的实际权重及不存在标识符验证通过；实际库前后结果保留 runtime/research。已增加文档频率加权、完全重复摘要合并与按来源分组。中文 BGE cross-encoder 已经 osdk 下载锁定并接为可配置对照；六条新问题对照仍有旧方案和复述问题排前，故不默认开启。复杂问题仍可能召回无关内容，不能把降噪当完整相关性验收。详情见 component-integration.md。

## 2026-10-02：原生 Agent 调查链

ACP 知识任务默认使用材料工作区、原生 skills、官方 MCP SDK 和候选提交工具。研究者自主补读，作者继续调查，独立 verifier 再查原件；不再固定三轮研究或限制宿主输入输出 token。工具覆盖材料、章节、代码定义/候选调用、知识文章、记忆、图片、历史和显式关联。真实 traex / gpt-5.6-sol 的工单分派样例已通过三角色工具运行与独立复核，生成页面有贯穿例子、输入输出、流程图、概念区别和修改入口。

真实 HTTP 也发现验收材料污染：同一句回归问题被测试/进度报告收录，结果可能先命中这些记录；“预期路径命中”不能代表找到机制。排序没有按这些路径特判。已进行了独立新问法和中文 cross-encoder 对照；仍需要规模更大的人工相关性标注、结构检索投影及正式时效数据。图片/历史工具、复杂全库调查和 UI 中的完整生成等待体验尚未单独实测。本仓库指南与材料产物在实现提交后更新；具体成功/失败和 current/stale/pending 在 .repo-review/knowledge/coverage.json 与当次 verification.json，不把旧报告冒充本轮结果。

- 程序检查：回归与构建，不能作为内容可用性的结论。

- 阅读：六篇样板是否解释完整流程、必要概念、案例和修改入口。
- 检索：真实问题是否找到必要背景；区分检索失败与给足材料仍答不好的生成失败。
- 界面：实际运行服务，检查桌面、平板、手机；可见问题与未验证内容如实记录。
