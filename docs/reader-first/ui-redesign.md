# 知识库阅读界面重设计

2026-10-02。此前分类页打开整理表单后，阅读列表被挤出首屏；导航在每个分类下重复操作链接；材料勾选框受全局 label 排版影响，与标题上下分离。只检查控件存在，没有检查真实展开状态，导致这些问题进入实际页面。

这轮将阅读和整理分别组织：分类首页展示标题、摘要与文章列表，创建入口打开两步弹窗。目录的箭头负责展开，分类名称负责打开列表；分类结构继续来自持久分类数据。材料列表支持搜索、只看已选和分批显示，避免数百项一次占满界面。已选范围与阅读目标仍提交给原有调查、写作和独立复核流程。

复用公共 OmDialog/OmButton/OmIcon，未增加仓库路径规则或改变知识结构。草稿在上下步与关闭重开时保留，成功提交后清空；手机弹窗全屏，底部按钮固定可见。桌面、768px、390px 均须实际截图检查，特别是长标题、选材行对齐及表单展开后的间距。
