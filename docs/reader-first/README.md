# 从读懂、找回到行动

目标是一个理解个人材料和经历、能找回答案并持续跟进事项的助手。代码、文档、群聊与图片共享来源；代码有专用结构分析，不能变成另一个知识产品。

2026-10-04 的整体复审指出文件说明与文章混杂、综合解释容易整体过期和检索规则缺少稳定收益。随后已分开发布用途，移除旧逐文件阅读目录，接入章节影响判断、文章持续维护、正式项目范围和材料用途的换版维护。现在主要缺口是前排材料仍可能不回答问题、文章仍有低价值细节，以及复杂项目的持续理解。具体已完成与失败以[实施进度](progress.md)为准；不继续把小模型筛选或少量题目的权重调整当主线。

阅读入口应覆盖从认识系统、保存材料，到整理文章、查找答案和记忆跟进的完整路线。验收问题：陌生开发者读后能否解释完整流程、找到实现、开始修改？个人用户能否找回准确约定并完成事项？已发布篇数、全文覆盖数和引用通过数不能替代这些判断。
