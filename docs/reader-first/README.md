# 从读懂、找回到行动

目标是一个理解个人材料和经历、能找回答案并持续跟进事项的助手。代码、文档、群聊与图片共享来源；代码有专用结构分析，不能变成另一个知识产品。

2026-10-01 的整体复审指出：来源保真和形式检查已经投入很多，但上下文调查、阅读路线、检索入口与长期理解还没有连成完整体验。本目录取代旧实施文档，跟进这次重构。

- [整体复审](review.md)：实际能力、问题成因及外部方案。
- [目标流程](architecture.md)：材料、检索、代码研究、知识与记忆如何协作。
- [写作与阅读](writing.md)：读者任务、页面模板、引用和视觉规范。
- [通用流程修正](general-knowledge.md)：去除仓库特判、持久分类和按选材生成。
- [实施进度](progress.md)：已完成、正在做、未实现及真实验收。
- [运行说明](operations.md)：启动、生成、本地模型、检查与数据位置。

第一阶段的可见交付是五篇可读的系统指南与一条可用的检索链。验收问题：陌生开发者读后能否解释完整流程、找到实现、开始修改？全文覆盖数和引用通过数不能替代这个判断。
