# 用户已确认的实施方向

确认日期：2026-09-26。本页替代第一轮设计中的待确认问题。

| 事项 | 已确认 |
| --- | --- |
| 使用对象 | 先服务个人，保留团队模型设计 |
| 部署 | 长期服务器运行，也能本地运行 |
| 大语言模型 | 不使用本地 LLM；先通过 Agent CLI/ACP（TraeX、Codex、Claude Code），以后接 API；模型、effort、上下文可配置 |
| 本地模型 | 当前无现成权重；需要时下载 embedding/reranker 等小模型，使用 osdk 管理；本轮不引入本地 LLM |
| 首批材料 | lark-cli 飞书文档、Git、纯文本、Agent 会话/hooks、主动输入；统一支持文本+图片+链接 |
| 助理目标 | 观察日常工作、记录需求/事项/待办，主动推进、整理与提醒；屏幕/UI节点/应用切换由外部观察工具喂入 |
| 自治 | 高置信度可自动变更，每次都通知修改内容；歧义、背景不足、大范围、危险操作可询问 |
| 通知与预算 | 预算较高；偏好即时通知，方式与频率可配置 |
| 前端 | 用户认可的原型风格；产品使用 Vue，沉淀设计 skill、根 design.md 和公共组件 |
| 工具链 | 基础依赖由 osdk 管理；container 未完整实测，能力不足或 bug 如实反馈 |

当前已实现和下一步见 [实施状态](implementation/status.md)。尚未配置生产令牌、外部飞书通知目标、全局 hooks 和屏幕采集范围；这些不妨碍开发基础功能，也不自动扩大真实材料采集范围。
