# 运行产物：交办留下的截图、录屏和报告

状态：2026-11-07 实现。和 [preview.md](preview.md) 一起解决“编码像黑盒”：预览看的是正在跑的页面，产物是改完以后留下来的记录，本人不用在本机起服务、找截图。

## 1. 要解决的

本人不在跑交办的那台机器上，过去想看改出来的效果只能自己拉代码、起服务；项目里的端到端测试、截图脚本、测试报告产出的文件留在工作区里，工作区一收回就没了，评审和逐项验证也看不到。

要做到：

1. 编码 Agent、宿主跑的检查命令、外部 Agent 的命令产出的截图、录屏、报告、日志，挂到运行上，按修改项看。
2. 不靠 omem 认识某个测试框架或截图工具：项目用什么办法产出由仓库自己定（仓库里的技能、测试脚本），omem 只管收、存、看。
3. 评审和逐项验证拿得到这些文件。
4. 从别的电脑（`omem peer open`，经中间设备也行）能直接看，视频能拖动，报告能打开。

## 2. 怎么交

两种，结果一样：

- **放进目录**：交办的编码 Agent（和编码助手）的进程，以及宿主替它跑的检查命令、外部 Agent 经 `code_workspace` 运行的命令，都带环境变量 `OMEM_ARTIFACTS`，指向这次运行自己的收件目录（`<数据目录>/artifacts/inbox/<运行 id>`，在工作区外面，不会被当成改动提交）。宿主在三个时候收走：编码 Agent 调用 `finish_task` 时（这时收到的归到那一项）、Agent 这一轮结束时、每条命令跑完时。
  - 顶层子目录 `T<编号>/` 里的归到那一项，不管什么时候收；
  - 其他子目录是分组（`改前/`、`改后/`、`预设-空列表/`），名字留在产物名里，页面上按目录分开；
  - 带 `index.html` 的目录是一份报告（如测试报告），整个目录一起收，打开的是它的 index.html；
  - 隐藏文件、符号链接不收；收完目录清空。
- **按路径交**：`attach_artifact`（编码 Agent、编码助手、逐项验证和阶段评审的评审项可用），`path` 写工作区里的文件或目录（几个仓库时带仓库目录名），或收件目录里的文件，可带 `caption`（一句话说明）、`task`、`req`（需求点或测试点 id）。只能交这次交办的工作区和自己的收件目录里的东西（解析符号链接以后再比），不能交整个工作区。外部 Agent 用 `code_workspace` 的 `attach`。

评审项和编码 Agent 共用一轮的运行 id，所以评审项没有收件目录，只能按路径交，免得收走编码 Agent 正在写的文件。

## 3. 存放和上限

- 文件复制（收件目录里的是移动）到 `<数据目录>/artifacts/<产物 id>/`，表 `run_artifacts` 记运行、所属交办（第一轮的运行 id）、空间、修改项、需求点、名字、说明、类型、大小、来源（agent / check / command）。工作区收回、交办应用或丢弃后照样能看。
- 类型按扩展名：图片（png、jpg、gif、webp、avif、svg）、视频（mp4、webm、mov）、网页（html）、报告（目录）、文本（txt、log、md、json、csv、xml、yaml）、其他文件（下载）。
- 单个文件最多 200 MB，一份报告最多 5000 个文件，一次最多收 300 个，一个交办（或交办之外的一次运行）合计最多 4 GB；超出的不收，在活动里写明。
- 只在产生它的设备上：`omem peer pull` 不搬（表在设备本地数据里）。本人可以在页面上删掉单个产物。

## 4. 怎么看

- 交办视图多一个“产物 N”标签（有产物时才出现），按修改项分组（T 编号和标题），没归到修改项的放最后；组里按目录分开，图片和视频显示缩略图。点开是全屏查看：图片、视频（能拖动）、文本、网页和报告；← → 切换，Esc 关闭并回到原来的位置。
- 修改项那一行写“产物 N”，展开后“看截图和报告”直接跳到那一项的产物。
- 阶段评审的材料里列出这次交办的全部产物，逐项验证列出那几项的产物，都带这台机器上的文件路径：能读图片的 Agent 可以直接打开看。

## 5. 文件怎么给出去（安全）

- 列表 `GET /api/runs/:id/artifacts` 按运行的读权限（交办的任一轮都列出整个交办的）。
- 文件 `GET /api/artifacts/<产物 id>.<密钥>/<路径>`：密钥是每个产物随机生成的，路径里带着它就能读，不用登录。这是有意的：报告页在沙箱里打开，没有 omem 的登录状态，它自己的脚本、样式、数据要按相对路径读回来；`omem peer open` 里沙箱页的请求带 `Origin: null`，这类请求也只对这个路径放行。列表之外拿不到密钥。
- 网页、报告和 SVG 带 `Content-Security-Policy: sandbox …`（不含 `allow-same-origin`），页面在自己的不透明源里运行，读不到 omem 的 cookie，也调不了 omem 的接口；网页上也只在 `sandbox` 的 iframe 里打开它们，不提供直接在新标签打开。所有文件带 `nosniff`、`Referrer-Policy: no-referrer`。
- 支持 Range（视频拖动）。中间设备转发时把 Range 和这些响应头原样带过去。

## 6. 和别的部分

- 编码 Agent 的说明（`roles/coder.md` 的“截图、录屏和报告”）：用项目已有的办法留下结果，按修改项放，写清是什么状态、改前改后；项目没有现成办法的不为此装工具。
- 预览（preview.md）解决“现在长什么样”，产物解决“当时验证的是什么样”；两者都不认项目的名字和框架。
- 截图墙（按 Mock 预设、基础分支和工作分支各截一套）由仓库技能产出到收件目录，按目录分组就是对照。

## 7. 没做的

- 测试点详情上显示最近一次的产物（`req` 已经记下，页面还没接）。
- 预览命令的输出不收（预览是长期运行的服务）。
- 自动清理旧产物；现在靠上限和手动删除。
