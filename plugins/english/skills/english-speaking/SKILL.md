## 看什么

只看学习者（learner）说的话；语音模型（partner）的话用来理解上下文。学习者的话是语音转写，个别词转错不扣分；转写看不出语速和发音，不要编。

| 维度（scores 的键） | 看什么 |
| --- | --- |
| 流利度 `fluency` | 句子能不能连着说下去；大量 “uh / um”、说半句停下、改口很多算不流利。 |
| 语法 `grammar` | 时态、主谓一致、冠词、介词、语序。区分“影响理解的错”和“小错”。 |
| 词汇 `vocab` | 用词是否准确、是否只会最基础的词、有没有中式直译（如 “open the light”）。 |
| 得体 `fit` | 在这个场景里说得是否自然、礼貌程度是否合适、有没有完成场景里要办的事。 |
| 求助 | 用中文问了哪些说法：这些就是要补的词和句型，记进 points（correct=false）。 |

每项 1–5 分：1 基本说不出，2 能说单词和短句、错误影响理解，3 能完成简单交流、常有小错，4 大体自然、偶有错，5 接近母语者。证据不够的项写 null，不要猜。

评价要真实：按记录里实际说出的话打分，不因为对方是学习者就放宽。学习者只说了一两句时，level 按能看出的给，review 直说“这次说得太少，没法细评”，再给下次的建议。

## review 怎么写

review 原样显示给学习者，用中文写，英文例句保留英文：

1. **一句话结论**：整体水平和这次最明显的问题。
2. **改一改**：挑 3–6 句学习者真说过的话，按 “你说的 → 更自然的说法（为什么）” 列出。优先挑影响理解的、反复出现的、中式直译的。
3. **这次学到的说法**：学习者用中文问过的说法和对话里值得记的表达，列成短表（英文 + 中文意思）。
4. **下次练什么**：1–2 条具体建议（换什么场景、刻意用什么句型）。

不写空话（“整体不错，继续加油”），不罗列学习者没犯的错。水平和分数页面上单独显示，review 里不用再列一遍。

## points 怎么记

和出题用同一套写法（`word:<词原形>`、`phrase:<短语>`、`grammar:<语法点>`，小写英文）。说错的、用中文求助的记 `correct: false`，`error_tag` 用出题时的错误类型（tense、article、preposition、word-choice……）；用对了且值得记的记 `correct: true`。它们会进学习画像，薄弱的会出现在之后的题里。反复说错的单词或短语，也可以用 `create_card` 加成复习卡。
