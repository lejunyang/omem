## 可编辑的知识目录

知识库可选择材料或项目、填写阅读目标，由 Agent 调查保存的快照并建议多篇页面。页面标题、用途、读者、案例、问题、材料范围、分类和顺序均可调整；支持合并候选和延续已有普通文章。草案持久保存，确认前不会创建正式文章；确认后复用既有调查、写作和独立补查流程。正式目录立即采用新标题和顺序，旧正文与固定引用保留。

网页与 CLI 已接通，随包 skill 和帮助已更新。主助手自然语言目录操作尚未注册；草案移除不删除已发表文章，确认时全部页面安排写作。重拟会替换候选，应先保存副本。完整入口和限制见[知识目录草案](../../../docs/reader-first/knowledge-outlines.md)。
