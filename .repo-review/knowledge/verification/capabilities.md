## 本轮交付

| 用户操作 | 已接通的行为 | 当前限制 |
| --- | --- | --- |
| 通过主助手或已绑定机器人交办 | 先查询真实会话和已有任务，再关注会话、修改采集政策、设置或管理简报；同名群消歧，同用途任务优先更新 | 每轮应用一个工作操作，采集和简报分轮设置；材料和群内他人的指令不构成本人授权 |
| 自动发现需要关注的群 | 过滤人工选择和免打扰，缓存抽样，快速模型按政策、排除、本人与项目关系、持续价值、越权指令六维判断 | 需开启采集、自动关注并准备快速模型；模型不可用或含糊保留待判断。默认关闭，没有验证真实私人群筛选准确率 |
| 定时整理跟进事项 | 按实际事项、需求、编码状态与已保存消息生成只读简报，可限定项目；同日状态未变不重复通知 | 未绑定机器人时保留站内结果。关机、休眠或停服务期间不运行；启动最多补一次到期执行 |
| 查看与设置定时任务 | 看板、查询、时间、范围、暂停恢复、立即执行、删除、运行历史、失败原因与通知状态；CLI 与随包 skill 同步提供入口 | 事项提醒是系统检查，提醒时间仍在事项页设置；运行记录保留上限不等于整个 jobs 表已做冷归档 |
| 沿简报引用查看讨论 | 站内打开保存的原件版本，机器人使用来源外部链接；项目范围按持久材料归属过滤 | 通知入队不代表飞书送达；本轮未连接私人机器人发测试消息 |

开发入口只恢复已提交知识、原件与历史，不自动生成整库或发材料通知。验收发现此前恢复误排了仓库记忆任务，已取消这些未完成任务；原件、知识历史和原有演示事项保留。显式材料导入继续按个人处理设置运行。

## 知识更新与既有缺口

个人消息读者指南使用真实 Traex ACP / Sol 完成调查、三稿写作和独立补查，发布时因输入换版失败，旧有效正文与固定引用保留。人工阅读发现三项启用缺口：自动关注与简报应分轮交办并查看回执；快速模型准备与记忆整理后台前提没有写全；免打扰案例缺少提及开关的位置和关闭行为。没有手改模型正文或继续重跑；当前使用以已核对的 CLI 和 reader-first 文档为准。
