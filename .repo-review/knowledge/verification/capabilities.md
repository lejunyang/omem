## 原件与重新处理

代码、普通文件和独立飞书文档只保留同一来源的最新原件。旧版本保留身份和移除原因，引用不可用时给出说明；已经生成的文章默认仍可读。聊天与本人反馈按事件保留正文和已下载资源；消息分享的文档响应归属当时事件。未下载的附件只有缺口记录。

PDF/DOCX 原字节先保存，再创建持久解析任务；失败仍有导入记录、错误和下载入口。同一上传标识更新原件，旧失败上传不再永久占用资源，正在解析的文件仍受保护。机器人保存事件 JSON 和资源，停用连接后可重新理解已保存材料；离线重放不再次执行旧委托或回复。

`omem reprocess` 与网页共同提供解析、理解、用途说明、远端刷新和文章写作。`--replace` 清除对应旧成果及其正文历史后生成，人工修改的记忆和事项保留；旧任务或启动恢复不能重新发布已删除的正文。持久处理记录跟踪后续任务，失败可重试。省略替换选项则在处理中保留旧成果。完整步骤见[重新处理](../../../skills/omem-cli/references/reprocessing.md)。

## 诊断日志

统一 Pino JSON 日志覆盖后台任务、Agent 调用、检索决策和 API 异常，按实际上下文带上任务、来源与消息标识。默认 info，配置或 `OMEM_LOG_LEVEL` 可调整；debug 记录逐条材料判断。原文、提示词及工具输出排除，异常只保留类别和位置，凭据脱敏。查询只读取现行日志末尾的有界窗口。

PM2 隔离加载 npm 包内的 pm2-logrotate 2.7.0，默认 10 MiB、7 份压缩归档，每十秒检查并在本机零点轮换。实际隔离实验核对本地加载、关闭 watch、压缩有效和归档份数；3.0.0 的布尔配置问题促成版本锁定。配置修改须重启，状态命令报告实际等级及模块在线状态。入口见[日志指引](../../../skills/omem-cli/references/logging.md)。
