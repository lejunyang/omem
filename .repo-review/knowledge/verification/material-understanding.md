## 用户现在可以做什么

在原始材料或引用弹窗中展开“材料用途与适用范围”，让 AI 读取原文后说明：这是实现、规范、计划、调研还是事件记录；是否尚未实施或已经过时；适用于什么场景；有哪些概念和常用说法，分别对应原文哪些行。用户可以修正，修正不会改变原件，后续模型也不会覆盖人工判断。原文换版后另行分析，不把旧说明自动套到新内容上。

搜索同时使用这些段落概念和正式用途；可以明确筛选命中材料的用途。Agent 的目录、补读、材料搜索和知识搜索也能看到说明。它帮助判断材料适不适用，**不是经过事实应用流程的个人记忆**。“材料声明现行”不等于系统已证明它在所有场景中正确。日期只接受材料明确提供的有效期，保存时间不是生效时间。

这是显式启动的功能，尚未自动处理每一份新输入。当前一种主用途也不能准确覆盖所有长文中的混合段落。网页用途筛选只影响命中材料，不暗中改变上方 AI 回答的调查范围。

## 真实模型与可复现记录

- 使用配置中的真实 Traex ACP、`gpt-5.6-sol`、medium；材料原件放入固定快照工作区，提供目录、搜索、补读、知识、记忆及代码导航工具。模型自行选择读取和调用次数，没有宿主 token 配额。
- 发布了 **88 份当前材料说明**，另保留 **17 份旧说明**。包括仓库文档与四份核心实现文件，不能说已理解全部代码库。当前恢复按固定 digest 匹配；历史文件用于追溯，不作为额外事实提高搜索权重。
- 从真实 dev 页面点击 AI，独立的“借阅登记试运行提案”被识别为计划／尚未实施，未编造日期，重复归还的概念指向原文第 7 行。模型 trace 记录了实际原文、章节补读和提交。这是通路样例，不是大库搜索效果证明。
- 人工修改说明后刷新仍保留，原件内容不变；实际 HTTP 能使用新增概念检索和用途筛选。
- 一次过宽的目录选择包含不需要处理的历史非 Markdown 文件，主动停止后改为明确目标重跑；保留原日志，不把被取消的运行记成成功或模型语义失败。

原生 CLI 仍可能读取祖先目录的指令，当前不能宣称完整文件系统隔离。

## 下一步应改什么

1. 明确符号需要独立的候选入口，保证完整方法先进入候选集，再与其他召回融合。对当前投影的只读诊断确认：长问题的全文候选有 189 条，`MemoryService.apply` 本体排第 159，融合只取前 100，因此最终名称加分救不回它。单独搜方法名只有 6 条全文候选，定义能进入最终排序。诊断保存在 gitignored `runtime/research/material-symbol-diagnostic.json`，没有改变排名。下一轮同时检查同名符号、否定提问和不存在的符号，避免只修这一个方法。
2. 对自然语言问题区分“当前能否使用”“为什么这样设计”“去哪里修改”。材料用途只能提供适用性，不能代替问题意图和答案内容相关性。按相关章节和实际代码邻接补齐功能链，保持完整上下文。
3. 继续评估中文重排与成熟检索方案，按真实命中收益和退步选择，不再单凭几个权重或复核通过下结论。派生文章本身若全是宽泛说明，排序算法也无法制造清楚的解释。

本轮没有实现上述独立符号分支，也没有自动完成章节级用途、可靠项目实体或完整时态推理。

记忆更新指南已发布，以规则“三次改五次”和另行交办评审跟进作对照，说明原文保存、重核验、知识更新和事项各自的结果。补查纠正了等待对象不能由上下文补猜的示例。不过正文仍用了较多 job、proposal、active、receipt 等内部状态，更接近开发者说明；普通用户入口仍应只先解释“保存了什么、当前采用什么、接下来会做什么”。

Agent 指南已发布，通过一次调查缺口说明两层分工：omem 准备材料、角色和发布流程，Traex 在一次 ACP turn 内自主选择工具并反复读取。它明确解释了“一次 prompt 不等于一次模型推理”，也区分补查与读者验收。实现和限制部分依然很长，应按读者目的拆成默认主线与可展开的开发细节。

运行也暴露了维护成本：本轮入门指南约 20 分钟，材料导入指南经历两次返修后约 34 分钟（含调查、写作、补查和模型等待）。复核有纠正操作步骤的价值，也花了大量时间补准引用范围。多篇文章依赖总览和进度文档，材料级摘要改变容易引发广泛失效。后续应评估按实际引用范围识别影响、复用未变的研究结论和局部改写；不能把“原生 Agent 能反复调用工具”直接当作有效率、易维护的知识系统。

另一个具体问题在 `writeAndVerify`：上轮意见会交给刷新者，但下一轮 verifier 主要收到新草稿、目标和原件，缺少上轮复核结论与正文差异。例如 Agent 指南仅恢复状态名混用就触发了完整返修周期。后续应给独立复核者同时提供原稿、改稿、上轮问题和改变的来源，让它判断哪些结论需要重新补查；保持独立判断，同时避免每次从零核对。文章也应删去读者不需要的内部状态名，减少无助于理解的事实负担。
