# 问答补读与定位：本轮实际结果

2026-10-03。实现为 `625766f`、`506514f`。本轮修复了真正造成失败的工具定位，补充了原生会话计时，并用真实 Traex ACP 继续检查 Luna/Sol。**工具更可用，但 Luna 仍会漏关键条件，初始检索也没有整体变好。默认不改成 Luna。**

## 修复了什么

- 初始原件的 `materialKey` 原先按存储命名空间重建，与输入适配器暴露的目录 key 不一致；模型照抄也失败。现在沿用检索固定引用的 key，历史范围也保留同一公开身份。
- 已有讲解原先只有标题和摘录，模型想继续读时拿不到文章及章节 key。现在同时传递完整定位；标题不再被当作定位字段。
- `search_materials.keys` 和原文读取共用解析，均接受准确 key、材料路径及导出路径；未知或有歧义的输入返回错误，不能用空结果掩盖限定范围失败。
- `read_section.atLine` 直接读取命中所在的完整章节或方法。入口给出实际 skill 路径、当前问题和阅读线索；完整历史、事项与摘录仍可按需读。没有新增 token、工具次数或研究轮数上限。
- trace 分开材料准备、ACP 初始化、会话配置、prompt、首工具等待和原生工具失败。prompt 包含工具与服务等待，不能叫纯推理时间。

修复讲解定位后，仅重跑暴露问题的记忆题：Luna **127.4 秒、24 次原生工具调用**，依然遗漏后台启用条件；提交时还把一个准确 key 自行改成斜杠形式，被工具拒绝后修正。不能用前一次 94 秒挑选最佳成绩。Sol 同题 **160.1 秒、35 次工具调用**，这次明确写出后台未启用时只排队、不自动完成，并保留同一记忆 ID 的示例；它也很冗长。中间首轮 Luna 曾答出启用条件，重跑又遗漏，说明质量仍不稳定。

原件定位修复后的四题，原生初始化约 1.3–1.9 秒、会话准备约 4.1–8.5 秒、prompt 约 58.6–106.0 秒，材料准备约 10–11 秒。主要时间仍在调查/组织回答，不能把所有延迟归因于启动。三题没有原生工具失败；记忆题暴露的讲解 key 缺失促成第二个修复。最终单题仍有一次错误引用提交；没有藏掉。

人工阅读还有两处不足：记忆题大量使用状态和测试作为解释，适合开发者但不够生活化；修改入口题给了过长的“写入时 trim 文本”示例，容易让人忽视已核验提案与最终写入内容应一致。找到文件、引用有效，并不代表这个教学例子就是推荐改法。

## 分类实验：减少干扰，没有制造答案

真实 Sol 自主读取 `config/` 的五份尚未分类材料：两份实际配置标为 implementation，两份示例标为 example，指南计划标为 plan。模型没有得到评测题或预期排序，没有按文件名写降权规则。

在隔离数据库保留同一原件、知识和排序实现，只移除/恢复这五份说明，重新建立受影响索引，并通过真实生产 HTTP `/api/search` 比较五题。[固定结果](assistant-reading-catalog.json)记录完整正文与行范围；更大的原始响应在报告中的 runtime 路径留存。

- “原始资料修改后怎样重新验证记忆”：写作计划由第 3 项退出返回列表，但第一项仍是关键词检索说明，后面有旧飞书实现和测试内容；关键流程没有因此进入前排。
- 本地模型下载和 `MemoryService.apply` 两题前五项不变，已有可用入口。
- “知识指南预备写哪些主题”：分类前后都偏向知识目录 UI，未找到应有的写作计划。不能把“计划永远靠后”当成正确性。
- “修改知识写作 Agent 思考强度”：前五项不变，说明文档有帮助，实际配置仍没有进入前排。

这次说明补齐有效地区分了材料用途，但不能修复候选缺失、混合用途或“主题相关但不回答”。因此继续保留成熟中文向量与可选重排，不把这轮说成新的排序方案。

## 模型知识与检查

实现先提交，再用 `config/review-code-model.json` 的真实 Traex ACP / `gpt-5.6-sol` 更新受影响的提问与自主研究指南。首次指南调查因发现讲解定位缺失而中止，日志保留；第二次按最终实现重启。旧历史与未更新的文件级文章保留，不能将两篇指南更新宣称为全库更新。

独立复核确实发现了阅读问题：第一版仅说“一份设计和一段实现”，没有具体输入、缺口与补读后的因果，因而被要求重写。后续稿用 `writePage` 解释“一次 ACP prompt 如何多次搜索”：先找到角色顺序，再发现仍解释不了交互循环，补读协议和会话实现，最后组织成文章。与此同时，依赖范围、作者与复核者交接、历史版本及时间含义仍经历了多轮返工；这套流程没有因此变快，下一步要减少分散反馈和不必要的边界论述，而不是把通过复核等同于可读。

最终两篇均已发布、独立复核 accepted、依赖 current：问答指南正文约 3652 字符/33 引用，自主调查指南约 3675 字符/20 引用。后一篇从初稿约 2866 字符增加了许多版本和隔离边界说明，事实更准确，但主线仍容易被细节打断；更适合把这些内容组织为按需阅读的补充。两篇更新没有修复其他四篇既有 stale 指南，文件级旧文章也没有冒充本轮重写。
