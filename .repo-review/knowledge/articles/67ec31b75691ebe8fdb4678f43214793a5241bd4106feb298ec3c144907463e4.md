# 代码图解析、同步生命周期与 HTTP 接口测试

验证 TypeScript/Vue 解析、按快照保存的代码图生命周期、与既有知识表的隔离，以及代码文件、符号、图和源码切片接口。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="parser"></a>
## 确定性解析范围

测试在临时 Git 仓库中提交 TypeScript 与 Vue 文件，经评审捕获后投影代码图。它断言函数、类方法、导出状态和源码行号能够提取，并仅检查函数符号的 `fragmentId` 非空；没有查询 fragments 表证明该值确实指向捕获片段。Vue SFC 至少产生以文件名命名的 component 符号。[TypeScript 与 Vue 解析夹具 ↗](../../../apps/server/tests/code-knowledge.test.ts#L70 "支持函数、类方法、非空 fragmentId 和 Vue component 符号的实际断言，并界定未验证的 fragment 引用完整性。") 当前材料也没有单独证明跨文件 calls 解析。

<a id="lifecycle"></a>
## 快照生命周期与数据隔离

相同输入二次同步复用快照且不增加符号行；相同字节但不同路径仍获得独立文件和符号身份。删除文件后，包含 removed 项的列表将其标为已删除，历史边行仍保留，而当前 head 图不再返回该文件的出边；测试没有断言当前图的 files 数组排除了该文件，因此此前更宽的结论被替代。新提交形成新快照，旧快照仍可读取。[代码同步生命周期 ↗](../../../apps/server/tests/code-knowledge.test.ts#L139 "支持幂等复用、路径参与身份、删除状态、历史边保留、当前图不返回被删文件出边及旧快照可读。") 未重新捕获的工作区脏改动不会成为新证据；代码投影前后，既有知识链表计数保持不变。[脏树与增量代码表 ↗](../../../apps/server/tests/code-knowledge.test.ts#L242 "支持未捕获磁盘编辑不进入证据，以及代码投影前后既有知识链表计数不变。")

<a id="coverage_http"></a>
## 真实仓库覆盖与读取接口

真实仓库用例要求图覆盖 assistant、memory、retrieval、Lark 和 Vue 区域，并断言文件、符号和边均非空；它没有检查每条边的 status，因此只能确认图中存在边。[真实仓库代码图覆盖 ↗](../../../apps/server/tests/code-knowledge.test.ts#L286 "支持真实仓库关键区域与 Vue 文件被投影，并准确限定断言为图中的文件、符号和边非空。") HTTP 用例验证文件列表、文件符号、图和合法源码切片可读取，越界行号返回 400。[代码读取 HTTP 接口 ↗](../../../apps/server/tests/code-knowledge.test.ts#L324 "支持文件、符号、图和源码切片接口，以及越界行号返回 400 的行为。") 测试未覆盖认证、分页、并发同步、超大仓库性能或跨 revision 的符号身份续接。
