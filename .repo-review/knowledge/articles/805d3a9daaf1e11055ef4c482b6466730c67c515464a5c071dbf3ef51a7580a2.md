# 安全的 Markdown、证据引用与流程图阅读器

该组件把知识正文转换为经过净化的可交互 HTML，统一处理可选的证据引用、代码高亮、Mermaid 流程图和链接分流，并在渲染失败时展示原文。递增代次避免旧异步结果覆盖新正文，但异步期间清空正文可能使加载提示无法结束。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 面向证据阅读的正文展示

组件接收 Markdown 正文和可选引用清单，对外发出“打开引用”与“内部导航”事件，适合作为知识文章或证据阅读器的正文层；引用最终如何打开、内部路径如何解释，仍由上层决定。参考 [正文输入与导航事件 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L7 "支持组件接收正文和引用清单，并把引用打开及内部导航交给上层处理的说明。")

提供引用清单时，正文中的 `[[引用键]]` 会转换为人类可读的标签：有效引用成为专用链接，不可操作引用显示原因，清单中找不到的键显示“引用不可用”。未提供引用清单时，标记保持原样，不会被误报为失效证据。参考 [引用标记转换条件 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L38 "支持仅在提供引用清单时转换引用标记，以及有效、不可用和缺失引用的不同展示行为。")

<a id="pipeline"></a>
## 从 Markdown 到安全 HTML

渲染分为引用替换、Markdown 解析、代码处理、HTML 净化、引用整理和流程图渲染。普通代码块调用共享高亮器，Mermaid 块先暂存；净化阶段仅允许指定标签、`href`、`class`、`title` 属性，以及外部协议、绝对路径或相对路径形式的 URI，同时禁用数据属性。参考 [解析与净化规则 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L45 "支持代码块处理、Mermaid 暂存，以及允许标签、属性和 URI 范围的渲染流水线说明。")

共享高亮器按语言别名加载 TypeScript、JavaScript、XML、CSS、Markdown、JSON、INI 与 Bash；Vue、HTML 映射到 XML，未知语言则只转义代码，不尝试高亮。参考 [共享代码高亮规则 ↗](../../../packages/ui/src/highlight.ts#L3 "支持语言别名、按需加载、XML 相关依赖和未知语言转义降级的说明。")

独立出现的引用会移到所在段落末尾组成“参考”区域，语句内部引用保留原位。Mermaid 采用严格安全级别，生成的 SVG 还会再次净化；渲染失败时保留原始图表描述。只有当前代次仍为最新时，异步结果才会写入页面。参考 [引用整理与流程图渲染 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L66 "支持段末引用整理、Mermaid 严格渲染与二次净化、失败保留原文及最新代次提交控制。")

<a id="interaction-limits"></a>
## 链接分流、失败降级与已知限制

点击引用专用链接时，组件发出引用事件；HTTP、邮件和电话链接在新窗口打开并设置隔离属性；其他链接阻止默认跳转后交给上层作为内部路径处理。参考 [链接点击分流 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L110 "支持引用链接、外部链接和内部路径采用不同点击行为的说明。")

Markdown 解析或依赖加载失败时，界面显示失败提示和原始正文；正常渲染期间显示加载提示，成功后展示净化后的 HTML。参考 [渲染状态与失败界面 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L125 "支持加载提示、失败后展示原始 Markdown 和成功后展示 HTML 的界面行为。") 图片标签不在允许列表内，因此普通 Markdown 图片会被移除；数据属性也被禁止，链接地址仅保留明确允许的协议和路径形式。参考 [HTML 与地址允许范围 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L19 "支持图片标签未获允许、数据属性被禁用，以及 URI 仅接受指定协议和路径形式的安全边界。")

空正文会立即清空已有 HTML，但该分支没有把 `loading` 复位。若前一次异步渲染尚未结束，此次更新会推进代次，使旧请求的收尾逻辑也不能复位加载状态，界面可能持续停留在“正在渲染 Markdown…”提示。参考 [空正文加载状态 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L25 "支持空正文清空 HTML 后提前返回且未复位 loading，以及异步收尾受渲染代次限制这一已知竞态。")
