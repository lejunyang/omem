# 研究数据库快照的并发构建与交付

该模块把指定材料和知识文章投影成一次研究流程使用的独立 SQLite 文件。它在 worker 线程中串行执行重型导出，对范围与数据库代际相同的重叠请求复用一次构建，同时保留每个调用者的独立取消和输出文件，并在发布前阻止已变化的材料被当作当前输入。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_and_roles"></a>
## 为研究请求准备隔离的数据库

该模块接收知识仓储、材料、文章和目标文件，也可附带片段可见性、状态收录选项与取消信号，输出供一次研究流程读取的 SQLite 快照。它依赖仓储提供当前数据库，并用稳定摘要识别相同输入。参考 [范围与构建键 ↗](../../../apps/server/src/knowledge/snapshot-build.ts#L85 "说明可见片段的计算、数据库代际读取、输入排序和稳定摘要构建。")

实际导出由 `snapshot-worker` 执行。参考 [worker 参数与创建 ↗](../../../apps/server/src/knowledge/snapshot-build.ts#L21 "说明模块等待前序构建，选择 snapshot-worker 入口，组装数据库、材料、文章、输出文件和范围参数，并按运行环境创建 Worker。")

重型导出一次只运行一个，排队采用异步等待，不阻塞读取、HTTP 监听或模型会话。参考 [输入与串行约束 ↗](../../../apps/server/src/knowledge/snapshot-build.ts#L12 "说明重型导出的串行策略、异步等待性质，以及快照构建接受的仓储、材料、文章、文件和可选范围参数。")

<a id="build_flow"></a>
## 从输入范围到独立文件

**示例调用：**调用方传入一个仓储、若干固定版本材料、文章列表、目标路径和可选 `visible` 过滤器。函数先求出可见片段，再读取当前连接的变更数和 SQLite `data_version`；材料按 key 排序，文章按文档 key 排序，因此仅列表顺序不同不会改变构建键。参考 [范围与构建键 ↗](../../../apps/server/src/knowledge/snapshot-build.ts#L85 "说明可见片段的计算、数据库代际读取、输入排序和稳定摘要构建。")

```mermaid
flowchart LR
  A[固定材料与文章] --> B[计算范围和数据库代际]
  B --> C[稳定摘要查找重叠构建]
  C --> D[worker 生成临时快照]
  D --> E[复制到调用者目标文件]
  E --> F[返回耗时与构建标识]
```

没有同键任务时，代码创建临时目录并启动一次构建；已有同键任务时则共享其 Promise。构建完成后，每个调用者把临时快照复制到自己的路径，并收到排队耗时、各阶段耗时、构建标识及是否合并的信息。参考 [重叠请求合并 ↗](../../../apps/server/src/knowledge/snapshot-build.ts#L104 "支持按稳定键复用正在进行的构建，并在没有匹配项时创建临时快照任务。") [独立文件交付 ↗](../../../apps/server/src/knowledge/snapshot-build.ts#L130 "说明调用者等待共享构建、复制到自己的目标文件，并取得构建标识、合并状态和阶段耗时。")

<a id="boundaries_and_cleanup"></a>
## 取消、变化检测与资源回收

取消按调用者隔离：某个读者取消时，只结束自己的等待；只要还有消费者，共享构建就继续。所有消费者都离开且构建未结束时，内部控制器才会终止 worker；构建结束后则删除临时目录。已完成项不会跨问题缓存。参考 [消费者取消与清理 ↗](../../../apps/server/src/knowledge/snapshot-build.ts#L117 "支持消费者计数、无消费者时的清理或内部取消，以及单个调用者取消不影响其他读者的机制。")

worker 消息携带错误时会拒绝，线程报错或未返回结果便退出也会拒绝。导出完成后，主线程再次核对每份材料对应 source 的当前 `head`；版本已变化时抛出 `KNOWLEDGE_INPUT_CHANGED`，不会把旧固定输入作为当前新快照交付。无论成功或失败，worker 都会终止，串行队列也会释放。参考 [失败处理与版本复核 ↗](../../../apps/server/src/knowledge/snapshot-build.ts#L57 "说明 worker 的消息、错误和异常退出处理，导出后的 source head 复核，以及 worker 与串行锁的最终释放。")
