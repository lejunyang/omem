# 共享证据 Trail 状态管理

以 Vue 组合式函数管理抽屉帧栈、当前帧、循环提示、焦点来源及关闭/后退/跳转操作，供个人与仓库知识阅读器复用。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="state-and-push"></a>
## 状态与入栈流程

组合式函数建立响应式帧数组、当前索引、开关状态、循环位置和触发元素，并以计算属性暴露当前活动帧。注释明确渲染栈不设深度上限，URL 长度预算交给路由序列化层。[共享 Trail 响应式状态 ↗](../../../packages/ui/src/useEvidenceTrail.ts#L1 "支持该组合式函数供两类知识阅读器共享、渲染无界且暴露当前帧的说明。") `push` 先按 kind 与 id 查重；若发现已有帧，只记录 `loopAt` 并返回，不重复入栈。首次打开时，浏览器环境会记录当前聚焦元素，随后不可变追加帧、移动到末帧、打开抽屉并调用变更回调。[去重、焦点记录与入栈 ↗](../../../packages/ui/src/useEvidenceTrail.ts#L8 "支持循环检测、首次打开时保存触发元素以及追加并打开抽屉的流程。")

<a id="navigation-and-boundaries"></a>
## 返回、跳转与关闭边界

`close` 清空全部帧并复位索引、开关和循环状态；`back` 在只剩一帧时直接关闭，否则删除末帧并更新当前索引；`jump` 保留目标索引之前的路径、切换当前帧并清除循环提示。三类成功状态变更都会调用 `onChange`，便于外层同步路由或持久化。[关闭、返回与跳转操作 ↗](../../../packages/ui/src/useEvidenceTrail.ts#L14 "支持三种导航操作如何变更栈、索引、开关、循环状态并通知外层。")

当前实现保存了首次触发元素，却没有在 `close` 中调用其 `focus()`；焦点归还可能由抽屉组件负责，但提供的材料不能证明。`jump` 也未校验负数或越界索引，调用者必须保证输入有效；重复 push 只设置循环位置，不触发 `onChange`。滚动位置虽然属于帧合同，本组合式函数没有直接读写。[组合式函数返回合同 ↗](../../../packages/ui/src/useEvidenceTrail.ts#L7 "用于界定已暴露的状态和方法，并支持焦点恢复、索引校验及滚动管理不在当前实现中的判断。")
