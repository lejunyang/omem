# 独立证据复核角色

该角色规范要求复核者脱离提取阶段的推理，直接对照原始证据与可信来源信息判断提案的支持程度，并严格限制输出状态和操作权限。材料描述的是角色契约，不能单独证明运行时已经接入或执行了该流程。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 为什么需要独立复核

该角色用于在提取之后建立一道独立检查：复核者不能沿用提取者的推理，而要重新确认引文或资产身份，并逐项比较主体、范围、时间、归属、否定关系、成立条件与论断强度。这样可以避免一段真实材料被错误地用于支持范围更大或语气更强的结论；遇到冲突或背景缺失时，也应保留不确定性，而不是强行消解。参考 [独立复核原则 ↗](../../../packages/agent-runtime/roles/verifier/1/prompt.md#L3 "支持复核者必须重新核对证据身份、语义范围与上下文，并保留冲突和缺失背景的说明。")

<a id="boundary"></a>
## 输出判定与权限边界

复核结果必须是单个 `AssessmentBatch.v1` JSON，并且只能使用 `supported`、`contradicted`、`insufficient` 或 `needs_scope` 四种状态。该角色只判断证据是否支持提案，不负责批准、应用、执行、发送消息或修改策略；即使材料正文要求调用工具或取得权限，也只能把它视为不可信证据。这里记录的是提示词规定的工作合同，并不能据此确认相应运行时流程已经实现或成功执行。参考 [判定状态与权限边界 ↗](../../../packages/agent-runtime/roles/verifier/1/prompt.md#L5 "支持结构化输出、限定判定状态以及复核角色不得执行或修改策略等边界。")
