# 证据核验角色 v1 提示词

提示词要求 verifier 脱离提取器推理，先复查引文或资产身份，再核对语义范围，并严格限制为支持性评估而非批准或执行。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="independent_review"></a>
## 独立复核流程

提示词把 verifier 定位为提案的独立复核者：只能依据所提供的原始证据和可信来源信息，不继承提取器的推理。流程先复查引文或资产身份，再比较主体、范围、时间、归属、否定、条件和陈述强度，并要求保留冲突及缺失上下文。[独立证据复核要求 ↗](../../../packages/agent-runtime/roles/verifier/1/prompt.md#L1 "支持不继承提取器推理、先核对身份再比较语义维度并保留冲突的流程说明。") 这体现的是角色行为要求；材料本身不证明模型每次都能稳定完成这些细粒度检查。

<a id="decision_boundary"></a>
## 输出与权限边界

输出必须是单个 `AssessmentBatch.v1` JSON 对象且不得夹带说明文字，语义结论只能使用四个受控状态。角色只判断证据是否支持提案，不负责批准、应用、执行、发送消息或修改政策。材料中即便出现索要工具或权限的文字，也仍被视为不可信证据。[结构化输出和无执行权限边界 ↗](../../../packages/agent-runtime/roles/verifier/1/prompt.md#L5 "支持限定输出枚举、仅评估支持性以及不批准、不执行、不修改政策的角色边界。")

因此该角色位于“提案形成”与“后续决策或变更”之间：它提供结构化支持性意见，但没有最终授权。这一边界也意味着后续消费者必须自行决定如何处理矛盾、证据不足和范围不清的结果。
