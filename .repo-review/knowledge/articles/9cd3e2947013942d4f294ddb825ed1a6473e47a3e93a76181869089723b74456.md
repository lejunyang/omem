# agent-runtime · 模块理解 · 专题 1

Agent 运行时把版本化角色制品、可信上下文、非可信材料、模型传输和持久任务连接为受控且可追踪的执行链：加载并核对角色资产，隔离组装提示，执行 ACP 或 CLI，按共享合同校验并有限修复输出，最后保存追踪和角色结果。当前交互请求仍以拒绝记录为主，角色输出保存与任务完成也不在同一事务。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="bundle_and_trust"></a>
## 角色制品与信任边界

运行入口先加载版本化角色包。注册表校验角色与清单身份、读取输出 Schema 并仅核对其 `$id` 末段是否匹配清单中的输出 Schema 标识，同时验证技能名称和制品摘要；它并不在此处验证 Schema 内容或模型输出。角色包身份由清单、提示、Schema 和技能内容共同形成，原生技能则复制到隔离工作区。[角色包加载、标识核对与工作区准备 ↗](../../../apps/server/src/agent-runtime/bundles.ts#L105 "支持角色清单身份、输出 Schema 标识核对、技能摘要、角色包身份和隔离工作区的说明，并限定此处不执行结构化输出验证。") 目录摘要统一路径分隔符与 CRLF/LF，降低跨平台差异。[跨平台技能目录摘要 ↗](../../../apps/server/src/agent-runtime/bundles.ts#L73 "支持目录摘要对路径分隔符和文本换行进行归一化的论断。")

提示构造把角色规则、内联技能、输出合同和来源元数据放入可信区，把派生知识及材料正文标为非可信数据。[可信提示与非可信材料分层 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L106 "支持角色规则和来源索引进入可信区，而派生知识与材料正文作为非可信内容进入提示。") 图像会校验 Base64、摘要及格式标记，并在提示组装时累计字节数，超过 10 MB 即拒绝。[图像校验与累计字节限制 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L81 "支持图像 Base64、摘要和格式标记校验，以及提示构造中超过一千万字节即拒绝的累计限制。")

<a id="execution_and_validation"></a>
## 预算、执行与结构化校验

网关合并输入、输出和上下文预留预算，并要求各值为 1 至 1,000,000 的安全整数；文本令牌量按 UTF-8 字节数除以 3 后增加 25% 余量近似估算，并非模型专用 tokenizer。[令牌估算与生成预算 ↗](../../../apps/server/src/agent-runtime/budget.ts#L1 "支持 UTF-8 近似令牌估算、25% 余量、预算默认值和数值边界校验。")

每轮尝试重新渲染提示并检查输入预算。ACP 可传图像、托管 MCP 和原生技能，CLI 仅接收文本。输出预算通过后，网关要求结果是单一 JSON 对象，再按清单指定的共享 Zod 合同解析，并执行可选的调用方附加校验；这才是实际结构化输出校验所在。[执行分支与实际输出校验 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L302 "支持每轮提示渲染、输入输出预算、ACP 与 CLI 分支、共享 Zod 合同解析、附加校验及有限修复边界。") 只有执行块内的输出类错误、语法错误或 Zod 错误会在次数允许时重试。成功 trace 保存运行审计字段，而指纹仅采用角色包、提示、上下文、技能、工具摘要及有效模型配置。[运行追踪与指纹范围 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L368 "支持 trace 保存的审计字段，以及运行指纹实际采用的摘要和模型配置范围。")

<a id="durable_job_flow"></a>
## 持久任务衔接与结果保存

角色任务处理器按任务生成上下文、透传取消信号、调用网关并要求存在会话标识，随后保存结构化结果和完整 trace，把输出记录引用交还 worker。[角色任务处理器成功路径 ↗](../../../apps/server/src/agent-runtime/job-handler.ts#L18 "支持上下文生成、网关调用、会话标识校验、角色输出保存和结果引用返回。") worker 负责租约领取、心跳、处理器分派及成功标记；失败会优先保留 `JobExecutionError` 明示的种类，否则普通异常默认归为 `permanent`，取消归为 `cancelled`，停机中断归为 `transient`。[Worker 的失败种类选择 ↗](../../../apps/server/src/jobs/worker.ts#L97 "支持显式 JobExecutionError 种类的保留，以及普通异常、取消和停机中断的默认分类方式。") 仓库定义的失败种类还包括 `bad_output`、`auth` 与 `config`，其中仅 `bad_output` 和 `transient` 具有内建重试额度。[任务失败类型与重试规则 ↗](../../../apps/server/src/jobs/repository.ts#L93 "支持完整失败类型集合，并说明 bad_output 与 transient 的重试额度及其他类型直接结束的规则。") 这替代了“异常仅按取消、瞬时或永久失败处理”的过窄结论。

角色输出保存会在一个事务内校验运行中租约、更新尝试追踪并插入输出记录。[角色输出事务保存 ↗](../../../apps/server/src/jobs/repository.ts#L452 "支持保存时校验运行中租约，并在一个事务内更新运行追踪和插入角色输出；也用于说明该事务未同时完成任务状态。") 任务成功标记随后由 worker 在另一个事务完成，因此两者之间仍有崩溃窗口，当前材料未显示按任务尝试或输出摘要去重。

<a id="progress_and_limits"></a>
## 当前能力与边界

共享知识合同统一约束文档、章节、引用、问题和批次形状，使多类分析角色复用同一输出结构。[共享知识输出合同 ↗](../../../packages/contracts/src/knowledge.ts#L3 "支持知识文档、章节、引用、问题和批次由统一 Zod 合同约束。") 代码分析角色清单声明无工具、会话不复用、不继承用户扩展，并设定上下文、输出和修复预算；这些是运行配置，并非质量或测试覆盖证明。[分析角色隔离与预算配置 ↗](../../../packages/agent-runtime/roles/code-analyst/1/manifest.json#L17 "支持代码分析角色的无工具、会话不复用、禁止继承扩展能力及预算配置。")

交互请求尚未形成等待用户决策后恢复执行的闭环：网关收到 ACP 权限或询问请求时，仅通过可选仓库记录为 `denied`；仓库虽声明 `pending`、`expired`、`resolved` 并提供决议方法，但材料未展示暂停任务、持久化具体动作及恢复原会话的调用链。[运行时交互请求仓储 ↗](../../../apps/server/src/agent-runtime/requests.ts#L7 "支持请求状态模型、拒绝记录、决议方法和查询边界，并说明当前网关持久化路径主要记录 denied。") 所给材料也没有自动化测试或真实 ACP/CLI 运行结果，无法确认路径安全、预算拦截、修复分支、崩溃恢复及并发决议的实际覆盖。
