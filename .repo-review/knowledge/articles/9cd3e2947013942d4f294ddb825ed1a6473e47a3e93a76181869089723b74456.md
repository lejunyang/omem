# agent-runtime · 模块理解 · 专题 1

agent-runtime 是固定证据分析角色的共享执行层：验证版本化角色资产，隔离可信规则与不可信材料，按 ACP 或 CLI 传输，实施预算与能力检查，校验结构化输出并记录运行追踪；它已接入耐久作业，但交互审批、引用语义复核和外部 Agent 兼容性仍有待确认。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 职责与设计背景

该模块把材料领域逻辑留在角色包中，把通用执行约束交给宿主。角色清单声明提示、技能、输出合同、工具策略、会话隔离和预算；代码分析角色例如使用固定内联技能、`KnowledgeBatch.v1`、无工具策略和不复用会话。[代码分析角色运行清单 ↗](../../../packages/agent-runtime/roles/code-analyst/1/manifest.json#L2 "支持角色包声明提示、技能、输出合同、工具与会话策略及预算的实例。") 网关负责构造分层上下文，随后执行模型传输、结果校验和追踪；这一结论分别由提示构造、执行及验证代码支撑，替代此前仅引用运行前装配章节来概括全部职责的表述。[可信上下文与材料提示构造 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L106 "支持网关对可信规则、上下文索引、派生知识及原始材料进行分层装配。")[ACP 与 CLI 执行分支 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L302 "支持每次尝试的输入预算检查、ACP 参数传递、实际配置回读、CLI 图片限制和会话记录。")[输出后验校验与运行追踪 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L365 "支持输出预算、可选后验验证、trace 字段汇集以及运行指纹的构造。")

<a id="assets-context"></a>
## 资产验证与信任分层

注册表限制角色与版本名称，核对清单身份、输出 schema 标识、技能名称及目录摘要，并以清单、提示、合同和技能内容形成包摘要。[角色资产加载与完整性验证 ↗](../../../apps/server/src/agent-runtime/bundles.ts#L105 "支持清单身份、输出合同、技能名称、目录摘要及包摘要的验证流程。") 文件解析后的真实路径必须仍在包内，普通资产及遍历到的目录项会拒绝符号链接；复制时若目标内容冲突则失败。[资产路径与复制冲突保护 ↗](../../../apps/server/src/agent-runtime/bundles.ts#L41 "支持包内路径约束、符号链接拒绝、确定性目录遍历和复制时的内容冲突检查。") 只有 `native` 技能会复制到按包摘要和运行 ID 隔离的工作区，并且存在 native 技能时要求 ACP；这两个条件改由其实际实现范围支持。[native 技能隔离工作区 ↗](../../../apps/server/src/agent-runtime/bundles.ts#L170 "直接支持仅复制 native 技能、按运行建立工作区，以及 native 技能要求 ACP 的条件。")

提示把角色规则、内联技能、输出合同、可信元数据和材料索引置于可信区，将既有文章及材料正文标为不可信数据。图片还会校验编码、摘要、文件签名和累计容量，从而让捕获内容保持为证据而非工具指令。[提示信任分层与图片校验 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L81 "支持可信提示、不可信派生知识和材料的区分，以及图片编码、摘要、类型和容量检查。")

<a id="execution"></a>
## 执行、预算与结果校验

网关合并调用覆盖值与角色默认预算，按 UTF-8 字节启发式估算 token 并增加余量；该方法适合保守控制，但不是模型精确 tokenizer。[生成预算估算与配置 ↗](../../../apps/server/src/agent-runtime/budget.ts#L1 "支持 UTF-8 字节启发式估算、25% 余量、覆盖优先级和预算整数范围校验。") 运行前会校验 profile、禁止未实现的会话复用、核对托管工具供给并准备工作区。[网关运行前装配 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L247 "支持 profile、会话策略、托管工具供给的检查，以及技能摘要和隔离工作区准备。") 随后按 transport 进入 ACP 或 CLI：ACP 接收工具、native 技能、输出及上下文预算，CLI 则拒绝图片；这替代此前用 ACP 能力发现代码支持全部网关分支约束的结论。[ACP 与 CLI 执行分支 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L302 "支持每次尝试的输入预算检查、ACP 参数传递、实际配置回读、CLI 图片限制和会话记录。") ACP 自身还会发现 native 技能、验证模型与推理强度选项，并在元数据可用时检查上下文窗口及图片能力。[ACP 能力发现与配置检查 ↗](../../../apps/server/src/agents.ts#L259 "支持 native 技能发现、模型和推理强度支持性检查、上下文窗口校验及图片能力检查。")

模型结果须是单个 JSON 对象，通过清单对应的运行时合同，并在适用时核对作业或角色身份。[结构化输出解析 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L210 "支持单个 JSON 对象要求、运行时合同解析及作业和角色身份一致性检查。") 输出预算和可选后验验证通过后，网关汇集包、提示、上下文、技能、工具、实际模型、会话、用量及修复次数，并形成运行指纹。[输出后验校验与运行追踪 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L365 "支持输出预算、可选后验验证、trace 字段汇集以及运行指纹的构造。") 只有输出类、语法或 Zod 校验错误会进入有限的完整重生成；取消和其他运行错误直接传播。[有限输出修复边界 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L396 "支持仅对指定输出、语法或合同错误重试，并在取消、其他错误或次数耗尽时终止。")

<a id="integration-limits"></a>
## 作业接入与当前限制

作业适配器构造上下文、透传取消信号，并在成功后选择末次会话，将结果和完整 trace 按作业 ID 与 lease token 保存。[角色作业适配器 ↗](../../../apps/server/src/agent-runtime/job-handler.ts#L9 "支持从作业上下文调用网关、选择末次会话，并以租约绑定保存结果及运行证据。") 作业领取、心跳、取消、成功提交及失败分类由耐久 worker 管理。[耐久作业执行流程 ↗](../../../apps/server/src/jobs/worker.ts#L47 "支持作业领取、心跳、取消、成功提交、失败分类和过期租约处理。") 因而模块已经形成从角色资产到耐久作业的连续实现链，但材料没有测试文件或真实外部 Agent 检查结果，不能据此宣称所有 CLI 均已验证。

后台权限和补充输入请求目前不会暂停会话：ACP 回调记录事件后立即取消或拒绝。[后台请求立即拒绝 ↗](../../../apps/server/src/agents.ts#L181 "支持 ACP 权限和补充输入回调在通知宿主后立即取消或拒绝，而不暂停等待用户。") 仓储当前创建的是 `denied` 记录；虽然提供 `resolve`，它只接受既有 `pending`，材料未展示 pending 的创建或决定回传链路。[运行时请求仓储边界 ↗](../../../apps/server/src/agent-runtime/requests.ts#L37 "支持 denied 记录的幂等保存，以及 resolve 仅处理既有且未过期 pending 请求的限制。") 此外，结构合同只约束输出形状；网关虽允许调用方注入后验验证，哪些角色已执行跨字段引用检查及独立语义复核仍无法由当前材料确定。[输出后验校验与运行追踪 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L365 "支持输出预算、可选后验验证、trace 字段汇集以及运行指纹的构造。")[KnowledgeBatch 结构合同 ↗](../../../packages/agent-runtime/roles/code-analyst/1/output.schema.json#L78 "支持输出合同对文档、章节、引用和问题字段形状的约束，同时界定其不能独自保证跨字段和语义一致性。")
