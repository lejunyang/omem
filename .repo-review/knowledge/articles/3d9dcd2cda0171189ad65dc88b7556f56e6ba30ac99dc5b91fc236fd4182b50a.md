# 用户确认的产品与实施方向

该记录确认个人优先、飞书主入口、CLI/ACP 模型接入、统一输入、自治边界和 Vue 前端方向，同时强调外部连接必须按实际配置与授权核验。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="direction"></a>
## 产品与技术方向

系统先服务个人，同时保留团队模型设计；飞书机器人主 Agent 是第一入口，Web 是后台和第二入口。部署需兼顾服务器长期运行与本地运行。大模型先经 Agent CLI/ACP 接入，不要求本地 LLM；首批材料覆盖飞书文档、Git、文本、Agent 会话或 hooks 及主动输入，并统一考虑文本、图片和链接。[个人助手、入口与模型接入 ↗](../../../docs/decisions.md#L7 "支持个人优先、飞书主入口、部署方式、CLI/ACP 及首批输入范围。")

<a id="autonomy"></a>
## 自治与当前限制

高置信度变更可自动执行，但每次都应通知；歧义、背景不足、范围扩大和危险操作可询问。前端已确认使用 Vue。首批并未配置全部外部通知，实际连接、采集和投递范围取决于配置与授权；低价值飞书质量标注已停止，后续 v3 建议不能写成已实现或已验收。[自治、通知与前端决策 ↗](../../../docs/decisions.md#L14 "支持自动变更通知、例外询问、预算偏好和 Vue 前端方向。")[集成范围与停止状态 ↗](../../../docs/decisions.md#L19 "支持外部集成以配置授权为准，以及质量标注停止、后续建议尚未证明实施。")
