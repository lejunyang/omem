# 检索索引补建：从材料同步到中文向量

解释 retrieval:index 维护命令如何选择个人库或隔离评审库、在评审模式下同步材料与知识、分批补齐中文语义向量，并通过健康状态和资源清理给出可观察结果。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决什么问题

`retrieval:index` 是一次性**追赶索引**命令，适合大批材料导入或分类、知识变更后主动补齐检索数据；后续新捕获仍由服务端持续索引。任务由 Bun 执行，并提供 `review` 开关。参考 [索引任务入口 ↗](../../../osdk.toml#L91 "支持该命令由 Bun 执行并声明 review 开关的使用方式。") [追赶索引用途 ↗](../../../scripts/retrieval-index.ts#L2 "支持脚本用于大批导入后的显式追赶，且服务端还会处理后续捕获。")

不带开关时，它读取常规配置并打开个人数据目录；带 `--review` 时，则读取仓库检索配置、使用与个人库隔离的评审数据库。两种路径最终共享同一个 `UnifiedRetrieval` 实现。参考 [数据库与配置分支 ↗](../../../scripts/retrieval-index.ts#L13 "支持普通模式和 review 模式选择不同配置、Store，并共同构造 UnifiedRetrieval。")

<a id="flow"></a>
## 一次评审库补建如何运行

以 `osdk run retrieval:index --review` 为例，流程是：

```mermaid
flowchart LR
  A[打开隔离评审库] --> B[同步仓库原件]
  B --> C[恢复知识与材料说明]
  C --> D[同步代码结构]
  D --> E[每批最多 16 个检索单位]
  E --> F[写入向量并输出健康状态]
  F -->|仍有单位| E
```

评审库位于独立运行数据目录；知识恢复会重新捕获仓库材料、材料说明和已发布文章，代码同步则从已捕获的不可变 head revision 解析文件，避免把现场文本与旧片段混合。参考 [隔离评审数据库 ↗](../../../apps/server/src/review/store.ts#L100 "支持 review Store 使用独立运行数据目录、与个人工作区分离。") [评审知识恢复 ↗](../../../apps/server/src/review/knowledge.ts#L10 "支持评审模式恢复用户补充、仓库材料、材料说明和已发布知识文章。") [代码快照来源 ↗](../../../apps/server/src/code/sync.ts#L152 "支持代码同步从捕获链的不可变当前 revision 读取并解析受支持文件。")

进入索引循环后，服务先投影检索单位，再查找“当前模型尚无 vector head”的记录。每个单位按窗口切分，以最多 16 个窗口调用 passage embedding；随后在写事务内再次确认单位仍存在，写入各窗口向量和模型 head。空批次返回 `0`，外层循环据此结束。参考 [待索引单位与窗口 ↗](../../../apps/server/src/retrieval/unified.ts#L148 "支持按当前模型筛选未索引单位、切分窗口并分批生成 passage embedding。") [向量事务写入 ↗](../../../apps/server/src/retrieval/unified.ts#L178 "支持写锁内复核单位存在性、原子写入窗口向量与模型 head，以及空批次结束所依赖的返回值。")

<a id="boundaries"></a>
## 输出、并发与可修改点

运行中每批打印累计数量与健康状态，完成时输出含 `completed: true` 的 JSON；无论成功或抛错，`finally` 都会关闭检索模型和数据库。SQLite 写入等待上限设为 10 秒，用来容忍其他维护命令的短暂写锁。参考 [循环输出与清理 ↗](../../../scripts/retrieval-index.ts#L20 "支持 16 个单位一批的循环、完成 JSON，以及 finally 中的模型和数据库关闭。")

这个入口始终传入中文 embedding 加载器，因此它是语义向量补建工具，不受服务常驻配置里 `enabled` 是否启动后台语义检索的控制；它也没有传入 reranker。模型由 osdk 提供，代码核对仓库、固定 revision 和文件哈希，禁止远程隐式加载；缺模型、快照不匹配或校验失败会终止命令。要改批量吞吐看脚本的 `indexBatch(16)`，要改窗口文本、事务写入或完成判定看 `UnifiedRetrieval.index`。参考 [本地中文模型约束 ↗](../../../apps/server/src/retrieval/embedding.ts#L17 "支持 embedding 由 osdk 固定快照提供，校验仓库、revision 与哈希，并禁止远程模型加载。") [待索引单位与窗口 ↗](../../../apps/server/src/retrieval/unified.ts#L148 "支持按当前模型筛选未索引单位、切分窗口并分批生成 passage embedding。")
