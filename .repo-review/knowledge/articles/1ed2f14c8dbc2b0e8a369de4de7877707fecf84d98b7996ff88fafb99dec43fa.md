# 个人知识库的阅读与证据追溯

个人知识库把主题目录、可复核正文、固定引用和原始材料组织成连续阅读体验。读者可在保留文章上下文的同时逐层查看证据，并通过深链恢复阅读路径；当前边界主要涉及超长路径、异常帧输入、章节参数变化以及问题回答后的服务端处理语义。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="reading-entry"></a>
## 从主题文章进入知识阅读

知识库以目录和搜索帮助读者发现主题，右侧持续展示当前文章；目录区分总览、功能实现与其他文章，并在无内容时引导先导入和分析材料。延伸阅读：[知识库入口说明 ↗](cb98ae49e639ca46a724f14b8c3f204b0ccb2ac59342a7813a1e9e0df43d7e1a.md#purpose "概括知识首页用于发现文章、连续阅读和进入引用导航的职责。")；参考 [知识目录与正文入口 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L30 "支持双栏目录、搜索、文章分组、正文区域及空内容引导。")

文章按章节呈现摘要与 Markdown 正文，并标明“当前知识”或因原文变化、证据缺失而“待更新”的状态。章节较多时提供页内目录，尚不能确认的事项则留在文章后的问题区域。参考 [文章章节与知识状态 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L11 "支持文章摘要、当前性提示、分节 Markdown、问题区域和页内目录，并说明加载监听及章节定位的依赖。")

<a id="evidence-flow"></a>
## 从论断回到固定证据

正文引用只有在当前可操作时才会生成固定引用帧，帧中保留文章、修订和引用键；统一阅读帧随后展示引用理由，并把目标分派到知识文章或原始材料，不可用目标会明确说明原因。参考 [可操作引用导航 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L20 "支持只有可操作引用才会生成包含文章、修订和引用键的导航帧。")、[引用目标分派 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L7 "支持知识、原文和固定引用三类展示，以及不可用目标的明确反馈；同时呈现异常帧缺少运行时判别校验的边界。")

个人知识入口让主文章与共享轨迹抽屉并存，读者深入证据时无需离开原阅读上下文。参考 [共享证据抽屉 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L27 "支持主知识页面与轨迹抽屉并存，并由活动帧承载继续阅读。")；延伸阅读：[证据路径说明 ↗](6cfb648275c3208d7f5b2eec871ec8ccf7e97c6c118bb950168912261683ccb2.md#purpose "概括个人知识入口保留主阅读上下文并沿轨迹查看证据的作用。") 原文视图会标明当前或历史版本，代码材料可围绕引用行逐步展开，Markdown 保持连贯全文阅读，并允许返回已有知识解读。参考 [固定原文阅读 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L37 "支持材料版本状态、知识解读入口、代码摘录扩展、Markdown 全文和图片展示。")

<a id="trail-and-deeplink"></a>
## 多层追溯与深链恢复

当前文章和证据帧栈会写入 URL hash，刷新或打开分享链接时可恢复文章、允许的帧类型、当前层级和抽屉状态。路径超过预算后，现有阅读不会中断，但页面停止保存完整路径并显示提示。参考 [阅读路径保存与恢复 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L8 "支持把文章和轨迹写入 URL、过滤允许的帧类型，并恢复当前层级与抽屉状态。")

共享轨迹按帧类型与稳定标识联合检测循环，运行时压栈本身不会截断；常量 200 约束的是深链持久化长度。参考 [轨迹循环与长度预算 ↗](../../../packages/ui/src/trail.ts#L37 "说明联合身份循环检测、运行时追加行为及深链持久化的 200 层预算。") 测试已覆盖不同类型同名不误判、五层钻取与回退，以及十二层链不沿用旧的八层截断。参考 [深层导航测试 ↗](../../../apps/web/src/codewiki/trail.test.ts#L8 "支持跨类型身份区分、十二层链保留及五层钻取与回退场景已经得到测试。")

<a id="progress-and-limits"></a>
## 当前能力与待验证边界

阅读链路已经贯通知识目录、文章、固定引用、原文和深链恢复；待确认问题也可在文章现场补充背景或请求加入待办。界面会提交相应请求并刷新状态，但前端材料不能证明答案已经持久化为原始证据，或相关知识已完成重核对。参考 [问题补充与待办请求 ↗](../../../apps/web/src/knowledge/KnowledgeQuestions.vue#L11 "支持问题状态展示、补充背景表单和加入待办操作，同时限定只能确认前端请求与反馈流程。")

异常深链仍缺少完整的帧类型及字段校验；超过 200 层后的链接保存、刷新恢复和提示也尚无边界测试。文章加载监听仅依赖文章键与修订号，因此只改变章节参数时不会重新执行定位。参考 [引用目标分派 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L7 "支持知识、原文和固定引用三类展示，以及不可用目标的明确反馈；同时呈现异常帧缺少运行时判别校验的边界。")、[文章章节与知识状态 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L11 "支持文章摘要、当前性提示、分节 Markdown、问题区域和页内目录，并说明加载监听及章节定位的依赖。")、[轨迹循环与长度预算 ↗](../../../packages/ui/src/trail.ts#L37 "说明联合身份循环检测、运行时追加行为及深链持久化的 200 层预算。")、[深层导航测试 ↗](../../../apps/web/src/codewiki/trail.test.ts#L8 "支持跨类型身份区分、十二层链保留及五层钻取与回退场景已经得到测试。") 共享合同已将合法章节键限制为字母开头且仅包含字母、数字、下划线或连字符，所以正常合同输入不存在特殊字符破坏章节选择器的问题。参考 [章节键格式合同 ↗](../../../packages/contracts/src/knowledge.ts#L25 "支持合法章节键只包含不会破坏当前属性选择器的受限字符，排除正常合同输入下的特殊字符风险。")
