# Web 模块专题 3：可追溯知识阅读与双 API 边界

Web 模块将个人知识首页、正文、固定引用、原始材料和疑问入口串成连续阅读流程，并提供隔离的 repo-review 浏览客户端；现有实现仍依赖若干未经运行时验证的接口与交互合同。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="personal-knowledge-flow"></a>
## 个人知识的阅读闭环

个人知识页把首页和活动阅读帧接到同一知识 API，并用共享 Trail 的 push、back、jump、close 组织连续导航。[个人知识页与共享 Trail 装配 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L1 "支持首页、活动阅读帧共用知识 API，并展示共享 Trail 的状态、导航事件和焦点目标接线；同时界定其不能证明共享组件内部行为。") 首页加载文章、材料和运行状态，计算当前解读覆盖数；未覆盖材料由用户显式触发分析，随后每 15 秒刷新。[首页覆盖统计与分析流程 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L9 "支持文章材料加载、覆盖计算、显式分析请求、running 本地更新及十五秒轮询。") 阅读帧再按正文、直接原文和固定引用分派；固定引用可解析到文章章节或带 digest、行范围的材料，不可操作目标会显示原因。[阅读帧与固定引用分派 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L7 "支持帧参数解析、固定引用请求和正文、原文、引用三类展示分支，以及不可操作目标与固定行范围的处理。") 原文界面区分当前与历史版本，关联知识查询失败时降级打开材料。[原始材料与关联导航 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L5 "支持材料版本请求、当前或历史状态展示，以及关联知识查询失败后降级打开原始材料。")

<a id="questions-and-evidence"></a>
## 疑问入口的可确认边界

前端会过滤被替代的疑问，展示接口返回的状态、原因和下一步，并允许用户提交背景或请求加入待办；成功后显示提示并刷新列表。[疑问展示与操作入口 ↗](../../../apps/web/src/knowledge/KnowledgeQuestions.vue#L5 "支持疑问过滤、状态展示、回答和待办请求、共享消息及成功后的列表刷新，并限定结论为前端行为。") 旧稿中“正文不会强行补全不确定事项”的结论超出了该组件证据，现改为仅确认疑问区的展示和请求行为。材料也不能证明服务端必然完成原始材料持久化、待办创建或重新核对。

<a id="review-api-boundary"></a>
## Repo-review 的隔离客户端

repo-review 客户端声明自己面向回环地址上的读取、浏览和同步接口，因此不发送个人工作区令牌；这只是客户端所依赖的安全前提。[Repo-review 客户端边界声明 ↗](../../../apps/web/src/review-api.ts#L1 "支持不发送个人令牌以及回环、无令牌门禁属于客户端声明前提的说明。") 关系 DTO 表达入向关系反转、过期状态和未解析对端。[关系方向与有效状态 ↗](../../../apps/web/src/review-api.ts#L112 "支持入向关系类型反转、过期状态判定及未解析对端为空的语义。") 代码文件、符号和边另有 `displayTitle`、`displayPath`、`actionable`、`reason` 等人类展示与可操作投影；该结论由对应 DTO 行直接支持，替代旧稿误用关系范围引用的表述。[代码 DTO 展示投影 ↗](../../../apps/web/src/review-api.ts#L262 "直接支持代码文件、符号和边的人类可读展示字段、可操作状态、原因及深链字段。") 通用请求成功后仅作 TypeScript 泛型断言，未进行运行时 schema 校验。[Repo-review 请求包装器 ↗](../../../apps/web/src/review-api.ts#L174 "支持统一 API 前缀、JSON 错误处理以及成功响应仅作泛型类型断言的限制。") 全文源码则先探测总行数，再发起第二次范围请求。[两阶段源码全文读取 ↗](../../../apps/web/src/review-api.ts#L498 "支持先用一行请求探测 totalLines，再按完整范围发起第二次请求的流程。")

<a id="runtime-and-limits"></a>
## 运行基础与已知限制

入口依次加载共享设计令牌和应用样式，再挂载 Vue 根组件。[Web 启动与样式导入 ↗](../../../apps/web/src/main.ts#L1 "支持共享设计令牌、应用样式的导入顺序及 Vue 根应用挂载。") 应用样式实际定义了阅读栏、错误与 Toast 反馈，并在 1100px、700px 两级断点调整布局；这替代了旧稿仅引用入口文件却推断具体样式的结论。[应用反馈与响应式样式 ↗](../../../apps/web/src/styles.css#L170 "直接支持错误、Toast 等反馈样式及 1100px、700px 两级响应式布局规则。") TypeScript 采用严格、无输出的跨包源码检查，Vite 在开发期监听回环地址并代理 `/api`。[TypeScript 检查配置 ↗](../../../apps/web/tsconfig.json#L1 "支持严格、无输出的 TypeScript 检查，以及应用、共享 UI 和契约源码的跨包 include 范围。")[Vite 本地开发链路 ↗](../../../apps/web/vite.config.ts#L1 "支持 Vue 插件、回环监听、严格端口以及将浏览器 API 请求代理到本地后端。")

当前限制均有对应材料：个人知识请求假设成功体为 JSON；[个人知识请求响应处理 ↗](../../../apps/web/src/knowledge/api.ts#L6 "支持成功响应无条件调用 response.json，以及失败响应尝试解析 JSON 的合同假设。") 帧 JSON 解析失败只退为空对象，缺少必填字段前置校验；[帧参数解析边界 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L7 "支持帧 id 解析失败时退为空对象，以及 citation 请求仍将参数转换为字符串的现有行为。") 分析成功后只在本地设置 running，疑问操作也没有逐项 pending 状态；[首页覆盖统计与分析流程 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L9 "支持文章材料加载、覆盖计算、显式分析请求、running 本地更新及十五秒轮询。")[疑问展示与操作入口 ↗](../../../apps/web/src/knowledge/KnowledgeQuestions.vue#L5 "支持疑问过滤、状态展示、回答和待办请求、共享消息及成功后的列表刷新，并限定结论为前端行为。") review 响应缺少运行时验证；[Repo-review 请求包装器 ↗](../../../apps/web/src/review-api.ts#L174 "支持统一 API 前缀、JSON 错误处理以及成功响应仅作泛型类型断言的限制。") Trail 材料仅证明装配和事件接线，不能证明深链、滚动恢复、Esc 或实际焦点归还。[个人知识页与共享 Trail 装配 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L1 "支持首页、活动阅读帧共用知识 API，并展示共享 Trail 的状态、导航事件和焦点目标接线；同时界定其不能证明共享组件内部行为。")
