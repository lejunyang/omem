# Web 模块：可追溯知识阅读与本地接口边界

Web 模块把个人知识首页、固定引用、原始材料和仓库评审组织为连续阅读体验；前端负责导航、状态表达与接口适配，但持久化、复核完成度、合同一致性及共享 Trail 的完整行为仍需后端和浏览器验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="knowledge-reading"></a>
## 从知识概览进入固定证据

个人知识页以薄装配层连接知识首页、活动阅读帧和共享 Trail 抽屉：首页与帧内导航进入同一阅读栈，加载结果还能更新当前帧标题。[个人知识页与共享阅读栈装配 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L1 "支持知识首页和活动阅读帧共用 Trail 状态、抽屉事件及标题回传。") 首页展示主题正文、材料覆盖数和文章索引，每 15 秒刷新状态；整理操作提交尚无当前解读的材料修订，但“正在分析”只表示前端请求已接受，不能证明分析、复核或保存完成。[知识首页覆盖统计与分析入口 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L9 "支持文章和材料加载、定时刷新、覆盖计算、待处理修订提交及运行状态展示。")

阅读帧按知识正文、原始材料和固定引用分派。引用解析携带文档、修订与引用键，并以请求代次避免旧响应覆盖新状态；成功后才把文章章节或材料摘要标识、固定行范围交给阅读器。[固定引用解析与目标分派 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L7 "支持引用请求的代次保护、不可操作状态，以及文章和材料目标的不同定位参数。") 原始材料阅读器区分当前与历史版本，可展示引用行、代码、Markdown 和图片；内部链接会规整为材料键，但不保留目标锚点。[原始材料呈现与关联导航 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L5 "支持材料版本状态、引用行、代码与 Markdown 分派、图片展示，以及内部路径导航不保留锚点。")

<a id="questions-and-boundaries"></a>
## 疑问闭环、认证与能力边界

材料不足以确认的事项进入疑问列表，而不是被正文强行补全。前端可按文档过滤并排除已替代项，区分开放、已回答、已转待办和阻塞状态；回答或建待办成功后会刷新列表。现有材料只证明请求与提示行为，不能单独证明原始材料、待办及后续重核验已经持久化完成。[知识疑问的状态与操作 ↗](../../../apps/web/src/knowledge/KnowledgeQuestions.vue#L5 "支持疑问过滤、状态表达、回答和待办请求及成功后的刷新流程，并限定只能确认前端行为。")

个人知识请求从浏览器会话读取令牌，按需加入 JSON 内容类型和 Bearer 认证；失败响应被转换为错误，成功响应则直接按 JSON 类型使用。[个人知识 API 请求封装 ↗](../../../apps/web/src/knowledge/api.ts#L1 "支持会话令牌、JSON 请求头、响应解析和错误传播的个人工作区客户端边界。") 根应用先探测仓库评审健康接口，命中 review 模式便进入评审应用，否则才启动个人工作区。[根应用的双模式启动 ↗](../../../apps/web/src/App.vue#L157 "支持先探测仓库评审模式，未命中时再启动个人工作区的分支流程。") 在个人工作区中，导航明确提供“知识整理”入口，并在对应视图装配 PersonalKnowledge；这替代了此前仅凭启动分支便断言其为独立视图的依据。[个人知识导航项与视图装配 ↗](../../../apps/web/src/App.vue#L428 "支持个人工作区导航包含“知识整理”，并在该视图实际渲染 PersonalKnowledge；用于替代此前范围不足的引用。") 因而两种体验共享 Web 壳，但评审模式的本地无令牌边界不能等同于个人空间认证。

<a id="review-and-runtime"></a>
## 仓库评审接口、代码知识与当前限制

仓库评审客户端被明确限定为 loopback 上的读取、浏览和同步表面，不发送个人工作区的授权头。[仓库评审访问边界 ↗](../../../apps/web/src/review-api.ts#L1 "支持评审接口绑定本地、用于读取浏览同步且不发送个人工作区授权头。") 来源、历史版本、片段、检索、同步和关系查询分别由具体接口暴露；关系 DTO 提供 `missing`、`stale`、关联端是否当前及是否移除，用于解释关系为何不可用。[评审来源、检索与同步接口 ↗](../../../apps/web/src/review-api.ts#L194 "支持来源及历史版本、片段、检索、同步状态、关系和关联汇总等具体访问范围。")[片段关系状态合同 ↗](../../../apps/web/src/review-api.ts#L112 "支持关系方向、missing 与 stale 状态，以及关联端当前性和移除状态用于解释不可用原因。")

代码知识部分在客户端展开快照、文件、符号、边和理解等 DTO，并提供结构图、理解详情及源码切片读取；源码全文采用先探测总行数、再读取完整范围的两步流程。[代码知识 DTO 与读取接口 ↗](../../../apps/web/src/review-api.ts#L257 "支持代码快照、结构图、文件符号、理解详情和源码切片等合同与请求范围，并说明全文读取的两步流程。") 通用请求封装统一 `/api/review` 前缀、JSON 解析和错误转换，但成功数据主要依赖 TypeScript 类型断言，因此 DTO 与服务端、共享合同的一致性仍不能由该文件独立证明。[评审通用请求封装 ↗](../../../apps/web/src/review-api.ts#L174 "支持统一 API 前缀、JSON 解析、错误转换，以及成功响应通过类型断言返回的边界。")

TypeScript 配置启用严格检查和 `noEmit`，并把应用、共享 UI 与契约源码纳入检查范围；这说明静态检查边界，却不证明生产构建或浏览器验收已经通过。[Web TypeScript 检查范围 ↗](../../../apps/web/tsconfig.json#L1 "支持严格模式、禁止直接输出，以及应用、共享 UI 和契约源码共同纳入静态检查范围。") 窄屏全局样式会收紧页面留白并把表单双字段网格改为单列；知识首页自身另将文章索引改为单列。[全局窄屏布局规则 ↗](../../../apps/web/src/styles.css#L212 "支持窄屏下页面留白收紧、表单双字段网格改为单列及反馈区域调整；不再把它误述为文章索引规则。")[知识首页窄屏文章索引 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L49 "支持知识首页在 700px 以下将文章索引由双列改为单列。") 主题对比度、键盘焦点，以及共享 Trail 的深链、滚动恢复、Esc 退层与焦点归还，仍需真实组件和浏览器检查。
