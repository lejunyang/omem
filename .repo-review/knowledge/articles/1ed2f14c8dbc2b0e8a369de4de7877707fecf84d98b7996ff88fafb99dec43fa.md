# Web 模块：可追溯知识阅读与本地接口边界

Web 模块以 Vue 页面串联知识首页、共享证据 Trail、固定引用和原始材料阅读，并分别对接个人知识与 repo-review 接口；已形成可追溯的浏览流程，但运行时合同校验、疑问操作可靠性和共享 Trail 完整行为仍待验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-and-background"></a>
## 职责与设计背景

该模块把知识正文、引用和原始材料组织成连续阅读体验，而非充当事实权威。个人知识页复用共享 Trail，将首页和活动阅读帧的导航压入同一栈，并统一使用 `/api/knowledge`；现有代码只能证明装配与事件接线。[个人知识页与共享证据 Trail ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L1 "支持个人知识页采用共享 Trail 状态，将首页和阅读帧导航接入同一栈，并界定这里只能证明装配接线。") Web 入口先加载共享设计令牌和应用样式，再创建并挂载 Vue 根组件。[Vue 应用与共享样式入口 ↗](../../../apps/web/src/main.ts#L1 "支持根应用挂载，以及共享设计令牌先于应用级样式加载的启动关系。")

<a id="knowledge-flow"></a>
## 知识阅读与反馈流程

首页加载文章、材料覆盖数和分析状态，每 15 秒刷新，并可提交尚无当前解读的材料修订。[知识首页加载与分析流程 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L9 "支持文章、材料和运行状态加载、覆盖统计、待处理修订提交、十五秒轮询及卸载清理。") 索引筛选的是非 `topic:` 知识文章，而非材料列表；页面还提供主题阅读、移动端主题选择和疑问入口。[主题阅读与文章索引 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L32 "支持主题选择、非主题文章筛选、分批展示、窄屏布局及疑问组件装配，并表明文本筛选针对文章而非材料列表。")

阅读帧分派知识正文、直接材料或固定引用。直接 knowledge 帧已经可以从帧 id 携带章节，直接 source 帧也可以携带 digest；固定引用解析结果还能给文章提供修订与章节、给材料提供 digest，其中材料起止行仅见于引用解析后的路径。此结论替代此前“章节、digest 与行范围均须引用解析后取得”的不准确表述。[直接帧与固定引用的目标定位 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L21 "支持直接知识帧携带章节、直接材料帧携带 digest，并支持固定引用解析结果向文章传递章节、向材料传递 digest 与起止行；据此更正此前过度限定的结论。") 原始材料视图按代码或 Markdown 呈现，并依据后端结果标记当前或历史版本；仅当存在关联知识解读时才显示进入知识正文的入口。[原始材料阅读与条件式知识入口 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L26 "支持按后端 current 字段呈现当前或历史版本、分派代码与 Markdown 渲染，并证明仅在存在关联知识时显示知识解读入口。")

<a id="interfaces-and-relations"></a>
## 接口分层与跨模块关系

个人知识客户端复用共享合同：存在会话令牌时附加 Bearer 认证，请求含 body 时补充 JSON 内容类型，成功响应按 JSON 解析。[个人知识 API 与帧合同 ↗](../../../apps/web/src/knowledge/api.ts#L1 "支持共享知识类型、条件式 Bearer 认证、JSON 请求与响应流程，以及可携带修订和章节的知识帧构造。") repo-review 客户端则基于回环、无令牌的设计假设，不发送授权头，但客户端注释不能独立验证实际部署边界。[Repo-review 客户端安全边界说明 ↗](../../../apps/web/src/review-api.ts#L1 "支持客户端的读取、浏览和同步用途，以及回环、无令牌和不发送授权头的设计假设；该注释不能独立验证部署状态。") 其代码 DTO 同时保留内部定位字段与人类可读的标题、路径、引用标签、可操作性和原因等投影。[代码图 DTO 展示投影 ↗](../../../apps/web/src/review-api.ts#L262 "支持代码快照、文件、符号和边同时包含内部定位字段与人类可读展示投影。") 关系合同还表达入向查询时的关系名反转、陈旧状态判定以及未解析对端为空。[关系方向与有效状态合同 ↗](../../../apps/web/src/review-api.ts#L112 "支持入向查询的关系名反转、陈旧状态判定、状态解释字段以及未解析关系对端为空的语义。")

<a id="progress-and-limits"></a>
## 当前进展与限制

现有界面具备主题阅读、文章索引、覆盖统计、显式分析和固定引用解析，也能呈现后端返回的历史版本材料；这不等同于已经提供完整的历史版本列表与选择流程。[主题阅读与文章索引 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L32 "支持主题选择、非主题文章筛选、分批展示、窄屏布局及疑问组件装配，并表明文本筛选针对文章而非材料列表。")[原始材料阅读与条件式知识入口 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L26 "支持按后端 current 字段呈现当前或历史版本、分派代码与 Markdown 渲染，并证明仅在存在关联知识时显示知识解读入口。") 疑问组件可发起回答和转待办请求，但共用反馈消息，未显示逐项 pending 或重复提交防护，成功文案也不能证明服务端已经持久化。[疑问回答与待办交互 ↗](../../../apps/web/src/knowledge/KnowledgeQuestions.vue#L7 "支持疑问筛选、回答和待办请求、成功提示与重新加载，并支持对共享反馈及缺少逐项请求状态的限制判断。")

两类客户端均未展示成功响应的运行时 schema 校验，repo-review 会把解析结果直接断言为泛型类型。[个人知识 API 与帧合同 ↗](../../../apps/web/src/knowledge/api.ts#L1 "支持共享知识类型、条件式 Bearer 认证、JSON 请求与响应流程，以及可携带修订和章节的知识帧构造。")[Repo-review 响应解析边界 ↗](../../../apps/web/src/review-api.ts#L174 "支持成功响应经泛型断言返回、JSON 解析失败回退为空对象，以及当前未展示运行时 schema 校验的判断。") 页面接线同样不足以证明共享 Trail 已实现 URL 深链、滚动恢复、Esc 退层、循环处理及关闭后的实际焦点归还。[个人知识页与共享证据 Trail ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L1 "支持个人知识页采用共享 Trail 状态，将首页和阅读帧导航接入同一栈，并界定这里只能证明装配接线。")
