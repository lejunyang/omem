# 人工维护的代码评审关系种子

定义并加载代码与需求、决策、研究及测试材料之间的人工关系种子；文件缺失视为空集合，格式损坏显式失败，未登记的语义相似命中不得据此成为 confirmed。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="authority"></a>
## 关系来源与权威边界

关系种子由人工维护，用于说明某个代码 Fragment 实现的意图及其需求、决策、研究和测试依据。JSON 中登记的每条 seed 会在同步时转为关系行；该文件同时明确禁止把未登记的词语相似命中据此提升为 `confirmed`。[人工关系种子的权威说明 ↗](../../../apps/server/src/review/associations.ts#L1 "支持人工维护、seed 同步成关系，以及未登记语义相似命中不得成为 confirmed。") 这并不排除系统其他部分产生 candidate、missing 或其他关系。种子文件位于仓库的 `docs/repo-review/associations.json`。

<a id="shape"></a>
## 种子结构与定位方式

每条记录用仓库相对 `codePath` 和符号名锚定代码，并保存意图、需求标签、决策／研究／测试引用、关系状态和证据说明。[关系种子字段定义 ↗](../../../apps/server/src/review/associations.ts#L19 "说明代码定位、意图、四类引用、状态和证据字段的职责。") 文档引用可写为路径或 `path::anchor`；解析器只在第一个双冒号处分割，未带锚点时返回空 anchor，供后续同步定位目标 Fragment。[路径与锚点解析 ↗](../../../apps/server/src/review/associations.ts#L92 "支持 path::anchor 引用格式及无锚点时的解析结果。")

<a id="loading"></a>
## 加载、默认值与失败语义

新检出或测试夹具中若文件不存在，加载结果为空；JSON 解析失败、根对象缺少 associations 数组，或条目缺少字符串形式的 codePath 与 symbol 时会抛错，避免坏文件静默清空关系。[关系种子加载与最小校验 ↗](../../../apps/server/src/review/associations.ts#L51 "支持文件缺失、解析失败、必填字段、默认数组和状态规范化行为。") 可选数组和文本缺失时归为空值；状态仅明确接受 candidate 或 missing，其他值规范为 confirmed。这里属于最小结构校验，并未验证路径、符号和锚点能否在当前代码图解析。[关系种子加载与最小校验 ↗](../../../apps/server/src/review/associations.ts#L51 "支持文件缺失、解析失败、必填字段、默认数组和状态规范化行为。")
