# 人工维护的代码评审关系种子

定义并加载代码与需求、决策、研究及测试材料之间的人工关系种子；已登记种子会在同步时转为关系，未登记的词语相似命中不能据此成为 confirmed。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="authority"></a>
## 关系来源与确认边界

该文件定义人工维护的关联种子，用于说明代码 Fragment 的实现意图以及需求、决策、研究和测试依据。每个 JSON 条目会在同步时转成评审关系；它并非自动语义匹配器，未登记的词语相似命中不得因此成为 `confirmed`。此处没有排除其他机制产生 candidate、missing 或其他关系。种子文件位于 `docs/repo-review/associations.json`。[人工关系种子的权威说明 ↗](../../../apps/server/src/review/associations.ts#L1 "支持种子人工维护、同步转为关系、禁止语义相似命中自动确认为 confirmed，以及固定文件位置。")

<a id="shape"></a>
## 种子结构与定位方式

每条记录以仓库相对 `codePath` 和符号名锚定代码，并保存意图、需求标签、决策／研究／测试引用、关系状态和证据说明。[关系种子字段 ↗](../../../apps/server/src/review/associations.ts#L19 "说明代码定位、意图、四类引用、状态和证据字段的职责。") 文档引用既可只写路径，也可写成 `path::anchor`；解析器仅按首个双冒号拆分，未带锚点时返回空 anchor。该函数只做字符串解析，不证明目标已在当前代码图中定位成功。[路径与锚点解析 ↗](../../../apps/server/src/review/associations.ts#L92 "支持 path::anchor 格式、首个分隔符拆分及无锚点结果。")

<a id="loading"></a>
## 加载、默认值与失败语义

种子文件不存在时返回空列表；JSON 损坏、根对象缺少 associations 数组，或条目缺少字符串形式的 codePath 与 symbol 时会抛错，避免坏文件静默清空关系。[关系种子加载与最小校验 ↗](../../../apps/server/src/review/associations.ts#L51 "支持文件缺失、解析失败、必填字段、默认数组和状态规范化行为。") 可选数组与文本缺失时归为空值；状态只明确保留 candidate 或 missing，其他输入会规范为 confirmed。这里属于最小结构校验，未验证路径、符号、锚点及引用目标是否可解析。[关系种子加载与最小校验 ↗](../../../apps/server/src/review/associations.ts#L51 "支持文件缺失、解析失败、必填字段、默认数组和状态规范化行为。")
