# omem 设计资料导航与状态边界

该页说明产品最新方向、设计资料入口及材料使用边界。它明确区分当前实施状态、设计提案和待实现交接方案，不能单独证明功能已经落地。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="direction"></a>
## 定位与最新方向

omem 被定位为面向 Agent 自治与自学习的长期记忆系统，核心是可深入阅读的版本化证据引用。最新方向以飞书主 Agent 为第一入口、Web 为后台和第二入口；但“90 项测试通过”不等于语义质量和助手体验已经达标，因此只能视为阶段性工程信息。[最新产品方向 ↗](../../../docs/README.md#L3 "支持飞书主入口、Web 第二入口以及测试通过不代表体验达标的判断。")
