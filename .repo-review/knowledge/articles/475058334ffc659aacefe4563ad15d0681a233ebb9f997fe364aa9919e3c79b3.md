# 知识服务 HTTP 路由与生成编排

该模块把知识仓库、固定版本引用解析、材料阅读、问答与异步知识整理统一暴露为 Fastify API，并在入口处校验材料版本、Agent 配置和并发状态。它也为代码材料生成确定性的相对 import 导航，但不据此推断跨文件调用。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-reading"></a>
## 知识读取与可追溯引用

`registerKnowledgeRoutes` 是知识子系统的 HTTP 入口：复用或创建仓库，并维护当前整理任务与最近结果。文章列表返回生成模型、复核模型、修订和问题数；读取单篇文章时，会逐条解析引用，而不是直接把模型给出的目标视为可访问。[路由注册与文章读取 ↗](../../../apps/server/src/knowledge/api.ts#L13 "支持该模块承担知识 HTTP 入口、维护运行状态并在文章详情中解析引用的说明。")

引用解析必须先匹配文章保存的依赖摘要：缺少固定版本依据时标记为不可操作；文章引用按指定摘要取知识修订，材料引用按摘要取原始材料，并同时返回 `current` 状态。这样既允许阅读历史版本，也会明确暴露目标已失效或不再最新的情况。[固定版本引用解析 ↗](../../../apps/server/src/knowledge/api.ts#L20 "支持引用依赖摘要、不可操作原因以及文章和材料历史版本解析规则。")

<a id="material-and-interaction"></a>
## 材料阅读、问答与检索

材料接口返回固定摘要、修订号、全文、图片和关联知识。对 TypeScript、JavaScript、Vue 等代码文件，它调用离线解析器提取 import，仅解析相对路径并按有限扩展名候选匹配已有材料；生成的是“确定性模块依赖”导航，不能据此确认跨文件调用。[代码材料依赖导航 ↗](../../../apps/server/src/knowledge/api.ts#L46 "支持材料接口通过相对 import 和有限候选路径生成模块导航，并明确不把依赖等同于调用。") 解析器合同也说明其没有跨文件类型解析，调用只到名称级候选。[离线单文件解析器边界 ↗](../../../apps/server/src/code/parse.ts#L1 "解释 parseFile 所依赖解析能力的单文件、无跨文件类型解析和名称级候选限制。")

图片接口会先确认修订正文中存在对应图片记录，再读取资产；只有 PNG、JPEG、WebP 三种 MIME 类型且资产字节确实存在时才返回，否则统一报图片不可用。[图片资产读取与类型限制 ↗](../../../apps/server/src/knowledge/api.ts#L69 "直接支持图片接口仅返回已登记且实际存在的 PNG、JPEG 或 WebP 资产这一论断。") 问题回答限制为去空白后 1–20000 字，成功后保存为修订并触发回调；问题也可转成任务。搜索只是对已生成文章章节做大小写不敏感的空白分词子串匹配，最多返回 50 条派生摘要，不是语义检索，也不直接检索原始材料。[问答、任务与章节搜索接口 ↗](../../../apps/server/src/knowledge/api.ts#L75 "支持回答长度校验、回答保存回调、任务创建以及简单子串检索的行为与上限。")

<a id="generation-lifecycle"></a>
## 异步整理流程与边界

整理入口要求已配置 Agent、当前没有运行中的管线，并要求提交 1–500 个材料修订号；服务端重新从仓库匹配这些固定版本，数量不一致即认为材料已更新或不可用。通过校验后，它把角色包注册表、运行时网关、请求仓库、Agent profile、预算和并发数 2 组装成 `KnowledgePipeline`，后台启动分析并立即返回 202。结果或错误写入 `lastRun`，结束后清空运行标记。[知识整理启动与校验 ↗](../../../apps/server/src/knowledge/api.ts#L87 "支持 Agent 配置、单实例运行、固定修订选择、管线组装、并发数和异步返回流程。")

该并发保护只由模块内的 `running` 变量提供，材料没有展示跨进程互斥。关闭 Fastify 时会等待当前管线停止，但这里未说明停止时的回滚、已发布结果处理或任务恢复语义。[服务关闭时停止管线 ↗](../../../apps/server/src/knowledge/api.ts#L93 "支持关闭阶段等待当前整理任务停止，同时界定本文件未展开具体停止与恢复语义。") 运行时请求仓库被注入网关；其合同显示可记录 permission 或 elicitation 请求及其状态，不过本文件没有证明管线何时触发这些请求。[运行时请求记录合同 ↗](../../../apps/server/src/agent-runtime/requests.ts#L7 "解释注入网关的 RuntimeRequestRepository 所管理的请求种类与状态；不据此推断实际触发时机。")
