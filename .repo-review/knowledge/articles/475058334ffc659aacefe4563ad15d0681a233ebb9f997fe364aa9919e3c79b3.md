# 知识阅读、问答与分析任务 API

该模块注册知识文章、固定材料、引用、问题、搜索和分析接口，以固定依赖解析引用，并通过统一 KnowledgePipeline 异步执行显式选择的材料分析。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="articles_citations"></a>
## 文章元数据与固定引用

路由层复用或创建 `KnowledgeRepository`，以精简元数据返回标题、摘要、类别、当前版本、生成与复核模型及问题数。文章详情会逐条解析引用依赖：缺少固定版本依据、目标文章不可用或原始材料版本不可用时，引用仍返回但标为不可操作并给出原因；可解析目标则铺开标题、版本或行号信息。[引用固定依赖解析 ↗](../../../apps/server/src/knowledge/api.ts#L18 "支持引用按固定依赖解析，并为缺失依据或不可用目标返回不可操作状态和人读原因。")

文章列表在读取前刷新仓库，并同时返回当前材料清单、分析运行状态和最近结果；文章不存在时明确返回 404。[文章列表与详情接口 ↗](../../../apps/server/src/knowledge/api.ts#L34 "支持仓库刷新、文章和材料元数据返回、运行状态展示以及文章缺失时的 404。")

<a id="materials_questions"></a>
## 材料阅读、问题回答与搜索

材料接口按可选 digest 解析固定版本，返回正文、行数、图片、关联知识及当前性。对代码材料还会解析相对 import，匹配已知材料路径后生成确定性的模块依赖链接；这只说明 import 关系，不推断实际调用行为。图片接口仅允许 PNG、JPEG 和 WebP，并在资产或 MIME 不合法时返回 404。[固定材料与图片读取 ↗](../../../apps/server/src/knowledge/api.ts#L46 "支持材料固定版本读取、相对 import 链接、代码语言识别、图片元数据和 MIME 白名单。")

问题回答要求 1–20000 字的非空文本，保存为 revision 后触发回调；问题也可显式转为任务。搜索只是对现有文章章节做大小写无关的词项包含匹配，最多返回 50 个派生摘要，因此不是语义检索，也不直接返回新的事实证据。[问题回答、任务与章节搜索 ↗](../../../apps/server/src/knowledge/api.ts#L75 "支持回答长度校验、回答保存回调、问题转任务及简单章节词项搜索的范围。")

<a id="analysis_lifecycle"></a>
## 显式分析与运行生命周期

分析必须配置 Agent、当前没有其他 pipeline 运行，且请求包含 1–500 个仍可解析的固定 revision；任何材料已更新或不可用都会拒绝整次请求。通过校验后，接口使用 `RoleRuntimeGateway` 和 `KnowledgePipeline`，以并发度 2 异步分析所选材料，并立即返回 202。[分析校验与流水线生命周期 ↗](../../../apps/server/src/knowledge/api.ts#L87 "支持 Agent 和并发状态校验、固定 revision 完整性检查、统一 pipeline 启动、后台结果记录及关闭时停止。")

后台成功或失败都会记录为最近运行结果，并在结束时清空运行标记；服务关闭前会等待当前 pipeline 停止。该进程内单实例锁避免同一路由对象并发运行两条知识流水线，但材料没有展示跨进程互斥。[分析校验与流水线生命周期 ↗](../../../apps/server/src/knowledge/api.ts#L87 "支持 Agent 和并发状态校验、固定 revision 完整性检查、统一 pipeline 启动、后台结果记录及关闭时停止。")
