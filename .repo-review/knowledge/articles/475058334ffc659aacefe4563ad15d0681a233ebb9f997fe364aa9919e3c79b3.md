# 知识服务 HTTP 路由与生成入口

该模块统一暴露知识文章与固定引用读取、原始材料和图片访问、问题回答与任务化、轻量文本搜索及异步知识整理接口。它用依赖摘要约束引用版本，以单进程运行标记避免重复整理；代码材料的相对 import 链接仅代表确定性模块依赖，不能当作跨文件调用事实。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="responsibility"></a>
## 文章读取与固定引用

`registerKnowledgeRoutes` 以可注入的知识仓库为核心，维护当前整理任务和最近一次结果。文章列表会先刷新仓库，并返回材料清单、运行状态及精简元数据；文章详情可按修订读取，不存在时返回 404。[文章列表与详情路由 ↗](../../../apps/server/src/knowledge/api.ts#L13 "支持文章列表刷新、精简元数据、按修订读取以及不存在时返回 404 的说明。")

引用解析要求文章依赖中存在与引用目标匹配的固定摘要：文章目标按固定修订解析，材料目标按固定 digest 解析。依赖缺失或目标版本不可用时，引用不会被静默删除，而是保留并标记为不可操作，同时给出可读原因；因此展示层能区分“曾有引用”与“当前仍可定位”。[固定版本引用解析 ↗](../../../apps/server/src/knowledge/api.ts#L20 "支持引用必须匹配文章依赖摘要，以及目标不可用时保留引用并返回不可操作原因的论断。")

<a id="materials"></a>
## 材料阅读、代码关联与图片边界

材料接口按 key 和可选 digest 获取固定版本，返回正文、行数、当前性、图片、关联知识及代码语言。对 TS、JS、Vue 等文件，它调用单文件解析器抽取 import，只处理相对路径，并尝试常见扩展名和 `index.ts` 定位已有材料；生成的链接明确表示模块依赖，调用行为仍须由知识正文佐证。[代码材料的相对 import 链接 ↗](../../../apps/server/src/knowledge/api.ts#L46 "支持材料端点解析相对 import、匹配候选路径并将结果表述为确定性模块依赖。") 解析器不构建跨文件 Program，也不做类型解析，名称级调用仅是候选，所以这些链接不能推导真实跨文件调用链。[单文件代码解析器边界 ↗](../../../apps/server/src/code/parse.ts#L1 "说明解析器不做跨文件类型解析，名称级调用仅标记为候选，限定了材料链接可表达的语义。")

图片端点同时检查修订记录、资产字节和 MIME，仅允许 PNG、JPEG、WebP；这一范围与捕获合同中的图片类型一致。[图片资产读取限制 ↗](../../../apps/server/src/knowledge/api.ts#L69 "支持图片端点要求数据库记录与资产字节同时存在，并仅接受三种 MIME 类型。") [捕获合同的图片类型 ↗](../../../packages/contracts/src/index.ts#L27 "说明通用捕获合同同样只接受 PNG、JPEG 和 WebP，与图片读取端点的范围一致。")

<a id="interaction"></a>
## 问题处理与文本搜索

问题可直接列出、回答或转成任务。回答校验的准确语义是：请求值必须为字符串，原始字符串长度不得超过 20000，且去除首尾空白后必须非空；通过后保存的是去除首尾空白的文本，并触发可选回调。原先“去空白后 1–20000 字”的表述已被替代，因为长度上限实际在裁剪前判断。[回答校验与保存顺序 ↗](../../../apps/server/src/knowledge/api.ts#L75 "直接支持先检查原始字符串长度和裁剪后非空、再保存裁剪文本的准确语义，并替代旧结论。")

搜索把查询裁剪、转小写并按空白分词，只要任一词出现在章节标题或正文中即返回；结果最多 50 条、摘要截取前 600 字，并标记为派生内容。[章节包含搜索 ↗](../../../apps/server/src/knowledge/api.ts#L82 "支持查询分词、大小写无关包含匹配、50 条上限、600 字截取及派生结果标记。") 这是轻量包含匹配，不足以证明存在相关性排序、向量召回或原始 Fragment 返回。

<a id="generation"></a>
## 异步整理与生命周期限制

整理入口要求已配置 Agent、当前没有其他整理任务，并接收 1–500 个固定材料版本；若任一版本已更新或不可用，请求会在启动前被拒绝。通过校验后，路由组装角色注册表、运行网关、运行时请求仓库与 `KnowledgePipeline`，以并发度 2 异步执行并立即返回 202；完成或失败结果写入 `lastRun`，最终释放运行标记，服务关闭前则停止当前 Pipeline。[知识整理启动与并发保护 ↗](../../../apps/server/src/knowledge/api.ts#L87 "支持 Agent 配置、并发冲突、固定材料版本校验、Pipeline 组装、异步状态记录和关闭停止流程。")

可选生成预算会传给 Pipeline；其默认值、整数范围校验和基于 UTF-8 字节的估算位于独立预算模块，而非本路由。[生成预算估算与校验 ↗](../../../apps/server/src/agent-runtime/budget.ts#L1 "说明预算的字段、默认来源、有效整数范围，以及 UTF-8 字节估算和预留余量属于独立模块。") 当前材料只显示启动与回收边界，不能据此确认 Pipeline 内部各阶段的事务顺序或失败时是否保留旧知识。
