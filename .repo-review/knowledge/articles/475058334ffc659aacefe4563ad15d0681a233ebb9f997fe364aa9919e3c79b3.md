# 知识阅读、引用追溯与生成任务 API

该模块以 Fastify 路由统一提供知识文章、固定版本引用、原始材料、图片、问题处理、文本搜索与异步知识整理。引用按生成时记录的依赖版本解析，代码材料可补充确定性的 import 导航。当前材料仅能确认整理状态保存在路由局部变量中，无法确认进程重启后的任务恢复能力。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="reading"></a>
## 面向阅读场景的统一入口

模块提供知识列表、文章详情和单条引用查询。列表返回文章元数据、材料目录、运行标记及最近结果；详情支持指定 revision，文章或引用不存在时分别返回 404。[知识文章与单条引用路由 ↗](../../../apps/server/src/knowledge/api.ts#L18 "支持知识列表、文章详情、版本选择、元数据字段、单条引用查询以及目标不存在时的 404 行为。")

引用不是直接跳转到目标的当前版本，而是先查找文章生成时记录的依赖 digest。依赖缺失，或固定的文章、材料版本已不可用时，接口仍保留引用描述，但将其标为不可操作并给出人读原因；解析成功时则补充目标标题、版本、材料行范围等信息。[固定版本引用解析 ↗](../../../apps/server/src/knowledge/api.ts#L20 "支持引用通过依赖 digest 解析，并在固定文章或材料版本不可用时返回不可操作状态和人读原因。")

<a id="materials"></a>
## 原始材料导航与输入边界

原始材料接口返回路径、语言、digest、revision、正文、行数、当前状态、图片、关联知识和模块链接。对于代码文件，它解析相对 import，经路径规范化和有限扩展名候选匹配已收录材料，形成确定性的模块依赖导航。[原始材料读取与模块导航 ↗](../../../apps/server/src/knowledge/api.ts#L46 "支持材料响应字段，以及相对 import 经路径规范化和扩展名候选匹配后形成模块链接的流程。") 这种导航不能证明跨文件调用：底层解析器按单文件工作，不做跨文件类型解析，名称级调用也只标为候选。[单文件代码解析边界 ↗](../../../apps/server/src/code/parse.ts#L1 "说明解析器不执行跨文件类型解析，名称级调用仅为候选，限定模块导航能够证明的范围。")

图片读取同时要求数据库记录、资产字节和受支持的 PNG、JPEG 或 WebP MIME；问题回答必须是非空且不超过 20000 字符的字符串，保存前会去除首尾空白。[图片与问题回答校验 ↗](../../../apps/server/src/knowledge/api.ts#L69 "支持图片资产、MIME 校验，以及回答非空、长度上限和保存前裁剪的处理。")

<a id="generation"></a>
## 知识整理与轻量检索流程

整理入口要求已有 Agent 配置、没有正在执行的流水线，并提交 1 至 500 个仍可用的固定 revision。校验通过后，服务端组装共享角色运行时，以并发度 2 异步分析并立即返回 202；结果或异常写入最近运行状态。[异步知识整理入口 ↗](../../../apps/server/src/knowledge/api.ts#L87 "支持 Agent 配置检查、运行互斥、固定 revision 校验、运行时组装、并发度和异步结果记录的说明。") 服务关闭前会停止当前流水线。[流水线完成与关闭处理 ↗](../../../apps/server/src/knowledge/api.ts#L93 "支持异步结果或错误写入最近状态、运行标记清理，以及服务关闭前停止当前流水线的说明。")

搜索仅对章节标题和正文做空白分词、大小写无关的包含匹配，最多返回 50 条并标记为派生结果，因此不能等同于语义或向量检索。[章节文本搜索 ↗](../../../apps/server/src/knowledge/api.ts#L82 "支持搜索的空白分词、大小写无关包含匹配、派生标记及最多 50 条结果的说明。") 当前路由明确把 `running` 与 `lastRun` 保存在局部变量中。[路由局部运行状态 ↗](../../../apps/server/src/knowledge/api.ts#L13 "支持 running 和 lastRun 在路由注册函数内声明并用于响应的受限结论。") 运行时权限或信息请求虽可写入数据库，仍不足以证明知识流水线的执行状态也会持久化或在重启后恢复。[运行时请求数据库记录 ↗](../../../apps/server/src/agent-runtime/requests.ts#L37 "证明权限或信息请求可写入数据库，同时界定该事实不能单独证明知识流水线状态持久化。")
