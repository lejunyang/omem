# B2-08 受控学习与生产 Host 验证

记录持久学习流水线、生产飞书 Host、通知聚合和质量数据基础设施的实现与验证，并区分确定性协议测试、真实 ACP、真实 Host 及尚未完成的质量发布门。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="pipeline"></a>
## 受控学习流水线

启用 learning 后，Fastify 生命周期启动单消费者持久 worker：capture 创建 extraction job，extractor 产出结构化提案和公开 trace；若有提案，再由全新 Agent session 验证固定 evidence 与规范化 digest。只有 assessment 完整覆盖且 digest 一致才进入 MemoryService，Agent 本身没有任务、记忆或通知写权限。流水线还处理稳定 ID、receipt 去重、stale 预拒绝和停机后的 transient retry。[B2-08 学习流水线实现范围 ↗](../../../docs/implementation/batch2/b2-08-learning-verification.md#L5 "解释 extractor、独立 verifier、写权限隔离、去重、stale 防护和停机恢复流程。")

<a id="host-and-tests"></a>
## 生产 Host、聚合与确定性验证

启用 Lark 后，生产服务装配注册、公开能力探测、现有应用 provider、WebSocket supervisor、delivery 与 card worker，但外部连接默认关闭并要求密钥。数据库迁移加入即时、短窗、定时聚合字段和本地质量标注结构。协议 fixture 在真实子进程、SQLite、lease 与 Fastify 生命周期上验证崩溃续跑、消息采集、聚合边界和标注卡防伪；这些结果证明编排及持久语义，不代表任意外部 Agent 均可用。[B2-08 Host 与确定性验证 ↗](../../../docs/implementation/batch2/b2-08-learning-verification.md#L14 "支持生产飞书组件、通知聚合、质量数据结构、持久编排测试及 fixture 证据边界。")

<a id="live-and-gates"></a>
## 真实验证与未完成发布门

真实 ACP smoke 使用 gpt-5.4、medium effort，extractor、verifier、proposal 应用、任务和通知均产生成功结果。[B2-08 真实 ACP 结果 ↗](../../../docs/implementation/batch2/b2-08-learning-verification.md#L44 "直接支持真实 ACP smoke 的模型、effort、任务状态和产物数量。") 生产 Lark Host 对既有隔离应用执行只读 capability probe 与启停，回读授权范围和 bot identity，并成功建立 WebSocket；因为待发送队列为空，没有发送新消息或卡片。[B2-08 真实飞书 Host 结果 ↗](../../../docs/implementation/batch2/b2-08-learning-verification.md#L56 "直接支持生产 Host 的只读能力探测、WebSocket 连接结果和未发送新消息的边界。") 全量检查通过 90 项测试和 12/12 组浏览器检查，但 dev 草稿人工确认、120 条跨来源 holdout 和真实等待窗口后的摘要投递仍未完成，因此不能声明质量发布门通过。[B2-08 回归结果与剩余发布门 ↗](../../../docs/implementation/batch2/b2-08-learning-verification.md#L82 "支持全量回归结果，以及质量数据集、真实摘要投递和分布式部署仍未完成的结论。")
