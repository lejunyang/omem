# 基于固定证据的问答面板

ChatPane.vue 提供围绕当前记忆片段或引用路径发起 Agent 问答的界面：提交运行参数，轮询异步结果，聚合文本事件，并处理取消、错误、自动滚动与证据回查。它明确区分“材料可回查”和“回答主张已核验”，后者目前尚未实现。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-input"></a>
## 作用与输入边界

该组件承接“从正在阅读的记忆证据继续提问”的交互。父组件提供固定片段、Agent profile、模型、effort 和可选的引用路径片段 ID；组件向外发出打开证据及回答已保存事件。[组件输入与对外事件 ↗](../../../apps/web/src/ChatPane.vue#L5 "支持父组件传入焦点片段、运行配置和路径片段，并由组件发出打开证据及保存完成事件的说明。")

界面展示当前固定证据，并允许把回答范围切换为当前片段或当前引用路径。没有焦点片段时，文本框和发送按钮都会禁用；问题为空时也不能发送，从而避免启动缺少明确依据或有效问题的运行。[固定证据、回答范围与禁用条件 ↗](../../../apps/web/src/ChatPane.vue#L87 "支持界面展示固定证据、选择回答范围，以及无焦点或问题为空时禁用输入和发送的论断。")

<a id="run-lifecycle"></a>
## 异步运行流程

提交时会拒绝空问题、缺少焦点或已有运行中的请求，再将问题、profile、焦点 ID、可选模型与 effort，以及按范围选出的 `contextIds` 发送到 `/runs`。创建成功后初始化空事件列表，并每 450 毫秒读取 `/runs/{id}`；运行离开 `running` 后解除忙碌状态，`done` 时通知父组件刷新已保存内容。[运行创建与轮询状态机 ↗](../../../apps/web/src/ChatPane.vue#L33 "支持提交参数、初始化运行、按 450 毫秒轮询状态以及完成后通知父组件的流程。")

回答由全部 `text` 事件按顺序拼接；事件数变化后等待 DOM 更新并滚动到底部。取消按钮只调用 cancel 端点。卸载时组件会设置终止标志并清除定时器，且成功返回的轮询结果会先检查该标志，因此不会在卸载后更新 `run`；但轮询失败的 `catch` 路径没有同样检查，迟到失败仍可能写入错误和忙碌状态。[事件聚合、取消与卸载处理 ↗](../../../apps/web/src/ChatPane.vue#L19 "支持文本事件聚合、自动滚动、取消请求和卸载清理，并揭示成功响应与失败路径对 disposed 检查不一致的限制。")

<a id="limits-and-relations"></a>
## 限制及模块关系

组件依赖共享的 `Run` 与 `Fragment` 类型；其中 `Run` 只规定运行状态、事件和可选回答 ID，服务端保存、取消状态转换及事件生成不在本文件中。[前端运行数据合同 ↗](../../../apps/web/src/api.ts#L58 "说明 ChatPane 依赖的 Run 类型只包含状态、事件和可选回答标识，服务端运行细节不属于该组件。") 证据引用被点击时也只是把焦点片段 ID 交给父组件处理。

完成态提供“查看本次提供的依据”，同时明确提示系统尚未自动核验回答中每个主张的支持度。因此，这里实现的是固定输入证据的回查入口，并不等同于逐主张引用或语义验证。[证据回查与核验限制 ↗](../../../apps/web/src/ChatPane.vue#L115 "支持完成后可打开本次固定依据，同时逐主张支持度尚未自动核验这一明确限制。") 现有材料也无法确定取消竞态、路径上下文预算及网络异常后的完整服务端行为。
