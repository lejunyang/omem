# 基于固定证据的 Agent 问答面板

ChatPane.vue 围绕当前固定片段启动异步 Agent run，通过轮询展示文本及错误事件，支持取消、模型与 effort 透传，并在完成后通知父组件刷新持久化结果。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="request-scope"></a>
## 提问前提与上下文范围

面板要求存在 focus、问题非空且当前不忙，因而每次运行至少绑定一个固定片段。请求 `/runs` 时提交问题、profileId 和 focusId；model、effort 仅在非空时透传。范围可选“当前片段”或“当前引用路径”，后者把父组件传入的 pathIds 放入 contextIds；组件本身不解析路径，也不验证这些 id 的含义。[运行创建参数与上下文选择 ↗](../../../apps/web/src/ChatPane.vue#L49 "支持提问门槛、固定焦点以及可选路径上下文的请求构造。")

<a id="run-lifecycle"></a>
## 运行生命周期

服务端返回 running run 后，组件先建立空事件列表，再约每 450 毫秒读取 `/runs/{id}`。运行中继续调度，结束时解除 busy；只有 done 状态触发 `saved`，交由父组件刷新持久结果。轮询失败会显示错误并停止忙碌状态，卸载则设置 disposed 并清除定时器，防止离开页面后更新组件。取消操作只请求服务端，最终状态仍依赖后续轮询返回。[运行轮询、完成通知与取消 ↗](../../../apps/web/src/ChatPane.vue#L26 "支持异步 run 的轮询状态机、saved 事件和卸载清理边界。")

<a id="rendering-and-limits"></a>
## 输出呈现与可信边界

回答由所有 text 事件按顺序直接拼接，error 与 permission 事件另行显示；事件增加后自动滚动到底部。[文本事件拼接与自动滚动 ↗](../../../apps/web/src/ChatPane.vue#L19 "支持回答的客户端聚合规则及事件变化后的滚动行为。") 完成时可以重新打开本次 focus 证据，但界面明确提示系统尚未自动核验回答中每个主张的支持度。因此引用按钮证明的是“运行获得了哪些材料”，并不证明生成文本逐句成立。该组件也未呈现多轮消息历史、结构化引用映射或客户端超时策略。[完成状态、依据入口与核验提示 ↗](../../../apps/web/src/ChatPane.vue#L87 "支持界面区分运行状态，并明确回答主张尚未被自动逐项核验。")
