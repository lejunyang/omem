# Web 前端的可追溯阅读与事项跟进

Web 前端既提供事项等待、提醒与取消操作，也把仓库知识、模块图、源码、符号和固定证据组织成连续阅读路径；共享合同、证据轨迹和人类可读标签共同约束交互边界。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="user_scenarios"></a>
## 面向用户的两类场景

Web 模块承接事项跟进与仓库阅读两类场景。开放或等待中的事项可以记录等待对象、设置下次检查时间或取消；跟进时间不改变截止时间，也不会自动联系对方。三种命令都会携带当前版本和随机请求标识；只有非取消操作携带跟进对象，其中检查时间、延后时间和时间表达式可以为空，取消操作直接发送空跟进对象。参考 [事项跟进命令载荷 ↗](../../../apps/web/src/TaskFollowUpControls.vue#L14 "支持三种操作都发送版本和请求标识，并证明取消操作发送空跟进对象、非取消操作才携带可空时间字段。") [事项命令共享合同 ↗](../../../packages/contracts/src/task-flow.ts#L17 "支持操作、期望版本和请求标识为命令字段，并说明跟进对象可空且可选。")

Code Wiki 则从知识首页或代码结构进入模块、文件、符号与不可变原文。页面消费评审接口，负责快照概览、模块图、详情视图、证据轨迹和 Hash 深链，而不在浏览器中重新解析仓库。参考 [代码知识页面职责 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L2 "说明页面负责仓库概览、模块图、详情、证据轨迹和深链，并从评审接口获取数据。")

<a id="reading_flow"></a>
## 从模块概览走到固定证据

```mermaid
flowchart LR
  A[知识首页或代码结构] --> B[模块说明]
  B --> C[文件源码与符号]
  C --> D[关系目标或符号范围]
  D --> E[不可变原始片段]
```
仓库路径由共享合同映射为稳定模块，聚合逻辑再以未删除文件、符号及可定位的跨模块导入构造模块节点与依赖边。参考 [共享模块路径规则 ↗](../../../packages/contracts/src/code-modules.ts#L1 "支持仓库路径归类规则由 contracts 包统一提供，并说明主要路径的模块映射。") [模块图聚合流程 ↗](../../../apps/web/src/codewiki/modules.ts#L60 "支持过滤已删除文件、调用共享路径规则、统计模块文件与符号并聚合跨模块导入。")

模块页先查询已保存文章；存在文章时交给通用阅读器，没有文章时显示加载、空状态或结构化的职责、边界、流程、风险与未决问题，之后仍提供文件入口。参考 [模块文章元数据查询 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L31 "支持模块变化时查询对应知识文章元数据，并证明查询异常会被统一忽略。") [模块知识与回退内容 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L73 "支持已保存文章、加载提示、无说明空态、结构化说明以及文件入口的呈现顺序。") 文件页以完整源码为主请求，符号、关系和理解数据可以分别降级，因此辅助信息故障不必阻断源码阅读。参考 [文件阅读加载策略 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L56 "支持完整源码为主请求，而符号、关系和理解请求失败时分别降级的行为。") 同文件符号关系进入符号范围帧，跨文件目标进入文件帧，外部或缺失目标不可导航，这些基本分支已有测试。参考 [关系下探测试 ↗](../../../apps/web/src/codewiki/edges.test.ts#L45 "支持同文件符号、跨文件目标和外部依赖对应不同下探结果的已测合同。")

<a id="traceability"></a>
## 统一轨迹、引用与深链

文件、符号、片段和知识引用都进入同一证据轨迹抽屉，由容器统一处理返回、跳转、循环提示和焦点归还。参考 [统一证据轨迹 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L371 "支持不同阅读帧复用同一抽屉，并统一承接关闭、返回、跳转和循环提示事件。") 知识正文只有在引用被标记为可操作时才发出导航事件。参考 [可操作引用导航 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L20 "支持知识正文只为可操作引用发出导航事件。")

Hash 路由测试覆盖文件行号、损坏路径回退和五层轨迹往返。参考 [Hash 深链测试 ↗](../../../apps/web/src/codewiki/hashroute.test.ts#L14 "支持文件行号、损坏路径回退以及多层轨迹写入和解析往返已有单元测试。") 共享路由器在解析和写出时都按 `MAX_TRAIL` 限制 URL 中的轨迹。参考 [Hash 恢复长度限制 ↗](../../../packages/ui/src/OmHashRoute.ts#L33 "支持共享路由器在解析恢复轨迹时按 MAX_TRAIL 截取帧栈。") [Hash 写出长度限制 ↗](../../../packages/ui/src/OmHashRoute.ts#L67 "支持共享路由器在写出轨迹时按 MAX_TRAIL 截取帧栈。") 但 Code Wiki 自有的 `syncHash` 会直接序列化当前完整轨迹，并未调用共享写出函数，因此页面生成深链时尚未统一应用该限制。参考 [页面自有深链写出 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L219 "证明 Code Wiki 的同步逻辑直接序列化当前轨迹，没有调用共享 writeHash 或显式截取。")

<a id="contracts_and_limits"></a>
## 数据边界与当前限制

个人工作区客户端从会话存储读取令牌，为 `/api` 请求添加 Bearer 认证；仓库评审客户端面向本机 `/api/review`，不发送该授权头。参考 [个人 API 会话认证 ↗](../../../apps/web/src/api.ts#L242 "支持个人工作区请求从会话存储读取令牌并添加 Bearer 授权头。") [仓库评审客户端边界 ↗](../../../apps/web/src/review-api.ts#L1 "支持仓库评审客户端面向本机读取、浏览与同步接口且不发送个人授权头。") 展示层优先使用 DTO 的标题和路径字段，再退回可读名称，测试明确防止文件或符号内部标识成为可见文本。参考 [人类可读标签测试 ↗](../../../apps/web/src/codewiki/labels.test.ts#L10 "支持展示字段优先、可读名称回退及禁止文件和符号内部标识泄漏的测试合同。")

恢复出的模块、文件或符号若已不属于当前代码图，轨迹帧仍可能存在，但对应正文组件不会渲染。参考 [失效轨迹渲染边界 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L383 "支持模块、文件和符号轨迹帧只有在当前代码图存在对应目标时才渲染正文组件。") 模块知识元数据查询会忽略所有异常，文件辅助请求也会把失败降级为空结果，因此界面尚未完全区分“没有内容”和“接口失败”。参考 [模块文章元数据查询 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L31 "支持模块变化时查询对应知识文章元数据，并证明查询异常会被统一忽略。") [文件阅读加载策略 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L56 "支持完整源码为主请求，而符号、关系和理解请求失败时分别降级的行为。")
