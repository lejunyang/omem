# Web 模块专题 2：Code Wiki 的可追溯阅读与下钻

Web 端把仓库快照、模块依赖、源码符号、知识正文和固定评审片段组织为统一阅读链。当前已具备确定性聚合、关系下钻、Hash 恢复和基础纯函数测试；超长深链持久化、异步竞态及辅助请求错误语义仍待完善。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="overview-flow"></a>
## 从仓库结构到模块阅读

Code Wiki 先并行读取当前快照、代码图和模块理解列表；理解列表失败会独立降级为空，而快照或代码图失败进入统一错误状态。[Code Wiki 初始化加载 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L120 "支持快照、代码图和理解列表并行读取、理解列表独立降级以及统一错误状态。") 页面随后把文件、符号与边聚合成模块节点、依赖边及下钻所需映射。[模块图聚合与索引 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L57 "支持代码图聚合为模块节点和边，并建立文件及符号映射。") 模块桶由 contracts 包的共享路径规则决定，避免页面自行推测仓库边界。[共享仓库路径分组 ↗](../../../packages/contracts/src/code-modules.ts#L1 "支持 Web、UI、contracts、服务端子目录等模块桶由共享合同统一确定。")

模块页优先显示已保存知识，否则回退到加载态、结构化理解或明确空态。[模块说明展示优先级 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L68 "支持已保存知识、加载状态、空态和结构化说明之间的主体分支。") 文件按语言计算分组，并在说明区域之后持续提供下钻入口。[模块文件语言分组 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L34 "支持模块文件按语言归组并按组中文件数量排序。")[按语言分组的文件入口 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L155 "支持模块页在说明区域之后按语言渲染文件列表并发出文件下钻。") 完整文章由通用阅读器按章节渲染，并在正文后接入当前文章的待核对问题。[知识正文与问题入口 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L26 "支持知识文章按章节渲染 Markdown，并在正文后挂载当前文章的问题组件。")

<a id="evidence-trail"></a>
## 源码、关系与统一证据 Trail

文件帧以完整源码为主请求，符号、关系和理解可分别失败并降级。[文件源码与辅助数据加载 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L56 "支持完整源码作为主路径，并证明符号、边和理解请求可独立降级。") 符号大纲生成固定范围并发出符号下钻；关系边由共享解析器转成同文件符号帧、跨文件文件帧或不可导航目标。[符号范围与下钻 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L90 "支持符号大纲范围生成、行号命中和符号帧下钻事件。")[关系边下钻解析 ↗](../../../apps/web/src/codewiki/modules.ts#L184 "支持同文件符号、跨文件目标以及外部或缺失目标的导航分支。") 纯函数测试覆盖同文件符号、跨文件符号和外部目标。[边下钻行为测试 ↗](../../../apps/web/src/codewiki/edges.test.ts#L45 "证明同文件符号、跨文件符号和外部目标已有纯函数测试。")

从文件、符号阅读链进入符号所关联片段的入口由 SymbolFrame 在存在 `fragmentId` 时提供。[符号关联片段入口 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L134 "支持从文件或符号阅读链进入符号所关联片段的入口。") 这并非唯一片段入口：知识引用由统一 Trail 承载，FragmentFrame 点击关系时也会优先进入可定位代码文件，否则在另一端存在片段时继续下钻到该片段。[统一 Trail 抽屉 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L371 "支持知识、模块、文件、符号和片段阅读器共用一个受控 Trail。")[片段关系目标选择 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L79 "支持关系点击优先进入可定位代码文件，否则转向关联片段，证明片段之间也可继续下钻。") 旧稿“片段入口由符号帧提供”的排他性结论已被上述多入口描述替代。

片段帧展示不可变原文，并将关系分为反向代码影响与“继续指向”的正向关系；正向集合实际包含实现、依赖、决策依据、调研依据和测试覆盖，不能统称为“依据关系”。[片段关系分类集合 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L31 "支持反向关系和继续指向的正向关系各自包含哪些类型，说明正向集合不全是依据关系。")[片段关系人类标签 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L69 "支持实现、依赖、决策依据、调研依据和测试覆盖等关系以不同人类标签呈现。") 页面模板分别渲染反向影响区和“继续指向”区。[片段原文与关系区域 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L93 "支持不可变原文、反向代码影响区和标题为“继续指向”的正向关系区的实际呈现。") 文件与符号标签优先采用 DTO 展示字段，再以可读名称兜底，避免暴露内部标识。[人类可读标签策略 ↗](../../../apps/web/src/codewiki/modules.ts#L222 "支持展示字段优先、可读名称回退以及不以内部标识作为界面标签。")

## 深链、测试进展与能力边界

页面当前用自有 `syncHash` 把主视图及全部内存 Trail 身份写入 URL，没有在写出路径应用 200 层预算。[页面实际 Hash 写出 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L218 "证明当前 Code Wiki 手工序列化完整 Trail，写出路径没有应用 MAX_TRAIL 截取。") 刷新恢复时，`parseHash` 最多保留 `MAX_TRAIL` 个帧；共享 `writeHash` 虽会在写出时截取，但当前页面没有调用它。[Hash 恢复长度限制 ↗](../../../packages/ui/src/OmHashRoute.ts#L27 "支持 parseHash 在恢复时把 Trail 截取到 MAX_TRAIL。")[共享 Hash 写出限制 ↗](../../../packages/ui/src/OmHashRoute.ts#L67 "支持共享 writeHash 会在序列化时应用 MAX_TRAIL，但与页面自有写出路径不同。") 因而旧稿“写出和解析都会截到 200 层”的结论已被替代：页面可能写出超长链，刷新后只恢复前 200 层且没有截断提示。现有路由测试最多覆盖五层往返，未验证第 201 层。[Hash 路由往返测试 ↗](../../../apps/web/src/codewiki/hashroute.test.ts#L4 "证明现有测试覆盖基础视图、损坏路径以及最多五层的 Trail 往返，未覆盖 200 层边界。")

异步保护也不一致。模块元数据、文件、符号和片段都会在目标变化后启动请求并直接写回状态，当前范围未见请求代次或取消校验。[模块元数据异步监听 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L31 "支持模块变化时直接发起请求并写回知识元数据，未展示代次或取消校验。")[文件帧异步重载 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L56 "支持文件标识变化触发加载并直接写回源码、符号、边和理解状态。")[符号帧异步重载 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L55 "支持符号标识变化触发源码和边加载、边失败降级为空，且当前范围未见过期响应保护。")[片段帧异步重载 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L34 "支持片段标识变化触发详情和关系加载、关系失败降级为空，且结果直接写回组件状态。") 相比之下，知识正文通过 `generation` 丢弃过期响应。[知识正文过期响应保护 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L10 "作为对照，支持知识正文仅允许最后一代请求更新结果或错误。") 因而旧请求覆盖新目标是有代码依据但尚待行为测试确认的风险。文件、符号和片段的辅助关系请求还会把异常降级为空数组，可能将服务故障呈现为无关系。[文件源码与辅助数据加载 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L56 "支持完整源码作为主路径，并证明符号、边和理解请求可独立降级。")[符号帧异步重载 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L55 "支持符号标识变化触发源码和边加载、边失败降级为空，且当前范围未见过期响应保护。")[片段帧异步重载 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L34 "支持片段标识变化触发详情和关系加载、关系失败降级为空，且结果直接写回组件状态。")
