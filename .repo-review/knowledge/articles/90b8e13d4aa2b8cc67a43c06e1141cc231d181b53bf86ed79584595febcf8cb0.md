# 版本化证据与任务状态的存储行为测试

该测试以隔离的临时 SQLite 存储验证 Store 的关键外部行为：捕获重试去重且历史证据保持不变、恢复生成新修订、引用边写入幂等、无效图片不产生半成品、逾期提醒按任务状态版本去重，以及百分号搜索按字面量匹配。现有断言主要描述公开行为，尚未覆盖更广泛的事务故障与搜索转义边界。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-fixture"></a>
## 测试场景与存储基础

这组测试检查个人记忆存储在重复捕获、内容更新、恢复和失败输入下能否保持可信。每个用例都在独立临时目录中创建 `Store`，结束后关闭数据库并清理目录，避免测试之间共享状态。参考 [临时存储测试夹具 ↗](../../../apps/server/tests/store.test.ts#L1 "支持每个测试创建独立临时 Store，并在用例结束后关闭数据库和清理目录。")

捕获夹具经共享 `captureSchema` 解析，并携带来源、操作者、事件时间与时区等溯源字段。参考 [捕获夹具的溯源字段 ↗](../../../apps/server/tests/store.test.ts#L20 "支持测试夹具通过共享合同解析，并携带来源、操作者、事件时间及时区等字段。") 但当前存储断言只明确确认旧修订保留了 `actorId`，不能据此推断夹具中的其余元数据都已写入版本记录。参考 [捕获去重与历史证据 ↗](../../../apps/server/tests/store.test.ts#L40 "支持重复捕获去重、内容变化生成新版本、旧证据保持固定，并明确只有 actorId 得到存储断言。")

Store 的当前基础被明确限定为**单用户 SQLite**，团队级约束留待后续迁移。参考 [单用户 SQLite 边界 ↗](../../../apps/server/src/store.ts#L4 "直接支持当前存储基础是单用户 SQLite，团队级约束仍属后续迁移的结论。") 构造过程创建数据库与资产目录、执行迁移，并初始化应用仓储、作业仓储、输入聚合器、运行请求仓储和来源配置服务。参考 [SQLite 与存储依赖初始化 ↗](../../../apps/server/src/store.ts#L45 "支持 Store 创建数据库和资产目录、执行迁移，并初始化应用仓储、作业仓储、输入聚合器、运行请求仓储和来源配置服务。")

<a id="verified-behaviors"></a>
## 被验证的核心行为

相同输入重试会被标记为重复；内容变化产生第二版，而旧片段仍可读取、旧修订不再是当前版本。参考 [捕获去重与历史证据 ↗](../../../apps/server/tests/store.test.ts#L40 "支持重复捕获去重、内容变化生成新版本、旧证据保持固定，并明确只有 actorId 得到存储断言。") 恢复不会覆写历史，而是创建新修订；再次用过期基线恢复会触发 `REBASE_REQUIRED`。参考 [恢复与过期基线拒绝 ↗](../../../apps/server/tests/store.test.ts#L54 "支持恢复创建新版本、保留被恢复前版本，并拒绝基于过期修订的再次恢复。")

片段之间可以形成循环引用，重复写入同一方向的边不会增加结果数量。参考 [循环引用与边去重 ↗](../../../apps/server/tests/store.test.ts#L68 "支持循环引用仍可双向导航，且重复写入同一引用边不会增加边数量。") 当内容并非真实 PNG 却声明为 PNG 时，捕获失败且修订列表与通知均为空；输入合同同时限定了可接受的图片类型、数据大小、标签和可选的部件溯源。参考 [无效图片的发布前拒绝 ↗](../../../apps/server/tests/store.test.ts#L79 "支持图片内容与声明类型不匹配时捕获失败，且不留下修订列表项或通知。") [图片输入合同 ↗](../../../packages/contracts/src/index.ts#L27 "说明图片部件允许的 MIME 类型、数据长度、标签和可选溯源字段。")

逾期提醒在同一任务状态版本只发送一次，状态修改要求匹配当前版本，重新打开后可以再次提醒。参考 [任务版本与提醒去重 ↗](../../../apps/server/tests/store.test.ts#L98 "支持逾期提醒按状态版本去重、任务更新采用乐观版本检查，并允许重新打开后再次提醒。") 搜索 `%` 只命中真实包含百分号的内容，说明该字符未被当作任意匹配通配符。参考 [百分号字面搜索 ↗](../../../apps/server/tests/store.test.ts#L118 "支持百分号不会被解释为任意匹配通配符，同时界定当前搜索测试只覆盖该字符。")

<a id="coverage-limits"></a>
## 当前覆盖边界

这些测试证明的是公开方法的结果，并未展示捕获、恢复、提醒和搜索的完整内部实现。当前源码范围只能确认 SQLite、资产目录以及应用、作业、输入、运行请求和来源配置等依赖的初始化方式。参考 [SQLite 与存储依赖初始化 ↗](../../../apps/server/src/store.ts#L45 "支持 Store 创建数据库和资产目录、执行迁移，并初始化应用仓储、作业仓储、输入聚合器、运行请求仓储和来源配置服务。")

失败原子性只覆盖图片类型不匹配这一条路径，尚不能确认资产写入、数据库提交或通知写入中途失败时是否整体回滚。参考 [无效图片的发布前拒绝 ↗](../../../apps/server/tests/store.test.ts#L79 "支持图片内容与声明类型不匹配时捕获失败，且不留下修订列表项或通知。") 搜索测试也只覆盖 `%`，不能推出下划线、反斜杠、空查询和大小写规则。参考 [百分号字面搜索 ↗](../../../apps/server/tests/store.test.ts#L118 "支持百分号不会被解释为任意匹配通配符，同时界定当前搜索测试只覆盖该字符。") 任务测试覆盖过期版本冲突与重复提醒，但没有说明未来截止时间、无截止时间或并发提醒者的行为。参考 [任务版本与提醒去重 ↗](../../../apps/server/tests/store.test.ts#L98 "支持逾期提醒按状态版本去重、任务更新采用乐观版本检查，并允许重新打开后再次提醒。")
