# 知识刷新角色清单与运行约束

清单静态声明了 knowledge-refresher 第 1 版的配置档案、提示模板、内联技能、输出合同、工具与会话策略及生成预算；这些字段描述预期装配和限制，不构成摘要校验、能力协商或真实执行已经成功的证据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="identity"></a>
## 角色装配与输出约定

该清单将角色规范标识为 `knowledge-refresher` 第 1 版，引用 `traex` 配置档案和 `prompt.md` 提示模板。[角色身份与提示模板配置 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/manifest.json#L2 "支持角色规范名称、版本、配置档案引用和提示模板来源均由清单静态声明的论断。") 它还声明加载规范名称为 `omem-knowledge-refresher` 的第 1 版技能包，采用内联模式并记录制品摘要，输出类型指定为 `KnowledgeBatch.v1`。[内联技能与输出合同配置 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/manifest.json#L9 "支持规范技能名称、版本、内联加载方式、制品摘要及 KnowledgeBatch 输出类型的装配说明。") 这些内容属于静态配置：材料没有给出技能摘要核验、输出模式解析或一次真实调用的结果，因此不能据此认定角色已经成功加载或产出合规数据。

## 能力隔离与资源边界

工具策略设为 `none`，允许工具列表为空；会话策略要求不复用会话，并关闭用户技能与 MCP 的继承。[工具与会话隔离配置 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/manifest.json#L18 "支持禁用工具、不复用会话以及不继承用户技能和 MCP 的配置事实，同时限定这些只是所列能力的隔离声明。") 这表明清单明确限制了工具和用户扩展能力，但不能进一步推断模型仅受本次固定上下文影响，因为配置档案、提示模板及其他宿主注入上下文仍可能参与执行。预算配置将上下文、输出和修复尝试分别限制为 96000、24000 和 2。[生成预算上限 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/manifest.json#L27 "支持上下文令牌、输出令牌和修复尝试次数具有明确静态上限的论断。") 这些数值是声明的资源上限，不证明 `traex` 已接受相应设置，也不证明实际请求能够在预算内完成。
