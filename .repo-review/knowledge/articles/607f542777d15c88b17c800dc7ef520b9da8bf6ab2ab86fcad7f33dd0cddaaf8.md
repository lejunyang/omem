# other · 模块理解 · 专题 2

本专题汇总固定输入、代码图与理解结果的生命周期，以及角色测试场景、会话隔离、读取接口和普通采集边界；同时区分已验证行为、协议替身能力与仍待确定的生产约束。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="evidence_foundation"></a>
## 固定证据与代码图

文件输入只接受允许根内的普通文本，拒绝逃逸符号链接和二进制内容；Git 输入读取指定修订而非未提交改动。[文件与 Git 输入边界 ↗](../../../apps/server/tests/connectors.test.ts#L9 "支持允许根内文本读取、逃逸与二进制拒绝，以及固定 Git 修订不读取工作区改动。") 捕获后的代码被投影为按快照保存的文件、符号和边：相同输入复用快照，不同路径保持独立身份，删除与新提交保留历史，磁盘脏改动须重新捕获后才进入证据。[代码快照生命周期 ↗](../../../apps/server/tests/code-knowledge.test.ts#L143 "支持快照幂等、路径身份、删除历史、旧快照可读及脏改动重新捕获后才成为证据。") 这使代码图成为固定材料的派生视图，而非另一套事实来源。

<a id="understanding_flow"></a>
## 理解生成、封存与替代

人工 seed 使用路径、限定名和类型描述节点；同步后，有效 seed 以低置信度、无模型、未验证状态进入当前视图，无法解析的符号引用保留为 rejected 历史。快照变化时旧理解标为 stale，新行通过替代关系指向旧行。[人工理解定位与陈旧化 ↗](../../../apps/server/tests/code-understanding-integration.test.ts#L70 "完整覆盖 seed 中的路径、限定名和类型定位，以及投影、坏引用隔离和新快照替代旧理解。") 模型路径先从当前代码表取得真实符号，再经 HTTP 生成、结构校验和持久化；畸形 JSON、未知引用或超时均不会成为当前理解。[模型生成与失败隔离 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L93 "覆盖从当前代码表取得真实符号、HTTP 生成成功，以及格式错误、未知引用和超时不会进入当前理解。") 这修正了旧稿中引用范围不足的问题。确定性校验还拒绝不存在的节点、边、证据、越界选择器及摘要不匹配，但它只能证明引用和输入封存有效，不能代替自然语言的语义复核。[代码理解确定性校验 ↗](../../../apps/server/tests/code-understanding.test.ts#L151 "支持未知引用、越界选择器、未知文件、内嵌 claim 引用和三类摘要不匹配均被拒绝。")

<a id="runtime_security"></a>
## 角色测试场景与会话安全

多角色 ACP 文件只是确定性协议替身：它提供动态模型与推理强度、不同角色合同、超长或非法输出、超时、取消和工具权限请求等测试场景，并要求权限响应为取消；仅凭该文件不能断言宿主运行时已正确处理全部场景或真实模型质量。[多角色 ACP 协议替身 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L1 "说明该文件是非生产协议替身，并提供动态配置、角色合同、异常输出、超时、取消和权限请求场景。") 会话路由按主体、渠道、聊天和线程复用会话，并记录递增轮次与当前目标。[会话身份、轮次与目标 ↗](../../../apps/server/tests/conversation-router.test.ts#L23 "支持会话组合键复用、轮次序号递增、工具动作历史和当前目标保存。") Web 入口强制收口为 owner、web、private；Lark 群聊使用独立命名空间，并在证据送入模型前排除无群聊绑定的私有片段。[渠道收口与群聊证据隔离 ↗](../../../apps/server/tests/conversation-security.test.ts#L64 "支持 Web 参数由服务器强制收口，以及 Lark 群聊新建命名空间并过滤私有证据。") 中文群聊用例另行证明分词检索可召回不含完整查询字面串的片段。[Lark 中文关键词召回 ↗](../../../apps/server/tests/conversation-security.test.ts#L296 "支持完整查询字面串无法命中时，群聊运行链仍通过中文关键词检索召回目标片段。") 这些仍是单用户语义，不能外推为完整租户授权。

<a id="progress_limits"></a>
## 当前覆盖与边界

真实仓库测试已投影 assistant、memory、retrieval、Lark 与 Vue 区域，并验证代码文件、符号、图和源码切片接口；越界切片返回错误。[真实仓库代码图与读取接口 ↗](../../../apps/server/tests/code-knowledge.test.ts#L286 "支持真实仓库关键区域的代码图覆盖，以及文件、符号、图、源码切片和越界校验接口。") 无模型时，人工理解详情和原始代码图仍可读取。[无模型只读降级 ↗](../../../apps/server/tests/code-understanding-integration.test.ts#L215 "支持模型不可用时人工理解列表、详情和原始代码图仍可读取。") 批次合同测试证明文档提议样例可解析，未知字段、正文类型不匹配和缺少并发版本的更新会被拒绝，但未逐项证明完整样例中的所有字段必填。[提议与批次合同边界 ↗](../../../apps/server/tests/contracts.test.ts#L14 "支持提议样例解析、严格反例以及批次和纠正对象完整样例的当前兼容性。") 普通采集会保存修订和片段，却不会自动创建质量数据集、样本或投递意图；研究导入必须显式启用。[普通采集与质量评测隔离 ↗](../../../apps/server/tests/import-quality-isolation.test.ts#L36 "支持普通采集不创建质量标注工作，并证明研究导入缺少显式启用值时失败。") 尚未覆盖跨文件调用、跨修订符号续接、大仓库性能、并发生成、真实外部模型兼容性及验证角色的独立身份约束。
