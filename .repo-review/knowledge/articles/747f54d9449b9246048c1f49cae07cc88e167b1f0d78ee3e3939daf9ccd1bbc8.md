# 视觉材料分析技能定义

该技能文件声明视觉分析角色的职责、固定材料边界和结构化输出规范；其执行规则与角色提示词逐项对应，但这些声明本身不构成图像载荷、模型调用或端到端复核能力已经实现的证据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="skill-purpose"></a>
## 技能定位

技能被定义为分析图像材料：根据原始图片说明可见结构、界面或图表，区分直接观察与推断，不虚构不可读文字，并在图片引用中说明区域。[视觉分析职责 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/skills/omem-visual-analyst/SKILL.md#L1 "支持技能名称、分析对象以及必须区分观察与推断的职责边界。") 这一职责适合把截图和图表转化为可追溯知识，但技能文件没有展示图像输入格式、模型视觉能力声明或真实执行结果。

<a id="execution-contract"></a>
## 执行与输出约束

执行规范要求仅处理给定材料，以中文返回指定 JSON，并按目标键逐项覆盖；正文宜组织为若干章节，说明作用、背景、流程、限制和材料关联，且每节都要把引用放在对应论断附近。[材料范围与正文组织规则 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/skills/omem-visual-analyst/SKILL.md#L10 "支持中文 JSON 输出、固定材料范围、目标覆盖、正文组织和章节内联引用要求。") 引用只能指向已提供的材料或文章，需使用完整目标键、人读标签和合规关系；不能确定的内容要形成带原因、下一步、阻塞状态和引用键的问题。[引用与疑问处理规则 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/skills/omem-visual-analyst/SKILL.md#L13 "支持引用定位、人读标签、关系约束及结构化记录不确定事项的说明。")

<a id="shared-rules"></a>
## 与角色提示词的关系

技能中的材料边界、目标覆盖、章节组织、内联引用和疑问处理规则，在独立角色提示词中也有对应表述。[角色提示词中的对应规范 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/prompt.md#L3 "与技能文件的执行规则形成跨材料对照，支持两处存在重复约束以及可能发生同步漂移的论断。") 因而可以确认两份材料存在重复约束，但仅凭现有材料无法判断运行时以哪一份为权威来源、是否由生成流程保持同步。若两处独立维护，后续修改可能造成实际提示与技能说明漂移。
