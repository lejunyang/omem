# agent-runtime · 模块理解

agent-runtime 是受宿主管控的角色执行层：它验证版本化角色资产，隔离可信上下文与不可信材料，经 ACP 或 CLI 调用模型，实施能力、预算及结构化输出校验，并把结果与运行追踪接入耐久作业。角色覆盖候选提取、知识生产与复核、代码理解和视觉分析；资产安全、部分交叉引用校验及诚实 seed 降级已有实现，但固定角色编排、发布门禁、交互审批和真实后端兼容性仍待验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 职责与设计背景

该模块把领域判断放入版本化角色包，把资产完整性、信任分层、模型传输、预算、输出合同和运行追踪交给统一宿主。角色清单固定提示、技能、输出类型、工具策略、会话隔离与修复预算，例如代码分析角色禁止工具且不复用会话。[代码分析角色运行配置 ↗](../../../packages/agent-runtime/roles/code-analyst/1/manifest.json#L2 "支持角色包静态绑定提示、技能、输出合同、无工具策略、独立会话和修复预算。") 提取器只生成绑定固定证据的候选，不批准或应用结果；通用核验者则不继承提取推理，独立比较原始证据的主体、范围、时间和条件。[候选提取职责 ↗](../../../packages/agent-runtime/roles/extractor/1/prompt.md#L3 "支持提取器仅从固定证据生成候选，并禁止批准、执行或宣称结果已应用。")[独立证据核验职责 ↗](../../../packages/agent-runtime/roles/verifier/1/prompt.md#L3 "支持核验者独立重查原始证据、比较语义维度且无权执行变更。")

<a id="runtime_flow"></a>
## 资产、上下文与执行流程

注册表通过包内路径和真实路径检查拒绝越界或符号链接资产，核对清单身份、输出合同、技能名称与摘要；只有 native 技能会复制到按运行隔离的工作区。[角色资产安全与隔离工作区 ↗](../../../apps/server/src/agent-runtime/bundles.ts#L41 "覆盖包内路径检查、符号链接拒绝、摘要核对、复制冲突保护和 native 技能隔离工作区。") 网关把角色规则、内联技能、合同和可信元数据置于可信区，将派生知识与材料正文标为不可信数据，并校验图片编码、摘要、类型和总量。[可信上下文与材料分层 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L81 "支持可信规则和元数据与不可信派生知识、材料正文分层，以及图片完整性和容量校验。")

执行预算采用 UTF-8 字节启发式估算并增加余量，而非精确 tokenizer。[生成预算估算 ↗](../../../apps/server/src/agent-runtime/budget.ts#L1 "支持预算覆盖优先级、整数范围限制及带余量的 UTF-8 字节启发式估算。") 模型结果必须是单个 JSON 对象，经解析后通过角色声明的运行时合同，并在适用时核对作业或角色身份。[结构化输出解析与身份校验 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L210 "直接支持结果必须是单个 JSON 对象、须经角色运行时合同解析，并在适用时核对作业或角色身份。") 网关校验 profile、工具供给和会话策略后进入 ACP 或 CLI；输出预算与可选后验验证失败可触发有限修复，并汇集实际模型、技能、工具、会话和预算 trace。[角色网关执行、修复与追踪 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L247 "支持运行前约束、ACP 与 CLI 分支、输出预算、可选后验验证、有限修复和运行 trace 汇集。") ACP 还会发现 native 技能、拒绝不支持的模型或推理强度，并在元数据可用时检查上下文窗口及图片能力。[ACP 能力发现与配置检查 ↗](../../../apps/server/src/agents.ts#L259 "支持 native 技能发现、模型和推理强度校验、上下文窗口检查以及图片能力拒绝。")

<a id="roles_and_evidence"></a>
## 角色体系与证据纪律

知识生产侧区分材料分析、撰写和独立复核：分析者避免把历史计划写成实现事实，撰写者解释原因、机制、关联与限制且不把派生总结当独立证据，复核者检查引用对附近论断的支持性、范围和条件。[材料分析的状态区分 ↗](../../../packages/agent-runtime/roles/material-analyst/1/prompt.md#L1 "支持材料分析者区分文档陈述、实现事实和历史状态，禁止把旧计划写成现状。")[知识撰写与原始依据边界 ↗](../../../packages/agent-runtime/roles/knowledge-writer/1/prompt.md#L1 "支持撰写者解释机制、关联和限制，并明确派生总结不得成为独立证据。")[知识独立复核规则 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/skills/omem-knowledge-verifier/SKILL.md#L8 "支持复核引用语义、范围、条件和时效，并将无支持或确定性过强的论断退回修订。") 规划器从目录设计可追溯知识树；刷新器根据新旧材料与用户回答更新受影响正文、引用和疑问，并保留未受影响知识。[可追溯知识树规划 ↗](../../../packages/agent-runtime/roles/knowledge-planner/1/skills/omem-knowledge-planner/SKILL.md#L8 "支持规划器从目录识别概念、组织固定章节并区分需求、历史方案、实现和未决问题。")[关联知识刷新规范 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/skills/omem-knowledge-refresher/SKILL.md#L8 "直接支持刷新器更新受影响正文、引用和疑问，同时保留未受影响知识并标明替代结论。") 这些规范证明职责存在，但不证明宿主按固定顺序编排。

视觉分析角色要求区分可见内容与推断、不虚构不可读文字并标注图片区域；其清单绑定 `KnowledgeBatch.v1`、无工具策略和独立会话。[视觉分析证据纪律 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/skills/omem-visual-analyst/SKILL.md#L8 "支持视觉角色区分观察与推断、不虚构不可读文字并引用图片区域。")[视觉分析角色配置 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/manifest.json#L2 "支持视觉角色绑定内联技能、KnowledgeBatch 输出、无工具策略、独立会话和预算。") 代码理解则以固定文件、符号、边和证据快照为事实边界，区分机械事实与解释。[代码理解固定快照与输出合同 ↗](../../../packages/agent-runtime/src/code-understanding.ts#L49 "支持固定快照结构、机械事实与解释区分、结构化未知项和来源封印。") 白名单角色加载、来源封印、显式引用检查和无模型时零置信度 seed 已实现。[代码理解验证与 seed 降级 ↗](../../../packages/agent-runtime/src/code-understanding.ts#L412 "支持白名单资产加载、显式交叉引用检查、失败状态返回及无模型时不伪造叙事的 seed。") 因而此前“派生文章或模型总结只能用于组织与召回”的过宽结论已被替代：当前材料仅能确认派生总结不应脱离原始依据成为独立证据。[知识撰写与原始依据边界 ↗](../../../packages/agent-runtime/roles/knowledge-writer/1/prompt.md#L1 "支持撰写者解释机制、关联和限制，并明确派生总结不得成为独立证据。")

<a id="integration_limits"></a>
## 作业接入与当前限制

作业适配器把上下文、取消信号与网关连接，并按租约保存结构化结果及完整 trace；耐久 worker 管理领取、心跳、取消、成功和失败分类。[角色作业适配器 ↗](../../../apps/server/src/agent-runtime/job-handler.ts#L9 "支持通过网关运行角色，并按租约保存结构化结果、模型配置、会话和完整追踪。")[耐久作业执行流程 ↗](../../../apps/server/src/jobs/worker.ts#L47 "支持作业领取、心跳、取消、成功提交、失败分类和过期租约处理。") 这形成了从角色包到耐久作业的实现链，但材料没有真实外部 Agent 的兼容性结果。

后台 ACP 权限或补充输入请求目前会立即取消或拒绝。[后台运行时请求立即拒绝 ↗](../../../apps/server/src/agents.ts#L181 "支持 ACP 权限和补充输入请求在通知宿主后立即取消或拒绝，而不暂停等待用户。") 仓储创建的是幂等 `denied` 记录；其 `resolve` 只接受既有且未过期的 `pending`，材料未展示 pending 创建、会话暂停和决定回传。[运行时请求仓储边界 ↗](../../../apps/server/src/agent-runtime/requests.ts#L37 "支持 denied 请求的幂等保存，并显示 resolve 仅处理既有且未过期的 pending 请求。") 此外，网关后验验证为可选；代码理解验证器虽能返回失败或拒绝，也未展示持久化入口必然阻止无效结果覆盖有效知识。[角色网关执行、修复与追踪 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L247 "支持运行前约束、ACP 与 CLI 分支、输出预算、可选后验验证、有限修复和运行 trace 汇集。")[代码理解验证与 seed 降级 ↗](../../../packages/agent-runtime/src/code-understanding.ts#L412 "支持白名单资产加载、显式交叉引用检查、失败状态返回及无模型时不伪造叙事的 seed。")
