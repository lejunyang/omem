# omem 界面与组件实施规范

这是 2026-09-26 的 v1 视觉与交互实施规范，规定黑白灰证据阅读风格、Vue 组件复用、引用层级、响应式与无障碍验收；它是实现约束，不代表所有界面行为均已完成。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="visual-information"></a>
## 视觉基线与信息架构

规范将黑白灰证据阅读风格设为产品基线，并明确此文件只管界面与组件，系统架构另见 `docs/design.md`；实现入口是 Vue 3 + TypeScript 的 `packages/ui`。[视觉规范定位 ↗](../../../design.md#L1 "支持该文档的实施规范状态、视觉基线、职责边界及 Vue 实现入口。") 页面采用顶栏、左侧材料、中间正文与右侧追问的结构，引用需贴近原句并展示版本、来源和关系；采集内容不得自动成为执行指令。[信息架构与证据展示 ↗](../../../design.md#L22 "支持三栏信息结构、引用展示要求以及材料不自动成为指令的约束。")

<a id="components-trail"></a>
## 共享组件与引用阅读链

业务界面必须复用 `@omem/ui` 的按钮、弹窗、引用、面板和壳组件，UI 包只接收 props、slots 与 events，不直接访问 API 或密钥。[共享 UI 组件合同 ↗](../../../design.md#L28 "支持组件复用范围、业务注入方式及 UI 包不得连接 API 或读取密钥的边界。") 引用弹窗以固定片段版本为节点，支持逐层 push、Esc/back、循环返回、滚动与草稿记忆，并保持背景文章状态。[引用弹窗交互 ↗](../../../design.md#L40 "支持固定片段、层级导航、循环处理、状态记忆和原位追问合同。") 这是交互合同，不是现有代码通过验收的证明。

<a id="responsive-acceptance"></a>
## 响应式、无障碍与真实行为

布局按 1100px 与 700px 两个边界切换三栏、侧栏和全屏引用；点击区域、标签、焦点、ARIA、Tab 顺序、触屏操作及减弱动画都有明确要求。[移动端与无障碍要求 ↗](../../../design.md#L44 "支持断点行为、可点击尺寸、焦点、ARIA、触屏和减弱动画要求。") 验收还要求真实动作、真实错误态、模型配置实际传入执行器、修改通知与 UTC 存储，并在 UI 变更后执行项目和浏览器检查。[真实行为与验收要求 ↗](../../../design.md#L50 "支持真实动作、错误态、模型参数传递、通知、时区及检查流程的验收约束。")
