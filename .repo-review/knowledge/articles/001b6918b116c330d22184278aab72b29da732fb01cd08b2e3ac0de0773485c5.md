# 日常助理对话界面

该 Vue 组件提供日常助理的会话入口：初始化固定 Web 会话与工作流说明，发送或重试消息，轮询处理状态，并把回答采用的证据交给外层打开。它承担前端交互和状态同步，但现有生命周期防护只覆盖部分异步写入，不能保证卸载后不再更新状态或创建定时器。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-state"></a>
## 作用与状态模型

组件把交办、事项回顾和记忆查询组织为连续会话，维护会话 ID、草稿、错误、轮次、发送状态与工作流模板。`busy` 同时考虑本地请求和服务端标为 `running` 的轮次，用于阻止并发发送或重试。轮次结构只包含输入、结果、状态和已选证据，说明推理过程、任务执行及证据选择均由组件之外完成。[日常助理状态与轮次结构 ↗](../../../apps/web/src/DailyAssistant.vue#L1 "支持组件维护的核心状态、忙碌判定以及轮次和证据字段范围。")

<a id="send-retry-lifecycle"></a>
## 发送、重试与生命周期边界

发送要求会话已建立、文本非空且当前不忙；同一文本失败后保留原 `requestId`，成功时才清除请求身份与草稿，并在重载轮次后通知外层刷新。失败路径会显示错误并尝试重新读取服务端状态；轮次重试则调用独立端点。[消息发送与失败重试流程 ↗](../../../apps/web/src/DailyAssistant.vue#L19 "支持发送前置条件、请求标识复用、成功刷新、失败恢复以及独立轮次重试的说明。")

挂载时并行获取固定 `web-daily` 会话和工作流模板，随后重载轮次并启动两秒轮询。此前“卸载标记可避免异步结果继续写入，并可靠清除定时器”的概括被替代：`disposed` 只保护初始化在并行请求后的赋值及 `reload` 对轮次的赋值；异常处理仍可能在卸载后写入错误。若卸载发生在首次 `await reload()` 期间，清理执行时定时器尚未赋值，而恢复后仍会创建新定时器，因此现有实现没有完整的卸载后状态与轮询保护。[会话初始化、轮询与卸载处理 ↗](../../../apps/web/src/DailyAssistant.vue#L38 "支持初始化和轮询流程，并界定 disposed 检查与定时器清理实际覆盖的范围及其生命周期缺口。")

<a id="rendering-and-boundaries"></a>
## 呈现、证据关系与未确认边界

界面将服务端状态映射为已处理、处理中、等待重试、处理失败和已停止等人读标签，仅为 `pending`、`failed` 轮次提供重试；无结果时也明确说明消息仍被保留。已选证据以修订标题展示，点击后只向父组件发送 fragment 标识，由外层负责打开原文。[消息状态、重试入口与证据界面 ↗](../../../apps/web/src/DailyAssistant.vue#L48 "支持状态标签、未完成提示、可重试条件以及证据点击交由父组件处理的说明。")

组件依赖本地 `api` 调用助理端点，但所给 API 材料范围仅展示共享数据类型，没有请求实现、后端路由、鉴权、幂等约束或响应版本合同。[前端 API 类型范围 ↗](../../../apps/web/src/api.ts#L1 "说明所给 API 材料只覆盖共享类型，不能据此确认请求传输、服务端幂等或响应顺序保证。") 因而不能确认复用 `requestId` 必然防止重复执行，也不能确认轮询与主动重载发生乱序时旧结果不会覆盖新轮次。

<a id="known-risks"></a>
## 当前限制与关联风险

发送、重试和定时轮询都可能触发轮次重载，而 `reload` 没有请求序号、取消信号或版本比较；较早请求若较晚返回，可能覆盖较新的 `turns`。[消息发送与失败重试流程 ↗](../../../apps/web/src/DailyAssistant.vue#L19 "支持发送前置条件、请求标识复用、成功刷新、失败恢复以及独立轮次重试的说明。")[会话初始化、轮询与卸载处理 ↗](../../../apps/web/src/DailyAssistant.vue#L38 "支持初始化和轮询流程，并界定 disposed 检查与定时器清理实际覆盖的范围及其生命周期缺口。") 此外，客户端保留请求身份只表达了幂等意图，真正的去重仍依赖未提供的服务端持久化与冲突处理机制，不能从前端调用点推定。[前端 API 类型范围 ↗](../../../apps/web/src/api.ts#L1 "说明所给 API 材料只覆盖共享类型，不能据此确认请求传输、服务端幂等或响应顺序保证。")
