# 日常助理会话：发送、轮询与证据跳转

这个 Vue 页面把日常交办、事项回顾和记忆查询组织成一条可持续查看的会话流：初始化固定 Web 会话与使用模板，提交带幂等标识的消息，轮询轮次状态，并把回答中的证据转成可打开的原文或片段。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-boundary"></a>
## 把日常请求汇入同一会话

该组件是日常助理的**前端会话编排层**：用户可直接交办、回顾事项或查找记忆，页面同时展示服务端提供的工作流用途。输入最多 2000 字；会话尚未建立、内容为空或已有消息处理中时，发送按钮不可用。参考 [日常助理输入界面 ↗](../../../apps/web/src/DailyAssistant.vue#L137 "支持页面面向交办、回顾和记忆查询的用途，以及输入长度和发送按钮禁用条件。")

组件复用 `@omem/ui` 的面板、Markdown、引用等展示组件，通过通用 `api` 访问后端，并把证据阅读交给 `readAssistantAnswer`；自身不负责模型推理或任务持久化。参考 [前端依赖与职责 ↗](../../../apps/web/src/DailyAssistant.vue#L2 "支持组件复用 UI、API、回答阅读器和知识导航类型，而非在组件内实现后端推理。")

<a id="message-flow"></a>
## 一次交办如何完成

以“明天上午 9 点提醒我检查评审回复”为例：页面挂载时并行打开固定的 `web-daily` 会话并加载工作流，随后读取历史轮次，每 2 秒刷新一次。参考 [会话初始化与轮询 ↗](../../../apps/web/src/DailyAssistant.vue#L115 "支持打开固定 Web 会话、加载工作流、首次读取轮次并按两秒间隔刷新。")

提交时先去除首尾空白，再为这段文本生成 `requestId` 并 POST 到当前会话。成功后清空幂等缓存与输入框、重载轮次，并通知父页面刷新其他数据；若请求报错，同一文本再次提交会沿用原 `requestId`，同时页面仍尝试重载，以避免把一次结果不明的请求轻易变成两次操作。`busy` 同时覆盖本地发送和任一运行中轮次，阻止并发提交或重试。参考 [消息提交与幂等标识 ↗](../../../apps/web/src/DailyAssistant.vue#L61 "支持忙碌保护、文本规范化、同文本复用 requestId、成功刷新及错误后重载的发送流程。")

<a id="results-evidence-and-limits"></a>
## 结果、证据与失败恢复

每个轮次先经回答阅读器生成可渲染 Markdown、引用和补充证据。点击正文引用时，有精确来源目标就向父层发出 `navigate`，否则用 fragment ID 发出 `open`，因此证据抽屉或原文页由外层承接。参考 [回答解析与证据跳转 ↗](../../../apps/web/src/DailyAssistant.vue#L32 "支持轮次经回答阅读器转换，并按是否存在精确来源目标选择原文导航或片段打开。")

页面把 `done`、`running`、`pending`、`failed`、`cancelled` 分别显示为“已处理”“处理中”“等待重试”“处理失败”“已停止”。参考 [状态中文名称 ↗](../../../apps/web/src/DailyAssistant.vue#L54 "直接支持五种轮次状态与中文显示名称的对应关系。") 未识别的状态显示“待处理”；没有结果且处于等待或失败状态时，原消息继续保留并出现重试按钮，正文未使用的补充证据则单独列出。该组件能显示“已停止”，但本页没有取消入口。参考 [轮次结果与重试界面 ↗](../../../apps/web/src/DailyAssistant.vue#L171 "支持未知状态回退、回答渲染、等待或失败提示与重试按钮，以及补充证据列表。")

发送或重试失败会把错误写入页面状态；初始化失败也会记录错误，而定时轮询失败会被忽略，避免周期刷新不断打断用户。参考 [发送与重试错误 ↗](../../../apps/web/src/DailyAssistant.vue#L91 "支持发送失败后记录错误并尝试重载，以及重试失败后记录错误。") [初始化与轮询错误处理 ↗](../../../apps/web/src/DailyAssistant.vue#L115 "支持初始化失败写入错误状态，以及定时轮询通过空 catch 忽略刷新错误。") 页面用告警区域显示已记录的错误。参考 [页面错误告警 ↗](../../../apps/web/src/DailyAssistant.vue#L165 "支持页面在存在错误状态时以 alert 区域向用户展示错误。") 卸载时组件会标记已销毁并清除定时器。参考 [卸载清理 ↗](../../../apps/web/src/DailyAssistant.vue#L130 "支持组件卸载时设置销毁标记并清除轮询定时器。") 若刷新请求在卸载前已经发出，它返回后也不会再写入轮次。参考 [迟到刷新保护 ↗](../../../apps/web/src/DailyAssistant.vue#L66 "支持刷新结果仅在组件尚未销毁时写入轮次。")
