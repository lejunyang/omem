# 缓冲输入、脱机队列与聚合窗口验收测试

覆盖 hook 脱机落盘、回执校验、去重与容量限制、敏感字段过滤，以及聊天和屏幕事件的有界聚合与迟到追踪。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="offline-spool"></a>
## 脱机暂存与可靠清除

测试把 hook 转发器指向不可达地址，要求进程正常退出、标准输出为空并提示已排队。重启 `HookSpool` 后，同一事件仍被识别为重复；发送失败或返回空回执都不能删除待处理项，只有 `Store.capture` 返回匹配回执后才清除。[脱机 hook 暂存与回执匹配 ↗](../../../apps/server/tests/inputs.test.ts#L48 "支持脱机排队、重启恢复、回执不匹配时保留以及成功后幂等清除的流程。") 重复重放最终只产生一份采集回执、材料和作业，说明暂存层与 Store 的幂等边界协同。

<a id="security-limits"></a>
## 隐私、冲突和容量约束

采集 profile 只保留允许的 prompt 字段，并把令牌样式内容替换为 `[REDACTED]`；工具响应、私有思考和未知秘密不得进入序列化结果。[采集 profile 与敏感信息过滤 ↗](../../../apps/server/tests/inputs.test.ts#L127 "支持仅保留允许字段、脱敏令牌并排除响应和私有思考的安全断言。") 同一事件标识配不同载荷时，spool 与 Store 分别明确报冲突；容量溢出抛出专用错误，警告只记录容量类别而不复制敏感正文。事件文件在 POSIX 下断言为 0600，[冲突、容量与事件文件权限 ↗](../../../apps/server/tests/inputs.test.ts#L151 "支持事件文件 0600 权限、冲突拒绝及容量警告不泄漏正文。") 暂存目录则在前一用例末尾断言为 0700。[暂存目录权限断言 ↗](../../../apps/server/tests/inputs.test.ts#L119 "支持 POSIX 下暂存目录被单独断言为 0700 的论断。")

<a id="aggregation"></a>
## 聊天与屏幕聚合流程

聊天事件进入五分钟窗口：重复噪声事件仍保留追踪标识，但聚合修订只保留去重后的三个正文 part；到 300 秒才强制落库，并记录窗口起止时间。[聊天窗口强制刷新与去噪 ↗](../../../apps/server/tests/inputs.test.ts#L227 "支持五分钟边界、事件标识保留、正文去重和窗口时间记录。") 已落库窗口中的迟到事件形成新修订，并通过 `lateForBatchId` 指回原批次。屏幕输入在达到 `maxEvents` 时立即刷新，两条相同画面压缩成一个正文 part。[迟到事件与屏幕事件聚合 ↗](../../../apps/server/tests/inputs.test.ts#L281 "支持迟到补充形成新修订并关联旧批次，以及屏幕事件按数量刷新和正文去重。")

<a id="coverage"></a>
## 边界与未覆盖行为

测试确认所有聚合输入最终清空，并形成三个批次和三个作业。[聚合完成状态断言 ↗](../../../apps/server/tests/inputs.test.ts#L323 "支持输入清空并产生三个批次和三个作业的最终状态。") Windows 分支只验证路径存在且可读取，因为 Unix mode 位不能表达 NTFS ACL；材料没有检查实际 Windows ACL。[跨平台权限断言策略 ↗](../../../apps/server/tests/inputs.test.ts#L32 "解释 POSIX 检查 mode，而 Windows 分支只检查文件或目录可访问的测试边界。") 其余未覆盖项包括写文件中途崩溃、磁盘写满、多进程同时操作同一 spool、超大单事件，以及不同会话或窗口之间的聚合隔离。
