# 离线输入缓冲与事件聚合的行为验证

该测试验证输入链路在服务离线、重复投递、事件冲突、容量受限及高频聊天或屏幕事件下的关键行为：钩子事件可安全落盘并重试，只有匹配回执才会清除；采集配置会裁剪及脱敏字段；聚合器按有界窗口形成批次、压缩重复内容，并将迟到事件关联到原批次而不改写旧修订。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="offline-delivery"></a>
## 离线投递不会丢失或误删事件

测试让钩子转发进程连接不可达地址，确认进程仍正常退出、事件进入本地缓冲；相同事件再次入列会被识别为重复，投递失败后待处理文件继续保留。参考 [离线入列与失败保留 ↗](../../../apps/server/tests/inputs.test.ts#L49 "支持连接失败时事件仍进入缓冲、重复事件被识别且失败刷新不会删除待处理项。")

缓冲实例重启后，无回执或回执不匹配都不能清除事件；接入真实采集存储并取得匹配回执后才标记投递成功。再次提交相同内容不会增加采集回执、材料或任务，说明该流程同时约束跨重启重试和存储层幂等。参考 [回执校验与跨重启幂等 ↗](../../../apps/server/tests/inputs.test.ts#L87 "支持无匹配回执不清除事件、成功采集后清除，以及重复采集不增加回执、材料和任务。")

POSIX 环境还断言缓冲目录仅所有者可访问；Windows 分支只确认路径存在且可读取，并未直接验证 ACL。参考 [缓冲目录权限断言 ↗](../../../apps/server/tests/inputs.test.ts#L32 "说明权限辅助断言的跨平台差异，并支持测试对 POSIX 缓冲目录权限的检查。")

<a id="privacy-and-limits"></a>
## 采集配置、冲突与容量边界

`prompt-only-v1` 配置只保留提示词，并将令牌样式内容替换为脱敏标记；响应、思维内容和额外秘密字段不得进入序列化结果。参考 [字段裁剪与秘密脱敏 ↗](../../../apps/server/tests/inputs.test.ts#L133 "支持采集配置只保留指定字段、脱敏令牌并排除响应、思维和秘密字段。")

缓冲文件在 POSIX 下要求使用 `0600` 权限。同一事件标识对应不同载荷时必须报冲突；超过条目上限时抛出容量错误并记录告警，但告警不得泄露被拒载荷。参考 [缓冲冲突与容量保护 ↗](../../../apps/server/tests/inputs.test.ts#L151 "支持缓冲文件权限、同事件异载荷冲突、容量溢出及告警不泄露载荷等断言。") 存储层也独立拒绝同标识异内容，且冲突不会新增材料或任务。参考 [存储层事件冲突 ↗](../../../apps/server/tests/inputs.test.ts#L180 "支持存储层拒绝相同事件标识的不同载荷，并保持材料和任务数量不变。")

<a id="bounded-aggregation"></a>
## 有界聚合、降噪与迟到事件追踪

聊天事件进入聚合器后，在五分钟窗口边界前调用刷新不会形成或保存聚合批次；到达边界后，即使会话仍活跃也会强制生成批次及其采集修订。批次保留全部事件标识和时间边界，但相同文本会被压缩，因此四个事件最终形成三个内容部分。参考 [聊天窗口刷新与降噪 ↗](../../../apps/server/tests/inputs.test.ts#L227 "支持五分钟边界前刷新不形成批次、边界时生成批次，以及事件追踪、时间范围和重复文本压缩行为。")

观测时间属于旧窗口、实际到达较晚的事件会生成独立的补充修订，并通过 `lateForBatchId` 指向原批次，从而避免改写已经保存的证据。参考 [迟到事件补充批次 ↗](../../../apps/server/tests/inputs.test.ts#L281 "支持迟到事件指向原批次但创建独立修订，不改写已有批次。") 屏幕事件达到显式数量上限时也会立即刷新；重复画面被压缩成一个内容部分，完成后没有待处理事件，并为三个批次分别产生任务。参考 [屏幕事件数量刷新 ↗](../../../apps/server/tests/inputs.test.ts#L296 "支持屏幕重复内容降噪、达到事件数上限即刷新，以及批次与任务数量断言。")
