# Repo Review 专用 Vite 子进程

为 review 开发模式创建独立 Vite 服务，绕开个人应用代理配置，严格绑定选定 Web 端口并把 API 请求代理到同次编排选定的 review 后端。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="isolation"></a>
## 配置隔离

该脚本刻意不读取共享的 `apps/web/vite.config.ts`，因为其中 `/api` 指向个人后端；它以 `configFile: false`、Web 根目录和 Vue 插件构造 review 专用服务，并从环境变量读取 Web/API 端口。[Review Vite 配置隔离 ↗](../../../scripts/dev-review-vite.ts#L1 "支持绕过个人代理配置并通过环境变量建立 review 专用前后端连接的说明。") 因而同一前端源码可以连接隔离的 review 后端，而无需修改个人开发配置。

<a id="lifecycle"></a>
## 端口和生命周期边界

Vite 只监听 `127.0.0.1`，`strictPort` 保证端口占用时非零退出，避免控制台宣告与实际监听地址不一致；`/api` 被代理到明确的本地 API 端口。启动后输出解析出的地址，收到 SIGINT 或 SIGTERM 时关闭 Vite 再退出。[严格端口、代理与信号退出 ↗](../../../scripts/dev-review-vite.ts#L22 "支持监听范围、strictPort、API 代理和优雅关闭行为的论断。") 本文件不校验端口数字范围、不探测 API 健康，也没有独立重启逻辑，这些职责由上层编排器承担。
