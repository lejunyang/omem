# 知识生成、复核与制品合同

该模块定义知识文档、内联引用、待确认问题、批量生成、独立复核与计划的严格 Zod 合同，并补充运行时材料和已验收制品的类型结构。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="document"></a>
## 正文、引用与问题

知识文档包含稳定 key、标题、摘要、分类和章节；章节正文可承载 Markdown。引用具有短 key、人读标签、理由、关系及材料或文章目标，材料目标可带行号，文章目标可带 section，quote 默认为空并由宿主按固定范围提取。[知识引用与正文合同 ↗](../../../packages/contracts/src/knowledge.ts#L3 "支持引用键、标签、理由、关系、材料行号或文章章节，以及宿主提取 quote 的设计。") questions 明确记录问题、原因、下一步、是否阻塞及关联引用，避免把证据不足伪装成结论。[问题与知识文档结构 ↗](../../../packages/contracts/src/knowledge.ts#L17 "支持待确认问题的完整字段，以及知识文档章节、引用和问题集合的边界。")

<a id="batch-review-plan"></a>
## 批量输出、复核与组织计划

批量合同一次容纳有限数量的知识文档；复核合同逐文档返回 accepted 或 needs_revision，并可附具体问题与待确认项。知识计划则把材料分配给至少四个章节，每章说明目的。[批量、复核与知识计划合同 ↗](../../../packages/contracts/src/knowledge.ts#L37 "支持批量文档、逐文档复核结论及按章节组织材料的交换格式。") 这些 schema 约束交换格式和数量边界，但不执行引用语义核验，也不负责修订合并。

<a id="artifact"></a>
## 材料与已验收制品

`KnowledgeMaterial` 保留来源、修订、摘要、正文行数、Fragment 与图片等信息。`KnowledgeArtifact` 则把文档、依赖摘要、生成模型与 trace，以及结论为 accepted 的复核模型和 trace 组合成版本化制品。[知识材料与制品类型 ↗](../../../packages/contracts/src/knowledge.ts#L59 "支持材料来源信息、Fragment、图片，以及制品依赖、生成 trace 和已验收复核 trace 的结构。") 该类型表达制品应携带生成和复核来源，但这里只是 TypeScript 类型，并未展示摘要核验、落盘或防篡改实现。
