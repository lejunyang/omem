# 检索配置

该配置声明启用检索能力，并将检索模型指向 osdk 管理的 memory-zh。它只表达期望的运行配置；材料未展示配置加载、模型锁定、索引构建或查询执行，因此不能据此认定检索链路已经实际可用。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 配置作用

该文件是检索功能的简洁开关与模型选择入口：`enabled` 被设为 `true`，表示配置层期望启用检索；`osdkModel` 指向 `memory-zh`，表示相关模型应通过这一逻辑名称解析。[检索开关与模型配置 ↗](../../../config/retrieval.json#L1 "支持附近关于检索被声明为启用、模型逻辑名称为 memory-zh，以及该文件仅包含两个主要配置字段的说明。") 两个字段共同描述“是否启用”和“使用哪个模型”，但没有给出召回参数、索引位置、向量身份或重排策略。

<a id="limits"></a>
## 可确认范围与限制

从材料只能确认静态 JSON 中存在上述声明，不能进一步证明应用已经读取该文件、osdk 已下载并锁定对应模型，或索引与查询流程已成功运行。[静态检索配置声明 ↗](../../../config/retrieval.json#L2 "支持附近对证据边界的判断：材料展示的是 enabled 与 osdkModel 的静态声明，并未展示加载、下载、建索引或查询执行过程。") 同样无法从这五行配置判断 `memory-zh` 对应的具体模型版本、向量维度及旧索引兼容规则；这些属于需要结合依赖锁、运行代码和验证结果确认的实现事实。
