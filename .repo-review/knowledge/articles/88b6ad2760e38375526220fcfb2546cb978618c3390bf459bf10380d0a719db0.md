# SQLite 本地语义检索与词法融合

在关键词检索之上增量构建本地向量索引，以精确余弦和 RRF 融合改善中文语义召回，并在模型或索引异常时回退词法结果。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="indexing"></a>
## 增量索引流程

`SemanticRetrieval` 继承关键词实现，只索引当前 source head 上的非派生片段。后台 `start` 周期调用 `indexBatch`，同一时间复用一个工作 Promise，正常时每秒追赶、出错后延迟 30 秒。每个长片段按 400 字窗口、320 字步长重叠切分，分批生成 passage 向量；全部向量准备好后才在事务中写入分片及 head 标记，从而避免半成品被视为已索引。[语义索引调度与事务写入 ↗](../../../apps/server/src/retrieval/semantic.ts#L34 "支持后台追赶、重叠窗口、批量嵌入和原子写入的流程说明。")

<a id="search"></a>
## 查询、融合与降级

查询先取最多 100 条词法候选；空查询或模型尚未加载时直接返回词法结果。模型可用后生成 query 向量，对同一片段的多个窗口取最高余弦分数，并在扫描过程中执行可见性和捕获时间过滤。词法与稠密分支通过基于排名的倒数分数融合，合并 `routes` 后稳定排序；嵌入或维度异常会记录健康错误并退回词法召回。[语义与词法融合搜索 ↗](../../../apps/server/src/retrieval/semantic.ts#L80 "支持过滤、最高窗口得分、RRF 融合及异常降级行为。")

<a id="boundaries"></a>
## 边界条件与依赖

窗口函数至少产生一个窗口，覆盖空文本；向量必须非空、有限且范数非零。读取旧向量时若维度与当前查询向量不同会明确报错，要求模型身份变化时建立新索引。该类依赖 `EmbeddingModel` 提供身份、query/passage 嵌入和关闭能力，也依赖 `KeywordRetrieval` 作为兼容基线；代码采用全量精确余弦，适用前提是个人 SQLite 资料规模。[窗口与向量校验 ↗](../../../apps/server/src/retrieval/semantic.ts#L122 "说明切窗边界和非法向量的显式失败条件。")
