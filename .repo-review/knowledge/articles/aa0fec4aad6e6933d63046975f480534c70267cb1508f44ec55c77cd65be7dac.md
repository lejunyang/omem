# source-profile · 模块理解

来源画像模块以确定性规则把固定来源修订及其有序片段转换为可重新派生的导航元数据，提供话语分类、标题关联、主题与语言候选、分代存储、最新版读取和失败降级；现有材料尚不能证明生产调用链、重建策略或下游消费效果。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-and-boundary"></a>
## 职责与证据边界

该模块为固定来源修订生成导航画像，记录载体类型、语言、标题层级、话语片段、主题与项目候选、时间提示、显式链接、覆盖缺口、证据片段引用及处理状态。[来源画像数据合同 ↗](../../../apps/server/src/source-profile/service.ts#L35 "支持画像包含的导航字段、派生标记及正常、部分、失败三种状态。") 数据库定义明确把画像定位为确定性、可重新派生且可能带有未知项的信息，而不是经过独立核验的新事实；画像生成失败也不得阻断原始证据读取。[派生画像的证据边界 ↗](../../../apps/server/src/storage/migrations.ts#L766 "支持画像可重新派生、并非已核验事实，且失败不得阻断原始证据读取。") 因此画像适合辅助导航和候选发现，事实判断仍需回到固定修订及片段。

<a id="analysis-and-storage"></a>
## 规则分析、分代存储与迁移

生成时，服务读取指定修订和按 ordinal 排序的片段，执行分析后查询已有最大 generation、递增代次并写入画像。[画像生成与代次递增 ↗](../../../apps/server/src/source-profile/service.ts#L131 "支持服务读取修订和有序片段、执行分析、递增 generation 并持久化画像。") 分类器按代码形态、问句、约束、示例、定义、未来或历史提示及指令词区分话语类型。[话语分类规则 ↗](../../../apps/server/src/source-profile/service.ts#L75 "支持图片噪声、代码、问题、约束、示例、定义、计划、历史、指令和一般论断的规则分类。") 与此前引用混用的表述不同，Markdown 标题栈和最近父标题关联由独立的遍历逻辑完成：标题更新栈，非标题片段取得最近父标题后才进入分类和 segment。[标题栈、父标题与覆盖缺口 ↗](../../../apps/server/src/source-profile/service.ts#L271 "支持标题栈维护、非标题片段的最近父标题关联，以及图片、疑似表格和长片段的覆盖缺口登记。") 主题候选则明确由标题文本与全文分词所得的高频非停用词合并、去重和截断产生；这替代了仅凭 `tokenize` 导入便断言候选生成方式的旧论证。[主题候选生成逻辑 ↗](../../../apps/server/src/source-profile/service.ts#L305 "支持标题文本与全文高频非停用词共同形成主题候选，并证明所有片段参与主题分词。")

画像表以“来源修订 + 生成代次”为复合主键，并建立 generation 倒序索引。[画像表主键与倒序索引 ↗](../../../apps/server/src/storage/migrations.ts#L769 "支持来源修订和生成代次构成复合主键，并为最新版读取建立代次倒序索引；也支持判断固定 generation 1 可能冲突的前提。") 此前若将表定义直接表述为“迁移已经应用”，现改为条件化结论：只有迁移入口被调用、历史校验通过且目标版本高于初始版本时，相应 statements 才会在事务中执行。[数据库迁移执行条件 ↗](../../../apps/server/src/storage/migrations.ts#L1104 "支持迁移需经过版本与历史校验，并仅在目标版本较新时于事务中执行，避免把迁移声明误写成已执行事实。")

<a id="reading-and-limits"></a>
## 读取、降级与识别限制

`latest` 按 generation 降序读取指定修订的最新画像。`recordFailure` 固定尝试写入 generation 1，并吞掉记录失败自身的数据库异常；结合复合主键约束，已有同代记录时可能发生冲突而没有新的失败画像，因此“失败状态始终可查询”不能由当前材料推出。[画像表主键与倒序索引 ↗](../../../apps/server/src/storage/migrations.ts#L769 "支持来源修订和生成代次构成复合主键，并为最新版读取建立代次倒序索引；也支持判断固定 generation 1 可能冲突的前提。")[最新版读取与失败记录 ↗](../../../apps/server/src/source-profile/service.ts#L122 "支持最新版查询顺序、失败画像固定使用 generation 1，以及失败记录写库异常被吞掉的降级行为。")

语言只按汉字和拉丁字母计数粗分，项目候选取自正文上下文字段，显式链接取自带 URL 的内容部件；所有片段仍参与语言统计并成为 evidenceRefs。[语言、项目、链接与证据引用 ↗](../../../apps/server/src/source-profile/service.ts#L320 "支持语言的字符计数式粗判、项目与链接候选来源，以及所有片段编号进入证据引用并由缺口决定 partial 状态。") 图片占位、含竖线的疑似表格和超长片段会额外形成 coverage gap，使状态成为 `partial`。[标题栈、父标题与覆盖缺口 ↗](../../../apps/server/src/source-profile/service.ts#L271 "支持标题栈维护、非标题片段的最近父标题关联，以及图片、疑似表格和长片段的覆盖缺口登记。") 此处替代了“这些片段只登记缺口、不参与其他分析”的旧结论：它们仍进入全文主题统计，图片占位还会被分类为 noise，但实现没有进一步理解图片、表格或长文内部语义。[话语分类规则 ↗](../../../apps/server/src/source-profile/service.ts#L75 "支持图片噪声、代码、问题、约束、示例、定义、计划、历史、指令和一般论断的规则分类。")[主题候选生成逻辑 ↗](../../../apps/server/src/source-profile/service.ts#L305 "支持标题文本与全文高频非停用词共同形成主题候选，并证明所有片段参与主题分词。") 给定材料未展示生产调用方、重建调度和下游消费接口，故不能断言画像已实际影响召回、排序或阅读提示。
