# PDF 与 DOCX 的解析及捕获输入构造

该模块把 PDF 或 DOCX 字节转换为统一的 CaptureInput：先校验格式和大小并按内容哈希保存原件，再检查 Docling 运行环境、调用 Python 解析器，最后保存结构化结果与内嵌图片，返回 Markdown 正文及文档元数据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_and_boundary"></a>
## 解决什么问题

`documentInput` 位于文件接入与统一捕获之间：调用方传入文件字节和文件名，并提供数据目录及外部标识，函数返回 `CaptureInput`。模块只接收扩展名为 PDF 或 DOCX 的文件；空文件和超过 20,000,000 字节的文件会立即失败。基础校验通过后，原件先按内容保存，再检查本地 `docling` 运行时中的 Python；环境未准备时会给出安装提示，此时原件已经写入资产目录。参考 [输入校验、原件先行保存与运行时检查 ↗](../../../apps/server/src/imports/documents.ts#L36 "支持 documentInput 的参数和返回类型、文件格式与字节大小限制，以及原件在 Docling 环境检查前保存的执行顺序。")

<a id="conversion_flow"></a>
## 一次 PDF 导入如何完成

以 `documentInput(pdfBytes, "guide.pdf", dataDir, externalId)` 为例，处理过程如下：

```mermaid
flowchart LR
  A[校验扩展名与大小] --> B[保存原件]
  B --> C[检查 Docling 环境]
  C --> D[创建临时目录并写入文件]
  D --> E[调用 Docling 转换脚本]
  E --> F[校验 Markdown]
  F --> G[保存图片与结构数据]
  G --> H[返回 CaptureInput]
```

转换脚本最多运行 180 秒，标准输出缓冲上限为 50,000,000 字节。返回内容必须含非空 Markdown，且长度不超过 200,000；否则导入终止。参考 [临时转换与正文校验 ↗](../../../apps/server/src/imports/documents.ts#L54 "支持临时目录和输入文件的创建、Python 转换进程的执行限制、JSON 解析，以及 Markdown 内容校验。")

解析结果中的图片先从 Base64 解码并独立保存，块内原始图片字段随后被资产 ID 取代。更新后的完整解析结构也会独立保存。最终结果以 Markdown 作为文本 part，`upstreamVersion` 使用原件资产 ID；文档元数据记录解析器及其版本、原件和结构资产 ID，还包含原始文件名与 MIME 类型，以及页数和警告。参考 [图片、结构资产与捕获结果 ↗](../../../apps/server/src/imports/documents.ts#L75 "支持图片外置、结构数据保存，以及最终 CaptureInput 的正文、上游版本和文档元数据。")

<a id="storage_and_failure"></a>
## 资产复用、错误与清理

同步与异步资产保存函数都以字节的 SHA-256 十六进制摘要作为 ID，将内容写入 `dataDir/assets`。写入采用独占创建；同一内容已经存在时忽略 `EEXIST`，因此原件、结构和图片可以按内容复用。目录权限设为 `0700`，文件权限设为 `0600`。参考 [内容寻址资产存储 ↗](../../../apps/server/src/imports/documents.ts#L10 "支持同步和异步保存均使用 SHA-256 ID、独占写入、重复内容复用及目录和文件权限设置。")

临时目录创建后的转换阶段发生异常时，函数优先取标准错误的最后一个非空行作为对外消息，否则保留原错误信息。不论转换成功或失败，临时目录都会在 `finally` 中递归删除。格式判断来自文件名扩展名，正文上限按 JavaScript 字符串长度执行；解析器标准输出还必须是可解析的 JSON，且 `blocks` 必须可遍历。参考 [临时转换与正文校验 ↗](../../../apps/server/src/imports/documents.ts#L54 "支持临时目录和输入文件的创建、Python 转换进程的执行限制、JSON 解析，以及 Markdown 内容校验。") [图片、结构资产与捕获结果 ↗](../../../apps/server/src/imports/documents.ts#L75 "支持图片外置、结构数据保存，以及最终 CaptureInput 的正文、上游版本和文档元数据。") [错误转译与临时目录清理 ↗](../../../apps/server/src/imports/documents.ts#L110 "支持从标准错误提取消息、异常重新抛出和 finally 清理临时目录。")
