# 质量标注状态与飞书交互验收

该测试验证质量样本从待处理、跳过、修订到确认和冻结的关键状态变化，并以伪造消息适配器串联飞书卡片投递、操作者鉴权与事件去重。它覆盖服务内部的真实 SQLite 持久化协作，但不等同于真实飞书网络或并发场景验收。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-fixtures"></a>
## 测试解决的问题与样本模型

这组测试关注“人工质量标注是否可靠落库”：标注者既可以跳过样本，也可以修改草稿后重新进入队列；通过飞书卡片操作时，还必须避免越权确认和重复事件推进状态。测试样本包含固定来源定位、文本、溯源信息以及待审核标签，其中标签可表达抽取对象、自动应用开关和禁止副作用，呼应仓储层对 `extract / abstain / needs_context` 等标签结构的约束。参考 [质量样本夹具 ↗](../../../apps/server/tests/quality-annotation.test.ts#L33 "支持样本包含来源定位、溯源信息、抽取对象和安全约束等字段的说明。")、[标签结构约束 ↗](../../../apps/server/src/quality/repository.ts#L39 "说明仓储层允许的标签处置类型、对象类型以及自动应用规则。")

每个用例创建独立临时目录和 `Store`，结束后关闭数据库并递归清理目录，因此验证的是实际 SQLite 持久化路径，而非纯内存替身。参考 [临时数据库生命周期 ↗](../../../apps/server/tests/quality-annotation.test.ts#L68 "支持测试创建临时 Store、使用真实仓储并在结束时关闭数据库的论断。")

<a id="state-transitions"></a>
## 跳过、修订与数据集状态迁移

第一个用例断言 `skip` 操作把样本持久化为 `skipped`，且进度汇总只包含一个跳过项；随后以原标签摘要作为乐观并发前提修改草稿，样本重新回到 `pending`，标签摘要也必须变化。这说明修订不是覆盖后仍保持完成态，而是要求重新审核。参考 [跳过与重新入队 ↗](../../../apps/server/tests/quality-annotation.test.ts#L83 "直接支持跳过状态、进度汇总、修订后回到待处理以及摘要变化的断言。")

第二个用例创建两个样本并启动标注会话。第一个合法确认后，进度从两个待处理变成一个已确认、一个待处理；处理第二张卡后，会话进入 `completed`、清空当前样本，数据集随后可冻结，并汇总为两个已确认样本。参考 [会话完成与冻结 ↗](../../../apps/server/tests/quality-annotation.test.ts#L218 "支持第二个样本处理后会话完成、当前样本清空及数据集冻结的行为。")

<a id="delivery-security-and-limits"></a>
## 卡片投递、安全约束与覆盖边界

测试通过 `QualityLarkAnnotationService`、投递仓储和投递 worker 串起“启动会话→生成待发送任务→发送卡片”的流程。伪消息适配器记录发送参数并返回固定消息号；断言确认按钮携带既定协议与动作，同时整个卡片序列化结果不泄露连接密钥。参考 [卡片投递与密钥保护 ↗](../../../apps/server/tests/quality-annotation.test.ts#L174 "支持投递 worker 成功发送卡片、动作协议正确且卡片不包含客户端密钥的断言。")

入站事件方面，测试明确拒绝非绑定所有者的伪造操作，且拒绝后进度不变；合法事件只推进一次，同一事件号重放时返回 `duplicate: true`。参考 [操作者鉴权与事件去重 ↗](../../../apps/server/tests/quality-annotation.test.ts#L197 "支持伪造发送者被拒绝、合法事件推进状态以及重复事件不重复处理的论断。")

覆盖仍有边界：发送端是本地 fake，`update` 为空实现，因此没有验证真实飞书 API、网络失败、卡片更新或重试；测试也未构造错误标签摘要来验证并发冲突。第二张卡变量名为 `abstainValue`，但最终进度记录为两个 `confirmed`，仅凭当前材料无法判断这是“放弃动作也计为已审核”的产品语义，还是命名与统计语义不一致。参考 [第二张卡的统计结果 ↗](../../../apps/server/tests/quality-annotation.test.ts#L229 "支持第二个动作取自名为 abstain 的卡片值、处理后确认数变为两个这一待澄清现象。")
