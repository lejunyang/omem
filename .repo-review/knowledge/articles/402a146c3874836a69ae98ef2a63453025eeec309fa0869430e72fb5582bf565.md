# 角色运行网关

统一角色资产、可信上下文、模型传输、工具边界、预算、结构化输出校验、有限修复与可追踪运行证据，是角色执行的核心编排层。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="prompt"></a>
## 提示构造与信任分层

网关先按合同解析上下文并核对角色身份，把 inline 技能、输出 schema、可信元数据和材料索引放入可信提示区；既有文章、草稿等派生知识以及材料正文则明确标为不可信数据。图片会校验 Base64、SHA-256 和文件签名，累计图片字节及文本字符也有上限。最终对提示块和完整上下文分别生成稳定摘要。[可信提示与材料分层 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L106 "支持 inline 技能、输出合同、可信上下文、派生知识和原始材料的分区组装。")[图片与提示容量校验 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L81 "支持图片真实性、媒体类型、累计字节限制及文本上下文粗粒度限制。")

<a id="setup"></a>
## 运行前装配与能力约束

运行入口加载角色包、合并预算并要求 profile 匹配；当前只接受永不复用会话的策略。清单允许的托管工具必须全部由宿主提供，且只有 ACP 能使用；随后建立按运行隔离的工作区，计算技能和工具摘要。[角色运行前置装配 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L247 "支持预算合并、profile 与会话策略检查、托管工具约束及工作区准备。")

<a id="execution"></a>
## 传输、预算与运行请求

每次尝试都会重新渲染提示并检查输入预算。ACP 获得内容块、MCP 服务、预期 native 技能、输出字符限制及上下文预算；权限或补充输入请求只被记录为拒绝事件。CLI 不接受图片，只接收合并文本。运行后记录会话、usage，以及 ACP 实际报告的模型和推理强度。[ACP 与 CLI 执行分支 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L302 "支持输入估算、ACP 参数传递、运行请求记录、实际配置回读，以及 CLI 图片限制。")

<a id="validation"></a>
## 输出校验、修复与追踪

输出必须是单个 JSON 对象，通过所声明的 Zod 合同，并在适用时匹配作业及角色身份。[结构化输出解析 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L210 "支持 JSON 对象要求、合同解析和作业及角色身份一致性检查。") 输出预算、引用后验校验或结构校验失败时，只对指定的输出类错误进行有限次数的完整重生成；取消及其他运行错误直接传播。成功 trace 汇集包、提示、上下文、技能、工具、模型、会话、预算和修复次数，并生成可复现指纹。[运行追踪与有限修复 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L365 "支持输出后验校验、追踪字段、指纹构造及可修复错误的重试边界。")
