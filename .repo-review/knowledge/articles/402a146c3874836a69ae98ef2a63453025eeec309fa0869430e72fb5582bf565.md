# 角色 Agent 的安全运行网关

RoleRuntimeGateway 把角色包、上下文、工具和模型传输统一成一次可验证、可追踪的运行：先划分可信指令与不可信材料，再调用 ACP 或 CLI，最后按角色合同校验结果；原生研究还要求通过专用提交工具交付。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 它解决什么问题

不同角色需要不同提示词、技能和输出合同，但都必须安全地读取用户材料并交回机器可处理的结果。网关用角色清单选择对应的 Zod 输出模式，使提取、评审、规划、知识写作等任务共享一套执行入口。参考 [输出合同映射 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L36 "支持不同角色输出由统一模式表选择并校验的说明。")

提示构造时，角色说明、内联技能、输出合同和经过校验的上下文进入**可信块**；文章草稿、既有研究等派生内容以及原始材料被移到单独的**不可信块**。这样，材料中的命令仍是待分析数据，不会与系统职责混为一层。参考 [角色与技能可信块 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L130 "支持上下文先校验、角色身份核对以及内联技能进入可信提示的说明。") [材料信任分层 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L170 "支持派生知识和原始材料被标记为不可信数据并与可信上下文分开的说明。")

<a id="call-flow"></a>
## 一条代表性调用如何完成

以调用方请求 `code-analyst` 为例：输入包含角色名、Agent 配置、上下文，可选预算、输出复核器与研究环境工厂。网关先加载角色包、合并预算并核对角色与配置；启用原生研究时必须使用 ACP，技能改为原生发现，并在独立工作区创建带工具和提交入口的研究环境。参考 [角色运行输入 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L287 "支持代表性调用所需角色、配置、上下文、预算、复核器和研究工厂等输入。") [运行环境准备 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L303 "支持角色包加载、预算合并、原生研究限制、独立工作区与研究环境接入流程。")

```mermaid
flowchart LR
  A[角色与上下文] --> B[加载角色包并准备工作区]
  B --> C[渲染可信指令与不可信材料]
  C --> D[ACP 或 CLI 执行]
  D --> E[取得提交结果]
  E --> F[合同与引用复核]
  F --> G[结果与运行轨迹]
```

每次尝试都会重新渲染提示；ACP 可接 MCP 服务、原生技能、权限判断和会话事件，CLI 则只接收拼接后的文本。普通模式从模型文本收集 JSON；原生研究模式忽略聊天正文，只接受研究环境中 `submit_result` 保存的对象。参考 [ACP 与 CLI 执行 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L380 "支持每轮提示渲染、两种传输分支以及 ACP 工具、权限和事件接入的说明。") [提交与结果复核 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L473 "支持原生模式必须使用提交入口、普通模式预算检查及二次领域校验的说明。")

<a id="boundaries"></a>
## 失败边界与模块关系

输出必须是完整 JSON 对象，通过角色模式，并在适用时匹配任务与角色；调用方还能用 `validateOutput` 做引用等领域校验。只有输出格式、模式或引用类错误进入有限次数的修复循环；取消、传输故障等错误立即上抛。成功时返回结果、角色包及包含模型、技能、工具、会话、用量和多种哈希的轨迹；无论成功失败，研究环境都会关闭。参考 [提交与结果复核 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L473 "支持原生模式必须使用提交入口、普通模式预算检查及二次领域校验的说明。") [轨迹、修复与清理 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L496 "支持成功轨迹字段、可修复错误范围、重试耗尽以及最终关闭环境的说明。")

网关上游依赖角色包注册表与调用方提供的上下文，下游连接 `agents` 中的 ACP/CLI，并通过摘要工具形成可复现指纹。工具白名单必须与实际提供的 MCP 服务一致，CLI 不能使用托管工具，当前也明确不支持会话复用。图片还会检查 Base64、SHA-256 与 PNG/JPEG/WebP 文件头，并限制总字节数。若要新增输出类型，修改模式映射；要改变信任分层，修改提示渲染；要调整执行、重试或轨迹，则从 `run` 主循环进入。参考 [工具与会话限制 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L328 "支持配置匹配、禁止会话复用、托管工具必须实际提供且仅 ACP 可用的边界。") [图片完整性检查 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L105 "支持图片 Base64、摘要和文件类型校验的说明；总量限制由提示渲染阶段继续执行。")
