# 角色运行时网关：受控提示组装、执行与结果校验

该模块将角色包、可信上下文、非可信材料、模型配置与工具策略收束为可审计的 Agent 运行流程：隔离并校验输入，选择 ACP 或 CLI 执行，验证结构化输出，有限修复可恢复错误，并记录边界明确的追踪与运行指纹。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_and_prompt"></a>
## 信任边界与提示构造

网关把角色规范、内联技能、输出合同、任务元数据和材料来源索引放入可信提示区；派生知识与材料正文则明确包装为非可信数据。说话者、时间、回复关系和转发状态可作为可信来源元数据保留，但正文不会因此获得指令权限。[可信提示与非可信材料分层 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L106 "支持角色、技能、输出合同和来源索引进入可信区，而派生知识及材料正文作为非可信数据处理的论断。")

图像进入模型前会检查 Base64 可逆性和 SHA-256 摘要，并分别验证 PNG 签名、JPEG 的 `FF D8` 起始字节以及 WebP 的 RIFF/WEBP 标记；因此“校验 JPEG 完整文件头”的旧结论已被替代。[图像内容与类型校验 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L81 "支持 Base64、摘要及三种图像格式的具体校验方式，并限定 JPEG 只检查起始字节。") 提示构造还累计文本字符数与图像字节数，超过角色上下文上限或 10 MB 图像总量即拒绝，并为提示块和上下文生成稳定摘要。[提示块与上下文预算 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L173 "支持文本和图像进入提示块、图像总量限制、文本预算以及提示与上下文摘要的说明。")

<a id="execution_flow"></a>
## 执行、校验与修复流程

`run` 先合并预算，核对 profile、会话策略和托管工具，并装载原生技能；当前不支持会话复用，非 ACP 传输也不能使用托管工具。[角色执行前置校验 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L247 "支持预算合并、profile 匹配、会话复用限制、托管工具约束和原生技能装载流程。") 每次尝试都会重新渲染提示并估算输入 token。ACP 可携带图像、MCP 服务和预期技能，并从会话配置回读实际模型与推理强度；CLI 仅传文本，遇到图像即拒绝，且此处没有最终配置回读。[重渲染、输入预算与传输分支 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L302 "支持每轮在执行 try 块之前重渲染和检查输入预算，以及 ACP 配置回读、CLI 文本限制等执行差异。")

输出必须是单个 JSON 对象，随后按角色清单指定的合同解析，并检查适用的 job、role 与修正来源一致性。[输出合同映射 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L25 "支持网关维护合同名称到知识、提案、评估和回答等 Zod schema 的映射。")[基础输出解析与一致性检查 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L210 "支持单一 JSON 对象要求、按清单选择 schema，以及 job、role 和修正来源一致性检查。") 调用方还可用 `validateOutput` 做引用等附加校验并返回规范化结果。[附加输出校验 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L365 "支持输出预算检查后调用 validateOutput，并将附加校验失败转换为角色输出引用错误。") 修复范围现明确限定为：执行 `try` 块内抛出的 `ROLE_OUTPUT_` 前缀错误，以及其中的 `SyntaxError` 或 `ZodError`，且仅在未取消、仍有修复次数时重试。[输出修复判定 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L396 "支持执行 try 块内可修复错误的条件，以及取消、非输出错误和次数耗尽时的失败行为。") 重渲染和输入预算检查位于该 `try` 之外，所以修复提示增长导致的 `ROLE_CONTEXT_BUDGET_EXCEEDED` 不会再次进入修复；这替代了“所有 `ROLE_OUTPUT_` 错误均可修复”的过宽结论。[重渲染、输入预算与传输分支 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L302 "支持每轮在执行 try 块之前重渲染和检查输入预算，以及 ACP 配置回读、CLI 文本限制等执行差异。")[输出修复判定 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L396 "支持执行 try 块内可修复错误的条件，以及取消、非输出错误和次数耗尽时的失败行为。")

<a id="trace_and_boundaries"></a>
## 追踪、稳定身份与运行边界

成功 trace 保存角色包、提示、上下文、技能和工具摘要，并记录有效模型与 effort 原值、会话标识、usage、预算估算及修复次数。运行指纹范围更窄，只由五类摘要以及 model、effort 构成，不包含会话标识、usage 或修复次数；“全部追踪字段共同生成指纹”的旧结论已被替代。[运行追踪与指纹组成 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L368 "支持 trace 原值字段与摘要字段的区分，并限定运行指纹只包含指定摘要以及模型和 effort。")

稳定摘要会递归规范化值、保持数组顺序、移除对象属性中的 `undefined` 并排序对象键，再对规范 JSON 计算 SHA-256。数组元素中的 `undefined` 不会被过滤，而会按 `JSON.stringify` 的数组规则表现为 `null`；这替代了“递归移除所有 `undefined`”的旧表述。[规范 JSON 与稳定摘要 ↗](../../../apps/server/src/storage/digest.ts#L3 "支持对象属性 undefined 过滤、对象键排序、数组顺序保持及 SHA-256 摘要，并据代码与 JSON 序列化语义限定数组中的 undefined。")

运行时请求仓库是可选依赖。[可选的运行时请求仓库 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L240 "支持 RuntimeRequestRepository 是角色运行时网关构造函数中的可选依赖。") ACP 权限或询问回调只有在仓库存在时才调用 `recordDenied`，后者把记录写为 `denied`；未配置仓库时不会在此处持久化。[ACP 运行时请求回调 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L323 "支持 ACP 回调通过可选链调用请求仓库，未配置仓库时不会执行记录。")[拒绝状态持久化 ↗](../../../apps/server/src/agent-runtime/requests.ts#L37 "支持 recordDenied 将权限或询问请求写入 runtime_requests，并把状态设置为 denied。")

<a id="contracts_and_open_point"></a>
## 共享合同与待确认事项

网关维护输出合同名称到具体 Zod schema 的映射，并按角色清单选择验证器；知识引用、问题、文档和批次结构本身也由共享知识合同约束。[输出合同映射 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L25 "支持网关维护合同名称到知识、提案、评估和回答等 Zod schema 的映射。")[基础输出解析与一致性检查 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L210 "支持单一 JSON 对象要求、按清单选择 schema，以及 job、role 和修正来源一致性检查。")[知识输出共享合同 ↗](../../../packages/contracts/src/knowledge.ts#L3 "支持知识引用、问题、文档和批次结构由共享 Zod 合同统一约束。")

当前 ACP 分支会用运行端配置更新 trace 中的有效模型与 effort，而 CLI 分支继续使用 profile 初始化值。由于现有材料没有给出 CLI 适配器的返回合同，尚不能确认这些字段对 CLI 而言代表“请求配置”还是“最终实际配置”。[重渲染、输入预算与传输分支 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L302 "支持每轮在执行 try 块之前重渲染和检查输入预算，以及 ACP 配置回读、CLI 文本限制等执行差异。")[运行追踪与指纹组成 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L368 "支持 trace 原值字段与摘要字段的区分，并限定运行指纹只包含指定摘要以及模型和 effort。")
