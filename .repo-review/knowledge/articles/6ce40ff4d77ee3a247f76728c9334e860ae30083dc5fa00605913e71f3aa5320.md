# docs-design.md · 模块理解

该文档是 omem 第一轮产品与系统架构提案的入口，定义证据驱动的长期记忆体验、权威数据边界、模块化部署、自治治理闭环及首版验收目标；它明确不等同于当前实现。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role"></a>
## 职责与设计背景

本模块为 omem 建立产品与架构基线：把外部材料保存为可引用证据，把任务过程沉淀为可复盘经历，再将稳定经验组织成知识和方法。其核心不是累计记忆数量，而是让旧问题更快解决、材料变化后停止沿用旧结论，并使重要回答能回到具体证据。面向用户的主链路是从结论下钻原文、继续沿引用探索、就地追问后返回原阅读位置。[长期记忆目标与证据阅读体验 ↗](../../../docs/design.md#L9 "支持模块为何存在、核心体验链以及以任务效果而非记忆数量衡量成功的论断。")

不过它的身份是可评审的首轮设计与交互原型，不是运行能力清单；当前实现、已确认决策和视觉规范分别由其他文档承载。[设计提案的状态边界 ↗](../../../docs/design.md#L5 "说明本文是第一轮架构与原型设计，并指向实施状态、决策和视觉规范，支持不能把设计当成现状的判断。")

<a id="architecture"></a>
## 权威数据、适配能力与阅读方式

设计把 PostgreSQL 中的来源、版本、片段、记忆和关系，与对象存储中的原件及快照共同视为权威集合；搜索索引、检索框架和反思引擎只是可替换、可重建的投影或候选生成器。Markdown 服务于人工编辑和导入导出，Git 是版本化导出目标，而非在线事务协调器。[权威数据与导出边界 ↗](../../../docs/design.md#L35 "支持 PostgreSQL、对象存储、Markdown 和 Git 各自承担的职责，以及索引只是可替换投影。")

WeKnora、Hindsight 等适配器提供检索或经历巩固能力，但不直接决定事实是否生效；即使外部引擎失效，核心存储仍应支持证据读取与定位。引用图允许成环，却只按当前节点的一跳关系加载，并把路径和正文分离，从而支持深入阅读而不一次返回整图或塞满模型上下文。[外部适配器与按需引用图 ↗](../../../docs/design.md#L41 "支持外部检索或反思引擎不掌握事实权威、核心检索可降级，以及引用图按一跳展开的架构关系。")

<a id="workflow"></a>
## 自治闭环与跨模块协作

运行闭环依次观察材料与反馈、筛选长期价值、组织主张和方法、验证版本与支持性、应用可信变更、按任务检索、记录结果，再用失败簇改进策略。确定性校验负责守住写入合同，模型只辅助语义抽取、冲突分析和策略改进；部署上因此采用共享领域契约的模块化单体，由一个 API 与一个 worker 代码库承载采集、治理、检索和交互等逻辑职责。[模块化单体部署 ↗](../../../docs/design.md#L91 "支持 API 与 worker 共用领域契约、逻辑职责不必拆为多套微服务，以及仅语义步骤调用模型。")[自治学习八步闭环 ↗](../../../docs/design.md#L108 "支持观察、选择、组织、验证、应用、使用、反馈和改进的端到端流程，以及确定性校验与模型辅助的分工。")

自治并不等于无边界执行：有可定位原文且不存在同域冲突的普通更新可自动提交；无法消解的冲突、跨域泛化和核心规则修改进入判断队列，批量硬删、扩权或外发资料需要明确确认。学习主要改变数据组织、检索配置与方法，不代表自动训练模型权重。[自动执行的风险边界 ↗](../../../docs/design.md#L119 "支持普通可信更新自动化、高风险动作需判断或确认，以及学习不等于模型权重训练的限制。")

<a id="progress"></a>
## 首版进展口径、验收与限制

规划上，P0 验证开源引擎和片段映射，P1 覆盖材料与经历双主线、外部 Agent 读写、引用阅读、真实问答、自动整理和变更恢复。验收强调深层下钻与环路稳定、引用跨版本不漂移、异常状态可见、引用可解析且确实支持论断、真实轨迹闭环，以及外部引擎失效时仍可读取和重建权威证据。[P0/P1 范围与核心验收 ↗](../../../docs/design.md#L155 "支持首版阶段安排及深链、引用稳定、真实闭环和引擎降级等验收目标。")

现有材料只能证明这些是设计目标，不能证明已经落地：文档明确原型仅模拟交互和本地状态，且不冒充已连接模型或生产数据库。要判断真实进展，仍需把每项验收要求关联到实施状态、行为测试、运行配置及实际执行记录。[原型不代表真实接入 ↗](../../../docs/design.md#L165 "支持当前材料不能证明模型、生产数据库和规划能力已经落地的限制判断。")
