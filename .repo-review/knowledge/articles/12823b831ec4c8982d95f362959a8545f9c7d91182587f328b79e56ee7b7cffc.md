# 代码高亮的跨行状态与安全转义测试

这组测试验证代码高亮在按行展示时仍能保留跨行语法状态，并确保已知及未知语言的输入标记都不会作为原始 HTML 输出。它覆盖核心正确性与基础注入防护，但未验证全部语言别名、并发加载及实际页面集成。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决按行展示与不可信代码输入的问题

代码阅读界面通常要把高亮结果拆成带行号的多行；若直接按换行符切割，跨行注释等语法生成的 `<span>` 可能在行间断裂。同时，代码内容可能含有看似 HTML 的文本，渲染前必须保证它不会变成真实标签。本测试以 TypeScript 跨行注释和带事件属性的图片标签为代表，分别守住显示正确性与安全转义两条底线。参考 [测试入口与跨行场景 ↗](../../../packages/ui/src/highlight.test.ts#L1 "支持测试直接组合调用高亮与分行函数，并以 TypeScript 跨行注释验证逐行展示结果。")

<a id="flow"></a>
## 从高亮结果到独立行片段

测试先调用异步高亮，再将返回的 HTML 交给分行函数，断言最终得到三行、第二行仍带注释样式、第三行能识别 `export` 关键字。实现侧会按语言别名动态注册语法；分行时维护尚未闭合的 `<span>` 栈，在每个换行处临时闭合标签，并在下一行重新打开，因此每一行都是可单独渲染的有效片段，同时保留词法状态。参考 [语言加载与高亮流程 ↗](../../../packages/ui/src/highlight.ts#L25 "说明已知语言经过别名解析、按需注册后交由 highlight.js 生成安全的高亮 HTML。") [跨行标签栈 ↗](../../../packages/ui/src/highlight.ts#L35 "支持分行函数在换行处闭合并重新打开 span，从而保留跨行词法状态且让每行 HTML 独立有效。")

<a id="coverage"></a>
## 已覆盖边界与仍未覆盖的行为

安全用例同时遍历已知语言 `ts` 与未知语言：前者经过高亮库，后者走显式转义回退；两条路径都不得保留真实 `<img`，且必须出现 `&lt;`。参考 [已知与未知语言的转义断言 ↗](../../../packages/ui/src/highlight.test.ts#L11 "支持两条语言处理路径都不会输出真实图片标签，并会将小于号编码。")

现有断言尚未覆盖空字符串、大小写语言名、其余别名、XML 额外语法加载、重复或并发注册，以及畸形高亮 HTML。材料也没有展示这些函数在 Vue 页面中的调用，因此无法据此确认行号渲染、样式注入方式或浏览器端焦点行为。

<a id="relationships"></a>
## 与高亮实现的关系

该测试直接依赖同目录的 `highlightCode` 与 `highlightedLines`：前者负责语言选择、动态加载和安全输出，后者负责把高亮 HTML 转成逐行片段。测试证明两者组合后的关键结果，却没有隔离断言各自的全部合同；若未来更换高亮引擎，只要跨行样式和转义结果保持一致，这些用例仍可作为面向行为的回归保护。参考 [测试入口与跨行场景 ↗](../../../packages/ui/src/highlight.test.ts#L1 "支持测试直接组合调用高亮与分行函数，并以 TypeScript 跨行注释验证逐行展示结果。") [跨行标签栈 ↗](../../../packages/ui/src/highlight.ts#L35 "支持分行函数在换行处闭合并重新打开 span，从而保留跨行词法状态且让每行 HTML 独立有效。")
