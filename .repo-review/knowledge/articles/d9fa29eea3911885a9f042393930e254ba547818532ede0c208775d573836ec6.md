# 助理运行时与 Lark 入口的治理行为测试

该文件以临时 SQLite、进程内模型实现和确定性的 Lark 事件环境，验证助理检索、任务写入、故障分类、待重试轮次恢复及消息路由的关键治理边界。测试还覆盖受控查询扩展、长证据窗口、任务时间闭环与应用收据，但不等同于真实 Agent CLI/ACP 或 Lark 平台链路的活体验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="intent-and-write-governance"></a>
## 意图识别与受控写入

测试区分明确的“记一下、提醒我、创建任务”和普通咨询。明确的所有者指令可经 `MemoryService` 创建任务；普通咨询即使收到模型提出的 `create_task`，服务端仍会因缺少明确任务意图而拒绝，保持任务表为空，并向用户说明未创建任务。模型输出只是提案，最终副作用取决于运行时治理和真实写入结果。[明确任务意图与咨询零写入 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L98 "支持明确所有者指令可以创建任务，而普通咨询中的模型写入请求会被拒绝并保持零任务写入。")

治理也覆盖跨轮上下文和取消边界：首轮检索到的证据可供下一轮“按这个记一下”引用；不存在的片段不能支撑任务创建；轮次取消后才返回的创建请求会被写入栅栏拦截。[跨轮证据复用与取消写入栅栏 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L547 "支持上一轮证据进入后续任务上下文、不存在的引用导致零写入，以及取消后的迟到创建请求不得落库。")

<a id="retrieval-visibility-resilience"></a>
## 检索、可见性与故障恢复

检索测试证明中文短语可借助共享二元片段召回会议记录，而无关查询不会命中。[中文短语召回与无关查询隔离 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L466 "支持中文短语召回相关片段，并证明该测试中的无关查询不会误召回会议材料。") 受控扩展允许模型提出一次英文检索词以找到跨语言原始材料，但首轮附带的写操作不会执行，第二轮提出的新查询也不再扩展。[受控的跨语言查询扩展 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L895 "支持仅进行一次查询扩展、用英文检索词补充原始证据，以及第一轮模型提出的写操作不被执行。") 长证据会围绕语义命中位置截取到预算内，并能在下一轮继续保留预约码等关键信息。[长证据的语义窗口保留 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L914 "支持在证据长度预算内保留语义命中内容，并在下一轮工作上下文中继续使用。")

群聊在未注入策略时默认无证据；另一个策略用例观察到私人会话可看到私人笔记，而以“群内公开”为查询的群聊结果只包含当前群材料、未出现私人内容。由于该群聊查询本身不匹配私人笔记，此结果尚不能单独证明策略过滤了一个原本可召回的私人候选。[群聊证据可见性场景 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L238 "支持群聊默认无证据，并记录注入策略场景中私人会话与群聊结果的实际差异；附近正文同时说明该查询设计不足以单独证明私人候选由策略过滤。") 模型不可用时轮次保持 `pending`、记录错误且不创建任务；普通异常则诚实降级并保持零写入。[模型不可用与普通异常分类 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L194 "支持模型不可用时轮次保持待重试、记录错误且零任务写入，也支持普通异常返回诚实降级结果。") 重复传输事件不会重复执行，新消息可取消旧轮次，悬挂模型也受超时约束。[事件幂等、并发取消与模型超时 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L362 "支持重复传输事件不重复执行、新消息取消旧轮次，以及悬挂模型在超时后结束且不写任务。") 成功写入会产生应用收据，已完成轮次不会被恢复；模型恢复后，待重试轮次可由 `retryTurn` 推进至完成。[应用收据与待重试恢复 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L621 "支持成功任务写入产生真实应用收据、已完成轮次不被恢复，以及待重试轮次在模型恢复后成功完成。")

<a id="lark-and-daily-workflow"></a>
## Lark 接入与日常任务闭环

Lark 测试环境先构造加密凭据引用、连接版本和所有者绑定，并明确标注为确定性接线、不使用真实 socket。[确定性且无真实连接的 Lark 环境 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L709 "支持凭据引用、连接和绑定的测试环境构造，并明确其不使用真实 socket，因而只能验证本地接线行为。") 随后把入站事件接入同一 `AssistantRuntime`：已绑定所有者私聊会生成回复投递意图并关联轮次；陌生发送者被忽略；群聊仅在提及机器人时进入助理，普通背景消息只做捕获；同一事件重投不会产生第二条回复意图。[Lark 主助理入口行为 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L733 "支持已绑定私聊、陌生发送者、群聊提及、背景捕获和重复投递的本地路由与出站意图断言。")

日常任务用例贯通创建、改期、完成和提醒抑制：带时区时间被转换为 UTC，任务版本随更新递增，完成后即使系统时间越过截止点也不再产生到期通知，三次变更均留下应用收据。用户看到的创建结果来自服务端确认，而不是模型自报成功。[任务时间与状态闭环 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L867 "支持任务创建、改期、完成、UTC 时间转换、版本递增、提醒抑制及应用收据数量断言。")

<a id="scope-and-gaps"></a>
## 测试范围与验证边界

模型侧使用 `ScriptedModel` 或测试内实现的 `AssistantModelPort`，按预设回复或异常驱动运行时。因此，本文件验证的是状态转换、写入治理和重试合同，不能据此确认真实 Agent CLI/ACP 的安装、鉴权、传输超时分类或网络表现。[进程内脚本模型夹具 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L72 "说明测试模型由进程内接口实现并按预设回复运行，支持其不能替代真实外部模型传输验证的边界判断。")

Lark 部分同样只证明本地入站路由、持久化、投递意图和事件幂等，不能确认平台长连接、真实事件重投、出站失败重试或最终送达。[确定性且无真实连接的 Lark 环境 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L709 "支持凭据引用、连接和绑定的测试环境构造，并明确其不使用真实 socket，因而只能验证本地接线行为。") 多进程竞争和数据库崩溃恢复等部署级行为也未在本文件中展示，仍需独立的活体或端到端验证。
