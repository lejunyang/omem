# 助手运行时治理与恢复测试

系统性验证助手从检索、证据可见性和模型生成到受治理任务写入的主流程，并覆盖幂等、超时、取消围栏、模型不可用重试、上下文隔离及 Lark 入口。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="governed-turn"></a>
## 受治理的对话写入

运行时先区分显式任务意图与普通咨询，再把模型的 `create_task` 视为待治理请求。明确 owner 指派可经 MemoryService 创建任务；咨询场景即使模型请求写入，也以 `not_explicit_task_intent` 拒绝并保持零任务。模型不可用会把轮次留为 `pending` 供重试，普通异常则返回诚实降级结果。[任务意图分类 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L98 "支持明确指派语句与普通咨询语句的基础分类边界。") [任务写入正反例 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L113 "支持显式 owner 请求可创建任务，而咨询时模型工具请求被治理层拒绝。") [模型失败语义 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L194 "支持模型不可用保持 pending、普通异常诚实降级，且两者均不创建任务。")

<a id="visibility-context"></a>
## 证据可见性与上下文连续性

群聊未注入策略时默认不给模型证据；注入策略后，仅当前群上下文材料可见，私人内容不会泄漏。关键词检索验证中文短语召回和无关查询不召回，同会话 correction 进入 trustedContext、不同会话隔离。两轮场景会复用首轮证据支撑下一轮任务，而不存在的片段引用不能产生写入。[群聊证据隔离 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L238 "支持群聊默认无证据以及注入策略后私人材料不会进入群聊结果。") [检索与修正作用域 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L466 "支持中文短语召回、无关查询不召回，以及 correction 仅进入同一会话作用域。") [两轮证据复用 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L547 "支持首轮检索证据进入第二轮工作上下文，以及伪造片段引用时保持零写入。")

<a id="concurrency-recovery"></a>
## 并发、取消与恢复

相同 transport event 只创建一个轮次和任务；同会话新消息会中断旧轮次。即使模型忽略 abort，超时也会使调用收敛；显式取消后，模型迟到返回的 `create_task` 无法越过提交围栏。恢复相关用例验证成功写入后确有 application receipt，且已完成轮次不会被 `recoverUnfinishedTurns` 重跑；它没有构造未完成轮次中 receipt 与 toolActions 冲突的场景，因此不能独立证明恢复判定依据。另一个用例直接证明模型恢复后 `retryTurn` 可把 pending 轮次推进为 done。[幂等与新消息取消 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L362 "支持 transport event 幂等，以及新轮次中断旧轮次而不产生旧任务。") [超时与取消提交围栏 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L441 "支持忽略 abort 的挂起模型仍会超时收敛，以及迟到工具请求无法越过取消围栏。") [Receipt 存在性与重试恢复 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L598 "支持成功任务写入后存在 receipt、完成轮次不会重跑，以及模型恢复后 retryTurn 成功；该范围未直接构造 receipt 与 toolActions 冲突的未完成轮次。")

<a id="lark-entry"></a>
## Lark 主助手入口

确定性 inbox 装配把已绑定 owner 的 P2P 消息路由到 AssistantRuntime，生成回复投递意图并关联回 turn；未绑定发送者被忽略且不产生投递。群聊仅在 owner 提及机器人时进入助手，普通背景消息只采集；重复 event id 不产生第二条回复意图。[Lark 入口路由 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L748 "支持绑定 owner、群聊提及、背景采集、未绑定发送者隔离和重复事件幂等行为。")
