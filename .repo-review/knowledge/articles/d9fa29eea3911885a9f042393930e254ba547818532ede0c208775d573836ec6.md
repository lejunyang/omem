# 助理运行时与 Lark 入口行为测试

隔离测试覆盖事项治理、证据可见性、轮次幂等与取消、检索上下文及 Lark 路由。修订后不再把测试名称视为“无假答案”的行为断言，并分别陈述 pending 状态、零写入与成功重试的实际证据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="task-governance"></a>
## 任务写入与证据治理

测试以临时 Store 和独立加密凭据目录隔离状态。[隔离测试夹具 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L23 "支持测试使用临时存储和独立加密凭据目录隔离运行状态。") 意图单测区分明确记录、提醒表达与普通咨询。[显式任务意图单测 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L98 "支持明确任务表达与普通咨询在意图检测中的区分。") 即使模型在咨询回答中请求 `create_task`，运行时仍拒绝动作并保持任务零写入。[咨询请求零写入 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L152 "支持咨询输入中的模型建任务请求被拒绝并保持零任务写入。")

群会话未注入可见性策略时默认看不到证据；测试中显式注入的策略可限制群聊只读取同一会话材料，避免私聊内容泄漏。[群聊默认证据拒绝 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L238 "支持未注入可见性策略时群会话不获得证据。")[群聊证据范围策略 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L267 "支持测试中显式策略按群会话上下文过滤证据并隔离私聊材料。") 这些用例证明测试场景中的运行时行为，但没有展示生产入口如何装配或审计该策略。

<a id="turn-resilience"></a>
## 幂等、取消与有限恢复证据

相同 transport event id 重放会复用既有轮次且不重复创建任务。[传输事件幂等 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L362 "支持相同 transport event id 不会创建第二个轮次或任务。") 新消息可以中断在途生成，忽略取消信号的模型也会在超时后收敛。[新消息中断与模型超时 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L402 "支持新轮次中断旧轮次，以及挂起且忽略信号的模型受超时约束。") 取消后的迟到建任务请求被写入栅栏阻断；正常创建会留下 application receipt，而已经完成的轮次重启后不会进入恢复集合。[取消栅栏与正常收据检查 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L598 "支持取消后迟到任务写入被阻断、正常完成存在真实收据，以及已完成轮次不会被恢复。")

`ModelUnavailableError` 用例直接断言轮次保持 `pending`、记录 unavailable 错误且没有任务写入，但没有直接断言 `turn.result` 为空或不含降级答复，因此不能据此声称已证明“不生成假答案”。[模型不可用的待处理状态 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L194 "支持模型不可用时轮次为 pending、记录错误且任务保持零写入；该范围未直接断言轮次结果内容。") 模型恢复后可通过 `retryTurn` 创建任务并把原轮次更新为 `done`，由组合测试另行证明。[待处理轮次成功重试 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L652 "直接支持模型恢复后 retryTurn 创建任务并把原轮次更新为 done。") 普通首次模型生成异常会产生明确降级答复并保持零任务写入。[模型生成异常的诚实降级 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L216 "支持普通首次模型生成异常返回降级答复并保持任务零写入。")

<a id="retrieval-and-entry"></a>
## 检索上下文、Lark 入口与日常流程

检索测试覆盖中文短语召回与无关查询排除；纠正按会话隔离，上一轮证据可供后续任务引用，不存在的引用会阻止写入。[中文召回与无关查询排除 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L466 "支持中文短语召回和无关查询不召回的行为。")[纠正隔离与跨轮证据 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L519 "支持纠正的会话作用域、上一轮证据复用及不存在引用导致零写入。") 日常流程验证带时区任务的创建、改期、完成和完成后不提醒；另有一次受限查询扩展，首轮模型提出的变更不会执行。[日常事项生命周期 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L867 "支持带时区任务的创建、改期、完成、收据计数和完成后抑制提醒。")[一次受限查询扩展 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L895 "支持一次补充检索，并证明首轮模型提出的任务变更不会执行。") 长材料测试确认语义命中片段在字符预算内保留，并可进入下一轮工作上下文。[长材料语义命中保留 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L914 "支持字符预算内保留长材料尾部命中，并在下一轮继续作为工作上下文使用。")

绑定 owner 的私聊会生成回复、创建投递意图并关联 outbox，但测试未确认真实网络送达。[绑定私聊回复入队 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L774 "支持绑定 owner 私聊生成回复、创建投递意图并关联 outbox，但不证明真实送达。") 未绑定发送者会得到忽略结果，且不会创建投递意图。[未绑定私聊发送者被忽略 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L796 "直接支持未绑定发送者得到忽略结果并且不创建投递意图。") 对已配置群目标，只有具体的提及与后台捕获场景得到验证。[已配置群目标路由 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L811 "支持特定已配置群目标中提及消息进入助理、后台消息进入捕获的限定场景。") 重复 Lark 事件不会产生第二条投递意图。[Lark 重复事件去重 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L847 "支持相同事件重复处理时不会创建第二条投递意图。")
