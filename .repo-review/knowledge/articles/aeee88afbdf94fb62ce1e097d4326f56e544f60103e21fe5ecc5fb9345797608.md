# 问答运行编排与证据化保存

Runs 负责把固定证据、用户问题和 Agent 配置组织为一次可取消的异步运行，限制并发、上下文、图片与输出规模，流式记录事件，并将成功回答作为派生材料保存且关联回输入证据。它是配置、Agent 传输层与单用户存储层之间的编排器，不负责证明回答结论已经得到引用材料支持。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-state"></a>
## 解决的问题与运行状态

`Runs` 为一次问答维护内存态生命周期：每个运行包含状态、事件流、取消控制器、异步任务及可选回答版本标识，对外可查询或取消；关闭服务时会中止仍在执行的运行并等待所有任务收敛。[运行对象、查询、取消与关闭流程 ↗](../../../apps/server/src/runs.ts#L11 "支持 Runs 维护的内存状态、取消能力以及关闭时等待任务结束的说明。") 启动时最多允许两个并发运行，运行记录达到 100 条后仅淘汰一个非运行项，因此这是进程内的轻量调度与近期状态缓存，不是持久任务队列；进程重启后的运行历史恢复在材料中没有体现。[并发上限与运行记录淘汰 ↗](../../../apps/server/src/runs.ts#L39 "支持最多两个活动运行及达到容量后淘汰非运行记录的边界。")

<a id="input-and-dispatch"></a>
## 固定证据组装与 Agent 调度

启动流程先按 `profileId` 找配置，并用请求中的 model、effort 覆盖默认值；随后合并焦点与上下文标识、去重并逐项读取证据。若选区不属于首个固定证据文本，或序列化证据与选区超过 profile 的字符预算，就在调用 Agent 前失败。[配置覆盖、证据解析与文本预算 ↗](../../../apps/server/src/runs.ts#L52 "支持 profile 选择、model/effort 覆盖、证据去重读取、选区校验和上下文限制。") 提示文本明确限定只能引用所给 evidenceId；图片则从证据所属修订的 parts 中去重加载，累计上限为 10 MB。存在图片时只接受 ACP，避免 CLI 路径静默丢图。[提示构造与图片载荷约束 ↗](../../../apps/server/src/runs.ts#L86 "支持 evidenceId 引用约束、图片去重加载、总大小限制及 ACP 图片要求。") 最终依据 transport 调用 `acp` 或 `cli`，并把工作目录、内容、事件回调与取消信号传给传输层。[ACP 与 CLI 分派 ↗](../../../apps/server/src/runs.ts#L139 "支持 Runs 根据 transport 调用不同 Agent 通道并传递取消信号。")

<a id="output-and-persistence"></a>
## 输出控制、保存与证据关系

事件回调忽略取消后的内容，累计输出超过 25 万字符会主动中止；文本事件同时拼接为最终回答，权限事件则通过 Store 记录需要关注的事项。[事件累计与权限关注记录 ↗](../../../apps/server/src/runs.ts#L117 "支持输出预算、文本拼接及权限事件写入关注记录的说明。") Agent 正常结束后仍会检查取消状态和空回答，再调用 `capture` 将回答保存为 `source=agent`、`producerKind=derived` 的材料，并把新回答的每个 fragment 链接到全部输入证据，最后发出完成事件。[回答捕获、来源关联与完成声明 ↗](../../../apps/server/src/runs.ts#L157 "支持回答作为派生材料保存、链接输入证据以及未承诺语义验证的边界。") 这里保存的是可追溯的派生回答，并未把回答提升为独立事实权威；完成提示也明确说明“提供材料引用”不等于结论支持度已验证。

<a id="boundaries-and-relations"></a>
## 边界与模块关系

该模块依赖 contracts 提供问题校验类型和运行事件类型，依赖 Config 提供 profile 与 Agent 工作目录，依赖 agents 模块执行 ACP/CLI，依赖 Store 查证据、读图片、记录关注项、捕获回答和建立链接。[编排模块的直接依赖 ↗](../../../apps/server/src/runs.ts#L1 "支持 Runs 与 contracts、Config、Store、Agent 传输模块之间的静态依赖关系。") Store 的文件头明确当前底座是 SQLite 单用户实现，团队级约束仍属后续迁移，因此 Runs 也不应被理解为具备租户隔离。[单用户 SQLite 存储边界 ↗](../../../apps/server/src/store.ts#L4 "支持当前存储层为单用户基础、团队级约束尚未实现的判断。") 异常统一转为 `error` 事件；只要取消信号已触发，状态即归为 `cancelled`。但材料未包含相应测试文件，无法确认并发淘汰、预算临界值、取消竞态和部分保存失败是否已有自动化覆盖。[运行错误与取消归态 ↗](../../../apps/server/src/runs.ts#L188 "支持异常被转为 error 事件，以及取消信号决定 cancelled 状态的行为。")
