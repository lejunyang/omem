# 基于固定证据的问答运行管理

管理短生命周期 Agent 问答任务：校验固定证据与上下文预算，选择 ACP 或 CLI 执行，流式保存事件，并把最终回答作为派生材料回写且链接原始证据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="prepare"></a>
## 运行创建与证据约束

`Runs` 在内存中维护任务状态、事件、取消控制器和回答修订，最多允许两个任务并发；累计达到 100 条时仅淘汰一个非运行任务。启动时必须找到 profile 和全部 evidence，选区还必须确实出现在首个固定片段中。模型与 effort 可由请求覆盖基础 profile，但此文件本身未展示能力校验。[运行并发、profile 与证据校验 ↗](../../../apps/server/src/runs.ts#L19 "支持并发限制、profile 合并、固定证据存在性和选区一致性检查。")

提示上下文只序列化所选证据的 ID、标题、版本、current 状态和原文，并限制总字符数。图片从固定修订资产加载、按 assetId 去重，总字节不得超过 10 MB；包含图片时必须使用 ACP，禁止静默退化为纯文本 CLI。[文本与图像上下文预算 ↗](../../../apps/server/src/runs.ts#L70 "支持证据序列化、字符预算、图片总预算及 ACP 图像要求。")

<a id="execute"></a>
## 流式执行、取消与输出预算

运行根据 transport 调用 ACP 或 CLI，并通过统一 emit 记录 status、text、permission 事件。累计事件超过 250000 字符会中止；权限请求同时写入 attention 记录。取消信号会阻止继续追加事件，关闭管理器时会取消所有运行任务并等待其 Promise 收敛。[流式事件与取消控制 ↗](../../../apps/server/src/runs.ts#L110 "支持事件输出预算、权限记录以及 ACP/CLI 的统一执行和取消行为。")

<a id="persist"></a>
## 回答保存及证据关联边界

任务只有在未取消且得到非空回答后才保存结果。回答以 `source: agent` 捕获，provenance 明确标记 bot 和 derived，再把每个回答片段链接到全部输入证据；完成事件同时提醒“引用不等于支持度已验证”。因此这里保存的是可追溯派生回答，并未执行独立语义核验。异常或取消只改变内存状态并追加 error 事件，不会保存半成品回答。[派生回答捕获与证据链接 ↗](../../../apps/server/src/runs.ts#L157 "支持非空回答保存、派生 provenance、输入证据链接及失败状态处理。")
