# 受约束的 Agent 问答运行管理器

管理内存中的 Agent 问答任务，固定证据上下文、限制并发与输入输出预算，调度 ACP 或 CLI，并把成功回答作为派生证据保存和回链。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="validation-and-context"></a>
## 启动校验与固定上下文

`Runs` 在内存中维护运行状态、事件、取消控制器与回答修订标识，同时最多允许两个任务运行；累计达到一百条记录时只淘汰一个非运行任务。启动时必须找到配置档案，并允许问题覆盖模型和 effort。焦点与上下文标识去重后逐一解析为证据；选区必须真实包含在首个固定片段中，文本总量也不得超过档案预算。[运行容量与证据校验 ↗](../../../apps/server/src/runs.ts#L39 "支持并发限制、档案选择、证据解析、选区固定性及文本上下文预算的说明。")

发送给 Agent 的材料包含证据标识、标题、版本、是否当前及原文，并要求只能引用这些标识。图片从相关修订的 parts 收集、按资源标识去重，总字节数上限为一千万；只要存在图片就必须使用 ACP，禁止静默退化成纯文本。[Agent 输入与图片边界 ↗](../../../apps/server/src/runs.ts#L86 "支持固定材料提示、图片去重与总量限制，以及图片仅允许 ACP transport 的论断。")

<a id="execution-and-storage"></a>
## 执行、事件与结果归档

任务依档案 transport 调用 ACP 或 CLI，共用取消信号和事件回调。事件累计超过 25 万字符会中止；文本事件拼成最终答案，权限事件还会写入 attention 记录。取消、关闭及执行异常都转成终态事件，空答案也视为错误。[调度和事件预算 ↗](../../../apps/server/src/runs.ts#L117 "说明 ACP/CLI 分支、共享取消信号、输出预算和权限注意事项记录。")

成功回答通过 `Store.capture` 保存为 agent 来源，provenance 明确标记机器人身份和 derived 生产类型；随后将回答的每个片段链接到全部输入证据。完成事件特别提醒“提供材料引用不等于结论已验证”，说明此处建立的是来源关系，而不是自动确认论断可信度。[回答保存与证据回链 ↗](../../../apps/server/src/runs.ts#L159 "支持成功回答作为派生捕获保存、链接输入证据并产生完成或错误事件的流程。")
