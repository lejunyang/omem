# 基于固定证据的 Agent 问答运行器

管理受并发、上下文和输出预算约束的 ACP/CLI 问答运行，将回答作为派生来源保存，并保留其与输入证据的链接。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="lifecycle"></a>
## 运行生命周期与并发

`Runs` 在内存中维护运行状态、事件、取消控制器和回答 revision。最多允许两个并发运行；累计记录达到一百时会移除一个非运行项。`cancel` 发出中止信号，`close` 中止所有活动任务并等待 promise 落定，因此进程重启后这些运行状态不会由本模块恢复。[运行状态与并发管理 ↗](../../../apps/server/src/runs.ts#L11 "支持内存状态、并发上限、旧运行淘汰、取消和关闭等待的说明。")

<a id="context"></a>
## 固定证据与输入预算

启动时必须找到指定 profile 和全部 evidence，并将用户选择的 model、effort 覆盖到基础 profile；选区必须真实包含于首个固定 fragment。输入材料序列化时携带 evidence ID、标题、版本、是否当前及原文，并受 profile 字符预算限制。[证据选择与文本预算 ↗](../../../apps/server/src/runs.ts#L52 "支持 profile 覆盖、固定 evidence 校验、选区匹配和上下文字符预算。")

图片从固定 revision 的 parts 读取、按 asset 去重，总字节数不得超过一千万；当前只有 ACP profile 可接收图片，其他 transport 会明确报错，不会静默退化成纯文本。[图片上下文约束 ↗](../../../apps/server/src/runs.ts#L88 "支持图片去重、总字节预算以及仅 ACP 可接收图片的明确限制。")

<a id="execution"></a>
## 执行、保存与证据关系

运行按 transport 调用 ACP 或 CLI，累计事件文本超过二十五万字符会中止；权限事件另记为 attention。成功要求非空回答，随后回答以 `source: agent` 捕获，provenance 标为 derived，并把每个回答 fragment 链接到全部输入 evidence。完成事件明确提醒：材料引用并不等于结论支持度已经验证。[执行事件与派生回答保存 ↗](../../../apps/server/src/runs.ts#L110 "支持输出预算、权限记录、回答捕获、派生 provenance、证据链接和完成提示。")

异常统一转成 error 或 cancelled 状态并追加错误事件。本文件只按配置分派 transport，没有展示模型能力发现，因此不能据此认定用户覆盖的 model 与 effort 已在启动前得到兼容性校验。[传输分派与错误收束 ↗](../../../apps/server/src/runs.ts#L139 "证明这里只按 transport 调用 ACP 或 CLI，并将异常映射为取消或错误状态。")
