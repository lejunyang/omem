# 基于输入证据的 Agent 问答运行管理

该模块把输入证据、选区和图片组织为受预算约束的 Agent 请求，并管理流式事件、取消与结果保存。回答会关联本次使用的输入证据以便追溯，但关联关系本身不代表结论已经通过支持性验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-input"></a>
## 从输入证据发起问答

`Runs` 在进程内管理每次问答的状态、事件、取消控制器和回答标识。系统最多允许两个任务同时运行；记录达到 100 项后，新任务启动时会尝试淘汰一个已结束任务。参考 [运行状态与数量限制 ↗](../../../apps/server/src/runs.ts#L11 "支持运行记录位于内存、最多两个任务并发，以及达到数量阈值时尝试淘汰已结束记录的说明。")

焦点证据与上下文证据先按标识去重，再从存储读取。用户选区必须出现在焦点证据正文中；这能防止选区脱离所选材料，但不判断选区是否语义完整或唯一。参考 [Profile 合并与证据读取 ↗](../../../apps/server/src/runs.ts#L52 "支持 profile 覆盖值合并、证据去重读取及选区必须匹配焦点证据正文的说明。")

<a id="context-and-budgets"></a>
## 组装文本与图片上下文

证据正文会连同标题、版本和当前状态序列化，再与选区一起接受字符预算检查。角色指令、问题正文和外层提示虽然进入最终请求，但不属于这项 `maxContextChars` 计算。参考 [文本上下文预算 ↗](../../../apps/server/src/runs.ts#L70 "支持证据序列化字段、字符预算范围，以及最终提示还包含指令和问题文本的说明。")

图片从证据所属修订中收集，按资源标识去重，总原始字节不得超过 10 MB；资源缺失会使运行失败。图片上下文目前只支持 ACP profile，其他传输不会静默退化为纯文本。参考 [图片上下文限制 ↗](../../../apps/server/src/runs.ts#L88 "支持图片按资源去重、累计字节限制、资源缺失失败及仅 ACP 接收图片上下文的说明。")

<a id="execution-and-persistence"></a>
## 执行、保存与取消

运行依据 profile 选择 ACP 或 CLI。适配器产生的 `status`、`text`、`permission` 事件统一累计字符数，超过 250,000 字符即中止；文本事件拼接为最终回答，权限事件还会登记需要关注的请求。参考 [流式事件处理 ↗](../../../apps/server/src/runs.ts#L110 "支持事件字符预算、文本回答拼接及权限请求登记的说明。") [Agent 传输分派 ↗](../../../apps/server/src/runs.ts#L139 "支持依据 transport 调用 ACP 或 CLI，并在返回后检查取消状态与空回答。")

Agent 返回后，系统检查取消状态和空回答，再将有效回答保存为派生材料，并把回答片段链接到本次使用的全部输入证据。完成事件明确说明：材料关联提供可追溯性，不等于结论支持度已经验证。参考 [回答保存与输入证据链接 ↗](../../../apps/server/src/runs.ts#L159 "支持将回答保存为派生材料、链接本次使用的全部输入证据，并说明链接不等于支持性验证。")

单次取消会触发对应运行的中止信号；服务关闭时会中止所有运行中任务，并等待已登记的异步流程收尾。参考 [取消与服务关闭 ↗](../../../apps/server/src/runs.ts#L31 "支持取消指定运行，以及关闭服务时中止运行中任务并等待异步流程收尾。")

<a id="relations-and-limits"></a>
## 组件关系与当前边界

该模块处于问答编排层：问题合同约束输入与事件形态，配置提供 profile 和工作目录，Agent 适配器负责通信，存储层负责读取证据、加载图片、捕获回答并建立链接。参考 [问答编排依赖 ↗](../../../apps/server/src/runs.ts#L1 "支持该模块直接依赖问题合同、配置、存储及 ACP、CLI Agent 适配器。")

运行状态和事件只保存在当前进程内，现有回收逻辑也只在新任务启动且达到数量阈值时删除一个非运行项；跨进程保留和按时间清理策略尚无材料说明。参考 [运行状态与数量限制 ↗](../../../apps/server/src/runs.ts#L11 "支持运行记录位于内存、最多两个任务并发，以及达到数量阈值时尝试淘汰已结束记录的说明。")

请求中的模型与推理强度会覆盖 profile 默认值并交给适配器，但现有材料范围不足以确认启动前是否校验该组合确实受 profile 支持。参考 [Profile 合并与证据读取 ↗](../../../apps/server/src/runs.ts#L52 "支持 profile 覆盖值合并、证据去重读取及选区必须匹配焦点证据正文的说明。") [Agent 传输分派 ↗](../../../apps/server/src/runs.ts#L139 "支持依据 transport 调用 ACP 或 CLI，并在返回后检查取消状态与空回答。")
