# 实时检查的 ACP 模型选择器

先通过空会话探测 ACP 暴露的模型选项，再按环境覆盖、基础 profile 或当前默认值确定模型；显式请求不可用时拒绝降级，并把可选 effort 传入实时 profile。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="probe"></a>
## 能力探测与必要条件

`selectLiveProfile` 接收基础 AgentProfile 和工作目录，首先以空输入、空事件处理器调用 `acp`，把返回会话作为能力探针。它要求 ACP 暴露 id 为 `model` 且类型为 `select` 的配置项，再通过共享的 `optionValues` 展开候选值；如果模型不可选择，函数直接失败。[ACP 模型能力探测 ↗](../../../scripts/live-model.ts#L1 "支持空会话探测、select 类型要求及候选模型展开过程。") 这种做法让多个 live smoke 复用同一套实际能力发现逻辑，而不是假定某个本地模型必然存在。

<a id="selection"></a>
## 选择优先级与失败边界

模型选择顺序是：若设置 `OMEM_LIVE_MODEL`，只接受候选列表中的精确匹配；否则优先采用基础 profile 已配置且仍可用的模型，再退到 ACP 当前值或首个候选。最终没有模型会报错，显式请求未匹配也会报错，因此不会静默改用别的模型。[实时模型选择优先级 ↗](../../../scripts/live-model.ts#L20 "支持环境覆盖、基础配置、ACP 默认值的优先顺序及显式请求失败策略。")

返回值同时保留原始 probe，并复制基础 profile、覆盖选定模型，把 `OMEM_LIVE_EFFORT` 原样写入 effort。[选定 profile 返回值 ↗](../../../scripts/live-model.ts#L29 "支持保留 probe、覆盖 model 并传入环境 effort 的说明。") 但本文件没有像模型一样核验 effort 是否为 ACP 支持值；是否由后续 `acp` 校验，需要其余实现证据，当前材料不足以确认。

<a id="limits"></a>
## 适用范围

该辅助函数只负责实时脚本的模型 profile 组装，不执行具体学习或问答断言。探测本身会启动真实 ACP 会话，因此依赖外部 Agent CLI、工作目录和环境配置；AbortSignal 也未设置超时，若下游不结束，本文件没有独立的超时保护。[无超时的探测调用 ↗](../../../scripts/live-model.ts#L4 "支持探测使用新 AbortSignal 但本文件未设置超时的边界分析。")
