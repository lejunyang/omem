# 反馈整理角色提示词：认证反馈到纠正候选

该提示词要求把经过认证的所有者反馈转换为绑定原目标与证据的纠正候选，并区分不同反馈强度和语义类别。它禁止把重复反馈或生成摘要提升为独立权威，也禁止直接应用纠正或修改权限、采集范围、预算及自动批准规则。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="feedback-classification"></a>
## 反馈分类与权威来源

角色接收经过认证的所有者反馈，并将其整理为关联原始目标和证据的纠正候选。处理时需要区分强纠正、任务调整、范围约束、较弱的有用性信号和结果证据；重复反馈与生成摘要不能脱离原始材料成为新的独立权威。[认证反馈的分类与权威限制 ↗](../../../packages/agent-runtime/roles/feedback-curator/1/prompt.md#L3 "支持反馈须绑定原目标和证据、区分多类信号并禁止派生摘要成为独立权威。") 该规则旨在避免派生内容因重复出现而被错误强化。

<a id="output-and-guardrails"></a>
## 输出边界与受保护策略

角色只能返回一个 `CorrectionProposal.v1` JSON 对象，并须把纠正限制在给定范围内、保留未解决冲突。它不得修改权限、采集范围、预算或自动批准规则，也不得直接应用纠正。[纠正候选的输出与权限边界 ↗](../../../packages/agent-runtime/roles/feedback-curator/1/prompt.md#L5 "支持仅输出纠正候选、保持范围和冲突，并禁止应用纠正或修改受保护策略。") 因而其定位是提出受证据约束的纠正候选，而非执行变更；材料未说明认证反馈如何进入角色或候选如何复核。
