# OmBadge 徽标组件

一个轻量 Vue 3 展示组件，以默认插槽承载内容，并通过 tone 属性提供中性、警告、危险和成功四种可选色调。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-flow"></a>
## 展示能力与渲染流程

OmBadge 提供统一的行内徽标容器和可选色调。组件以 Vue 3 `<script setup>` 声明 `tone` 属性，将取值限制为 `neutral`、`warning`、`danger`、`success`；调用方未传入时使用 `neutral`。这只能确认组件直接提供的色调接口与默认行为，不能据此推断它专用于某类业务状态或风险提示。[色调属性与默认值 ↗](../../../packages/ui/src/components/OmBadge.vue#L1 "支持组件提供四种 tone 取值以及默认采用 neutral 的接口说明。")

渲染时始终输出一个 `span`：固定应用 `om-badge` 基础类，同时把当前 tone 作为动态类；调用方提供的内容由默认插槽放入其中。[徽标模板结构 ↗](../../../packages/ui/src/components/OmBadge.vue#L7 "支持固定基础类、动态色调类和默认插槽共同构成渲染结构的说明。") 组件本身不生成文字、不解释 tone 的业务含义，也未包含点击等交互逻辑。

<a id="styles-and-boundaries"></a>
## 视觉规则与实现边界

基础样式把容器设为行内弹性布局并垂直居中，统一边框、内边距、圆角和 12px 字号；文字颜色及边框依赖 `--om-secondary`、`--om-line` 等外部 CSS 变量。`white-space: nowrap` 会阻止内容换行，但文件中没有最大宽度、溢出隐藏或省略号规则。[徽标基础样式 ↗](../../../packages/ui/src/components/OmBadge.vue#L10 "支持行内布局、尺寸规则、主题变量依赖以及内容不换行边界的说明。")

`warning`、`danger`、`success` 分别覆盖文字色和背景色，`neutral` 没有独立选择器，因此只使用基础样式。[三种专用色调样式 ↗](../../../packages/ui/src/components/OmBadge.vue#L21 "支持 warning、danger、success 具有专用颜色规则，而 neutral 仅沿用基础样式的结论。") 样式采用 `scoped`，其选择器影响被限定在该组件。当前固定材料未提供调用方、无障碍约定或测试，因而无法确认四种 tone、长内容和主题变量缺失时是否已有自动化或视觉覆盖；此前关于具体使用场景与设计动机的宽泛结论已被这一实现范围说明替代。
