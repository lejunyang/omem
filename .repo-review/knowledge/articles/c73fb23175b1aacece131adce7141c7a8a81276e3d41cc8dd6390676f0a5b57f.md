# 语义色调徽标组件

该 Vue 组件提供一个轻量内联徽标容器，通过 neutral、warning、danger 和 success 四种 tone 表达状态；内容完全由默认 slot 提供。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="api"></a>
## 组件接口与渲染

组件只暴露可选 `tone` 属性，允许 neutral、warning、danger、success，默认 neutral；模板把 tone 作为附加 class，并通过默认 slot 渲染调用方内容。[徽标属性与插槽模板 ↗](../../../packages/ui/src/components/OmBadge.vue#L1 "支持 tone 的允许值、默认值、动态 class 绑定和默认 slot 内容接口。") 因此它负责一致的视觉容器而不规定业务文案、图标或状态映射，具体语义仍由调用方选择。

<a id="styles"></a>
## 基础样式与状态色

徽标采用行内弹性布局、细边框、小内边距、圆角、12px 字号和不换行，基础文字色使用共享次要色变量。warning 与 danger 使用对应主题变量和浅色背景，success 使用固定前景色与背景色。[徽标基础与语义色样式 ↗](../../../packages/ui/src/components/OmBadge.vue#L10 "支持布局、尺寸、颜色变量以及 warning、danger、success 的具体视觉规则。") neutral 没有独立规则，沿用基础样式；组件也未在材料中声明 ARIA 属性，不能只依靠颜色承载必须被辅助技术识别的状态。
