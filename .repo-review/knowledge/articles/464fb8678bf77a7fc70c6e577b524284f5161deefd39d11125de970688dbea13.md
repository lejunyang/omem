# 服务端应用装配与 HTTP 接口边界

该模块是服务端组合根：创建 Fastify 与核心领域服务，注册捕获、检索、任务、记忆、质量、Lark、Agent 运行及助手接口，并统一管理访问控制和进程生命周期。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="assembly_security"></a>
## 服务装配与访问边界

`buildApp` 创建 Fastify、SQLite Store、运行记录、记忆与反馈服务，并把关键词检索和 ACP 模型适配器注入助手运行时；生产路径只选取 ACP profile，未配置或传输不可用时由模型层如实降级。[核心服务与助手装配 ↗](../../../apps/server/src/app.ts#L44 "支持 Fastify、Store、记忆服务、ACP 模型、关键词检索及 AssistantRuntime 的组合关系。")

非回环监听在启动时强制要求 token。对所有 `/api/` 请求，有 token 时比较 Bearer 凭据且使用定时安全比较；无 token 时同时校验 Host 和可选 Origin 必须为回环地址。统一错误处理把版本或陈旧状态冲突映射为 409、并发 probe 映射为 429，其余校验及应用错误返回 400。[API 请求鉴权与错误映射 ↗](../../../apps/server/src/app.ts#L126 "直接支持 Bearer token 的安全比较、无 token 时的 Host/Origin 回环限制及 HTTP 错误码映射。")

<a id="route_surface"></a>
## 领域接口与可信入口

前半部分路由承接健康检查、手工及文件/Git/Lark/hook 捕获、输入聚合、来源版本与证据查询、关系和搜索、资产读取、变更恢复、通知、任务与作业，以及运行请求、提案、决策、记忆和反馈。多数写入先通过共享合同或局部 Zod schema 校验，再委托 Store、MemoryService 等领域对象。[捕获、证据、任务与记忆路由 ↗](../../../apps/server/src/app.ts#L171 "支持健康状态以及捕获、检索、恢复、通知、任务、作业、提案、记忆和反馈等接口范围，也表明当前运行模式为 personal。")

后半部分提供质量数据集和 Lark 标注会话、Lark onboarding 与绑定、Agent profile 查询/probe，以及通用 agent run。Lark 或学习组件未配置时，相应接口不会伪装可用，而是明确报错或走基础仓储能力。[质量、Lark 与 Agent 运行路由 ↗](../../../apps/server/src/app.ts#L395 "支持质量标注、Lark 集成、profile probe 和通用 run 接口及其可选组件边界。")

Web 助手入口禁止调用方伪造 Lark 渠道、群可见性或 principal，服务端固定创建 owner、web、private 会话；发送、查询、取消和重试回合均交给同一 `AssistantRuntime`。[Web 助手会话接口 ↗](../../../apps/server/src/app.ts#L525 "支持 Web 身份与可见性由服务端固定，以及回合发送、查询、取消和重试均委托 AssistantRuntime。")

<a id="lifecycle_limits"></a>
## 启动、恢复与关闭

应用在返回前恢复遗留的 pending/running 助手回合，再启动提醒、输入聚合以及可选学习和 Lark worker；静态前端仅在构建目录存在时挂载。关闭钩子会停止定时器和助手，等待可选服务及 Runs 结束，最后关闭 Store。[应用启动恢复与资源清理 ↗](../../../apps/server/src/app.ts#L589 "支持静态资源挂载、未完成回合恢复、周期任务启动以及关闭时的资源释放顺序。")

该文件主要定义 HTTP 与生命周期边界，不实现连接器的路径安全、记忆治理或模型协议细节；这些行为由被注入模块负责。当前健康响应明确声明 `personal` 与 SQLite，因此这里不能据此推断多租户隔离已经实现。[捕获、证据、任务与记忆路由 ↗](../../../apps/server/src/app.ts#L171 "支持健康状态以及捕获、检索、恢复、通知、任务、作业、提案、记忆和反馈等接口范围，也表明当前运行模式为 personal。")
