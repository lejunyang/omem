# 真实 ACP 助理现场冒烟验证

在临时数据库和合成材料上调用选定的真实 ACP 模型，验证跨语言事实召回以及任务创建、改期、完成；报告写入配置数据目录，但不发送外部消息或写入用户数据库。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="live-boundary"></a>
## 现场验证边界与装配

脚本声明只使用合成材料，但会发起真实 ACP 调用；它创建临时 Store，选择 live profile，并强制模型为 `gpt-5.6-sol`。[真实模型与临时环境 ↗](../../../scripts/live-assistant-smoke.ts#L13 "支持脚本使用合成数据、真实 ACP 调用、临时 Store，并限定实际模型。") 随后捕获一条英文熔断器事实，将 AcpAssistantModel、KeywordRetrieval、MemoryService 和时区配置装入 AssistantRuntime，所有对话都在临时私有 web 会话中执行。[助理运行时现场装配 ↗](../../../scripts/live-assistant-smoke.ts#L23 "支持英文材料捕获以及 ACP 模型、记忆、关键词检索和时区的运行时装配。")

<a id="recall-and-tasks"></a>
## 跨语言召回与任务生命周期

中文提问必须选中原英文 fragment，回复还需包含连续失败次数 7 和冷却 41 秒。之后脚本以自然语言创建带明确时间的英语复习任务，断言北京时间被规范化为 UTC；再改期并标记完成，直接检查持久化任务的到期时间和状态。[召回与任务行为断言 ↗](../../../scripts/live-assistant-smoke.ts#L36 "支持跨语言证据命中、事实值检查及任务创建、改期和完成的持久化断言。") 这验证了真实模型参与下的端到端主路径，而不是仅验证模型输出文本。

<a id="report-and-limits"></a>
## 报告与未覆盖范围

每轮输入、答案、工具动作和选中证据都会进入报告；失败设置非零退出码，最终报告写到配置数据目录的 verification 子目录，并关闭、删除临时 Store。[现场报告与清理 ↗](../../../scripts/live-assistant-smoke.ts#L47 "支持失败退出、验证报告落盘以及临时资源清理行为。") 材料没有覆盖模型不可用后的重试、群聊权限、重复事件、取消栅栏、提醒实际投递或真实外部消息，因此这些能力仍需其他测试证明。
