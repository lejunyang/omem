# 真实 ACP 助手端到端冒烟脚本

该脚本用于在隔离的临时 Store 中，以合成记忆和任务请求驱动指定的真实 ACP 模型，并在成功运行时检查跨语言证据召回、任务创建、改期和完成。现有固定材料只描述脚本流程，未提供运行退出码或成功 trace，因此不能据此断言验证已经通过。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-setup"></a>
## 验证目标与隔离方式

脚本面向协议 fixture 之外的真实模型链路：它加载配置，在系统临时目录创建独立 Store，并声明只使用合成材料、真实 ACP 调用，不发送外部消息或写入用户数据库。随后从 `traex` 基础配置选择实时 profile，要求所选模型为 `gpt-5.6-sol`，并把模型与 effort 写入报告。[隔离初始化与模型约束 ↗](../../../scripts/live-assistant-smoke.ts#L13 "支持脚本使用临时 Store、选择实时 profile、约束目标模型并准备报告；同时说明材料只有流程定义，没有运行结果。")

运行时由 Store、MemoryService、关键词检索、ACP 模型适配器和 AssistantRuntime 组成，用来贯通捕获、检索、生成、对话及任务写入。[助手运行时组件装配 ↗](../../../scripts/live-assistant-smoke.ts#L23 "支持脚本把存储、记忆服务、关键词检索、ACP 模型和助手运行时串成同一验证链路。") ACP 适配器只接受 ACP transport；缺少 profile 或使用 CLI transport 时会明确报模型不可用，不生成伪造回退答案。[ACP 模型适配器边界 ↗](../../../apps/server/src/assistant/acp-model.ts#L10 "支持适配器只接受 ACP profile，并对缺少配置或 CLI transport 明确失败而不伪造答案。")

<a id="core-flow"></a>
## 核心场景与业务断言

脚本先捕获一条英文熔断器说明，再建立私有 Web 会话。统一的 `turn` 包装器调用运行时，要求输入消息引用状态为 `done`，并在该轮成功返回后记录回答、工具动作和所选证据。[统一对话执行与步骤记录 ↗](../../../scripts/live-assistant-smoke.ts#L29 "说明每轮如何调用运行时、检查消息引用状态，并在成功返回后记录回答、动作和证据。") 中文提问需要选中原始英文 fragment，回答还必须包含“7 次失败”和“41 秒”，从而在脚本成功执行时验证跨语言召回及证据落点。[跨语言召回断言 ↗](../../../scripts/live-assistant-smoke.ts#L36 "支持中文问题必须命中原始英文材料，并回答两个关键数值。")

后三轮依次创建英语复习任务、改期并标记完成，检查任务数量、换算为 UTC 的到期时间和最终 `done` 状态。[任务创建改期与完成断言 ↗](../../../scripts/live-assistant-smoke.ts#L39 "支持脚本检查任务数量、两次 UTC 到期时间以及最终完成状态。") 时间写入还受运行时约束：时间表达必须实际出现在用户消息中，`dueAt` 必须带时区且可解析，之后才转换为 ISO 时间。[任务时间校验规则 ↗](../../../apps/server/src/assistant/runtime.ts#L42 "支持服务端要求时间表达来自原消息，且到期时间必须带时区并可解析。")

<a id="boundaries-and-reporting"></a>
## 报告、清理与证据边界

主流程抛错时，脚本把报告标为失败并设置非零退出码；`finally` 再尝试写入 `verification/live-assistant.json`、输出摘要、关闭 Store 并删除临时目录。由于这些操作顺序执行，目录创建、报告写入或日志输出若再次抛错，后续资源释放并无无条件保证。[失败报告与资源清理顺序 ↗](../../../scripts/live-assistant-smoke.ts#L46 "支持异常状态、报告写入、日志输出和资源释放的实际排列，并揭示前序失败可能阻断清理。")

此前“该冒烟测试已经证明指定模型下真实 ACP 成功链路”的结论被替代：当前材料只能证明脚本**用于**执行这项验证，以及全部断言通过时会把状态设为 `passed`；没有实际运行报告、退出码或 trace，不能确认本次链路已经成功。[隔离初始化与模型约束 ↗](../../../scripts/live-assistant-smoke.ts#L13 "支持脚本使用临时 Store、选择实时 profile、约束目标模型并准备报告；同时说明材料只有流程定义，没有运行结果。") 它也不覆盖其他模型、认证失败、超时、通知发送、多任务歧义、版本冲突或越权场景。
