# omem 目标、现状与调研目录

文档以四类用户场景概括统一证据助手的目标和截至 2026-10-01 的进展，并明确更强召回、主动跟进与英语学习仍有缺口；后半部分是历史调研导航，不是现状清单。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="product-and-scenarios"></a>
## 统一材料库上的个人助手

omem 的核心定位是先保存可追溯材料，再基于同一材料帮助回答和办事；文档、代码、聊天与图片共用材料库，AST 只是代码定位层，Code Wiki、回答和学习卡都属于派生内容。[产品统一证据定位 ↗](../../../docs/2026-10-01/README.md#L1 "支持多来源共用材料库、AST 特化和派生内容不另建事实库的定位。") 四个场景展示了当前切片：统一引用链和跨语言检索已有验证；事项创建、改期、完成已跑通但仍限站内一次性提醒；来源由“重试 3 次”变为“5 次”时，真实模型验证了同一记忆更新且旧原文保留。[四类用户场景进展 ↗](../../../docs/2026-10-01/README.md#L5 "概括问答、跨语言检索、事项闭环和来源更新的当前验证结果与边界。")

<a id="remaining-work"></a>
## 仍待完成的三条主线

检索已经从词法路线扩展到 osdk 管理的中文 BGE embedding 和原片段分窗索引，但尚无语义重排；主动能力已有来源更新重核验和到期站内提醒，等待回复、临近截止、周期治理和外部提醒仍未接入。[三条后续工作主线 ↗](../../../docs/2026-10-01/README.md#L16 "支持更强召回、主动跟进和英语学习仍存在明确未实现项。") 英语学习只确定复用 Capture、固定原文引用、FSRS 与稳定 ID 导出方向，卡片、评分和复习页面尚未实现，不能把普通待办当作间隔重复。

<a id="evidence-status"></a>
## 目录的证据属性

后续 13 章和两份附录保存的是基于旧基线的详细调研，用于解释机制选择和证据边界；文档明确要求实际能力以实施状态页和代码为准。[调研与现状的分界 ↗](../../../docs/2026-10-01/README.md#L22 "明确旧调研只解释选择，当前能力应以实施状态和代码为准。") 因而章节中的建议、拟议数据模型和历史验证必须与当前实现区分。阅读时可先看决策、迁移、风险，再沿记忆、事项、学习或评测主题进入对应章节，最后用验证附录核对哪些结论只是历史记录。[调研阅读路径 ↗](../../../docs/2026-10-01/README.md#L49 "支持按决策、知识、事项、学习、评测和证据边界分主题阅读的说明。")
