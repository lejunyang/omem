# 安全代码高亮与逐行 HTML 拆分

按语言别名懒加载 highlight.js 语法定义，对未知语言安全降级，并在保持跨行 span 状态的前提下生成可独立渲染的行。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="language-loading"></a>
## 语言选择与安全降级

模块只从 highlight.js 核心包起步，以字面量动态导入声明 TypeScript、JavaScript、XML、CSS、Markdown、JSON、INI 和 Bash，便于构建工具解析开发及生产环境的代码块；常用扩展名和名称再统一映射到这些加载器。[高亮语言加载器与别名表 ↗](../../../packages/ui/src/highlight.ts#L1 "说明受支持语言、构建时可解析的字面量动态导入及扩展名归一化关系。") `highlightCode` 将语言名转为小写后查别名，未知语言不尝试自动探测，而是对 `&`、`<`、`>` 做转义后原样返回，避免把捕获内容当成标记。XML 路径额外注册 JavaScript 与 CSS，以支持嵌入内容；注册完成后才调用高亮器，并容忍非法语法。[高亮入口与未知语言降级 ↗](../../../packages/ui/src/highlight.ts#L21 "支持语言查找、XML 依赖注册、未知语言转义和最终调用 highlight.js 的流程。")

<a id="line-splitting"></a>
## 跨行样式的拆分流程

代码查看器需要每个编号行都是有效 HTML，但 highlight.js 的 span 可能跨越换行。`highlightedLines` 因而扫描生成的 span、闭合标签和换行：遇到起始 span 就压栈，遇到闭合标签就出栈；遇到换行时先闭合当前全部样式，再在下一行按栈中起始标签重开。这样每行可独立渲染，同时保留多行注释等词法状态。[逐行 span 状态机 ↗](../../../packages/ui/src/highlight.ts#L37 "支持换行时闭合并在下一行重开活动 span 的核心算法说明。")

该解析器明确假定输入只来自 highlight.js 的已转义文本和生成 span，并不是通用 HTML 解析器。它只识别特定 span 形态，未校验错误嵌套；若调用者传入任意 HTML，其正确性与安全性不能由本模块保证。[拆分器输入前提 ↗](../../../packages/ui/src/highlight.ts#L35 "支持该函数仅面向 highlight.js 输出、不是通用 HTML 解析器的边界判断。")
