# 知识复核角色运行清单

该清单定义 knowledge-verifier 第 1 版的运行身份、内联技能、结构化输出、工具与会话隔离策略，以及上下文、输出和修复预算；它证明配置已声明，但不单独证明宿主已完整执行这些约束。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-contract"></a>
## 角色与输出合同

清单把该运行单元标识为 `knowledge-verifier` 第 1 版，使用 `traex` profile，并加载一个提示模板及内联的 `omem-knowledge-verifier` 技能包；技能制品以摘要固定，便于宿主识别具体版本。其声明的输出为 `KnowledgeReview.v1`，说明职责是产出复核结论，而非撰写知识正文。[知识复核角色身份与输出声明 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/manifest.json#L2 "支持角色版本、profile、提示模板、内联技能以及 KnowledgeReview.v1 输出合同的说明。")

<a id="isolation-budget"></a>
## 隔离边界与预算

配置明确禁用工具且允许列表为空；每次会话都不复用，也不继承用户技能或 MCP。这些设置把复核限制在宿主提供的固定上下文中，降低草稿或材料触发外部动作的风险。预算上限为 96,000 个上下文 token、24,000 个输出 token，并允许最多两次修复尝试。[知识复核角色隔离与预算配置 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/manifest.json#L18 "支持无工具、会话不复用、不继承用户扩展及 token 和修复预算的说明。") 这些是角色清单中的配置事实，是否被所有运行后端严格落实仍需结合宿主实现或运行记录验证。
