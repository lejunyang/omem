# 知识成果的独立复核角色配置

该清单定义知识复核角色的执行配置：由 traex profile 承载，内联加载固定版本与摘要的复核技能，并要求输出 KnowledgeReview.v1。角色禁用工具、拒绝继承用户扩展且不复用会话，同时设定上下文、输出和修复次数预算；这些字段表达配置边界，其实际强制执行方式仍需运行时证据确认。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 角色定位与结构化输出

这份清单注册了版本为 1 的 **knowledge-verifier** 角色，指定 `traex` profile 和 `prompt.md` 提示模板，为知识成果提供独立复核配置。参考 [复核角色基础配置 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/manifest.json#L2 "支持角色标识、版本、执行 profile 与提示模板的配置事实。")

角色以内联方式加载 `omem-knowledge-verifier` 技能包，并固定技能版本与产物摘要；输出被声明为 `KnowledgeReview.v1`，说明复核结果需要遵循结构化合同。产物摘要为一致性核对提供了配置依据，但清单本身不能证明运行时何时校验摘要或如何处理不匹配。参考 [技能装载与输出合同 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/manifest.json#L9 "支持技能包以内联方式加载、固定版本和产物摘要，并声明 KnowledgeReview.v1 输出合同。")

<a id="isolation"></a>
## 隔离的复核会话

角色被配置为不使用任何工具，每次会话均不复用，也不继承用户技能或 MCP。这些限制旨在减少外部能力、个人扩展和既有会话状态对复核判断的影响。参考 [隔离会话策略 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/manifest.json#L18 "支持禁用工具、禁止会话复用以及不继承用户技能和 MCP 的配置边界。")

不过，这里记录的是角色清单中的策略声明；是否所有调用入口都会强制执行这些限制，还需要结合清单加载器、会话创建逻辑和行为测试判断。

<a id="budget"></a>
## 上下文、输出与修复预算

复核任务最多可使用 96,000 个上下文 token，并允许输出至 24,000 token，适合接收正文、内联引用和疑问项等较完整的结构化内容。格式或合同修复最多尝试两次，用于限制失败后的重试范围。参考 [复核资源预算 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/manifest.json#L27 "支持上下文、输出 token 上限以及最大修复尝试次数的说明。")

清单没有说明预算超限或两次修复后仍不合格时如何记录失败，也无法据此确认旧知识成果是否会被保留；这些语义需要从提示模板、输出 schema 与运行时错误处理流程继续核实。

<a id="scope"></a>
## 清单能够确认的边界

从该文件可以直接确认角色身份、技能装载方式、输出合同、隔离策略和资源上限，但不能确认复核标准的具体内容，也不能把配置字段等同于已经过行为验证的运行能力。角色定位与输出约束分别见清单的基础配置和合同声明。参考 [复核角色基础配置 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/manifest.json#L2 "支持角色标识、版本、执行 profile 与提示模板的配置事实。")、[技能装载与输出合同 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/manifest.json#L9 "支持技能包以内联方式加载、固定版本和产物摘要，并声明 KnowledgeReview.v1 输出合同。")
