# omem 交互原型说明

文档描述一个可离线打开的单文件交互原型，集中演示知识阅读、递归证据、追问、历史恢复与响应式布局；同时明确其使用虚构数据和确定性模板，未接入真实 LLM、数据源、数据库或记忆引擎。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 定位与交付方式

原型以单个 `index.html` 交付，脚本和样式均已包含，无需 CDN、API key 或后端，可通过 `file://` 或静态 HTTP 服务预览，便于独立传阅和交互评审。[单文件离线原型 ↗](../../../docs/prototype/README.md#L1 "支持直接打开方式、外部依赖边界和便于传阅的交付形态。") 这是 README 对演示交付形态的陈述，不应外推为生产部署能力。

<a id="interactions"></a>
## 交互覆盖

文档把文章与材料搜索、深层引用链、弹窗层级导航、原文和版本比较、循环引用提示列为已实现交互。[知识阅读与证据链交互 ↗](../../../docs/prototype/README.md#L5 "支持对搜索、递归引用、层级导航、版本比较和循环状态的概括。") 追问演示包括圈选、引用继续展开、停止生成及草稿保留，同时明确回答均为模拟，并展示无权限、已删除和锚点不确定状态。[模拟追问与不可见状态 ↗](../../../docs/prototype/README.md#L11 "支持追问交互组成、回答的模拟性质以及不可访问内容的展示原则。") 模拟同步、恢复记录、引擎启停及桌面和手机布局也在声明范围内。[学习、历史与响应式演示 ↗](../../../docs/prototype/README.md#L14 "支持模拟同步、历史恢复及桌面和手机布局等交互陈述。")

<a id="limits"></a>
## 真实能力边界

原型未连接 LLM、真实数据源、数据库或记忆引擎；问答来自确定性模板，学习和同步不会启动真实后台任务，恢复也不修改静态知识 fixture。[原型能力边界 ↗](../../../docs/prototype/README.md#L18 "直接支持真实模型、数据、数据库、后台任务和恢复副作用均未接入的限制说明。") 所以“已实现”仅表示演示交互被编码，不能视为正式策略、权限或副作用语义已经落地。演示历史保存在 `localStorage`，问题草稿与会话仅存在于当前页面内存。[浏览器内状态保存 ↗](../../../docs/prototype/README.md#L41 "说明演示历史与会话数据的不同生命周期，并限定截图属于验证产物。")

<a id="build_test"></a>
## 构建与验证声明

React 交互逻辑、虚构示例图和样式由 `build.mjs` 打包为单个 HTML，依赖版本固定在 lockfile；打开已交付 HTML 不要求现场运行 esbuild。[源码与打包结构 ↗](../../../docs/prototype/README.md#L28 "解释 React 逻辑、虚构数据、样式和 esbuild 在单文件交付中的分工。") README 还规定了 Playwright 检查入口、覆盖行为以及预期的验证摘要和截图。[浏览器检查范围 ↗](../../../docs/prototype/README.md#L32 "列出 README 声明的测试入口、覆盖行为及预期产物，用于区分测试描述和实际执行证据。") 这些是测试流程说明；缺少退出码、运行时间或产物内容时，不能认定当前版本已实际通过检查。
