# 证据路径模态对话框

基于原生 dialog 管理模态打开、焦点归还、返回与关闭事件，并支持证据层级、操作区和可选侧栏。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="lifecycle"></a>
## 打开、关闭与焦点

组件监听 open 属性：打开前等待 DOM 更新，保存当前活动元素并调用 showModal；关闭时调用原生 close，再把焦点还给仍连接在文档中的原元素。卸载前也会关闭 dialog。[对话框生命周期与焦点恢复 ↗](../../../packages/ui/src/components/OmDialog.vue#L1 "支持模态打开、受控关闭、焦点归还及卸载行为的说明。") 原生 cancel 被阻止并转换为 back，因此 Esc 表示退一层而非直接关闭全部；点击遮罩或右上关闭按钮则发出 close。[返回与关闭事件 ↗](../../../packages/ui/src/components/OmDialog.vue#L30 "说明 Esc、遮罩点击和关闭按钮分别映射到 back 或 close。") 组件自身不修改 open，状态所有权留给父组件。

<a id="composition"></a>
## 证据阅读布局

标题区可按 depth 显示“证据路径”层级，主体包含默认滚动插槽、可选 aside 和 actions 页脚；sideOpen 同时决定侧栏可见性与宽版样式。[插槽与侧栏结构 ↗](../../../packages/ui/src/components/OmDialog.vue#L43 "支持层级标题、正文、侧栏、操作区和 sideOpen 渲染方式的说明。") OmButton 和 OmIcon 被直接用于关闭按钮，表明该组件依赖基础 UI 原语来保持交互外观一致。桌面端侧栏固定 330px，移动端改为纵向并给正文和侧栏分别设置视口高度约束。[响应式双栏布局 ↗](../../../packages/ui/src/components/OmDialog.vue#L128 "说明宽版对话框、固定侧栏及移动端纵向布局的实现。")

<a id="limits"></a>
## 边界条件

焦点仅在由 open 变为 false 的分支中归还；若组件仍打开时直接卸载，卸载钩子只关闭 dialog，没有执行焦点恢复。[对话框生命周期与焦点恢复 ↗](../../../packages/ui/src/components/OmDialog.vue#L1 "支持模态打开、受控关闭、焦点归还及卸载行为的说明。") 标题使用固定 id `om-dialog-title`，若页面同时挂载多个实例，aria-labelledby 可能指向重复标识；材料也没有显示组件内部的焦点陷阱测试或多层实例测试。sideOpen 为假时 aside 仍通过 v-if 创建、再由 v-show 隐藏，插槽内容仍可能保留状态与成本。[插槽与侧栏结构 ↗](../../../packages/ui/src/components/OmDialog.vue#L43 "支持层级标题、正文、侧栏、操作区和 sideOpen 渲染方式的说明。")
