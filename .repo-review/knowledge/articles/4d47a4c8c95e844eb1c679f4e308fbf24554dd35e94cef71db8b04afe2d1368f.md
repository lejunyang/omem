# 知识文章的文件发布与恢复

该模块负责把已生成、已独立复核的知识文章发布为 JSON 与 Markdown，并按文章依赖顺序将文件产物恢复到知识仓库。它处理内联引用链接、来源变化导致的过期、无效产物拒绝和缺失子知识；结构与引用位置由宿主校验，论断的语义支持性仍由独立模型复核。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="publishing"></a>
## 双格式发布与可追溯阅读

模块将知识文章同时输出为机器可读 JSON 和供人阅读的 Markdown。渲染时先按 citation key 建立索引，再把正文中的 `[[引用]]` 替换为目标链接：文章引用指向摘要命名的 Markdown 与可选章节，`omem:` 材料引用指向相对源码路径和起始行；找不到引用时显示“引用不可用”，标签与悬浮理由也会清理影响 Markdown 的字符。[Markdown 引用渲染流程 ↗](../../../apps/server/src/knowledge/artifacts.ts#L8 "支持内联引用替换、目标链接生成、缺失引用提示以及标签与理由清理的说明。")

输出文件以文档 key 的摘要命名。JSON 会剔除仓库运行态的 `current`、`revision` 字段，只保留可移植产物；写入前比较已有内容，相同则跳过。目录会递归创建，但这里使用同步文件 API，材料未显示写入锁或原子替换机制。[知识文章文件写入 ↗](../../../apps/server/src/knowledge/artifacts.ts#L21 "支持摘要文件名、JSON 与 Markdown 双输出、运行态字段剔除、内容相同时跳过写入及同步文件操作的说明。")

<a id="restoration"></a>
## 恢复、校验与状态记录

恢复流程按文件名排序读取 JSON；解析失败的文件立即作为 `rejected` 加入返回结果，不进入后续校验队列。其余产物最多经过 100 轮依赖处理：若引用的子文章尚未存在于仓库，就继续留在 pending；依赖满足后才进入校验分支。[产物读取与依赖分轮处理 ↗](../../../apps/server/src/knowledge/artifacts.ts#L32 "支持 JSON 解析失败仅进入返回结果、材料摘要映射、排序读取及依赖未满足时继续 pending 的恢复流程。")

进入校验分支的产物必须为版本 1、复核结论为 `accepted`，并具有生成与复核模型来源；文档还须通过共享 schema。材料 digest 或子文章 revision 不一致时标为 `stale` 且不发布，依赖一致且仓库没有相同 revision 时才发布。只有这些已进入校验处理分支的文件，才会把 `restored`、`stale` 或校验产生的 `rejected` 状态写入 `knowledge_imports`。此前“每个已处理文件都会持久化导入状态”的宽泛结论已被替代：初始 JSON 解析失败者，以及循环结束后仍 pending 而返回 `missing` 的文件，都未在此函数中写入该表。[产物校验、发布与导入状态记录 ↗](../../../apps/server/src/knowledge/artifacts.ts#L46 "支持 provenance 与结构校验、过期判定、条件发布，并证明只有进入校验分支的文件会写入导入状态，而剩余 pending 仅返回 missing。")

<a id="boundaries"></a>
## 依赖、摘要身份与校验边界

从导入关系只能确认本模块依赖稳定摘要、文件系统、知识合同以及仓库类型与字符串摘要函数，不能据此推断具体仓库操作。[模块导入依赖 ↗](../../../apps/server/src/knowledge/artifacts.ts#L1 "仅用于证明模块导入稳定摘要、文件系统、知识合同以及仓库类型和字符串摘要函数，不用于证明具体仓库方法调用。") 实际的材料枚举、文章依赖查询、条件发布、导入状态写入和最终刷新分别出现在恢复流程中。[产物读取与依赖分轮处理 ↗](../../../apps/server/src/knowledge/artifacts.ts#L32 "支持 JSON 解析失败仅进入返回结果、材料摘要映射、排序读取及依赖未满足时继续 pending 的恢复流程。")[产物校验、发布与导入状态记录 ↗](../../../apps/server/src/knowledge/artifacts.ts#L46 "支持 provenance 与结构校验、过期判定、条件发布，并证明只有进入校验分支的文件会写入导入状态，而剩余 pending 仅返回 missing。") 产物 revision 的比较值由 `stableDigest(artifact)` 再经字符串 SHA-256 得到；稳定摘要会递归规范化数组和对象、过滤值为 `undefined` 的对象项、排序对象键，再对规范 JSON 求 SHA-256。先前仅凭导入行说明算法细节的结论，已由直接实现证据替代。[稳定摘要的规范化实现 ↗](../../../apps/server/src/storage/digest.ts#L3 "直接支持递归规范化、过滤 undefined、排序对象键以及对规范 JSON 计算 SHA-256 的算法说明。")

循环无进展或达到 100 轮后，剩余产物统一返回 `missing`，因此真实缺失、依赖环和过深依赖链目前无法从状态上区分。共享 schema 负责结构约束；仓库校验还检查内联引用是否使用、目标与材料行范围是否有效、引文是否来自所选范围，而语义正确性明确交由独立模型角色判断。[知识文档引用校验边界 ↗](../../../apps/server/src/knowledge/repository.ts#L41 "支持结构校验、内联引用使用与目标范围检查，并说明语义正确性由独立模型角色检查。")
