# 知识制品导出与恢复

在数据库知识版本与可提交的 JSON、Markdown 制品之间转换，并在恢复时校验结构、状态字段和依赖新鲜度。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="export"></a>
## 导出格式与引用呈现

`articleMarkdown` 将结构化章节渲染为 Markdown，并把正文中的 `[[引用键]]` 替换成下钻链接：文章引用指向按文档键摘要命名的 Markdown，可附章节锚点；仓库内 `omem:` 材料指向源文件及起始行；其他材料落到本页证据锚点。找不到引用定义时显示“引用不可用”。[Markdown 引用渲染 ↗](../../../apps/server/src/knowledge/artifacts.ts#L8 "支持章节渲染、不同引用目标的链接规则以及缺失引用占位行为。") `writeKnowledgeArticle` 以文档键摘要作为稳定文件名，同时写 JSON 与 Markdown，只在内容变化时覆写；导出制品剥离仓库运行态的 `current` 和 `revision` 字段。[知识制品写入 ↗](../../../apps/server/src/knowledge/artifacts.ts#L21 "支持稳定命名、JSON 与 Markdown 双格式输出、剥离运行态字段及按内容写入。")

<a id="restore"></a>
## 恢复顺序、校验与限制

恢复时先读取目录中排序后的 JSON 文件，解析失败记为 rejected；随后最多执行 100 轮依赖有序恢复，引用子文章且目标尚未进入仓库的制品会继续等待。[恢复扫描与依赖轮次 ↗](../../../apps/server/src/knowledge/artifacts.ts#L32 "支持 JSON 扫描、解析拒绝和等待子知识依赖的恢复顺序。") 每个候选制品必须是版本 1，带有 `accepted` 复核状态、非空的生成模型与复核模型字段，并通过文档 schema。先前“具有 accepted 独立复核”的结论已被替代：这里的恢复校验只核对这些字段，不验证 trace、生成者与复核者是否实际独立，也不证明制品来源真实性。材料摘要或子文章修订变化时记为 stale；合法且未以相同修订存在的制品才发布，最终无法消解的依赖记为 missing。[制品字段与新鲜度校验 ↗](../../../apps/server/src/knowledge/artifacts.ts#L47 "支持版本、accepted 状态、模型字段和文档结构校验，以及 stale、rejected、missing 分类；也界定该检查并未验证实际独立执行。")

该模块只扫描 `.json`，Markdown 只是输出视图；同步文件读写、旧文件清理和并发目录协调仍由上层负责。
