# Web 应用启动页

该文件是 omem Web 前端的最小 HTML 宿主：声明中文页面、适配移动端视口，提供应用挂载容器，并通过 ES 模块加载 TypeScript 入口。它能证明浏览器启动链的入口约定，但不能单独证明所用前端框架、具体界面、业务能力或运行状态。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="page-shell"></a>
## 浏览器页面的基础外壳

这个页面解决的是 Web 应用进入浏览器时的**基础装载问题**。文档声明为 HTML5，页面语言设置为简体中文，字符集采用 UTF-8，并配置与设备宽度一致的视口，为中文内容显示和移动端页面缩放建立基础环境。浏览器标签标题为“omem · 个人工作记忆”，表明该入口面向个人工作记忆场景。参考 [Web 应用 HTML 入口 ↗](../../../apps/web/index.html#L1 "支持页面语言、字符集、视口、标题、应用容器和 TypeScript 模块入口等事实，同时界定这份 HTML 能够证明的范围。")

## 应用代码的加载入口

页面主体提供一个名为 `app` 的容器，并以模块脚本加载 `/src/main.ts`；具体界面没有直接写在这份 HTML 中，而应由后续入口代码负责。现有材料只能确认容器和 TypeScript 模块入口的存在，不能据此断定该容器由 Vue 挂载，也无法确认页面结构、业务功能、构建结果或浏览器中的实际运行状态。参考 [Web 应用 HTML 入口 ↗](../../../apps/web/index.html#L1 "支持页面语言、字符集、视口、标题、应用容器和 TypeScript 模块入口等事实，同时界定这份 HTML 能够证明的范围。")
