# 统一开发、模型与知识评审入口

该配置固定项目工具链、中文向量模型及常用任务入口，把开发检查、在线验证、检索索引和仓库知识生成收拢到 osdk；它能说明命令如何声明，但不能单独证明脚本已经成功运行或对应能力已经实现。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="toolchain-and-checks"></a>
## 统一工具链与基础检查

配置固定 Node、pnpm 与 Bun 版本，其中 Bun 承担 TypeScript 脚本执行，Node 用于编译后的服务和构建工具。日常开发、构建、测试、类型检查与启动均映射到 pnpm 命令；综合 `check` 依次执行类型检查、测试和构建，为本地与持续集成提供一致入口。这里记录的是**任务声明**，不能据此认定任一检查当前已经通过。参考 [工具链与基础任务 ↗](../../../osdk.toml#L1 "支持固定运行时版本、常用 pnpm 任务以及综合检查执行顺序的说明。")

<a id="live-and-quality"></a>
## 在线验证与质量评估

除浏览器测试外，配置还提供 daily、ACP、角色、学习、流水线及 Lark Host 等在线检查，并将 Lark 标注、质量评估和完整质量运行分别暴露为任务。这些入口适合验证需要真实外部环境或端到端协作的场景，但文件没有给出凭据、前置服务、成功标准或最近运行结果，因此它们应被理解为可调用的验证通道，而非已验证状态。参考 [在线检查与质量任务 ↗](../../../osdk.toml#L29 "支持浏览器、在线集成验证及质量评估入口的配置说明。")

<a id="retrieval-and-review"></a>
## 中文检索与仓库知识流程

中文记忆检索使用锁定版本的 BGE-small-zh-v1.5 量化 ONNX 模型，并明确列出随模型获取的配置、词表和模型文件。检索索引支持切换到隔离的仓库数据库；完整评审验证任务声明会覆盖依赖、项目检查和中文实时检索。参考 [中文向量模型与检索验证 ↗](../../../osdk.toml#L51 "支持中文 embedding 模型身份、锁定文件、仓库索引选项和完整验证范围的说明。")

仓库知识侧提供构建、分析和生成入口：可按文件或目录处理，省略目标时覆盖全部材料；分析与生成还支持更新受影响模块及既有上层、仅处理源材料，以及重试未完成的模型工作。配置展示了参数边界与命令路由，但没有证明模型生成、独立复核或知识发布已经完成。参考 [仓库知识任务参数 ↗](../../../osdk.toml#L71 "支持知识构建、分析、生成及其目标、模块更新、仅材料和重试参数的说明。")
