# osdk.toml：统一运行时、任务与中文向量模型配置

该文件声明 omem 的 Node/pnpm 工具链、项目任务入口、osdk 指南来源，以及固定版本的中文 embedding 模型。它是环境与命令编排配置，不足以证明任务已执行、检查已通过或模型已下载。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="runtime_and_dependency"></a>
## 运行时与依赖约定

配置将项目基础描述为服务 Vue、API 与 CLI/ACP 桥接的一套 TypeScript 运行时，并固定 Node 24.18.1、pnpm 11。pnpm 依赖启用自动处理，并允许从源码构建；osdk 指南则锁定到 `lejunyang/one-sdk` 的特定提交，供 universal 与 claude-code 两类代理使用。[基础运行时与工具版本 ↗](../../../osdk.toml#L1 "支持项目采用统一 TypeScript 运行时并固定 Node、pnpm 版本的陈述。") [pnpm 与 osdk 指南来源 ↗](../../../osdk.toml#L8 "支持依赖处理策略以及 one-sdk 指南来源、提交和代理适用范围的说明。")

这些内容表达的是期望的工具链和依赖来源；仅凭配置无法确认本机当前版本、依赖解析结果或对应指南已经成功加载。

<a id="task_orchestration"></a>
## 开发、验证与质量任务入口

任务表集中映射了日常开发、repo-review、检索索引与验证、知识分析与生成、构建、测试和类型检查入口。综合检查 `check` 按顺序组合 typecheck、test 与 build，浏览器测试和多类 live smoke/质量评估则保留为独立任务。[核心项目任务映射 ↗](../../../osdk.toml#L18 "支持开发、检索、知识生成、构建、测试和类型检查入口由该配置统一编排的陈述。") [综合检查与专项验证任务 ↗](../../../osdk.toml#L31 "支持 check 的组成及浏览器、live、Lark 和质量任务保持独立入口的说明。")

这里定义的是可调用命令及其组合关系，不是运行记录：无法据此声称全量检查、真实 ACP、浏览器验证、Lark 集成或检索验证已经通过。

<a id="embedding_model"></a>
## 中文记忆向量模型

`memory-zh` 被声明为 embedding 模型，来源锁定到 Xenova 发布的 BGE-small-zh-v1.5 特定修订，并明确列出配置、分词器、词表及量化 ONNX 文件；模型家族为 BGE，派生自 BAAI/bge-small-zh-v1.5。[中文向量模型身份 ↗](../../../osdk.toml#L53 "支持 memory-zh 的锁定来源、文件清单、模型类型、家族和上游模型说明。")

固定来源修订与文件清单有助于形成可复现的模型身份，但空的 `views` 与 `exclude` 只反映当前配置结构；材料未展示下载状态、文件校验结果、向量维度、索引身份迁移或真实检索效果。[模型视图占位配置 ↗](../../../osdk.toml#L6 "支持当前 views 为空的事实，并界定配置本身没有给出索引与运行验证结果。")
