# 仓库材料捕获与用户补充恢复测试

验证仓库文本、部署配置和图片进入统一材料库时的筛选、幂等与历史保留，并确认用户澄清能够作为原始证据跨数据库恢复；同时明确当前测试与安全过滤的实际边界。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="capture-policy"></a>
## 仓库材料如何安全进入知识库

首个场景模拟仓库采集：Markdown、部署配置和 PNG 图片会进入材料库，图片保留为可读取的图像部分；测试明确验证 `.env` 与 `settings.local.json` 未被纳入。参考 [捕获与排除断言 ↗](../../../apps/server/tests/review-materials.test.ts#L9 "支持文本、部署配置和 PNG 被捕获，并准确限定测试实际验证排除的是 `.env` 与 `settings.local.json`。")

这里采用的是**路径规则过滤**，并非通用秘密检测：实现排除 `.repo-review/`、依赖与构建目录、`.git`、`.env` 和 `.env.*`，但保留 `.env.example`，同时排除以 `.local.json` 结尾的文件。候选文件优先来自 Git，失败时才遍历目录。参考 [候选发现与路径过滤 ↗](../../../apps/server/src/review/materials.ts#L15 "解释 Git 优先、目录遍历回退以及 `.env`、`.env.*`、`.local.json` 等固定排除模式。")

<a id="identity-and-removal"></a>
## 重复扫描、删除与历史身份

材料以内容哈希和捕获格式判断是否需要重新捕获；内容未变时不会生成新 revision。文件删除后会从当前材料列表消失，但历史 revision 仍然可读；相同内容再次出现时会恢复到原 revision 身份。参考 [幂等与历史恢复断言 ↗](../../../apps/server/tests/review-materials.test.ts#L24 "支持重复扫描不增加 revision、删除保留历史以及同内容重建后复用原 revision。") [内容哈希判定 ↗](../../../apps/server/src/review/materials.ts#L37 "解释只有内容哈希或捕获格式变化时才重新执行捕获。")

扫描结束后，适配器依据本轮成功捕获的来源更新 removed 状态，而不是删除旧证据，因此当前视图与可追溯历史可以同时成立。参考 [移除状态协调 ↗](../../../apps/server/src/review/materials.ts#L57 "支持扫描后按照当前成功捕获集合更新来源 removed 状态而不删除历史。")

<a id="linked-and-manual"></a>
## 关联材料与用户澄清的恢复

README 中指向部署配置的链接能够提出对应文件作为延伸材料，使读者可从说明继续追到实际配置；当前测试只证明一个直接链接的结果。参考 [部署链接发现 ↗](../../../apps/server/tests/review-materials.test.ts#L21 "支持 README 的直接链接能够提出对应部署配置，并表明测试仅检查首个结果。")

用户对职责边界的澄清会以 `manual` 原始材料保存，并能在新数据库中恢复正文、作者与原始生产者属性。参考 [用户澄清跨库恢复 ↗](../../../apps/server/tests/review-materials.test.ts#L39 "支持手工澄清被保存和恢复，并保持作者及 original 生产者属性。") 恢复后，只有补充 ID 能关联到已有知识问题，且对应文章尚无相同 key 与 digest 的材料依赖时，系统才写入待重核对记录；无法关联到问题的材料不会触发该标记。参考 [恢复与重核对条件 ↗](../../../apps/server/src/review/knowledge.ts#L9 "解释笔记恢复、问题关联，以及仅在文章缺少匹配材料依赖时写入知识失效记录的完整条件。")

<a id="coverage-limits"></a>
## 测试覆盖边界

现有用例覆盖文本、PNG、两种私密配置路径、重复扫描、删除再出现、单个文档链接及用户笔记跨库恢复。实现中还存在 Git 失败回退、符号链接与越界路径排除、5 MB 限制、非法 UTF-8、空文件及 JPEG/WebP 等分支，但这些行为没有被当前测试逐项断言，不能视为已由该测试验证。参考 [尚未逐项验证的分支 ↗](../../../apps/server/src/review/materials.ts#L17 "列出实现中的 Git 回退、文件安全检查、大小与编码限制、空文件和多种图像格式分支，用于界定测试覆盖范围。")
