# 开发端口选择与占用处理

该脚本为开发环境解析、校验并探测本机端口：显式配置无效或被占用时直接报错，默认端口被占用时自动申请临时端口，并将最终选择结果返回调用方。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 作用与设计意图

`selectDevPort` 统一处理开发服务端口的选择。文件注释声明，返回的端口预期同时传给后端与代理，避免浏览器连接到另一套 API；但材料未包含调用方，因此这里能确认的是模块设计意图，而非实际启动流程已经满足该约束。[开发端口设计说明 ↗](../../../scripts/dev-ports.ts#L3 "支持选定端口预期同时传给后端与代理、避免浏览器连接错误 API 的设计意图。")

<a id="flow"></a>
## 选择与探测流程

函数在没有显式配置时采用 `fallback`，否则把输入字符串转换为数字；结果必须是 0–65535 范围内的整数。校验通过后，它在 `127.0.0.1` 上创建临时监听，从服务器地址读取实际端口，并在关闭探测服务器后返回，因此端口 `0` 可用于请求操作系统动态分配端口。[端口校验与绑定探测 ↗](../../../scripts/dev-ports.ts#L5 "支持输入转换、端口范围校验、回环地址临时监听、读取实际端口及关闭探测服务器的流程。")

<a id="boundaries"></a>
## 冲突处理与竞态边界

监听失败时，非 `EADDRINUSE` 错误会原样抛出；显式端口被占用则返回要求更换端口的中文错误。仅当默认端口冲突时，函数才递归使用 `"0"` 获取临时端口并记录替代结果。[端口占用处理 ↗](../../../scripts/dev-ports.ts#L18 "支持非占用错误透传、显式端口冲突报错及默认端口冲突时改用动态端口的分支行为。") 由于返回前会关闭探测服务器，端口不会被持续保留，实际服务稍后绑定时仍可能遭遇其他进程抢占。

<a id="relationships"></a>
## 与启动流程的关系

完整文件只定义并导出端口选择函数，没有启动后端、代理或其他服务。[端口选择脚本完整边界 ↗](../../../scripts/dev-ports.ts#L1 "覆盖完整文件，支持该脚本仅导出端口选择函数、未包含后端或代理启动逻辑的结论，并替代此前范围不足的引用。") 因而它负责提供经过一次本机绑定探测的端口，外部启动流程负责传播并重新监听该端口；当前材料无法证明后端与代理确实共享同一返回值，也未展示实际绑定失败后的重试策略。
