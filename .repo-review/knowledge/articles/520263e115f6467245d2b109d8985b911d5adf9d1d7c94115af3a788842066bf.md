# 自治学习机制：从可观察结果改进后续行动

该设计把事实、方法和检索策略学习拆成可验证闭环，并以证据独立性、作用域、权限和预算作为硬边界；完整学习管线仍属于后续实施阶段。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="scope"></a>
## 学习对象与证据边界

系统可学习事实、偏好、有效步骤、错误条件和检索路线，但第一版不自动修改模型权重、不把自身文本循环包装成独立证据，也不扩大工具权限或采集范围。失败经历只能先记为 Episode，结合纠正和实际结果后才有资格提炼为 Procedure。[学习范围和证据独立性 ↗](../../../docs/autonomous-learning.md#L7 "支持可学习内容、禁止自动扩权及 Episode 晋升 Procedure 的条件。")

<a id="loops"></a>
## 三类闭环与风险约束

事实巩固检查主体、时间、范围和冲突；方法学习需经历聚类、正反例、回放或沙箱验证，并限定任务族；检索策略学习针对错配、旧版误用和无答案误答调整路由、过滤与组装。ACL、工具能力、不可逆动作确认和预算上限不能由学习环放宽。[三种学习闭环 ↗](../../../docs/autonomous-learning.md#L49 "解释事实、方法和检索策略学习流程及不可放宽的外部边界。")

<a id="evaluation"></a>
## 评价、归档与实施状态

证据可靠性、适用性、有用性和新鲜度分别计量，热度不能冒充真实性。归档只影响默认候选池，不破坏历史引用；发布还需检查来源、版本、冲突、适用范围和评测污染。完整学习管线、沙箱回放及真实效果评估被明确列为服务端 P1b/P2，而非现有能力。[评分与归档规则 ↗](../../../docs/autonomous-learning.md#L65 "支持四维评价相互分离以及归档不等于删除。")[发布条件与后续阶段 ↗](../../../docs/autonomous-learning.md#L113 "支持候选发布要求和完整学习管线仍属于 P1b/P2 的状态判断。")
