# 视觉材料分析提示词

该提示词规定视觉分析应基于可见内容、明确区分观察和推断，并以中文输出受约束的知识 JSON；它描述角色行为要求，而非已经完成的视觉识别能力。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="analysis-boundary"></a>
## 观察边界

角色面向原始图片说明可见结构、界面或图表，核心边界是区分直接观察与推断，不虚构无法辨认的文字，并在引用图片时指出相应区域。[视觉观察原则 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/prompt.md#L1 "支持角色应描述可见内容、区分观察与推断并避免虚构不可读文字的论断。") 同时，处理范围被限制在已提供材料内，不应额外调用工具或读取其他文件；因此结论的可信度取决于输入图片本身是否清晰、完整。[语言与材料范围限制 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/prompt.md#L3 "支持仅用中文、遵循指定合同且不调用工具或读取额外文件的范围说明。")

<a id="output-workflow"></a>
## 结构化产出流程

产出必须逐一覆盖目标键，文档键与任务完全一致，并用带内联引用的 Markdown 章节组织作用、背景、流程、限制及材料关联。引用必须指向提供的材料或文章，标签应便于人读；不能确认的内容进入结构化问题，而不是伪装成确定事实。[目标覆盖与引用规则 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/prompt.md#L4 "支持目标键覆盖、章节内联引用、引用目标限制以及结构化记录疑问的流程说明。") 这些规则与输出 Schema 配合：提示词规定如何写，Schema 规定结果可接受的字段形态。
