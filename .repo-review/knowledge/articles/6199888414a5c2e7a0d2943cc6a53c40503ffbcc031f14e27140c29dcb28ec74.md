# 受限外部来源到统一捕获输入的转换器

将本地文本文件、Git 历史文件、飞书文档和 Agent hook 事件安全地转换为统一 CaptureInput，同时限制路径、大小、URL、字段和敏感文本。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="filesystem-git"></a>
## 文件与 Git 的有界读取

文件连接器先解析真实路径，并要求它位于显式配置的捕获根目录内，从而同时约束普通路径和符号链接；随后限制为 500 KB、严格 UTF-8 且不含 NUL 的纯文本。[捕获根目录与文本限制 ↗](../../../apps/server/src/connectors.ts#L1 "支持真实路径约束、文件大小、UTF-8 和二进制文本检查。") Git 连接器复用仓库根目录检查，并分别限制 ref 与仓库内路径；它先把 ref 验证为 commit SHA，再用参数数组调用 `git show`，最终把 SHA 记录为上游版本。材料只证明该文件读取指定提交中的单个路径，没有递归扫描或自动抓取链接。[Git 引用与路径读取 ↗](../../../apps/server/src/connectors.ts#L36 "说明 Git ref、仓库路径的校验及通过已验证提交读取单文件的流程。")

<a id="lark"></a>
## 飞书文档读取

飞书入口只接受 HTTPS、无用户名密码、路径形态为 docx/wiki 且主机位于允许域名的 URL。验证后通过 `lark-cli` 请求 Markdown 和引用详情，检查响应成功及正文类型，再把正文、原文链接和可选引用映射作为捕获内容；引用映射只是来源上下文，不被解释为可执行标记或推导链接。[飞书 URL 和 CLI 响应转换 ↗](../../../apps/server/src/connectors.ts#L76 "支持允许域名、URL 形态、外部 CLI 调用及统一捕获内容的构造。")

<a id="hook"></a>
## Hook 字段筛选与来源身份

Hook 转换要求对象输入，只从 profile 明示的字段中选择会话、轮次、工具、提示、输入输出和错误；未知扩展及隐藏转录不会自动进入捕获。序列化时仅对形如部分 API token 的字符串做替换，并执行字符预算。[Hook 白名单与文本预算 ↗](../../../apps/server/src/connectors.ts#L137 "说明 hook 仅捕获 profile 明示字段、执行有限脱敏并限制最大字符数。") 事件优先采用显式 ID，否则由会话、调用信息和正文摘要生成稳定身份；结果携带时间、collector 和原始生产者标记，但 actor 保持未知，避免无依据绑定到个人。[Hook 稳定身份与来源元数据 ↗](../../../apps/server/src/connectors.ts#L196 "支持事件 ID 回退算法、时间规范化和未验证 actor 的 provenance 表达。")
