# 实施提案：证据主链、检索安全与验收路线

该模块是一份第一轮架构与原型提案，定义从权威原件、固定修订、外部投影到安全检索的目标流程，并给出阶段退出条件。它不是当前实现状态；其中 React 已被后续 Vue 决策取代，其他技术选型与阶段进度也需由实际代码和测试证据确认。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-and-status"></a>
## 定位与背景

本文用于划定个人助理的实现边界和验收方式，而不是证明服务端已经建成或路线已经完成。早期工程形态建议以 Python、FastAPI、Celery 和 React 组织 API、worker 与 Web；后续决策已明确产品前端采用 Vue，因此首次阅读时应把前述技术栈视为历史提案，并以实施状态和实际代码为准。[实施提案的状态声明 ↗](../../../docs/implementation.md#L3 "支持本文属于第一轮架构与原型设计、不能被当作当前运行能力或服务端完成证明的判断。")[早期工程形态建议 ↗](../../../docs/implementation.md#L7 "支持早期方案对 Python、FastAPI、Celery 和 React 的工程分工描述。")[Vue 前端决策 ↗](../../../docs/decisions.md#L16 "支持产品前端已明确采用 Vue，说明早期 React 建议不能作为现行实现结论。")

<a id="authority-and-ingestion"></a>
## 权威数据与摄入主链

提案以 PostgreSQL 保存主体、来源、不可变修订、固定片段、关系、任务和投影水位，对象存储承载原件；当前状态、追加审计事件与 outbox 在数据库事务中协调，但不假定数据库与对象存储之间存在分布式事务。[权威存储与事务设计 ↗](../../../docs/implementation.md#L29 "支持 PostgreSQL 表职责、对象存储写入顺序、事务审计及不采用全域纯事件溯源的设计边界。") 连接器事件只提供变化线索，系统仍需读取上游真实版本并去重，原件提交后才能推进水位。Git 输入不得执行仓库脚本，AgentRun 不采集隐藏推理，主动发现也不能越过既定 namespace 或授权范围。[连接器摄入与采集边界 ↗](../../../docs/implementation.md#L72 "支持读取上游真实版本后去重、水位推进条件，以及 Git、AgentRun、主动发现和撤权的安全约束。")

<a id="projection-and-retrieval"></a>
## 外部投影与检索安全

模型、连接器和适配器通过版本化能力清单协商契约；能力不足应明确拒绝。外部引擎只是可重建投影：命中结果必须重新映射并读取权威片段，检查 ACL、哈希、状态、有效 generation 与来源 head，缺失出处的学习结果只能作为研究假设。[适配器映射与投影协议 ↗](../../../docs/implementation.md#L102 "支持能力协商、外部结果回映权威片段、至少一次投递、generation 隔离和查询时陈旧性复核。") 检索随后按权威修订去重、统一重排，并在预算内让结论与支持片段成对进入 Context Packet；若证据不足则拒答并说明下一步。权限检查贯穿召回、展开、生成和缓存命中。[检索与上下文组装流程 ↗](../../../docs/implementation.md#L134 "支持检索路由、权威修订去重、hydrate、统一重排、证据预算、拒答及多阶段 ACL 检查。")

<a id="roadmap-and-limits"></a>
## 进展表达、验收与限制

P0 至 P3 描述的是按验收推进的粗估路线：先验证证据合同和引擎映射，再建设证据工作台、经历自治闭环、团队权限与评估，最后按实际收益扩展渠道。其退出条件关注引用可解析、证据支持准确、无越权或陈旧注入、正确拒答、恢复与投毒防护。原型交互测试不能替代服务端故障测试，也不能替代针对锁定上游版本的适配器契约测试；因此本文本身不能回答各阶段已经完成多少。[阶段退出条件与测试边界 ↗](../../../docs/implementation.md#L184 "支持 P0 至 P3 是粗估路线，并说明验收指标、故障场景以及原型测试不能替代服务端和适配器契约测试。")
