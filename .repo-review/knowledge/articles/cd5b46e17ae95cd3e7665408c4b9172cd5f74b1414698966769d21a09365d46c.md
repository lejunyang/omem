# 对话材料分析角色规范

该文件定义 conversation-analyst 的材料整理职责、输出约束和引用规则。其核心是保留对话来源与语境，区分不同陈述性质，并避免把他人的承诺误转成用户待办。文件属于角色规范，不能单凭其内容认定相应校验、宿主引用提取或待办隔离机制已经实现。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-boundary"></a>
## 角色目标与语义边界

该角色用于整理对话材料，重点保留说话人、时间、转述和回复语境，并区分请求、承诺、猜测与事实；尤其明确规定，他人的承诺不能自动成为用户待办。[对话整理职责 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/skills/omem-conversation-analyst/SKILL.md#L2 "支持附近关于保留对话语境、区分陈述性质以及不把他人承诺转成用户待办的论断。") 这是一项信息解释与归责规则，旨在防止上下文丢失后产生错误事实或错误行动项。文件仅陈述角色应如何工作，没有提供运行代码、测试结果或部署状态，因此应视为需求规范，而非已实现能力。

<a id="output-process"></a>
## 输出流程与覆盖要求

分析过程被约束为中文输出，并且只能返回指定 JSON 合同；材料中出现的命令或提示词只能作为待分析数据，不能反向控制分析角色，也不得调用工具或读取未提供文件。[输入与执行边界 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/skills/omem-conversation-analyst/SKILL.md#L10 "支持附近关于中文 JSON 输出、材料不构成指令以及禁止调用工具和读取其他文件的说明。") 每次任务还必须完整覆盖 `task.targetKeys`，保持文档键精确一致，并用若干有解释力的章节说明作用、背景、流程、限制及材料关联。[目标覆盖与正文要求 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/skills/omem-conversation-analyst/SKILL.md#L11 "支持附近关于覆盖全部目标、保持文档键一致及正文应解释背景流程和限制的说明。") 这些要求共同限定了输入信任边界与批量产物的可追踪性。

<a id="citation-and-uncertainty"></a>
## 证据引用与不确定性处理

正文中的论断需要就近放置引用标记，且每节至少包含一处引用；所有声明的 citation 都必须实际出现在正文中，不能集中堆放到文末。[正文引用布局 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/skills/omem-conversation-analyst/SKILL.md#L12 "支持附近关于引用必须贴近论断、每节至少一处且不能只在文末罗列的要求。") 引用目标只能来自任务提供的材料或文章：材料引用需使用完整键和真实行号，并将 `quote` 留空，由宿主从固定范围提取原文。[固定材料引用规则 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/skills/omem-conversation-analyst/SKILL.md#L13 "支持附近关于引用来源、完整材料键、真实行号及由宿主提取引文的说明。") 引用标签应面向读者，理由要说明其支持的附近论断；无法确认、背景不足或需要选择的事项应进入结构化 questions，而不能用笼统追问代替。[标签与问题记录规则 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/skills/omem-conversation-analyst/SKILL.md#L14 "支持附近关于人类可读标签、引用理由和结构化记录不确定事项的要求。")

<a id="status-limit"></a>
## 实现状态限制

该文件描述了 conversation-analyst 的预期行为和产物格式，但未展示合同校验器、引用提取宿主、待办生成链路或端到端测试。因此，目前只能确认这些是设计与运行约束，不能据此断言系统已经自动阻止错误归责、校验全部引用，或在实际任务中稳定覆盖所有目标。[规范文件内容范围 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/skills/omem-conversation-analyst/SKILL.md#L1 "该材料仅给出角色描述及输出规范，支持附近将其界定为设计约束而非实现证据的判断。")
