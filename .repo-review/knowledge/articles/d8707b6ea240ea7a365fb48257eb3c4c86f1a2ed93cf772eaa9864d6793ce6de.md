# omem 界面设计技能入口配置

为 Agent 界面登记 omem 设计技能的展示名称、简短说明和默认提示词；这是入口元数据，不是 UI 实现或技能执行记录。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="interface-metadata"></a>
## 界面展示元数据

配置在 `interface` 下提供人类可读名称“omem 界面设计”，并用简短说明把能力定位为：沿用证据阅读设计语言，构建可访问的 Vue 组件和移动端页面。[技能展示名称与简介 ↗](../../../.agents/skills/omem-design/agents/openai.yaml#L1 "支持该配置用于人类可读展示，并界定可访问 Vue 与移动端页面的能力描述。") 它承担的是技能发现与展示作用，没有声明运行时、组件路径、权限或验证结果。

<a id="default-invocation"></a>
## 默认调用语义

默认提示词要求调用 `$omem-design`，并以项目 `design.md` 作为 Vue 界面的设计依据。[默认技能提示词 ↗](../../../.agents/skills/omem-design/agents/openai.yaml#L4 "支持默认提示词会引用 omem-design 技能和项目 design.md 的论断。") 这一行只表达默认引导语；是否实际加载对应技能、读取设计文件并完成实现，仍取决于宿主的技能解析与执行流程，不能由该 YAML 本身证明。
