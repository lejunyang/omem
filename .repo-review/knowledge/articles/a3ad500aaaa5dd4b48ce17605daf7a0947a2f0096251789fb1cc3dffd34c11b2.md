# 证据复核角色的运行配置

该清单定义 verifier 角色第 1 版的提示词、内联复核技能、结构化输出合同、隔离策略与资源预算。它能说明角色被期望如何运行，但仅凭配置文件不能证明运行时已完整执行这些约束，也不能证明任何具体复核已经成功。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 角色定位与输出边界

这份清单把角色标识为 `verifier` 第 1 版，并选择 `traex` profile；角色使用单独的 `prompt.md`，表明复核行为由版本化角色配置和提示模板共同描述。参考 [角色与提示配置 ↗](../../../packages/agent-runtime/roles/verifier/1/manifest.json#L2 "支持 verifier 的角色版本、运行 profile 和提示模板由清单明确指定这一陈述。")

复核结果被要求符合 `AssessmentBatch.v1`，因此它面向的是可被后续流程解析的结构化评估，而不是自由文本答复。清单只陈述配置意图，不能单独证明宿主已加载该 schema 或成功产出评估。参考 [结构化评估输出 ↗](../../../packages/agent-runtime/roles/verifier/1/manifest.json#L17 "支持复核角色将 AssessmentBatch.v1 作为输出合同的陈述。")

<a id="evidence-review-skill"></a>
## 固定的证据复核能力

角色声明加载 `omem-evidence-review` 的 `review-1` 版本，并采用内联模式；同时记录制品摘要，可用于把一次运行追溯到确定的技能内容，降低技能版本漂移带来的复核差异。参考 [证据复核技能绑定 ↗](../../../packages/agent-runtime/roles/verifier/1/manifest.json#L9 "支持技能名称、版本、内联加载方式和固定制品摘要的说明。")

这里没有给出技能正文，也没有展示摘要校验过程，所以能够确认的是“清单绑定了特定技能制品”，而非“该技能已在每次运行中得到正确执行”。

<a id="isolation-budget"></a>
## 隔离策略与资源上限

工具策略设为 `none` 且允许列表为空，意味着该角色按配置不应调用外部工具；会话也要求永不复用，并禁止继承用户技能与 MCP，以减少既有会话状态或个人扩展对独立复核的干扰。参考 [工具与会话隔离 ↗](../../../packages/agent-runtime/roles/verifier/1/manifest.json#L18 "支持禁用工具、禁止复用会话以及不继承用户技能和 MCP 的隔离策略。")

预算允许最多 96,000 个上下文 token、24,000 个输出 token，并设置最多 2 次修复尝试。这些数值描述宿主可采用的运行边界，不等同于实际消耗，也不能证明超限和修复逻辑已经实现。参考 [复核运行预算 ↗](../../../packages/agent-runtime/roles/verifier/1/manifest.json#L27 "支持上下文、输出和修复尝试上限属于角色配置边界的陈述。")
