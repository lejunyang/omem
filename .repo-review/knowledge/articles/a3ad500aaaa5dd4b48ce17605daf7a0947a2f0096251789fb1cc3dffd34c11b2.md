# 证据核验角色 v1 运行清单

该清单声明 verifier 的角色包、结构化输出、工具与会话策略及预算；独立核验与证据比较要求来自提示词，清单本身不足以证明运行时已强制执行这些约束。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role_contract"></a>
## 角色组成与核验职责

清单将角色标识为 `verifier` v1，引用 `traex` profile 和 `prompt.md`，以内联方式加载带版本及制品摘要的 `omem-evidence-review` 技能，并声明输出为 `AssessmentBatch.v1`。这些字段描述角色包及预期结构化产物，但没有展示加载器是否校验摘要或输出。[核验角色、技能与输出配置 ↗](../../../packages/agent-runtime/roles/verifier/1/manifest.json#L2 "支持 verifier 的角色版本、profile、提示词、内联技能制品和 AssessmentBatch 输出声明。")

独立判断的要求来自提示词：角色应以提供的原始证据和可信来源信息复核提案，不继承提取者推理，并检查主体、范围、时间、归因、否定、条件与表述强度；它只评估支持性，不负责批准或执行变更。[独立证据核验提示词 ↗](../../../packages/agent-runtime/roles/verifier/1/prompt.md#L3 "支持独立复核原始证据、检查语义范围以及只评估支持性而不执行变更的职责说明。")

<a id="isolation_budget"></a>
## 隔离声明与资源预算

工具策略声明为 `none`、允许列表为空；会话配置声明永不复用，且不继承用户技能与 MCP。[工具与会话隔离配置 ↗](../../../packages/agent-runtime/roles/verifier/1/manifest.json#L18 "支持无可调用工具、会话不复用以及不继承用户技能和 MCP 的配置事实。") 这只能确定配置限制了可调用工具和可继承上下文；此前将其解释为“保证只依据任务证据”的结论由此替代，因为独立依据证据判断是提示词要求，而非这些清单字段本身能够保证的运行效果。[独立证据核验提示词 ↗](../../../packages/agent-runtime/roles/verifier/1/prompt.md#L3 "支持独立复核原始证据、检查语义范围以及只评估支持性而不执行变更的职责说明。")

清单还设定 96,000 个上下文 token、24,000 个输出 token及最多两次修复尝试。[核验任务预算配置 ↗](../../../packages/agent-runtime/roles/verifier/1/manifest.json#L27 "支持上下文、输出 token 与修复尝试次数的配置上限。") 这些是声明的预算上限；材料未提供策略执行代码、超限行为或运行记录，不能据此确认运行时已强制落实。
