# Batch 2 调研来源清单

该文件是截至 2026-09-26 的外部调研来源快照，固定了 Mempalace 与 Lark SDK 的版本信息，并记录 Mempalace、Lark SDK 及飞书开放平台材料的路径、地址、校验值和大小。它用于来源追溯与完整性复核，但不记录 omem 的设计取舍、实现状态或本地基准结果，不能据此认定相关能力已经采纳、实现或验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="scope_and_provenance"></a>
## 范围与来源固定

清单记录了调研检查日期，将 Mempalace 固定到 `develop` 分支的特定提交，并保存其许可证与归档状态；Lark SDK 也固定了提交及源码中的包版本。[上游版本与许可证快照 ↗](../../../docs/implementation/batch2/research-sources.json#L1 "支持调研日期、Mempalace 固定提交与分支、许可证和归档状态，以及 Lark SDK 固定提交和包版本的论断。") 这使后续研究能够回到同一上游快照，减少分支演进造成的证据漂移。

每个文件条目进一步保存路径、固定地址、SHA-256 与字节数，可用于定位来源并核对取得内容是否与研究时一致。[来源文件完整性元数据 ↗](../../../docs/implementation/batch2/research-sources.json#L21 "支持来源条目以路径、固定地址、SHA-256 和字节数进行定位与完整性核对，并说明其性质是来源元数据。") 这些字段是溯源和完整性元数据，不是 omem 的依赖声明、实现记录或采用结论。

<a id="research_coverage"></a>
## Mempalace 调研覆盖面

Mempalace 资料覆盖项目概览与配置，以及搜索、本地模型、基准、Python API 和 MCP 工具文档。[Mempalace 文档资料 ↗](../../../docs/implementation/batch2/research-sources.json#L23 "支持概览、项目配置、搜索、本地模型、基准、Python API 与 MCP 工具文档均在调研范围内。") 实现源码范围还涉及房间识别、查询解析、嵌入、对话挖掘、通用抽取、知识图谱、模型客户端、配置、存储后端，以及候选生成、查询和排序等检索环节。[Mempalace 实现资料 ↗](../../../docs/implementation/batch2/research-sources.json#L71 "支持调研覆盖查询解析、嵌入、抽取、知识图谱、模型客户端、配置、后端和检索组件，也支撑其只是考察范围而非采用证明的边界。")

基准材料包含原始检索、混合检索与 LLM 重排结果，并收录说明文档和运行脚本。[检索基准与运行材料 ↗](../../../docs/implementation/batch2/research-sources.json#L172 "支持清单收录原始、混合及 LLM 重排结果、基准说明与运行脚本，并据此区分上游资料和 omem 自身复现证据。") 这些记录证明相关资料曾被纳入调研范围，但没有给出 omem 的复现条件、测量结果或采用决策，因此不能把上游结果直接视为本项目的验证结论。

<a id="lark_and_limits"></a>
## 飞书资料与解释边界

飞书方向收录了固定提交下的 Node SDK 中文说明，[Lark Node SDK 中文说明 ↗](../../../docs/implementation/batch2/research-sources.json#L65 "支持飞书方向收录固定提交下 Node SDK 中文说明的论断。") 以及一键创建应用、集成概览、消息发送、事件订阅回调和卡片回调资料。[飞书开放平台接入与交互资料 ↗](../../../docs/implementation/batch2/research-sources.json#L214 "支持开放平台资料覆盖一键创建应用、集成概览、消息发送、事件订阅回调与卡片回调，并说明这些条目提供可追溯入口。") 它们为研究应用接入与交互链路提供可追溯入口，但清单本身不能证明机器人、事件处理或卡片交互已经在 omem 中落地。

清单还保存了 Mempalace 许可证文件的固定地址、校验值和大小。[Mempalace 许可证文件入口 ↗](../../../docs/implementation/batch2/research-sources.json#L244 "支持清单保留固定提交下许可证文件的路径、地址、SHA-256 与大小；不据此推断历史结论或能力状态。") 顶层元数据将该仓库许可证标为 MIT，但具体复用方式仍需结合许可证正文、本仓库实现与合规要求审查。这里仅能确认资料被固定和收录，不能由此推出能力已实现。
