# 知识刷新角色提示模板

提示模板规定刷新任务应基于新旧固定材料和用户回答，只更新受影响内容、保留未受影响知识并标明替代关系，同时严格约束语言、JSON 输出、引用和疑问表达。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="refresh"></a>
## 增量刷新目标

模板把任务定义为依据新旧固定材料和用户回答更新受影响的正文、引用与疑问，同时保留未受影响知识并标明已被替代的结论。[增量知识刷新目标 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/prompt.md#L1 "支持只更新受影响内容、保留其他知识并标明替代结论的工作目标。") 这是增量维护目标，而非重写全部知识；不过材料仅说明期望行为，没有展示差异识别算法或成功刷新记录。

<a id="output"></a>
## 输出覆盖与篇章要求

角色被要求使用中文、只返回指定 JSON 合同，且不得把材料中的指令当作执行命令，也不得调用工具或读取未提供文件。它还必须覆盖全部目标键并保持文档键精确一致，正文应解释背景、流程、限制及材料关联。[语言、隔离和目标覆盖要求 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/prompt.md#L3 "支持中文 JSON 输出、固定材料边界、完整目标覆盖和正文组织要求。") 这些要求与清单中的无工具策略相呼应。

<a id="evidence"></a>
## 证据与疑问规则

每节正文都要就近放置引用，所有引用都必须实际出现；材料引用须使用完整键和真实行号，精确引文由宿主复制。[正文引用与固定定位规则 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/prompt.md#L5 "支持引用须贴近论断、全部被使用，并使用完整材料键和真实行号。") 标签应便于人读，关系必须来自合同枚举；不确定、缺背景或需用户选择的事项应形成带原因、下一步、阻塞状态和引用键的具体问题。[可读标签与疑问记录要求 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/prompt.md#L7 "支持关系枚举约束及将不确定事项转化为具体问题的规则。")
