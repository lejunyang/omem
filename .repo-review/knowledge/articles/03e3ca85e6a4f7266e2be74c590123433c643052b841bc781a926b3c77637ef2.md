# 代码理解预算的兼容出口

该文件不实现预算算法，只把通用 Agent Runtime 的令牌估算、生成预算函数及类型从代码知识命名空间重新导出，使代码理解模块复用统一预算合同。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 作用与边界

该模块是一个极薄的兼容层：代码理解相关代码可以从本目录导入 `estimateTokens`、`generationBudget` 和 `GenerationBudget`，但真正的计算逻辑与类型定义仍归属于通用 Agent Runtime。[预算能力重导出 ↗](../../../apps/server/src/code/budget.ts#L1 "支持该文件仅转出通用运行时预算函数和类型、没有本地实现的判断。") 因此这里不会读取配置、执行模型或改变预算；预算算法的精度、上下文裁剪规则及输出上限均需到被转出的模块中判断。
