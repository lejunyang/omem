# 代码理解种子的投影、失效与读取集成验证

该测试验证人工维护的代码理解种子能否解析到当前代码图，并覆盖幂等投影、无效引用拒绝、源码变化后的版本换代、无模型时的本地读取接口及原始证据隔离。大多数夹具用例使用临时 Git 仓库，所有用例使用独立 Store；最后一个用例直接同步真实 omem 仓库，检查已提交种子的解析基线。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-fixture"></a>
## 验证目标与运行环境

这组集成测试用于防止人工模块说明脱离真实代码图：种子中的路径和符号必须能在当前快照中解析，派生理解也不能改写原始证据。大多数夹具用例创建临时 Git 仓库、写入源码和种子并提交；所有用例都使用独立 `Store`，结束后关闭数据库并清理其临时目录。参考 [临时夹具与独立存储 ↗](../../../apps/server/tests/code-understanding-integration.test.ts#L20 "支持大多数夹具用例使用临时 Git 仓库、所有用例创建独立 Store 并在结束后清理的说明。")

测试直接串联评审同步、代码同步、理解查询和 HTTP 应用，因此验证的是文件、Git 快照、SQLite 投影与读取接口之间的集成链路。参考 [集成链路依赖 ↗](../../../apps/server/tests/code-understanding-integration.test.ts#L12 "支持测试直接连接存储、评审同步、代码同步、理解查询和 HTTP 应用的说明。") 最后一个用例不创建夹具仓库，而是读取真实仓库并使用隔离 Store 验证已提交种子。参考 [真实仓库种子基线 ↗](../../../apps/server/tests/code-understanding-integration.test.ts#L272 "支持最后一个用例直接同步真实仓库，并检查五个关键模块人工种子属性的说明。")

<a id="projection-lifecycle"></a>
## 种子投影与版本生命周期

有效种子同步后成为当前 `seed` 记录，明确保持非模型生成、未经 Agent 独立复核及较低置信度；相同快照再次同步仍只有一条当前记录，详情可找到已解析的节点引用。参考 [有效种子与幂等投影 ↗](../../../apps/server/tests/code-understanding-integration.test.ts#L110 "支持种子状态、非模型属性、重复同步幂等性和节点引用可查询的论断。")

引用不存在符号的种子不会进入当前列表，但会作为 `rejected` 历史保留，避免失败结果遮蔽好结果。参考 [无效符号引用拒绝 ↗](../../../apps/server/tests/code-understanding-integration.test.ts#L147 "支持幽灵符号种子不进入当前结果、但以 rejected 状态保留在历史中的说明。") 源码内容变化会产生新的理解记录，旧记录转为 stale，新记录通过换代关系指向旧版本，说明派生知识随输入快照更新而非原地覆盖。参考 [快照变化与理解换代 ↗](../../../apps/server/tests/code-understanding-integration.test.ts#L178 "支持源码变化后创建新理解、旧理解转为 stale 并记录换代关系的说明。")

<a id="interfaces-and-boundaries"></a>
## 读取接口与覆盖边界

未配置模型时，状态接口返回不可用，但种子理解、详情和原始代码图仍可读取。请求使用 loopback Host，并携带获准的本地开发 Origin；Host 为 `127.0.0.1:5180`、Origin 为 `127.0.0.1:5181`，端口不同，不能称为同源请求。参考 [本地开发来源读取 ↗](../../../apps/server/tests/code-understanding-integration.test.ts#L225 "支持测试使用不同端口的 loopback Host 与本地开发 Origin，并验证无模型时读取接口仍可工作的论断。") 该行为对应评审应用在无令牌模式下对 loopback Host 和本地开发浏览器来源的安全约束。参考 [评审接口安全边界 ↗](../../../apps/server/src/review/app.ts#L12 "解释无令牌模式对 loopback Host 和本地开发浏览器来源的访问约束。")

重复投影前后，通用 `sources` 与 `fragments` 数量不变，表明代码理解是派生视图，不会反向制造原始材料。参考 [原始证据数据隔离 ↗](../../../apps/server/tests/code-understanding-integration.test.ts#L251 "支持重复代码理解投影不会改变通用来源和片段数量的边界说明。") 真实仓库用例要求五个关键模块存在当前人工种子，但只证明资产可被当前图解析，不代表正文语义或真实模型链路已经验证。参考 [真实仓库种子基线 ↗](../../../apps/server/tests/code-understanding-integration.test.ts#L272 "支持最后一个用例直接同步真实仓库，并检查五个关键模块人工种子属性的说明。")
