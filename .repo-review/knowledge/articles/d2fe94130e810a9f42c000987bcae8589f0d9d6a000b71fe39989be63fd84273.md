# 统一阅读界面的视觉基础与可访问性

这份共享样式表用颜色与字体变量、基础元素规则、键盘焦点、减弱动画和中性代码高亮，统一阅读界面的视觉与交互基线。它不负责具体页面布局、内容渲染或样式加载，因此实际覆盖范围仍取决于应用入口和组件。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="visual-foundation"></a>
## 建立统一的阅读基线

样式表集中定义墨色、次要文字、纸张、面板、边线、状态色、圆角以及中西文字体栈。页面默认使用浅色背景、深色正文和无衬线字体，为不同阅读页面提供一致的黑白灰基线。参考 [颜色与正文字体基线 ↗](../../../packages/ui/src/tokens.css#L1 "支持共享颜色、圆角、字体变量以及页面默认背景、正文颜色和无衬线排版的说明。")

一级、二级标题改用衬线字体，并分别设定字号、字重和行高，使标题与正文形成清晰层次。参考 [标题排版规则 ↗](../../../packages/ui/src/tokens.css#L47 "支持一级、二级标题采用衬线字体并设置字重、行高和字号的说明。") 这些规则仍不是完整主题系统：部分颜色和圆角直接写在具体规则中，也未提供深色模式或主题切换机制。

<a id="interaction-baseline"></a>
## 统一表单与键盘交互

按钮、输入框、文本域和选择器继承页面字体；普通按钮显示可点击光标，禁用按钮则通过光标和透明度表达不可操作状态。参考 [控件字体与按钮状态 ↗](../../../packages/ui/src/tokens.css#L25 "支持表单控件继承字体，以及普通和禁用按钮通过光标与透明度表达状态的说明。") 输入框、文本域和选择器共享最大宽度、边框、圆角、内边距、背景与文字颜色；标签以纵向弹性布局组织文字和控件，文本域只允许纵向缩放。参考 [表单外观与标签布局 ↗](../../../packages/ui/src/tokens.css#L63 "支持输入控件共享边框、内边距、背景和文字颜色，文本域纵向缩放及标签纵向布局的说明。")

键盘用户聚焦按钮、链接、表单控件或 `summary` 时，会看到带偏移的清晰轮廓。参考 [键盘焦点轮廓 ↗](../../../packages/ui/src/tokens.css#L38 "支持按钮、链接、表单控件和 summary 元素获得清晰焦点轮廓的说明。") 当系统请求减少动态效果时，页面会关闭动画与过渡，并取消平滑滚动。参考 [减少动态效果 ↗](../../../packages/ui/src/tokens.css#L91 "支持响应系统偏好而关闭动画、过渡和平滑滚动的说明。") 这些规则提供基础可访问性保障，但材料没有说明错误提示、触控尺寸或屏幕阅读器语义如何处理。

<a id="shared-code-theme"></a>
## 让代码与 Markdown 共用高亮语言

代码视图与 Markdown 围栏针对相同的 highlight.js 类名使用一组中性色规则：关键字加粗，注释和引用使用灰色斜体，字符串、属性、标题、内建值与数字以不同灰阶区分。这样既保留基本语法层次，也维持整体阅读风格。参考 [共享代码高亮主题 ↗](../../../packages/ui/src/tokens.css#L99 "支持代码视图与 Markdown 容器共用中性 highlight.js 语法高亮规则及其适用范围的说明。")

这份样式只规定 `.om-code-view` 和 `.om-markdown` 容器内相应类名的呈现，不负责解析代码、渲染 Markdown 或生成高亮类名。现有材料也没有展示样式导入入口，因此不能据此确定哪些页面实际加载了这些规则。
