# 共享视觉令牌与全局基础样式

定义 UI 的中性配色、中文优先字体、标题与表单基线、键盘焦点、减少动效策略，以及代码查看器和 Markdown 共用的语法高亮主题。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="foundation"></a>
## 视觉令牌与排版基线

根节点集中定义正文、次级与弱化文字色，纸张、面板、边线、警告和危险色，以及圆角和中西文字体栈；页面据此建立浅色背景、正文颜色、无衬线字号与统一盒模型。[根视觉变量与页面排版 ↗](../../../packages/ui/src/tokens.css#L1 "支持共享颜色、圆角、字体栈、统一盒模型以及页面正文基础样式的说明。") 一级、二级标题明确改用衬线字体并分别设置字号，形成与正文不同的内容层级；小字则使用更小字号和弱化色。[标题与小字排版规则 ↗](../../../packages/ui/src/tokens.css#L47 "直接支持标题使用衬线字体、标题字号分级及小字弱化样式的论断。")

<a id="controls"></a>
## 表单控件与内容细节

按钮、输入框、文本域和选择器首先继承页面字体；按钮以指针表示可点击，禁用时改为不可用光标并降低透明度。[控件字体与按钮状态 ↗](../../../packages/ui/src/tokens.css#L25 "支持表单控件继承字体，以及按钮普通和禁用状态反馈的说明。") 输入框、文本域和选择器共享最大宽度、边框、圆角、内边距、白色背景及文字色，文本域只允许垂直缩放；标签以纵向 flex 和间距组织字段说明。[输入控件、文本域与标签布局 ↗](../../../packages/ui/src/tokens.css#L63 "直接支持输入控件共享边框、圆角、间距和颜色，以及文本域缩放和标签布局的论断。") 段落另设较宽行高，选中文本使用灰色背景，链接继承上下文颜色，因此该文件提供的是全局基线而非完整组件状态体系。

<a id="accessibility-and-code"></a>
## 键盘、动效与语法主题

按钮、链接、各类输入控件及 `summary` 在 `:focus-visible` 下获得统一轮廓和偏移，为键盘操作提供可见焦点。[可见键盘焦点规则 ↗](../../../packages/ui/src/tokens.css#L38 "支持多类交互元素获得统一焦点轮廓的无障碍行为。") 当系统请求减少动态效果时，全局关闭动画与过渡并取消平滑滚动；其中 `!important` 会覆盖组件自身的相关声明。[减少动态效果媒体查询 ↗](../../../packages/ui/src/tokens.css#L91 "支持系统偏好触发全局禁用动画、过渡和平滑滚动，并说明强制覆盖边界。")

语法主题限定在代码查看器与 Markdown 容器中，按 highlight.js 输出的关键字、注释、字符串、标题、数字等类名设置中性色与字重。它只负责这些类的呈现，是否生成相应高亮标记需由其他模块完成。[共享中性语法主题 ↗](../../../packages/ui/src/tokens.css#L99 "支持代码查看器和 Markdown 围栏共用 highlight.js 类样式，并界定该 CSS 仅负责呈现。")
