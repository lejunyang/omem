# 仓库增量同步、检索与 API 安全测试

覆盖路径稳定身份、不可变 revision、Git 增量扫描、失败基线、检索预过滤、安全边界以及需求与决策锚点解析。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="identity-history"></a>
## 稳定来源身份与历史版本

同步以仓库相对路径区分来源：内容相同的两个文件仍是独立 source；同一文件变化会追加 revision，旧版本保留但退出默认召回。删除文件会标记 removed，默认检索隐藏它，显式参数仍可查看；没有变化的再次同步不会增加 revision。[显式单文件捕获 ↗](../../../apps/server/tests/review-sync.test.ts#L116 "支持指定文件导入、重复同步幂等以及同步后可检索的论断。")[来源身份与 revision 历史 ↗](../../../apps/server/tests/review-sync.test.ts#L143 "支持同内容文件保持独立、内容变化追加版本、删除隐藏及无变化不新增版本。") 这些用例尚未证明路径重命名能够延续原来源身份。

<a id="incremental-reliability"></a>
## Git 增量、脏树与失败基线

增量同步覆盖已提交差异、已修改文件和未跟踪文件；基线无效时退化为全量扫描并给出警告。非法 UTF-8 仅使单文件失败，越界符号链接不会被跟随。[增量扫描与输入边界 ↗](../../../apps/server/tests/review-sync.test.ts#L237 "支持干净基线跳过、提交与脏树共同扫描、失效基线全扫、编码失败隔离和符号链接限制。") 中文路径与未跟踪目录可被展开；脏树或文件失败不会推进 baseline，恢复工作树或修复文件后仍会重新扫描并最终推进。[深候选预过滤与基线可靠性 ↗](../../../apps/server/tests/review-sync.test.ts#L465 "以超过候选池上限的命中证明类别预过滤，并支持非 ASCII 路径、目录展开及失败或脏树不推进基线。")

<a id="retrieval-api-anchors"></a>
## 检索安全与结构化锚点

较小数据集证明 category 查询只返回目标类别，并同时覆盖跨源 POST 拒绝、健康接口路径脱敏和版本 current 标志。[检索与 API 安全行为 ↗](../../../apps/server/tests/review-sync.test.ts#L369 "支持普通规模下的类别过滤、跨源写入拒绝、数据目录脱敏及版本 current 标志。") 更强的 250 个 architecture 命中场景进一步证明类别约束发生在受限候选池之前，唯一 decision 不会被截断淹没。[深候选预过滤与基线可靠性 ↗](../../../apps/server/tests/review-sync.test.ts#L465 "以超过候选池上限的命中证明类别预过滤，并支持非 ASCII 路径、目录展开及失败或脏树不推进基线。") requirement locator 会定位各自标题 fragment，而非共享总表；决策日期来自正文，缺失时为 unknown，并与同步时间分离。[需求锚点与决策日期 ↗](../../../apps/server/tests/review-sync.test.ts#L573 "支持需求引用落到专属标题 fragment，以及正文决策日期与同步时间分离。")
