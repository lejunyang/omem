# 离线知识阅读与证据追溯交互原型

React 单页离线原型，用虚构材料演示知识阅读、固定版本引用、递归证据路径、范围化问答、变更历史及异常证据状态；回答、同步、工作区和引擎均为模拟实现。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-structure"></a>
## 解决的问题与页面结构

该文件把“结论必须能回到原始依据”实现为单页交互原型。`App` 集中维护文章阅读、搜索、来源、变更、能力开关、证据帧栈与问答线程等状态，并通过主导航切换视图。[应用状态与视图入口 ↗](../../../docs/prototype/app.jsx#L339 "支持单个应用组件集中管理阅读、证据、问答、来源、变更和能力状态的说明。") 页面从 `data.js` 导入节点、文章、初始变更和来源，所以本文件负责展示与交互编排，而非真实知识存储。[原型数据导入 ↗](../../../docs/prototype/app.jsx#L9 "说明页面从数据模块取得节点、文章、初始变更和来源。") 最终通过 React 根节点挂载到浏览器页面。[React 应用挂载 ↗](../../../docs/prototype/app.jsx#L1635 "支持该文件作为浏览器端应用入口的判断。")

<a id="evidence-trail"></a>
## 递归证据阅读流程

证据阅读用 `frames` 保存路径：首次打开记录入口焦点，深入引用前保存当前层滚动位置并压入新帧；返回、面包屑跳转和关闭分别裁剪或清空栈。目标已在栈中时仅提示循环，不重复压栈。[证据路径栈操作 ↗](../../../docs/prototype/app.jsx#L404 "解释打开节点、循环检测、滚动保存、返回和跳转的核心流程。") 原生 `dialog` 随栈开关，切层恢复滚动并聚焦标题，全部关闭后把焦点还给入口元素。[对话框与焦点恢复 ↗](../../../docs/prototype/app.jsx#L385 "支持对话框生命周期、逐层滚动记忆及关闭后焦点归还的说明。") 历史版本仍可读并提示现行版本；无权限、已删除或定位失败的节点显示原因，且追问按钮会被禁用。[不可用证据与追问限制 ↗](../../../docs/prototype/app.jsx#L1396 "同时展示不可用材料的原因页及追问按钮按状态禁用，支持其只能查看状态而不能基于正文追问的论断。") URL 初始深链只读取一个节点，复制链接也仅编码当前节点，因此无法恢复完整多层路径。[单节点深链与复制链接 ↗](../../../docs/prototype/app.jsx#L400 "初始化与复制逻辑都只使用当前节点标识，支持完整帧栈未被序列化的判断。")

<a id="qa-and-boundaries"></a>
## 问答、学习与实现边界

`ChatPanel` 根据当前片段、回答范围和路径组装最多五个可用引用，延时生成透明的模板回答；不可访问材料会被拒绝作为证据。[模拟回答与引用筛选 ↗](../../../docs/prototype/app.jsx#L163 "解释回答范围选择、状态过滤、模板生成以及缺失证据时拒答的逻辑。") 回答可以沉淀为待核对候选，但不会直接成为正式事实。[回答沉淀为候选 ↗](../../../docs/prototype/app.jsx#L463 "支持演示回答只形成待核对候选、不会直接成为正式事实的说明。") 变更列表写入浏览器 `localStorage`；恢复只接受当前生效项，会追加反向的新修订，并把原记录标为已恢复，从而保留历史。[本地变更持久化 ↗](../../../docs/prototype/app.jsx#L370 "说明变更列表仅写入当前浏览器的本地存储。")[恢复生成新修订 ↗](../../../docs/prototype/app.jsx#L527 "支持恢复操作追加反向记录、保留原记录并改变其状态的语义。") 来源同步通过计时器模拟状态变化，工作区按钮仅提示本地示例；能力页也明确数据库、外部服务和引擎开关尚未真实连接。[模拟来源同步与本地工作区 ↗](../../../docs/prototype/app.jsx#L550 "同步逻辑只通过前端状态和定时器模拟，工作区入口也明确提示所有材料与问答均为本地示例。")[未连接的外部能力 ↗](../../../docs/prototype/app.jsx#L1189 "支持数据库、外部服务和学习引擎开关均处于演示或待接入状态的判断。")

<a id="coverage"></a>
## 边界场景与验证缺口

界面提供八层路径、百层合成长链、受限、删除和定位不唯一等入口，用于观察深层导航与异常材料展示。[异常状态体验入口 ↗](../../../docs/prototype/app.jsx#L697 "说明原型刻意提供深链和多类不可用来源作为边界场景。") 文本选择会排除控件区域，并要求选择起止于同一可选择容器且内容长度大于一。[文本选择约束 ↗](../../../docs/prototype/app.jsx#L495 "支持只接受同一选择容器内有效文本且排除控件交互的边界说明。") 当前材料未提供原型自身的测试文件，因此循环路径、逐层 Esc、焦点归还、滚动恢复、输入法组合输入、剪贴板降级和存储异常只能从实现推断，不能确认已有自动化回归保障。
