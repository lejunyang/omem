# 带行锚点与引用入口的代码阅读器

该组件将源码呈现为可滚动、带绝对行号的阅读视图，并整合异步语法高亮、目标行定位、范围导航和逐行引用。高亮失败或语言未知时仍会安全显示转义后的源码；范围点击目前只输出行号，重叠范围则按输入顺序选择首个匹配项。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 从源码阅读回到具体证据

`OmCodeViewer` 用于阅读一段带原始行号的源码，并让读者从具体代码行继续打开引用或发起导航。调用方可以传入代码、语言、起始行、目标行、高亮行、范围与行级引用；组件对外发出“打开引用”和“导航”事件，最终目的地仍由外层页面决定。参考 [阅读器输入与事件 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L14 "支持组件可接收定位、范围和引用数据，并把引用打开及导航交给外层处理的说明。")

代码按行渲染，行号位于独立栏中，引用按钮则附着在对应代码行。视图使用等宽字体并限制最大高度，长内容可在组件内部滚动；窄屏下仅缩小行号栏的左右内边距。参考 [逐行代码结构 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L82 "支持代码按行渲染、行号置于独立单元格以及引用按钮附着于代码行的说明。")、[滚动与排版 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L104 "支持视图内部滚动、最大高度和等宽字体排版的说明。")、[窄屏行号栏 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L159 "支持窄屏时缩小行号栏左右内边距的说明。")

<a id="highlight-flow"></a>
## 异步高亮与安全回退

代码或语言变化时，组件会清空旧高亮并启动新的异步任务。递增的代际编号保证只有最近一次任务能够写入结果或结束加载状态，避免较慢的旧任务覆盖新代码；高亮失败时保留空映射，模板会改用经过 HTML 转义的原始文本。参考 [高亮任务代际控制 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L34 "支持异步高亮、旧任务隔离、异常回退和加载状态更新流程。")

高亮工具根据语言别名动态加载语法包，未知语言直接返回转义文本；XML 类内容还会准备 JavaScript 与 CSS 语法。高亮结果中的跨行 `<span>` 会在行末临时闭合并在下一行恢复，使每个表格行都能独立渲染，同时保持多行词法状态。参考 [语言加载与跨行着色 ↗](../../../packages/ui/src/highlight.ts#L21 "解释高亮工具如何处理语言别名、动态加载、安全转义和跨行 HTML 状态。")

<a id="navigation-limits"></a>
## 定位、引用与范围选择

当目标行变化时，组件等待页面更新，把对应行滚动到视口中央并设置闪烁状态；实际动画只播放一次、持续 `0.6s`，状态在三秒后清除。系统偏好减少动态效果时会禁用该动画。参考 [目标行定位状态 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L51 "支持目标行滚动到视口中央、设置闪烁状态并在三秒后清除状态的说明。")、[闪烁动画时长 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L138 "支持闪烁动画实际持续 0.6 秒且在减少动态效果偏好下被禁用的说明。")

点击代码行时，只有该行落入某个范围才会触发导航，而且当前事件只携带行号。范围查找使用 `find`，因此多个范围重叠时会选择输入数组中的首个匹配项。参考 [范围选择与行导航 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L68 "支持范围查找选择首个匹配项，以及范围点击当前只发送行号的边界说明。") 行级引用按钮会阻止点击继续冒泡，并单独发出引用目标，避免同时触发行导航。参考 [逐行引用按钮 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L91 "支持引用按钮按绝对行号显示、阻止点击冒泡并发出引用目标的说明。")
