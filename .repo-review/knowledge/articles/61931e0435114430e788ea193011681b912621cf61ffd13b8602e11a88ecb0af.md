# 带稳定行锚点的源码查看器

按行展示完整源码，异步完成语法高亮，并提供行号锚定、范围标记、引用打开与行导航事件。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="pipeline"></a>
## 高亮与竞态处理

查看器接收源码、语言、起始行、锚点、高亮行、范围及逐行引用；它把语法着色委托给共享 highlight 模块，并将返回 HTML 拆成逐行片段。[源码查看器输入与高亮依赖 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L1 "说明查看器的输入合同、输出事件以及对共享高亮模块的依赖。") 每次源码或语言变化都会递增 generation、清空旧结果并进入 loading；异步结果只有仍属于最新代次时才写回，失败则退回空高亮映射，模板随后使用转义后的原文。这避免较慢的旧请求覆盖新内容，也保证高亮失败时仍能安全显示代码。[异步高亮状态机 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L29 "支持 generation 防竞态、失败降级和 loading 状态的核心流程说明。")

<a id="navigation"></a>
## 行定位与事件流

startLine 负责把数组下标转换为稳定显示行号。anchorLine 更新后，组件等待 DOM 刷新，将对应行滚动到视口中央并短暂闪烁三秒；显式 highlightLines 与锚点都会形成命中背景。[锚点滚动与命中判断 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L51 "支持锚点变化后的滚动、闪烁及高亮行判定。") 点击处于 ranges 中的代码行只发出带 line 的 navigate 事件；范围的 id、kind、title 除标题提示外未进入导航载荷。逐行引用按钮则阻止事件冒泡并发出 open-reference，其目标解释仍由父层处理。[逐行渲染与导航 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L68 "说明范围点击导航、稳定行号、引用按钮和安全回退渲染的行为。")

<a id="boundaries"></a>
## 显示边界与依赖

组件通过 v-html 注入共享高亮模块生成的片段；该模块对未知语言先转义文本，对已知语言使用 highlight.js，并维护跨行 span 状态，因此这里依赖其输出安全约束。[共享高亮与逐行 HTML ↗](../../../packages/ui/src/highlight.ts#L21 "证明未知语言会转义，并说明多行 span 被拆成有效逐行 HTML 的依赖约束。") 表格限制为 70vh 并可滚动，窄屏仅收紧行号栏；没有虚拟列表，大文件会为每一行创建表格节点，性能上限未在材料中验证。范围重叠时使用 find，只有首个匹配范围生效，且行点击不会携带该范围的目标身份。
