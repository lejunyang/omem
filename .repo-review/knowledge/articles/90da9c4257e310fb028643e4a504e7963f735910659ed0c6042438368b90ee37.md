# ConversationRouter 会话身份与轮次持久化测试

验证会话路由按主体、渠道、聊天与线程形成稳定身份，并记录有序轮次、输入、工具动作和当前目标；测试会写入所选证据，但尚未断言其从历史往返还原。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="identity-routing"></a>
## 会话身份与隔离维度

ConversationRouter 测试使用真实临时 Store，并在每个用例后关闭数据库、删除目录，以隔离测试状态。[路由器测试资源生命周期 ↗](../../../apps/server/tests/conversation-router.test.ts#L8 "说明测试以临时 Store 运行，并在用例结束后关闭和清理资源。") 相同 principal、channel、chat 与缺省 thread 的重复 `open` 返回同一会话；改变聊天或渠道会得到不同标识，且首个会话保持 `private`，缺省 thread 被规范化为空字符串。[会话组合键复用 ↗](../../../apps/server/tests/conversation-router.test.ts#L23 "支持相同组合键复用、聊天或渠道变化产生不同会话，以及缺省线程和可见性断言。") 因而当前证据支持组合键复用，而非仅按聊天号复用；显式 thread、不同 principal、群组可见性和并发冲突不在本文件覆盖范围内。

<a id="turns-goals"></a>
## 轮次顺序、历史与目标

轮次从 1 开始并单调推进，两次记录后下一个 ordinal 为 3。测试在首轮写入了所选证据，在次轮写入结构化工具动作；历史断言只确认输入文本按顺序返回，并确认第二轮工具动作可还原，未断言 `selectedEvidence` 的历史往返。[有序轮次与有限历史断言 ↗](../../../apps/server/tests/conversation-router.test.ts#L45 "支持 ordinal 递增、写入所选证据与工具动作，并准确限定历史只断言输入文本和工具动作。") 这替代了此前“历史能够还原所选证据”的过强结论。会话还可保存当前目标并经 `get` 读取。[会话当前目标 ↗](../../../apps/server/tests/conversation-router.test.ts#L83 "支持路由器能够设置并读取会话级当前目标。") 本文件没有证明工具动作被执行，也未覆盖时间戳、回滚、幂等、并发写入或跨重启读取。
