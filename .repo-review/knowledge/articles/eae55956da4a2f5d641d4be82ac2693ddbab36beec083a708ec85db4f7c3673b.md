# 工作区的阅读布局、交互状态与移动端适配

这份样式表为工作区导航、正文阅读、材料片段、表单与反馈元素建立以黑白灰为主的视觉体系，并用危险色突出错误。它侧重信息密集页面的可读性、当前位置辨识和窄屏布局；仅凭 CSS 尚不能确认状态由哪些组件驱动，也不能判断隐藏信息后的实际可访问性。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="workspace-navigation"></a>
## 让工作区入口清晰可辨

顶部控制区采用横向弹性布局，输入框宽度不超过 460 像素，并让通知按钮文字保持单行，适合搜索或筛选入口与通知操作共享一行。参考 [顶部控制区 ↗](../../../apps/web/src/styles.css#L1 "支持顶部输入框与通知按钮采用弹性同行布局、输入宽度受限和通知文字不换行的说明。")

侧栏导航纵向排列，按钮具有至少 44 像素的高度，并通过悬停和深色激活样式帮助用户辨认当前位置。来源入口同样保留足够的点击高度，允许长文本换行，并以浅灰背景标识当前选择。参考 [导航与来源状态 ↗](../../../apps/web/src/styles.css#L32 "支持侧栏纵向排列、按钮最小高度、悬停与激活样式，以及来源入口换行和选中状态的说明。")

这些规则只定义 `active`、`selected` 等状态呈现后的视觉效果；材料没有展示具体 Vue 组件，因此无法据此判断状态由谁设置、何时切换。

## 围绕长文与材料片段组织阅读

正文区域限制为 950 像素宽并居中显示，配合较宽留白和标题自动换行，使长标题与连续字符不易撑破页面。材料片段用分隔线组织连续内容，正文保留原始换行、允许任意位置折行，并以较大行高改善阅读体验；聚焦片段仅加强分隔线，提供克制的视觉提示。参考 [正文阅读容器 ↗](../../../apps/web/src/styles.css#L88 "支持正文最大宽度、居中留白及标题长文本换行策略的说明。") [材料片段排版 ↗](../../../apps/web/src/styles.css#L135 "支持片段分隔、聚焦提示、原始换行保留和正文行高的说明。")

阅读提示块使用浅灰背景与紧凑字号承载辅助说明；示例引文采用衬线字体、较大字号和柔和底色突出展示；长摘要限制为 140 像素高度，超出后可滚动，避免单段内容挤占页面。参考 [阅读提示块 ↗](../../../apps/web/src/styles.css#L125 "支持阅读提示块的浅灰背景、字号、布局和间距说明。") [示例引文 ↗](../../../apps/web/src/styles.css#L205 "支持示例引文采用衬线字体、较大字号、柔和背景和内边距的说明。") [可滚动摘要 ↗](../../../apps/web/src/styles.css#L193 "支持长摘要限制高度、保留换行并在溢出时滚动的说明。")

知识文章中的编辑性阅读目标会被隐藏，样式注释说明由文章摘要承担面向读者的介绍，从而把工作流元数据与产品正文分开。参考 [隐藏编辑阅读目标 ↗](../../../apps/web/src/styles.css#L275 "支持知识文章隐藏编辑性阅读目标、由摘要承担读者介绍的设计意图。")

<a id="feedback-responsive"></a>
## 反馈信息与窄屏退化策略

界面整体以黑白灰为主，但错误反馈是明确例外：错误横幅使用浅红背景、红色边框和危险色文字，并以弹性布局分隔其中的内容。Toast 则固定在视口底部中央，采用深色背景、受限宽度、阴影和较高层级，使其在视觉上浮于页面内容之上。参考 [错误与浮层样式 ↗](../../../apps/web/src/styles.css#L170 "支持错误横幅的危险色和弹性布局，以及 Toast 的固定位置、宽度、颜色、阴影与层级说明。")

页面采用两个响应式断点：宽度低于 1100 像素时收紧正文和顶栏留白；低于 700 像素时进一步缩小页面边距与标题字号，将双列表单改为单列，并调整输入框、按钮、提示块和 Toast。顶栏徽标也会在这一断点下隐藏。参考 [窄屏响应式规则 ↗](../../../apps/web/src/styles.css#L213 "支持两个响应式断点及移动端正文、顶栏、表单、徽标和反馈元素的样式调整。")

这些规则说明了布局如何适应窄屏，但没有提供实际页面结构或视口验证，因此仍无法确认隐藏徽标后是否保留等价状态信息，也不能仅凭样式判断键盘和屏幕阅读器体验。
