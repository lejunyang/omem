# Web 应用级布局、阅读状态与响应式样式

定义导航、页面内容、片段阅读、表单、错误和通知等应用级视觉规则，并在窄屏下调整布局；它依赖共享设计令牌，但材料未展示对应模板与视觉测试。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="layout-and-navigation"></a>
## 导航与页面骨架

样式文件为应用外壳补充具体布局：顶部控制区使用横向弹性布局，搜索输入采用深色背景并限制最大宽度；导航则纵向排列，按钮提供至少 44px 的触控高度，并用深色活动态区分当前位置。[顶部控制区与导航状态 ↗](../../../apps/web/src/styles.css#L1 "支持顶部控件、导航排列、触控高度以及活动状态的样式说明。") 来源链接允许任意位置换行，选中与悬停状态采用浅灰背景，适合展示较长路径。主内容通过固定最大宽度、自动居中和较大内边距形成阅读栏，页顶栏负责标题区分隔和状态信息排列。[来源链接与页面框架 ↗](../../../apps/web/src/styles.css#L64 "说明长路径换行、来源选中态、页顶栏和居中内容栏的布局。")

<a id="reading-and-feedback"></a>
## 阅读内容与反馈状态

阅读区以底部分隔线组织片段，聚焦片段加深边线；正文保留换行、允许长文本断行，并使用较宽松的行高。[阅读片段样式 ↗](../../../apps/web/src/styles.css#L125 "支持片段分隔、聚焦状态、正文换行和行高设计。") 表单支持纵向字段栈和双列网格，错误横幅使用危险色，Toast 固定在视口底部中央且具有较高层级；摘录区域限制高度并滚动，避免长证据无限撑开页面。[表单与反馈组件样式 ↗](../../../apps/web/src/styles.css#L154 "说明双列表单、错误横幅、Toast 和长摘录滚动区域的表现。") 这些规则只负责视觉呈现，是否显示、何时聚焦以及 Toast 生命周期仍需由组件逻辑决定。

<a id="responsive-boundaries"></a>
## 响应式边界与依赖

文件依赖 `--om-secondary`、`--om-muted`、`--om-line`、`--om-ink` 等共享 CSS 变量，因此需要入口先加载 UI 令牌。[共享设计变量使用 ↗](../../../apps/web/src/styles.css#L37 "支持应用样式依赖共享颜色与边线令牌，而不是完全自包含。") 在 1100px 以下页面缩小留白；700px 以下进一步收紧页面和顶栏、隐藏顶栏徽章、压缩控制区与按钮，并把双列表单改成单列。[窄屏响应式规则 ↗](../../../apps/web/src/styles.css#L212 "支持 1100px 与 700px 两级断点下的留白、控件、表单及反馈布局变化。") Toast 在手机宽度下固定为 90vw，阅读提示改为顶部对齐。材料没有横向滚动、超窄屏、系统深色模式、减少动画或安全区适配规则，也未提供 HTML 结构，因而无法确认所有选择器当前都有对应元素。
