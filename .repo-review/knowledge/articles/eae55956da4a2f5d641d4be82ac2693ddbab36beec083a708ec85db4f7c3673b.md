# Web 应用页面与阅读界面样式

该样式表定义顶部控件、导航、正文阅读、表单及反馈组件的页面级布局，并通过 1100px 和 700px 两级断点适配窄屏。交互状态来源、主题变量定义及无障碍表现无法仅凭此文件确认。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="layout-navigation"></a>
## 顶部控件、导航与正文布局

顶部控件采用横向弹性布局并在两端分布内容；搜索输入最大宽度为 460px，同时允许随可用空间收缩。通知按钮保持文字不换行，工作区标题则为辅助说明预留间距。[顶部控件与搜索输入 ↗](../../../apps/web/src/styles.css#L1 "支持顶部控件的弹性排列、搜索输入的宽度与收缩行为，以及通知按钮和工作区标题的基本样式。")

导航及来源列表纵向组织，按钮和来源项均具有至少 44px 的高度。悬停、激活和选中选择器提供不同背景或文字颜色，长来源名称允许任意位置换行。[导航与来源列表 ↗](../../../apps/web/src/styles.css#L32 "支持导航纵向布局、最小交互高度、悬停与选择状态、长名称换行及所依赖主题变量的说明。") 页栏固定为 51px 高并两端对齐，正文以 950px 为最大宽度居中，一级标题可处理超长文本；这些规则只说明视觉布局，不能证明页栏实际承载哪些业务状态。[页栏与正文容器 ↗](../../../apps/web/src/styles.css#L88 "支持页栏尺寸和对齐方式、正文最大宽度与留白，以及标题长文本断行和相关主题变量依赖。")

<a id="reading-forms-feedback"></a>
## 阅读内容、表单与操作反馈

阅读区把证据片段组织成带底部分隔线的内容流，聚焦片段使用更深的边线。片段正文保留原始换行、允许长串断行，并使用较宽行距增强连续阅读的可读性。[证据片段阅读样式 ↗](../../../apps/web/src/styles.css#L125 "支持片段分隔、聚焦边线、原始换行保留、长文本断行和阅读行距的说明。") 表单默认纵向排列；双字段区域在宽屏使用两列网格，提交按钮靠起始侧对齐。[表单与双字段网格 ↗](../../../apps/web/src/styles.css#L154 "支持表单纵向排列、双字段两列网格、字段间距和提交按钮对齐方式。")

错误横幅以浅红背景和危险色文字呈现页内异常，toast 固定在视口底部中央并限制最大宽度。摘录区域限制高度且允许滚动，样例引文依赖衬线字体与柔和背景变量，`summary` 则具有 44px 最小交互高度。[错误、通知与摘录反馈 ↗](../../../apps/web/src/styles.css#L170 "支持错误横幅、固定 toast、可滚动摘录、样例引文主题依赖及 summary 最小交互高度。")

<a id="responsive-theme"></a>
## 响应式边界与主题依赖

在 1100px 以下，正文与页栏缩小横向留白；在 700px 以下，正文进一步收紧、标题缩小、页栏徽标隐藏，搜索框与通知按钮压缩字号和间距，双列表单改为单列，阅读提示、错误横幅和 toast 也同步调整。[窄屏响应式规则 ↗](../../../apps/web/src/styles.css#L212 "支持 1100px 与 700px 两级断点下页面、顶部控件、表单、阅读区和反馈组件的调整。")

导航依赖 `--om-secondary`、`--om-muted` 与 `--om-ink`，页栏、片段和反馈区域还使用边线、危险色、衬线字体及柔和背景等全局变量。[导航与来源列表 ↗](../../../apps/web/src/styles.css#L32 "支持导航纵向布局、最小交互高度、悬停与选择状态、长名称换行及所依赖主题变量的说明。")[页栏与正文容器 ↗](../../../apps/web/src/styles.css#L88 "支持页栏尺寸和对齐方式、正文最大宽度与留白，以及标题长文本断行和相关主题变量依赖。")[错误、通知与摘录反馈 ↗](../../../apps/web/src/styles.css#L170 "支持错误横幅、固定 toast、可滚动摘录、样例引文主题依赖及 summary 最小交互高度。") 因此，本文件无法单独确认变量在深色模式中的取值、颜色对比度是否达标，也不能证明 `active`、`selected` 与 `focused` 状态由哪些组件或事件驱动。
