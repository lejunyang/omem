# 知识正文引导的原始证据召回

该模块用已生成的知识正文扩大检索入口，但最终只返回仍有效且与引用行区间重叠的原始 Fragment；它通过依赖摘要校验、文章引用递归、引文核对和结果去重，避免把派生知识直接当作证据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 作用与数据边界

`knowledgeEvidenceCandidates` 连接知识正文检索与原始证据召回：它先在当前知识修订的序列化内容中按词项模糊匹配，查询至多取 30 篇文章，再沿正文引用寻找原始 Fragment，而不把派生文章本身作为证据返回。检索词为空或知识表不存在时直接返回空数组。[知识候选查询入口 ↗](../../../apps/server/src/knowledge/retrieval.ts#L8 "支持空输入和缺表短路、知识正文模糊匹配以及 SQL 查询最多选取 30 篇候选文章的说明。")

来源解析区分 `omem:` 文件键和其他命名空间，读取 source 的 head revision，并排除上下文或 provenance 标记为 derived 的材料。文本和链接被拼接为可定位文本；图片信息参与材料身份摘要，但不进入文本坐标。[原始来源解析与派生材料排除 ↗](../../../apps/server/src/knowledge/retrieval.ts#L14 "支持 source head 解析、派生来源排除、文本与链接拼接及图片摘要输入的说明。")

<a id="flow"></a>
## 依赖校验与引用回溯

遍历知识产物前会校验全部依赖：material 依赖重新计算稳定摘要，article 依赖比较当前修订 ID；任一依赖不一致便放弃该产物。材料摘要覆盖文本、图片、作者和引用或转发标志；摘要工具递归排序对象键、忽略 `undefined`，再以规范 JSON 计算 SHA-256，因此表达的是稳定内容身份，而非语义相似度。[知识依赖有效性检查 ↗](../../../apps/server/src/knowledge/retrieval.ts#L27 "支持遍历前按材料摘要或文章修订 ID 校验依赖、失效时停止使用整篇产物的论断。")[稳定摘要实现 ↗](../../../apps/server/src/storage/digest.ts#L3 "解释摘要如何递归规范化数据、排序对象键、忽略未定义值并计算 SHA-256。")

遍历仅处理命中章节正文实际出现的引用键。文章引用可递归进入指定章节；材料引用必须具有非空 quote、有效行号，且固定行区间确实包含该引文。随后函数按字符区间选出与引文重叠的数据库 Fragment，并返回其原始文本、修订、标题、命名空间和作者信息。[引用递归与原始 Fragment 映射 ↗](../../../apps/server/src/knowledge/retrieval.ts#L37 "支持文章章节递归、材料引文行区间校验，以及按字符重叠映射回原始 Fragment 的流程。")

<a id="limits"></a>
## 遍历限制、容错与待确认契约

递归仅在深度不超过 8 且进入 `visit` 时结果数尚未达到 100 的情况下继续，并以“文章键加引用键”防止重复访问、以 Fragment ID 去重。这里的 100 不是严格输出上限：某次 `visit` 开始时若尚未达到阈值，其同一轮引用和 Fragment 循环仍可能把结果增加到 100 以上；达到阈值后只会阻止后续新的 `visit` 进入。无法按拼接文本定位的 Fragment 会被跳过，代码注明图片占位不属于文本坐标；无效 JSON 或投影异常也不会中断其他候选处理。[遍历阈值、去重与容错 ↗](../../../apps/server/src/knowledge/retrieval.ts#L33 "支持深度与进入遍历时的数量阈值，并说明循环内没有再次检查结果数，因此 100 不是严格输出上限；同时支持去重、图片坐标跳过和异常容错的描述。")

现有材料未包含调用方或行为测试，因此无法确认 terms 是否始终预先转为小写，也无法证明注释所称的助手可见性过滤覆盖所有调用路径；本函数自身未实施该过滤。知识合同只约束引用目标、行号、section、quote 和疑问等数据形状，不能替代这些运行时契约的验证。[知识引用与疑问合同 ↗](../../../packages/contracts/src/knowledge.ts#L4 "说明合同规定引用目标、位置、quote 与疑问字段的数据形状，但不证明调用链中的词项规范化或可见性过滤行为。")
