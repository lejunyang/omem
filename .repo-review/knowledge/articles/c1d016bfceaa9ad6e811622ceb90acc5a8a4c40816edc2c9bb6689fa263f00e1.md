# 用知识讲解找回原始证据

解释知识文章如何作为检索导航，把读者问题映射回经过版本与引文校验的原始材料片段，而不把派生讲解冒充独立事实。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决什么问题

知识文章往往使用更贴近读者的说法，原始代码或文档却未必包含这些词。这里让**派生讲解充当检索导航**，但返回值始终是固定原件片段；助手可见性规则仍由后续流程处理。参考 [派生知识只作导航 ↗](../../../apps/server/src/knowledge/retrieval.ts#L1 "支持派生讲解参与检索但候选仍必须回到固定原件，以及可见性规则在后续执行。")

入口 `knowledgeEvidenceCandidates(db, terms)` 接收数据库与已分词的查询。没有查询词或尚未建立知识表时直接返回空数组；有数据时只读取当前知识版本，并只搜索段落、列表、引用和表格等可读正文，排除代码块、Mermaid、标题与元数据。参考 [入口与正文抽取 ↗](../../../apps/server/src/knowledge/retrieval.ts#L11 "支持函数输入、空查询和缺表返回，以及只读取当前知识并从 Markdown 中提取可读正文的行为。")

<a id="flow"></a>
## 一条代表性调用怎样工作

例如查询词命中某篇文章中“避免重复配送”的段落：函数先给各正文块计算相关度，只取该块实际出现的引用键；若引用指向子文章，则限定到指定章节继续展开，并把分数沿链路传递。显式章节即使措辞不同，也可作为背景继续解析，但不会扩展到兄弟章节。参考 [章节引用递归 ↗](../../../apps/server/src/knowledge/retrieval.ts#L50 "支持校验依赖、按命中正文块筛选引用、限定子文章章节、处理措辞不同的显式背景章节并传递相关度。")

```mermaid
flowchart LR
  Q[查询词] --> P[匹配知识正文块]
  P --> C[筛选块内引用]
  C --> V[校验固定依赖与精确引文]
  V --> F[映射重叠的原始 fragment]
```

落到材料引用后，代码先确保整篇知识产物的依赖仍对应当前材料或文章，再核对引用的行范围和保存的精确引文；随后把引用区间换算为字符坐标，收集所有与之重叠的原始 fragment。输出包含 fragment、revision、标题、来源命名空间、作者和引导分数，可直接并入统一证据候选。参考 [章节引用递归 ↗](../../../apps/server/src/knowledge/retrieval.ts#L50 "支持校验依赖、按命中正文块筛选引用、限定子文章章节、处理措辞不同的显式背景章节并传递相关度。") [引文映射原始片段 ↗](../../../apps/server/src/knowledge/retrieval.ts#L71 "支持校验材料引用行与精确引文、换算字符区间，并输出全部重叠的原始 fragment；也说明一次访问可能增加多个结果。")

<a id="boundaries"></a>
## 可信边界与修改入口

任一依赖摘要不再匹配时，整篇产物不参与导航；派生来源、空引文、越界行号或无法在原文中找到的引文也会被跳过。递归深度超过 8 层即停止；当准备进入一次新的 `visit` 时，如果已有 100 个结果，也停止该次访问。这个阈值约束的是继续递归或访问，并非严格的返回上限：已经开始的访问仍会处理其余引用，而单个材料引用会加入全部重叠 fragment，因此结果数可能超过 100。按“文章 + 引用键”记录已见分数，可避免以相同或更低分重复遍历。参考 [版本与遍历停止条件 ↗](../../../apps/server/src/knowledge/retrieval.ts#L49 "支持依赖失效即跳过、深度超过 8 层即停止，以及只在进入 visit 时以已有 100 个结果阻止继续访问；该检查不是严格返回数量上限。") [引文映射原始片段 ↗](../../../apps/server/src/knowledge/retrieval.ts#L71 "支持校验材料引用行与精确引文、换算字符区间，并输出全部重叠的原始 fragment；也说明一次访问可能增加多个结果。")

图片占位不当作文本坐标；同一 fragment 被多条路径命中时保留更高的 `guide_score`。文章标题兜底只在正文无任何得分、查询词不超过两个、**所有查询词都被小写后的文章标题字面包含**且存在正文块时触发，并把首个正文块设为 0.4；单篇产物解析失败不会中断其他原始证据检索。要调整“哪些内容可搜索”，修改 `passages`；要调整递归、标题兜底或规模边界，分别查看遍历和最终匹配逻辑。参考 [文本坐标与分数去重 ↗](../../../apps/server/src/knowledge/retrieval.ts#L81 "支持图片占位不参与文本坐标，以及同一 fragment 保留更高引导分数。") [标题兜底与故障隔离 ↗](../../../apps/server/src/knowledge/retrieval.ts#L92 "支持标题兜底必须同时满足正文无得分、查询词不超过两个、全部查询词命中文章标题和存在正文块，并说明坏产物不打断检索。")
