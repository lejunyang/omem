# 派生知识引导的原始证据召回

从当前知识正文的关键词命中出发，核验整篇文章的依赖后沿引用链回溯原始固定 Fragment；实现具有入口级数量保护、九层文章访问范围与逐引用容错，但不保证结果严格不超过三十项。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="entry"></a>
## 检索入口与候选文章

该实现把派生正文仅作为检索导航，返回候选始终是原始固定 Fragment，后续仍需应用助手可见性规则。[派生正文的检索边界 ↗](../../../apps/server/src/knowledge/retrieval.ts#L1 "支持派生知识仅引导检索、返回对象仍为原始固定 Fragment，并保留后续可见性检查的论断。") 查询词为空或知识表不存在时返回空；否则在 current head 的文章投影中执行转义后的 `LIKE` 匹配，SQL 最多取三十篇候选文章，并在单次调用内缓存材料来源与子文章。[当前文章筛选与缓存 ↗](../../../apps/server/src/knowledge/retrieval.ts#L8 "支持空查询处理、current head 限定、转义关键词匹配、候选文章 SQL 限量及调用内缓存。")

<a id="verification"></a>
## 依赖核验与引用回溯

每篇文章开始遍历前，会重建材料内容摘要并核对子文章当前修订；任一依赖缺失或摘要、修订不符，都会终止整篇文章的证据输出，而非只跳过该依赖。校验通过后，顶层仅遍历命中章节正文里实际出现的引用键；子文章则递归处理其全部引用。材料引用必须含非空精确引文，且该引文仍能在当前来源的某个 Fragment 中定位，最终返回该 Fragment 及其修订、来源和作者信息。[依赖校验与引用链遍历 ↗](../../../apps/server/src/knowledge/retrieval.ts#L33 "支持整篇文章的依赖校验、递归深度计数、入口级结果数量检查，以及材料引文定位和逐引用跳过行为。")

<a id="limits"></a>
## 命中范围、边界与容错

顶层命中范围包括文章标题、摘要以及章节标题或正文；命中的章节再从正文提取引用键，无效文章投影不会中断其他候选的处理。[章节命中与失败隔离 ↗](../../../apps/server/src/knowledge/retrieval.ts#L49 "支持文章标题、摘要、章节标题和正文的命中范围，以及从章节正文提取引用键和解析失败隔离。") 递归从 `depth=0` 开始、仅在大于八时停止，因此可访问九个文章层级，等价于最多八次子文章跳转。`output.size >= 30` 只在进入一次文章遍历时检查；同一遍历的引用循环仍可能继续加入多个 Fragment，所以此前“输出最多三十项”的硬上限结论已被替代。空引文或无法定位引文时只跳过该条材料引用；此前将“来源不存在”一概描述为逐路径跳过也已被替代，因为依赖来源缺失会先使整篇文章停止输出。[依赖校验与引用链遍历 ↗](../../../apps/server/src/knowledge/retrieval.ts#L33 "支持整篇文章的依赖校验、递归深度计数、入口级结果数量检查，以及材料引文定位和逐引用跳过行为。")
