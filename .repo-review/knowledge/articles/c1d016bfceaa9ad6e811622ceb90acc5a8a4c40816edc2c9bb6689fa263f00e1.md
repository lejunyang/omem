# 派生知识引导的原始证据召回

在 current 知识文章中匹配查询词，再沿通过摘要核验的引用链定位原始固定 Fragment；派生正文只负责导航，不作为返回证据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="entry"></a>
## 检索入口与候选文章

该实现把派生正文限定为检索导航，最终候选仍是原始固定 Fragment，之后还需执行助手可见性规则。[派生正文的检索边界 ↗](../../../apps/server/src/knowledge/retrieval.ts#L1 "支持派生知识仅用于导航、返回项仍为原始固定 Fragment。") 查询词为空或知识表不存在时返回空；否则只检索 current head，以转义后的 LIKE 条件匹配文章投影，SQL 最多先取三十篇，并为来源与子文章建立本次调用缓存。[当前文章筛选与缓存 ↗](../../../apps/server/src/knowledge/retrieval.ts#L8 "支持空查询处理、current head 限制、LIKE 转义、SQL 初始上限和缓存。")

<a id="verification"></a>
## 依赖核验与引用回溯

遍历一篇文章前会核对其全部材料摘要及子文章修订；任何依赖缺失或不一致都会终止整篇文章的证据输出。[知识引用链回溯 ↗](../../../apps/server/src/knowledge/retrieval.ts#L33 "说明依赖整体核验、实际深度判定、非硬性数量检查及 Fragment 定位。") 顶层只处理命中章节正文里实际出现的引用键；引用子文章时递归遍历其引用。材料引用要求非空精确引文仍能在当前来源的某个 Fragment 中找到，随后返回固定 Fragment 及 Revision、来源和作者信息；空引文或无法定位的引文仅跳过该条引用。[知识引用链回溯 ↗](../../../apps/server/src/knowledge/retrieval.ts#L33 "说明依赖整体核验、实际深度判定、非硬性数量检查及 Fragment 定位。")[命中章节筛选与失败隔离 ↗](../../../apps/server/src/knowledge/retrieval.ts#L49 "支持标题、摘要、章节标题和正文匹配，以及无效投影的失败隔离。")

<a id="limits"></a>
## 深度、数量与失败边界

递归从顶层 `depth=0` 开始，在 `depth>8` 时停止，因此最多访问 depth 0 至 8 的九个文章层级，也就是最多八次子文章跳转。入口还会在 `output.size>=30` 时拒绝新的 visit，但单次已进入的引用循环可继续加入多个 Fragment，所以三十并非严格结果上限。[知识引用链回溯 ↗](../../../apps/server/src/knowledge/retrieval.ts#L33 "说明依赖整体核验、实际深度判定、非硬性数量检查及 Fragment 定位。") 顶层匹配标题、摘要、章节标题或章节正文；知识投影解析失败不会中断其他文章的召回。[命中章节筛选与失败隔离 ↗](../../../apps/server/src/knowledge/retrieval.ts#L49 "支持标题、摘要、章节标题和正文匹配，以及无效投影的失败隔离。") 实现依赖精确引文，没有语义匹配或跨修订位置续接。
