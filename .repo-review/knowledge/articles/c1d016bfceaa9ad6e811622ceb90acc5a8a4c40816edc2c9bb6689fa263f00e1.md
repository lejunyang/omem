# 让知识文章引导检索回到原始证据

解释知识文章如何用读者可见的正文引导查询，再沿精确引用返回当前有效的原始材料片段，并说明段落范围、递归依赖、引用映射与候选阈值的真实边界。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决什么问题

知识文章通常比原始文件更接近读者的提问方式，但文章是派生解释，不能成为第二份事实。这个模块把两者接起来：文章正文负责提供概念入口，返回候选始终是引用所指向的固定原始片段；助手可见性等规则留给后续检索阶段。参考 [派生知识回到原始片段 ↗](../../../apps/server/src/knowledge/retrieval.ts#L1 "支持文章正文只用于引导检索、候选保持为原始固定片段，以及可见性规则在后续执行。")

例如，读者搜索文章中解释过的业务名称时，系统可以先命中那段解释，再回到它旁边的材料引用。这样结果仍能定位原文，而不会把整篇讲解当作证据。

<a id="flow"></a>
## 一次命中如何落到证据

函数先把每篇当前知识文章的 Markdown 拆成可读文字块：段落、普通文本、列表项、引用块和表格行会参与匹配，标题、代码块、Mermaid 与元数据不会作为解释性正文。命中粒度因此贴近引用所在的文字块，避免一个章节命中后扩散到章节中的所有来源。参考 [可读正文分块 ↗](../../../apps/server/src/knowledge/retrieval.ts#L11 "说明哪些 Markdown 内容参与正文匹配，以及代码、图表、标题和元数据为何不会扩大召回。")

收到非空词项后，函数读取当前知识头，并为材料和文章建立缓存。材料必须能解析到当前来源，且不能是派生内容；正文与图片共同计算摘要，用来检查文章依赖是否仍对应当前材料。参考 [当前知识与材料校验 ↗](../../../apps/server/src/knowledge/retrieval.ts#L24 "支持空输入和缺表处理、当前知识头读取、原始材料筛选以及当前摘要计算。")

命中文字块后，只跟随其中实际出现的引用键。文章引用可以限定到指定章节并递归；显式章节即使词汇不同，也只把该章节作为背景，不扩展到兄弟章节。材料引用则校验引文、行号和当前原文，再把引用字符区间映射为所有相交的持久化片段，并携带引导分数返回。参考 [递归引用控制 ↗](../../../apps/server/src/knowledge/retrieval.ts#L49 "支持访问阈值、依赖有效性检查、重复访问抑制和限定子文章章节的递归行为。") [引用范围映射 ↗](../../../apps/server/src/knowledge/retrieval.ts#L71 "支持引文与行号校验、引用字符区间到所有相交片段的映射，也证明一次访问可能写入多个候选。")

<a id="boundaries"></a>
## 精度、递归与数量边界

递归访问深度超过 8 时停止；同一“文章＋引用”若已经以不低于当前值的分数访问过，也不会重复展开。任何依赖摘要失效都会跳过该文章，材料缺失、空引文、越界行号或当前摘录不再包含保存引文时，同样不产生候选。参考 [递归引用控制 ↗](../../../apps/server/src/knowledge/retrieval.ts#L49 "支持访问阈值、依赖有效性检查、重复访问抑制和限定子文章章节的递归行为。") [引用范围映射 ↗](../../../apps/server/src/knowledge/retrieval.ts#L71 "支持引文与行号校验、引用字符区间到所有相交片段的映射，也证明一次访问可能写入多个候选。")

`output.size >= 100` 的含义是：**已有 100 个候选时，不再进入后续 `visit`**，而不是保证本函数严格最多返回 100 个候选。判断只发生在访问入口；一旦进入某个材料引用，循环仍会写入与引用区间相交的全部片段，因此一次访问可能让数量超过 100。函数末尾直接返回去重映射中的全部值，没有再次裁剪；最终展示名额属于下游搜索排序职责。参考 [递归引用控制 ↗](../../../apps/server/src/knowledge/retrieval.ts#L49 "支持访问阈值、依赖有效性检查、重复访问抑制和限定子文章章节的递归行为。") [引用范围映射 ↗](../../../apps/server/src/knowledge/retrieval.ts#L71 "支持引文与行号校验、引用字符区间到所有相交片段的映射，也证明一次访问可能写入多个候选。") [文章匹配与候选返回 ↗](../../../apps/server/src/knowledge/retrieval.ts#L92 "支持标题回退只打开首个解释块、解析失败隔离，以及函数直接返回去重映射全部候选。")

单篇文章解析失败不会中断其他文章的证据发现。文章标题只在词项很少、正文没有命中且标题包含全部词项时，以较低分打开第一个解释性文字块，仍然不会把整篇文章的所有引用一起提升。参考 [文章匹配与候选返回 ↗](../../../apps/server/src/knowledge/retrieval.ts#L92 "支持标题回退只打开首个解释块、解析失败隔离，以及函数直接返回去重映射全部候选。")
