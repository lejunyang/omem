# 派生知识引导的原始证据召回

在 current 知识文章中匹配查询词，再沿经过依赖摘要校验的引用链定位固定原始 Fragment；派生正文只提供导航，不作为返回证据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="entry"></a>
## 检索入口与候选文章

该实现把派生正文限定为检索导航，返回候选仍是固定原始 Fragment，后续还需执行助手可见性规则。[派生正文的检索边界 ↗](../../../apps/server/src/knowledge/retrieval.ts#L1 "支持派生知识只负责引导、候选仍回到固定原始 Fragment。") 查询词为空或知识表不存在时直接返回空；否则只查询 current head，并对转义后的 LIKE 条件先取最多三十篇文章，同时缓存材料来源和子文章读取。[current 文章初筛 ↗](../../../apps/server/src/knowledge/retrieval.ts#L8 "说明空查询处理、current head 约束、LIKE 转义、初始三十篇限制和缓存。")

<a id="verification"></a>
## 依赖核验与引用回溯

进入一篇文章后，会先核对其全部材料摘要和子文章修订；任一材料来源不存在或摘要变化，都会终止整篇文章的证据输出。[引用链遍历与证据定位 ↗](../../../apps/server/src/knowledge/retrieval.ts#L33 "支持准确说明深度计数、入口数量检查、整篇依赖核验和单条材料引用跳过条件。") 顶层匹配覆盖文章标题、摘要、章节标题和正文，并只从命中章节正文实际出现的引用键开始；子文章引用则继续递归。材料引文为空或无法在当前 Fragment 中精确定位时，才只跳过该条引用路径。[引用链遍历与证据定位 ↗](../../../apps/server/src/knowledge/retrieval.ts#L33 "支持准确说明深度计数、入口数量检查、整篇依赖核验和单条材料引用跳过条件。")[命中范围与解析隔离 ↗](../../../apps/server/src/knowledge/retrieval.ts#L49 "说明文章标题、摘要、章节标题和正文均参与匹配，并支持无效投影的失败隔离。")

<a id="limits"></a>
## 深度、数量与容错边界

深度从顶层零开始，仅在大于八时停止，因此可访问深度零至八的九个文章层级，即最多八次子文章跳转。输出数量检查只发生在每次进入 `visit` 时；一次已经开始的引用循环仍可能继续加入多个 Fragment，所以三十不是严格结果上限。[引用链遍历与证据定位 ↗](../../../apps/server/src/knowledge/retrieval.ts#L33 "支持准确说明深度计数、入口数量检查、整篇依赖核验和单条材料引用跳过条件。") 文章和 Fragment 分别去重；单篇投影解析失败不会中断其他文章，但当前定位依赖保存的精确短引文仍存在，不提供语义匹配或跨修订位置续接。[命中范围与解析隔离 ↗](../../../apps/server/src/knowledge/retrieval.ts#L49 "说明文章标题、摘要、章节标题和正文均参与匹配，并支持无效投影的失败隔离。")
