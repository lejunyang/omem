# 统一的轻量 SVG 图标组件

OmIcon 集中提供一组常用线性图标。调用方可选择图标名称和尺寸，组件以统一描边风格渲染 SVG，并继承外层文字颜色；名称无法识别时回退为书本图标。图标本身对辅助技术隐藏，因此具有操作含义时需由外层控件提供可访问名称。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决重复绘制与风格不一致

该组件把书本、层级、箭头、关闭、菜单、链接等常用图形集中为一组 SVG 路径，避免页面分别维护图标时产生形状和风格差异。它只暴露 `name` 与 `size` 两个属性，默认名称为 `book`、默认尺寸为 18，适合在按钮、导航和状态提示旁作为轻量视觉符号。参考 [图标属性与路径集合 ↗](../../../packages/ui/src/components/OmIcon.vue#L2 "支持组件的默认名称、默认尺寸以及集中维护常用图标路径的说明。")

<a id="rendering-flow"></a>
## 从名称到 SVG 的渲染流程

渲染时，组件用 `name` 从路径表中取得对应的 `d` 数据，再交给唯一的 `<path>` 元素绘制；名称不存在时回退到书本路径。外层 SVG 将宽高绑定到 `size`，使用固定的 24×24 坐标系，并通过 `currentColor` 继承外层文字颜色，因此调用方可以用常规 CSS 同步图标与文本的颜色。参考 [未知名称回退 ↗](../../../packages/ui/src/components/OmIcon.vue#L32 "支持组件按名称选择路径，并在名称无法识别时回退到书本图标的流程说明。") [统一 SVG 样式 ↗](../../../packages/ui/src/components/OmIcon.vue#L21 "支持尺寸绑定、固定坐标系、颜色继承以及统一描边风格的说明。")

<a id="boundaries"></a>
## 边界与接入注意事项

未知名称不会报错或显示空白，而会静默变成书本图标；这提高了容错性，也可能掩盖名称拼写错误。`size` 只声明为数字，组件内没有正数范围校验。SVG 还设置了 `aria-hidden="true"`，将自身作为装饰内容隐藏；若图标独立承担“关闭”或“返回”等操作含义，外层按钮或链接必须另行提供可访问名称。参考 [装饰性图标标记 ↗](../../../packages/ui/src/components/OmIcon.vue#L26 "支持图标对辅助技术隐藏，以及操作语义需要由外层交互元素提供的判断。")

现有材料仅展示组件本身，没有调用方或测试，因此无法据此确认哪些页面使用它，也不能确认异常名称、尺寸和可访问名称是否已被自动化检查。

<a id="module-relations"></a>
## 与外层界面的协作边界

页面组件可通过属性选择图形和尺寸，图标颜色则由 SVG 的 `currentColor` 跟随外层 CSS 文本颜色。参考 [名称与尺寸属性 ↗](../../../packages/ui/src/components/OmIcon.vue#L2 "支持调用方能够通过组件属性选择图标名称和尺寸的边界说明。") [统一 SVG 样式 ↗](../../../packages/ui/src/components/OmIcon.vue#L21 "支持尺寸绑定、固定坐标系、颜色继承以及统一描边风格的说明。")

材料没有提供导出入口、组件注册方式或实际调用代码，因此目前不能把它与某个具体页面、按钮组件或导航流程建立已确认的跨文件调用关系。
