# 共享线条图标组件

根据名称从内置路径表选择 SVG 图形，以统一尺寸、描边风格和装饰性无障碍行为。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="selection"></a>
## 图标选择与回退

组件提供可选 name 和 size，默认分别为 book 与 18；内置路径覆盖书籍、层级、方向、关闭、菜单、状态、链接、时间和新增等常用符号。[图标默认值与路径字典 ↗](../../../packages/ui/src/components/OmIcon.vue#L1 "支持名称、尺寸默认值、已知图标集合及未知名称回退逻辑的说明。") 渲染时以 name 查表，未知名称不会报错或留下空白，而是回退到 book。这提高了运行时容错，但也可能掩盖拼写错误；由于 name 类型是任意字符串，编译期不能限制调用方只能选择已知图标。

<a id="rendering"></a>
## 渲染与模块关系

所有图标共用 24×24 viewBox、无填充、currentColor 描边以及圆角端点和连接，实际宽高由 size 同步控制，因此会继承父元素文字颜色并保持一致线条风格。SVG 标记为 aria-hidden，定位为装饰性图形；可访问名称必须由外层控件提供。[SVG 渲染合同 ↗](../../../packages/ui/src/components/OmIcon.vue#L20 "说明尺寸、继承颜色、统一描边、装饰性语义和路径回退。") 对话框正是将 close 图标放入带 aria-label 的 OmButton 中，展示了预期组合方式。[关闭图标的按钮组合 ↗](../../../packages/ui/src/components/OmDialog.vue#L43 "证明上层对话框通过带 aria-label 的按钮承载装饰性 close 图标。") 组件不支持非正方形尺寸、独立标题或多路径样式。
