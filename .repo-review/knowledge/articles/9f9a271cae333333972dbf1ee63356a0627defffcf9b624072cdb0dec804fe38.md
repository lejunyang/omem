# quality · 模块理解

quality 模块提供与生产知识捕获隔离的质量评测路径：从研究材料生成候选样本，经 SQLite 仓储完成人工确认与冻结，再由飞书卡片承载 owner 标注，并以确定性规则汇总预测质量。现有材料证明各实现路径存在，但不足以证明端到端闭环经过真实集成运行；并发写入、重复冻结、投递回填和规则语义覆盖仍待验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-boundary"></a>
## 职责与生产边界

quality 模块围绕“研究样本生成、人工复核、冻结题集、预测评估”组织质量设施。样本合同记录来源、类别和正文；标签区分提取、弃权与需要上下文，并约束提取必须包含对象、非提取不得自动应用。[质量样本与标签合同 ↗](../../../apps/server/src/quality/repository.ts#L8 "支持质量样本字段、处置和对象类型，以及提取与自动应用之间的跨字段约束。")

规则导入器明确仅用于研究标注集，不能进入普通 HTTP、CLI、学习或捕获链路；逐字 claim 与 `autoApply=true` 只是供人判断的冷启动草稿。[研究导入隔离说明 ↗](../../../apps/server/src/quality/import.ts#L1 "支持规则样本生成仅用于人工研究标注，不属于普通捕获、导入和学习链路。") 统一捕获合同支持文本、图片和链接，但导入器只聚合文本部件，因此图片和链接内容不会进入候选句。[统一捕获内容合同 ↗](../../../packages/contracts/src/index.ts#L20 "支持捕获输入包含文本、图片和链接，并用于对照导入器仅消费文本的限制。")

<a id="dataset-and-review-flow"></a>
## 样本生成、评审与冻结

导入器清洗文本、识别章节、跳过复杂布局，按长度筛选句子，再按规则词、限制、否定和数字评分；候选不足目标数量时直接失败。[候选提取与排序流程 ↗](../../../apps/server/src/quality/import.ts#L46 "支持文本聚合、布局跳过、句子筛选、规则评分、排序截取和数量不足失败的生成路径。") “章节＋文本”、标签版本及冻结清单所需摘要均基于规范化 JSON 的 SHA-256 计算。[规范化稳定摘要 ↗](../../../apps/server/src/storage/digest.ts#L3 "支持递归规范化、键排序和 SHA-256 摘要的确定性计算方式。")

仓储分开保存草稿和确认标签。四种人工动作按规则映射到 `confirmed`、`needs_edit` 或 `skipped`：确认与弃权都会进入 `confirmed`，但确认沿用草稿标签，弃权则生成空对象、禁止自动应用的标签；需修改进入 `needs_edit`，跳过进入 `skipped`。写入同时校验 `pending` 状态和标签摘要。[人工标签动作与状态转换 ↗](../../../apps/server/src/quality/repository.ts#L278 "支持确认和弃权均进入 confirmed、需修改进入 needs_edit、跳过进入 skipped，并说明确认与弃权采用不同确认标签。") 这一表述替代旧稿中“四种动作映射到不同评审状态”的不准确结论。全部目标样本确认后，冻结流程按序号、输入摘要和确认标签摘要生成可复算清单。[冻结清单与完整性复算 ↗](../../../apps/server/src/quality/repository.ts#L358 "支持冻结前置条件、清单组成、状态更新及后续完整性复算流程。") 更细的状态转换与并发边界可从仓储子知识继续追踪。[质量数据集仓储子知识 ↗](49fd1d32ef4c1278549cf6f20863208b590b78dc9d3e0b474f5304a4eb22ed2e.md#review-lifecycle "为草稿、人工评审、修订及其并发控制提供聚合阅读入口，附近事实同时由原始代码引用支撑。")

<a id="lark-and-evaluation"></a>
## 飞书标注与预测评估

飞书服务把待审样本包装为带会话、样本、标签摘要、时效和随机数的卡片。启动或续发时，会话变更与投递意图事务化写入；这里只能证明消息已入队，不能据此断言已经送达。[标注会话与投递意图 ↗](../../../apps/server/src/quality/lark-annotations.ts#L180 "支持活动会话复用或续发、新会话目标选择，以及会话和投递意图的事务化持久化。") 回调会持久化并去重事件，联合核对 owner、聊天、消息、应用、时效、摘要和随机数；通过后原子记录标注、审计和会话推进。[卡片回调校验与推进 ↗](../../../apps/server/src/quality/lark-annotations.ts#L355 "支持事件收件去重、联合身份校验，以及标注、审计和会话游标的事务推进。")

评估器只以已确认样本为分母，逐行比较处置、自动应用、预期对象覆盖和任务完成。[预测对齐与任务完成 ↗](../../../apps/server/src/quality/evaluator.ts#L234 "支持已确认样本筛选、重复预测拒绝、对象覆盖、不必要打断和任务完成的逐行计算。") 汇总还包含引用定位、语义支持、数字槽、必要证据召回、打断、延迟和失败明细。[质量指标汇总 ↗](../../../apps/server/src/quality/evaluator.ts#L337 "支持引用定位、语义支持、数字槽、必要证据、任务完成、打断、延迟和失败等汇总输出。") 语义裁决是有限词表与二元词组阈值驱动的确定性基线，数字槽也只是检查陈述中的特定数字是否出现于短引，并非完整自然语言推理。[规则式语义与事实槽裁决 ↗](../../../apps/server/src/quality/evaluator.ts#L33 "支持确定性语义规则的判定顺序、词面阈值和有限数字检查，并说明其能力边界。") 评估器子知识集中解释了这些指标及限制。[预测评估器子知识 ↗](54f7340a31e5f5edaae4bd88493f85ebc33326c978a0ddaffd5f348b609b8dc5.md#metrics-and-limits "为对象裁决、任务完成、汇总指标和规则限制提供聚合阅读入口。")

<a id="progress-and-limits"></a>
## 当前进展、替代结论与限制

材料展示了研究数据生成、仓储评审与冻结、飞书会话以及预测汇总的静态实现路径，但没有端到端运行记录或集成测试结果；因此不能把代码存在表述为质量闭环已跑通。[候选提取与排序流程 ↗](../../../apps/server/src/quality/import.ts#L46 "支持文本聚合、布局跳过、句子筛选、规则评分、排序截取和数量不足失败的生成路径。")[冻结清单与完整性复算 ↗](../../../apps/server/src/quality/repository.ts#L358 "支持冻结前置条件、清单组成、状态更新及后续完整性复算流程。")[标注会话与投递意图 ↗](../../../apps/server/src/quality/lark-annotations.ts#L180 "支持活动会话复用或续发、新会话目标选择，以及会话和投递意图的事务化持久化。")[质量指标汇总 ↗](../../../apps/server/src/quality/evaluator.ts#L337 "支持引用定位、语义支持、数字槽、必要证据、任务完成、打断、延迟和失败等汇总输出。")

持久化边界仍需验证：`addSamples` 在 `BEGIN IMMEDIATE` 前读取数据集状态与最大序号；[样本批量写入事务边界 ↗](../../../apps/server/src/quality/repository.ts#L155 "支持数据集状态与最大序号在立即事务开始前读取，以及批量写入使用 INSERT OR IGNORE。") `revise` 最终更新只约束样本标识和旧摘要，没有再次约束允许状态；[标签修订写入条件 ↗](../../../apps/server/src/quality/repository.ts#L328 "支持修订读取时的状态检查及最终 UPDATE 未再次约束样本状态的并发边界。") `freeze` 只更新 `labeling` 状态且未检查命中行数。[冻结状态更新条件 ↗](../../../apps/server/src/quality/repository.ts#L358 "支持冻结只更新 labeling 状态、未检查受影响行数却直接返回新冻结信息的限制。") 飞书会话创建或续发时消息标识为空，而回调要求其与事件消息标识相等；当前材料仍缺投递成功后的回填协议。[消息标识回调约束 ↗](../../../apps/server/src/quality/lark-annotations.ts#L369 "支持回调要求会话消息标识与事件完全匹配，并与启动阶段消息标识为空共同形成待补充协议。")
