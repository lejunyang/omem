# 角色资产包加载与隔离工作区

从版本化目录加载并验证角色清单、提示、输出合同和技能资产，计算稳定摘要，并为 native 技能准备按运行隔离的工作目录。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="loading"></a>
## 加载与完整性验证

注册表先用白名单限制角色和版本名称，再读取清单、提示模板及输出 schema。清单身份必须与请求一致，schema 标识须匹配声明；技能名称不能重复，`SKILL.md` 的名称与整个技能目录摘要也必须符合清单。通过验证后，规范化的清单、提示、schema 和技能内容共同形成 `bundleHash`。[角色清单与输出合同校验 ↗](../../../apps/server/src/agent-runtime/bundles.ts#L105 "支持角色标识、清单身份、提示模板和输出 schema 的加载及一致性检查。")[技能验证与包摘要 ↗](../../../apps/server/src/agent-runtime/bundles.ts#L132 "支持技能去重、frontmatter 名称、目录摘要验证和 bundleHash 构成。")

<a id="filesystem"></a>
## 路径与摘要边界

普通资产经解析后必须仍位于包根目录，目标存在且被读取的路径本身不是符号链接；技能目录遍历也会拒绝其中发现的符号链接目录项。代码没有单独对 `skillDirectory` 根节点执行 `lstat`，因此不能据此断言技能根目录为符号链接时一定被拒绝。[资产路径与符号链接检查 ↗](../../../apps/server/src/agent-runtime/bundles.ts#L41 "支持普通文件的真实路径边界检查及递归遍历中对符号链接目录项的拒绝，同时界定未显式检查技能根节点的限制。") 目录摘要按相对路径排序，并统一路径分隔符和 CRLF 换行，以减少不同平台检出的摘要差异。[跨平台目录摘要 ↗](../../../apps/server/src/agent-runtime/bundles.ts#L68 "支持文件排序、相对路径分隔符统一和 CRLF 到 LF 的规范化。")

<a id="workspace"></a>
## 运行工作区与传输限制

工作区路径由包摘要和运行 ID 构成，创建时请求使用 `0o700`；若目录已存在，这里的递归 `mkdir` 并不证明权限会被重新收紧。只有 `native` 技能会复制到工作区，已有目标文件内容不一致时拒绝覆盖；native 技能要求 ACP，CLI profile 会失败。[隔离工作区准备 ↗](../../../apps/server/src/agent-runtime/bundles.ts#L92 "支持工作区布局、创建时的权限参数、native 技能复制、内容冲突检查及 ACP 限制。") 网关在模型调用前准备该目录，并把实际技能集合纳入运行摘要。[网关装配角色工作区 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L273 "说明网关如何计算技能摘要并在运行前调用工作区准备逻辑。")
