# 冻结质量集的隔离实时预测运行器

该脚本对冻结数据集逐样本创建隔离 Store，调用真实学习管线生成规范化预测，记录耗时与 token 使用，并以原子替换和逐样本持久化支持断点续跑。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="setup"></a>
## 冻结集、模型与断点状态

命令要求冻结数据集标识，验证其 manifest，并从应用配置选择可用的 `traex` 实时 profile。预测文件若已存在，每项必须通过 schema 解析；已有 sampleId 会被视为完成，单次处理数量由环境变量限制且至少为 1。[冻结数据集与续跑初始化 ↗](../../../scripts/quality-run.ts#L27 "支持数据集冻结校验、实时 profile 选择、已有预测 schema 校验和运行数量限制。") 这使运行可以从已有合法结果续接。

<a id="isolation"></a>
## 逐样本隔离执行

每个未完成样本都获得独立临时 Store，输入文本、来源位置和 provenance 被捕获后交给 `LearningPipeline`；管线排空并停止，再从内存提案中选取已应用、待决定或已批准状态。[隔离捕获与学习管线 ↗](../../../scripts/quality-run.ts#L63 "支持逐样本临时 Store、输入 provenance 捕获、学习管线执行和提案状态筛选。") 每个样本使用不同 worker 标识和数据目录，避免样本之间共享运行状态。

<a id="prediction"></a>
## 预测映射与故障降级

存在提案时 disposition 为 `extract`，否则为 `abstain`；对象保留 kind、可读陈述、证据引文，并为 task 附带 owner 与截止信息。脚本汇总任务尝试中的输入、输出 token 和耗时。[规范化预测与用量统计 ↗](../../../scripts/quality-run.ts#L117 "支持提案到预测对象的映射、自动应用判定，以及耗时和 token 用量记录。") 若某样本失败，则写入 `needs_context`、空对象、非自动应用及截断错误消息；随后关闭并删除该样本临时目录。[样本失败降级与隔离清理 ↗](../../../scripts/quality-run.ts#L157 "支持异常样本写入 needs_context 结果，并说明临时 Store 总会关闭和删除。")

<a id="persistence"></a>
## 持久化与边界

每处理一个样本就把完整预测数组写入随机临时文件，再重命名到目标并强制 `0600`，从而减少中断造成的半写文件风险。[预测文件原子替换 ↗](../../../scripts/quality-run.ts#L51 "支持以随机临时文件、重命名和强制文件权限实现逐批持久化。") 目录仅在创建时请求 `0700`。最终输出完成数并关闭源 Store；失败样本也会占据 sampleId，因此后续续跑默认不会自动重试。
