# 知识阅读 Trail 的真实浏览器回归脚本

该脚本在临时仓库中构造固定知识链，启动 Review API 与 Vue 页面，并用 Chromium 验证多层引用阅读、深链、焦点、响应式、待办和源码转义。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="fixture"></a>
## 夹具与被测系统

脚本创建包含 A→B→C import 的临时仓库及带脚本标签的 HTML 原文，执行 Review 同步、材料捕获和代码同步，再发布 C、B、A、架构与总览五层固定知识。随后它以临时路径实例化 Store、启动 Review 应用并打开无头 Chromium。[临时仓库与固定知识链 ↗](../../../scripts/knowledge-browser.ts#L14 "支持临时源码、同步、固定知识发布以及 Review 应用和浏览器启动流程。") 这覆盖固定材料、知识仓库、API 和已构建 Web UI 的集成链路，不依赖模型生成；当前材料不进一步证明 Store 构造期间的迁移细节。

<a id="trail"></a>
## Trail 与深链断言

浏览器从总览进入 Trail，逐层打开三个模块与固定代码，检查五层面包屑、引用理由和源码内容；Esc 会退回一层，刷新后四层深链仍可恢复，关闭全部再打开和关闭后焦点回到入口。[多层 Trail 与深链断言 ↗](../../../scripts/knowledge-browser.ts#L46 "支持逐层阅读、Esc 回退、刷新恢复、关闭全部和焦点归还等交互结论。") 这些断言验证了帧栈导航、URL 序列化和基本无障碍焦点行为。

<a id="other-assertions"></a>
## 导航、安全与覆盖边界

脚本还验证 import 行可打开目标模块知识，1440、768、390 三种视口不产生水平溢出，未解决问题只能由用户显式加入待办，并且 HTML 材料作为源码显示而不会执行其中脚本。[导航、响应式、待办与源码安全 ↗](../../../scripts/knowledge-browser.ts#L70 "支持 import 跳转、多视口无溢出、显式创建待办和 HTML 不执行的测试范围。") 它属于单页 Chromium 冒烟回归，不覆盖其他浏览器、并发、真实历史库或网络异常；最终会检查页面错误并清理浏览器、应用与临时仓库。[错误检查与资源清理 ↗](../../../scripts/knowledge-browser.ts#L91 "说明脚本断言无页面错误，并在 finally 中关闭浏览器、应用及删除临时仓库。")
