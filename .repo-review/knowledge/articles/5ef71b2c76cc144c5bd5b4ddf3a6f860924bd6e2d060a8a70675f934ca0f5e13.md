# 知识阅读 Trail 的真实浏览器回归脚本

该脚本在临时仓库和真实 SQLite Store 中构造固定知识链，启动 Review API 与 Vue 页面，并以 Chromium 验证多层引用阅读、深链、焦点、响应式、待办和源码转义。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="fixture"></a>
## 夹具与被测系统

脚本创建包含 A→B→C import 的临时仓库及带脚本标签的 HTML 原文，执行 Review 同步、材料捕获和代码同步，再发布 C、B、A、架构、总览五层固定知识并启动 Review 应用。[临时仓库与固定知识链夹具 ↗](../../../scripts/knowledge-browser.ts#L14 "支持临时源码构造、同步、固定知识发布以及 Review 应用启动的集成流程。") 被测 `Store` 以 SQLite 文件作为单用户持久化基础；构造时创建数据目录和数据库、执行迁移、建立资源目录，并收紧数据库文件权限。[SQLite Store 构造与迁移 ↗](../../../apps/server/src/store.ts#L1 "支持 Store 的单用户 SQLite 定位，以及构造时创建数据库、执行迁移、建立资源目录和设置文件权限的论断。") 因而测试覆盖材料适配、知识仓库、API 与已构建 Web UI 的集成链路，不依赖模型生成。

<a id="assertions"></a>
## 交互断言

Chromium 从总览进入 Trail，逐层打开三个模块与固定代码，断言五层面包屑、引用理由和源码内容；Esc 回退一层，刷新后恢复四层深链，关闭全部后将焦点归还入口。[多层 Trail 与深链断言 ↗](../../../scripts/knowledge-browser.ts#L46 "支持逐层阅读、Esc 回退、刷新恢复及关闭后焦点归还等交互结论。") 脚本还验证 import 导航、1440/768/390 三种宽度无水平溢出、用户显式创建待办，以及 HTML 材料仅作为转义源码展示。[导航、响应式、待办与源码安全断言 ↗](../../../scripts/knowledge-browser.ts#L70 "支持 import 跳转、多视口无溢出、显式创建待办和 HTML 不执行的测试范围。")

<a id="limits"></a>
## 覆盖边界

这是单个无头 Chromium 页面与人工夹具的冒烟回归：它证明所列路径成立且页面没有捕获到错误，但不覆盖其他浏览器、并发页面、真实历史数据库、网络失败或模型生成知识。`finally` 会关闭浏览器和应用并删除临时仓库。[浏览器测试资源清理 ↗](../../../scripts/knowledge-browser.ts#L91 "说明脚本在 finally 中关闭浏览器、应用并移除临时仓库。")
