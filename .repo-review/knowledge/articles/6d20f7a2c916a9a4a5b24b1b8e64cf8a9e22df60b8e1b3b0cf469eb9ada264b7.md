# MemPalace 检索实验产物审计

该文件记录三组 MemPalace 结果产物的文件名、样本规模、开发集重叠、SHA-256 及聚合指标。它可用于识别和核对已有产物，但三组样本口径并不一致，也缺少代码、配置与指标定义，不能单独证明算法提升或实验可复现性。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="audit_scope"></a>
## 审计范围与产物身份

文件是一份结果审计快照，而非实现或运行记录。held-out hybrid v4 包含450个唯一问题、开发集重叠为0，并记录了内容哈希 [严格隔离的 hybrid v4 产物信息 ↗](../../../docs/research/mempalace/artifact-audit.json#L3 "支持 held-out hybrid v4 的文件身份、样本规模、开发集零重叠及哈希记录。")；LLM rerank 与 raw 各有500个唯一问题、均重叠50道开发题 [LLM 重排产物信息 ↗](../../../docs/research/mempalace/artifact-audit.json#L84 "支持 LLM rerank 产物的500题规模、50题开发集重叠及哈希记录。")[Raw 基线产物信息 ↗](../../../docs/research/mempalace/artifact-audit.json#L165 "支持 raw 产物的500题规模、50题开发集重叠及哈希记录。")。哈希可在取得原始文件后核对身份，但材料未提供生成命令、代码版本、模型、索引配置或数据集版本，无法仅凭本文件重建实验。

严格 held-out hybrid 的 session Recall@1/@3/@5 分别为0.8911、0.9711、0.9844，NDCG@3约0.9375 [Held-out hybrid 前五位 session 指标 ↗](../../../docs/research/mempalace/artifact-audit.json#L9 "支持 held-out hybrid 的 session Recall@1/@3/@5及 NDCG@3数值，也为 session 与 turn 的示例对照提供基准。")；其 Recall 到@30和@50均为1.0，而 NDCG 分别约0.9347和0.9344 [Held-out hybrid 深位 session 指标 ↗](../../../docs/research/mempalace/artifact-audit.json#L41 "支持 Recall@30/@50均为1.0以及对应 NDCG 数值；只用于描述不同 K 下的指标，不推断候选生成或排序机制。")。这些数值只说明不同截断深度下的聚合指标变化；材料没有候选列表或排序过程，不能据此断言变化由“新增候选”造成，也不能直接评价固定前部位置是否改善。LLM rerank 的 session Recall@3为0.982、NDCG@3约0.9157 [LLM 重排前三位 session 指标 ↗](../../../docs/research/mempalace/artifact-audit.json#L98 "支持 LLM rerank 的 session Recall@3与 NDCG@3数值描述。")，raw 对应为0.926和约0.8741 [Raw 基线前三位 session 指标 ↗](../../../docs/research/mempalace/artifact-audit.json#L179 "支持 raw 产物的 session Recall@3与 NDCG@3数值描述。")，但由于样本数和开发集重叠不同，不能形成严格横向提升结论。
