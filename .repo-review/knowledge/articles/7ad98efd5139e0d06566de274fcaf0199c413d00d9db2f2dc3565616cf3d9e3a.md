# ACP 助手模型的传输路由与回复解析测试

该测试文件验证助手模型在缺少配置、误用 CLI 传输和使用 ACP 传输时的失败边界，并覆盖结构化 JSON 回复到内部回答、引用和创建任务调用的解析。它同时暴露两个未被行为性证明的点：ACP 用例只依据错误消息判断是否越过路由检查，历史预算用例仅验证实例可构造。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="transport-routing"></a>
## 传输路由的失败边界

测试用两个 `AgentProfile` fixture 区分 ACP 与 `codex-cli`。无 profile 时，`generate` 必须抛出 `ModelUnavailableError`；CLI profile 也必须被拒绝，且错误消息包含“CLI transport”，从而防止把一次性 CLI 错当成 ACP 会话。[传输路由测试 ↗](../../../apps/server/tests/acp-model.test.ts#L9 "支持无配置与 CLI profile 均被明确拒绝，以及错误类型和消息断言。") 这与适配器的生产约束一致：只有 `transport === "acp"` 才继续，缺配置或其他传输都会明确降级，且不生成伪答案。[ACP 模型路由实现 ↗](../../../apps/server/src/assistant/acp-model.ts#L12 "解释测试对应的生产行为：仅接受 ACP，其他传输抛出模型不可用错误。")

ACP fixture 使用不存在的命令，预期最终仍是 `ModelUnavailableError`，但消息不能包含 CLI 路由错误。该断言只能说明错误表现不同，不能严格证明进程创建确已发生，也未覆盖真实 ACP 握手、鉴权、超时和成功回复。[ACP 失败路径测试 ↗](../../../apps/server/tests/acp-model.test.ts#L58 "支持 ACP fixture 最终失败但不得呈现 CLI 路由错误，并界定该断言能够证明的范围。")

<a id="reply-parsing"></a>
## 结构化回复解析合同

解析测试把 JSON 中的 `answer`、`citation_ids` 和可选 `create_task` 转成运行时回复：回答文本与引用顺序被保留，创建任务被规范成一个 `toolCalls` 项；当 `create_task` 为空缺时则不产生工具调用。[助手回复解析测试 ↗](../../../apps/server/tests/acp-model.test.ts#L81 "支持回答、引用、创建任务调用及无任务回复的具体解析断言。") 运行时合同说明引用是回答实际依赖的 fragment 标识，而工具调用仍需服务端重新治理，因此这里验证的是解析形状，不代表任务已获授权或真正创建。[运行时回复合同 ↗](../../../apps/server/src/assistant/runtime.ts#L23 "解释 citationIds 与受服务端治理的 toolCalls 在运行时中的职责边界。")

异常路径覆盖非 JSON、缺少 `answer`，并确认混合类型的 `citation_ids` 会过滤掉数字和空值。[畸形回复处理测试 ↗](../../../apps/server/tests/acp-model.test.ts#L111 "支持非 JSON、缺失回答以及非字符串引用被过滤的边界行为。") 尚未看到对空白回答、重复引用、畸形 `create_task` 字段、额外字段、更新时间或二次检索字段的断言。

<a id="history-budget"></a>
## 历史预算测试的实际覆盖范围

名为“truncates prior turns”的用例传入 `maxPriorTurns: 3`，但没有调用 `generate` 或检查最终 prompt，只断言对象成功构造；注释也明确承认截断逻辑位于内部、当前未被拦截验证。[历史预算用例 ↗](../../../apps/server/tests/acp-model.test.ts#L129 "表明该用例只构造带 maxPriorTurns 的模型，没有行为性验证历史截断。") 实现材料显示真实逻辑会取最近若干轮，默认上限为 10，并把每轮助手结果截到 500 字符。[历史上下文裁剪实现 ↗](../../../apps/server/src/assistant/acp-model.ts#L47 "解释实际截断最近轮次、默认上限和单轮结果裁剪规则，以对照测试缺口。") 因此该用例目前是构造器兼容性检查，不能作为历史截断顺序、默认值、零值行为或 prompt 长度受控的证据。
