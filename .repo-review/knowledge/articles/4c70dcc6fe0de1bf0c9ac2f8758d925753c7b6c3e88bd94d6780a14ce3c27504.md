# 来源修订的规则化内容画像

从固定修订及其片段派生结构、语言、话语类型、主题、时间提示和覆盖缺口，并以可重新生成的导航元数据写入 SQLite。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="profile-lifecycle"></a>
## 画像生命周期与失败隔离

该服务为已经捕获的来源修订生成派生画像，包括载体类型、标题结构、主题候选、话语段、时间提示、链接和证据片段。`latest` 按 generation 读取最新记录；`persistForRevision` 从 revisions 与 fragments 读取固定修订，执行规则分析，递增代次后写入数据库。[画像读取与代次持久化 ↗](../../../apps/server/src/source-profile/service.ts#L119 "支持从固定修订及有序片段分析画像、递增 generation 并写入数据库的生命周期。")

画像被视为辅助导航而非原始证据。分析失败时，`recordFailure` 尝试写入 failed 行；若失败记录本身也无法插入，异常会被吞掉，从而保持来源可读。材料只展示服务内部行为，未展示调用方事务、重试或补建流程，因此不能确定画像与原始捕获是否原子一致。[画像失败记录 ↗](../../../apps/server/src/source-profile/service.ts#L168 "支持画像失败采用尽力记录、失败记录异常不影响来源可读的容错边界。")

<a id="analysis-flow"></a>
## 结构识别与话语分类

话语分类先识别图片占位和短噪声，再优先把代码、SQL、命令等识别为示例，随后判断问题、约束、定义、计划、历史和指令；同时以关键词推断时态及是否指称上文。[规则化话语分类 ↗](../../../apps/server/src/source-profile/service.ts#L75 "支持代码材料优先、时态与上文指称检测，以及问题、约束等话语类别的判断顺序。")

结构分析只有在某个片段的整个 trimmed 文本恰好匹配单行 Markdown 标题时，才把它作为标题节点并跳过话语分类；若标题与正文同处一个片段，正则不会匹配，该片段会作为普通话语处理。普通片段继承最近标题，图片、表格样式和超长内容会记录覆盖缺口并使状态变为 partial。[完整片段标题匹配与覆盖缺口 ↗](../../../apps/server/src/source-profile/service.ts#L251 "支持标题必须匹配整个 trimmed 片段、标题栈继承、普通话语分析和覆盖缺口生成的说明。")

<a id="derived-fields"></a>
## 主题、语言与外部关联

主题候选由标题文本和去停用词后的高频词合并产生；语言只依据中英文字符数量阈值判断。项目候选仅读取 context 中的 application、conversationId 和 runId，显式链接也只从 parts 中带 url 的对象提取。最终 `evidenceRefs` 覆盖全部输入片段，表示画像可追溯，但并不代表这些启发式结论经过人工验证。[派生候选字段 ↗](../../../apps/server/src/source-profile/service.ts#L305 "支持主题频率、语言阈值、有限 context 字段、parts 链接以及 evidenceRefs 和状态的生成规则。")
