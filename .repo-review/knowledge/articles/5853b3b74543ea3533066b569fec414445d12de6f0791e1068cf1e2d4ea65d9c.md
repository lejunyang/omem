# MemPalace 指标制品审计脚本

该脚本对固定上游提交中的三份检索结果制品进行哈希核验并重新汇总已保存指标，不重跑检索或验证金标准。划分、重复 ID 与 held-out 集合约束依赖 Python assert，在 python -O 下会被跳过；哈希和下载大小限制则由显式 ValueError 保证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决的问题与可信边界

脚本解决的是 MemPalace 研究制品的完整性与指标可复算审计：它读取上游已经保存的 metrics，不会重跑检索，也不验证 gold label，因此输出不能证明检索过程或金标准正确。网络下载是可选的，离线模式只读取指定目录中的既有文件。[脚本用途与离线约束 ↗](../../../docs/research/mempalace/audit_artifacts.py#L1 "支持脚本只重聚合已保存指标、不重跑检索或验证金标准，以及下载为可选行为的说明。") 三份结果文件绑定固定 Git 提交和预期 SHA-256，用于发现上游内容漂移或本地文件被替换。[固定提交与制品哈希 ↗](../../../docs/research/mempalace/audit_artifacts.py#L13 "说明三份结果文件与固定上游提交及预期 SHA-256 的绑定关系，支持制品完整性审计的论断。")

<a id="flow"></a>
## 核心流程与数据关系

入口要求 `--data-dir`，可选 `--download`；下载地址由固定提交、`benchmarks` 路径和文件名组成，单个响应读取超过 16 MB 时显式抛出 `ValueError`。[下载流程与显式大小限制 ↗](../../../docs/research/mempalace/audit_artifacts.py#L21 "支持固定提交下载地址、60 秒超时、16 MB 读取边界及超限时显式抛出 ValueError 的流程说明。") 随后加载 dev/held-out 划分，逐个读取 JSONL、核验哈希、提取 `question_id`，并以首行 metrics 的分组和键为模板，对所有行计算 sum 与 mean，最终输出行数、唯一 ID 数、dev 重叠量、哈希和聚合指标。[结果解析与指标聚合 ↗](../../../docs/research/mempalace/audit_artifacts.py#L49 "支持 JSONL 读取、问题 ID 提取、按首行指标结构聚合、dev 重叠统计、held-out 条件检查及输出字段，也暴露空文件和结构缺损的失败边界。")

<a id="limits"></a>
## 运行时限制与未覆盖行为

划分规模与互斥、重复 `question_id`、held-out 结果集合一致性都通过 Python `assert` 实现，只在断言启用时执行；使用 `python -O` 等关闭断言的方式运行会跳过这些约束，不能把它们视为无条件审计保证。相比之下，哈希不符使用显式 `ValueError`，下载大小超限同样显式失败，不受断言优化影响。[断言约束与显式哈希异常 ↗](../../../docs/research/mempalace/audit_artifacts.py#L40 "表明划分、重复 ID 和 held-out 一致性约束均使用 assert，而哈希不符采用显式 ValueError，支持两类失败机制在 python -O 下行为不同的判断。") 文件名不含 `held_out` 的两份结果仅报告 `dev_overlap`，并未要求 ID 集合等于 dev。空 JSONL 会在访问 `rows[0]` 时失败，缺键、指标结构不一致或非数值也只有通用异常；材料未提供测试文件、自动化调用关系或其他项目模块依赖的源代码依据。[结果解析与指标聚合 ↗](../../../docs/research/mempalace/audit_artifacts.py#L49 "支持 JSONL 读取、问题 ID 提取、按首行指标结构聚合、dev 重叠统计、held-out 条件检查及输出字段，也暴露空文件和结构缺损的失败边界。")
