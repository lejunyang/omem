# docs-prototype：可追溯知识交互的离线原型

该模块以自包含 HTML 演示知识结论到固定材料的递归阅读、局部追问、版本与异常状态及响应式布局；已有离线 Chromium 检查记录，但真实数据、模型、权限、同步和后台任务均未接入。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 定位与设计背景

`docs/prototype` 是可直接传阅的离线交互样稿：脚本与样式收入单个 HTML，可通过 `file://` 打开，无需 CDN、密钥或后端。[离线单文件交付说明 ↗](../../../docs/prototype/README.md#L1 "支持原型可直接打开且不依赖外部服务的定位。") 它覆盖文章与材料搜索、递归引用、追问、版本比较和异常来源展示。[原型交互范围 ↗](../../../docs/prototype/README.md#L5 "支持搜索、递归引用、追问、版本、异常来源及响应式展示等交互范围。") 视口不超过 1050px 时固定问答栏隐藏并可作为浮层打开；手机端再收起侧栏，将证据对话框铺满动态视口并纵向排列追问区。[窄屏问答栏与手机侧栏规则 ↗](../../../docs/prototype/index.html#L1721 "直接支持窄屏隐藏固定问答栏、按需浮层打开，以及手机端收起侧栏的说明。")[手机端证据阅读布局 ↗](../../../docs/prototype/styles.css#L1909 "支持证据对话框全屏化和追问区纵向排列的手机布局。")

<a id="workflow"></a>
## 证据阅读与问答流程

三篇示例文章分别声明各自的首层证据映射。[示例文章与首层证据映射 ↗](../../../docs/prototype/data.js#L178 "直接证明三篇示例文章分别声明了不同的首层证据引用。") 已确认的后续关系应分开理解：发布规范连接回滚手册；验证轨迹则连接代码修订、测试、健康指标和原始采样。[发布规范与回滚手册 ↗](../../../docs/prototype/data.js#L3 "证明发布规范直接引用回滚操作手册，并限定这一段已确认关系。")[验证轨迹与原始观测链 ↗](../../../docs/prototype/data.js#L47 "证明验证轨迹到代码修订、测试、指标和原始采样的连续关系。") 这替代了此前把两段材料串成同一连续链的过宽结论。阅读器用帧栈保存层级和滚动位置，支持循环检测、返回、跳转及关闭后归还焦点。[证据路径栈与焦点管理 ↗](../../../docs/prototype/app.jsx#L385 "支持层级压栈、循环检测、滚动记忆、返回、跳转及焦点归还流程。") 不可用来源展示原因并禁用追问；模拟回答仅选可用材料，保存后也只是待核对候选。[异常来源与追问限制 ↗](../../../docs/prototype/app.jsx#L1396 "支持历史版本提示、不可用来源原因页以及追问禁用规则。")[模拟回答的证据筛选 ↗](../../../docs/prototype/app.jsx#L163 "支持回答仅选取可用或已替代材料，并拒绝把缺失正文作为证据。")[回答保存为待核对候选 ↗](../../../docs/prototype/app.jsx#L463 "证明演示回答不会直接成为正式事实，而是进入待核对候选。")

<a id="delivery"></a>
## 构建、状态与验证进展

构建脚本用 esbuild 打包 React 应用，并内联样式与第三方声明生成自包含 HTML。[自包含 HTML 构建流程 ↗](../../../docs/prototype/build.mjs#L1 "支持应用打包、样式和声明内联以及离线 HTML 输出流程。") 演示变更历史写入 `localStorage`，问题草稿和会话只保存在页面内存。[本地演示状态生命周期 ↗](../../../docs/prototype/README.md#L41 "说明变更历史与问题会话分别保存在本地存储和页面内存。") 冒烟脚本明确通过 Playwright 启动 Chromium；验证记录显示 2026-09-26 使用版本 153.0.8010.12 检查了长链、循环、版本、追问、恢复、搜索和移动布局，错误及外部请求为空。[Chromium 启动流程 ↗](../../../docs/prototype/smoke.mjs#L2 "证明冒烟脚本实际通过 Playwright 启动 Chromium，从而确定验证记录中的浏览器类型。")[离线原型验证记录 ↗](../../../docs/prototype/verification.json#L2 "支持检查日期、浏览器版本、场景清单、空错误和空外部请求，并限定验证范围。") 该记录只覆盖离线原型，不证明后端或模型能力。

<a id="limits"></a>
## 能力边界与待确认关系

原型未连接 LLM、真实数据源、数据库或记忆引擎；同步、学习和恢复都只是演示状态。[真实能力边界 ↗](../../../docs/prototype/README.md#L18 "直接支持模型、真实数据、数据库、记忆引擎和后台任务尚未接入的限制。") 因此不能把它已作为正式 UI 合同视为既定事实。当前 hash 仅记录当前节点，初始化只恢复单帧，无法还原完整阅读路径。[单节点链接与恢复 ↗](../../../docs/prototype/app.jsx#L400 "支持链接只记录当前节点、初始化只恢复单帧，无法还原完整路径的判断。") 调节参数通过跨窗口消息请求宿主持久化；发送使用通配目标，激活与停用消息也未校验来源，可信嵌入边界仍待明确。[调节参数持久化请求 ↗](../../../docs/prototype/tweaks-panel.jsx#L177 "支持参数更新后通过通配目标跨窗口消息请求宿主持久化。")[调节面板消息边界 ↗](../../../docs/prototype/tweaks-panel.jsx#L236 "支持激活与停用消息仅检查类型、未校验消息来源的风险判断。")
