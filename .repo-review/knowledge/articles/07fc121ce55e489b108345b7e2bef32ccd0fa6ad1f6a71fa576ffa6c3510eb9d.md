# 飞书应用注册与能力核验

封装飞书设备码注册流程，为注册轮询的临时网络故障提供有限重试，并通过公开 OpenAPI 核验权限、回调和机器人身份；事件订阅改由实时投递确认。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="registration"></a>
## 注册流程与轮询续命

注册适配器把内部配置映射到飞书 SDK，包括仅创建模式、已有应用 ID、预设、附加能力、取消信号以及二维码和状态回调，最后转换客户端凭据与可选用户信息。[官方注册适配器 ↗](../../../apps/server/src/integrations/lark/registration.ts#L73 "支持注册参数、取消信号、二维码与状态回调的映射，以及凭据结果转换。")

为避免一次网络错误终止设备码流程，模块在共享 HTTP 实例上安装一次响应拦截器。它只重试注册路径上的 5xx 或指定传输错误，检查取消信号，最多重试五次并采用封顶的指数退避；复用原请求可维持同一设备码。拦截器由模块级标志控制，只安装一次。[注册轮询重试拦截器 ↗](../../../apps/server/src/integrations/lark/registration.ts#L29 "支持保持原轮询请求、限定可重试错误、检查取消状态、重试上限和指数退避行为。")

<a id="capability"></a>
## 能力探测与保守失败

能力探测先用应用凭据换取租户令牌，再并行读取机器人和应用信息，从返回数据整理 scopes、callbacks 与机器人 open ID，并与请求配置求差集。公开应用接口不暴露事件订阅列表，因此结果中的 events 为空，事件能力改由首个匹配的 WebSocket 投递在运行时确认。[公开接口能力探测 ↗](../../../apps/server/src/integrations/lark/registration.ts#L135 "支持公开应用接口不提供事件列表、运行时确认事件能力，以及令牌、权限、回调和机器人身份探测流程。")

若调用方未装配真实探针，拒绝型实现返回 `live_capability_probe_not_configured`，而不会把请求的附加能力当成已经授权。这使激活流程在缺少租户侧实证时保守失败。[拒绝型能力探针 ↗](../../../apps/server/src/integrations/lark/registration.ts#L225 "支持未配置真实能力探针时明确返回缺失项并拒绝乐观激活。")
