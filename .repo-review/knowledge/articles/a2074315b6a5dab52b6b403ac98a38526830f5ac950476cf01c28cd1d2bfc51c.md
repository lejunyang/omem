# 本地运行产物与评审数据忽略策略

该文件排除依赖、构建产物、本地环境与运行数据，同时保留环境变量示例；对 repo-review，它明确区分受版本控制的冻结基线、知识资产与被忽略的实时运行目录。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="general"></a>
## 常规本地产物隔离

忽略规则覆盖依赖目录、构建输出、`.omem/` 本地状态、测试报告、Playwright 报告及 osdk 本地目录。`.env` 和各类 `.env.*` 默认被排除，但 `.env.example` 被显式重新纳入，体现“秘密留在本地、模板进入版本库”的配置边界。规则表达的是版本控制意图，不能单独证明相关文件从未被提交。[通用忽略项与环境模板例外 ↗](../../../.gitignore#L1 "支持依赖、构建、本地状态和测试产物被忽略，以及 `.env.example` 被保留的结论。")

<a id="review-boundary"></a>
## repo-review 三类资产

注释将 repo-review 数据分为三类：冻结的运行基线被有意跟踪；实时写入迁移到 `.repo-review/runtime/` 后忽略；curated knowledge、清单和种子继续受版本控制。缓存、临时目录、模型输出和嵌入也被排除。由于 Git 忽略规则不影响已跟踪文件，这些模式不能作为冻结资产已被删除或取消跟踪的证据。[repo-review 数据边界 ↗](../../../.gitignore#L15 "支持冻结基线、实时运行目录、知识资产及派生缓存之间的版本控制边界。")
