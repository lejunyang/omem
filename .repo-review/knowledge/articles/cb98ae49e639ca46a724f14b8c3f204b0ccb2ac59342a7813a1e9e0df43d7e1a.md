# 知识库阅读入口与文章导航

知识库首页以双栏布局组织文章目录与正文阅读，支持主题分组、关键词筛选、会话内选中恢复和定时刷新，并把文章加载及引用导航交给正文组件处理。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 从知识目录进入连续阅读

知识库首页解决文章增多后难以发现和连续阅读的问题：左侧提供目录与搜索，右侧展示当前文章；没有可读内容时，引导用户先导入并分析材料。参考 [知识库双栏入口 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L29 "支持首页包含搜索、目录、正文区域以及无内容引导的用途说明。")

目录按“总览与主题”“功能与实现”“全部文章”组织。主题总览优先，模块列表排除分片文章，让首次进入的读者先理解整体，再深入具体实现。参考 [文章分组规则 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L12 "支持主题总览优先、模块入口排除分片文章及其他文章独立归类。")

<a id="flow"></a>
## 目录加载、选择与正文展示

页面挂载时请求文章元数据，之后每 15 秒刷新，卸载时停止轮询。选中的文章键保存在浏览器会话中；若原选择已失效，则优先回退到主题总览，否则选择列表首篇。参考 [目录刷新与选择恢复 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L16 "支持会话保存、失效选择回退、首次加载、十五秒轮询和卸载清理流程。")

```mermaid
flowchart LR
  A[加载文章目录] --> B[分组或筛选]
  B --> C[选择当前文章]
  C --> D[请求完整正文]
  D --> E[渲染章节并沿引用导航]
```

首页把文章键和修订号交给正文组件。正文组件请求完整文章，以代次校验忽略过期响应，并把各章节交给 Markdown 阅读器；可操作引用会转换为继续导航事件。参考 [正文组件衔接 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L44 "支持首页向正文组件传递文章键、修订号并转发导航事件。") [正文请求与引用导航 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L10 "支持完整文章请求、过期响应保护、章节定位和可操作引用导航。") [文章章节渲染 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L31 "直接支持正文遍历文章章节并通过 Markdown 组件渲染章节内容。")

<a id="boundaries"></a>
## 筛选方式与状态边界

搜索在前端对标题、摘要和文章键拼接后的文本执行大小写不敏感子串匹配；输入搜索词后，匹配结果以扁平列表展示。参考 [关键词匹配范围 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L14 "直接支持筛选覆盖标题、摘要和文章键，并采用小写化后的子串匹配。") [搜索结果列表 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L34 "支持有搜索词时直接遍历匹配文章并传入空子文章集合，形成扁平结果列表。") 目录树会排除当前节点和祖先节点以避免可见循环，并为非当前文章标注“待更新”。参考 [目录树防环与更新标记 ↗](../../../apps/web/src/knowledge/KnowledgeTree.vue#L4 "支持过滤当前及祖先节点，并为非当前文章显示待更新状态。")

目录请求失败时，错误显示在正文区域，已有文章数组不会在异常分支中主动清空。参考 [错误展示位置 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L44 "直接支持请求错误在右侧正文内容区域以警告文本显示。") [首页请求处理 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L18 "支持成功时替换文章数组、失败时仅记录错误且没有主动清空既有目录。") 首页轮询没有正文加载所用的请求代次保护，因此慢请求可能重叠，乱序响应是否需要专门处理仍待行为测试确认。参考 [正文过期响应保护 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L10 "用于对照说明正文组件使用递增代次忽略过期响应，而首页目录加载未采用该机制。")
