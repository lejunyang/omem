# 可追溯知识首页

汇总主题、材料覆盖率、文章检索与显式分析入口，并将正文阅读和待核对问题组织在同一知识主页中。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="loading-analysis"></a>
## 加载、覆盖率与显式分析

首页同时加载文章、材料和运行状态，以当前文章计算材料覆盖率；只要用户尚未主动选择，存在概览主题时便默认展示它。分析按钮仅提交尚无当前解读的 revision，并在请求成功后进入运行状态；页面每十五秒刷新，卸载时清理定时器。[知识首页状态与分析流程 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L1 "支持文章和材料加载、默认主题、覆盖率计算、显式分析请求及定时刷新行为。")

<a id="reading-index"></a>
## 主题阅读与知识索引

界面先展示覆盖率、分析状态和主题导航，再以内嵌正文阅读器打开当前主题。模块与材料区域按标题、键和摘要做客户端过滤，分批显示卡片；卡片区分材料知识、模块知识和主题知识，并提示已复核或来源变化。页面底部接入待核对问题。[知识首页阅读与索引界面 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L32 "支持覆盖率展示、主题导航、文章过滤与分页、状态标签以及问题入口的论断。")

<a id="current-limitations"></a>
## 当前交互限制

筛选只在已经载入浏览器的文章集合中进行，匹配规则是简单的小写子串；轮询间隔固定，也没有在此组件中呈现任务进度明细。[知识首页状态与分析流程 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L1 "支持文章和材料加载、默认主题、覆盖率计算、显式分析请求及定时刷新行为。")[知识首页阅读与索引界面 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L32 "支持覆盖率展示、主题导航、文章过滤与分页、状态标签以及问题入口的论断。") 因而它适合作为轻量入口，但材料规模很大或分析耗时较长时，仍可能需要服务端搜索、分页和更细的任务状态。
