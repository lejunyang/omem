# 知识首页、覆盖进度与材料索引

汇总当前知识文章和材料覆盖情况，提供主题阅读、文本筛选、分批索引与显式分析入口，并定时刷新运行状态。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="loading-selection"></a>
## 数据加载与主题选择

首页从文章接口同时取得文章、材料及分析运行状态，并每 15 秒刷新；卸载时清除定时器。当前主题只取以 `topic:` 开头且仍为 current 的文章，在用户尚未手动选择时优先打开总览主题，避免后续轮询覆盖用户选择。[文章加载、主题选择与轮询 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L9 "支持文章和材料加载、总览主题默认选择、定时刷新及卸载清理。")

<a id="coverage-analysis"></a>
## 覆盖统计与显式分析

覆盖数按“材料存在同键 current 文章”计算。若仍有未解读材料，按钮会把对应 revisionId 集合提交到分析端点，并在请求成功后标记为运行中；运行期间按钮禁用。这里能够确认的是前端提交与状态表达，不能单独证明后台分析、复核或持久化已经完成。[覆盖状态与分析请求 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L19 "支持覆盖统计、待处理 revisionId 收集、分析 POST 请求和运行状态界面。")

<a id="reading-index"></a>
## 主题阅读与知识索引

桌面主题导航和移动选择器共享 selected 状态；选中的当前文章以内嵌正文展示。非主题文章可按标题、键和摘要做不区分大小写筛选，卡片展示摘要及“已复核”或“来源变化，待更新”，点击后创建知识帧。列表每次显示 40 篇，可继续扩展，页面底部还装配全局疑问列表。[主题阅读与文章索引界面 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L32 "支持响应式主题选择、正文展示、筛选分页、状态文案及疑问组件装配。")
