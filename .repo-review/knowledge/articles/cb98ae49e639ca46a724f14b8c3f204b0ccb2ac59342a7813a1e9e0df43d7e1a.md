# 知识首页、覆盖状态与分析入口

知识首页汇集主题、当前解读和材料覆盖情况，提供筛选、分页式展开与显式分析请求，并定时刷新运行状态。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="loading-and-selection"></a>
## 加载、轮询与默认主题

首页从 articles 接口同时读取文章、材料和分析运行状态，并在未发生人工选择时优先选中当前的“概览”主题。组件挂载后立即加载，随后每 15 秒刷新一次，卸载时清除定时器；用户主动点击主题会锁定选择，避免后续刷新重新切回默认概览。请求失败则把异常文本放入页面警告区域。[首页加载与主题选择 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L9 "支持文章和材料加载、概览主题默认选择、人工选择保护以及十五秒轮询生命周期。")

<a id="coverage-and-analysis"></a>
## 覆盖统计与显式分析请求

覆盖数按“材料键存在同键且 current 的文章”计算。仍有未覆盖材料时，界面允许显式请求 analyze，并提交这些材料的 revisionId；请求成功后仅在前端把 running 设为 true，按钮随之禁用，实际分析、复核及持久化是否完成仍要由服务端和后续轮询结果确认。[覆盖计算与分析请求 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L19 "支持当前解读覆盖数的计算、待处理修订筛选和显式分析 POST 行为。")

<a id="reading-and-index"></a>
## 主题阅读与知识索引

当前选中文章直接嵌入正文阅读器；没有当前文章时显示等待材料分析与复核的空状态。非 topic 文章组成索引，可按标题、键和摘要的组合文本过滤，初始最多展示 40 篇并逐批扩展；卡片同时标示材料、模块或主题类别，以及“已复核”或“来源变化，待更新”状态。页面底部还挂载全局疑问列表。[知识主题与索引界面 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L32 "支持主题导航、正文嵌入、文章筛选、分批显示、状态标签和疑问列表的位置。")
