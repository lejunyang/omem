# 知识库浏览、检索与文章整理入口

KnowledgeHome 是知识库的页面级协调组件：它加载文章、材料与整理状态，构建主题导航，管理文章选择和搜索，并在正文阅读、分类概览与文章整理之间切换。它保存并恢复会话内选中的文章，同时适配窄屏布局，但不负责正文渲染、主题树算法或服务端检索排序。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-navigation"></a>
## 把分类浏览和连续阅读汇集到一个入口

该页面解决知识文章增多后难以定位和连续阅读的问题。它按当前主题路径筛选文章，并在所选文章的同分类文章中依照阅读顺序计算“下一篇”。参考 [分类筛选与下一篇 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L39 "支持按主题路径筛选文章、确定同分类文章并计算下一篇的说明。")

分类树、路径包含判断和文章排序由主题工具完成；递归目录组件负责展开子主题并转发主题或文章选择事件。因此，主页承担浏览流程的编排，而不解析文章正文。参考 [主题树与文章排序 ↗](../../../apps/web/src/knowledge/topics.ts#L3 "说明路径包含判断、阅读顺序排序和主题树构建由主题工具负责。") [递归主题目录 ↗](../../../apps/web/src/knowledge/KnowledgeFolder.vue#L22 "支持目录递归渲染子主题并向上转发主题和文章选择事件。")

页面初始化时优先采用外部传入的文章键，否则读取会话存储中的文章键；用户选择文章后，又会关闭移动目录、保存新文章键并通知上层。两者共同实现当前浏览会话中的阅读位置恢复。参考 [会话文章恢复 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L25 "支持页面初始化时优先使用外部文章键，否则从会话存储恢复已选文章键。") [文章选择与保存 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L117 "支持选择文章时关闭移动目录、保存文章键并通知上层。")

<a id="loading-and-search"></a>
## 定期刷新数据并避免旧搜索覆盖新结果

页面挂载后立即加载文章、可选材料与整理状态，随后每五秒刷新一次。卸载时会停止轮询、清除尚未执行的搜索定时器、中止当前搜索请求并使旧搜索版本失效。参考 [数据轮询与卸载清理 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L134 "支持首次加载、五秒轮询以及卸载时清理轮询和搜索任务的说明。")

```mermaid
flowchart LR
  A[输入关键词或切换主题] --> B[等待 250 毫秒]
  B --> C[携带关键词和主题路径请求搜索]
  C --> D[合并远程结果与本地标题摘要匹配]
  D --> E[按文章键去重展示]
```

搜索条件变化时，页面先取消旧请求并递增版本号，只有最新版本可以更新结果、错误和加载状态，从而避免较慢的旧响应覆盖新查询；空查询则回到主题目录。参考 [防竞态搜索流程 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L70 "支持搜索防抖、取消旧请求、版本校验以及远程和本地结果合并去重的流程。") 请求封装会附加会话令牌、解析 JSON，并把非成功响应转换为异常。参考 [知识接口请求封装 ↗](../../../apps/web/src/knowledge/api.ts#L6 "说明请求如何附加会话令牌、解析 JSON，并将非成功响应转换为异常。")

<a id="reading-and-composing"></a>
## 在阅读、分类概览和文章整理之间切换

选中文章时，页面按文章键与修订号挂载正文组件，并向上转发证据导航事件；未选中文章时，则展示分类面包屑、主题卡片和分页文章列表。非当前版本的文章会标记为“待更新”，读者还可以返回分类或继续阅读同分类的下一篇。参考 [正文与分类概览切换 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L274 "支持正文挂载、证据导航转发、分类概览、待更新标记及继续阅读入口。")

点击“整理文章”会打开整理器。整理器把所选材料修订和文章简报提交到 `/pages`；提交成功事件回到主页后会再次执行数据加载，使新状态能够出现在目录和提示区域。参考 [文章整理提交 ↗](../../../apps/web/src/knowledge/ArticleComposer.vue#L58 "证明整理器向 pages 接口提交所选材料修订和文章简报。") [提交后重新加载 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L368 "支持整理器触发 submitted 事件后由主页调用 load 重新加载数据。") 页面还会分别显示整理中、失败和发布完成状态，并在完成后提供文章入口。参考 [整理任务状态 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L254 "支持主页展示整理中、失败和发布完成状态，并在完成后提供文章入口。")

在窄屏上，目录于 900 像素以下变为可展开区域；到 700 像素以下，正文间距进一步收紧，主题卡片改为单列。参考 [窄屏目录布局 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L645 "支持页面在 900 像素以下折叠目录，并在 700 像素以下调整正文和卡片布局。")
