# 可点击的证据引用标签

该组件把引用名称和可选版本号呈现为紧凑按钮，并将打开引用的动作交给父组件处理；它负责基础视觉与长文本适配，但不包含引用查询、抽屉导航或缺失证据处理逻辑。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 把正文引用变成操作入口

`OmCitation` 用于在正文附近呈现一个可点击的证据标签。调用方必须提供人可读的 `label`，可以附带 `version`；组件同时声明了不携带参数的 `open` 事件，因此自身只表达“用户想打开这条引用”，并不决定打开哪个页面或如何加载证据。参考 [组件输入与打开事件 ↗](../../../packages/ui/src/components/OmCitation.vue#L1 "支持组件接收标签和可选版本，并仅向上层发出无参数 open 事件的说明。")

模板采用原生按钮：主体显示标签，右上角在版本存在时显示 `v版本号`，否则显示外链式箭头。点击按钮只向父级发送 `open`，实际的证据抽屉、导航和数据读取应由使用它的上层模块完成。参考 [引用按钮渲染规则 ↗](../../../packages/ui/src/components/OmCitation.vue#L5 "支持点击触发 open，以及版本存在时显示版本、否则显示箭头的流程和边界判断。")

<a id="display-rules"></a>
## 版本显示与长标签适配

版本判断使用真值条件，因此正整数会显示为 `v1`、`v2` 等，而 `undefined` 或数值 `0` 都会退回箭头。这意味着组件没有区分“未提供版本”和“版本号为 0”；若业务允许零版本，调用方需要先统一版本语义。参考 [引用按钮渲染规则 ↗](../../../packages/ui/src/components/OmCitation.vue#L5 "支持点击触发 open，以及版本存在时显示版本、否则显示箭头的流程和边界判断。")

按钮最大宽度限制为容器宽度，并允许在任意位置换行，适合较长的引用名称。背景、文字颜色取自共享 CSS 变量，悬停时改为灰色；这些样式使组件能嵌入阅读正文，但材料没有给出焦点态或禁用态设计。参考 [按钮阅读样式 ↗](../../../packages/ui/src/components/OmCitation.vue#L11 "支持按钮颜色、尺寸、长文本换行和悬停反馈的说明。")

<a id="integration-boundaries"></a>
## 与证据阅读流程的边界

该文件没有接收引用标识、来源地址或证据状态，也没有导入其他模块。因此能够确认的集成合同只有 `label`、可选 `version` 和 `open` 事件；无法仅凭本材料确认它具体由哪些页面使用，或 `open` 是否连接递归证据抽屉。参考 [组件输入与打开事件 ↗](../../../packages/ui/src/components/OmCitation.vue#L1 "支持组件接收标签和可选版本，并仅向上层发出无参数 open 事件的说明。")

组件也没有加载中、引用缺失、点击失败等分支，且未展示测试文件。右上角标记仅调整字号和左间距，属于视觉提示，不承担状态说明。参考 [角标视觉样式 ↗](../../../packages/ui/src/components/OmCitation.vue#L26 "支持右上角版本或箭头标记只具有字号与间距样式的说明。")
