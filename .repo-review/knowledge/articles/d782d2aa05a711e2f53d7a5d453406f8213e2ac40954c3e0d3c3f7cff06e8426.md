# 可点击引用标签组件

把人类可读的引用标签与可选版本提示呈现为按钮，并通过 open 事件把证据打开行为交给父组件。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="contract"></a>
## 交互合同

组件只接收 label 与可选的 number 型 version，并声明无参数 open 事件；点击时不解析目标，而是通知父组件执行导航或打开证据，因此目标标识、权限判断和 trail 管理均不在本文件内。[引用组件事件接口 ↗](../../../packages/ui/src/components/OmCitation.vue#L1 "支持组件输入、无参数 open 事件，以及点击行为交由父组件处理的职责边界。") 模板采用真值判断：version 为真值时显示 `v` 加数字，否则显示箭头；所以 0 会落入箭头分支，不能笼统理解为“只要提供版本就显示版本号”。[引用版本分支 ↗](../../../packages/ui/src/components/OmCitation.vue#L5 "支持模板按 version 真值选择版本标记或箭头，并揭示数值 0 的边界行为。")

<a id="layout"></a>
## 布局与限制

按钮使用柔和背景、下边框和左对齐，并允许在任意位置换行，避免较长的人类标签撑破容器；版本或箭头以较小上标呈现。[引用标签样式 ↗](../../../packages/ui/src/components/OmCitation.vue#L10 "支持长标签换行、柔和背景、下边框以及较小上标等布局说明。") 当前接口没有 disabled、actionable 或 reason，也未显式设置 type="button"。因此它位于表单中时可能触发原生默认提交；失效引用如何展示原因、禁止打开，以及版本是否允许 0，均无法仅凭该文件确认。
