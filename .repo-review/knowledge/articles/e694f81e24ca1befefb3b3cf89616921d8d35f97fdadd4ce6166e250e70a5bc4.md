# 仓库评审知识库主应用

作为 repo-review 前端编排层，整合 Code Wiki、材料浏览、固定修订阅读、全文搜索、代码关系追溯和增量同步状态，并区分人工确认关系与关键词候选。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="navigation-data"></a>
## 视图编排与数据入口

组件维护 Code Wiki、材料浏览、固定修订阅读、全文搜索、代码追溯和同步状态等视图，并集中调用评审 API 获取健康信息、分类、来源、修订、片段、关系及同步数据；Code Wiki 是默认入口。[主应用视图与评审 API ↗](../../../apps/web/src/ReviewApp.vue#L1 "支持组件定义的视图集合、默认 Wiki 状态以及其直接依赖的评审 API 范围。") 启动时并行读取健康信息和分类，再读取同步状态；由于默认处于 Wiki，启动阶段不会预载材料列表。[应用启动流程 ↗](../../../apps/web/src/ReviewApp.vue#L390 "支持启动时并行读取健康状态和分类、默认不预载来源列表以及随后读取同步状态。") 浏览视图按分类请求来源，默认过滤已删除来源；用户切换“显示已删除”后，会按当前分类重新查询。[来源过滤与分类加载 ↗](../../../apps/web/src/ReviewApp.vue#L170 "支持默认隐藏已删除来源、按分类加载材料以及切换选项后重新查询。")

<a id="revision-relations"></a>
## 固定版本阅读与关系导航

打开修订时先读取固定快照，并尝试取得同一来源的历史版本；历史列表失败会降级为空，不阻断当前正文。选择片段后并行读取片段详情和登记关系，关系读取失败同样降级为空，再以路径及最多三个符号生成决策、调研候选关键词。[修订、片段与候选加载 ↗](../../../apps/web/src/ReviewApp.vue#L219 "支持历史版本失败降级、片段和关系并行加载，以及根据路径和符号查询决策、调研候选。") 关系状态直接使用服务端给出的有效状态，并按预设类型顺序稳定分组，前端不重新推断当前性。[关系状态与稳定分组 ↗](../../../apps/web/src/ReviewApp.vue#L108 "支持前端直接使用有效关系状态，并按预设关系类型顺序分组展示。") 点击关系时仅在对端或对端修订标识缺失时拒绝跳转，否则打开对端修订并定位片段；因此是否可跳转并不等同于关系是否为 confirmed。[关系对端跳转边界 ↗](../../../apps/web/src/ReviewApp.vue#L281 "支持关系对端缺失时拒绝跳转，以及存在对端修订时打开并定位片段的准确条件。") 阅读界面展示当前或历史版本、工作树 dirty 标记、commit、内容哈希、同步时间及历史版本选择器，用于辨认所读内容对应的固定快照。[固定快照与历史版本界面 ↗](../../../apps/web/src/ReviewApp.vue#L495 "支持阅读界面展示当前性、dirty 标记、commit、内容哈希、同步时间和历史版本选择器。")

<a id="search-trace-sync"></a>
## 搜索、追溯与同步边界

搜索命中只携带片段标识时，界面先读取片段详情以确定所属修订，再打开并定位。代码追溯则按仓库路径查找代码来源、读取人工登记关系，并尝试读取头部修订中的符号；修订读取失败时退回路径关键词，决策和调研搜索失败则降级为空候选。[搜索命中与代码追溯流程 ↗](../../../apps/web/src/ReviewApp.vue#L309 "支持命中解析、按路径读取代码来源、人工关系读取、符号关键词构造及失败降级。") 页面将人工登记链路与关键词候选分区展示，候选最多各显示五项，并明确不把相似结果当作确认关系。[登记链路与关键词候选界面 ↗](../../../apps/web/src/ReviewApp.vue#L644 "支持人工关系和关键词候选分区展示、候选标识及每类最多五项的界面限制。") 执行同步后，组件并行刷新同步状态、分类和健康统计；这里的 `syncBusy` 只反映当前组件的一次操作。[同步请求与刷新流程 ↗](../../../apps/web/src/ReviewApp.vue#L364 "支持同步调用、成功后刷新同步状态、分类和健康信息，以及组件本地忙碌状态的生命周期。") 同步页展示扫描、新增、更新、未变、跳过及最近提交信息，并声明当前浏览和检索不依赖 Agent CLI 或模型；该声明限于此只读评审界面，不能据此推断服务端同步的并发与事务语义。[同步统计与只读模式声明 ↗](../../../apps/web/src/ReviewApp.vue#L704 "支持同步页展示扫描统计、最近结果，并声明浏览检索不依赖 Agent CLI 或模型。")
