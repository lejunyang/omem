# 仓库评审应用的多视图入口与证据浏览流程

ReviewApp.vue 是 repo-review Web 端的顶层编排组件，承载代码 Wiki、分类材料浏览、固定版本阅读、全文搜索、代码追溯与同步状态。被替代结论：启动或点击“浏览材料”均不会自动加载材料列表，只有点击具体分类才发起查询。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role"></a>
## 组件定位与职责边界

该组件是仓库评审 Web 端的应用壳，集中维护 Wiki、浏览、阅读、搜索、追溯和同步等顶层视图及共享状态，并将默认入口交给 `CodeWiki`。[顶层视图与共享状态 ↗](../../../apps/web/src/ReviewApp.vue#L37 "支持组件统一维护六类顶层视图和相应响应式状态的论断。") 后者负责仓库快照、模块图、文件与模块详情、证据 trail 及哈希深链，因此 `ReviewApp` 的核心职责是跨视图编排和材料阅读，而非重复建设 Wiki 内部导航。[代码 Wiki 容器职责 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L1 "说明 CodeWiki 负责模块图、详情、证据 trail 和深链，界定与应用壳的分工。")

数据访问统一经过 repo-review API 客户端；该接口面向本机的浏览、读取和同步场景，不发送个人工作区授权头。这是当前通信边界，不能据此推断存在多租户鉴权。[评审 API 客户端边界 ↗](../../../apps/web/src/review-api.ts#L1 "支持本机浏览、读取和同步接口不发送个人工作区授权头的边界说明。")

<a id="browse_read"></a>
## 启动、分类浏览与固定版本阅读

挂载时会并行读取健康状态与材料分类，再读取同步状态。默认视图是 Wiki，故启动阶段不预加载材料列表。[应用启动流程 ↗](../../../apps/web/src/ReviewApp.vue#L390 "支持启动时读取健康、分类和同步状态，且默认 Wiki 场景不预加载材料列表。") 被替代的旧结论是“进入浏览页时会加载当前分类”：侧栏“浏览材料”实际上只切换视图，只有点击具体分类按钮才调用 `loadSources`，首次直接进入浏览页可能暂时显示空列表。[侧栏导航与分类加载 ↗](../../../apps/web/src/ReviewApp.vue#L423 "支持被替代结论：普通浏览导航只切换视图，具体分类按钮才加载材料。")

分类查询会更新当前分类；列表默认过滤已删除源，勾选后重新请求。打开条目会读取固定修订、清空旧片段状态并加载同源历史版本，历史查询失败只降级为空列表，不阻断当前版本阅读。[材料列表与版本阅读流程 ↗](../../../apps/web/src/ReviewApp.vue#L170 "支持删除项过滤、分类查询、固定修订打开和历史版本失败降级。")

<a id="relations_search"></a>
## 片段关联、搜索与代码追溯

选择片段时并行取得详情和登记关系，再从文件名、路径段与少量符号生成关键词，查找决策和调研候选；关系目标缺失时提示并停止跳转。[片段详情与关系加载 ↗](../../../apps/web/src/ReviewApp.vue#L253 "支持片段详情、登记关系、关键词候选以及缺失目标不可跳转的流程。") 关系的有效状态由服务端结果映射为“已关联、候选、缺失、已过期”，并在片段关系卡片中显示；词匹配结果仍只是候选，不能替代人工登记链路。[关系状态映射与呈现 ↗](../../../apps/web/src/ReviewApp.vue#L112 "支持确认、候选、缺失和过期状态的标签映射及其在片段关系卡片中的实际展示。")

全文搜索修剪输入后查询片段，点击命中会解析所属修订并定位原片段。代码追溯按路径读取代码源与登记关系，并尝试用当前修订符号增强关键词；修订或关联搜索失败时可局部降级。[搜索与代码追溯流程 ↗](../../../apps/web/src/ReviewApp.vue#L290 "支持搜索命中解析、路径追溯、登记关系读取、符号关键词增强和局部失败降级。")

<a id="sync_limits"></a>
## 同步流程与并发限制

手动同步会设置忙碌状态；成功后并行刷新同步状态、分类与健康统计，失败写入统一错误栏，最终恢复按钮。同步页明确声明当前是只读浏览与检索模式，不依赖 Agent CLI 或模型；该声明不等同于对整个组件所有潜在能力的穷举。[同步流程与页面模式声明 ↗](../../../apps/web/src/ReviewApp.vue#L364 "支持同步刷新流程以及同步页面明确给出的只读浏览、检索和无模型依赖限制。")

版本与片段请求完成后会直接写入共享状态，材料未显示请求序号、取消或旧响应丢弃机制。[版本与片段异步状态写入 ↗](../../../apps/web/src/ReviewApp.vue#L219 "支持版本和片段流程直接更新共享状态且未显示竞态防护的判断。") 搜索与追溯流程同样直接更新各自状态。[搜索与追溯异步状态写入 ↗](../../../apps/web/src/ReviewApp.vue#L290 "支持搜索和追溯流程也直接写入状态、未显示请求序号或取消控制的判断。") 因而快速连续切换目标时存在较慢旧响应覆盖新状态的可能，但最终一致性策略仍需由产品约定和行为测试确认。
