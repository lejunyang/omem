# 符号范围阅读与关系钻取组件

该 Vue 组件把代码图中的单个符号组织成可继续钻取的阅读帧：解析符号与文件，读取带上下文的源码窗口和文件关系边，高亮符号固定范围，并将关系目标或关联知识片段交给上层导航。更新后的结论明确了源码窗口的最小覆盖规则，并把同文件钻取限定为组件声明的交互合同；辅助函数的实际判定细节仍待材料验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 职责与阅读界面

组件从上层提供的 `symbolMap` 和 `fileMap` 解析当前符号及所属文件，自身不搜索仓库；它统一发出文件、符号或知识片段三类 `drill` 事件，由上层维护阅读栈和实际导航。[符号解析与钻取事件合同 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L28 "支持组件依赖上层代码图解析当前符号和文件，并向外发出三类钻取目标的说明。") 界面展示路径、名称、类型、行范围、导出状态和签名，并以共享代码查看器突出符号的绝对范围；存在 `fragmentId` 时还可进入对应决策或规则片段。[符号详情与源码查看界面 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L147 "支持界面展示符号元数据、片段入口以及使用代码查看器呈现源码的论断。")[符号绝对范围标记 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L84 "支持代码查看器的高亮范围由符号绝对起止行、类型和名称构成。")

<a id="loading"></a>
## 加载与范围定位

组件在挂载及 `symbolId` 变化时加载。它先确认符号和文件仍在当前图中，再以符号起点向上六行为基础确定 `start`；终点取“符号末行向下六行”和“从 `start` 起至少覆盖约十一行”中的较大值，并受文件总行数限制。[源码窗口与边并行加载 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L55 "支持修正后的窗口计算规则、文件总行数限制、源码与关系边并行读取及边失败降级。")[响应式加载触发 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L81 "支持组件仅在挂载和 symbolId 变化时启动加载，并为竞态疑问界定现有证据范围。") 因而此前“始终向上下各扩展六行”的绝对结论已被替代：文件开头、缺失范围或短符号都可能使下方上下文超过六行。源码读取或图节点失败进入统一错误状态；边查询失败则降级为空数组，仍允许源码展示。[源码窗口与边并行加载 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L55 "支持修正后的窗口计算规则、文件总行数限制、源码与关系边并行读取及边失败降级。")

<a id="edges"></a>
## 关系筛选与钻取边界

加载文件级关系后，组件仅保留起点或终点为当前符号的边，并根据当前符号所在端显示入向或出向；标签、可点击性和钻取目标均委托给 `edgeDrillTarget`。[关系筛选与目标解析 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L97 "支持关系筛选、方向判断、标签生成、可解析性检查和 drill 事件转换的说明。") 文件头明确把“同文件关系应打开另一个符号范围帧”声明为组件合同，替代此前把该行为直接归因于当前可见辅助函数实现的结论。[同文件关系交互合同 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L2 "支持将同文件符号打开新范围帧表述为组件文件头声明的交互合同，而非已核实的辅助函数内部规则。") 但现有 `modules.ts` 材料未覆盖该函数实现，因此跨文件、同文件及缺失端点的实际判定优先级仍不能确认。[关系辅助函数所在模块的可见范围 ↗](../../../apps/web/src/codewiki/modules.ts#L1 "当前提供的 modules.ts 范围仅展示模块聚合定义，未包含 edgeDrillTarget 实现，支持保留导航规则疑问。") 界面最多渲染前 60 条相关边，无法解析的目标会被禁用；空数组统一显示“暂无登记边”，没有区分真实空集和请求失败。[关系列表与空状态 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L165 "支持关系列表最多显示 60 条、不可解析目标禁用以及空数组统一显示无登记边的限制说明。")

<a id="relations"></a>
## 模块关系与未确认行为

组件复用 `@omem/ui` 的面板、按钮、空状态和代码查看器，而源码及边数据来自 `review-api.ts`。[共享界面组件依赖 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L10 "支持符号帧复用公共 UI 面板、按钮、代码查看器和范围标记类型。") 后者被定义为本机 repo-review 的读取、浏览和同步客户端，不发送个人工作区授权头，因此这里属于仓库评审界面而非个人知识 API。[repo-review 客户端边界 ↗](../../../apps/web/src/review-api.ts#L1 "支持 review-api 是本机仓库评审读览同步客户端且不发送个人工作区授权头的模块关系说明。") 当前材料只证明挂载和标识变化会触发异步加载，未见请求取消或代次校验，也未提供组件测试，故快速切换的乱序覆盖、边失败提示和超过 60 条边等行为仍需验证。[响应式加载触发 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L81 "支持组件仅在挂载和 symbolId 变化时启动加载，并为竞态疑问界定现有证据范围。")
