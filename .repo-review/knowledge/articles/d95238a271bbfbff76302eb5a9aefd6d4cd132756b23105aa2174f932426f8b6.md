# 固定符号范围与双向关系帧

围绕单个解析符号读取带上下文的源码切片，突出固定范围，并允许沿符号关系或关联材料继续下探。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="source-window"></a>
## 符号定位与源码窗口

组件先从全局 symbolMap 找到符号，再由 fileMap 定位所属文件；对象缺失时明确报错。读取时先探测文件总行数，再取符号前后各约六行的窗口，同时加载所属文件的关系边；关系请求失败可降级为空。[符号源码窗口装载 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L43 "支持图对象校验、总行数探测、上下文切片和关系降级读取。") 固定符号起止行被转换为代码范围标记，切换 symbolId 会重新加载。[固定符号范围标记 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L84 "说明符号起止行如何转换为源码高亮范围。")

<a id="edge-navigation"></a>
## 双向边与同文件下探

符号边只保留以当前 symbolId 为起点或终点的记录，并据此标记入向或出向。每条边通过统一解析器转换为文件或符号目标；同文件目标仍发出新的 symbol drill，不会被吞掉。标签优先使用可读文件名或符号名，不可解析时才显示证据或“外部包 / 未解析”。[符号边解析与标签 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L97 "支持双向筛选、文件或符号下探及不可解析目标的显示策略。")

<a id="rendering-limits"></a>
## 材料入口与展示边界

符号若关联 fragmentId，会提供进入对应决策或规则片段的按钮；源码区域显示文件路径、符号名、种类、固定行范围、签名和导出状态。[片段入口与符号信息 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L147 "证明关联片段按钮以及路径、种类、范围、签名和源码切片的展示。") 关系列表当前最多渲染 60 条，只以是否能解析目标决定按钮可用性，并直接显示原始 edgeKind；它未像文件帧一样结合关系状态、原因和人类标签处理 missing、candidate 或 stale。[符号关系列表 ↗](../../../apps/web/src/codewiki/SymbolFrame.vue#L165 "支持 60 条渲染上限、仅按可解析性禁用以及直接展示 edgeKind 的边界说明。")
