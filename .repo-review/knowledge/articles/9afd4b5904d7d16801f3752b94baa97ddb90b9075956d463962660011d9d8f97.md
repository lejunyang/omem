# 视觉分析技能的 OpenAI 界面配置

该 YAML 提供技能在 OpenAI 类代理界面中的展示名称、简短说明和默认调用提示，是轻量级发现与启动配置；它没有声明模型、图像能力、推理强度或运行参数。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="interface-metadata"></a>
## 界面元数据

配置把界面展示名称设为“分析图像材料”，与技能职责相符；简短说明则使用英文，强调从固定证据构建带链接的知识。[界面名称与简短说明 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/skills/omem-visual-analyst/agents/openai.yaml#L1 "支持配置采用中文展示名、英文知识构建说明的界面元数据分析。") 这表明配置同时面向中文用户界面与通用知识产出概念，但未说明双语呈现是否出于产品设计。

<a id="default-invocation"></a>
## 默认调用入口

默认提示要求使用视觉分析技能处理已提供的固定材料，作用是把代理入口指向相应技能，并继承技能中的证据范围和输出约束。[默认技能调用提示 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/skills/omem-visual-analyst/agents/openai.yaml#L4 "支持默认入口将固定材料交给视觉分析技能处理的说明。") 然而该文件仅有界面字段，没有模型名称、视觉输入能力、effort、预算或兼容性设置，因此不能据此认定任意 OpenAI 模型都能执行图片分析。
