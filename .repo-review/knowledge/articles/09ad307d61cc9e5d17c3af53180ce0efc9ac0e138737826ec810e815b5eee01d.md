# 代码评审模型配置示例

给出 repo-review 模型执行器的 ACP 启动方式、模型与 effort，以及输入、输出和上下文预留预算。它是参考模板，不代表当前实际配置或模型能力验证结果。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="transport"></a>
## 只读 ACP 执行入口

模板以 `traecli` 启动 ACP server，并通过参数声明只读沙箱。[ACP 启动模板 ↗](../../../config/review-code-model.example.json#L2 "支持 transport、命令和只读沙箱参数的说明。") 这说明预期由外部 Agent 执行代码分析，但文件本身不能证明命令存在、ACP 握手成功或只读限制已被宿主实际落实。

<a id="model-budget"></a>
## 模型选择与预算边界

示例指定 `gpt-5.6-sol`、中等 effort、480 秒超时，并分别设置 192000 输入 token、24000 输出 token和 16000 上下文预留。[模型与 token 预算 ↗](../../../config/review-code-model.example.json#L10 "支持模型、effort、超时和三项 token 预算的具体描述。") 这些值共同约束一次评审任务的规模；模型名称与 effort 是否受当前 ACP 实现支持，仍需运行时能力发现和校验。
