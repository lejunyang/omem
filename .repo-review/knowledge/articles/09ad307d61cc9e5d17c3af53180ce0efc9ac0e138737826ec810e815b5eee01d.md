# 仓库知识模型示例配置

示例规定 repo-review 通过只读 TraeX ACP 调用 gpt-5.6-sol，并给出 effort、超时及输入输出预算；它用于复制和说明配置形态，不单独证明模型可用。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="transport"></a>
## 传输与模型选择

示例选择 ACP 传输，命令为 `traex`，以只读沙箱启动 ACP 服务；模型指定为 `gpt-5.6-sol`，推理 effort 为 `medium`。[示例 ACP 与模型设置 ↗](../../../config/review-code-model.example.json#L1 "支持只读 TraeX ACP、gpt-5.6-sol 和 medium effort 的配置说明。") 只读参数与知识分析场景相符：模型应处理宿主提供的固定材料，而不自行改动仓库。不过，示例文件只是声明预期组合，外部 CLI、模型和 effort 是否受支持仍需由 ACP 能力校验确认。

<a id="budgets"></a>
## 超时与上下文预算

单次超时设为 480 秒，最大输入 192000 tokens、最大输出 24000 tokens，并预留 16000 tokens 上下文。[示例模型预算 ↗](../../../config/review-code-model.example.json#L12 "说明超时、输入输出上限及上下文预留的具体配置。") 这些值把输入、输出和内部预留分开，避免只按字符数粗略判断可容纳材料；它们是运行上限而非实际计费量。当前状态说明 review 已改为读取实际配置文件，环境变量仍可覆盖，因此示例不应被当作运行时权威。[review 实际配置来源 ↗](../../../docs/implementation/status.md#L11 "用于区分 example 与当前运行所读取的实际配置，并指出环境变量覆盖入口。")
