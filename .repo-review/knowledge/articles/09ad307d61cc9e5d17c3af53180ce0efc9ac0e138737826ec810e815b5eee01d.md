# 代码评审模型配置示例

该文件给出代码评审生成流程的示例模型配置：通过 traex 的 ACP 服务调用 gpt-5.6-sol，采用 medium 推理强度和只读沙箱，并明确超时、输入输出令牌及上下文预留预算。它仅是示例配置，不能据此断言当前实际运行配置或调用状态。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="transport"></a>
## 调用通道与执行边界

示例选择 `acp` 作为传输方式，并以 `traex -c sandbox_mode="read-only" acp serve` 启动服务，表达了评审模型通过外部 Agent CLI/ACP 接入、且执行环境按只读模式约束的预期配置。[ACP 启动与只读沙箱配置 ↗](../../../config/review-code-model.example.json#L2 "支持附近关于传输方式、启动命令以及只读执行边界的说明。") 这是配置模板中的声明，不足以证明本机已安装对应命令、ACP 能成功握手，或实际任务确实使用了该文件。

<a id="model"></a>
## 模型与推理强度

模型被指定为 `gpt-5.6-sol`，推理强度为 `medium`。[模型与推理强度配置 ↗](../../../config/review-code-model.example.json#L10 "支持附近关于示例所选模型和推理强度的陈述。") 这组字段用于表达示例的模型选择，但材料没有包含能力发现或兼容性校验结果，因此无法确认当前 CLI 是否支持该模型与 effort 组合，也不能把示例值视为生产运行事实。

<a id="budgets"></a>
## 运行预算与限制

配置将单次调用超时设为 480000 毫秒，并设置 192000 输入令牌、24000 输出令牌以及 16000 上下文预留。[超时与令牌预算配置 ↗](../../../config/review-code-model.example.json#L12 "支持附近关于调用超时、输入输出令牌和上下文预留预算的说明。") 这些值共同限定长材料分析的容量与收尾空间；它们是静态预算声明，材料未说明超限时的截断策略、重试机制或运行 trace 是否实际记录并执行这些限制。
