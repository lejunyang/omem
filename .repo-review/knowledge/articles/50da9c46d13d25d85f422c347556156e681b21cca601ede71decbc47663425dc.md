# 证据、版本与递归引用设计合同

该合同定义稳定身份、不可变修订、引用关系、递归阅读、原位问答和补偿恢复的目标语义。文件明确是实现评审示意，并非已发布 API。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="identity"></a>
## 身份、修订与时间

Source、Fragment、Memory 等稳定身份与不可变 Revision 分离：前者用于跨版本追踪，后者用于准确打开当时内容。片段续接优先使用上游块、代码符号和结构邻域，歧义时记录候选继任而不猜测。有效时间与系统获知时间采用双轴，避免后录材料改写历史认知。[对象与修订不变量 ↗](../../../docs/contracts/evidence-model.md#L9 "支持稳定对象身份与不可变内容修订相分离的设计。")[片段续接与双轴时间 ↗](../../../docs/contracts/evidence-model.md#L21 "解释歧义片段的处理及有效时间、记录时间的不同用途。")

<a id="relations"></a>
## 关系和事实支持

contains、references、derived_from、supported_by 等关系具有不同证据含义；提到、派生或语义相关均不自动构成事实支持，supported_by 还需要有效评估。支持链不能因多跳引用自动传递，多来源摘要也必须满足必要证据的权限约束。[关系语义与非传递支持 ↗](../../../docs/contracts/evidence-model.md#L60 "支持引用、派生、相关和事实支持必须分离，并说明支持不可自动跨引用链传递。")

<a id="interaction"></a>
## 递归阅读、问答与恢复

Trace Session 以帧栈保存路径、焦点和滚动状态，支持逐层进入、返回及循环检测；请求规模有界，但不限制用户继续深入。原位回答需重新读取授权片段并验证引用。更新通过新修订和 ChangeSet 提交；恢复也是补偿性新变更，存在后续修改时必须重算而非覆盖旧状态。[Trace Session 与原位问答 ↗](../../../docs/contracts/evidence-model.md#L123 "支持帧栈式递归阅读、循环处理、上下文选择和回答引用验证。")[ChangeSet 与补偿恢复 ↗](../../../docs/contracts/evidence-model.md#L147 "支持事务提交、追加事件以及发生并发后续修改时必须重算的恢复语义。")
