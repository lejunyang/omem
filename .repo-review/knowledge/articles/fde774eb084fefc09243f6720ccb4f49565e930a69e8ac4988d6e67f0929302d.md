# 知识写作角色运行清单

该清单定义 knowledge-writer 第 1 版：加载内联写作技能，输出 KnowledgeBatch.v1，并采用无工具、无会话复用和不继承用户扩展的隔离配置；其预算与复核角色同量级。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="writer-contract"></a>
## 写作角色与产物

清单把运行单元标识为 `knowledge-writer` 第 1 版，使用 `traex` profile 和 `prompt.md`，并以内联方式加载带制品摘要的 `omem-knowledge-writer` 第 1 版技能。其输出 schema 是 `KnowledgeBatch.v1`，表明配置职责是生成结构化知识批次，而非作出 KnowledgeReview 判定。[知识写作角色与输出声明 ↗](../../../packages/agent-runtime/roles/knowledge-writer/1/manifest.json#L2 "支持 writer 的角色版本、profile、内联技能制品及 KnowledgeBatch.v1 输出职责。")

<a id="runtime-boundaries"></a>
## 运行隔离与容量

写作角色配置为完全禁用工具，每次建立新会话，且不继承用户技能或 MCP；这使其依赖宿主显式提供的材料与角色资源。上下文和输出上限分别为 96,000 与 24,000 token，结构修复最多尝试两次。[知识写作角色隔离与预算 ↗](../../../packages/agent-runtime/roles/knowledge-writer/1/manifest.json#L18 "支持无工具、会话不复用、不继承用户扩展以及上下文、输出和修复预算的说明。") 这些内容证明当前清单如何声明角色，不证明写作质量、引用语义核验或宿主执行状态；独立复核仍需由另一角色完成。
