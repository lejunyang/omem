# Lark 运行宿主真实环境冒烟验证

该脚本使用现有数据目录、加密凭据和官方 Lark 能力探测器启动真实运行宿主，验证已激活连接能否进入 connected 状态；同时通过待发送消息保护、能力缺失检查、超时和 finally 清理控制真实外部副作用。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-guards"></a>
## 验证目标与启动保护

这是面向真实配置的宿主冒烟脚本，不是隔离单元测试：它从指定数据目录打开数据库，并要求通过环境变量或密钥文件提供加密密钥。启动前会统计尚未完成的 Lark 投递；只要存在待发送记录且没有显式设置允许投递，脚本就关闭存储并拒绝继续，以避免一次“连通性检查”意外发送业务消息。[启动配置与待投递保护 ↗](../../../scripts/live-lark-host-smoke.ts#L15 "支持脚本要求真实密钥，并在存在未完成 Lark 投递时默认拒绝启动的说明。")

随后脚本只选择最早创建的一条 active 连接，读取其当前版本的密钥引用，并校验解密所得 appId 与数据库记录一致；没有活动连接、密钥不可读或应用标识不匹配都会在启动宿主前失败。[活动连接与凭据一致性检查 ↗](../../../scripts/live-lark-host-smoke.ts#L42 "支持仅选择一条活动连接、读取密钥引用并校验应用标识的流程。") 密钥仓库还要求密钥恰好为 32 字节，并限制密钥引用格式，因此脚本依赖已有凭据文件满足这些约束。[加密密钥仓库约束 ↗](../../../apps/server/src/integrations/lark/secret-store.ts#L24 "说明脚本所依赖的密钥长度、环境变量和密钥引用格式边界。")

<a id="execution-flow"></a>
## 核心执行流程与模块关系

脚本先使用官方能力探测器检查现有凭据与默认配置；探测异常直接传播，任何缺失能力也会阻止宿主启动。[官方能力预检 ↗](../../../scripts/live-lark-host-smoke.ts#L62 "支持能力探测在宿主启动前执行，且缺失能力会直接终止验证的论断。") 接着它把同一数据库、加密密钥仓库、官方注册适配器、能力探测器和 Botmux 既有应用提供器组装进 `LarkOnboardingService`；该服务的构造合同表明这些组件分别承担持久化、凭据、注册、能力检查与既有应用发现。[引导服务依赖合同 ↗](../../../apps/server/src/integrations/lark/onboarding.ts#L24 "说明 LarkOnboardingService 接收数据库、密钥仓库、注册器、能力探测器和既有应用提供器。")

运行宿主还接收面向固定 owner 的记忆服务、500 毫秒轮询周期和独立 worker 名称。脚本记录启动时间后调用 `host.start()`，最多轮询 180 次连接事件表，只读取该时间点之后产生的状态；一旦看到 `connected` 即成功，否则约 90 秒后抛出包含已观察状态的错误。[宿主启动与连接等待循环 ↗](../../../scripts/live-lark-host-smoke.ts#L77 "支持运行宿主的组件配置、事件轮询条件及约 90 秒超时边界。")

<a id="assertions-and-limits"></a>
## 断言、输出与未覆盖边界

成功结果会输出结构化 JSON，包含连接状态、经历的状态序列、实际 scope 与 callback 数量、事件校验方式、机器人身份是否存在、启动前待投递数以及宿主状态，便于人工或外层任务保存真实运行证据。无论成功还是异常，`finally` 都会停止宿主并关闭数据库，降低残留 worker 和文件句柄风险。[成功报告与资源清理 ↗](../../../scripts/live-lark-host-smoke.ts#L111 "支持脚本输出的观测字段，以及无论结果如何都会停止宿主并关闭存储。")

该脚本明确断言的是“能力无缺失且宿主产生 connected 事件”，并未直接创建测试消息、验证入站事件被捕获、确认记忆写入内容，或核对实际出站消息到达。允许投递开关只是放行已有队列，不能把投递成功等同于本脚本的连接成功；此外，它只验证一条 active 连接，多连接选择、公平性及失效连接恢复均不在当前流程内。[连接冒烟测试的断言范围 ↗](../../../scripts/live-lark-host-smoke.ts#L93 "脚本只等待 connected 事件并报告待投递数量，没有创建消息或断言消息处理结果，支持未覆盖行为分析。")
