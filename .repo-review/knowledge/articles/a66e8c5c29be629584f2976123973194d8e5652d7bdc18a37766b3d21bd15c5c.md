# 知识、证据链与变更场景的虚构数据模型

集中定义离线原型使用的证据节点、文章入口、变更历史和材料来源，并用状态、版本及引用关系覆盖正常、历史、缺失和百层路径场景。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="evidence-model"></a>
## 证据节点与关系

`nodes` 是以稳定示例键索引的证据图。每个节点包含标题、章节、类型、版本、状态、固定引文、解释正文和下一层引用，引用边另有标签与关系类型。[证据节点结构 ↗](../../../docs/prototype/data.js#L2 "展示节点元数据、固定正文和带标签引用边的基本数据形态。") 主链从发布规范、操作手册和复盘延伸到验证轨迹、代码修订、测试、指标及原始健康记录。[验证轨迹到原始观测 ↗](../../../docs/prototype/data.js#L47 "支持证据链由任务轨迹继续连接代码、测试、指标和原始记录的描述。") 这表达“结论—方法—经历—执行—观测”的追溯关系，但文件本身只是前端夹具，未展示模式校验或持久化约束。

<a id="versions-and-failures"></a>
## 版本与异常边界

历史规范保留 r6 原文，以 `superseded` 标记并指向现行 r7，使旧回答仍可核对。[历史规范节点 ↗](../../../docs/prototype/data.js#L110 "说明旧版本保留原文、标记已替代并指向现行版本。") 受限、删除和定位不唯一分别采用独立状态；它们没有可用于问答的引文，删除记录还声明不会把旧引用静默改指其他材料。[不可用来源状态 ↗](../../../docs/prototype/data.js#L122 "支持权限不足、来源删除和锚点不唯一采用不同状态与说明文本。") 另有程序生成的一百层合成长链，前 99 层引用下一节点，最后一层终止，仅用于检验深层导航。[百层合成长链 ↗](../../../docs/prototype/data.js#L156 "说明长链节点的生成规则、演示用途及终止条件。")

<a id="articles-changes-sources"></a>
## 文章、变更与来源的装配关系

`articles` 将三篇知识文章映射到首层证据，覆盖发布回滚、经验提炼与版本更新主题；具体阅读和跳转由应用文件消费这些键。[知识文章索引 ↗](../../../docs/prototype/data.js#L178 "支持三篇文章分别关联首层证据节点的说明。") `initialChanges` 只定义两条已生效记录及其变更前后内容、原因和依据，能够作为比较与恢复操作的输入数据，但本文件自身不执行恢复。[初始变更记录 ↗](../../../docs/prototype/data.js#L204 "仅支持这些记录自身提供变更前后内容、依据和生效状态，不把应用侧的比较或恢复行为归因于本文件。") `sources` 声明文档、Git 和 Agent 轨迹三类虚构来源及同步状态。[虚构材料来源 ↗](../../../docs/prototype/data.js#L228 "说明来源列表覆盖文档、代码仓库和 Agent 轨迹及其范围。") 文件首行明确所有故事和数字都不是公司政策，故只能用于交互研究。[虚构夹具声明 ↗](../../../docs/prototype/data.js#L1 "明确限制这些故事与数字的事实效力。")

<a id="test-meaning"></a>
## 测试记录表达的断言与未覆盖行为

数据中的“回滚一致性测试”断言镜像版本与配置版本同时恢复到上一稳定快照，并继续关联发布后的健康指标。[回滚一致性测试断言 ↗](../../../docs/prototype/data.js#L73 "支持领域测试记录具体断言镜像和配置同时恢复，并关联后续观测。") 它同时限定：一次测试成功不能推广为所有环境永久可用，原始记录也只证明特定时间点的观测。[观测范围限制 ↗](../../../docs/prototype/data.js#L81 "说明测试和观测只覆盖特定路径及时间窗口，不能泛化为永久可用。") 这是领域故事中的测试记录，不是对原型代码执行的自动化测试，因此不能证明搜索、证据遍历、本地恢复或离线构建正确。
