# server-root · 模块理解

服务端根模块把运行配置、受限来源接入、不可变证据存储、HTTP 接口、Agent 运行和生命周期组合为单用户个人助手后端；当前闭环已覆盖捕获、检索、问答与派生结果保存，但团队隔离、恢复传播和部分运行边界仍待完善。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role"></a>
## 定位与组合关系

配置层校验 Agent 档案及可选集成，并派生数据目录、工作目录、令牌、主机和端口。[运行配置加载与派生参数 ↗](../../../apps/server/src/config.ts#L17 "支持配置校验、档案去重以及数据目录、工作目录、令牌、主机和端口的派生流程。") `buildApp` 进一步装配 Fastify、Store、记忆、反馈、检索与助手运行时；学习管线则依据独立配置和 profile 按需创建。[核心服务与助手运行时装配 ↗](../../../apps/server/src/app.ts#L44 "支持 Fastify、Store、记忆、反馈、关键词检索和助手运行时的组合关系。")[学习管线的条件装配 ↗](../../../apps/server/src/app.ts#L78 "支持学习配置、profile 查找及 LearningPipeline 按需创建的独立陈述。") 薄进程入口只负责加载配置、监听，并在终止信号到来时关闭应用。[服务进程启动与信号关闭 ↗](../../../apps/server/src/main.ts#L1 "支持入口加载配置、构建监听并响应 SIGINT 与 SIGTERM。")

## 从外部材料到固定证据

文件和 Git 经真实路径、大小、引用及仓库内路径约束后转换为统一捕获输入；飞书入口另行限制 URL 和响应格式，Hook 只选择白名单字段并控制字符预算。[文件与 Git 有界读取 ↗](../../../apps/server/src/connectors.ts#L1 "支持文件真实路径、大小与文本限制，以及 Git ref、仓库路径和指定提交读取边界。")[飞书文档转换 ↗](../../../apps/server/src/connectors.ts#L76 "支持飞书 URL 白名单、外部读取、响应校验及统一捕获内容构造。")[Hook 字段筛选与预算 ↗](../../../apps/server/src/connectors.ts#L137 "支持 Hook 白名单字段、有限脱敏、字符预算和来源身份构造。") Store 以事件回执和内容指纹实现幂等，将变化追加为不可变修订与固定片段。[捕获幂等与不可变修订 ↗](../../../apps/server/src/store.ts#L141 "支持事件回执冲突检查、相同内容复用以及新修订和固定片段的追加。") 新版本还推进有效性代次、使旧记忆依赖失效并排入刷新作业；派生材料不进入声明提取队列，避免自循环成为独立证据。[来源更新传播与学习队列 ↗](../../../apps/server/src/store.ts#L221 "支持画像容错、head 和有效性代次更新、依赖失效、刷新作业及派生材料排除规则。")

<a id="agent_flow"></a>
## 证据问答与可信边界

通用运行先解析 profile 和固定 evidence，校验选区、文本预算与图片总量；图片目前只允许 ACP transport。[固定证据与上下文预算 ↗](../../../apps/server/src/runs.ts#L52 "支持 profile 覆盖、evidence 与选区校验、文本预算、图片总量及 ACP 图片限制。") 执行完成后，回答以派生来源保存并链接输入证据，引用关系本身不等于语义已核验。[Agent 执行与派生回答保存 ↗](../../../apps/server/src/runs.ts#L110 "支持传输分派、输出收集、派生来源保存、证据链接和失败状态收束。") ACP 会协商模型、推理强度、技能和图片能力，并声明无文件或终端能力；权限与补充输入请求统一拒绝。[ACP 能力协商与权限边界 ↗](../../../apps/server/src/agents.ts#L180 "支持只读能力声明、技能发现、模型与推理强度校验、图片能力检查及权限请求拒绝。") API 使用 Bearer token 或回环 Host/Origin 限制访问，Web 会话的 principal、渠道与可见性由服务端固定。[API 访问控制 ↗](../../../apps/server/src/app.ts#L126 "支持 Bearer token 安全比较以及无 token 时的回环 Host 和 Origin 限制。")[Web 会话可信身份 ↗](../../../apps/server/src/app.ts#L525 "支持 Web 调用者不能伪造 Lark 渠道或群可见性，并由服务端固定 owner、web 和 private 属性。")

<a id="progress_limits"></a>
## 现状与限制

现有接口覆盖捕获、来源历史、证据关系、检索、通知、待办、作业、记忆、质量、Lark、Agent run 和 Web 助手；启动时恢复未完成助手回合并启动可选 worker，关闭时停止运行并释放数据库。[接口范围与应用生命周期 ↗](../../../apps/server/src/app.ts#L171 "支持当前领域接口范围、助手回合恢复、可选 worker 启动以及关闭时的资源释放。") 健康响应仍明确标示 SQLite 与个人模式，不能据此推断团队租户隔离。来源恢复虽然复制旧内容为新修订并切换 head，却未展示普通捕获的画像、有效性代次和依赖刷新传播。[来源恢复实现 ↗](../../../apps/server/src/store.ts#L493 "支持恢复复制旧修订、片段和出边并切换 head，也显示该路径未调用普通捕获的完整传播步骤。")
