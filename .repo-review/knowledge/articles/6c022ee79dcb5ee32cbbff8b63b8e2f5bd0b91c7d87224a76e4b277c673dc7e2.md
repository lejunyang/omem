# 个人记忆服务端：统一捕获、可追溯存储与受控助理

服务端组合配置、多来源捕获、单用户 SQLite、检索和 Agent 问答。外部材料经公共合同约束后形成不可变修订与固定片段；来源更新触发依赖失效和重核验，派生回答保留证据关系但不自动成为独立事实。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 服务端解决什么问题

服务进程依次加载配置、构建 Fastify 应用并开始监听；组合根装配 Store、知识路由、检索、助理运行时和可选学习管线。参考 [服务启动与信号处理 ↗](../../../apps/server/src/main.ts#L1 "支持配置加载、应用构建、监听以及进程信号处理的最外层顺序。") [核心服务装配 ↗](../../../apps/server/src/app.ts#L47 "支持 Store、知识路由、检索、助理运行时和可选学习管线在组合根中的装配关系。")

公共捕获合同统一描述文本、图片、HTTP(S) 链接、上下文和来源信息。直接捕获及文件、Git、飞书、Hook HTTP 入口会在调用 Store 前解析该合同；`/api/input-events` 的入站事件也会解析，但聚合器产出的成熟批次随后直接交给 Store，现有材料未显示它再次执行运行时合同解析。参考 [公共捕获合同 ↗](../../../packages/contracts/src/index.ts#L70 "支持文本、图片、链接、上下文和来源信息的统一捕获结构与字段约束。") [捕获接口与聚合入口 ↗](../../../apps/server/src/app.ts#L202 "支持直接及连接器入口执行合同解析，并说明入站事件解析后，成熟聚合批次被直接传给 Store。") 文件和 Git 连接器限制读取路径与参数，飞书限制文档地址，Hook 则收敛字段、预算并生成事件身份。参考 [文件与 Git 有界读取 ↗](../../../apps/server/src/connectors.ts#L10 "支持本地路径、文本大小、Git 参数和固定提交读取的边界。") [飞书与 Hook 输入约束 ↗](../../../apps/server/src/connectors.ts#L76 "支持飞书文档地址限制，以及 Hook 字段选择、字符预算、脱敏和事件身份生成。")

<a id="capture-flow"></a>
## 从外部材料到可追溯记忆

`Store.capture` 先在 SQLite 事务外解码、校验图片类型与大小，并按内容哈希写入资产文件；随后才进入立即事务，处理事件幂等、内容去重、不可变修订、固定片段、来源当前版本及相关数据库记录。参考 [图片资产预处理 ↗](../../../apps/server/src/store.ts#L102 "支持图片在事务开始前完成解码、类型校验、内容寻址和文件写入。") [捕获事务与来源更新 ↗](../../../apps/server/src/store.ts#L143 "支持事务从事件幂等开始，并覆盖内容去重、修订、片段、来源状态、依赖失效和刷新任务入列。")

来源更新会把旧依赖标为过期、使相关记忆失效，并冻结受影响集合后入列重核验；任务派发只表示已排队，只有记忆恢复有效、依赖指向当前修订且真实应用完成，刷新状态才成为已应用。参考 [捕获事务与来源更新 ↗](../../../apps/server/src/store.ts#L143 "支持事务从事件幂等开始，并覆盖内容去重、修订、片段、来源状态、依赖失效和刷新任务入列。") [刷新应用判定 ↗](../../../apps/server/src/learning/refresh.ts#L6 "支持冻结受影响集合，并区分任务入列与重核验真实应用成功。") 派生材料不会再次进入声明抽取队列，避免模型产物循环成为独立证据。参考 [派生材料防自循环 ↗](../../../apps/server/src/store.ts#L357 "支持派生材料跳过声明抽取队列，避免模型产物被循环当作独立证据。") 当前持久化明确是单用户 SQLite，尚不具备团队租户强制隔离。参考 [单用户存储边界 ↗](../../../apps/server/src/store.ts#L4 "支持当前 SQLite 实现是单用户基础，团队级强制隔离仍属后续迁移。")

<a id="assistant-flow"></a>
## 检索与受控 Agent 问答

未启用语义检索时使用关键词实现；启用后才启动中文 embedding 与语义检索生命周期。参考 [检索模式选择 ↗](../../../apps/server/src/retrieval/factory.ts#L14 "支持关键词检索默认路径，以及启用后才启动语义检索与中文 embedding。") 固定证据问答会检查选区、文本和图片预算，再按 profile 分派 ACP 或兼容 CLI；成功回答作为派生材料保存并关联输入证据，但引用边不等于语义支持已经验证。参考 [固定证据问答编排 ↗](../../../apps/server/src/runs.ts#L52 "支持证据与预算校验、图片处理、Agent 分派、派生回答保存及证据关联边界。")

ACP 会校验会话公布的模型和推理强度选项；仅在传入 `expectedSkills` 时等待技能发现，仅在提供 `contextBudget` 时检查上下文窗口，并仅在实际 prompt 含图片时检查图片能力。参考 [ACP 条件化能力检查 ↗](../../../apps/server/src/agents.ts#L283 "支持技能发现、上下文预算和图片能力检查各自受调用参数或输入内容触发。") Agent 请求权限或补充输入时，系统先等待可选运行时回调；回调成功后才提示并取消或拒绝，回调异常则交由外层错误流程处理，不会静默授权。参考 [权限与补充输入处理 ↗](../../../apps/server/src/agents.ts#L183 "支持运行时回调先执行，随后才提示并取消或拒绝，且回调异常会阻断后续显式响应。")

<a id="boundaries"></a>
## 安全边界、配置与生命周期

非回环监听必须配置令牌。API 配置令牌时校验 Bearer token；未配置时只接受本地主机，并在请求带有 `Origin` 时要求来源也是本地地址。参考 [API 访问控制 ↗](../../../apps/server/src/app.ts#L138 "支持 Bearer token、本地主机检查，以及仅在存在 Origin 时执行本地来源检查。") Web 调用方不能声明飞书频道、群组可见性或任意主体，服务器固定创建私有 Web 会话。参考 [Web 会话信任边界 ↗](../../../apps/server/src/app.ts#L555 "支持 Web 调用方不能伪造飞书频道、群组可见性或主体，且服务器固定私有会话属性。")

应用会先恢复未完成助理轮次，再启动提醒、输入聚合及可选后台组件；关闭时清理定时器并依次停止助理、学习、飞书、运行管理和检索，最后关闭 Store。参考 [恢复、后台循环与关闭顺序 ↗](../../../apps/server/src/app.ts#L623 "支持未完成轮次恢复、后台任务启动及关闭阶段的资源回收次序。") 配置 schema 约束 profile、通知、检索、学习和飞书，但 `OMEM_PORT` 目前仅经过 `Number` 转换。参考 [配置与运行参数组装 ↗](../../../apps/server/src/config.ts#L18 "支持配置解析和默认值，并说明端口环境变量目前只经过 Number 转换。") 进程收到 SIGINT 或 SIGTERM 后等待 `app.close()` 成功再退出，未展示关闭拒绝、超时或重复信号的兜底。参考 [关闭信号边界 ↗](../../../apps/server/src/main.ts#L7 "支持 SIGINT、SIGTERM 仅在 app.close 成功后退出，且当前代码未展示失败或超时兜底。")
