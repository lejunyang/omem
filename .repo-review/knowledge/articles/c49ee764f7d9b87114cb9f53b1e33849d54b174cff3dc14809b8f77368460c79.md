# 验证体系、质量评测与证据强度

项目以分层证据区分基础实现、用户流程、外部集成和模型质量：自动化检查验证依赖、类型、测试与构建，浏览器脚本验证真实应用边界，实机快照观察外部能力，冻结人工样本衡量输出质量。受控流程已有较完整证据，但真实外部运行、复杂中文语义、并发一致性和飞书投递回填仍需补强。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="validation_layers"></a>
## 不同验证层分别回答什么问题

“代码可构建”“用户流程可操作”“外部服务可调用”和“模型输出质量足够”是不同问题。历史记录显示依赖冻结、类型检查、全量测试与构建曾成功完成；在此基础上，确定性浏览器验收覆盖应用交互，在线冒烟观察真实模型和外部集成，冻结人工数据集则承担质量门禁。参考 [自动化检查记录 ↗](bdb7f03a6b11e14c8d0fc0422224be587295dc20ec8b9b9d0454406960ec3f42.md#automated-checks "支持依赖冻结、类型检查、全量测试和构建位于基础验证层，并记录其历史退出结果。")

```mermaid
flowchart LR
  A[自动化测试与构建] --> B[真实应用边界的浏览器验收]
  B --> C[真实模型与外部集成冒烟]
  C --> D[冻结人工样本质量门禁]
```

这些层次互补但不能相互替代。参考 [分层验证工作流 ↗](97762e76cba3d5e9bc19883e9db79e5f8ed0afd3e77c4114d9fc9ae68437691e.md#layered_validation "说明确定性浏览器验收、真实模型与外部集成冒烟、冻结数据集质量门禁之间的分层关系。") [质量门禁职责 ↗](97762e76cba3d5e9bc19883e9db79e5f8ed0afd3e77c4114d9fc9ae68437691e.md#quality_gate "说明冻结数据集评测与在线冒烟解决不同风险，不能互相替代。")

浏览器脚本运行真实 Vue、API 与 SQLite，验收记录也确认后端使用真实 Fastify 和 SQLite；智能体响应则来自确定性 ACP 协议夹具。因此它能证明受控输出下的界面与应用编排，不能单独证明真实模型、网络或供应商服务可用。参考 [浏览器验收运行边界 ↗](../../../scripts/browser-smoke.ts#L1 "支持脚本运行真实 Vue、API 与 SQLite，并以夹具稳定 Agent 输出。") [浏览器验收证据边界 ↗](../../../docs/implementation/browser-verification.json#L21 "支持后端为真实 Fastify 与 SQLite、智能体为确定性 ACP 协议夹具。")

<a id="quality_loop"></a>
## 从研究样本到可复算质量指标

质量样本生成与普通捕获明确隔离，只能通过研究标注入口显式启用。导入器仅聚合文本部件，跳过图片标记、表格等复杂布局，再按长度、规则词、否定和数字筛选排序候选；这条路径不得进入普通捕获或学习流程。参考 [研究导入隔离边界 ↗](../../../apps/server/src/quality/import.ts#L1 "支持质量样本构建只用于显式研究标注，不得进入普通捕获、导入或学习链路。") [候选样本生成流程 ↗](../../../apps/server/src/quality/import.ts#L46 "支持文本聚合、复杂布局跳过、长度筛选、规则评分、排序截取及候选不足失败。")

样本必须全部确认后才能冻结。清单摘要由样本序号、输入摘要和确认标签摘要组成，完整性检查会按相同结构复算；行为测试覆盖重复导入去重、未确认时拒绝冻结、摘要复算，以及冻结后标签被篡改时校验失败。参考 [冻结清单与完整性复算 ↗](../../../apps/server/src/quality/repository.ts#L358 "支持冻结前置条件、清单摘要组成，以及完整性检查按相同结构复算。") [质量数据集生命周期测试 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L50 "支持重复导入去重、未确认时拒绝冻结、人工确认、摘要复算和冻结后篡改检测。")

评估器把引文定位、语义支持、数字槽、必要证据覆盖、任务完成和不必要打断分开计算。引文可在原文中定位并不代表结论受支持：反向结论会被判为矛盾；没有预测对象时支持率为 `null`，但遗漏必要证据仍记为覆盖失败。参考 [可定位引文的矛盾反例 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L201 "证明引文能够定位不等于语义支持，反向结论会被判为矛盾并导致任务未完成。") [空预测分母语义 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L234 "支持零预测对象时支持率为空，而必要证据遗漏仍按覆盖失败计算。")

## 知识发布与产品流程的交叉验证

知识草稿只有经过独立会话复核才会发布；复核拒绝或分析期间输入变化都会阻止晋升，被拒草稿可携带反馈继续修订。参考 [独立复核后发布 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L39 "支持生成与复核使用不同会话，接受后才发布，并可复用持久结果。") [拒绝与输入变化保护 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L53 "支持复核拒绝和分析期间来源变化时不发布，并从旧草稿与反馈继续修订。") 更高层文章保留对已复核下层文章的依赖，底层来源变化会使上层结果失效。参考 [上层知识失效传播 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L123 "支持概览依赖已复核下层文章，并在底层来源变化后转为非当前状态。")

产品侧浏览器验收覆盖提案应用、学习结果、固定原证据和通知详情；还检查循环证据与不可变旧版本、人工判断及过期保护、移动布局与百层证据栈，以及故障展示和重启恢复。参考 [提案应用与证据回看 ↗](../../../scripts/browser-smoke.ts#L228 "支持提案应用后查看学习结果、固定原证据和通知详情的浏览器主路径。") [循环证据与版本历史 ↗](../../../scripts/browser-smoke.ts#L283 "支持循环引用导航、基于原文追问，以及新旧修订并存和旧版本可读。") [人工判断与过期保护 ↗](../../../scripts/browser-smoke.ts#L399 "支持补充背景、拒绝、确认应用和来源变化后禁止提交旧判断。") [移动布局与深层证据 ↗](../../../scripts/browser-smoke.ts#L567 "支持平板、手机布局、对话框焦点和一百层证据导航的容量检查。") [故障展示与重启恢复 ↗](../../../scripts/browser-smoke.ts#L653 "支持模型失败、通知失败、API 离线及服务重启后持久数据仍可读取。") 阅读器同时验证 Markdown 表格和 Mermaid 图表呈现，并排除脚本与 `foreignObject`。参考 [富文本安全渲染 ↗](../../../scripts/browser-smoke.ts#L727 "支持 Markdown 表格与 Mermaid SVG 呈现，同时排除脚本和 foreignObject。")

这些证据表明受控环境中的关键用户路径可以追溯，但知识管线测试替换了角色运行器，浏览器测试也使用协议夹具，不能据此推断真实模型或外部渠道已经通过同等范围的验收。

<a id="progress_and_limits"></a>
## 当前证据与仍需补强的边界

历史验证记录包含浏览器流程和小型模型校准，并明确不代表所有外部集成都已实测，也不证明普遍语义正确。参考 [浏览器与模型校准记录 ↗](bdb7f03a6b11e14c8d0fc0422224be587295dc20ec8b9b9d0454406960ec3f42.md#browser-and-live "说明浏览器流程和小型模型校准的历史结果，并限定其不代表全部外部集成或普遍语义正确。") 现有实机证据仍较窄：ACP 快照只记录 Agent、模型、effort、回答和事件类型；飞书快照只记录连接器、文档版本、部件类型及文本规模，均缺少完整输入指纹、退出码和关键行为断言。参考 [ACP 实机快照 ↗](../../../docs/implementation/live-acp-verification.json#L1 "支持现有 ACP 记录仅包含 Agent、模型、effort、回答及事件类型。") [飞书导入实机快照 ↗](../../../docs/implementation/live-lark-verification.json#L1 "支持现有飞书记录只包含连接器、文档版本、部件类型和文本规模。")

确定性评估基线包含两个独立维度：`semanticSupport` 以否定翻转、反义关系、时间错配、限定词丢失和二元词组重叠判断语义支持；`coreFactSlots` 则单独检查陈述中的数字或数量边界是否能在引文中找到。二者分别计算和汇总，数字变化不会被表述为语义支持规则自身的能力。参考 [确定性语义支持规则 ↗](../../../apps/server/src/quality/evaluator.ts#L33 "支持语义支持裁决仅使用否定翻转、反义关系、时间错配、限定词丢失和二元词组重叠，不包含数字槽判断。") [独立数字槽检查 ↗](../../../apps/server/src/quality/evaluator.ts#L185 "支持数字或数量边界一致性由 judgeFactSlots 独立检查，而不是由语义支持函数处理。") [语义与数字指标分开汇总 ↗](../../../apps/server/src/quality/evaluator.ts#L409 "支持 semanticSupport 与 coreFactSlots 作为两个独立指标分别统计和报告。") 短句测试覆盖同义改写、范围扩大、时间错配和否定翻转；数值变化用例只断言独立的数字槽检查。参考 [中文语义与数字槽测试 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L262 "支持同义改写、限制丢失、时间错配和否定翻转由语义支持指标断言，而数值变化由独立的数字槽函数断言。")

一致性边界仍待验证：样本加入在事务开始前读取状态和最大序号；修订最终更新未再次约束允许状态；冻结更新只匹配 `labeling` 状态，却未检查实际命中行数。参考 [样本批量写入事务边界 ↗](../../../apps/server/src/quality/repository.ts#L155 "支持数据集状态和最大序号在立即事务开始前读取，为并发加入样本的待验证边界提供依据。") [标签修订更新条件 ↗](../../../apps/server/src/quality/repository.ts#L328 "支持修订先检查允许状态，但最终更新只约束样本标识和旧标签摘要。") [冻结状态更新条件 ↗](../../../apps/server/src/quality/repository.ts#L358 "支持冻结更新只匹配 labeling 状态，且没有检查更新命中行数。")

飞书续发会把会话消息标识清空，新建会话也以空消息标识入库；回调则要求会话中的消息标识与事件完全一致。发送成功后的标识回填、重试与未知结果恢复协议在当前材料中尚未出现。参考 [续发时清空消息标识 ↗](../../../apps/server/src/quality/lark-annotations.ts#L203 "支持已有标注会话续发时明确把 message_id 更新为 NULL。") [新建会话的空消息标识 ↗](../../../apps/server/src/quality/lark-annotations.ts#L292 "支持新建标注会话时 message_id 字段以 NULL 写入。") [质量卡片回调约束 ↗](../../../apps/server/src/quality/lark-annotations.ts#L369 "支持回调联合校验会话、样本、身份、聊天、应用和时效，并要求会话消息标识与事件消息标识一致。")
