# 学习管线：提取、复核与策略应用

以持久化作业串联固定 revision 上下文、角色提取、独立复核和整批记忆决策，并明确陈旧输入、输出完整性、错误暴露、运行控制及依赖重核对尚未实现等边界。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-flow"></a>
## 职责与核心流程

`LearningPipeline` 是学习作业的编排层，只领取提取、复核和依赖刷新三类任务。构造时会核对 extractor、verifier 的角色配置；作业尝试指纹记录模型与 effort，并分别用管线标识、profileId、model、effort 和固定阶段名计算 prompt、skill、tool 哈希。这里的阶段哈希不等同于对实际提示词、技能内容或工具摘要进行散列，此表述取代旧稿中范围过大的结论。[学习管线构造与尝试指纹 ↗](../../../apps/server/src/learning/pipeline.ts#L86 "支持管线限定处理种类、校验角色 profile，并证明当前阶段哈希只由管线标识、profile、模型、effort 和固定阶段名计算。")

提取阶段从固定 revision 构造上下文，调用 extractor，校验并保存 `ProposalBatch` 与观察记录；仅当存在 proposal 时，才创建以提取任务为父任务的 verifier 作业。[提取作业与复核作业衔接 ↗](../../../apps/server/src/learning/pipeline.ts#L410 "支持提取结果保存、观察记录以及仅在存在 proposal 时创建 verifier 子作业的流程。") 复核阶段检查父子关系、输出 schema、输出摘要和角色包哈希，规范化 proposal 后要求 assessment 数量一一覆盖且摘要匹配；随后把整个变更集一次性交给批量策略评估，避免拆分操作绕过自动应用预算。[复核完整性与整批策略评估 ↗](../../../apps/server/src/learning/pipeline.ts#L443 "支持复核输入完整性、assessment 覆盖与摘要校验，以及整批进入记忆策略评估的论断。")

<a id="context-boundaries"></a>
## 上下文与可信边界

输入 revision 必须仍是 source head，并与可选的 sourceId、validity epoch 一致，否则以 `STALE_JOB_INPUT` 拒绝。应用、会话和运行标识只描述捕获发生的位置，不能替代已确认的项目关联；当前项目保持未知且不可信，相关记忆按 workspace 范围召回。[Revision 新鲜度与项目可信边界 ↗](../../../apps/server/src/learning/pipeline.ts#L172 "解释 source head、sourceId、validity epoch 校验，以及捕获上下文不能被提升为可信项目。")

固定 fragment 会依照捕获拆分顺序映射回原始 part，使 actor、回复关系、观察时间、引用、转发和生产者类型等逐 part 来源进入模型上下文。文本按段落拆分，链接和图片各对应一个 fragment；图片还必须能从资产存储读取，缺失时直接失败。[固定材料与原始 part 映射 ↗](../../../apps/server/src/learning/pipeline.ts#L212 "支持逐 part 来源字段、捕获拆分顺序、图片资产读取及缺失失败的说明。")

<a id="failure-runtime"></a>
## 失败语义与运行控制

对外错误会先遮蔽常见密钥和认证字段、移除换行并限制长度，再按坏输出、认证、暂时性、配置或永久错误分类，供持久化作业系统采用相应失败语义。[错误清理与失败分类 ↗](../../../apps/server/src/learning/pipeline.ts#L30 "支持错误信息脱敏、单行化、截断和失败种类分类的论断。") `refresh_dependents` 目前只记录受影响记忆及 `needs_review` 范围，随后明确抛出未实现的配置类错误；因此受影响数量不能被解释为已经完成重核对，这取代了任何“刷新任务已完成复核”的旧结论。[依赖刷新尚未实现 ↗](../../../apps/server/src/learning/pipeline.ts#L126 "支持刷新只记录影响范围并以未实现错误结束、不得冒充完成重核对的限制。")

单次处理会累计已处理数量；`drain` 达到上限仍未排空时主动失败。后台循环在空闲或异常后轮询，保存脱敏后的最近错误，并可通过取消入口处理具体作业，或由 `stop` 中止 worker 和循环。[排空、轮询、取消与停止 ↗](../../../apps/server/src/learning/pipeline.ts#L553 "支持 drain 上限、后台轮询、最近错误记录、具体作业取消入口与停止行为的说明。")
