# Store：单用户记忆存储与捕获事务中枢

Store 以 SQLite 和本地资产目录承载单用户数据，将材料捕获、不可变修订、固定片段、变更通知及后续学习任务纳入事务；同时提供证据关系、历史恢复、检索、通知和待办等基础操作。它是多个专用仓储与服务的组装入口，但当前并不提供团队租户隔离。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="foundation"></a>
## 职责与事务基础

`Store` 是服务端持久化门面：初始化数据目录和 SQLite，执行迁移、收紧数据库及资产权限，并组装应用、任务、输入聚合、运行时请求和来源画像等专用组件。注释明确它只是单用户基础，Postgres 与团队权限仍属后续迁移。初始化任一步失败都会关闭数据库；`tx` 使用 `BEGIN IMMEDIATE`，成功提交、异常回滚，从而为捕获及状态变更提供原子边界。[Store 初始化与事务边界 ↗](../../../apps/server/src/store.ts#L1 "支持 Store 的单用户定位、依赖组装、权限设置、失败清理及提交回滚语义。")

<a id="capture"></a>
## 捕获、幂等与派生处理

捕获先计算载荷摘要；图片经大小、Base64 往返和 PNG/JPEG/WebP 文件头校验后，以内容哈希写入私有资产目录。来源由 `source + externalId` 定位：同一采集器事件若摘要不同则报冲突，相同事件或相同 head 指纹视为重复，但仍会尝试补入学习任务。新内容创建递增且不可变的修订，把文本段落、链接和图片说明转成最多 2000 个固定片段，并以 best-effort 方式生成来源画像。[捕获校验与不可变修订 ↗](../../../apps/server/src/store.ts#L100 "支持图片验证、事件幂等、来源识别、修订创建、片段预算及来源画像 best-effort 行为。")

新修订随后更新 source head 与有效性 epoch；若替换旧 head，则把旧依赖标为 stale、相关记忆置为 invalidated，冻结刷新影响集并入列 `refresh_dependents`。原始材料会入列 `extract_claims`，而 `producerKind=derived` 被排除以避免派生内容自循环成为独立证据。上述数据库动作、变更记录、通知、回执和任务入列都处在同一捕获事务内；但入列本身不代表刷新最终应用成功。[来源更新与学习任务入列 ↗](../../../apps/server/src/store.ts#L229 "支持 head 更新、依赖失效、刷新记录、刷新任务及派生材料防自循环的核心流程。")

<a id="evidence-history"></a>
## 证据导航、检索与历史恢复

读取接口可列出当前 head、完整版本历史和按序片段；`evidence` 同时返回目标片段、所属修订、出边与反向引用。`link` 只创建 `references` 边，并明确用户引用不自动等同事实支持。搜索仅在当前 head 的片段正文和标题上执行转义后的 SQLite `LIKE`，最多返回 50 条，因此不是语义检索。[证据关系与当前版本搜索 ↗](../../../apps/server/src/store.ts#L377 "支持证据出入边、人工引用的语义边界以及只检索当前 head 的 LIKE 查询限制。")

恢复不会覆盖或删除历史，而是把旧修订内容复制为高一版本的新 head，并为片段分配新 ID；旧片段的出边会复制，若目标也在被恢复片段集合中则重映射，否则继续指向原目标。恢复要求调用方给出的预期 head 同时等于被撤销变更的 after 修订，否则以 `REBASE_REQUIRED` 阻止并发覆盖。该路径未显示执行来源 epoch 更新、旧记忆失效或学习任务入列，是否由上层另行补偿无法从本材料确认。[以新修订恢复历史 ↗](../../../apps/server/src/store.ts#L495 "支持恢复的并发前置条件、复制修订与片段、边重映射以及保留历史的实现说明。")

<a id="notifications-tasks"></a>
## 变更通知与待办边界

`record` 会同时写变更和站内通知；通知详情还聚合外部投递意图、应用回执及提案证据片段。待办创建可绑定已存在证据，并同步写首个 `task_revisions`；状态切换使用 expectedVersion 乐观并发控制，成功后追加新修订和通知。到期提醒仅扫描开放且已到期的任务，借助 `due:任务:版本` 去重键避免同一版本重复提醒。[通知聚合与待办版本控制 ↗](../../../apps/server/src/store.ts#L566 "支持通知详情的关联信息、待办证据校验、修订追加、乐观锁和到期提醒去重。")
