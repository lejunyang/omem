# 中文本地向量模型加载器

从 osdk 锁定快照加载 BGE-small-zh-v1.5，逐文件校验后以离线 CPU 量化模式提供查询与材料向量，并把全部关键资产摘要纳入向量身份。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="contract"></a>
## 模型抽象与快照身份

模块用 `EmbeddingModel` 统一模型身份、批量向量化和资源关闭，并显式区分 query 与 passage，给上层语义检索留下用途特化入口。[向量模型接口 ↗](../../../apps/server/src/retrieval/embedding.ts#L7 "支持模型身份、用途区分、批量嵌入和关闭生命周期的说明。") 当前实现只接受固定仓库与固定 revision 的 BGE-small-zh-v1.5；模型路径由 `osdk model show` 返回，应用自身不负责下载。[osdk 快照解析与版本门禁 ↗](../../../apps/server/src/retrieval/embedding.ts#L14 "说明应用通过 osdk 查找快照且只接受锁定的仓库和 revision。")

<a id="verification"></a>
## 加载与完整性校验

加载器枚举配置、分词器、词表和量化 ONNX 文件，把 osdk 清单中的 SHA-256 与本地文件逐项比较；缺少记录或内容不一致都会中止。[关键模型文件校验 ↗](../../../apps/server/src/retrieval/embedding.ts#L22 "支持逐文件比较清单摘要、本地内容不符即失败的完整性策略。") 校验后才动态载入 Transformers，并关闭远程模型和文件系统缓存，以 `local_files_only`、CPU、q8 和双线程建立特征提取管线，因此运行期不会隐式联网补模型。[离线 CPU 量化加载 ↗](../../../apps/server/src/retrieval/embedding.ts#L29 "说明禁止远程模型和缓存、仅从本地快照创建 q8 CPU 管线。")

<a id="embedding"></a>
## 向量生成与边界

查询文本会加中文检索指令，材料文本保持原样；两者都使用 CLS pooling 和归一化。模型身份由固定算法/窗口标签及所有关键文件哈希共同组成，可阻止不同权重或分词资产产生的向量被当成同一索引。[向量身份与查询特化 ↗](../../../apps/server/src/retrieval/embedding.ts#L35 "支持文件哈希参与模型身份、查询加指令、CLS 归一化及资源释放的描述。") `close` 会释放 extractor。该文件没有展示截断到“window400”的具体参数，名称表达的窗口策略是否由模型配置或其他层落实仍不能确定。
