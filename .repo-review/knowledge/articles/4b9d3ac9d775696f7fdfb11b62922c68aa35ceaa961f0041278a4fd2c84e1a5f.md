# 原始材料读取与证据导航

KnowledgeSource 按材料键读取原文，并可用可选 digest 请求指定版本；组件处理请求竞态、代码与 Markdown 展示，以及关联知识和内部路径导航。未提供 digest 时，版本选择取决于后端。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="loading"></a>
## 版本请求与竞态保护

组件接收材料键、可选 digest 和引用行范围。材料键或 digest 变化时会清空旧内容并重新请求；提供 digest 时，它被编码到查询参数中，用于请求指定材料版本，未提供时则只发送材料键，因此此处不能单独证明响应固定到不可变版本，实际版本选择取决于后端。递增的 `generation` 只允许最新请求更新材料、错误和标题，避免较慢的旧响应覆盖当前阅读对象。[材料请求与竞态保护 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L5 "支持 digest 仅为可选查询参数、未提供时只按材料键请求，以及 generation 防止旧响应覆盖新状态的论断。")

界面区分加载、失败和成功状态。成功后以 `current` 标记“当前版本”或“历史版本”，并可显示引用行范围；代码类材料进入代码查看器，Markdown 材料显示所引原文块与完整正文，附件图片继续呈现。加载提示虽称“固定原文”，但版本标签也说明当前结果可能是当前或历史版本。[原始材料阅读界面 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L26 "支持加载与错误状态、当前或历史版本标记、引用行提示、代码与 Markdown 分流以及图片展示的说明。")

## 关联知识与内部链接解析

代码查看器触发引用时，组件先查询同键文章的元数据并创建知识帧；如果文章查询失败，则降级为原始材料帧，让读者仍能回到证据，而不是静默中断。[关联知识的降级导航 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L15 "支持先打开关联知识文章、查询失败时退回原始材料帧的导航流程。")

Markdown 内部链接仅在材料具有路径时处理：以当前文件目录为基准，逐段规整 `..`、`.` 和普通路径，移除片段部分后补成 `omem:` 键，再复用关联引用流程。由于片段标识被去除，当前实现定位到关联文件，但不会保留目标文档内的锚点位置。[Markdown 内部路径解析 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L19 "支持内部链接以当前材料目录为基准规整路径、移除片段并转换为材料键的说明。")
