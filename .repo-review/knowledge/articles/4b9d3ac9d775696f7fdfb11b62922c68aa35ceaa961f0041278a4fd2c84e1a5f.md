# 固定原始材料阅读与知识跳转

该组件用于在知识阅读界面展示当前或历史版本的固定原文，并根据材料类型提供代码摘录、Markdown 连贯阅读、图片展示及关联知识跳转。它处理异步切换竞态和引用行范围，但不负责材料解析、权限校验或服务端版本选择。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 从知识结论回到固定证据

组件接收材料键、可选摘要标识和引用行范围，用于把知识文章中的论断重新落到固定原文。加载完成后，它展示材料标题及“当前版本/历史版本”状态；若已有知识解读，还可回到对应知识文章，从而连接派生知识与原始证据。参考 [原文阅读状态与知识入口 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L37 "支持组件展示材料版本状态，并在存在知识解读时提供跳转入口的说明。")

材料数据通过统一请求函数获取；该函数从会话存储读取令牌、附加认证头，并把非成功响应转成可读错误。因此本组件只组织阅读交互，实际鉴权与材料版本解析仍由服务端接口决定。参考 [知识接口请求封装 ↗](../../../apps/web/src/knowledge/api.ts#L6 "说明材料请求所依赖的认证头注入、错误转换和 JSON 响应流程。")

<a id="loading-flow"></a>
## 加载、竞态控制与跳转流程

当材料键或摘要标识变化时，组件先清空旧内容，再请求新材料。递增的 `generation` 相当于请求代次：只有最后一次请求可以写入页面或显示错误，避免快速切换材料时较慢的旧响应覆盖新结果。加载成功后还会向父组件报告标题。参考 [材料异步加载与竞态保护 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L16 "支持按材料键或摘要重新加载，并仅接受最新请求结果的核心流程。")

关联跳转会先尝试取得文章元信息并构造知识阅读帧；若文章不可用，则退回原始材料帧。Markdown 内部链接则以当前材料路径为基准处理 `.`、`..`，忽略锚点后转换为 `omem:` 材料键，再复用同一跳转流程。参考 [关联知识与内部路径跳转 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L22 "支持文章优先、原始材料回退，以及相对 Markdown 路径解析的交互说明。")

<a id="rendering-boundaries"></a>
## 按材料类型阅读及其边界

代码或非 Markdown 文件默认只显示引用附近的摘录，可每次向上、向下扩展 20 行，并把引用起始行交给代码查看器定位；Markdown 则保持全文连续渲染，同时在有完整起止行时额外显示引用块。附带图片会在正文后依次展示。参考 [代码、Markdown 与图片呈现 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L41 "支持不同材料类型的渲染分支、代码行展开和图片展示行为。")

引用范围会被限制在材料总行数内，默认从首行展示到第 80 行；不过源码未显式纠正“结束行早于起始行”的输入。内部路径解析也只是字符串级归一化，没有展示对绝对路径、URL、查询参数或越过根目录的专门处理，这些输入的最终语义需由上游约束。参考 [引用范围计算 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L9 "支持默认展示范围及上下界限制，同时暴露结束行未保证不早于起始行的边界。")
