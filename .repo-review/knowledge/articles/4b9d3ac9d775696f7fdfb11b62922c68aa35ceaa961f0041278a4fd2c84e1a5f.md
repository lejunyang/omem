# 原始材料读取与证据导航

按材料键及可选 digest 请求材料，展示当前或历史版本、引用位置与附件，并把关联知识和内部链接接回统一导航。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="loading"></a>
## 可选版本定位与竞态保护

组件接收材料键、可选 digest 和引用行范围；请求由材料键或 digest 变化触发。提供 digest 时会将其作为查询参数请求指定内容，未提供时仅按材料键请求，版本固定性取决于后端解析，前端材料本身不能证明其不可变。`generation` 只允许最新请求更新材料、错误和标题。[材料请求与代次保护 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L5 "支持 digest 为可选查询参数、监听触发条件，以及最新请求独占状态更新。")

<a id="rendering"></a>
## 材料状态与内容呈现

界面区分加载、不可用和成功状态，并按返回的 current 标记显示“当前版本”或“历史版本”。若有行号则显示引用位置；代码或非 Markdown 文件进入代码查看器，Markdown 可同时呈现引用原文块与全文，图片附件随后展示。存在知识解读时还可创建知识帧继续阅读。[原始材料阅读界面 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L26 "支持版本标记、引用行、代码与 Markdown 分派、知识入口及图片呈现。")

<a id="navigation"></a>
## 关联知识与内部链接

代码引用会先查询同键文章，成功时以文章标题创建知识帧，失败则降级为原始材料帧。Markdown 内部链接以当前材料目录为基准规整 `..`、`.` 和普通路径，去掉片段后补成 `omem:` 键，再复用同一引用流程；因此当前实现定位关联文件，但不保留目标锚点。[关联文章的降级导航 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L15 "支持先查询文章元数据，失败时仍打开原始材料帧。")[Markdown 内部路径解析 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L19 "支持以当前文件目录规整内部路径、去除片段并转换为材料键。")
