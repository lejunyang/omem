# 原始材料阅读与证据跳转

该组件读取指定材料，并可通过 digest 固定到特定修订；它根据材料类型呈现代码或 Markdown，恢复引用位置及上下文，同时支持知识解读、关联材料跳转、版本提示和异步请求竞态保护。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 从知识解读回到可核对的原文

这个页面解决的是**如何从知识结论返回原始材料并核对上下文**。组件接收材料键、可选的版本摘要和行范围：请求始终按材料键发起，提供 `digest` 时才固定到特定修订；加载成功后向外报告材料标题，并可通过导航事件切换页面。参考 [材料输入与加载请求 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L5 "支持组件接收材料键、可选 digest 和行范围，并仅在提供 digest 时将其加入材料请求。")

界面区分加载失败、读取中和读取完成三种状态。材料可用后会显示标题及“当前版本”或“历史版本”标记；若材料已有知识解读，还会提供返回解读页面的入口。参考 [原文状态与知识入口 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L34 "支持页面的失败、加载和成功状态，以及版本标记和知识解读入口。")

<a id="render-flow"></a>
## 按材料类型恢复引用上下文

材料加载后会被拆分成行，并依据传入范围计算代码摘录。没有指定起始行时默认从首行展示至多 80 行；指定范围时则定位到相应起止位置。参考 [代码摘录范围 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L11 "支持材料拆行、摘录生成、默认展示范围和起止行裁剪规则，也揭示反向范围未被归一化。")

代码材料使用代码查看器呈现，传入显示起始行、引用锚点和材料内引用，并允许读者每次向上或向下扩展 20 行。非代码材料使用 Markdown 连贯渲染；若起止行均存在，还会单独展示对应原文块。材料附带的图片统一排列在正文之后。参考 [材料呈现与上下展开 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L42 "支持代码查看器的锚点、引用链接和每次扩展 20 行的交互，以及 Markdown、原文块和图片的呈现分支。")

<a id="navigation-limits"></a>
## 关联跳转、竞态保护与边界

材料键或 `digest` 改变时会启动新请求。组件为每次加载递增代次，只允许最新请求写入材料或错误状态，因此较慢的旧响应不会覆盖后来选择的材料。参考 [请求竞态保护 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L17 "支持材料变化触发请求、递增加载代次以及仅由最新请求更新成功或错误状态。") 底层请求会附带已有的会话令牌，并将非成功响应转换成可展示的错误。参考 [接口鉴权与错误转换 ↗](../../../apps/web/src/knowledge/api.ts#L6 "支持请求附带会话令牌并把非成功响应转换为错误，也说明上层捕获的异常可能包含鉴权、网络或服务端错误。")

打开代码中的引用时，组件先尝试读取对应知识文章；若失败，则导航到关联原始材料。Markdown 内部链接只按 `documentLinks` 中的精确地址匹配，无法定位时显示“尚未导入或存在多个同名来源”的提示，不会猜测目标。参考 [关联知识与内部链接导航 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L23 "支持引用先尝试打开知识文章、失败后回退原始材料，以及 Markdown 链接采用精确映射并在缺失时提示。")

当前起止行会分别限制在材料长度内，但没有显式保证结束行不小于最终起始行，因此反向范围可能得到空摘录。参考 [代码摘录范围 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L11 "支持材料拆行、摘录生成、默认展示范围和起止行裁剪规则，也揭示反向范围未被归一化。") 此外，关联文章请求的所有异常都会触发原文回退，现有实现未区分文章不存在、鉴权失败或网络故障。参考 [关联知识与内部链接导航 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L23 "支持引用先尝试打开知识文章、失败后回退原始材料，以及 Markdown 链接采用精确映射并在缺失时提示。") [接口鉴权与错误转换 ↗](../../../apps/web/src/knowledge/api.ts#L6 "支持请求附带会话令牌并把非成功响应转换为错误，也说明上层捕获的异常可能包含鉴权、网络或服务端错误。")
