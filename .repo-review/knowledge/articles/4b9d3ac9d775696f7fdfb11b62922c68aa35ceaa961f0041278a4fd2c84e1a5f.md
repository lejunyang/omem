# 固定原始材料阅读与引用跳转

该组件读取知识引用所指向的固定原始材料，区分当前与历史版本，并为代码、Markdown、图片及指定行范围提供相应阅读方式；关联目标会转换为上层可管理的知识或原文导航帧。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 让知识结论回到固定原文

组件用于核查知识文章背后的原始证据。材料键变化时，它会携带可选摘要读取指定版本；成功后保存材料并把可读标题通知上层，失败则记录异常。只有最新请求可以更新这些状态。参考 [材料加载与竞态保护 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L16 "支持按材料键和摘要发起请求、仅接纳最新响应、发送已加载标题以及记录最新请求错误的说明。")

页面把请求状态明确呈现为“正在读取”、可见错误或材料正文；加载完成后显示材料标题、当前或历史版本标识，并在存在知识解读时提供返回文章的入口。参考 [材料阅读状态与版本入口 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L33 "支持加载、错误、材料标题、版本状态和知识解读入口的可见界面说明。")

请求统一经过知识 API：它从会话存储读取令牌、按需设置请求头，将非成功响应转换为异常，再解析 JSON 结果。参考 [知识接口请求封装 ↗](../../../apps/web/src/knowledge/api.ts#L6 "支持会话令牌注入、非成功响应转为异常及 JSON 返回行为。")

<a id="loading-and-window"></a>
## 定位引用行并隔离过期响应

每轮材料请求都有递增标记，因此快速切换材料时，较慢的旧响应不会覆盖当前页面；网络请求本身不会被取消，只在结果落地时判断是否仍属最新一轮。参考 [材料加载与竞态保护 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L16 "支持按材料键和摘要发起请求、仅接纳最新响应、发送已加载标题以及记录最新请求错误的说明。")

代码阅读窗口把材料按行拆分，并依据传入的起止行计算摘录。未指定范围时默认从首行开始、最多展示前 80 行；起点和终点分别受全文长度约束，但代码没有保证终点不小于起点。参考 [引用行窗口计算 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L9 "支持引用起止行的默认值、边界约束和窗口摘录方式，并揭示反向范围未被统一纠正的限制。")

<a id="render-and-navigation"></a>
## 按材料类型阅读并追踪关联

代码或非 Markdown 文件通过代码查看器展示当前窗口，可向上或向下扩展 20 行，并把引用锚点与关联链接交给查看器。Markdown 连贯渲染全文；同时给出起止行时会显示对应摘录，材料图片排列在正文之后。参考 [代码、文档与图片展示 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L41 "支持代码窗口扩展、Markdown 连贯渲染、指定行摘录和图片展示流程。")

打开关联目标时，组件先请求知识文章，成功后进入知识阅读；任意请求异常都会回退为原始材料帧。Markdown 内链以当前材料目录为基准，移除片段并处理 `.`、`..` 后生成材料键。该逻辑没有区分文章不存在、鉴权失败、服务端错误或网络故障，也未专门识别外部 URL 与绝对路径。参考 [关联目标与相对路径解析 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L22 "支持知识文章跳转、异常时回退原文，以及 Markdown 相对路径解析行为和相关限制。")
