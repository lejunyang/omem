# Web 应用启动入口

浏览器端入口导入 Vue、根组件和两份全局样式，随后创建应用并挂载到 `#app`。根组件接续管理导航、当前视图与页面标题。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 启动 Vue 组件树

该文件是 Web 前端的启动入口：它以 `App.vue` 为根组件创建 Vue 应用，并将应用挂载到匹配 `#app` 的页面元素。入口代码保持精简，没有直接处理知识检索、材料阅读或待办等业务，这些能力由挂载后的组件树继续承载。参考 [Vue 应用挂载 ↗](../../../apps/web/src/main.ts#L1 "支持入口创建以 App.vue 为根组件的 Vue 应用并挂载到 #app，也界定了当前材料能够确认的启动行为。")

<a id="dependencies"></a>
## 装配根组件与全局样式

启动前，入口导入根组件以及 `@omem/ui/tokens.css`、本地 `styles.css` 两份样式文件。现有材料只能确认这些样式是启动依赖，不能进一步判断其中包含哪些视觉规则或二者如何分工。参考 [入口样式依赖 ↗](../../../apps/web/src/main.ts#L2 "支持入口导入根组件、共享包中的 tokens.css 和应用本地 styles.css；不对样式内容作超出材料的推断。")

根组件定义了日常助理、知识库、原始材料、学习流程、待办与通知等导航项，并依据当前视图计算页面标题；这说明启动入口把后续页面组织交给了 `App.vue`。参考 [根组件导航状态 ↗](../../../apps/web/src/App.vue#L38 "支持 App.vue 定义主要功能导航、从地址片段或会话状态确定当前视图，并据此计算页面标题。")

<a id="boundaries"></a>
## 运行前提与证据边界

挂载调用直接使用 `#app` 选择器，因此应用运行依赖页面中存在可匹配元素。不过，当前材料没有包含 HTML 模板，无法确认该元素的位置、数量以及缺失时的处理方式。入口中也未展示路由器安装、插件注册或全局错误处理，不能仅凭这几行代码认定这些机制存在。参考 [Vue 应用挂载 ↗](../../../apps/web/src/main.ts#L1 "支持入口创建以 App.vue 为根组件的 Vue 应用并挂载到 #app，也界定了当前材料能够确认的启动行为。")
