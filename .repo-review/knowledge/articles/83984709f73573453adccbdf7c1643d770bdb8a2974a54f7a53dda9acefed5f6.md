# 知识仓库的引用、失效与恢复测试

该测试以临时 Store 验证固定材料引用、不可变知识修订、依赖失效、资产恢复、问题动作、原始证据召回和通知去重等知识仓库核心语义。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="fixtures"></a>
## 固定知识夹具

测试为每个用例创建临时 Store、知识仓库和手工捕获入口，并构造带内联引用、调查问题、生成 trace 与已接受复核结果的固定知识资产。[知识文档与资产夹具 ↗](../../../apps/server/tests/knowledge-repository.test.ts#L11 "支持临时仓库、手工捕获、内联引用、调查问题以及生成和复核元数据的测试基础。") 清理钩子会关闭数据库并删除临时目录，使后续断言都在隔离环境中围绕同一最小合同展开。

<a id="citation-validation"></a>
## 引用绑定与严格校验

仓库把材料行范围绑定为精确引文，并接受正文中就近出现的有效引用；正文没有引用、引用未知键或行号越界都会被拒绝。[引用绑定与错误拒绝 ↗](../../../apps/server/tests/knowledge-repository.test.ts#L33 "支持精确引文绑定，以及缺少内联引用、未知引用和越界范围均被拒绝的断言。") 因而引用位置和固定原文范围是发布合同的一部分，而不是仅供展示的附加信息。

<a id="revision-lifecycle"></a>
## 修订失效、恢复与问题动作

材料产生新修订后，直接依赖章节及引用它的上层文章都会变为非当前状态，但旧材料与旧知识修订仍可按固定标识读取；测试还确认，依赖旧材料摘要的 child 资产不能再次发布。[依赖知识失效测试 ↗](../../../apps/server/tests/knowledge-repository.test.ts#L47 "支持材料换头造成 child 与上层文章失效、旧修订仍可读取，以及旧摘要绑定的 child 不能重发。") 已复核资产可恢复到新数据库；在本测试场景中，新增的损坏 JSON 被标记为 rejected，且未覆盖已恢复版本。问题转待办具备幂等性，用户回答作为原始材料保存并把问题置为已回答。[资产恢复与问题动作测试 ↗](../../../apps/server/tests/knowledge-repository.test.ts#L62 "支持已复核资产恢复、当前测试中的损坏文件隔离、待办幂等和回答保存语义。")

<a id="retrieval-and-notification"></a>
## 召回、身份与通知边界

派生知识标题可帮助检索，但命中仍返回原始 Fragment；材料换头后，即使投影尚未刷新，旧派生词也不会召回过期证据。[派生知识引导原始证据召回 ↗](../../../apps/server/tests/knowledge-repository.test.ts#L82 "支持派生标题用于检索但返回原始证据，并在材料换头后过滤过期召回。") 不同载体即使 external id 相同仍保持不同材料身份。重复发布同一资产不新增通知，而删除问题形成的新修订会把旧问题标为被替代并新增一次通知。[材料身份与通知去重 ↗](../../../apps/server/tests/knowledge-repository.test.ts#L98 "支持不同材料载体的身份隔离、重复发布不重复通知及旧问题被替代。")
