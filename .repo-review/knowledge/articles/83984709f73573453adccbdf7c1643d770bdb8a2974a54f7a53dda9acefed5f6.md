# 知识仓库的不变性、恢复与检索测试

覆盖精确行内引用、依赖失效传播、artifact 恢复、问题动作、派生知识辅助检索、来源身份隔离及通知去重。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="citations-invalidation"></a>
## 引用校验与失效传播

测试将引用绑定到材料第二行的精确文本，并验证缺少行内引用、未知引用键和越界行号都会被拒绝。[行内引用校验测试 ↗](../../../apps/server/tests/knowledge-repository.test.ts#L33 "支持精确 quote 绑定以及缺失、未知、越界引用被拒绝的说明。") 子文章依赖原材料，概览再依赖子文章；材料更新后两级知识都变为非当前，但旧材料文本和旧知识正文仍可按固定修订读取，尝试重新发布旧 artifact 会得到输入变化错误。[级联失效与旧修订保留 ↗](../../../apps/server/tests/knowledge-repository.test.ts#L47 "支持材料变化使子知识和概览失效，同时保留旧证据及拒绝旧 artifact 再发布。")

<a id="restore-questions"></a>
## 恢复与问题操作

已复核文章写入 artifact 目录后，可在新数据库捕获相同材料并恢复为相同修订；损坏 JSON 被标记为 rejected，且不会覆盖先前好文章。[知识恢复和问题动作 ↗](../../../apps/server/tests/knowledge-repository.test.ts#L62 "支持跨数据库恢复、坏文件隔离、任务幂等及回答 provenance 状态。") 恢复出的调查问题创建任务具有幂等性，回答则形成 `original` provenance 的新修订并把问题标为 answered。

<a id="retrieval-identity"></a>
## 检索、身份与通知

派生文章标题可帮助关键词检索命中，但返回的是原材料 fragment；材料 head 更新后，即使投影尚未刷新，也不会召回陈旧来源。[派生知识引导原证据检索 ↗](../../../apps/server/tests/knowledge-repository.test.ts#L82 "支持检索利用派生标题但返回原始 fragment，并排除 head 已变化的陈旧来源。") 相同 external id 在 file 与 manual carrier 下保持不同 material key。重复发布同一 artifact 不新增通知；新知识修订移除问题时，旧问题转为 superseded，并只新增一次通知。[来源身份和通知生命周期 ↗](../../../apps/server/tests/knowledge-repository.test.ts#L98 "支持不同 carrier 的身份隔离，以及相同修订通知去重和旧问题退役。") 未覆盖数据库并发写入、循环文章依赖、超深依赖链和 artifact 文件名冲突。
