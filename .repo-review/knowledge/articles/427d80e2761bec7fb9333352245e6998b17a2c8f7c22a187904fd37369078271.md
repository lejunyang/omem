# Agent 运行时、角色分工与模型治理

该体系以版本化角色资产和统一宿主管理模型运行：可信上下文与不可信材料分层，ACP 协商模型、推理强度、图片和技能能力，CLI 提供受限兼容；预算、结构化输出、有限修复与运行追踪贯穿执行。知识、提案及代码理解角色各有合同，但静态规范和局部校验不能自动证明实际编排、发布门禁、持久化覆盖保护或自由文本语义质量。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="governance_foundation"></a>
## 宿主治理与信任边界

模型输出不能仅凭提示词获得可信性。运行时把角色身份、版本、提示、技能摘要、输出合同、工具与会话策略固化为角色包，并校验路径、清单身份、技能名称和摘要；native 技能只会复制到按运行隔离的工作区。[角色资产加载与隔离实现 ↗](../../../apps/server/src/agent-runtime/bundles.ts#L105 "支持版本化角色包的身份、合同、技能摘要校验，以及 native 技能隔离工作区机制。") 工作区的创建、内容冲突保护及 ACP 限制可继续下钻至角色资产包子知识。[隔离工作区与传输限制 ↗](5503d6ef2391166c507baa3b95d360b323b4ce4f2dd15f599f73d3db08635011.md#workspace "提供工作区创建、native 技能复制、内容冲突保护和 ACP 传输限制的子知识入口。")

提示组装把角色规范、输出合同、来源元数据和材料索引置于可信区，把既有文章、草稿及材料正文标为不可信数据；图片还会校验编码、摘要、媒体类型和累计容量。[可信上下文、材料分层与图片校验 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L81 "支持图片完整性和容量检查，以及可信角色信息与不可信派生知识、材料正文的分区组装。") 这使“材料是证据而非工具指令”成为宿主实施的边界。

<a id="transport_and_controls"></a>
## 模型传输、能力与预算

ACP 初始化声明不提供文件读写和终端能力，随后发现 native 技能，并拒绝 Agent 未公布的模型或推理强度；若模型元数据给出上下文窗口，还会核算输入、输出与预留预算，图片也须由 Agent 明示支持。[ACP 能力协商与模型配置检查 ↗](../../../apps/server/src/agents.ts#L259 "支持无文件和终端能力声明、技能发现、模型与推理强度检查、上下文窗口核算及图片能力拒绝。") 对应子知识进一步说明 ACP 的能力协商机制。[ACP 能力协商 ↗](f8da03813c756ea9ba7c66980a3595085142586aae031e5046704333ce5b6cfc.md#acp "提供 ACP 初始化、模型与推理强度合法性、native 技能及图片能力协商的子知识入口。") 传统 CLI 则通过无工具、只读或不询问权限、临时会话参数运行，只解析提供方 JSON 文本事件，缺少 ACP 的能力发现和图片通道。[受限 CLI 兼容路径 ↗](../../../apps/server/src/agents.ts#L377 "支持 CLI 的无工具、只读或不询问权限参数，以及模型设置、事件解析、输出限制和失败条件。")

预算采用 UTF-8 字节除以三并增加 25% 余量的启发式估算，而非精确 tokenizer。[生成预算估算规则 ↗](../../../apps/server/src/agent-runtime/budget.ts#L1 "支持预算采用带余量的 UTF-8 字节启发式而非精确 tokenizer，并限制配置值范围。") ACP 收到权限或补充输入请求时先通知可选宿主回调，随后立即取消或拒绝；只有网关配置了请求仓储时才会写入 denied 记录。[后台权限与补充输入拒绝 ↗](../../../apps/server/src/agents.ts#L180 "支持 ACP 请求先调用可选宿主回调，再立即返回取消或拒绝，而不暂停后台任务。")[运行请求的条件式记录 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L323 "支持网关向 ACP 提供运行请求回调，并说明仅在配置可选仓储时记录 denied 请求。")

<a id="roles_and_contracts"></a>
## 角色分工与证据链

候选提取器只从固定证据形成原子化提案，保留归属、否定、条件、时间、冲突和未知结果，且不得批准或执行；通用核验者不继承提取推理，只独立判断原始证据是否支持提案。[候选提取职责边界 ↗](../../../packages/agent-runtime/roles/extractor/1/prompt.md#L3 "支持提取器从固定证据产生候选并明确不得批准、执行或宣称应用。")[通用证据独立核验 ↗](../../../packages/agent-runtime/roles/verifier/1/prompt.md#L3 "支持核验者不继承提取推理、独立比较证据维度且只评估支持性的职责。")

知识侧拆分材料分析、规划、写作、刷新和独立复核。规划器按概念组织可追溯知识树并区分需求、历史方案、实现、验证记录与未决问题；复核者检查引用对附近论断的支持性，对范围错配、条件遗漏或把不确定内容写成事实的草稿要求修订。[知识规划与状态区分 ↗](../../../packages/agent-runtime/roles/knowledge-planner/1/skills/omem-knowledge-planner/SKILL.md#L8 "支持规划器按概念组织知识树，并区分需求、历史方案、实现、验证记录和未决问题。")[知识独立复核规则 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/skills/omem-knowledge-verifier/SKILL.md#L8 "支持复核引用的语义、范围、条件和时效，并将事实错误或确定性过强的论断退回修订。") 固定证据知识生产专题说明这些角色的合同与静态配置，同时明确现有材料尚不能证明固定编排、修订回流和发布门禁。[知识生产角色的进展与限制 ↗](95b177e06915baa0e87ddd239f792a05585e0b3f2a1d1ba45d52b325ca8083d7.md#progress_limits "提供合同、静态配置、跨字段校验边界和尚未证实的运行编排及发布门禁说明。")

代码理解以固定文件、符号、边和证据快照为边界；确定性验证器核对来源封印、部分交叉引用、选择器范围和引用预算，无模型时只生成零置信度的机械事实 seed。[代码理解验证与无模型降级 ↗](../../../packages/agent-runtime/src/code-understanding.ts#L489 "支持来源封印、交叉引用、选择器和预算校验，以及无模型时只生成机械事实 seed 的行为。")

<a id="outputs_progress_limits"></a>
## 结构化结果、追踪与现有限制

模型结果必须是单个 JSON 对象，通过角色声明的运行时合同，并在适用时核对作业或角色身份。[结构化输出解析与身份检查 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L210 "支持单个 JSON 对象要求、角色声明合同解析及适用的作业或角色身份一致性检查。") 输出超预算、结构错误或可选后验校验失败时，网关只在清单限定次数内完整重生成；成功 trace 记录角色包、提示、上下文、技能、工具、实际模型与 effort、会话、usage 和修复次数。[有限修复与运行追踪 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L247 "支持输出预算、可选后验验证、有限修复，以及模型、技能、工具、会话和预算 trace 的生成。") 作业适配器保存结构化结果及 trace，耐久 worker 管理领取租约、心跳、取消、成功提交和失败分类。[角色结果与作业保存 ↗](../../../apps/server/src/agent-runtime/job-handler.ts#L9 "支持角色适配器把结构化输出、模型配置、会话和完整运行 trace 保存为作业结果。")[耐久作业执行流程 ↗](../../../apps/server/src/jobs/worker.ts#L47 "支持 worker 的作业领取、租约心跳、取消、成功提交、失败分类和过期租约处理。")

当前可确认资产校验、信任分层、能力拒绝、预算、合同解析、部分确定性交叉引用和诚实 seed 已实现；此前把静态角色规范视为实际编排或语义质量证明的结论已被替代。后验 `validateOutput` 仍是可选入口，代码理解材料也未展示持久化层必然阻止失败结果覆盖既有有效知识。[有限修复与运行追踪 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L247 "支持输出预算、可选后验验证、有限修复，以及模型、技能、工具、会话和预算 trace 的生成。")[代码理解验证与无模型降级 ↗](../../../packages/agent-runtime/src/code-understanding.ts#L489 "支持来源封印、交叉引用、选择器和预算校验，以及无模型时只生成机械事实 seed 的行为。")
