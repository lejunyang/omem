# other · 模块理解

该模块汇集服务器的通用可信运行能力：以不可变证据和单用户 SQLite 为底座，连接受控 Agent、助手会话、知识学习、仓库评审及 Lark 输入。现有实现已覆盖持久作业、能力协商、独立复核和历史追溯，但团队隔离、依赖自动复核、真实外部服务兼容性及跨修订代码身份仍未闭环。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="responsibility"></a>
## 职责与基础边界

该模块提供多条业务链共用的可信底座：采集事务创建不可变修订和固定片段、更新来源版本，并只把非派生材料送入学习队列，避免模型总结成为自证材料。[单用户存储基础 ↗](../../../apps/server/src/store.ts#L1 "支持 Store 的组件装配、SQLite 单用户定位及团队级约束尚待迁移。")[采集修订与学习队列 ↗](../../../apps/server/src/store.ts#L141 "支持回执幂等、不可变修订、来源换头、依赖失效及派生材料不进入学习队列。") `Store` 同时装配应用、作业、输入聚合和来源画像，但明确只是单用户 SQLite 基础，不能据此宣称已有团队租户隔离。

<a id="main-flows"></a>
## 主要运行流程

Agent 子进程过滤敏感环境并以无 shell 方式启动，超时或取消会终止进程。[Agent 子进程生命周期 ↗](../../../apps/server/src/agents.ts#L32 "支持敏感环境过滤、无 shell 启动、超时和取消终止等进程边界。") 协议总输出和回答长度另有独立上限，权限及补充输入默认拒绝；[ACP 输出与权限限制 ↗](../../../apps/server/src/agents.ts#L151 "支持协议输出预算、回答字符上限，以及权限和补充输入请求默认拒绝。") 模型、推理强度、上下文窗口与图片能力则在会话发现后校验。[模型能力协商 ↗](../../../apps/server/src/agents.ts#L301 "支持模型与推理强度校验、上下文窗口检查、图片能力检查及结束状态校验。") 这替代了旧稿用单一引用覆盖全部 Agent 边界的结论。助手只接受 ACP profile，并裁剪历史与证据、要求结构化回答；只有明确任务意图才允许写入任务。[助手 ACP 适配器 ↗](../../../apps/server/src/assistant/acp-model.ts#L42 "支持 ACP 专用路由、历史和证据裁剪、结构化回答、取消传播及输出解析。")[任务意图与零写入治理 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L98 "验证明确指派可创建任务、咨询拒绝模型擅自写入，以及模型不可用时不伪造答案。") 学习链通过独立提取、核验和持久回执完成应用，Code Wiki 保存可回读的不可变快照，Lark 富消息也转换为统一采集分片。[受控学习流水线 ↗](../../../apps/server/tests/learning-pipeline.test.ts#L65 "验证独立提取和核验、持久应用回执、顺序重启续跑及重复处理去重。")[代码快照生命周期 ↗](../../../apps/server/tests/code-knowledge-snapshot.test.ts#L60 "验证显式当前快照、历史快照可读和源码按指定快照固定返回。")[Lark 富消息统一分片 ↗](../../../apps/server/tests/lark-rich-parts.test.ts#L112 "验证富文本、图片和回复关系进入统一采集分片，并保存图片资产。")

<a id="relationships"></a>
## 知识、代码与关系的协作

正文知识只有在独立复核接受且输入未变化时发布；材料换头会使依赖知识失效，但旧版本仍可固定读取，派生正文只引导召回原始证据。[知识复核与失效流程 ↗](739ea31d68edbd56041f02c23fac65549a179fc6d4e76a67dcc9b55a47416e9c.md#knowledge-jobs "支持独立复核发布、输入变化失效、旧版本保留及派生知识仅引导原始证据召回。") 仓库 association seed 生成独立意图片段及显式关系，支持多引用、幂等、缺失保留、失效和双向查询，不按同名文件猜测关联。[仓库关系同步与查询 ↗](../../../apps/server/tests/review-relations.test.ts#L207 "验证逐 seed 意图片段、多引用建边、幂等、缺失关系、失效及双向查询。") 此前“三类关系已通过统一阅读合同端到端连通”的结论已被替代：现有材料只分别证明知识依赖、普通片段链接和 repo-review 专用关系。[关系统一结论的边界 ↗](a39b9cdb1225ba6c8bef555f5a7fa616adddef9a1dcdcb378deacc882d541142.md#evidence-foundation "明确现有证据不足以证明正文引用、代码关系与个人知识已共用完整阅读合同。")

<a id="progress-limits"></a>
## 可靠性进展与限制

已验证采集与作业同事务、重启恢复、竞争领取和过期租约拒绝提交；[持久作业与租约 ↗](../../../apps/server/tests/jobs.test.ts#L52 "验证事务入队、重启恢复、竞争 worker 单次领取及过期 fencing token 被拒绝。") 分类失败分别限制重试并脱敏错误，[分类重试与错误脱敏 ↗](../../../apps/server/tests/jobs.test.ts#L207 "直接支持临时失败、坏输出和认证失败采用不同重试上限，并避免敏感令牌写入错误。") 应用后崩溃重放也不会重复任务、通知或投递意图。[应用后崩溃的幂等重放 ↗](../../../apps/server/tests/jobs.test.ts#L325 "直接验证业务应用后崩溃再重放时，任务、回执、通知和投递意图均不重复。") 群聊默认不暴露证据，注入策略后仅允许群范围材料；[群聊证据隔离 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L238 "验证群聊默认无证据，注入策略后只暴露当前群材料且私人证据不泄漏。") 会话修正只进入原会话，不泄漏到其他会话。[会话修正作用域 ↗](../../../apps/server/tests/assistant-runtime.test.ts#L519 "直接验证修正进入原会话的可信上下文，同时不会泄漏到另一会话。") 这修正了旧稿以群聊测试同时支持修正作用域的错误。

来源更新会使旧知识退出活跃检索，但自动复核仍以未实现失败并记录待复核状态。[依赖刷新尚未实现 ↗](../../../apps/server/tests/learning-refresh.test.ts#L152 "验证刷新任务失败并记录待复核对象，支持自动重新核验尚未闭环的结论。") 角色测试大量依赖明确标注为非生产模型的协议替身，因此不能证明真实 Agent CLI 的认证、图片和取消兼容性。[非生产 ACP 协议替身 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L1 "材料明确声明其为确定性测试替身，因此不能作为真实外部 Agent CLI 兼容性证明。") 跨文件调用、跨修订符号续接、真实 Lark 服务端幂等及团队级授权也仍缺直接验收。
