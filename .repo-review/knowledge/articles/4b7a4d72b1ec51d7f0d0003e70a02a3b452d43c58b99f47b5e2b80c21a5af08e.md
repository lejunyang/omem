# 可追溯章节撰写技能规范

该技能文件定义 omem-knowledge-writer 的用途和操作约束：围绕固定材料撰写中文概念章节，保持证据可追溯，并把不确定事项结构化为问题。它与提示模板高度一致，属于角色规范，不是实际生成质量的证明。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="skill_purpose"></a>
## 技能定位与知识边界

技能元数据将其命名为“撰写可追溯章节”，目标是组织概念知识，解释原因、机制、关联、进展和限制。它特别要求同时引用子知识及其原始依据，避免将派生总结视为新的独立证据。[可追溯章节技能定位 ↗](../../../packages/agent-runtime/roles/knowledge-writer/1/skills/omem-knowledge-writer/SKILL.md#L1 "支持附近关于技能名称、知识组织目标、证据边界和固定输入约束的说明。")

执行边界包括只使用提供内容、不调用工具、不读取额外文件，并以中文返回指定 JSON。每个 targetKey 都要生成键完全一致的文档，因此技能适合对固定输入进行受限知识编排，而不是开放式调查。

<a id="traceability_rules"></a>
## 可追溯输出流程

正文按章节组织，并要求引用紧邻所支持的句子或段落；每节至少一个引用，且 citations 中的每项都必须被正文使用。材料目标使用完整 key 与真实行号，文章目标使用真实 section，材料 quote 留空等待宿主抽取。[技能的引用与疑问规则 ↗](../../../packages/agent-runtime/roles/knowledge-writer/1/skills/omem-knowledge-writer/SKILL.md#L12 "支持附近关于正文引用位置、目标定位、空 quote 和 questions 编写方式的说明。")

技能还要求标签可读、理由具体、关系符合 Schema，并将缺背景或需选择的事项写成带证据的问题。这些规则描述了期望流程；是否存在宿主抽取、独立复核和自动拒绝违规结果，仍需实现材料佐证。
