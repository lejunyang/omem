# omem 项目概览与当前能力边界

omem 是面向个人工作场景的统一记忆与助理系统，以不可变原始材料为依据，将材料捕获、知识整理、语义检索、问答、待办和通知串联在同一证据链上。README 同时记录了当前可运行能力、验证入口和明确未完成项；其中仓库 Wiki 是统一知识流程对代码材料的应用，不是独立知识库。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="positioning"></a>
## 定位、证据链与运行形态

omem 将文本、图片、链接及上下文统一纳入 Capture，并保留不可变证据；Agent 负责分析与独立复核，个人问答、受治理记忆、待办和通知继续沿用同一证据链。仓库 Wiki 只是代码材料的一种应用，外部屏幕采集等仍需单独配置。[产品定位与统一证据链 ↗](../../../README.md#L1 "支持本节关于统一材料输入、不可变证据、知识处理及仓库 Wiki 定位的概述。")

当前基础运行依赖 osdk 和已登录的 Agent CLI，不要求 Docker、Python、Redis或本地大语言模型。默认以个人空工作区启动，生产入口为 4317；开发模式同时启动 API 与 Vue，并在端口冲突时选择空闲端口。[启动依赖与端口行为 ↗](../../../README.md#L5 "说明当前运行所需组件、默认工作区、生产及开发启动方式。")

<a id="retrieval"></a>
## 中文语义检索及适用范围

可选的本地 BGE-small-zh-v1.5 已接入个人助手、飞书助手与仓库搜索，与全文、记忆及 Wiki 引用结果合并；派生知识用于导航，最终依据仍回到当前原始 Fragment。模型由 osdk 固定并校验，应用不在运行时隐式下载；模型缺失时保留全文检索并报告降级。[中文语义检索接入与模型管理 ↗](../../../README.md#L20 "支持本节对混合召回、原始 Fragment 回查、离线模型快照及降级行为的说明。")

README 将当前实现限定为个人库上的精确余弦计算，尚无 ANN 或 cross-encoder reranker。四条中文同义问法的首位命中仅是小样本连通性验证，不代表全面召回率；英文和代码标识符仍依赖全文检索与模型补搜。[语义检索验证与限制 ↗](../../../README.md#L35 "限定当前向量检索实现及小样本验证的解释范围，避免将局部结果当作全面评估。")

<a id="knowledge"></a>
## 知识整理与仓库 Wiki

知识流程复用 Capture、Source、Revision、Fragment、持久任务和角色运行网关：材料经专用角色分析、独立复核，再组织为模块、架构、背景、需求、进展与概览。正文引用贴近论断并指向固定位置；AST 负责代码定位和明确结构关系，语义解释仍由模型分析与复核。[统一知识整理流程 ↗](../../../README.md#L39 "支持知识角色、独立复核、内联固定引用以及 AST 与语义分析职责划分。")

仓库 review 使用隔离 SQLite，启动只恢复已提交知识而不自动调用模型；显式 analyze 或 generate 才产生模型消耗。可提交知识、覆盖记录和验证报告与可重建 runtime 分离，旧 data 仅作历史档案。[Review 运行与知识资产目录 ↗](../../../README.md#L45 "说明 review 的显式生成方式、隔离运行配置以及提交知识与可重建运行数据的边界。") 独立模型复核不等于人工验收，跨文件调用精确解析、语义重排、周期巡检以及跨来源冲突自动修订仍未完成，不能视为已交付。[知识可信度与未完成能力 ↗](../../../README.md#L76 "支持独立复核不等于人工验收，并列明检索和跨来源处理尚未完成的能力。")

<a id="assistant_and_boundaries"></a>
## 助理操作、接入与部署边界

主助手目前可查询事项，并在用户明确指令下创建、改期、完成或重新打开任务；时间按用户时区解析，数据库写入失败不会伪装成“已安排”。提醒目前仅在应用内按任务时间触发，独立 reminder、重复安排、取消状态和外部到期投递尚未接通。[事项操作与提醒现状 ↗](../../../README.md#L105 "支持助手当前可执行的事项操作、成功回执要求及尚未接通的提醒能力。")

材料可由本地文件、固定 Git 提交、飞书文档或 CaptureEnvelope 显式录入；飞书只读取用户指定文档，系统不会自动抓取整个空间，也不会自动安装全局 hook 或启动屏幕监控。[材料接入范围与显式授权 ↗](../../../README.md#L117 "说明文件、Git、飞书及统一捕获入口，并支持不会自动全空间抓取或安装监听器的边界。") 默认部署是 loopback 上的单用户服务；远程监听需要强令牌和安全传输，但 shared token 不是团队级租户权限系统。[单用户部署与认证边界 ↗](../../../README.md#L132 "支持默认 loopback、远程访问安全要求以及当前并非多租户权限系统的判断。")
