# 普通采集与质量评测导入隔离测试

回归验证普通业务材料只形成可检索的不可变修订与片段，不会生成质量标注工作；研究导入必须携带显式 opt-in。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="ordinary-capture"></a>
## 普通采集的隔离保证

测试构造 40 段足以被评测分割器选中的业务文本，经 `captureSchema` 校验后调用 `Store.capture`。它先确认修订确实包含可检索片段，再查询质量数据集、草稿样本和投递意图三张表，要求计数全部为零。[普通采集零质量副作用断言 ↗](../../../apps/server/tests/import-quality-isolation.test.ts#L36 "支持普通采集保留片段但不创建质量数据集、样本或投递意图的核心保证。") 这防止普通材料仅因内容形态类似评测样本，就意外变成人工标注任务。

<a id="explicit-opt-in"></a>
## 研究导入的显式入口

第二个用例直接调用质量导入器：缺少判别值时必须抛出 `QUALITY_IMPORT_IS_EVAL_ONLY`，显式传入 `QUALITY_EVAL_ONLY` 后才生成 40 个样本。[评测导入显式启用测试 ↗](../../../apps/server/tests/import-quality-isolation.test.ts#L98 "支持缺少判别值时报错、传入指定常量后生成样本的论断。") 该值是导出的普通字符串常量，作用是要求调用方明确 opt-in、阻止遗漏参数的意外调用，并非不可伪造的安全凭证。[评测专用判别常量 ↗](../../../apps/server/src/quality/import.ts#L26 "说明 QUALITY_EVAL_ONLY 是导出的字面量常量，其作用是让遗漏 opt-in 的调用显式失败。") 实现注释同时规定该工具只服务研究标注流程，普通 HTTP、CLI、输入聚合与学习路径不应调用。[研究标注导入边界 ↗](../../../apps/server/src/quality/import.ts#L1 "解释质量分割器仅供显式研究标注流程使用，不属于普通采集链。")

<a id="coverage"></a>
## 测试边界

临时 SQLite 目录在每次用例后递归清理，Store 也在 `finally` 中关闭。[临时资源清理 ↗](../../../apps/server/tests/import-quality-isolation.test.ts#L22 "支持测试在用例后清理临时目录，并结合用例中的 finally 关闭 Store。") 测试覆盖手工来源的普通采集和 Lark 来源的直接评测调用，但没有逐一执行 HTTP、文件、Git、Lark CLI 或学习管线，也未以静态依赖分析证明不存在其他误调用；它验证的是当前 `Store.capture` 行为及导入函数的运行时参数保护。
