# 普通材料捕获与研究评测隔离

该回归测试确认普通业务文档捕获会保存材料版本及正文片段，但不会自动创建质量数据集、草稿样本或外发确认意图；研究评测导入器只有收到专用选择标识后才可生成样本。测试未直接验证检索接口及各类上层捕获入口。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 防止业务材料误入人工标注

规则切分器会从长文档中挑选研究样本，因此普通捕获若误接入该流程，可能把业务材料变成人工标注任务。本测试用 40 个足够长的业务段落制造敏感输入，要求捕获后只保留材料版本和片段，不产生质量数据集、草稿样本或确认卡。参考 [普通捕获隔离目标 ↗](../../../apps/server/tests/import-quality-isolation.test.ts#L1 "支持普通业务捕获只应保存材料版本和片段，不应自动创建质量数据或确认卡的测试目标。") [长业务文档构造 ↗](../../../apps/server/tests/import-quality-isolation.test.ts#L28 "支持测试使用 40 个足够长的业务段落制造容易被评测切分器选中的输入。")

质量导入器本身也声明仅供显式启动的研究标注流程使用；其候选标签具有较激进的默认行为，不应进入 HTTP、CLI、输入聚合器、学习流程或一般捕获路径。延伸阅读：[研究导入器使用边界 ↗](../../../apps/server/src/quality/import.ts#L1 "说明规则切分器仅服务显式研究标注流程，并列出不得调用它的普通捕获入口。")

<a id="ordinary-path"></a>
## 普通捕获只保存材料

第一项用例在临时 SQLite 目录中创建 `Store`，用公共捕获合同提交带来源信息的手工文档。断言仅确认返回版本含有片段，且首个片段保留“三方核对”正文；它没有调用检索接口，因此不能据此认定检索链路已通过行为验证。参考 [材料版本与片段断言 ↗](../../../apps/server/tests/import-quality-isolation.test.ts#L42 "支持用例执行普通捕获，并仅断言返回片段存在且包含指定正文；范围内没有检索接口调用。")

用例随后直接查询质量数据集、质量样本和外发意图三张表，要求记录数全部为零。这证明当前直接捕获场景没有产生三类质量副作用。参考 [质量副作用归零 ↗](../../../apps/server/tests/import-quality-isolation.test.ts#L68 "支持普通捕获后质量数据集、质量样本和外发意图的记录数均为零。") Store 材料只展示数据库迁移和仓储初始化，未提供 `capture` 的内部调用链，相关实现细节不能由本组材料推出。延伸阅读：[存储初始化范围 ↗](../../../apps/server/src/store.ts#L38 "表明所给 Store 代码仅覆盖 SQLite、迁移和仓储初始化，不能支持对 capture 内部调用链的进一步判断。")

<a id="eval-guard"></a>
## 研究导入必须显式选择

第二项用例直接调用研究导入器：缺少专用选择标识时必须抛出 `QUALITY_IMPORT_IS_EVAL_ONLY`；传入导出的评测常量后，同一文档可生成 40 条样本。这既让误接生产路径的调用明显失败，也保留了研究工具的合法入口。参考 [评测入口回归分支 ↗](../../../apps/server/tests/import-quality-isolation.test.ts#L98 "支持缺少选择标识时抛错，以及显式选择后生成 40 条样本的两条行为断言。") [评测专用选择标识 ↗](../../../apps/server/src/quality/import.ts#L26 "说明专用字面量用于阻止普通生产路径意外调用研究导入器。")

该成功分支只核对样本数量，尚未检查样本正文、来源定位、标签约束、数据集记录及外发策略；本测试也未逐一运行 HTTP、CLI、输入聚合器或学习入口，因此结论限于两个被直接调用的入口。

<a id="cleanup"></a>
## 隔离临时运行数据

每个用例都登记独立临时目录，并在 `finally` 中关闭各自数据库；`afterEach` 再递归移除所有登记目录。这样，正常完成和预期抛错都不会让数据库连接或临时数据影响后续用例。参考 [临时目录清理 ↗](../../../apps/server/tests/import-quality-isolation.test.ts#L22 "支持每项测试结束后递归移除登记的临时目录。") [普通捕获数据库关闭 ↗](../../../apps/server/tests/import-quality-isolation.test.ts#L93 "支持第一项用例在 finally 中关闭 Store 数据库。") [评测用例数据库关闭 ↗](../../../apps/server/tests/import-quality-isolation.test.ts#L136 "支持第二项用例在 finally 中关闭 Store 数据库。")
