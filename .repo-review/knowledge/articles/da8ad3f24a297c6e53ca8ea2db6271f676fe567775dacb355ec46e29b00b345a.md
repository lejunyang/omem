# 助手回合编排、证据隔离与工具治理

该模块是 Web 与 Lark 共用的助手运行时，负责回合持久化、会话内串行化、证据检索与隔离、模型调用、受治理的任务创建、超时取消及崩溃恢复。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="turn_state"></a>
## 回合状态、取消与恢复

运行时在模型调用前持久化回合，并按外部事件标识去重；同一会话的新消息会中止旧控制器、取消旧回合，再沿 Promise 链串行执行。[回合入队、去重与会话内抢占 ↗](../../../apps/server/src/assistant/runtime.ts#L198 "支持模型调用前持久化、外部事件幂等去重，以及同一会话中新消息取消旧回合并串行执行。") 公开取消同步更新回合状态；重试与崩溃恢复会检查真实 application receipt，已提交任务副作用的回合只补齐完成状态，其余未完成回合才重新执行。`shutdown()` 只处理当前进程内的会话映射。[取消、重试、关闭与崩溃恢复 ↗](../../../apps/server/src/assistant/runtime.ts#L261 "支持公开取消、receipt 幂等检查、pending 重试、进程恢复及 shutdown 的实际处理边界。")

取消信号由 `deriveSignal` 合并外部中止与会话控制器，并设置回合定时器；任一来源触发都会中止合并信号，且已中止的上游信号会立即生效。[合并取消信号与回合定时器 ↗](../../../apps/server/src/assistant/runtime.ts#L393 "直接支持外部信号、会话控制器和定时器如何共同驱动合并信号，并处理创建时已经中止的情况。") 模型等待另有 `withTimeout` 通过 `Promise.race` 设置独立拒绝路径，即使模型忽略 abort，也会在时间预算耗尽后结束等待。[独立模型等待超时 ↗](../../../apps/server/src/assistant/runtime.ts#L576 "支持模型调用由独立计时器和 Promise.race 约束，并在外部中止时快速拒绝等待。")

<a id="context_model"></a>
## 上下文、检索与模型失败

执行阶段只回放当前会话近期完成的回合，将本轮检索与上一轮选中证据去重合并，并读取会话范围内的 owner 纠正。模型不可用会把回合退回 pending，取消记为 cancelled；其他模型异常才生成明确的临时不可用答复。[上下文组装与模型失败转换 ↗](../../../apps/server/src/assistant/runtime.ts#L421 "支持会话历史、检索证据、上一轮上下文和纠正的组合，并区分取消、模型不可用与普通错误。")

检索优先走注入的 `RetrievalPort`，未注入时才回退到 Store 搜索；检索结果及上一轮工作上下文都经过可见性过滤。没有宿主策略时，仅 private 会话可读，group 默认拒绝全部证据；纠正读取失败则容错为空。[检索、纠正与上一轮证据 ↗](../../../apps/server/src/assistant/runtime.ts#L604 "支持 RetrievalPort 优先、Store 回退、上一轮证据复用、纠正容错和默认可见性策略。")

<a id="tool_governance"></a>
## 引用校验与任务写入治理

模型不能自行授权创建任务。运行时先用确定性中英文模式识别明确交办，咨询问句优先否决弱任务词；工具调用仍须经过 `MemoryService`，并在工具执行前和最终持久化前检查取消状态。最终答复引用也只保留运行时实际提供给模型的 fragment。[任务意图与写入栅栏 ↗](../../../apps/server/src/assistant/runtime.ts#L494 "支持确定性任务意图判断、MemoryService 治理、取消栅栏以及最终引用白名单。")

明确的 owner 交办若没有已有引用，运行时会尝试把本轮原话捕获为证据，再构造可幂等重放的提案。此前“任一模型引用无法解析就拒绝写入”的结论已被替代：无效引用会被过滤，只有模型指定了引用、当前证据与上一轮上下文均无法解析时，才以 `no_prior_evidence` 拒绝。[引用解析与任务提案 ↗](../../../apps/server/src/assistant/runtime.ts#L701 "支持先前上下文回退、指定引用全部不可解析时的拒绝条件，以及直接消息捕获和治理提案流程。") 有限正则仍可能漏掉未枚举表达，群聊检索也依赖宿主注入真实的来源与范围策略。[任务规则与群聊默认拒绝 ↗](../../../apps/server/src/assistant/runtime.ts#L90 "支持任务意图依赖有限模式，并说明未注入可见性策略时群聊证据默认不可见。")
