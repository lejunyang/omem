# 知识抽取质量的确定性评估器

对已确认样本与预测结果进行结构化比较，并分别衡量引用定位、语义支持、事实槽、必要证据覆盖、任务完成和不必要打扰。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="semantic-judges"></a>
## 从引用定位分离语义支持

评估器先以严格 schema 校验预测，再用规则基线判断陈述是否得到引文支持。`judgeSemanticSupport` 依次检查共享动词的否定翻转、概念反义、历史时间与当前有效性的错配、限制条件丢失，以及中文二元片段重叠过低，输出 supported、partial、contradicted 或 unsupported。它明确不是 LLM，因此可重复且易审计，但只能覆盖列出的词根、反义组和限制词。[确定性语义支持规则 ↗](../../../apps/server/src/quality/evaluator.ts#L33 "支持语义判定的五类规则、四种结果及非 LLM 的实现边界。") `judgeFactSlots` 另行要求陈述中的数字或量化界限也出现在引文中，避免把“最多五个”改成其他数量。[核心事实槽一致性 ↗](../../../apps/server/src/quality/evaluator.ts#L185 "支持陈述新增或改变数字、数量界限时判为不一致的说明。")

<a id="sample-evaluation"></a>
## 样本级匹配流程

`evaluateQuality` 只把状态为 confirmed 且有标签的样本纳入分母，并拒绝同一样本的重复预测。缺少预测会记录为失败；有预测时，先比较 disposition、autoApply 和归一化后的对象集合，再逐对象检查引文是否位于输入文本、语义支持和事实槽一致性。空对象数组不会凭借 `every()` 获得虚假的支持分。必要证据覆盖则从期望对象出发，看预测是否以相同引文或足够相近的陈述覆盖它。[确认样本的逐项评估 ↗](../../../apps/server/src/quality/evaluator.ts#L234 "支持样本筛选、重复预测拒绝、缺失处理、对象级证据判断及必要证据覆盖算法。")

<a id="metrics-boundaries"></a>
## 指标输出与边界

汇总结果把引用位置准确率、语义支持率、事实槽一致率、必要证据召回、任务完成率和不必要打扰率分开，另给出自动应用精度、显式抽取覆盖、模糊/转发样本的所有者误应用数及延迟分位数。没有预测对象时，前三类对象指标返回 null 而不是 1；失败列表保留所有非完全匹配样本。[质量指标汇总结果 ↗](../../../apps/server/src/quality/evaluator.ts#L337 "支持各项独立指标、空分母返回 null、延迟分位数和失败明细的说明。") 当前完成度允许 `needs_context` 类期望在“不抽取或不自动应用”时完成，且规则评估没有展示对英文语义、复杂数字表达或跨句推理的覆盖。
