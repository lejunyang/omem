# 质量预测评估器：证据支持、任务完成与安全打断指标

该模块对齐已确认质量样本与严格校验后的预测，分别评估标签一致性、引用定位、规则式语义支持、数字事实槽、必要证据覆盖、任务完成和不必要打断，并汇总延迟与失败明细。其确定性规则适合稳定回归，但不等同于完整的自然语言推理或量词语义核验。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-input"></a>
## 评估目标与输入边界

模块用于弥补“短引能在原文定位，但陈述仍可能相反、无关或遗漏限制”的评估缺口，把引用位置与语义支持拆成独立信号。预测必须关联 UUID 样本、通过质量标签校验，并可携带耗时、token 数和错误信息。[预测输入校验合同 ↗](../../../apps/server/src/quality/evaluator.ts#L4 "支持预测必须关联 UUID 样本、包含合法质量标签，并可记录耗时、token 与错误信息。") 标签合同规定 disposition、抽取对象、自动应用、安全副作用与备注；抽取至少包含一个对象，非抽取不得自动应用。[质量标签结构与约束 ↗](../../../apps/server/src/quality/repository.ts#L39 "支持标签字段组成，以及抽取必须有对象、非抽取不得自动应用的约束。")

评估入口拒绝重复样本预测，只把状态为 `confirmed` 且有确认标签的样本纳入分母；缺失预测生成失败行。[样本筛选与精确匹配 ↗](../../../apps/server/src/quality/evaluator.ts#L234 "支持重复预测检测、确认样本筛选、缺失预测处理，以及 exact 实际参与比较的字段。") 因此 `predictionCount` 可包含未进入分母的输入，不能与 `denominator` 混为一谈。

<a id="judging-flow"></a>
## 对象级裁决与任务完成

每个预测对象分别检查短引能否在样本原文中定位、陈述是否受短引支持，以及事实槽检查是否通过。[预测对象证据评估 ↗](../../../apps/server/src/quality/evaluator.ts#L285 "支持每个预测对象分别计算引用定位、语义裁决和事实槽一致性。") 语义规则按否定翻转、反义冲突、历史时间被表述为当前、限制词遗漏和二元词组重合度依次裁决为 `supported`、`partial`、`contradicted` 或 `unsupported`。[规则式语义支持裁决 ↗](../../../apps/server/src/quality/evaluator.ts#L138 "支持语义裁决的执行顺序、词面阈值及四类输出结果。")

事实槽只提取阿拉伯数字，以及后接特定单位的中文数字，并检查陈述中的这些数字 token 是否也出现在短引中。[可识别数字事实槽 ↗](../../../apps/server/src/quality/evaluator.ts#L185 "支持事实槽仅提取特定数字形式并执行从陈述到短引的单向包含检查，也说明其不核验边界词本身。") 它不是完整的量词或边界语义一致性检查：若数字相同而“最多”“至少”“不超过”等边界词改变，该函数仍可能返回 `true`。

预期对象覆盖采用规范化短引相等或双向包含；若短引不匹配，还可由实际与预期陈述的二元词组重合度达到 0.5 判为覆盖。[预期对象覆盖判定 ↗](../../../apps/server/src/quality/evaluator.ts#L221 "直接支持短引相等、双向包含以及陈述二元词组重合度达到 0.5 的覆盖规则。") 预期为抽取时，完成仅要求实际 disposition 为 `extract`、覆盖全部预期对象且没有对象被判为 `contradicted`；`partial`、`unsupported`、引用未定位或事实槽不一致均不会单独阻止完成。弃权要求实际弃权且对象为空，`needs_context` 分支则采用“未抽取或未自动应用”的宽松条件。[打断与任务完成规则 ↗](../../../apps/server/src/quality/evaluator.ts#L296 "支持不必要打断的判定，以及 extract、abstain、needs_context 三类预期下的完成条件。")

<a id="metrics-and-limits"></a>
## 汇总指标与实现限制

输出汇总精确匹配、disposition 一致、自动应用精度、引用定位、四类语义裁决、数字槽一致、必要证据召回、任务完成、不必要打断、延迟分位数及失败行；没有预测对象时，对象级比率为 `null`，不会因空数组获得满分。[质量指标汇总输出 ↗](../../../apps/server/src/quality/evaluator.ts#L387 "支持对象级、任务级、延迟与失败指标的含义，以及空对象分母返回 null。") `explicitCoverage` 实际筛选预期 disposition 为 `extract` 的行，再统计其中的精确匹配，并不按输入类别 `explicit` 筛选。[预期抽取样本筛选 ↗](../../../apps/server/src/quality/evaluator.ts#L364 "说明 explicitCoverage 实际按预期 disposition 为 extract 筛选，并以 exact 统计覆盖。")

评估器复用仓储模块的样本类型和标签 schema。[评估器类型依赖 ↗](../../../apps/server/src/quality/evaluator.ts#L1 "支持评估器从仓储模块复用质量标签 schema 与样本类型。") `exact` 只比较 disposition、autoApply 和规范化后的对象，当前未比较 `forbiddenEffects` 与 `notes`。[样本筛选与精确匹配 ↗](../../../apps/server/src/quality/evaluator.ts#L234 "支持重复预测检测、确认样本筛选、缺失预测处理，以及 exact 实际参与比较的字段。") 此外，语义判断依赖有限中文词表、规则顺序和词面重合，无法保证覆盖跨句指代、复杂否定、未收录同义表达或忠实但低重合的改写。
