# 抽取质量评估器

对已确认样本与预测结果进行确定性质量评估，分别衡量引用定位、语义支持、事实槽一致性、必要证据覆盖、任务完成、打扰率和延迟。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="semantic-judges"></a>
## 确定性语义与事实槽判断

该模块先用严格 schema 校验预测结构。`judgeSemanticSupport` 不调用模型，而是按共享动词的否定翻转、反义概念、历史时间与当前表述冲突、限制条件丢失及二元词重叠依次判为 contradicted、partial、unsupported 或 supported。[语义支持规则 ↗](../../../apps/server/src/quality/evaluator.ts#L33 "支持语义裁决的规则顺序、四种 verdict 及非模型实现的说明。") `judgeFactSlots` 另行检查陈述中的数字和量化边界是否都能在引文中找到，防止凭空改变数量。[数字事实槽检查 ↗](../../../apps/server/src/quality/evaluator.ts#L185 "支持陈述新增或改变数量时判为不一致的说明。") 这些都是显式规则基线，词表之外的同义、否定和复杂数值表达不保证正确识别。

<a id="sample-evaluation"></a>
## 样本对齐与完成判定

`evaluateQuality` 只把状态为 confirmed 且带确认标签的样本放入分母，并拒绝同一样本的重复预测；缺失预测会形成失败行。[预测去重与确认样本筛选 ↗](../../../apps/server/src/quality/evaluator.ts#L234 "支持只评估已确认标签、拒绝重复预测并显式记录缺失预测。") 每个预测对象分别检查引文是否位于原文、陈述是否受引文支持、事实槽是否一致；空对象数组不会因 `every()` 的空真值获得支持分。预期对象覆盖则通过引文包含关系或陈述二元词相似度匹配。[逐对象证据评估 ↗](../../../apps/server/src/quality/evaluator.ts#L275 "支持引用定位、语义与事实槽逐对象计算，以及预期证据覆盖匹配。") 完成判定结合 disposition、预期对象覆盖和“不得矛盾”，但 partial 与 unsupported 并不会直接令 extract 样本失败，这是当前指标口径的重要边界。[打扰与完成判定 ↗](../../../apps/server/src/quality/evaluator.ts#L302 "支持不必要打扰和不同 disposition 下任务完成条件的说明。")

<a id="metrics"></a>
## 聚合指标与模块边界

返回结果将引用位置、语义支持、事实槽、必要证据覆盖、任务完成和不必要打扰分开统计，并给出自动应用精度、显式样本覆盖、歧义所有者误自动应用数、P50/P95 延迟及逐行失败信息。没有预测对象时，前三类对象级比率返回 `null`，不会虚报满分。[质量指标输出 ↗](../../../apps/server/src/quality/evaluator.ts#L337 "支持各类聚合指标、空分母处理、延迟百分位和失败明细的描述。") 文件依赖 quality repository 提供标签 schema 与样本类型，但所给材料未包含该仓储实现，也没有测试文件，因此无法仅据此确认样本持久化方式、所有规则分支是否已有断言或实际线上阈值。
