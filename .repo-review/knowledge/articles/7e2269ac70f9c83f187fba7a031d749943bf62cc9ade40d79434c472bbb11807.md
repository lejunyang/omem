# 测试用确定性助手模型

该模块提供无需 LLM 的确定性 AssistantModelPort 实现，只用于测试检索结果展示和引用传播，不属于生产降级路径。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 测试替身的职责

`DeterministicAssistantModel` 是测试替身，不进行推理，只把运行时已经检索出的证据组合成固定格式回答。文件注释明确规定生产装配必须使用真实 `AcpAssistantModel`；没有可用模型时应显式降级，不能用该类制造看似真实的回答。[确定性模型的测试限定 ↗](../../../apps/server/src/assistant/default-model.ts#L7 "支持该实现仅用于测试、生产不得把它作为假降级答案的说明。")

<a id="behavior_limits"></a>
## 可断言行为与未覆盖范围

实现最多选取前五条证据，每条正文截取 160 字符，并把对应 fragmentId 原样作为引用；有历史轮次时只追加“延续上一话题”的轮次提示。无证据时返回固定的“没有直接相关内容”回答且引用为空。[固定回答生成逻辑 ↗](../../../apps/server/src/assistant/default-model.ts#L16 "说明五条证据上限、截断、引用、历史提示和无证据分支，也界定其可直接断言的行为。")

因此它适合断言证据数量上限、标题/文本投影、引用集合及有无历史的输出差异，但不覆盖语义相关性、ACP 传输、JSON 解析、取消超时、工具治理或模型故障恢复；这些能力也未在本材料中由测试文件直接证明。[固定回答生成逻辑 ↗](../../../apps/server/src/assistant/default-model.ts#L16 "说明五条证据上限、截断、引用、历史提示和无证据分支，也界定其可直接断言的行为。")
