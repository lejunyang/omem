# 测试用确定性助手模型

为测试提供不执行推理的固定模型实现，仅展示运行时已经检索出的证据；生产装配不得用它替代真实 ACP 模型。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="scope"></a>
## 用途与生产边界

`DeterministicAssistantModel` 是 `AssistantModelPort` 的测试替身，不承担语义推理。文件明确要求生产环境注入真实 `AcpAssistantModel`；模型未配置时应由运行时诚实报告不可用，而不是悄悄改用固定答案。因此它只能证明运行时的确定性编排与引用链路，不能证明真实模型效果。[测试替身边界 ↗](../../../apps/server/src/assistant/default-model.ts#L7 "支持该实现仅供测试、生产必须使用真实 ACP 且不可伪造兜底回答的结论。")

<a id="behavior"></a>
## 固定输出行为

生成时最多取前五条已检索证据。没有证据便返回“当前材料中没有直接相关内容”且不附引用；有证据时按顺序展示标题和文本前缀，并把对应 fragment id 全部作为引用。若存在历史轮次，只追加轮次延续提示，不分析其内容。[确定性回答生成 ↗](../../../apps/server/src/assistant/default-model.ts#L16 "支持无证据和有证据两种固定输出、五条上限、历史提示及 fragment 引用行为。") 这种行为便于测试断言稳定输出，但不应被解读为检索质量、回答正确性或外部 ACP 可用性的验收结果。
