# 上游源码核验索引

记录2026年9月26日对17个上游项目的固定提交、许可证正文和抽查文件，作为可复查的研究快照；它不是依赖锁定、运行验证或选型结论。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 定位与核验范围

本文是上游研究的人读索引，汇总项目、核验提交、许可证正文结论和已检查文件。证据截至2026年9月26日，属于研究时的源码快照，而非生产依赖锁定；正式接入仍须选择 release 或 digest，并重新运行契约测试。[研究快照说明 ↗](../../../docs/research/source-index.md#L1 "支持核验日期、快照性质以及正式接入仍需锁定版本并重跑契约测试的论断。")

表格共列出17个项目，包括 LightRAG、memU、WeKnora、A-mem、Haystack、Docling、Graphiti、RAGFlow、LangGraph、LangMem、Letta、Mem0、pgvector、LlamaIndex、Temporal、Cognee 和 Hindsight。[17个上游项目核验表 ↗](../../../docs/research/source-index.md#L5 "支持索引实际列出的17个项目及其提交、许可证和检查内容范围。") 完整文件 URL 与内容摘要由配套的 `sources.json` 承担，本文主要提供可读导航。

<a id="evidence-boundary"></a>
## 证据方法与边界

许可证判断优先依据仓库中的许可证正文，而非只采用 GitHub SPDX 返回值；WeKnora、memU 与 pgvector 的 `NOASSERTION` 均经过补充核对，不能据此推断项目闭源。研究也明确没有按 star 数或供应商自报 benchmark 进行选型。[许可证与选型边界 ↗](../../../docs/research/source-index.md#L25 "支持对 NOASSERTION 的解释，以及研究未依据 star 数和供应商 benchmark 选型的边界。")

输入还包括指定版本的用户参考文档、旧项目只读抽查和前端设计稿。旧项目没有运行测试，因此观察不能表述为已复现缺陷；设计稿中的企业政策及 Gartner 数字也只是演示素材。[输入材料与历史抽查限制 ↗](../../../docs/research/source-index.md#L27 "说明用户文档、旧项目抽查和设计稿的来源，并支持未运行旧测试、演示素材不是事实依据的限制。")

<a id="traceability"></a>
## 可追溯性与资料保留

索引保留内部文档的读取 revision 和旧项目 commit，方便后续回到当时材料复核。原始内部文档响应仅保存在本机临时研究目录，没有复制进仓库；仓库只保存来源与版本线索。[内部材料保留方式 ↗](../../../docs/research/source-index.md#L34 "支持原始内部响应仅留在临时研究目录、仓库只记录来源和版本的可追溯安排。") 因而该文件能说明研究检查过什么，却不能单独证明任何上游组件已经集成、通过运行测试或适合生产部署。
