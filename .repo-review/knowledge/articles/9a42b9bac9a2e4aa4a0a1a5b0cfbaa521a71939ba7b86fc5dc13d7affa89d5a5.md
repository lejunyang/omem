# 基础 ACP 协议测试替身

一个通过标准输入输出模拟 ACP 会话的确定性进程，用于测试能力发现、模型与推理强度配置、文本和图片提示、超时、取消及权限拒绝。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="protocol"></a>
## 协议握手与动态配置

该文件明确是协议测试替身而非生产模型。它逐行读取 JSON-RPC 消息，在初始化时声明图片提示和会话关闭能力，新建会话时返回固定会话标识及配置选项。[ACP 初始化与会话创建 ↗](../../../apps/server/tests/fixtures/acp-agent.mjs#L1 "支持该替身通过 JSON-RPC 声明能力并建立固定测试会话。") 模型可选 alpha/beta；推理强度默认 low，只有切到 beta 后才出现 high，因此可检验调用方是否重新读取并校验动态能力。[模型与推理强度选项 ↗](../../../apps/server/tests/fixtures/acp-agent.mjs#L8 "支持 beta 模型才提供 high 强度以及配置可动态更新的说明。")

<a id="prompt-flow"></a>
## 提示处理与可见输出

收到提示后，替身拼接所有文本块；包含 `TIMEOUT` 时故意不响应。普通路径先发送私有思考块，再发送包含当前模型、强度和图片数量的可见消息，最后以 `end_turn` 完成。[提示响应事件序列 ↗](../../../apps/server/tests/fixtures/acp-agent.mjs#L48 "支持超时触发、思考块、可见答案和结束原因的核心流程说明。") 这可用于验证调用方区分思考与答案、传递图片并等待终止响应，但替身本身不验证图片内容或真实模型质量。

<a id="permission"></a>
## 权限与取消边界

包含 `ASK_PERMISSION` 时，替身主动请求写受保护文件的权限并暂停提示。它只接受调用方返回 `cancelled`；其他结果以退出码 8 暴露错误，拒绝后再输出提示并结束。[权限请求与拒绝处理 ↗](../../../apps/server/tests/fixtures/acp-agent.mjs#L55 "支持权限必须被取消以及拒绝后继续完成提示的边界说明。") 会话取消则直接把挂起提示标记为 `cancelled`。[取消与权限响应分支 ↗](../../../apps/server/tests/fixtures/acp-agent.mjs#L98 "支持会话取消和权限结果处理的终止行为。") 未覆盖允许工具执行、多次并发提示、畸形 JSON 或完整 ACP 错误对象。
