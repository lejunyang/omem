# 飞书机器人接入与 Owner 配对

该页面编排飞书应用的创建、已有应用授权和凭据导入，持续展示授权、能力核验与 Owner 配对状态。现有材料可确认前端请求与交互流程，但服务端的密钥保护和配对防重放机制仍需补充证据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-entry"></a>
## 接入入口与能力范围

页面提供创建新应用、授权已有应用和直接导入凭据三种入口；导入时可复用本机 botmux 配置，也可手工填写 App Secret。参考 [飞书应用接入方式 ↗](../../../apps/web/src/LarkSetup.vue#L216 "支持创建、授权和凭据导入三种入口，以及 botmux 与手工输入两种导入来源。") 同一应用在界面中被用于群消息、Owner 通知与确认；页面还声明 Secret 由服务端加密保存且不会出现在响应、日志或页面结果中，但该安全承诺仍需服务端材料验证。参考 [应用用途与安全声明 ↗](../../../apps/web/src/LarkSetup.vue#L209 "支持界面声明的应用用途，并界定 Secret 安全性目前属于页面承诺。")

初始化会并行读取默认能力配置、已有连接和可复用应用，并优先回填第一项可复用应用的 App ID，否则回填第一项已有连接的 App ID。参考 [基础配置与 App ID 回填 ↗](../../../apps/web/src/LarkSetup.vue#L60 "支持并行加载三类基础数据，以及按第一项可复用应用、第一项已有连接的顺序回填 App ID。") 页面汇总应用权限、用户权限、事件和回调数量，并说明预留能力与明确不申请的高风险操作范围。参考 [能力配置摘要 ↗](../../../apps/web/src/LarkSetup.vue#L280 "支持权限、事件和回调数量展示，以及预留和不申请能力的边界说明。")

<a id="onboarding-flow"></a>
## 从提交到能力核验

更新与导入要求 App ID 符合 `cli_…` 格式。导入请求会按来源决定是否提交 Secret；创建或更新则启动 onboarding。请求结束后，组件会清空内存中的 Secret，但这只能证明前端清理，不能证明服务端的落盘加密或日志脱敏。参考 [接入请求与 Secret 清理 ↗](../../../apps/web/src/LarkSetup.vue#L96 "支持 App ID 校验、接入模式分流、手工 Secret 提交及请求结束后的组件状态清理。")

接入处于非终态时，页面每 1.5 秒刷新任务及连接状态；进入终态或组件卸载后停止轮询。参考 [接入状态轮询 ↗](../../../apps/web/src/LarkSetup.vue#L190 "支持非终态定时刷新、终态停止轮询及组件卸载时清理定时器。") 收到凭据也不会立即视为可用：在 `credentials_received` 或 `checking` 阶段，界面等待实际权限与事件的 capability probe，完成前不标记为 active。参考 [实际能力核验 ↗](../../../apps/web/src/LarkSetup.vue#L362 "支持收到凭据后仍需完成实际权限与事件核验，完成前不标记 active。")

<a id="pairing-and-boundaries"></a>
## Owner 配对、终态与责任边界

进入 `awaiting_pair` 后，前端请求配对码；只有状态中出现候选 Open ID，才会向确认接口提交 pairing ID 与预期 Open ID，随后刷新接入状态。参考 [Owner 配对接口流程 ↗](../../../apps/web/src/LarkSetup.vue#L152 "支持配对码签发、候选 Open ID 前置条件、确认参数及确认后的状态刷新。") 界面要求用户生成一次性配对码、私聊同一应用，并在网页读回候选发送者后确认绑定。参考 [一次性配对交互 ↗](../../../apps/web/src/LarkSetup.vue#L375 "支持私聊同一应用、等待候选发送者并由用户确认的界面流程。")

`active`、`cancelled`、`denied`、`expired` 和 `failed` 都被视为终态。参考 [终态定义 ↗](../../../apps/web/src/LarkSetup.vue#L28 "支持接入终态集合及成功、危险和等待状态的显示语义。") “重新配置”只清空当前组件中的 onboarding、配对码和 Secret。参考 [本地重新配置重置 ↗](../../../apps/web/src/LarkSetup.vue#L185 "支持重新配置仅清空当前组件内接入状态、配对码与 Secret。") 失败视图优先显示错误信息；仅当错误消息和错误码都不存在时，才提示可重新发起且不会自动删除平台上可能已创建的应用，缺失能力则另行列出。参考 [失败状态与兜底提示 ↗](../../../apps/web/src/LarkSetup.vue#L409 "支持失败视图优先显示错误、无错误信息时使用重新发起提示，并单独展示缺失能力。") 组件通过本地 API 模块取得请求函数和飞书 DTO，并复用共享 UI 组件，因此现有材料只能确认前端编排，不能确认服务端如何保护 Secret 或抵御配对重放。参考 [组件与 API 依赖 ↗](../../../apps/web/src/LarkSetup.vue#L1 "支持组件依赖本地 API 请求函数、飞书 DTO 和共享 UI 组件的关系。")
