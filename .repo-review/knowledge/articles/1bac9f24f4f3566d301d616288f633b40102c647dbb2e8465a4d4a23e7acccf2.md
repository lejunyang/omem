# 飞书机器人接入与 owner 配对界面

该 Vue 页面集中处理飞书应用的创建授权、已有应用更新、凭据导入、能力核验和 owner 配对，并通过轮询把服务端接入状态转化为可操作的分阶段界面。它只负责浏览器端编排和展示；凭据保存、权限探测、配对校验及群消息采集的真实安全边界位于后端接口。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决什么问题

页面为个人实例提供统一的飞书机器人接入入口，使同一个应用能够承载群消息采集、owner 通知与确认。用户可以创建新应用、更新已有应用，或从 botmux／手工输入导入凭据；界面明确提示 App Secret 只提交给服务端，并在请求后清除浏览器表单中的值。参考 [接入用途与凭据说明 ↗](../../../apps/web/src/LarkSetup.vue#L206 "支持页面统一承载群消息、owner 通知与确认，并声明 Secret 的服务端保存边界。") [三种接入方式 ↗](../../../apps/web/src/LarkSetup.vue#L216 "支持创建、更新、凭据导入以及 botmux 和手工凭据来源的交互说明。")

<a id="onboarding-flow"></a>
## 从配置到接入完成

挂载时，页面并行加载默认能力配置、现有连接和可复用应用，并用已有记录预填 App ID。提交时，导入模式调用已有凭据接口；创建和更新模式走 onboarding 接口。随后界面依据状态展示授权二维码、能力核验、owner 配对、成功或失败结果。参考 [基础数据加载 ↗](../../../apps/web/src/LarkSetup.vue#L60 "支持页面并行读取默认配置、已有连接和可复用应用并预填 App ID 的流程。") [接入请求分流 ↗](../../../apps/web/src/LarkSetup.vue#L96 "支持不同模式分别调用凭据导入或 onboarding 接口，并在请求结束后清空 Secret。") [接入状态模型 ↗](../../../apps/web/src/LarkSetup.vue#L28 "支持终态判定、状态文案以及仅在等待扫码阶段显示二维码的条件。")

<a id="pairing-and-polling"></a>
## 状态轮询与 owner 配对

非终态接入每 1.5 秒刷新一次，进入成功、取消、拒绝、过期或失败状态后停止，组件卸载时也会清理定时器。等待配对时，用户先申请一次性配对码，再由页面读取候选发送者；确认请求同时提交配对记录和预期 Open ID，成功后重新拉取状态。参考 [轮询生命周期 ↗](../../../apps/web/src/LarkSetup.vue#L190 "支持非终态定时刷新、终态停止以及组件卸载时清理定时器的行为。") [owner 配对确认 ↗](../../../apps/web/src/LarkSetup.vue#L152 "支持配对码申请、候选 Open ID 校验和确认后刷新接入状态的流程。")

<a id="boundaries"></a>
## 边界条件与模块关系

更新或导入仅接受 `cli_` 开头的 App ID；收到凭据并不代表可用，完成能力探测前不会显示为 active。失败状态保留缺失能力和服务端错误，重新配置也不会自动删除平台上可能创建的应用。该组件通过 `./api` 的泛型请求函数依赖后端集成接口，但材料未展示接口实现、鉴权、加密保存和实际群消息监听逻辑。参考 [能力核验与失败处理 ↗](../../../apps/web/src/LarkSetup.vue#L362 "支持凭据接收后仍需能力探测，以及失败时展示错误和缺失能力的边界。") [API 依赖入口 ↗](../../../apps/web/src/LarkSetup.vue#L2 "支持该组件从相邻 API 模块导入请求函数和飞书相关数据类型；材料不足以证明后端实现细节。")
