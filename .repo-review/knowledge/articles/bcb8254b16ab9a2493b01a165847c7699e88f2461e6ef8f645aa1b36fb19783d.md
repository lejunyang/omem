# 提取角色运行清单

该清单声明 extractor 角色的版本、配置档引用、内联技能、ProposalBatch.v1 输出、无工具策略、隔离会话政策和令牌预算。它是期望运行配置，不等同于执行成功或外部 CLI 能力证明。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="identity-bundle"></a>
## 角色身份与技能制品

清单将角色标识和版本分别固定为 `extractor` 与 `1`，引用 `traex` 配置档和 `prompt.md` 模板。技能包以 `omem-extract`、`extract-1` 标识并采用内联加载，同时记录制品摘要，便于运行时锁定具体技能内容。[提取角色与内联技能配置 ↗](../../../packages/agent-runtime/roles/extractor/1/manifest.json#L1 "支持角色身份、配置档、提示模板、技能加载方式和制品摘要的说明。") 这些字段只声明配置关系，是否成功解析仍需运行记录或测试证明。

<a id="contract-isolation"></a>
## 输出合同与会话隔离

角色输出被声明为 ProposalBatch.v1，工具策略为完全禁用且允许工具列表为空。会话每次均不复用，也不继承用户技能或 MCP，形成面向固定输入的隔离执行边界。[输出、工具与会话策略 ↗](../../../packages/agent-runtime/roles/extractor/1/manifest.json#L17 "支持 ProposalBatch.v1 输出、禁用工具和会话隔离边界的说明。") 这与提取合同中的提案、证据和不确定性结构相衔接。[提案批次合同概要 ↗](../../../packages/agent-runtime/roles/extractor/1/output.schema.json#L3 "支持输出合同包含观察、提案、弃权及提案证据与不确定性字段的关联说明。")

<a id="budget"></a>
## 预算与修复上限

清单设置最大上下文 96000、最大输出 24000 token，并允许最多两次修复尝试。[提取角色预算配置 ↗](../../../packages/agent-runtime/roles/extractor/1/manifest.json#L27 "支持上下文、输出令牌和修复次数上限的说明。") 这些数值是配置上限，不代表单次运行必然获得对应模型容量，也没有说明超限、修复失败或不支持配置时的具体错误行为。
