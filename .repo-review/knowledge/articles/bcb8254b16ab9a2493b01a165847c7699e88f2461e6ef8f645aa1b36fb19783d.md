# 提取器角色清单配置

该清单声明 extractor 角色第 1 版的提示模板、内联技能、结构化输出合同、工具与会话隔离策略，以及上下文、输出和修复预算。它是运行配置，不足以单独证明角色加载、摘要校验或提取流程已在运行时成功执行。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role_contract"></a>
## 角色与输出合同

清单将角色标识为 `extractor`、版本设为 `1`，并指定 `traex` profile 与 `prompt.md` 模板，说明其用途是按固定角色配置发起提取任务。[提取器角色基本配置 ↗](../../../packages/agent-runtime/roles/extractor/1/manifest.json#L2 "支持附近关于角色标识、版本、执行 profile 和提示模板的配置说明。") 输出被约束为 `ProposalBatch.v1`，因此下游预期接收结构化提案批次，而非自由文本；这里是接口声明，并不等同于已验证运行时能够正确产出该合同。[提案批次输出合同 ↗](../../../packages/agent-runtime/roles/extractor/1/manifest.json#L17 "支持附近关于 extractor 输出被声明为 ProposalBatch.v1 的论断。")

<a id="skill_and_isolation"></a>
## 技能装载与隔离边界

角色绑定 `omem-extract` 的 `extract-1` 技能包，采用内联装载，并记录制品摘要，用于固定所依赖的技能版本与内容身份。[内联提取技能绑定 ↗](../../../packages/agent-runtime/roles/extractor/1/manifest.json#L9 "支持附近关于技能名称、版本、装载方式及制品摘要的说明。") 同时，工具策略禁止全部工具，会话永不复用，也不继承用户技能或 MCP；这使单次提取更易复现，并降低材料内容借助外部能力产生副作用或跨会话污染的风险。[工具与会话隔离策略 ↗](../../../packages/agent-runtime/roles/extractor/1/manifest.json#L18 "支持附近关于禁用工具、禁止复用会话及不继承用户扩展能力的说明。")

<a id="resource_budget"></a>
## 资源与失败恢复预算

配置允许最多 96,000 个上下文 token、24,000 个输出 token，并设置最多两次修复尝试。[提取任务资源预算 ↗](../../../packages/agent-runtime/roles/extractor/1/manifest.json#L27 "支持附近关于上下文、输出 token 上限和修复次数的配置说明。") 这些值为宿主执行提供资源上限和结构化输出失败后的恢复边界，但清单没有呈现超限处理、修复触发条件、实际消耗或成功率，因此不能据此判断当前 extractor 的性能与可靠性。
