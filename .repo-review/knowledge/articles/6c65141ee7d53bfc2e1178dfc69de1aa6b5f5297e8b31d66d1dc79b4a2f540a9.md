# Repo-review 前端 API 客户端与数据合同

集中描述 repo-review 的浏览、同步、关系图与代码理解接口；轻量 fetch 封装依赖服务端合同一致性，目前材料未显示运行时响应校验。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-contract"></a>
## 职责与接口边界

该模块是 repo-review 知识库的前端客户端，覆盖读取、浏览与同步，并与个人工作区 API 区分：按文件注释，目标服务绑定回环地址、没有令牌门禁，因此请求不附带 `Authorization`。[Repo-review 客户端边界说明 ↗](../../../apps/web/src/review-api.ts#L1 "支持该客户端的用途、回环无令牌假设及不发送授权头的设计背景。") 类型描述来源、带版本的历史修订、片段、搜索与同步状态，也描述代码快照、文件、符号、边及理解结果；其中修订具有版本号、当前状态和前序标识，但材料没有证明运行时不可修改。[历史修订与修订详情类型 ↗](../../../apps/web/src/review-api.ts#L37 "支持修订被描述为带版本的历史记录，并具有 current、previousId 等状态字段；不据此扩张为不可变保证。")

<a id="request-flow"></a>
## 请求封装与核心流程

通用 `get`、`post` 拼接 `/api/review` 前缀并尝试解析 JSON；失败响应优先采用服务端 `error`，否则抛出统一错误，成功响应则直接断言为泛型。[通用请求包装器 ↗](../../../apps/web/src/review-api.ts#L174 "支持统一路径前缀、JSON 解析、错误提取及成功值泛型断言的流程。") 来源列表支持分类和已删除项参数，修订、片段、搜索及关系查询会编码相应标识或路径。[来源、修订、搜索与关系请求 ↗](../../../apps/web/src/review-api.ts#L194 "支持查询参数和各类标识经过编码后构造请求路径的说明。") `reviewCode` 单独将 404 转为 `null`，使追踪视图可以表达“该文件没有材料”，其他错误仍会抛出。[按代码路径查找材料 ↗](../../../apps/web/src/review-api.ts#L231 "说明该查询将 404 转为 null，而对其他失败继续抛出异常。")

<a id="code-knowledge-flow"></a>
## 代码知识读取与同步

代码知识接口提供当前快照、整图、文件、符号、边和文件理解读取；DTO 除内部定位字段外，还允许携带展示标题、展示路径、引用标签、可操作状态、原因与深链。[代码图 DTO 与读取入口 ↗](../../../apps/web/src/review-api.ts#L262 "支持代码文件、符号、边的展示投影字段及代码图读取接口。") 策展理解区分列表摘要和完整详情，记录 seed、代理复核、过期、证据引用、未知项及被替代结果。[策展理解合同 ↗](../../../apps/web/src/review-api.ts#L398 "支持理解结果的列表与详情结构，以及 seed、复核、过期、替代、证据和未知项字段。") 源码全文读取先请求第一行取得 `totalLines`，再按探测到的范围请求全文；代码同步则发送空 JSON 对象并返回文件、符号、边及过期边统计。[源码全文读取与代码同步 ↗](../../../apps/web/src/review-api.ts#L498 "支持先探测总行数再读取完整范围的流程，以及代码同步请求和返回统计。")

<a id="conditions-and-limits"></a>
## 关系语义与可确认限制

关系 DTO 会为入向查询反转关系名；当对端不再指向当前且未删除的 head 时，有效状态被标为 `stale`，未解析关系的对端可为 `null`。[关系方向与有效状态合同 ↗](../../../apps/web/src/review-api.ts#L112 "支持反向关系名、过期状态判定及未解析对端为空的语义。") 当前客户端对成功 JSON 没有展示运行时 schema 校验：解析失败会回退为 `{}`，随后仍通过 TypeScript 断言返回，因此合同偏差可能延迟到消费端才暴露。[响应解析与类型断言边界 ↗](../../../apps/web/src/review-api.ts#L174 "支持成功响应未经运行时模式验证便断言为目标类型，以及 JSON 解析失败回退为空对象的限制。") 此外，回环绑定、代理暴露范围以及两次源码请求之间的快照一致性均不在所给客户端材料中，不能视为已经验证。
