# 可追溯知识撰写角色的界面配置

该配置为知识撰写角色声明中文显示名称、简短能力说明和默认提示词，将角色定位为基于固定证据构建带引用的知识内容。材料只证明界面与提示词配置存在，不能据此确认角色已被运行时注册、调用或完成端到端验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-purpose"></a>
## 面向固定证据的知识撰写入口

该角色在界面中显示为“撰写可追溯章节”，面向需要把已有材料整理成可回溯知识内容的场景。这个名称表达的是用户可理解的任务目标，而不是底层模型或内部角色标识。参考 [角色显示名称 ↗](../../../packages/agent-runtime/roles/knowledge-writer/1/skills/omem-knowledge-writer/agents/openai.yaml#L1 "支持该配置将角色以“撰写可追溯章节”的名称呈现给用户。")

简短说明进一步把能力限定为从**固定证据**构建相互链接的知识，强调正文与来源之间应保留联系。这里记录的是配置所宣称的职责，不能单独视为引用校验、证据固定或知识发布流程已经实现。参考 [固定证据知识说明 ↗](../../../packages/agent-runtime/roles/knowledge-writer/1/skills/omem-knowledge-writer/agents/openai.yaml#L3 "支持角色被描述为从固定证据构建带关联知识的配置定位。")

<a id="default-invocation"></a>
## 默认调用方式与证据边界

默认提示词要求调用指定的知识撰写技能处理已提供的固定材料，表明该配置预期通过技能合同约束生成过程，而不是让角色自行扩展材料范围。参考 [默认技能提示词 ↗](../../../packages/agent-runtime/roles/knowledge-writer/1/skills/omem-knowledge-writer/agents/openai.yaml#L4 "支持默认调用会指定知识撰写技能并限定处理已提供固定材料的论断。")

这份文件仅包含界面元数据和默认提示词，没有给出技能正文、输入输出结构、运行时注册方式或测试结果。因此能够确认的是**角色入口的配置意图**；角色能否被实际发现、是否严格执行固定证据约束，以及失败时如何处理，仍需结合运行时实现与验证记录判断。
