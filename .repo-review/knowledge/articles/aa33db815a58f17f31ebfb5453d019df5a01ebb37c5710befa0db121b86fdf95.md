# 可追溯章节技能的 OpenAI 界面配置

该 YAML 为技能声明展示名称、简短英文说明和默认调用提示，用于代理界面中的发现与启动。文件只描述界面元数据，未包含模型、预算、工具权限或输出校验配置。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="interface_metadata"></a>
## 展示与发现信息

配置在 interface 下提供中文展示名“撰写可追溯章节”和英文短描述“Build linked knowledge from fixed evidence”。这使用户或代理目录能够以人读名称识别技能，并突出其从固定证据构建关联知识的用途。[技能界面名称与简介 ↗](../../../packages/agent-runtime/roles/knowledge-writer/1/skills/omem-knowledge-writer/agents/openai.yaml#L1 "支持附近关于展示名称、英文短描述及界面发现用途的说明。")

材料只有五行，未声明模型选择、推理强度、工具权限、上下文预算或 Schema，因此不应把它解释为完整的角色运行配置。

<a id="default_invocation"></a>
## 默认调用入口

default_prompt 建议通过 `$omem-knowledge-writer` 处理已提供的固定材料，说明该文件的主要作用是生成一个技能调用入口。[技能默认调用提示 ↗](../../../packages/agent-runtime/roles/knowledge-writer/1/skills/omem-knowledge-writer/agents/openai.yaml#L4 "支持附近关于默认提示通过技能名处理固定材料的说明。")

默认提示没有复述章节、引用和问题等详细规则；这些行为需要由相应技能正文或角色提示补充。材料也未展示哪个宿主读取此 YAML、变量如何解析以及调用失败如何处理，所以这里只能确认配置意图，不能确认界面集成已运行。
