# pnpm 依赖锁定与工作区解析快照

该锁文件以 pnpm 9 格式记录根项目、Web 应用和共享 UI 包的已解析依赖，固定后端、前端、测试与构建工具版本，并展开传递依赖及平台可选包。它能证明依赖图和工作区链接的当前配置状态，但不能单独证明相关功能已经实现或测试通过。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="scope"></a>
## 锁定范围与工作区关系

文件采用 `lockfileVersion: '9.0'`，并启用 peer 依赖自动安装；`importers` 下分别存在根项目、`apps/web` 与 `packages/ui`，说明一次锁定覆盖多个工作区单元。Web 应用通过 `workspace:*` 链接共享 UI，而不是从外部仓库解析该包。[工作区 importer 与本地 UI 链接 ↗](../../../pnpm-lock.yaml#L1 "支持锁文件覆盖根项目、Web 应用和共享 UI，并说明 Web 使用工作区链接引用共享 UI。")

这是一份依赖解析快照：它表明包管理器曾为这些 importer 生成一致的版本关系，但不等同于应用入口、页面或服务端能力已可运行。

<a id="dependency_profile"></a>
## 技术栈、工具链与运行限制

根项目锁定 Fastify、静态资源插件、Agent Client Protocol SDK、飞书 SDK 与 Zod；开发侧锁定 TypeScript、Vite、Vitest、Playwright、Vue 编译器及类型检查工具。[根项目运行与开发依赖 ↗](../../../pnpm-lock.yaml#L9 "支持对后端集成、类型系统、构建和测试工具链构成的概括；这里只证明依赖被锁定。") Web 与共享 UI 同时依赖 Vue、Markdown 渲染、代码高亮和 HTML 净化组件，反映出共享富文本展示能力所需的依赖基础。[Web 与共享 UI 的展示依赖 ↗](../../../pnpm-lock.yaml#L58 "支持两个前端工作区共享 Vue、Markdown、高亮与净化依赖这一配置事实。")

解析结果还给出明确环境约束，例如 Vite 7.3.1 要求 Node `^20.19.0 || >=22.12.0`。[Vite 的 Node 版本要求 ↗](../../../pnpm-lock.yaml#L1372 "支持运行环境存在最低 Node 版本约束，说明锁定成功不代表任意环境均可运行。") 因此仅看到锁文件不能确定实际部署所用 Node 版本是否兼容，也不能把 Playwright、Vitest 的存在解释为测试已经执行或通过。
