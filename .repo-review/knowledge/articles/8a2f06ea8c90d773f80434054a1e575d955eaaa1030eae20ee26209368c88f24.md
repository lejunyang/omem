# 证据独立复核流程与判定边界

说明独立复核角色如何先确认固定证据的有效性，再比较证据与提案的语义范围、辨别陈述主体、处理冲突与图像推断，并严格停留在评估而非批准或执行阶段。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决什么问题

这套流程用于独立判断：固定的原始证据是否足以支持某项记忆或任务提案。复核者接收候选项与原始证据，产出结构化评估，但不负责批准变更。这样可以把“证据是否成立”和“是否应用变更”分成两个阶段，避免审查角色越权。参考 [独立证据复核职责 ↗](../../../packages/agent-runtime/roles/verifier/1/skills/omem-evidence-review/SKILL.md#L2 "说明该角色面向固定证据与候选提案执行独立验证，并只返回评估结果而不批准变更。")

<a id="review-flow"></a>
## 从证据身份到语义支持

复核首先确认精确引文或图片身份；确定性校验无效或存在歧义时，结论不能标为支持。之后逐项比较证据与提案的主体、范围、时间、条件、否定关系、归属和断言强度，而不能只凭措辞相似作判断。参考 [证据与提案核对要点 ↗](../../../packages/agent-runtime/roles/verifier/1/skills/omem-evidence-review/SKILL.md#L8 "支持先校验引文或图片身份，再比较主体、范围、时间、条件及断言强度的复核顺序。")

还需区分资料所有者的明确承诺、转述内容、建议以及未知主体的说法。若当前记忆中存在矛盾或后续更正，应保留冲突，而不是选择语气更自信的一方。参考 [主体辨别与冲突保留 ↗](../../../packages/agent-runtime/roles/verifier/1/skills/omem-evidence-review/SKILL.md#L10 "支持区分承诺、转述、建议和未知主体，并在出现矛盾或后续更正时保留冲突。")

<a id="limits"></a>
## 推断限制与输出边界

OCR 结果和图片描述默认属于推断，除非提供的图片本身能够被独立辨认；一次工具步骤成功也不能推出整体任务成功，更不能把相关性写成因果关系。复核结果只能以 `AssessmentBatch.v1` JSON 返回，角色不得批准、应用或执行变更，也不得发送消息或修改策略。参考 [推断与执行边界 ↗](../../../packages/agent-runtime/roles/verifier/1/skills/omem-evidence-review/SKILL.md#L12 "说明图像和 OCR 的推断属性、禁止过度归因，以及复核角色仅输出评估 JSON 的行为边界。")
