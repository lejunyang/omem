# omem 证据复核技能规则

该技能细化了固定证据核验的检查顺序、归属和图像推断边界、冲突处理及禁止操作，是 verifier 提示词的操作性补充。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="verification_sequence"></a>
## 从确定性身份到语义支持

技能要求先复查精确引文或图像身份；确定性检查无效或存在歧义时，不得给出 `supported`。随后逐项比较主体、范围、时间、条件、否定、归属和预期强度。[身份复查与语义比较顺序 ↗](../../../packages/agent-runtime/roles/verifier/1/skills/omem-evidence-review/SKILL.md#L6 "支持先验证引文或图像身份、再按多个语义维度审查，且歧义身份不得判为支持。") 这一顺序将“证据是否是所声称的材料”与“材料是否支持提案”拆开，防止定位错误被语言相似性掩盖。

<a id="provenance_conflict"></a>
## 来源归属、冲突与推断限制

复核需区分所有者承诺、转发言论、建议和未知说话者，并检查当前记忆中的矛盾与后续更正；遇到冲突应保留冲突，而不是因措辞更自信就选定一方。[归属与冲突保留规则 ↗](../../../packages/agent-runtime/roles/verifier/1/skills/omem-evidence-review/SKILL.md#L10 "支持区分不同言论来源，并结合当前记忆和后续更正保留冲突的要求。") OCR 和图片描述在无法直接读取原图时只能视为推断，也不能从单个工具步骤成功推导整体成功，或把相关性写成因果。[图像与因果推断限制 ↗](../../../packages/agent-runtime/roles/verifier/1/skills/omem-evidence-review/SKILL.md#L12 "支持将不可独立读取的 OCR 或图片描述视为推断，并禁止从步骤成功或相关性作过强结论。")

<a id="non_authorizing_output"></a>
## 只评估、不授权

技能最终只允许返回 `AssessmentBatch.v1` JSON，并再次禁止批准、应用、执行、发送消息或改变政策。[核验技能输出权限边界 ↗](../../../packages/agent-runtime/roles/verifier/1/skills/omem-evidence-review/SKILL.md#L14 "支持仅返回 AssessmentBatch.v1 且不得批准或执行任何变更的结论。") 因而它是证据质量控制环节，而不是变更执行器。技能规则描述了预期行为，但没有包含自动检查这些行为的测试或运行记录，实际遵循程度仍需从宿主校验和任务结果确认。
