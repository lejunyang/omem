# 文档材料分析角色的界面配置

该配置为“分析文档材料”角色声明展示名称、简短说明和默认提示词，用于把宿主界面中的角色入口关联到 omem-material-analyst 技能。文件只描述配置意图，不能据此确认技能加载、提示词执行或知识生成流程已经实际运行。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role_presentation"></a>
## 角色如何呈现给使用者

该文件定义了一个角色界面配置，面向使用者显示的名称是“分析文档材料”。它的作用是让用户在选择能力时能够识别该角色，而不是描述材料分析的内部算法、证据处理流程或运行结果。参考 [角色展示名称 ↗](../../../packages/agent-runtime/roles/material-analyst/1/skills/omem-material-analyst/agents/openai.yaml#L1 "支持附近关于该文件声明界面配置及中文展示名称的说明。")

从现有材料只能确认这项**配置声明**存在；无法仅凭展示名称判断界面是否已经接入该配置，也不能把它视为角色已成功执行的实现证据。

<a id="skill_invocation"></a>
## 默认提示词与能力边界

简短说明把该角色定位为基于固定证据构建关联知识；默认提示词则要求使用 `omem-material-analyst` 处理宿主提供的固定材料。这表明配置意图是将角色入口导向对应技能，并强调输入证据由外部提供。参考 [角色说明与默认提示词 ↗](../../../packages/agent-runtime/roles/material-analyst/1/skills/omem-material-analyst/agents/openai.yaml#L3 "支持附近关于角色定位、固定材料输入以及调用 omem-material-analyst 技能之配置意图的说明。")

不过，配置没有给出模型、运行参数、输出合同、错误处理或验证机制，也没有执行记录。因此，它只能说明预期调用方式，不能证明技能可用、知识已生成，或生成结果已经经过复核。
