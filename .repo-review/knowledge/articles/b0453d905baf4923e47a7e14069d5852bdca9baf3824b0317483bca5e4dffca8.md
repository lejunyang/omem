# 材料分析技能的 OpenAI 界面配置

提供技能在 OpenAI 代理界面中的展示名称、英文短描述和默认调用提示；它是展示及启动配置，不包含模型、预算、输出模式或运行成功证据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="interface_metadata"></a>
## 界面元数据

该 YAML 仅定义一个 `interface` 配置块：面向用户的展示名为“分析文档材料”，英文短描述强调从固定证据构建相互链接的知识。[界面名称与简述 ↗](../../../packages/agent-runtime/roles/material-analyst/1/skills/omem-material-analyst/agents/openai.yaml#L1 "支持该配置提供中文展示名及固定证据知识构建短描述的论断。") 展示名与材料分析技能的中文职责相符，而短描述突出证据固定性和知识关联，但没有进一步说明“linked knowledge”的数据结构。

<a id="default_invocation"></a>
## 默认调用方式与限制

默认提示要求使用材料分析技能处理已提供的固定材料，表明该配置的作用是为代理入口预填技能调用语句。[默认技能调用提示 ↗](../../../packages/agent-runtime/roles/material-analyst/1/skills/omem-material-analyst/agents/openai.yaml#L4 "支持该文件通过默认提示引导代理使用材料分析技能处理给定材料的论断。") 文件没有指定模型、推理强度、上下文预算、JSON 强制模式或错误处理，因此不能仅凭此配置断言 OpenAI 代理会正确加载技能、满足输出合同或拒绝越界读取。
