# docs-prototype：可追溯知识交互的离线原型

该模块以自包含 HTML 演示知识阅读、递归证据路径、上下文追问、版本与异常状态及变更恢复。前端交互和构建、检查入口已编码，但数据、问答、同步与引擎均为本地模拟，不能代表正式后端能力。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 职责与设计背景

该模块把“知识结论能够回到固定原文”做成可传阅的交互样稿：单个 `index.html` 可通过 `file://` 打开，不依赖 CDN、密钥或后端。[单文件离线交付说明 ↗](../../../docs/prototype/README.md#L1 "支持原型可直接打开、无需外部服务并便于单文件传阅的定位。") 原型覆盖文章与材料搜索、递归引用、局部追问、历史版本及异常来源；桌面以导航、阅读、问答三栏组织，窄屏隐藏固定问答栏，手机端收起侧栏并把证据对话框铺满视口。[原型交互范围 ↗](../../../docs/prototype/README.md#L5 "支持搜索、递归引用、追问、版本与异常来源等已编码交互范围。")[响应式布局规则 ↗](../../../docs/prototype/index.html#L1721 "支持中窄屏问答栏切换、手机侧栏和全屏证据阅读等布局说明。")

<a id="evidence_workflow"></a>
## 证据阅读与问答流程

示例文章分别映射到若干首层证据节点；发布规范明确引用回滚手册，而另一段已提供的链路从验证轨迹依次连接代码修订、测试、指标和原始采样。[知识文章与首层证据映射 ↗](../../../docs/prototype/data.js#L178 "直接支持三篇示例文章各自关联哪些首层证据节点。")[发布规范与操作手册关系 ↗](../../../docs/prototype/data.js#L3 "支持发布规范引用回滚操作手册这一上游关系，不外推未展示的中间链路。")[验证轨迹到原始观测链 ↗](../../../docs/prototype/data.js#L47 "支持验证轨迹继续连接代码修订、测试、指标和原始采样的链段。") 这替代了此前把材料概括成一条完整连续链的过宽结论；未提供的中间节点关系不作推断。应用用帧栈保存滚动位置和阅读层级，支持返回、面包屑跳转、循环提示及关闭后的焦点归还。[证据路径栈与焦点管理 ↗](../../../docs/prototype/app.jsx#L385 "支持滚动记忆、压栈、循环检测、返回、跳转及关闭后归还焦点的流程。") 不可用材料显示具体原因且追问按钮禁用；模板回答也会拒绝把缺失正文当作证据。[不可用来源与追问禁用 ↗](../../../docs/prototype/app.jsx#L1396 "支持历史版本提示、不可用原因页以及仅允许可用或已替代材料开启追问。")[模拟回答与证据筛选 ↗](../../../docs/prototype/app.jsx#L163 "支持回答范围筛选、状态过滤、模板生成和不可用材料拒答。") 回答若被保存，只形成待核对候选，不会直接成为正式事实。[回答保存为待核对候选 ↗](../../../docs/prototype/app.jsx#L463 "直接支持演示回答只形成候选、需核对原始证据且不会直接成为正式事实。")

<a id="build_progress"></a>
## 构建、依赖与验证声明

React 交互、示例图、样式及第三方声明由 esbuild 打包并内联到离线 HTML。[自包含 HTML 构建流程 ↗](../../../docs/prototype/build.mjs#L1 "支持 esbuild 打包、资源和第三方声明内联以及离线 HTML 输出。") 包配置固定 React、React DOM、esbuild 与 Playwright Test 版本，并提供构建和冒烟检查入口。[原型脚本与依赖配置 ↗](../../../docs/prototype/package.json#L1 "支持构建、测试入口及主要运行和开发依赖的精确版本。") README 声明浏览器检查覆盖长链、循环、版本、追问、同步、恢复、搜索、移动布局和零外部请求；但材料没有实际退出码、日志或验证摘要，因此只能确认预期流程，不能认定当前版本已经通过。[浏览器检查声明 ↗](../../../docs/prototype/README.md#L32 "说明文档列出的检查命令、覆盖行为和预期产物，并界定其不是实际运行证据。")

<a id="limits"></a>
## 能力边界与未决风险

原型未连接 LLM、真实数据源、数据库或记忆引擎；同步、学习和恢复只改变演示状态。[真实能力边界 ↗](../../../docs/prototype/README.md#L18 "直接支持模型、真实数据、数据库、后台学习和同步尚未接入的限制。") 变更历史写入 `localStorage`，问题草稿与会话仅保存在页面内存。[本地状态生命周期 ↗](../../../docs/prototype/README.md#L41 "支持变更历史与问题会话分别保存在本地存储和页面内存。") 当前链接实现仅以当前节点生成 hash，初始化也只恢复一个节点，因而不能还原完整证据路径。[单节点链接与恢复实现 ↗](../../../docs/prototype/app.jsx#L400 "支持复制链接只写当前节点、页面初始化仅从 hash 恢复单帧，因此无法还原完整路径。") 锁文件使用特定依赖镜像，目标环境仍需确认可达性；Tweaks UI 只记录了改编来源，缺少版本和独立许可信息。[依赖镜像来源 ↗](../../../docs/prototype/package-lock.json#L582 "支持锁文件绑定特定包镜像地址及目标环境可能存在可达性约束的判断。")[Tweaks UI 来源记录 ↗](../../../docs/prototype/THIRD_PARTY_NOTICES.txt#L25 "支持风格面板的改编来源，同时表明现有声明未给出完整许可元数据。")
