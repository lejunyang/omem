# 对话分析技能的代理界面元数据

该 YAML 文件提供技能在代理界面中的展示名称、简短描述和默认调用提示。它属于发现与呈现配置，不包含模型、工具权限、预算或执行状态。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="interface-metadata"></a>
## 界面名称与用途描述

配置把界面展示名称设为“整理对话材料”，简短描述则强调从固定证据构建带链接的知识。[代理界面展示元数据 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/skills/omem-conversation-analyst/agents/openai.yaml#L1 "支持展示名称和简短用途描述的说明。") 两者共同表达面向用户的入口含义，但中英文表述侧重点不同：前者强调整理对象，后者强调证据链接产物。

<a id="default-invocation"></a>
## 默认调用方式与边界

默认提示要求使用对话分析技能处理所提供的固定材料，表明该文件的作用是为代理界面预填技能调用语句。[默认技能调用提示 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/skills/omem-conversation-analyst/agents/openai.yaml#L4 "支持该配置用于预填固定材料处理提示的论断。") 具体的中文输出、语境保留和引用规则仍由技能正文定义。[技能正文处理规则 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/skills/omem-conversation-analyst/SKILL.md#L6 "说明默认调用所依赖的实际分析职责和固定材料边界来自技能正文。") 当前配置未声明模型、推理强度、工具策略或加载成功状态，因此不能据此推断实际执行环境。
