# 对话材料分析角色的 OpenAI 界面配置

该 YAML 为“整理对话材料”能力声明面向 OpenAI 代理界面的展示与默认调用配置：它提供中文名称、英文简介及引用技能名的默认提示词。材料仅能证明这些静态字段存在，不能单独证明技能实现、运行时注册、模型调用或知识生成流程已经可用。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="interface-metadata"></a>
## 界面元数据与用途

配置在 `interface` 下声明了中文展示名“整理对话材料”，并用英文短描述将其定位为依据固定证据构建关联知识的能力。[界面名称与能力简介 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/skills/omem-conversation-analyst/agents/openai.yaml#L1 "支持附近关于界面展示名、短描述及其配置性质的说明。") 这些字段主要服务于代理或技能选择界面的可读呈现；从本材料只能确认配置意图与文字内容，无法推断前端如何渲染、角色如何注册，也不能把描述中的知识构建能力视作已经完成的实现事实。
