# 证据、知识生成与递归阅读

原始 Capture 修订构成事实底座；知识正文通过固定引用、独立复核和不可变发布组织理解，并借助共享 Evidence Trail 递归阅读。派生正文可以扩大召回，但最终仍返回有效的原始 Fragment。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="evidence_boundary"></a>
## 证据与派生知识的边界

系统排除派生修订，只从当前来源 head 构造知识材料；材料身份摘要覆盖文本、图片、行为者以及引用和转发标志，并以规范化摘要识别这些内容变化。[原始修订到知识材料 ↗](e5a00f71eb3b9c04183300900af72d54d39599d69b8a20785ec7260e4f963a1d.md#material_identity "支持排除派生修订、选择当前来源 head，并界定材料身份摘要覆盖的字段。")[稳定内容摘要 ↗](../../../apps/server/src/storage/digest.ts#L3 "支持对象规范化后计算稳定 SHA-256 摘要。") 正文的章节、内联引用、疑问、类别和引用关系遵循共享合同；产物依赖及生成、复核记录则由同一合同中的 `KnowledgeArtifact` 补充定义。[知识文档合同 ↗](../../../packages/contracts/src/knowledge.ts#L3 "支持章节、引用、疑问、类别和引用关系由统一合同约束。")[知识产物合同 ↗](../../../packages/contracts/src/knowledge.ts#L73 "支持产物依赖以及生成和独立复核记录属于 KnowledgeArtifact。") 子文章可以参与综合，但会被明确标注为带版本的派生理解，不能升级为新的独立证据。[固定材料与派生文章上下文 ↗](../../../apps/server/src/knowledge/pipeline.ts#L30 "支持原始材料必须存在，且子文章被标为派生知识而非独立证据。")

<a id="generation_review"></a>
## 生成、复核与不可变发布

分析角色依图片、会话来源或代码扩展名选择。[分析角色选择规则 ↗](../../../apps/server/src/knowledge/pipeline.ts#L15 "支持依据图片、会话来源和代码扩展名选择分析角色。") 任务固化模型、预算、材料摘要、子文章版本和角色 bundle 身份，并通过持久 worker 执行。[持久化角色执行 ↗](../../../apps/server/src/knowledge/pipeline.ts#L60 "支持任务输入固化模型、预算、材料、文章和 bundle 身份，并由持久 worker 执行。") 模型只选择引用位置，宿主复制固定材料短引文；批次校验要求目标完整且材料引用不得越过获准行段。[宿主绑定固定引文 ↗](../../../apps/server/src/knowledge/repository.ts#L74 "支持模型选择定位后由宿主复制固定材料短引文。")[批次与引用范围校验 ↗](../../../apps/server/src/knowledge/pipeline.ts#L96 "支持目标键完整唯一、文档校验及材料引用不得越过获准行段。")

草稿最多经历四轮写作与独立复核：没有既有反馈时首轮使用指定分析或写作角色，存在历史反馈或前轮被拒后才切换刷新角色定向修订。只有 accepted 文档才携带生成与复核 trace 发布；仓库发布前再次核对依赖，并以事务保存不可变修订、切换当前 head。[写作、复核与定向修订 ↗](../../../apps/server/src/knowledge/pipeline.ts#L113 "支持最多四轮写作与复核，并表明只有存在 repair 时才改用刷新角色。")[不可变正文发布 ↗](../../../apps/server/src/knowledge/repository.ts#L118 "支持发布前复检依赖、事务保存修订、切换 head 并同步疑问状态。") 这替代了“全部轮次都是定向修订”的旧结论。

<a id="recursive_reading"></a>
## 分层关联、阅读与证据召回

主题、模块和文件理解可以引用较低层知识章节；上层综合保留下钻关系及必要的原始依赖，而不把全部来源压平成新事实。[分层综合与来源保留 ↗](../../../apps/server/src/knowledge/pipeline.ts#L217 "支持上层综合保留对子文章的下钻关系及有限原始依赖。") 个人知识页把首页、活动帧和抽屉接入同一帧栈。[个人知识页的共享阅读栈 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L1 "支持首页、活动帧和抽屉共用同一 Trail 状态及导航事件。") 抽屉支持逐层返回、循环跳回、滚动记忆和 Escape 退层；完整关闭或组件卸载时会尝试归还焦点。[Trail 导航行为 ↗](c7842e3898b68e6a6aba8a0bf450c620c4d2331d9b056d0bfce241f79bb9f6cd.md#navigation-behavior "支持 Escape 退层、面包屑回跳、循环处理和滚动记录。")[抽屉焦点生命周期 ↗](../../../packages/ui/src/components/OmTrailDrawer.vue#L35 "支持关闭或卸载时尝试将焦点归还给触发元素或此前焦点。") 助手可先命中派生正文，再校验依赖并沿固定引用递归到与行区间重叠的原始 Fragment，最终候选仍是原始证据。[知识引导的原始证据召回 ↗](c1d016bfceaa9ad6e811622ceb90acc5a8a4c40816edc2c9bb6689fa263f00e1.md#flow "支持校验依赖后递归文章引用，并将材料行区间映射回原始 Fragment。")

<a id="progress_limits"></a>
## 进展、疑问演进与限制

当前功能切片已覆盖正文合同、共用运行时、独立复核、仓库适配、共享阅读和知识引导召回。[通用知识流程进展 ↗](../../../docs/implementation/knowledge-pipeline.md#L5 "支持正文合同、共用运行时、独立复核、仓库适配、共享阅读和知识召回等已完成功能切片。") 新正文不再提出的开放项会标为被替代，已回答或已转待办的记录保留；用户回答保存为新的原始材料，并使相关正文进入待重核对状态，而非直接改写旧证据。[疑问随知识演进 ↗](../../../docs/implementation/knowledge-pipeline.md#L71 "支持开放问题被标为 superseded，并保留已回答或已转待办记录。")[用户回答与正文失效 ↗](../../../apps/server/src/knowledge/repository.ts#L169 "支持用户回答保存为新的原始捕获，并使相关知识等待重新核对。")

现有边界包括：预算使用 UTF-8 字节近似而非模型 tokenizer。[生成预算估算边界 ↗](../../../apps/server/src/agent-runtime/budget.ts#L1 "支持 token 预算由 UTF-8 字节近似并增加余量，而非使用模型专用 tokenizer。") 代码 AST 不解析跨文件类型关系，名称级 calls 只能视为候选。[单文件 AST 解析边界 ↗](../../../apps/server/src/code/parse.ts#L1 "支持解析器不做跨文件类型解析，名称级 calls 标记为候选。") 检索函数自身未实施可见性过滤，且传入 terms 未在函数内统一小写，完整调用链仍需集成验证。[检索调用链待确认边界 ↗](c1d016bfceaa9ad6e811622ceb90acc5a8a4c40816edc2c9bb6689fa263f00e1.md#limits "支持词项大小写处理和可见性过滤仍需调用方与集成测试证明。") Trail 的 200 层常量仅是 URL 持久化预算，渲染和入栈不应静默截断；负责超限提示与刷新恢复的路由层仍待确认。[Trail URL 持久化预算 ↗](../../../packages/ui/src/trail.ts#L37 "支持 200 层只限制 URL 持久化、渲染不受此限，并要求调用者显式提示而非静默丢帧。")
