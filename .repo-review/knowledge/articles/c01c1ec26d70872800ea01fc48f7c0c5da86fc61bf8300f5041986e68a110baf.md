# contracts · 模块理解

contracts 模块以 Zod schema 和 TypeScript 类型统一采集、证据提案、Agent 运行、知识制品及 Code Wiki 投影的跨层数据边界，并提供共享的仓库路径分组规则。它主要描述可校验的数据形状与读取端口，不等同于持久化、语义复核、安全隔离或模型编排已经实现。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-and-background"></a>
## 为什么需要统一合同

`contracts` 是采集端、Agent 运行时、存储适配器、HTTP 层和阅读界面之间的共同语言。采集输入统一容纳文本、图片与 HTTP(S) 链接，并可保留逐部分的参与者、时间、回复、转发及来源属性；Revision 与 Fragment 在此描述进入系统后的数据形状。[采集与证据基础 ↗](439de5f507fee66e8fe835c284be88fb9de9c14a25605109433a2c72974d6580.md#capture-evidence "概括采集合同的多模态输入、逐部分来源信息以及 Revision、Fragment 数据形状。")[多模态采集结构 ↗](../../../packages/contracts/src/index.ts#L1 "支持文本、图片、HTTP(S) 链接、逐部分来源信息以及 Revision 和 Fragment 类型的论述。") 提案合同把作用域、文本或图像证据、不确定项及派生来源组合起来，更新或取代还须携带目标和预期版本，以表达并发修改前提。[证据提案与版本前提 ↗](../../../packages/contracts/src/index.ts#L202 "支持提案使用文本或图像证据、携带作用域与不确定项，并要求更新和取代提供目标及预期版本。") 这些定义减少跨层歧义，但不实现存储不可变性或事务控制。

<a id="knowledge-flow"></a>
## 知识生成与复核如何衔接

知识子模块规定计划、正文、引用、问题和复核结果的交换格式：引用可定位固定材料行号或文章章节，复核合同按文档给出接受或需要修订的结论。[知识批量与复核合同 ↗](22433a027dd13694e08015aaa4fd838ca212c23122a385272abee5a9c26ffaec.md#batch-review-plan "概括知识计划、批量文档和逐文档复核合同之间的结构关系。")[知识正文、引用与复核格式 ↗](../../../packages/contracts/src/knowledge.ts#L3 "支持章节、内联引用、问题、批量结果以及接受或修订结论的具体格式约束。") 制品类型记录直接材料或文章依赖的键与摘要，以及生成和已接受复核的模型、时间与 trace，为追溯提供结构。[知识制品的直接依赖与追踪信息 ↗](../../../packages/contracts/src/knowledge.ts#L66 "支持制品记录直接材料或文章依赖、生成 trace 和已接受复核 trace，同时界定其只是类型结构。") “派生正文不作为新的独立证据”仍是系统层规则，并非该类型自动保证；递归追溯到原始材料、精确引文抽取、语义支持性判断、修订合并和防篡改也需宿主实现。

<a id="cross-module-progress"></a>
## 跨模块关系、现状与边界

路径分组函数让 Wiki 索引与 Vue 阅读器复用同一口径，对 contracts、UI、Agent 运行时、Lark、服务端子目录和脚本作确定性映射，未知路径归入 `other`。[共享路径分组规则 ↗](a73807a7fa14d3e9f2528c36ba0e29ab962e902649656f2eda17a79dde920bc3.md#mapping "概括 Wiki 索引与 Vue 阅读器复用路径分组口径及其顺序敏感的映射规则。")[仓库路径到模块的映射 ↗](../../../packages/contracts/src/code-modules.ts#L1 "支持主要目录、Lark 特例、服务端子目录、脚本及未知路径兜底的实际映射。") Code Knowledge 类型覆盖快照、文件、符号、关系和理解结果，并明确是隔离 review 数据库中的附加读视图，不替代 Source、Revision、Fragment 和关系链。[Code Knowledge 附加投影 ↗](439de5f507fee66e8fe835c284be88fb9de9c14a25605109433a2c72974d6580.md#code-projection "概括代码知识投影与统一材料链之间的关系，并说明其读取边界。")[代码快照、理解状态与读取端口 ↗](../../../packages/contracts/src/index.ts#L884 "支持代码位置仅在快照内有效、投影不替代来源链，以及读取图、理解结果和触发同步的论断。") 角色合同还约束输出 schema、工具、会话和预算，并将可信上下文与材料分字段承载。[角色策略与上下文字段隔离 ↗](../../../packages/contracts/src/index.ts#L672 "支持角色输出、工具、会话和预算约束，以及可信上下文与材料被分字段承载的合同层边界。") 因而当前可确认的是协议骨架；信任隔离、状态映射、引用复核及快照失效处理仍需运行时实现与行为测试证明。
