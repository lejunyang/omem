# 设计原型依赖锁定

该锁文件固定了 omem 设计原型的 React 运行依赖与 esbuild、Playwright 测试工具版本，并记录平台相关可选包、下载源及完整性信息。它能说明依赖解析结果，但不能单独证明构建或浏览器测试已经实际执行成功。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="dependency-baseline"></a>
## 依赖基线

锁文件采用 lockfileVersion 3，并在根包中固定 React、React DOM、Playwright Test 与 esbuild 的精确版本，形成可重复安装的依赖解析基线。[根依赖锁定清单 ↗](../../../docs/prototype/package-lock.json#L1 "支持锁文件格式以及 React、React DOM、Playwright Test 和 esbuild 四项直接依赖均固定到精确版本的论断。") 这些是配置事实，与 package.json 的直接声明相对应，但不能据此推断原型已具备某项产品功能。

<a id="toolchain-and-runtime"></a>
## 工具链与运行约束

Playwright Test 被锁定为 1.58.2，依赖同版本 Playwright，并声明 Node.js 至少为 18；这说明浏览器自动化工具链的安装约束，不代表已有测试覆盖或通过记录。[Playwright 测试工具约束 ↗](../../../docs/prototype/package-lock.json#L459 "支持 Playwright Test 的锁定版本、同版本 Playwright 依赖以及 Node.js 最低版本要求，同时界定其只是安装配置。") esbuild 同样要求 Node.js 至少为 18，并将 AIX、Android、macOS、Linux、BSD、Windows 等操作系统及多种 CPU 架构的二进制包列为可选依赖，以便安装时选择匹配平台。[esbuild 多平台可选依赖 ↗](../../../docs/prototype/package-lock.json#L475 "完整列出 esbuild 的 Node.js 约束及各操作系统、CPU 架构对应的可选包，支持其按目标平台选择二进制依赖的说明。")

<a id="registry-and-limits"></a>
## 来源与证据边界

锁定包的解析地址指向 `bnpm.byted.org`，说明该依赖快照绑定了特定镜像来源；迁移到外部、离线或受限网络环境时，需要确认该地址是否可达。[依赖镜像来源示例 ↗](../../../docs/prototype/package-lock.json#L582 "支持锁定包的解析地址使用 bnpm.byted.org 镜像源这一配置事实及其环境可达性风险。") 锁文件还提供完整性摘要，但没有命令退出码、行为断言或构建产物信息，因此不能声称构建、冒烟测试或浏览器测试已经通过。
