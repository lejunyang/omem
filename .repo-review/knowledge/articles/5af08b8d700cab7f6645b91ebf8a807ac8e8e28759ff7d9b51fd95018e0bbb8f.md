# 阅读体验、变更记录与材料处理状态

这份 2026-10-01 的进展记录说明了知识阅读、引用深链、版本差异、通知、材料处理和 Agent 能力探测的产品行为，并明确若干历史数据与统计边界。文档陈述的最终验证结果仍需结合本轮 verification.json 判断。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="reading_experience"></a>
## 连贯阅读与引用返回

知识库与其他页面共用完整主菜单，原始材料筛选放入页面左栏，小屏则移到正文上方；组件预览只保留设计入口。这种布局以正文阅读为中心，同时保留材料筛选能力。参考 [阅读页面布局 ↗](../../../docs/implementation/reading-and-activity.md#L3 "支持主菜单、材料筛选目录及小屏布局的当前文档陈述。")

段末引用按目标及固定位置去重，但同一目标若在不同段落支撑不同论断，仍可分别出现。共享引用弹窗按层保存滚动位置，并在异步内容改变高度时重试恢复；个人知识弹窗还缓存各层组件和代码展开范围。URL 深链保存阅读路径而不保存滚动位置，因此可分享导航上下文，但不会固化个人浏览进度。参考 [引用与滚动恢复 ↗](../../../docs/implementation/reading-and-activity.md#L5 "解释引用去重规则、分层滚动恢复、组件缓存和深链保存边界。")

<a id="change_and_notifications"></a>
## 版本变化与通知边界

变更历史面向“哪份内容的哪些行或章节发生变化”这一问题：材料比较基于完整固定版本，知识发布记录前后版本及变化章节，前端展示增删和上下文。早期知识记录因缺少版本关联，无法生成可信差异；恢复原始材料也不会改写旧日志，而是创建新版本。参考 [变更历史规则 ↗](../../../docs/implementation/reading-and-activity.md#L9 "支持固定版本比较、知识版本记录、早期历史限制和恢复语义。")

通知则是变化和提醒的收件箱。标记已读只更新阅读状态，不等同于批准判断、完成事项或取消未来提醒；详情仅展示真实存在的差异、证据和外部发送记录，并避免暴露空回执或内部对象标识。参考 [通知状态边界 ↗](../../../docs/implementation/reading-and-activity.md#L11 "说明已读状态不具有批准、完成或取消提醒的业务含义。")

<a id="material_processing"></a>
## 材料处理与能力探测

原“学习流程”被重新命名为“材料处理”，用于表达新材料或来源变化后的知识加工，而非语言学习或记忆卡复习。其阶段关系可概括为：

```mermaid
flowchart LR
  A[新材料或来源变化] --> B[提炼]
  B --> C[独立核验]
  C --> D[受影响记忆复查]
```

页面展示材料名称、后台配置、结果和失败原因；原文已保存并不代表模型处理成功。接口最多返回 200 条，优先展示运行中和待处理项，因此筛选数量不能解释为全队列总数。参考 [材料处理流程 ↗](../../../docs/implementation/reading-and-activity.md#L13 "支持材料处理的阶段、页面信息、返回顺序和原文保存不等于处理成功等限制。")

能力与连接页会在进入页面或切换 Agent 时探测能力，并提供加载、失败和重试状态。该过程只发现能力，不生成知识正文；服务访问令牌也与 Agent、飞书凭据分开说明，文档明确认证机制本身没有改变。参考 [Agent 能力探测 ↗](../../../docs/implementation/reading-and-activity.md#L15 "说明能力探测的触发方式、状态反馈、非生成性质及凭据边界。")
