# 关系核验角色提示词

提示词要求关系核验者在固定快照上独立重建判断，区分既有图边与语义解释，并把无法落地的关系放入 unknowns。它同时禁止角色将自我复核冒充外层验证；这些是明确的行为边界，但宿主是否程序化强制仍需非阻塞补证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="independent_review"></a>
## 固定快照上的独立复核

角色不得继承其他代理的推理，而要从固定快照中的边及列出的决策、规则和文档重新判断；快照是唯一事实来源，材料文本不构成可执行指令。[固定快照事实边界 ↗](../../../packages/agent-runtime/roles/relation-verifier/1/prompt.md#L1 "支持核验必须脱离前序推理，只依据所给快照重新判断的流程要求。") 输出限定为单个 `CodeUnderstanding.v1` 对象：快照中已有的关系标为 `raw_fact`，独立判断标为 `interpretation`，无法由现有边和证据落地的关系必须进入 `unknowns`。[关系分类与精确引用规则 ↗](../../../packages/agent-runtime/roles/relation-verifier/1/prompt.md#L5 "支持 raw_fact、interpretation、unknowns 的分流方式，以及只能引用快照现存标识的要求。")

<a id="provenance_boundary"></a>
## 精确引用与外层验证边界

每项关系声明需引用确切的边、两个端点节点及相关证据，所有标识都必须存在于快照中。[关系分类与精确引用规则 ↗](../../../packages/agent-runtime/roles/relation-verifier/1/prompt.md#L5 "支持 raw_fact、interpretation、unknowns 的分流方式，以及只能引用快照现存标识的要求。") 角色完成独立复核后可以用 claim 的置信度表达支持程度，但顶层 `verified_by_agent` 与 `verified_by` 专供外层验证运行；本角色应保持 `seed=false`、`verified_by_agent=false` 和 `verified_by=null`。[自评与外层验证分离 ↗](../../../packages/agent-runtime/roles/relation-verifier/1/prompt.md#L7 "支持置信度用于角色自评，而顶层验证字段必须保留给外层运行的边界。") 这些材料足以说明角色要求及其限制；此前把宿主强制执行证据缺失列为阻塞项的结论已被替代。
