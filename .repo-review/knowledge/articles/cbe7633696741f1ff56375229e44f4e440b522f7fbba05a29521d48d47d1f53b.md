# omem Extract 的 OpenAI 代理界面配置

该 YAML 为 omem Extract 声明面向代理宿主的展示名称、简短说明和默认提示词。它表达“从固定证据中提取限定范围的记忆候选”的角色意图，但仅凭配置不能证明技能加载、证据约束或提取流程已经在运行时实现并通过验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="interface-purpose"></a>
## 界面身份与职责定位

文件以 `interface` 节点声明代理界面，并将其展示名称设为“omem Extract”。简短说明把职责限定为：依据固定证据提取具有明确范围的记忆候选。[omem Extract 界面声明 ↗](../../../packages/agent-runtime/roles/extractor/1/skills/omem-extract/agents/openai.yaml#L1 "支持展示名称以及从固定证据提取限定范围记忆候选的职责描述。") 这体现的是面向宿主或用户的能力描述，强调候选内容应受证据边界约束；它不是提取算法、数据结构或验证结果本身，也不能单独作为该能力已实现的证据。

<a id="default-invocation"></a>
## 默认调用提示
