# 证据阅读器：可追溯浏览、关联与上下文追问

该组件以栈式对话框组织证据阅读：按片段加载证据及版本信息，在引用片段、完整材料和反向引用之间切换，并支持沿引用继续深入、恢复滚动位置、手动建立关系以及围绕当前证据路径追问。它依赖通用 UI、证据 API、ChatPane 和 AssetImage；并发加载、循环引用和请求错误受到显式处理，但关系目标仍需用户输入内部片段 ID，且现有材料没有提供对应测试。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-model"></a>
## 解决的问题与状态模型

组件把片段、来源版本和引用关系组合成可连续下钻的证据阅读界面。每个 `Frame` 保存证据、当前标签页、追问开关和滚动位置，`current` 始终指向栈顶，因此阅读路径是一段可以返回和截断的导航历史。[证据阅读帧状态 ↗](../../../apps/web/src/EvidenceReader.vue#L7 "支持组件以帧栈保存证据、标签页、追问状态和滚动位置的说明。") 后端返回的 `Evidence` 同时包含片段、所属修订、出向引用与反向引用，为引用片段、完整材料和反向引用等视角提供数据基础。[证据数据结构 ↗](../../../apps/web/src/api.ts#L18 "说明 Evidence 数据由片段、修订、出向关系和反向关系组成。")

<a id="navigation-and-relations"></a>
## 导航、阅读与关系创建

打开片段时，组件用 `loading` 阻止重叠加载；若目标已在栈中，则记录既有层级并提示回跳，不再压入重复帧。加载新证据前会保存当前滚动位置，入栈后滚到顶部；返回上一层时再恢复先前位置，请求异常则显示为界面错误。[片段打开与返回流程 ↗](../../../apps/web/src/EvidenceReader.vue#L16 "支持并发保护、循环检测、证据加载、滚动保存恢复及错误处理的流程说明。") 路径按钮可以直接截断到任意既有层，循环提示也提供“回到该层”的明确操作。[路径与循环提示 ↗](../../../apps/web/src/EvidenceReader.vue#L75 "支持路径截断、循环提示以及回到既有阅读层的交互说明。")

阅读区可在引用片段、完整材料和反向引用之间切换，并允许沿出向或反向关系继续打开证据；界面明确说明引用关系本身不自动代表支持度判断。[阅读标签与引用入口 ↗](../../../apps/web/src/EvidenceReader.vue#L104 "支持三种阅读视角、沿关系打开证据及不自动判定支持度的边界说明。") 用户还可把目标片段 ID 提交到 `/relations`，成功后刷新当前证据、清空输入并发出保存事件。客户端在此处只检查输入非空，没有校验目标格式或目标是否存在；失败信息由请求异常转为页面错误。[手动建立片段关系 ↗](../../../apps/web/src/EvidenceReader.vue#L48 "支持非空检查、关系提交、当前证据刷新、输入清理、保存通知和错误展示的描述，也表明客户端未进行其他目标校验。")

<a id="module-connections"></a>
## 模块协作与实现限制

组件复用 `OmDialog`、按钮、引用、徽标和图标等通用 UI，并组合 `ChatPane` 与 `AssetImage`。[通用界面与子组件依赖 ↗](../../../apps/web/src/EvidenceReader.vue#L2 "说明 EvidenceReader 复用通用 UI 组件，并组合 ChatPane 与 AssetImage。") `open` 方法通过 `defineExpose` 公开，使父组件能够从外部启动指定片段的阅读。[公开片段打开入口 ↗](../../../apps/web/src/EvidenceReader.vue#L64 "直接支持组件通过 defineExpose 向父组件公开 open 方法的论断。") 完整材料中的图片交由 `AssetImage` 获取；后者携带请求头读取二进制资源，并在资源切换或组件卸载时取消旧请求、释放对象 URL。[图片资源加载与清理 ↗](../../../apps/web/src/AssetImage.vue#L7 "支持图片请求、取消过期加载、错误处理及对象 URL 回收的模块协作说明。")

追问侧栏由 `ChatPane` 执行运行创建和轮询：它以焦点片段 ID 发起请求，并仅在用户选择路径范围时附带 `pathIds`。[追问运行与路径参数 ↗](../../../apps/web/src/ChatPane.vue#L33 "说明 ChatPane 使用焦点片段创建运行任务、按范围附带路径 ID，并轮询运行结果。") EvidenceReader 将当前帧片段作为焦点，同时把当前 `frames` 中全部片段 ID 映射为路径上下文，因此追问可在单片段与整条阅读路径之间切换。[焦点片段与完整帧路径绑定 ↗](../../../apps/web/src/EvidenceReader.vue#L161 "直接支持 EvidenceReader 将当前帧作为焦点并把全部帧片段映射为追问路径上下文的论断。") 当前滚动记忆直接查询 `.om-dialog .dialog-scroll`；若对话框内部 DOM 或类名改变，保存与恢复可能失效。[滚动容器选择器依赖 ↗](../../../apps/web/src/EvidenceReader.vue#L27 "支持滚动保存与恢复依赖特定对话框 DOM 选择器的实现限制。") 现有材料也未包含组件级或浏览器级测试，相关交互是否受到自动化验证仍待确认。
