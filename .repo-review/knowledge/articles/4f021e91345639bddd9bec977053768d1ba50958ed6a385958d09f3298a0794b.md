# 知识 API 的证据与操作回归测试

以手工材料贯穿文章读取、引用解析、历史修订、问题转任务、无模型错误及历史图片资产访问，验证 API 的关键组合行为。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="article-citation"></a>
## 文章、引用与历史文本

测试构造含行内引用和调查问题的知识文档，绑定固定原文并发布；文章 API 必须返回可操作的引用及人读标签、理由，citation API 则解析到带固定摘要的材料。[文章与引用 API 断言 ↗](../../../apps/server/tests/knowledge-api.test.ts#L11 "支持文章引用可操作字段及 citation 解析到固定材料摘要的说明。") 当同一外部材料产生新 head 后，携带旧摘要读取材料仍应返回原文本且标记为非当前，证明引用可以回看不可变历史修订。[旧材料修订读取 ↗](../../../apps/server/tests/knowledge-api.test.ts#L23 "支持材料更新后仍能按旧摘要取回原始文本和非当前状态。")

<a id="actions-model"></a>
## 问题动作与模型缺失

问题列表中的条目可通过 task 端点生成任务，并且 Store 中确实只出现相应任务；未配置分析模型时，分析端点返回 503，而不是伪造成功。[任务创建与无模型响应 ↗](../../../apps/server/tests/knowledge-api.test.ts#L26 "支持问题转任务的持久化断言和未配置模型返回 503。") 这同时覆盖了读 API 和两类写操作，但没有断言无效问题 ID、重复请求、权限或并发行为。

<a id="assets-limits"></a>
## 历史图片与未覆盖边界

测试先捕获 PNG，再以文本新修订替代同一材料，随后按旧 asset id 请求仍返回 200 和 `image/png`，说明历史图片不随 source head 更新而失去访问能力。[历史图片资产访问 ↗](../../../apps/server/tests/knowledge-api.test.ts#L31 "支持图片被新修订替代后，旧资产仍可按 id 获取的行为。") 用例只检查内容类型和状态码，没有核对响应字节、缓存头、未知资产、超大资产或非图片资产的错误处理。
