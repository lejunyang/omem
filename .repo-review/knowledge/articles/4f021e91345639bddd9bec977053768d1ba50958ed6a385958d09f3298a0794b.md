# 知识 API 的引用、历史材料与操作测试

验证手工材料形成的文章能够通过同一 API 暴露可操作引用和疑问，并保持固定修订、历史图像及无模型错误语义。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="article-citation"></a>
## 文章、引用与固定修订

测试捕获一份手工发布计划，构造带行内引用和明确疑问的知识文档，经绑定原文及已接受复核后发布。文章接口必须返回可操作、带人读标签和理由的引用，引用解析接口还要定位到材料的固定摘要。[文章引用 API 行为 ↗](../../../apps/server/tests/knowledge-api.test.ts#L11 "支持已复核文章发布、引用的人读字段以及固定材料摘要解析。") 当同一外部来源产生新修订后，带旧摘要读取仍返回原始文本，并标记其不再是当前版本，证明引用没有漂移到新内容。[旧材料修订读取 ↗](../../../apps/server/tests/knowledge-api.test.ts#L23 "支持来源更新后仍可按旧摘要读取原始文本，并识别为非当前版本。")

<a id="actions-assets"></a>
## 疑问操作、缺少模型与历史资产

疑问列表中的条目可显式转成任务，并实际写入任务存储；未配置模型时，请求分析返回 503，而不是假装完成。[疑问转任务与无模型响应 ↗](../../../apps/server/tests/knowledge-api.test.ts#L26 "支持显式问题操作创建任务，以及未配置模型时分析接口返回服务不可用。") 测试还先保存图像、再以文本替换同一来源，旧资产仍能按资产标识读取并保持 PNG 内容类型，说明历史修订的二进制证据仍可访问。[历史图像资产访问 ↗](../../../apps/server/tests/knowledge-api.test.ts#L31 "支持图像来源被新修订替代后，旧资产仍可读取并保留正确媒体类型。")
