# 知识 API 的固定引用与历史证据集成测试

该测试以临时 SQLite 存储和真实 Fastify 路由串联手工捕获、知识发布、固定引用解析、历史材料读取、问题转任务、缺少模型配置以及历史图片访问，验证知识 API 的关键证据可追溯行为；同时未覆盖错误引用、模型成功运行和权限并发等场景。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 测试目标与装配方式

测试在临时目录中创建 `Store` 和 Fastify 实例，并注册知识路由，因而验证的是服务器组件之间的真实集成，而非纯协议夹具。它先捕获一条手工“发布计划”，再以该材料的稳定键和摘要发布带内联引用、问题及独立复核元数据的知识文档。[测试装配与知识发布 ↗](../../../apps/server/tests/knowledge-api.test.ts#L11 "支持临时存储、真实路由、手工材料捕获以及带引用和复核信息的知识发布流程。") 用例无论成功或异常都会关闭应用与存储连接，并递归清理临时目录，补足测试资源的生命周期边界。[测试资源清理 ↗](../../../apps/server/tests/knowledge-api.test.ts#L37 "支持用例结束时关闭 Fastify 与 Store，并递归清理临时目录的生命周期陈述。") `Store` 初始化会建立 SQLite、执行迁移并创建受限权限的资源目录，说明本用例运行在当前单用户持久化基础上。[Store 初始化基础 ↗](../../../apps/server/src/store.ts#L38 "解释测试所用存储会建立 SQLite、执行迁移并创建资源目录，界定其单用户持久化背景。")

<a id="asserted-flow"></a>
## 已断言的核心流程

发布后，文章读取接口必须返回可操作且具有人读标签、理由的引用；引用解析接口还必须落到固定材料摘要，而不是仅指向当前 source head。随后同一外部来源被新版本覆盖，测试仍按旧摘要读取原文，并断言其 `current=false`，证明历史证据可回溯。[固定引用与历史材料断言 ↗](../../../apps/server/tests/knowledge-api.test.ts#L19 "支持文章引用可操作、引用解析到固定摘要，以及更新后仍能读取旧材料并标记为非当前版本。") 该行为对应 API 按文章依赖摘要解析材料、同时返回当前性标志的实现。[API 的摘要固定解析 ↗](../../../apps/server/src/knowledge/api.ts#L20 "解释文章与引用接口如何依据依赖摘要解析固定材料，并返回可操作性、解析目标和当前性状态。") 测试还读取知识问题并通过专用接口创建任务，确认响应包含任务标识且存储中实际新增一项；未配置模型时，分析入口必须返回 503，而非伪造生成结果。[问题转任务与缺少模型 ↗](../../../apps/server/tests/knowledge-api.test.ts#L26 "支持问题可以显式创建任务，以及未配置模型时分析请求返回 503 的断言。")

<a id="boundaries"></a>
## 图片历史与未覆盖边界

用例进一步捕获一张 PNG，保存其资源标识后再以文本修订替换同一来源；旧资源仍应返回 200 且保持 `image/png`，验证图片资产不会因 source head 更新而失去访问能力。[历史图片资产访问 ↗](../../../apps/server/tests/knowledge-api.test.ts#L31 "支持来源更新后旧图片资产仍可读取且 MIME 类型正确的行为。") 不过测试只覆盖成功发布与解析路径：没有断言不存在的文章或引用是否返回 404、依赖摘要缺失时是否变为不可操作，也没有覆盖模型配置有效时的实际分析、任务重复创建、并发更新或访问控制。材料构造中调用了引用绑定函数，但所给仓库片段未展示其实现，因此这里只能确认测试使用了宿主绑定后的文档，不能据此说明其具体截取算法。[引用绑定调用边界 ↗](../../../apps/server/tests/knowledge-api.test.ts#L17 "表明测试确实调用引用绑定并发布结果，但当前提供的行段没有该函数实现，支持对分析确定性边界的说明。")
