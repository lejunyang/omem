# 知识 API 的固定证据与问题行动集成测试

该测试以临时 SQLite 存储和 Fastify 注入请求贯通知识发布、固定版本引用、历史材料读取、问题转任务、模型缺失及历史图片访问，验证同一 API 能同时提供可追溯证据和明确行动入口。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决的问题与测试范围

该测试针对一个关键风险：知识正文虽然引用了原始材料，但材料更新后引用可能漂移，问题项也可能无法进入实际任务流程。它创建临时 `Store`、注册知识路由，并捕获一份人工发布计划作为原始材料，形成完全隔离的端到端测试环境。[临时存储与知识路由初始化 ↗](../../../apps/server/tests/knowledge-api.test.ts#L11 "支持测试以隔离存储、Fastify 实例和人工捕获材料建立端到端环境的说明。") 随后构造带内联引用和待确认责任人的知识文档，经固定 quote、依赖摘要、生成记录及独立复核记录发布，说明被测对象不是单一路由，而是“捕获—发布—读取—行动”的组合合同。[知识文档发布与复核记录 ↗](../../../apps/server/tests/knowledge-api.test.ts#L17 "支持文档包含内联引用、问题项、固定依赖以及生成和复核元数据的论断。")

<a id="flow"></a>
## 核心断言与模块关系

读取文章时，测试断言引用包含可操作标记、人类可读标签和引用理由；再调用 citation 路由，确认引用解析回带原材料 digest 的固定版本。[文章引用与固定版本解析断言 ↗](../../../apps/server/tests/knowledge-api.test.ts#L19 "支持文章读取结果保留可操作标签，并能通过引用接口解析到材料摘要的说明。") 这与 API 中依据文章 dependencies 查找材料版本、返回 `actionable/current/resolved` 的流程一致：引用能否跳转取决于固定依赖是否仍可解析，而不是仅凭当前材料键。[API 的引用依赖解析流程 ↗](../../../apps/server/src/knowledge/api.ts#L20 "解释引用为何依赖发布时记录的固定版本，并如何生成 actionable、current 与 resolved 状态。")

测试随后用相同 externalId 写入新版本并刷新仓库，再按旧 digest 请求原材料，断言仍返回旧文本且 `current=false`，直接覆盖“历史证据可读但已非最新”的语义。[旧摘要材料读取断言 ↗](../../../apps/server/tests/knowledge-api.test.ts#L23 "支持材料更新后仍可按旧 digest 读取原文且标记为非当前版本的论断。") 对知识问题，则先从问题列表取得条目，再 POST 创建任务，并同时检查响应存在 taskId、Store 中确有一个任务，验证接口结果与持久状态一致。[问题转任务持久化断言 ↗](../../../apps/server/tests/knowledge-api.test.ts#L26 "支持问题操作既返回任务标识又实际写入 Store 的说明。")

<a id="boundaries"></a>
## 边界条件与未覆盖行为

测试明确覆盖两项降级行为：未配置模型时分析接口返回 503；图片材料被文本新版本替代后，旧 assetId 仍可读取，并保持 `image/png` 内容类型。[无模型与历史图片边界断言 ↗](../../../apps/server/tests/knowledge-api.test.ts#L29 "支持分析接口缺少模型时返回 503，以及被新版本替代的历史图片仍可访问并保持媒体类型的说明。") 这证明生成能力不可用不会伪装成功，同时历史二进制证据不因 source head 前移而消失。

其边界也很清楚：全文件只有一个综合用例，主要验证成功路径和一个无模型状态；没有断言文章、引用、材料或图片不存在时的 404，也没有覆盖缺失依赖导致 `actionable=false` 的响应。API 源码确实定义了引用不存在和固定材料不可用的 404 分支，但本测试未触发它们。[引用和材料不存在的 API 分支 ↗](../../../apps/server/src/knowledge/api.ts#L41 "证明实现包含引用不存在与固定材料不可用的 404 分支，从而界定当前测试尚未覆盖的行为。") 此外，测试使用 fixture 模型元数据直接发布已接受文章，并不证明真实 Agent CLI、生成器或独立复核模型能够运行。
