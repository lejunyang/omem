# 知识 API 的引用、疑问与历史材料测试

以真实 Fastify 路由和临时存储验证内联引用解析、历史 revision 读取、问题转任务、无模型错误以及历史图像资产保留。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="citation-contract"></a>
## 文章与引用合同

测试从手动发布计划构造带内联引用和明确疑问的知识文档，经引用绑定后发布。文章接口必须返回可操作、具有人读标签和理由的引用；引用解析接口还必须定位到固定材料及其摘要，验证正文展示与底层证据目标使用同一合同。[内联引用 API 验证 ↗](../../../apps/server/tests/knowledge-api.test.ts#L11 "支持文章引用的人读字段、可操作状态及固定材料解析行为。")

<a id="history-and-actions"></a>
## 历史证据与问题动作

当同一手动来源捕获新版本并刷新仓库后，旧摘要仍可读取原始文本，但会标记为非当前版本。知识疑问可显式转换为任务并进入任务列表；在没有配置模型时，请求分析返回 503，而不是伪造分析结果或静默成功。[历史材料与问题任务验证 ↗](../../../apps/server/tests/knowledge-api.test.ts#L23 "支持旧 revision 读取、问题转任务以及未配置模型时返回 503 的断言。")

<a id="historical-assets"></a>
## 历史图像资产保留

测试先捕获 PNG 图像并记录其资产标识，再用文本 revision 替代同一来源。即使图像已不再是当前版本，历史资产接口仍返回成功且保持图像 MIME 类型，说明固定引用所需的旧二进制证据不会随 head 更新而消失。[历史图像资产验证 ↗](../../../apps/server/tests/knowledge-api.test.ts#L31 "支持来源被新 revision 替代后，旧图像资产仍可按原 MIME 类型读取。")
