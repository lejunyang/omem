# 浏览器端到端验收范围与证据边界

该记录描述了 2026-10-01 在指定 Chromium 版本上完成的一组浏览器验收场景，覆盖捕获、证据阅读、助手跟进、授权、响应式布局、故障呈现与富文本渲染。后端为真实 Fastify 与 SQLite，但智能体使用确定性 ACP 协议夹具，因此它能证明界面和应用流程在受控响应下可运行，不能单独证明真实外部 Agent CLI 或模型调用成功。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 这份记录验证什么

这是一份浏览器验收结果快照，记录日期为 2026-10-01，并明确了执行时使用的浏览器版本。它适合回答“哪些用户场景曾在浏览器中走通过”，但不是持续集成报告，也不能据此推断其他浏览器或后续代码版本仍然通过。参考 [验收日期与浏览器版本 ↗](../../../docs/implementation/browser-verification.json#L2 "支持该记录是特定日期、特定浏览器版本下的历史验收快照。")

<a id="coverage"></a>
## 覆盖的用户流程

验收从空工作区与材料捕获开始，继续覆盖提案应用、通知和递归证据阅读，以及版本更新时保留不可变旧修订。日常助手部分检查了无选中片段时的持久会话，并验证等待、稍后提醒、取消等跟进控制。范围还包括决策差异与过期状态、二维码和授权链接、页面重载、桌面及移动布局、键盘焦点、大量证据节点下的受限渲染，以及 Markdown 表格和 Mermaid 图表的真实阅读器呈现。参考 [浏览器验收场景 ↗](../../../docs/implementation/browser-verification.json#L5 "支持正文对捕获、证据、助手跟进、授权、响应式布局、故障状态和富文本渲染等覆盖范围的概括。")

<a id="evidence-boundary"></a>
## 实现事实与证明边界

记录声明执行时没有错误，后端使用真实 Fastify 与 SQLite，因此可视为应用服务器、持久化和浏览器界面协同工作的历史证据。不过智能体一侧采用的是**确定性 ACP 协议夹具**：这能稳定验证协议消费和界面行为，却不能替代真实 Agent CLI、模型能力发现、网络异常或供应商兼容性的现场检查。`errors` 为空也只表示本次记录未发现错误，不代表所有环境均无缺陷。参考 [执行结果与运行组件 ↗](../../../docs/implementation/browser-verification.json#L21 "支持本次记录无错误、后端采用真实 Fastify 与 SQLite，同时智能体使用确定性 ACP 协议夹具的证据边界。")
