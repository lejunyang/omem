# 对话分析角色的运行配置

该清单定义 conversation-analyst 第 1 版所使用的运行配置、提示词、内联技能、结构化输出格式、隔离策略和资源预算。它是宿主加载角色时的配置合同；仅凭此文件不能确认各项约束已被运行时执行或验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 角色入口与结构化产出

清单将角色标识为 `conversation-analyst` 第 1 版，指定使用 `traex` 配置并加载 `prompt.md`。这里能够确认的是角色名称和启动配置，具体如何分析对话、怎样形成知识结论，仍取决于未在本材料中展开的提示词与技能内容。参考 [角色启动配置 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/manifest.json#L2 "支持角色标识、版本、运行配置引用和提示词模板的说明。")

角色的输出被声明为 `KnowledgeBatch.v1`，意味着宿主期望收到符合该合同的结构化结果；这项声明本身并不能证明某次输出已经通过校验或独立复核。参考 [结构化输出合同 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/manifest.json#L17 "直接支持角色输出被声明为 KnowledgeBatch.v1 的论断。")

<a id="isolation"></a>
## 技能绑定与会话隔离

角色以内联方式绑定 `omem-conversation-analyst` 第 1 版技能，并记录对应制品摘要，从配置层面明确了预期加载的技能版本。清单没有说明摘要由哪个组件校验，也没有给出摘要不一致时的处置行为。参考 [内联技能绑定 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/manifest.json#L9 "支持技能名称、版本、内联加载方式和制品摘要的说明。")

执行期间不允许调用工具；会话不复用，也不继承用户技能或 MCP。因而该角色被配置为只处理宿主已注入的上下文，避免借助外部工具或沿用用户环境中的扩展能力。参考 [工具与会话隔离 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/manifest.json#L18 "支持禁用工具、不复用会话以及不继承用户技能和 MCP 的边界说明。")

<a id="budget"></a>
## 上下文、输出与修复上限

单次运行最多可使用 96,000 个上下文 token，并允许生成至多 24,000 个输出 token；结构化结果的修复尝试上限为 2 次。这些数值规定了运行资源与自动修复边界，但没有描述预算超限或两次修复仍失败后的持久化、重试和人工介入流程。参考 [角色资源预算 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/manifest.json#L27 "支持上下文、输出和自动修复尝试上限的说明。")
