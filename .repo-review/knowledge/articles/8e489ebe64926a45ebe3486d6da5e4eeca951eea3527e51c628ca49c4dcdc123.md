# 对话分析角色运行清单

该清单声明第一版对话分析角色及其提示模板、内联技能、输出合同、工具与会话策略和预算。与代码分析清单对照可确认两者共享运行轮廓，但使用不同角色标识、技能名称和制品摘要；清单本身不证明运行时已经强制执行这些配置。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-contract"></a>
## 角色身份与结构化输出

对话分析清单声明第一版 `conversation-analyst`，使用 `traex` profile、`prompt.md`、第一版内联对话分析技能，并把输出指定为 `KnowledgeBatch.v1`。[对话分析角色与技能配置 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/manifest.json#L2 "支持对话角色版本、profile、提示模板、内联技能名称、制品摘要和输出合同的说明。") 代码分析清单声明相同 profile 和输出合同，但角色标识、技能名称及制品摘要不同。[代码分析角色与技能配置 ↗](../../../packages/agent-runtime/roles/code-analyst/1/manifest.json#L2 "为跨清单比较提供代码分析侧依据，支持共享 profile 和输出合同、但角色与技能制品不同的论断。")

由此只能确认两份配置在结构化输出层面的对称性，以及各自绑定了不同技能制品；现有材料没有给出对话分析的 prompt 或技能正文，不能据此确认参与者识别、转发、回复关系或隐私处理逻辑。

<a id="runtime-policy"></a>
## 隔离策略与预算对照

对话分析角色禁用工具、不复用会话，也不继承用户技能或 MCP。[对话分析隔离策略 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/manifest.json#L18 "支持对话分析角色无工具、会话不复用且不继承用户扩展能力的配置描述。") 代码分析角色声明了相同的工具和会话隔离参数。[代码分析隔离策略 ↗](../../../packages/agent-runtime/roles/code-analyst/1/manifest.json#L18 "为隔离策略的跨角色对照提供代码分析清单中的直接依据。") 两者的上下文、输出及修复预算也分别同为 96000、24000 和 2：对话侧配置如此声明，[对话分析运行预算 ↗](../../../packages/agent-runtime/roles/conversation-analyst/1/manifest.json#L27 "支持对话分析角色的上下文、输出 token 和修复次数上限。") 代码侧配置提供了对应依据。[代码分析运行预算 ↗](../../../packages/agent-runtime/roles/code-analyst/1/manifest.json#L27 "为两类角色预算相同的比较提供代码分析侧直接依据。")

这些均是清单中的配置陈述，并非实际执行记录；材料没有证明运行时已强制隔离，也没有提供指标说明统一预算是否适合两类材料。
