# 文件源码、符号与关系下探视图

FileFrame 汇集仓库文件的原始源码、解析或模型理解、符号大纲和关系边，并通过 drill 事件请求文件、符号或片段导航。源码是主加载路径，辅助数据可独立降级；关系能否下探及其原因展示由组件解析结果和共享辅助函数共同决定。旧稿把理解面板概括为纯确定性统计并过度推断全部目标状态的结论，已按实际界面行为收窄。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-loading"></a>
## 作用与数据装载

组件接收文件、可选锚点及文件和符号映射，并定义文件、符号、原文片段三类 `drill` 事件；它负责发出导航请求，但现有材料没有展示上层如何维护阅读轨迹。[文件帧输入与下探事件合同 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L32 "支持组件输入以及文件、符号、原文片段三类 drill 事件，并限定材料未展示上层轨迹管理。") 挂载或 `fileId` 改变时，组件并行读取完整源码、符号、关系边和文件理解。源码请求失败会进入错误状态并允许重试；另外三项各自捕获异常并降级为空结果，因此辅助数据故障不必然阻断源码阅读。[并行加载与独立降级 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L56 "支持源码主请求、辅助请求分别降级、错误记录及加载状态收束的流程。")

<a id="source-and-symbol-flow"></a>
## 理解面板、原文与符号导航

界面以“派生说明（确定性解析）”和“来自解析器，非模型摘要”标记理解面板，并与“仓库当前快照原文，不可变”的源码区域分区呈现；这是可确认的界面标签与布局行为，不足以证明所有 understanding 内容本质上都只来自确定性解析。面板展示语言、符号数、import 数和未决项；若 `understanding.model` 存在，还显示模型名称与置信度，仅在模型不存在时提示“未配置模型 · 无 AI 摘要”。这替代了旧稿“理解数据只展示解析统计和未决项”的结论。[理解面板与原文状态呈现 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L217 "支持理解面板的解析统计、未决项、可选模型与置信度显示、无模型提示，以及原文区域的独立状态标签。") 符号经 `outlineSymbols` 转为代码范围标记和大纲。代码导航仅在行号命中某个符号起始行时下探；点击符号会更新锚点并发出包含文件、符号和行号的事件，即使该符号没有 fragment 也不会静默无响应。[符号范围与固定下探 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L90 "支持符号范围生成、起始行命中以及即使没有 fragment 仍发出符号下探事件的行为。")

<a id="edge-resolution-boundaries"></a>
## 关系解析与展示边界

关系边先经 `edgeDrillTarget` 解析，再由映射补充目标文件和符号名称；组件以解析结果是否为 `none` 判断可解析性，并以来源文件等于当前文件或来源符号为空来推断出边。[关系目标与方向解析 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L116 "支持组件调用共享辅助函数解析目标，并在本地计算可解析性、目标名称和关系方向。") 目标标签依次回退到展示标题、符号名、文件标签、摘要、证据或“未解析”；因此只能确认组件级回退，不能据此断言所有外部、缺失或过期目标都具备完整的人类可读原因。[关系目标标签回退规则 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L141 "支持目标显示文本依次使用展示标题、符号名、文件标签、摘要、证据或未解析占位的限定说明。") 按钮仅在目标可解析且 `edgeDisabled` 未禁用时可点击，禁用原因来自 `edgeReason` 或“不可下探”。可下探关系最多渲染 60 条，其他关系最多 20 条，所以该视图不能视为完整关系清单。[关系按钮禁用与展示上限 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L256 "支持关系按钮的组件级禁用条件、原因展示，以及可下探边和其他边分别存在 60 条与 20 条渲染上限。") FileFrame 的请求函数与 DTO 来自 `review-api`，标签、符号轮廓和边解析逻辑来自 `modules.ts`。[FileFrame 的 API 与辅助函数依赖 ↗](../../../apps/web/src/codewiki/FileFrame.vue#L20 "支持 FileFrame 从 review-api 引入请求函数和 DTO，并从 modules.ts 引入标签、轮廓、边解析与禁用辅助函数。") 后者明确保持无 Vue 和 DOM 依赖，便于纯函数单测，但材料没有提供 FileFrame 自身的组件或浏览器测试证据。[无界面依赖的纯辅助模块 ↗](../../../apps/web/src/codewiki/modules.ts#L1 "支持 modules.ts 被定位为无 Vue 和 DOM 依赖、便于独立单测的纯辅助模块。")
