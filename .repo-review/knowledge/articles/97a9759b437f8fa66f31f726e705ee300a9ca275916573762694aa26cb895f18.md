# 通用内容面板与插槽布局

OmPanel 是一个轻量的 Vue 3 结构组件，以统一容器组合可选页头、默认内容和可选操作区。页头由真值 title 或 heading 插槽触发，页脚由 actions 插槽触发；边框、背景和圆角依赖外部提供的 CSS 自定义属性。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-structure"></a>
## 内容区域的基础结构

OmPanel 将内容组织在一个带有 `om-panel` 类名的 `section` 中。默认插槽始终位于主体位置；页头和页脚则根据调用方传入的属性或插槽按需创建。因此，它提供的是通用的标题、正文与操作区结构，具体承载何种业务内容由使用方决定。参考 [面板基础结构 ↗](../../../packages/ui/src/components/OmPanel.vue#L4 "支持组件以 section 包裹默认内容，并按条件提供页头和操作区的结构描述。")

<a id="rendering-flow"></a>
## 标题、正文与操作区的组合规则

组件只声明一个可选的字符串属性 `title`。当 `title` 为真值或存在 `heading` 插槽时，页头会被渲染；真值 `title` 显示为 `h3`，命名插槽 `heading` 紧随其后，因此两者同时提供时会同时出现。默认插槽不受这些条件影响。只有存在 `actions` 插槽时才会生成页脚，未提供操作内容时不会留下空页脚。参考 [属性与插槽渲染规则 ↗](../../../packages/ui/src/components/OmPanel.vue#L1 "支持 title 属性的类型，以及 title、heading、默认插槽和 actions 插槽各自的渲染条件。")

<a id="visual-boundaries"></a>
## 布局样式与主题依赖

面板具有 24 像素内边距。页头使用横向弹性布局、垂直居中和 12 像素间距，并与正文保持 16 像素距离；标题字号为 16 像素。页脚同样采用弹性布局，操作项间距为 8 像素，允许换行，并与正文保持 20 像素距离。边框、背景和圆角分别读取 `--om-line`、`--om-panel` 与 `--om-radius`，组件内未设置回退值；仅凭当前文件无法确认这些变量由何处声明。参考 [面板布局样式 ↗](../../../packages/ui/src/components/OmPanel.vue#L15 "支持面板、页头、标题和页脚的尺寸与布局规则，并表明三个主题变量没有组件内回退值。")
