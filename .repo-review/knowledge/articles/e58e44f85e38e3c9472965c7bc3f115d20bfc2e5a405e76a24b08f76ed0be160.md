# 代码图的人类可读 DTO 投影

在保留内部动作键的同时，为快照、文件、符号和边补充稳定的人类展示字段、引用标签、深链及不可操作原因，隔离数据库实体与界面文案。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="projection"></a>
## 投影职责

该模块面向前端投影代码图实体：原始对象通过展开保留 `fileId`、`symbolId`、端点等路由所需字段，另外增加 `displayTitle`、`displayPath`、`citationLabel`、`actionable` 和 `reason`，避免把内部 ID 当作可见标签。快照以短提交号展示；无提交时区分脏工作树与无提交状态。[DTO 展示字段约定 ↗](../../../apps/server/src/code/dto.ts#L1 "支持保留内部动作键、同时增加人类可读字段且不显示内部 ID 的核心职责。") 文件标题取路径末段，但完整路径仍用于展示位置与引用。[文件 DTO ↗](../../../apps/server/src/code/dto.ts#L35 "支持文件标题、路径、版本、可操作状态和深链的投影方式。")

<a id="symbols_edges"></a>
## 符号、边与失效状态

符号标题对 route/test 使用名称，其余使用限定名；若有关联文件，源码深链会携带声明起止行，否则退回符号接口。[符号 DTO ↗](../../../apps/server/src/code/dto.ts#L54 "说明符号的人类标签、源码范围链接与无文件时的回退链接。") 边标题把端点的人类标签与关系词组合起来，`confirmed` 和 `candidate` 可操作，`missing`、`stale` 则给出明确原因并禁止动作。未知边类型会直接显示原始 kind，因此新增关系不会丢失，但可能缺少友好翻译。[边 DTO 与状态原因 ↗](../../../apps/server/src/code/dto.ts#L78 "支持边关系文案、可操作状态及 missing/stale 原因的论断。")
