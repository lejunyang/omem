# 代码图谱的用户可见 DTO 投影

该模块把代码快照、文件、符号和关系边投影为前端可用对象：保留内部操作字段，补充人类可读标签、引用信息、深链及状态说明。文件仅在 removed 时不可操作；关系边仅在 confirmed 或 candidate 时可操作，而完整状态集合仍需合同材料补证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 职责与设计边界

该文件位于可重建代码视图与用户界面之间。投影展开原始记录，保留文件、符号、范围和边端点等内部操作键，同时增加 `displayTitle`、`displayPath`、`citationLabel`、`actionable` 与 `reason` 等人读字段，避免把内部 ID 直接作为可见标签。[DTO 投影职责说明 ↗](../../../apps/server/src/code/dto.ts#L1 "支持投影保留内部操作字段、增加人读展示字段，并避免将内部 ID 渲染为可见标签。")

此前“不可操作对象等同于已移除文件及 missing/stale 边”的笼统结论已被替代：文件确实只按 `removed` 判定，移除后关闭操作并给出原因；关系边则采用独立的正向状态白名单。[文件 DTO 投影 ↗](../../../apps/server/src/code/dto.ts#L35 "支持文件标题、完整路径、摘要、版本、链接以及仅按 removed 状态决定可操作性和原因的结论。")

<a id="projection-flow"></a>
## 快照、文件与符号的投影流程

快照投影把提交号缩为七位；没有提交号时，`shortCommit` 根据工作区状态返回 `dirty` 或 `no-commit`。这一结果用于展示标题、短提交字段和引用标签，但摘要独立由解析器版本与文件数量组成，API 深链是固定的当前快照路径，trail 链接则由快照 ID 构成。此前声称提交状态同时决定摘要和链接的结论已被替代。[快照展示元数据 ↗](../../../apps/server/src/code/dto.ts#L13 "支持分别描述短提交状态对标题和引用标签的影响，以及摘要、固定 API 深链和基于快照 ID 的 trail 链接各自独立的生成规则。")

文件投影以路径末段为标题，以完整路径作为展示路径和引用标签，并附带语言、大小及可选快照版本；其 API 与 trail 链接均携带文件 ID。[文件 DTO 投影 ↗](../../../apps/server/src/code/dto.ts#L35 "支持文件标题、完整路径、摘要、版本、链接以及仅按 removed 状态决定可操作性和原因的结论。") 符号投影对 route/test 使用短名称，其他类型使用限定名；起始范围会进入引用标签和源码深链，结束范围缺失时回退到起始行，再缺失则回退到第 1 行。存在文件时链接源码范围，否则进入符号详情。[符号标签与源码深链 ↗](../../../apps/server/src/code/dto.ts#L54 "支持符号名称选择、引用范围生成、源码行回退，以及有无文件时采用不同深链目标的结论。")

<a id="edges-and-limits"></a>
## 关系边状态、跳转与限制

关系边将已知种类映射成人读动词，并用两端标签组成标题；端点缺失时显示问号，未知种类回退为原始类型。仅 `confirmed` 与 `candidate` 被标为可操作；`missing` 的原因是目标无法解析，`stale` 表示已被较新快照替代。跳转优先进入来源文件，否则回到全局代码图。[关系边展示与跳转 ↗](../../../apps/server/src/code/dto.ts#L78 "支持边类型文案、端点占位、confirmed/candidate 可操作规则、missing/stale 原因及跳转目标。")

因此，`candidate` 可操作不等于关系已经确认。其他可能状态若不在白名单中也会不可操作，但原因函数只明确解释 missing 与 stale；当前材料没有给出 `CodeEdge` 的完整状态 schema，也没有消费端或行为测试，不能进一步断言状态集合封闭、候选关系有独立视觉提示，或异常回退分支已被测试覆盖。[关系边状态正向白名单 ↗](../../../apps/server/src/code/dto.ts#L90 "说明实现只对 confirmed 和 candidate 开放操作，而原因函数仅明确处理 missing 与 stale，支持对完整状态范围保持保守结论。")
