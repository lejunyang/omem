# ACP 助理模型的提示编排与结构化回复

该适配器把助理运行时提供的会话、证据、任务和时间上下文交给真实 ACP Agent，并把返回文本解析成回答、检索请求或待宿主治理的任务操作；它不自行推理，也不把模型声明当作执行结果。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 把运行时上下文接到真实模型

`AcpAssistantModel` 是 `AssistantModelPort` 的生产适配器：它不在本地生成答案，而是把运行时上下文交给项目共用的 ACP 传输，并要求模型返回可解析的结构化结果。只有 `transport: "acp"` 的配置会进入真实会话；未配置模型或选用 CLI 传输时直接报告模型不可用，不伪造兜底答案。参考 [适配器职责与传输限制 ↗](../../../apps/server/src/assistant/acp-model.ts#L13 "支持该类只桥接真实 ACP、拒绝 CLI 或缺失配置且不生成伪答案的说明。")

它与任务合同、日常消息规则、检索目的枚举、ACP 客户端及助理运行时端口相连，因此处在“上下文装配”与“宿主执行治理”之间。参考 [依赖的运行时合同 ↗](../../../apps/server/src/assistant/acp-model.ts#L1 "说明适配器依赖任务 schema、工作流提示、ACP 传输、检索目的和助理运行时端口。")

模型只能提出请求，真正的变更仍以宿主回执为准。参考 [结构化提示合同 ↗](../../../apps/server/src/assistant/acp-model.ts#L68 "支持提示包含可信上下文、时间、任务、证据、检索轮次和结构化输出约束，并明确只有宿主回执才能确认执行。")

<a id="flow"></a>
## 一次代表性调用如何流动

例如用户说“帮我跟进张三的评审回复”时，调用方传入当前问题、历史轮次、可见证据、已有任务、可信约束和时区。适配器默认只保留最近 10 轮历史，并把每轮旧回答截到 500 字；证据则带片段标识和标题写入独立区块。参考 [历史与证据编排 ↗](../../../apps/server/src/assistant/acp-model.ts#L48 "支持历史轮数、旧回答长度限制以及证据区块格式的流程说明。")

```mermaid
flowchart LR
  A[运行时输入] --> B[拼装受约束提示]
  B --> C[ACP 会话]
  C --> D[累积文本输出]
  D --> E[解析为回答、检索或任务请求]
```

提示中同时声明证据引用范围、任务数据规则、相对时间解析、二次检索预算和唯一 JSON 输出合同；随后以工作区、取消信号和 20000 字输出上限调用 ACP，只收集文本事件，最后交给解析器。参考 [结构化提示合同 ↗](../../../apps/server/src/assistant/acp-model.ts#L68 "支持提示包含可信上下文、时间、任务、证据、检索轮次和结构化输出约束，并明确只有宿主回执才能确认执行。") [ACP 调用与输出收集 ↗](../../../apps/server/src/assistant/acp-model.ts#L96 "支持以工作区和取消信号调用 ACP、限制输出、收集文本并转交解析器的流程。")

<a id="boundaries"></a>
## 解析边界与可修改入口

解析器从首个 `{` 到最后一个 `}` 截取 JSON，因此能容忍 JSON 前后的普通文本，但没有对象、JSON 无效或 `answer` 为空都会失败。引用只保留字符串；检索请求还要求合法的 `text` 与目的，并最多保留 3 条。参考 [基础回复与检索解析 ↗](../../../apps/server/src/assistant/acp-model.ts#L127 "支持 JSON 截取、必需回答、引用过滤及检索请求白名单与数量限制的边界说明。")

任务输出是**请求**而非已执行事实：创建任务至少要有非空标题，更新任务要有字符串任务 ID、整数版本和允许的动作；`follow_up` 交给共享 schema 校验。若模型异常地同时给出创建与更新，后解析的更新会覆盖前者，因此协议提示明确要求每次只选一种变更。要调整提示与上下文预算看 `generate`，要调整模型输出兼容性看 `parseAssistantReply`。参考 [任务请求解析 ↗](../../../apps/server/src/assistant/acp-model.ts#L153 "支持创建与更新任务的最低字段校验、共享跟进 schema 解析及更新覆盖行为。")
