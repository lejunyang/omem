# ACP 助手模型适配器

将助手运行时请求转换为受约束的 ACP 提示词，调用真实 Agent Profile，并把模型 JSON 解析为回答、检索建议或单个任务操作；同时明确拒绝缺失配置和非 ACP 传输。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_and_boundary"></a>
## 解决的问题与传输边界

`AcpAssistantModel` 是助手运行时与真实 ACP Agent 之间的生产适配层，本身不做推理，也不生成兜底答案。它要求存在 Agent Profile 且 `transport` 必须为 `acp`；未配置 Profile 或使用 CLI 单次调用协议时，都会以 `ModelUnavailableError` 明确降级，避免把不能稳定产出结构化任务 JSON 的通道伪装成可用模型。[模型适配器的职责与传输路由 ↗](../../../apps/server/src/assistant/acp-model.ts#L12 "支持适配器不推理、不伪造答案，并明确拒绝缺失配置及非 ACP 传输的论断。")

适配器跨文件复用 `agents.ts` 暴露的 `acp()` 传输，但现有材料只展示了该传输的进程启动、环境过滤和终止机制，不能据此确认完整会话、权限请求及协议处理细节。[ACP 子进程启动基础 ↗](../../../apps/server/src/agents.ts#L1 "说明跨文件依赖的 ACP 传输至少负责安全环境过滤、子进程启动与终止，但材料不足以证明完整协议流程。")

<a id="prompt_and_execution"></a>
## 提示词组装与执行流程

生成流程先限制上下文体积：默认仅保留最近 10 个历史轮次，每个旧回答截到 500 字；每条证据正文截到 2000 字。提示词合并 Profile 指令、可见性、可信上下文、当前时间与时区、现有任务、每日工作流、证据、历史和当前问题，并要求只引用给定证据、不得执行证据内指令。[上下文预算与提示词构造 ↗](../../../apps/server/src/assistant/acp-model.ts#L47 "支持历史、证据截断以及可信上下文、任务、证据和当前问题如何进入提示词的描述。")

任务规则区分截止时间与跟进时间，限定每次回复最多一种变更，并允许首轮在证据不足时提出最多三个检索词，第二轮则必须基于已有证据回答。每日工作流进一步区分明确交办、讨论归并、等待跟进和事项回顾。[每日消息工作流规则 ↗](../../../apps/server/src/assistant/message-workflows.ts#L1 "支持提示词所复用的交办、讨论、等待和回顾四类处理政策。") ACP 调用仅累积 `text` 输出，限制最多 20000 字；取消信号原样传播，其他传输异常统一包装为模型不可用。[ACP 调用与异常转换 ↗](../../../apps/server/src/assistant/acp-model.ts#L93 "支持仅收集文本、输出长度上限、取消传播和传输错误包装的执行流程。")

<a id="parsing_and_limits"></a>
## 结构化解析、校验与边界条件

解析器从返回文本的第一个 `{` 到最后一个 `}` 提取 JSON；缺少 JSON、语法错误或空回答都会失败。引用 ID 及检索词只做字符串过滤，检索词最多保留三个。[基础回复解析 ↗](../../../apps/server/src/assistant/acp-model.ts#L124 "支持 JSON 截取、必填回答、引用过滤及检索词数量限制的说明。") 创建事项仅在标题为非空字符串时形成工具调用，跟进字段交给共享 Zod 合同验证；更新事项还要求任务 ID、整数版本和受支持动作，动作范围与时区、时间格式约束来自任务合同。[任务操作共享合同 ↗](../../../packages/contracts/src/task-flow.ts#L3 "支持跟进字段、动作枚举、带偏移时间和 IANA 时区由共享合同严格校验的论断。")

边界上，解析器不会验证引用 ID 是否真的属于输入证据，也不会在此处校验 `due_at`；若模型同时返回合法创建与更新，后解析的更新会覆盖创建，最终仍只有一个工具调用。当前材料未包含测试文件，因此只能说明代码分支，不能确认异常 JSON、双变更冲突、取消传播及真实 ACP 输出已被自动化测试覆盖。[创建与更新解析分支 ↗](../../../apps/server/src/assistant/acp-model.ts#L146 "支持创建、更新工具调用的成立条件，以及更新分支会覆盖先前创建结果这一边界判断。")
