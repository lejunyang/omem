# 记忆提案治理、应用与反馈服务

将提案持久化、证据校验、知识匹配、影响预算、用户决策和原子应用串成一条治理链，并把可信反馈转成可复用约束。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="evidence-policy"></a>
## 证据校验与政策分流

`MemoryService` 不让模型直接写入记忆或任务，而是先按合同解析提案与独立评估，再校验固定证据：文本引用必须匹配指定修订、选择区间和精确内容，图片必须同时存在于修订部件与资产存储中。[提案证据的确定性校验 ↗](../../../apps/server/src/memory/service.ts#L227 "支持文本修订、精确选择区间及图片资产的校验规则，且引用紧邻相关论断。") 随后政策层综合语义结论、不确定性、图片推断、任务所有者身份、模糊时间、跨来源更新及影响量：确定性证据错误或语义矛盾直接拒绝；噪声忽略；非阻塞的不确定性延迟到使用时；图片推断、流程和他人承诺仅保留为来源；只有影响超限，或触及活跃知识/当前任务的跨源冲突，才升级为用户决策。[AttentionGate 政策分流 ↗](../../../apps/server/src/memory/service.ts#L730 "支持拒绝、忽略、延迟、保留来源、自动应用和升级用户决策的条件。")

<a id="matching-application"></a>
## 既有知识匹配与原子应用

创建 claim 前会在同一工作区和项目内召回活跃记忆。规范化陈述完全相同且来源重叠时视为重复，不再创建第二条活跃记忆；独立来源得出相同结论时创建新记忆并记录可查询的等价关系；评估指出矛盾时，还要满足有效期重叠、实体词相交和谓词极性相反，才记录争议及双方证据链。该规则是确定性启发式，并非完整语义推理。[新 claim 的重复、等价与冲突匹配 ↗](../../../apps/server/src/memory/service.ts#L443 "支持作用域过滤、来源重叠、有效期、实体词和极性规则及可追溯冲突链。") 真正应用前再次检查来源 head 与 validity epoch，任务和记忆写入统一走 Store 的 application 接口；流程类知识未经所有者批准禁止自动应用。[应用前新鲜度检查与统一写入 ↗](../../../apps/server/src/memory/service.ts#L1167 "支持应用前检查来源读取版本、通过 Store 写任务或记忆，以及流程知识需批准的边界。")

<a id="batch-decision"></a>
## 批量影响预算与决策

单条更新的影响量包含目标及共享来源的其他活跃记忆；创建操作则按工作区、项目和实体内容生成键。`evaluateBatch` 先对整份 ChangeSet 的受影响记忆与新实体做去重并集，超过自动上限时，把原本可自动应用的提案全部停放，避免逐条以低影响绕过预算，并只创建一个汇总 AttentionCase。[整批去重影响门控 ↗](../../../apps/server/src/memory/service.ts#L1431 "支持批量影响由记忆并集和新实体并集组成、超预算时整体停放并汇总提问。") 单条决策具有所有者绑定、七天有效期、请求幂等和版本新鲜度检查；批准才调用应用，拒绝或请求背景只更新决策及提案状态。[用户决策的版本与幂等处理 ↗](../../../apps/server/src/memory/service.ts#L1686 "支持参与者、摘要、请求 ID、过期和来源新鲜度检查，以及批准、拒绝和补背景的状态转换。")

<a id="feedback"></a>
## 反馈约束与模块关系

`FeedbackService` 对反馈事件按工作区、生产者和事件 ID 去重，并用稳定摘要检测同一事件内容冲突。只有身份已验证、来源为 original 且证据均存在的强反馈才可成为 active confirmed 约束；权限、预算、自动批准等受保护策略始终进入 shadow，普通有用性或结果信号保持 weak。当前自动改写仅作用于任务负责人匹配。[反馈强度与任务约束应用 ↗](../../../apps/server/src/memory/service.ts#L1895 "支持反馈去重、受保护策略降级、confirmed 条件及当前只改写任务负责人的范围。") 应用工厂直接以同一个 Store 构造记忆与反馈服务，说明两者共享数据库、事务和应用收据基础设施。[应用工厂中的服务装配 ↗](../../../apps/server/src/app.ts#L53 "证明 MemoryService 与 FeedbackService 由同一 Store 构造并接入服务器应用。")
