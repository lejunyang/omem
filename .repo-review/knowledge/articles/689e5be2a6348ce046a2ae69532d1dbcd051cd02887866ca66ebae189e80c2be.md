# MemPalace 本地检索适配研究

研究认为 MemPalace 值得作为独立本地检索 sidecar 做 PoC，但固定片段身份、中文召回、离线性和运维仍须验证；已复算的是上游保存结果，不是重新运行检索，更不是 omem 服务指标。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="recommendation-and-scope"></a>
## 选择与核验边界

材料建议优先做薄适配器 PoC，让 omem 保持原始证据、治理与任务权威，MemPalace 只维护可重建的候选检索投影。该判断来自固定 develop 快照的源码、文档和保存结果检查；本轮没有安装软件、下载权重或重新运行向量检索。[MemPalace 研究结论与未实测范围 ↗](../../../docs/research/mempalace/README.md#L1 "支持优先做本地检索 PoC、保持 omem 权威，以及本轮没有安装或重跑检索的说明。")

<a id="identity-obstacle"></a>
## 固定证据身份障碍

高层添加接口没有任意外部身份字段，且相同目录与正文会生成相同标识，可能把同文不同来源或不同版本错误合并。建议由 Python sidecar 使用公共后端 API 写入自定义投影身份和版本元数据，再由 omem 回查固定原件；不能依赖展示文件名反推证据。[片段身份与去重风险 ↗](../../../docs/research/mempalace/README.md#L67 "说明高层接口缺少外部身份、正文去重可能误合并，以及推荐的自定义投影与回查方式。")

<a id="adapter-and-gates"></a>
## 薄适配器流程与采用门

权威片段经幂等 outbox 投影到独立 worker，搜索仅返回候选与证据映射，最后由 omem 校验有效性和范围。采用前必须保证候选可回查固定片段、更新撤回可过滤、预热后断网无外部请求、索引可重建，并与同口径关键词及薄组合基线比较质量和成本。[适配器流程与决策硬门 ↗](../../../docs/research/mempalace/README.md#L77 "支持候选投影的端到端流程、降级原则、同口径对照方法及最终采用条件。")
