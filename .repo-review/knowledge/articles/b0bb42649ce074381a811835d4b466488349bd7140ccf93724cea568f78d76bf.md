# 代码理解模型传输适配器

该模块为仓库评审中的代码理解能力提供显式配置、默认关闭的模型端口，统一适配 ACP、命令行和 HTTP 三种传输，并负责配置校验、文本汇集、取消信号传递及模型来源记录。它自身不执行推理，也不主动读取凭据；实际进程和协议能力委托给 agents 模块。当前各传输对预算、超时和模型身份的处理并不完全一致。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-contract"></a>
## 作用与端口合同

该模块解决“评审代码可以接入模型，但不能把模型或凭据硬编码进评审模式”的问题。宿主必须显式传入传输配置；未配置或选择 `none` 时返回 `null`，表示仅使用已有 seed，而显式配置错误则抛出 `CodeModelUnavailableError`，避免静默降级。[默认关闭与错误显式化 ↗](../../../apps/server/src/code/understanding-model.ts#L80 "支持模型必须由宿主显式启用、none 返回空端口以及坏配置抛错的论断。")

对上层暴露的端口只包含传输名称与异步 `run`：输入提示词、取消信号及可选生成预算，输出模型文本和模型标识。配置同时容纳命令、工作目录、参数、model、effort、超时和 HTTP endpoint；其中预算类型由公共运行时预算模块转出。[传输配置与模型端口合同 ↗](../../../apps/server/src/code/understanding-model.ts#L24 "说明配置字段、run 输入和统一回复结构。") [生成预算类型转出 ↗](../../../apps/server/src/code/budget.ts#L1 "证明本模块使用的 GenerationBudget 来自共享 agent-runtime 预算实现。")

<a id="transport-flow"></a>
## 三类传输的核心流程

ACP 与 CLI 都先通过 `makeProfile` 生成固定用途的 AgentProfile，要求显式命令，补齐参数、上下文字符上限和默认 120 秒超时。运行时仅累计 `text` 类型输出：ACP 把 prompt 包装成文本内容块，并将输出字符上限和上下文预算传给 `acp`；CLI 则把 prompt 直接交给 `cli`。二者默认工作目录均落在 `.repo-review/runtime/agent-workspace`。[AgentProfile 构造 ↗](../../../apps/server/src/code/understanding-model.ts#L52 "支持显式 command、默认参数、上下文上限和默认超时的描述。") [ACP 与 CLI 调用流程 ↗](../../../apps/server/src/code/understanding-model.ts#L88 "支持文本累积、默认工作目录、ACP 预算传递及 CLI 委托调用的流程说明。")

HTTP 分支要求显式 endpoint，以 JSON POST 发送 prompt 和可空 model，并透传 AbortSignal。响应非成功状态、或既无有效 `text` 也无有效 `content` 时会报不可用；成功时优先采用响应里的 model，否则退回配置值或通用 `http` 标签。[HTTP 模型端点适配 ↗](../../../apps/server/src/code/understanding-model.ts#L125 "支持 POST 请求、响应检查、文本解析与模型标识回退规则。")

<a id="boundaries-and-relations"></a>
## 边界条件与模块关系

本文件是适配层而非推理实现：实际 ACP/CLI 进程由 `agents.ts` 提供。该运行模块以 `shell:false` 启动显式命令、创建受限权限的工作目录，并过滤部分敏感环境变量；因此这里传入的 profile、cwd、signal 和预算最终依赖该模块的进程及协议生命周期语义。[Agent 进程启动边界 ↗](../../../apps/server/src/agents.ts#L32 "证明被委托模块负责目录创建、环境过滤和无 shell 的子进程启动。")

边界上，只有 ACP 分支把 `GenerationBudget` 继续传给底层；CLI 与 HTTP 分支没有使用传入预算。`timeoutMs` 被写入 ACP/CLI profile，但 HTTP 请求只依赖调用方给出的 AbortSignal，没有在本文件内依据 timeoutMs 创建超时。代码也未在此校验 model/effort 是否为底层支持值；这类能力发现或拒绝应由被调用运行时或更上层配置流程承担，现有材料无法确认。[各传输的预算与取消处理 ↗](../../../apps/server/src/code/understanding-model.ts#L92 "支持只有 ACP 消费预算、HTTP 仅透传 signal，且分支处理能力不一致的边界判断。")
