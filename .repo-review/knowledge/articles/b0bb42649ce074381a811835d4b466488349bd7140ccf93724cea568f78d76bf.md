# 显式配置的代码理解模型适配端口

该模块以默认关闭、宿主显式配置的方式适配 ACP、CLI 和 HTTP；当前实现会在缺失真实模型名时写入 transport 占位值，这与文件头的 provenance 声明存在冲突。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="opt_in"></a>
## 默认关闭与配置边界

模块只适配宿主选择的 transport，不自行推理，也不直接读取环境变量、凭据或个人秘密；从本模块实现边界看，它构造新的隔离 profile，不会加载已有或个人 profile。[模型端口的选择加入边界 ↗](../../../apps/server/src/code/understanding-model.ts#L1 "支持默认无硬编码模型、不自行推理或读取环境变量和凭据，并仅适配宿主明确选择的 transport。")[隔离 Agent profile ↗](../../../apps/server/src/code/understanding-model.ts#L60 "支持模块从传入配置构造新 profile、清空 instructions 和 skills，而非加载现有 profile。") 未提供配置或选择 `none` 时返回 `null`；显式配置缺少必填字符串或使用不支持的 transport 时抛出 `CodeModelUnavailableError`，而非静默伪装可用。[无模型配置分支 ↗](../../../apps/server/src/code/understanding-model.ts#L80 "支持缺少配置或 transport 为 none 时返回 null。")[配置字段与 transport 错误 ↗](../../../apps/server/src/code/understanding-model.ts#L21 "支持必填字符串校验及不支持 transport 时抛出 CodeModelUnavailableError。")

<a id="local_transports"></a>
## ACP、CLI 与身份回退

ACP 和 CLI 由显式配置构造 profile，清空 instructions 与 skills，并透传命令、模型、effort、超时和取消信号。ACP 使用请求预算换算输出字符上限并传递上下文预算，CLI 在此处不消费该预算。[Profile 配置映射 ↗](../../../apps/server/src/code/understanding-model.ts#L60 "支持 ACP 与 CLI profile 使用显式命令、模型、effort、超时，并清空附加指令和技能。")[ACP 与 CLI 适配实现 ↗](../../../apps/server/src/code/understanding-model.ts#L88 "支持文本聚合、取消信号、ACP 预算传递、CLI 不消费预算，以及缺少模型时的 transport 名称回退。")

两条本地分支都聚合文本增量，但不会主动拒绝空聚合结果。未配置 model 时，它们分别把 `acp`、`cli` 写入 reply 的 model；这些是 transport 占位标签，并非 transport 响应提供的真实模型身份，因而与文件头“模型 ID 仅来自响应或显式配置、绝不虚构”的声明冲突。[ACP 与 CLI 适配实现 ↗](../../../apps/server/src/code/understanding-model.ts#L88 "支持文本聚合、取消信号、ACP 预算传递、CLI 不消费预算，以及缺少模型时的 transport 名称回退。")[模型身份 provenance 声明 ↗](../../../apps/server/src/code/understanding-model.ts#L11 "文件头声明模型身份应来自响应或显式配置；与各分支生成 transport 占位值的实现形成直接冲突。")

<a id="http_boundary"></a>
## HTTP 校验与 provenance 缺陷

HTTP 分支向显式 endpoint POST 提示词和可选模型名，并透传取消信号；只有该分支会在非成功状态或响应文本为空时主动转换为模型不可用错误。模型名优先取响应，其次取配置，但两者都缺失时仍回退为 `http`。[HTTP 请求、响应与模型回退 ↗](../../../apps/server/src/code/understanding-model.ts#L125 "支持 HTTP 专属状态和空文本校验，以及响应模型、配置模型、http 占位值的回退顺序。")

因此，先前把该回退同时描述成符合“never invent a model id”的结论已被替代：`acp`、`cli`、`http` 当前都可能只是代码生成的 transport 标签，与文件头 provenance 声明不一致。[模型身份 provenance 声明 ↗](../../../apps/server/src/code/understanding-model.ts#L11 "文件头声明模型身份应来自响应或显式配置；与各分支生成 transport 占位值的实现形成直接冲突。") 此外，本模块只返回文本和 model，没有展示生成结果写入及 `verified_by_agent` 的持久化路径。
