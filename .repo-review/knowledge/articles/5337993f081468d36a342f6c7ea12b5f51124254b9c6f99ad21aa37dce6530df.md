# docs-prototype · 模块理解 · 专题 2

该专题说明离线知识阅读原型的视觉与交互支撑层：样式系统组织文章、问答和证据路径，调节面板统一原型参数与宿主通信，浏览器冒烟脚本验证关键前端合同；现有成果仍限于离线原型，不代表后端、模型或生产兼容性已经验收。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="responsibility"></a>
## 职责与组成

这一部分把离线原型从静态展示推进为可操作的知识阅读体验。样式系统用固定视口外壳组织导航、独立滚动文章和右侧问答区，并把行内引用呈现为进入证据路径的操作入口；它负责布局和状态表达，不负责检索或生成答案。[知识阅读布局 ↗](e9da3ae0f3d2927555f5ba23124101b64470aa0f621b098f227d3f041e2ca998.md#layout-system "概括应用外壳、独立文章区和右侧问答区的布局职责，支持附近的模块组成说明。")[文章与行内引用样式 ↗](../../../docs/prototype/styles.css#L403 "直接展示独立滚动文章、可调正文字号及可点击行内引用的样式实现。")

证据阅读器承载路径面包屑、历史版本、循环提示、原文摘录、异常空态与原位追问，使读者能够从结论逐层返回依据。桌面端采用受限尺寸对话框，手机端则铺满视口并将追问区纵向堆叠，以适应窄屏阅读。[证据追踪交互 ↗](e9da3ae0f3d2927555f5ba23124101b64470aa0f621b098f227d3f041e2ca998.md#evidence-trail "说明证据阅读器如何呈现路径、历史、循环、异常状态和原位追问。")[手机端证据阅读布局 ↗](../../../docs/prototype/styles.css#L1909 "支持手机端全屏证据对话框、纵向追问区及增大触控目标的响应式说明。")

<a id="workflow"></a>
## 参数调节与验证流程

阅读字号、密度等参数由通用调节面板管理：更新会合并到 React 本地状态、通知父宿主持久化，并向同页组件广播变更。[调节状态与宿主通知 ↗](../../../docs/prototype/tweaks-panel.jsx#L177 "支持参数更新合并本地状态、通知父宿主持久化并广播同页变更的流程。") 可持久化默认对象必须内联在 HTML 的指定标记区且保持合法 JSON；移出该区域、删除标记或使用非 JSON 内容，会使调节编辑停止持久化。[可持久化默认值约束 ↗](../../../docs/prototype/tweaks-panel.jsx#L14 "直接支持默认对象必须内联于 HTML 标记区并保持合法 JSON，否则调节编辑停止持久化的约束。") 面板还统一处理宿主激活与关闭、拖动位置夹紧及常用表单控件。[调节面板生命周期 ↗](7e3c7e286307f227373dc5a51af6cffb0a509065a858df79aa162677cd9ec404.md#panel-lifecycle "概括宿主握手、关闭同步和拖动位置夹紧等通用面板职责。")

浏览器脚本验证多层证据下钻、循环跳回、历史版本、原位追问、草稿以及滚动和焦点恢复，并走完 100 层合成路径，表明展示交互没有把较浅的示例层数当作业务深度上限。[证据路径浏览器验证 ↗](264c706a98c326db5498e7ec20a5d5f78bd6e87621fdca8ea374d5be82fb0d8f.md#interaction-contract "支持多层下钻、循环与历史版本、原位追问、状态恢复及长路径等核心交互合同。") 外围检查另行覆盖搜索与空结果、模拟同步、本地恢复历史、阅读字号、移动端全屏引用、脚本异常和外部请求，因此不能只由证据路径章节概括。[外围前端场景断言 ↗](../../../docs/prototype/smoke.mjs#L200 "直接支持搜索、模拟同步、本地恢复、阅读字号、移动布局以及无异常和零外部请求等外围检查。")

<a id="progress-and-limits"></a>
## 进展、关联与限制

冒烟脚本明确从 Playwright 导入 Chromium、以无头模式启动浏览器，并把 `browser.version()` 写入验证记录。[Chromium 启动与版本记录流程 ↗](../../../docs/prototype/smoke.mjs#L2 "证明冒烟脚本实际导入并启动 Chromium；脚本随后将该浏览器实例的版本写入验证记录，支持附近对浏览器类型的限定。") 该记录显示，2026-09-26 曾在 Chromium 153.0.8010.12 中完成所列离线场景，错误和外部请求数组均为空。[离线原型验证记录 ↗](../../../docs/prototype/verification.json#L2 "支持检查日期、浏览器版本、场景清单以及空错误和空外部请求结果；结合 Chromium 启动与报告生成流程可确定版本对应的浏览器类型。") 这将视觉状态、参数调节和证据阅读串成了可重复检查的前端切片，也为后续真实知识服务提供交互合同。

不过报告明确限定为离线原型，不包含后端行为或模型评估；固定回答、模拟同步和本地历史不能证明真实检索、权限、服务端持久化或答案质量。[验证范围声明 ↗](../../../docs/prototype/verification.json#L21 "直接证明现有验证只覆盖离线原型，明确排除后端行为和模型评估。") 当前截图也未建立视觉差异基线，兼容性尚未覆盖其他浏览器和移动软键盘。调节协议向通配目标发送消息，接收激活消息时未校验来源或负载结构，因此非完全可信的嵌入环境仍需收紧边界。[跨窗口消息边界 ↗](../../../docs/prototype/tweaks-panel.jsx#L236 "展示消息发送使用通配目标且接收逻辑只检查消息类型，支持可信嵌入边界仍待明确的判断。")
