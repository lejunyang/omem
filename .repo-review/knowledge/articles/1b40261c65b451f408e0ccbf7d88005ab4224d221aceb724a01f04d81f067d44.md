# 共享知识阅读与证据导航界面

共享 UI 包统一承载知识正文、源码、证据路径和模块关系图。它已实现安全 Markdown 渲染、按行代码定位、可返回的证据轨迹与确定性图形布局；当前限制集中在空正文加载状态、深链截断与类型恢复，以及关系图的长链分层和键盘操作。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 统一知识阅读体验

`@omem/ui` 是工程内部复用的 Vue 3 ESM 包，公开组件入口与视觉令牌，并集中提供 Markdown、代码高亮、HTML 净化和 Mermaid 等阅读依赖。参考 [共享界面包配置 ↗](../../../packages/ui/package.json#L1 "支持共享包的内部定位、Vue 运行时边界、公开入口及富文本阅读依赖。") Markdown 阅读器接收正文与引用清单，把证据打开和站内导航作为事件交给宿主，因此共享层负责呈现与交互合同，业务数据加载和页面切换仍由上层处理。参考 [正文阅读器接口 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L7 "支持阅读器接收正文和引用，并把证据查看与站内导航交给宿主。")

<a id="reading-flow"></a>
## 从正文到安全可追溯内容

正文中的引用标记会先转换为可操作或不可用标签；随后解析 Markdown，普通代码块调用共享高亮器，生成结果再按标签、属性和 URI 白名单净化。参考 [Markdown 解析与净化 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L38 "支持引用替换后的代码块处理、共享高亮调用及 HTML 白名单净化流程。") Mermaid 描述先保留为转义占位，之后以严格模式生成 SVG并再次净化；渲染失败时保留原始描述。参考 [流程图安全渲染 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L100 "支持 Mermaid 严格模式、SVG 二次净化及失败时保留原始描述。")

异步渲染以代次阻止旧结果覆盖新正文，但切换为空正文时只清空 HTML并提前返回，没有主动结束 loading；旧任务也会因代次失效跳过最终清理，加载提示可能持续存在。参考 [空正文提前返回 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L25 "支持空正文分支清空 HTML后直接返回、未主动重置 loading 的边界说明。") [最新代次状态清理 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L111 "支持只有当前代次才能在 finally 中清除 loading，据此说明旧任务无法补做清理。")

<a id="evidence-trail"></a>
## 沿引用深入并返回原处

证据路径以帧栈表示模块、文件、符号、知识与来源等阅读层级；每帧包含稳定身份、可读标题、滚动位置和数据定位字段，循环检测使用“类型与身份”的组合。参考 [证据轨迹帧合同 ↗](../../../packages/ui/src/trail.ts#L16 "支持轨迹帧类型、稳定身份、可读标题、滚动位置及数据定位字段。") [轨迹循环检测 ↗](../../../packages/ui/src/trail.ts#L44 "直接支持循环检测以 kind 与 id 的组合识别已有帧。")

渲染栈本身不受深度限制，但 URL 持久化预算为 200 帧。参考 [轨迹深链预算 ↗](../../../packages/ui/src/trail.ts#L37 "支持 200 帧上限只约束 URL 持久化、渲染栈本身不受限及调用方应提示的合同。") 哈希写入会保存主视图、源码行号及轨迹的类型与身份，因此刷新后仍需宿主恢复标题、滚动位置和其他上下文。参考 [哈希深链写入 ↗](../../../packages/ui/src/OmHashRoute.ts#L67 "支持主视图、源码行号和轨迹类型与身份的序列化方式及持久化截取行为。") 解析侧同样截取到 200 帧，并把外部 kind 直接断言为轨迹类型，未做运行时成员校验。参考 [轨迹深链解析 ↗](../../../packages/ui/src/OmHashRoute.ts#L33 "支持轨迹按类型与身份成对解析、截取到预算上限及 kind 缺少运行时成员校验的说明。") 原生对话框承载路径交互：Esc 返回一层，遮罩或关闭按钮关闭全部，正常关闭后尝试归还焦点。参考 [对话框返回与关闭 ↗](../../../packages/ui/src/components/OmDialog.vue#L14 "支持模态打开、正常关闭时焦点归还，以及 Esc、遮罩和关闭按钮的交互语义。")

<a id="implemented-limits"></a>
## 源码定位、关系图与实现边界

源码查看器通过代次隔离处理异步高亮，并支持稳定行号、锚点滚动和短暂强调。参考 [源码高亮与锚点 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L34 "支持异步高亮代次隔离、稳定行号、锚点滚动和短暂强调。") 行内引用按钮会阻止代码行点击冒泡并发出打开引用事件，具体目标仍由父层解释。参考 [源码行内引用 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L78 "直接支持按行渲染引用按钮、阻止冒泡并发出打开引用事件。")

关系图按固定顺序传播模块层级并计算坐标，保证相同输入下布局稳定；但传播最多执行 12 轮，长依赖链和循环不保证严格分层，`missing` 关系也不参与布局。参考 [关系图分层布局 ↗](../../../packages/ui/src/components/OmRelationGraph.vue#L48 "支持固定排序、最多十二轮层级传播、缺失关系排除和坐标计算。") 节点可用点击、Enter 或空格选择；边标签点击会选择关系，但键盘事件复用节点处理器并传入关系身份，可能触发错误导航。参考 [关系图选择交互 ↗](../../../packages/ui/src/components/OmRelationGraph.vue#L127 "支持节点键盘选择，并揭示边标签键盘操作复用节点处理器而与点击语义不一致。")
