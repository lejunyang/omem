# ui · 模块理解 · 专题 1

共享 UI 模块集中提供基础视觉原语、安全 Markdown、源码定位、关系图、证据对话框及 Trail 深链数据合同。各局部能力已有实现，但公开导出、端到端组合、关系图异常状态、无障碍细节和自动化回归覆盖仍待核实。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-and-boundary"></a>
## 职责与模块边界

`@omem/ui` 是私有 ESM 共享包，由消费方提供 Vue 运行时，并公开源码入口与设计令牌样式；Markdown 解析、HTML 净化和语法高亮依赖也集中在包内。[共享 UI 包配置 ↗](../../../packages/ui/package.json#L1 "支持共享包的 ESM、导出边界、Vue 对等依赖及富文本相关依赖说明。") 它以小型组件统一交互和排版：按钮规定变体、原生类型以及 loading 联动的禁用与忙碌状态；[通用按钮接口与加载状态 ↗](../../../packages/ui/src/components/OmButton.vue#L1 "支持按钮变体、默认原生类型及 loading 联动 disabled、aria-busy 的论断。") 面板提供标题、正文和操作区插槽，空状态提供标题、说明及后续动作容器；[共享面板结构 ↗](../../../packages/ui/src/components/OmPanel.vue#L1 "支持面板以标题、正文和操作区插槽组成内容容器的说明。")[空状态内容合同 ↗](../../../packages/ui/src/components/OmEmpty.vue#L1 "支持空状态的必填标题、可选说明和默认插槽职责。") 徽标负责有限的状态色调，图标则提供统一描边且默认作为装饰内容隐藏于辅助技术。[状态徽标接口 ↗](../../../packages/ui/src/components/OmBadge.vue#L1 "支持徽标允许的色调、默认值及插槽内容边界。")[共享线条图标渲染 ↗](../../../packages/ui/src/components/OmIcon.vue#L1 "支持图标统一描边、继承颜色、未知名称回退及装饰性隐藏语义。")

这些材料证明了共享原语各自的局部合同，但未包含根入口源码，因而尚不能据此确认完整公开 API，也不能证明所有应用都已按同一方式复用它们。此前仅用按钮材料概括面板、空状态、徽标和图标的结论已被上述逐项证据替代。

<a id="evidence-flow"></a>
## 正文、源码与深链数据流

Markdown 组件把 `[[引用键]]` 转换为可读链接或不可用提示，解析正文和代码块后用白名单净化 HTML，并以 generation 避免旧异步结果覆盖新内容；点击引用、外链和站内路径时分别交给不同出口。[Markdown 编译、净化与链接分流 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L25 "支持内联引用替换、异步解析、高亮、白名单净化、防竞态和点击分流流程。") 源码查看器同样采用代次控制，按稳定行号渲染全文，支持锚点滚动、范围命中和逐行引用；高亮异常时模板回退到转义原文。[源码查看器高亮与安全回退 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L29 "支持异步代次控制、锚点定位、范围导航、逐行引用及高亮失败后转义显示原文。") 对于未知语言，共享高亮函数会直接转义源码，而非尝试加载语法包。[未知语言的转义策略 ↗](../../../packages/ui/src/highlight.ts#L21 "专门支持未知语言不加载语法包而直接转义源码的论断。")

Trail 帧保存 kind、稳定标识、标题、滚动位置及可选文件或符号上下文，并以 kind 与 id 检测循环；`MAX_TRAIL` 是 URL 持久化预算，不限制实际渲染栈。[Trail 帧与深链预算 ↗](../../../packages/ui/src/trail.ts#L16 "支持帧上下文字段、循环检测及 MAX_TRAIL 仅约束 URL 持久化深度的说明。") Hash 路由可恢复主视图、文件行号及 Trail，但只持久化帧的 kind/id。空 Hash或无法识别的主路由回退到概览；无法 URI 解码的段会保留原值，只要仍符合 module 或 file 路由形状就不会回退。[Hash 路由解析与序列化 ↗](../../../packages/ui/src/OmHashRoute.ts#L19 "支持主视图、行号和 Trail 的恢复方式，并精确说明空或未知路由回退及解码失败保留原段的行为。") 这替代了此前“损坏路由一律回退概览”的过宽结论。

<a id="progress-and-limits"></a>
## 关系阅读能力与待核实边界

证据对话框基于原生 dialog，受父层 open 状态控制：Esc 发出返回事件，遮罩和关闭按钮发出关闭事件，正常关闭时归还焦点，并可组合正文、侧栏和操作区。[证据对话框生命周期与结构 ↗](../../../packages/ui/src/components/OmDialog.vue#L1 "支持受控打开、正常关闭焦点归还、Esc 返回、关闭事件、固定标题 id 和卸载路径限制。") 关系图则以固定排序和最多十二轮分层计算生成可复现坐标，向外暴露节点与边选择事件。[关系图合同与确定性布局 ↗](../../../packages/ui/src/components/OmRelationGraph.vue#L14 "支持节点和边选择合同、固定排序、missing 边过滤及十二轮分层计算。") 但 missing 边没有专用样式：两端存在时落入 confirmed 外观，端点缺失时路径为空且标签回到原点；边标签的键盘操作还错误复用节点选择处理器，与鼠标选择边不一致。[关系边绘制与键盘交互 ↗](../../../packages/ui/src/components/OmRelationGraph.vue#L107 "支持 missing 边缺少专用样式、缺失端点回退原点及边标签键盘误发节点选择的限制。")

Trail、Hash 路由、对话框和关系图分别具备形成下钻阅读流程所需的原语，但当前材料没有父容器或调用链，不能证明它们已经组成可操作的“关系—证据—返回”端到端流程；此前把该集成关系写成既成事实的结论已被替代为待核实事项。另有局部无障碍限制：对话框标题使用固定 id，打开时直接卸载不会执行正常关闭分支的焦点归还；[证据对话框生命周期与结构 ↗](../../../packages/ui/src/components/OmDialog.vue#L1 "支持受控打开、正常关闭焦点归还、Esc 返回、关闭事件、固定标题 id 和卸载路径限制。") 独立引用按钮也没有 `type="button"`、不可操作状态或原因字段，只能发出 open 事件。[独立引用按钮合同 ↗](../../../packages/ui/src/components/OmCitation.vue#L1 "支持引用组件仅接收标签和版本、发出 open 事件且未声明按钮类型或不可操作原因状态。")
