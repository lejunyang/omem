# ui · 模块理解 · 专题 1

@omem/ui 是面向 Vue 3 应用的共享展示与证据阅读层。本次材料确认了基础视觉组件、安全 Markdown、源码阅读、证据轨迹深链和模块关系图；完整轨迹恢复、超长深链提示、missing 关系呈现及键盘等价性仍待上层合同或测试确认。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-and-boundary"></a>
## 模块职责与边界

`@omem/ui` 是私有 ESM 包，对外声明 TypeScript 根入口和设计令牌样式，由消费方提供 Vue 3 运行时；Markdown 解析、HTML 清洗和代码高亮依赖也集中在包内。[共享 UI 包配置 ↗](../../../packages/ui/package.json#L1 "支持包的私有 ESM 属性、公开入口、Vue 对等依赖及富文本相关依赖范围。") 本次所列组件材料显示：OmPanel 组织标题、正文和操作区，OmButton 统一按钮变体及加载禁用语义，OmBadge 提供状态色调，OmEmpty 表达空态内容，OmIcon 提供装饰性线条图形。[通用面板结构 ↗](../../../packages/ui/src/components/OmPanel.vue#L1 "支持 OmPanel 通过标题、正文和操作插槽提供内容骨架。")[通用按钮状态合同 ↗](../../../packages/ui/src/components/OmButton.vue#L1 "支持 OmButton 的视觉变体、默认原生类型以及 loading 与 disabled 行为。")[状态徽标色调 ↗](../../../packages/ui/src/components/OmBadge.vue#L1 "支持 OmBadge 提供四种色调并通过插槽展示状态内容。")[空状态内容结构 ↗](../../../packages/ui/src/components/OmEmpty.vue#L1 "支持 OmEmpty 组合标题、可选说明和扩展操作内容。")[共享装饰图标 ↗](../../../packages/ui/src/components/OmIcon.vue#L1 "支持 OmIcon 从内置路径选择图形、统一尺寸与描边，并将 SVG 标记为装饰性内容。")

此前“整个包不保存知识或决定业务权限”的宽泛否定结论缺少完整入口与全部实现证据，现被替代为更窄的判断：**本次覆盖的组件未显示知识持久化或权限决策逻辑**，其可证职责主要是展示、组合和交互。

<a id="evidence-reading"></a>
## 富文本、源码与证据入口

证据正文会先把内联引用转换为可操作链接或不可用提示，再解析 Markdown、处理代码块，并按标签、属性与 URI 白名单清洗；异步代次控制只允许最新结果写回。[Markdown 编译与清洗流程 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L25 "支持引用替换、代码高亮、HTML 白名单清洗和异步代次保护组成富文本渲染流程。") 点击随后被分流为证据引用、站外链接和站内导航，失败时展示原始 Markdown。[Markdown 点击分流与失败回退 ↗](../../../packages/ui/src/components/OmMarkdown.vue#L69 "支持引用、外部链接和内部路径的点击分流，以及失败时展示原始 Markdown。")

源码查看器以稳定行号拆分完整文档，处理异步高亮竞态、锚点滚动、范围命中、逐行引用和导航事件。[源码查看器高亮与导航 ↗](../../../packages/ui/src/components/OmCodeViewer.vue#L29 "支持稳定行号、异步高亮、锚点滚动、范围导航与逐行证据入口的实现说明。") 它依赖共享高亮器按需加载已知语言；未知语言直接转义，跨行高亮则被拆成逐行仍有效的 HTML。[共享代码高亮边界 ↗](../../../packages/ui/src/highlight.ts#L21 "支持已知语言按需加载、未知语言转义以及跨行高亮拆分由共享模块负责。") 当前实现逐行创建表格节点且范围重叠时只取首个匹配项，大文件性能和多语义范围导航仍需结合调用场景验证。

<a id="trail-and-routing"></a>
## 证据轨迹与深链流程

阅读轨迹用帧栈表达模块、文件、符号、片段、知识、引用和原文等层级；完整帧含稳定身份、标题、滚动位置及数据定位字段，并以 `kind + id` 检测循环。渲染入栈不会自行截断，200 帧上限被定义为 URL 持久化预算。[共享证据轨迹合同 ↗](../../../packages/ui/src/trail.ts#L6 "支持轨迹帧字段、循环检测、URL 深度预算及入栈不截断渲染栈的说明。") OmDialog 提供受控原生模态：Esc 发出返回，遮罩和关闭按钮发出关闭全部，正常关闭后尝试归还焦点，同时支持正文、侧栏及操作区。[证据对话框交互 ↗](../../../packages/ui/src/components/OmDialog.vue#L14 "支持模态生命周期、焦点归还、Esc 返回、关闭全部和正文侧栏组合方式。")

哈希路由承载主视图、文件行号和轨迹，但解析后的轨迹只恢复 kind、id，并暂以 id 作为标题；解析与写入都会截取到预算范围。[哈希路由解析 ↗](../../../packages/ui/src/OmHashRoute.ts#L27 "支持主视图、文件行号及轨迹解析，并证明恢复后的帧只含 kind、id 和临时标题。")[哈希路由写入 ↗](../../../packages/ui/src/OmHashRoute.ts#L67 "支持轨迹序列化只保存 kind 与 id，并在写入深链时应用 200 帧预算。") 因而此前将“完整帧可直接通过哈希往返”视为既定能力的结论已被替代：刷新后的标题、滚动位置及文件或符号定位仍需上层补全，而本次材料没有证明恢复层或超限提示已经实现。

<a id="graph-progress-limits"></a>
## 关系展示进展与限制

关系图把模块与聚合导入边绘制为确定性分层 SVG。布局固定排序模块，排除 missing 和端点异常的边后进行最多十二轮分层迭代，再按层与行生成坐标；相同输入不会产生力导向式漂移，但循环或很深的依赖链不能视为严格最长路径结果。[关系图确定性分层 ↗](../../../packages/ui/src/components/OmRelationGraph.vue#L48 "支持过滤 missing 与异常端点边、固定排序、有界迭代并按层计算节点位置的流程。")

已有端点间的边使用贝塞尔曲线，candidate 与 stale 有专用样式，其他状态进入 confirmed 默认分支；端点缺失时路径为空且标签位置回退原点。[关系边路径与状态分支 ↗](../../../packages/ui/src/components/OmRelationGraph.vue#L107 "支持端点缺失时的空路径和原点回退，以及 missing 状态落入 confirmed 默认样式的限制。") 模板中鼠标可分别选择节点和边，节点也支持 Enter 或空格；但边标签键盘事件复用了节点处理器，会把边标识作为节点标识发出。[关系图鼠标与键盘事件 ↗](../../../packages/ui/src/components/OmRelationGraph.vue#L141 "支持鼠标分别选择节点和边，并证明边标签键盘事件错误复用节点选择处理器。") 因此此前“边标签具备与鼠标一致的键盘选择”这一结论被明确替代；missing 边的专用断裂样式也尚未由实际实现兑现。
