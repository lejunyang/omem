# 浏览器端到端验收脚本

该脚本在隔离临时目录中启动真实 Vue 前端、Fastify API 与 SQLite 存储，通过 Playwright 验证材料捕获、证据阅读、提案决策、待办跟进、飞书接入、响应式布局、故障展示和重启恢复。Agent、飞书注册及能力探测使用确定性替身，因此它证明的是产品流程与本地持久化集成，不等同于真实外部服务验收。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_setup"></a>
## 目标与测试环境

脚本直接启动应用、SQLite `Store` 和 Playwright 浏览器，属于跨前端、API 与存储的回归验收，而非仅检查组件或协议。[真实前端、API 与存储依赖 ↗](../../../scripts/browser-smoke.ts#L1 "支持脚本直接依赖 Playwright、应用构建器和 SQLite Store，说明其为跨层浏览器验收。") 它在临时目录中配置确定性 ACP Agent、飞书注册器、既有应用提供器和能力探测器，监听随机本地端口并收集页面异常。[隔离环境与确定性替身初始化 ↗](../../../scripts/browser-smoke.ts#L18 "支持临时目录、飞书替身、确定性 ACP fixture、真实应用启动及页面错误收集的测试边界。") 因而页面与本地持久层使用真实实现，但模型输出及飞书外部交互仍由固定替身控制。

<a id="proposal_decision_flow"></a>
## 材料、提案与决策主流程

辅助流程从固定 revision 的 fragment 构造带 Unicode 精确选择器的提案，经评估接口注入 `supported` 复核结论；它既能创建事项或声明，也能按预期版本替代既有实体。[固定证据提案评估流程 ↗](../../../scripts/browser-smoke.ts#L116 "支持提案类型、精确证据选择器、固定复核结论以及创建或替代实体的流程说明。") 主流程从空工作区录入材料，随后确认作业完成、提案自动生效、通知详情可见，并能返回原始证据。[材料捕获与自动应用验收 ↗](../../../scripts/browser-smoke.ts#L194 "支持从空工作区录入材料，到作业完成、实体生效、通知详情和原证据阅读的端到端断言。") 冲突声明还覆盖补充背景、拒绝和确认应用。来源再次捕获后，基于旧来源版本的提案会被标记为失效且不能提交，同时旧 revision 仍可回看。[人工决策与来源过期保护 ↗](../../../scripts/browser-smoke.ts#L387 "支持补背景、拒绝、确认应用，以及来源更新使旧提案失效且不可再提交；不支持新结论已经生成或应用。") 此结论替代此前“新证据替代旧结论”的表述；脚本并未生成或应用一个由新证据支持的新结论。

<a id="product_behaviors"></a>
## 阅读、跟进与飞书接入行为

证据阅读验收建立双向引用，覆盖递归入栈、环路返回、片段追问、关闭全部和历史版本回看；同一区段还检查待办通知、持久会话、等待、暂缓、取消及窄屏不泄露内部标识。[证据、版本、待办与日常助理交互 ↗](../../../scripts/browser-smoke.ts#L283 "支持环路证据栈、历史版本、待办通知、持久会话及等待、暂缓、取消等行为描述。") 飞书流程检查复用应用、二维码与直接授权链接、取消重配、导入凭据、owner 配对和启用，并断言密钥不出现在页面或状态 API。[飞书授权、复用应用与 owner 配对 ↗](../../../scripts/browser-smoke.ts#L487 "支持二维码授权、复用应用凭据、owner 配对启用和密钥不出现在 UI 与状态 API 的验收，同时界定外部交互由替身提供。") 这些断言证明 UI 与本地接入状态能够协作，不证明真实飞书授权轮询、网络重试或权限配置可用。

<a id="limits_failures"></a>
## 布局、故障与验收边界

布局检查覆盖桌面、768px 键盘焦点和 390px 全屏对话框，并通过页面交互连续进入第 100 层证据，确认只渲染当前正文块；它没有验证 URL 深链的序列化、刷新或直接打开。[响应式、焦点与百层证据导航 ↗](../../../scripts/browser-smoke.ts#L548 "支持桌面和移动布局、键盘焦点，以及通过页面交互进入第 100 层并保持单正文块渲染；不支持 URL 深链结论。") 故障场景通过数据库直接制造模型不可用和通知失败，再中断作业 API，检查错误可见、材料仍可读及 SQLite 重启恢复；这不等于执行了真实通知发送或重试。[故障可见性与重启恢复 ↗](../../../scripts/browser-smoke.ts#L646 "支持模型失败、数据库中标记的投递失败、API 离线降级和 SQLite 重启恢复，同时表明没有执行真实通知投递。") 最后脚本要求页面错误集合为空，写出浏览器验证记录，并清理浏览器、应用、存储和临时目录。[验收记录与资源清理 ↗](../../../scripts/browser-smoke.ts#L725 "支持最终页面错误检查、验证报告生成及临时资源清理的说明。")
