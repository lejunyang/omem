# 真实浏览器产品流程验收

该脚本以真实 Vue 页面、Fastify API 和临时 SQLite 数据库执行端到端验收，覆盖材料、证据、事项、判断、飞书接入、响应式阅读、异常展示、重启恢复与富文本安全。Agent、提案评估结果和飞书外部能力使用确定性替身，因此其结果不等同于独立模型复核或真实外部服务联调。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 验证用户真正走过的产品链路

脚本用于发现“组件单测通过，但完整产品链路不可用”的问题：它启动真实 API 与 SQLite，通过无头 Chromium 按可访问名称操作 Vue 页面，并收集页面异常和关键控制台错误。Agent 响应使用固定 ACP fixture，以保持界面断言稳定；验收重点是前后端、持久化和交互集成，而不是模型回答质量。参考 [真实栈与固定 Agent ↗](../../../scripts/browser-smoke.ts#L1 "说明脚本使用真实 Vue、API 和 SQLite，而 fixture Agent 仅用于保持界面断言确定性。") [验收环境启动 ↗](../../../scripts/browser-smoke.ts#L66 "支持临时数据目录、真实应用构建、本地随机端口和无头 Chromium 的启动方式。")

测试数据放在临时目录，服务监听随机本地端口。结束时脚本关闭浏览器、服务和数据库并清理目录，同时记录浏览器版本、已通过检查及错误列表。参考 [验收记录与资源清理 ↗](../../../scripts/browser-smoke.ts#L739 "支持错误汇总、验证记录写入，以及关闭资源并删除临时目录的行为。")

<a id="main-flow"></a>
## 从材料到可追溯行动

主流程先由用户录入材料，再根据固定 revision 与 fragment 构造带精确文本范围的提案，并把预设为 `supported` 的确定性 assessment 一同提交评估接口。这里验证的是评估之后的策略和产品流程，包括高置信结果自动生效、处理任务完成、通知生成，以及从事项或通知返回原始证据；它没有实际运行独立 verifier，不能证明复核质量。参考 [固定提案与评估输入 ↗](../../../scripts/browser-smoke.ts#L129 "表明测试直接向评估接口同时提交基于固定证据的提案和预设为 supported 的确定性 assessment，并未在此运行独立 verifier。") [材料到通知的产品流程 ↗](../../../scripts/browser-smoke.ts#L194 "支持材料录入、自动应用提案、任务完成、查看原证据和通知详情等产品流程断言。")

证据阅读覆盖递归跳转、循环返回既有层、基于当前原文追问，以及关闭全部后弹窗不再可见；材料产生新版本后仍可阅读旧 revision。事项侧还验证创建、完成、等待对象、暂缓与取消，日常助理的对话在页面切换后仍然保留。脚本没有断言弹窗关闭后焦点回到触发元素，因此焦点恢复不属于这里已验证的结论。参考 [递归证据与版本历史 ↗](../../../scripts/browser-smoke.ts#L283 "支持证据循环导航、基于原文追问、关闭后弹窗不可见，以及新旧 revision 均可阅读；该范围没有检查焦点恢复。") [事项与日常跟进 ↗](../../../scripts/browser-smoke.ts#L333 "支持事项创建完成、持久对话、等待、暂缓、取消及窄屏布局行为。")

<a id="decisions-and-integrations"></a>
## 需要判断的变更与飞书接入

对于会覆盖既有事实的变更，脚本分别验证补充背景、拒绝和确认应用三条处理路径；如果来源在判断前产生新版本，旧判断会显示失效且不能继续提交。确认应用后，测试还直接查询 SQLite，核对获批事实已经持久化。参考 [判断分支与过期保护 ↗](../../../scripts/browser-smoke.ts#L389 "支持补背景、拒绝、确认应用，以及来源更新后旧判断失效和获批事实持久化的论断。")

飞书场景覆盖复用已有应用、二维码与授权链接、取消后重配、导入凭据、生成配对码、确认 owner 和启用机器人，并断言密钥不会出现在页面或状态 API 中。注册器、能力探测和既有应用提供者均为脚本内替身，因此这些断言只验证本地接入流程和保密边界，不代表真实飞书开放平台当前可用。参考 [飞书接入与密钥保护 ↗](../../../scripts/browser-smoke.ts#L489 "支持二维码授权、既有应用复用、owner 配对和密钥不暴露等断言，也显示相关外部能力由脚本内替身提供。")

<a id="boundaries"></a>
## 界面边界、故障与未覆盖范围

界面验收覆盖桌面、768px 与 390px 视口无横向溢出；中窄屏与移动端均检查弹窗打开后 Tab 焦点仍处于弹窗内，并验证 Esc 可关闭弹窗。测试还走到 100 层持久证据链，并确认当前只渲染一个正文块，但未检查关闭后的焦点归还。参考 [响应式与深层证据 ↗](../../../scripts/browser-smoke.ts#L550 "支持不同视口、弹窗内焦点约束、Esc 关闭、移动端全屏弹窗和 100 层证据导航；该范围未断言关闭后焦点恢复。")

故障场景通过预置模型任务失败和通知投递永久失败，检查页面如实展示错误；脚本还单独中断 `/api/jobs` 请求，确认出现获取失败提示后“原始材料”导航仍可使用。随后重启真实服务，验证既有事项可从 SQLite 恢复；这里没有模拟整个 API 或网络全面断开。参考 [故障展示与重启恢复 ↗](../../../scripts/browser-smoke.ts#L652 "支持模型任务失败、通知失败、单独中断 /api/jobs 请求后的降级展示，以及服务重启后事项恢复；不支持将其解释为整个 API 断网。") 富文本阅读另行验证 Markdown 表格和 Mermaid SVG 可以显示，同时过滤脚本节点与 `foreignObject`。参考 [富文本渲染安全 ↗](../../../scripts/browser-smoke.ts#L727 "支持 Markdown 表格与 Mermaid 正常渲染，同时过滤脚本和 foreignObject 的安全断言。")

因此，本脚本不能证明真实 Agent CLI、目标模型、飞书网络或通知渠道可用，也未覆盖多用户竞争、长期任务恢复、性能以及 Firefox、WebKit 等跨浏览器兼容性。

<a id="test-oracle"></a>
## 通过条件与断言方式

每项检查只有在其中的 Playwright 可见性、文本、属性、焦点、布局或后端状态断言全部成功后，才会加入通过列表；最终还要求收集到的页面错误数组为空。中途异常会进入资源清理流程，但不会被记录为通过。参考 [检查记录机制 ↗](../../../scripts/browser-smoke.ts#L104 "说明检查函数仅在断言函数成功返回后记录通过，并由最终错误数组补充页面运行时判据。")
