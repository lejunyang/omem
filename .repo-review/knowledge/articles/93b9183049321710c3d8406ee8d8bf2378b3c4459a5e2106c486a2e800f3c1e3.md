# 个人助手端到端浏览器验收脚本

以真实 Vue、Fastify API 和临时 SQLite 为主干，配置确定性 ACP fixture，并以直接构造提案、操作任务仓库和飞书适配器的测试装配验证个人助手主要产品流程；它不证明真实 Agent 或外部飞书服务已运行。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_setup"></a>
## 问题与测试装配

该脚本解决“组件或协议测试通过，但真实产品链路仍可能断裂”的问题：它创建临时数据目录，组装真实服务、SQLite Store 和飞书 onboarding，并启动无头 Chromium 收集页面异常。为保证断言稳定，脚本提供注册适配器、能力探测和既有飞书应用提供器等 fixture，后者返回固定应用与凭据；同时在配置中登记 ACP fixture profile。[真实服务与确定性外部适配装配 ↗](../../../scripts/browser-smoke.ts#L1 "支持脚本使用真实服务与浏览器，并定义注册、能力探测、既有应用及 ACP profile 等确定性 fixture 的说明。") 这些装配隔离了外部系统，但脚本没有据此证明真实模型、Agent CLI 或飞书网络可用。

<a id="core_flows"></a>
## 核心验收流程

材料保存后，核心提案由 `evaluateTask` 直接注入 `/api/proposals/evaluate`；任务完成状态也由脚本直接 claim、标记运行并 succeed，而非实际启动 ACP Agent。[提案注入与任务状态直接驱动 ↗](../../../scripts/browser-smoke.ts#L116 "支持提案通过内部接口直接评估、任务由脚本直接领取并完成，而非实际调用 ACP Agent 的限定。") 在此基础上，UI 验证提案自动生效、通知与原证据阅读、循环引用和追问、不可变历史版本、待办状态，以及冲突提案的补背景、拒绝、批准和来源过期处理。[材料、证据与决策流程验收 ↗](../../../scripts/browser-smoke.ts#L193 "支持从材料捕获到提案、证据 Trail、历史版本、待办和冲突决策状态的产品流程描述。") 飞书流程覆盖二维码与授权链接、复用固定应用、配对 owner 和启用连接；保密断言仅确认指定 fixture secret 未出现在页面正文及状态响应。[飞书接入与固定密钥检查 ↗](../../../scripts/browser-smoke.ts#L451 "支持授权链接、既有应用复用、owner 配对及指定 fixture secret 不出现在页面和状态响应中的断言。")

<a id="boundaries"></a>
## 故障、布局与未覆盖行为

脚本检查桌面、768px 和 390px 的横向溢出、对话框焦点与 Esc 关闭，并构造 100 层证据链确认深层可达且当前正文渲染有界。[响应式与深证据链验收 ↗](../../../scripts/browser-smoke.ts#L512 "支持多视口、键盘焦点、移动端全屏对话框和百层证据导航边界的说明。") 它还直接写入模型任务失败和通知投递失败状态、拦截任务接口模拟离线，再重建服务确认材料与待办持久化。[失败展示与重启持久化 ↗](../../../scripts/browser-smoke.ts#L610 "支持模型任务失败、通知投递失败、任务接口离线及服务重启后数据仍存在的断言。") 未覆盖真实 ACP 执行、真实飞书注册及通知渠道、并发写入、浏览器矩阵、全部敏感字段枚举和故障自动恢复。
