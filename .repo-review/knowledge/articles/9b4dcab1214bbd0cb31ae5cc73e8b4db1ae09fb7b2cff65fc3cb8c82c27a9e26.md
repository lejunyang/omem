# 模块理解与文件入口帧

把知识文章或结构化模块理解、符号证据引用和模块内文件组织为统一阅读入口。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="content"></a>
## 模块说明的来源与结构

组件随模块标识请求对应知识文章，同时接收父组件提供的结构化理解详情；模块文件按语言分组，并按每组文件数量排序。[模块知识请求与文件分组 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L31 "支持知识文章随模块切换加载，以及文件按语言分组和按组大小排序的说明。") 没有知识文章时，结构化详情可展示职责、边界、关键流程、入口、出口、风险、未决问题和引用，并用 seed、stale、model、curatedBy 等字段标识来源与状态。[结构化模块理解主体 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L82 "证明结构化详情的来源状态、职责、边界、流程、入口出口、风险和未决问题等展示内容。")

<a id="references"></a>
## 证据与下探关系

详情引用按 node 与 evidence 分流。符号引用优先通过父级映射解析名称，失败时使用策展备注或“符号”，点击后只上报 symbolId，所属文件由父组件查询全局图补齐。[符号引用名称与事件 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L46 "说明内部符号标识如何转换为人类可读名称，以及文件归属由父组件补齐。") evidence 引用当前仅显示备注，不发出 fragment 下探；文件行则直接发出 fileId，即使文件被标记为已删除也仍保留点击行为。[证据引用和文件入口 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L131 "支持符号引用可点击、证据引用为静态内容，以及已删除文件仍发出文件下探事件的说明。")

<a id="boundaries"></a>
## 互斥展示与降级边界

知识文章、加载状态、空状态和结构化详情位于同一条 `v-if / v-else-if / v-else` 条件链，因此文章存在时不会同时渲染结构化详情；文件列表位于条件链之后，仍会继续显示。文章请求失败被静默忽略，界面随后依据 loading、detail 和 output 选择加载提示、空状态或结构化说明。[文章与结构化详情条件链 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L68 "直接证明知识文章、加载态、空状态和结构化详情互斥，而文件列表位于该条件链之后。") 材料没有展示已删除文件进入父级文件帧后的失败反馈，因此其最终可读性不能确定。[证据引用和文件入口 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L131 "支持符号引用可点击、证据引用为静态内容，以及已删除文件仍发出文件下探事件的说明。")
