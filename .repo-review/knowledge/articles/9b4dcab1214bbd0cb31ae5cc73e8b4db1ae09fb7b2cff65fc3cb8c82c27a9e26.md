# 模块说明、证据与文件下探界面

该组件把模块级知识正文、结构化代码理解结果、证据入口和模块文件清单汇集到同一阅读页面，并通过事件把知识引用、符号及文件的进一步浏览交给父组件处理。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 把模块结论与可核查入口放在一起

`ModuleFrame` 面向想快速理解一个代码模块的读者：顶部显示模块名称、文件数和解析符号数，优先加载已发布的知识文章；若文章不存在，仍可展示结构化模块说明或继续浏览文件，避免根据解析计数臆造摘要。模块名称由聚合模块的稳定标识转换而来，文件和符号统计也直接来自 `AggModule`。参考 [模块页概览 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L68 "支持页面展示模块名称、文件数、符号数以及优先呈现知识文章的说明。") [聚合模块数据结构 ↗](../../../apps/web/src/codewiki/modules.ts#L36 "说明模块标签转换以及文件数、符号数和文件集合的来源。")

知识文章加载成功后交给通用 `KnowledgeDocument` 渲染；其正文中的可操作引用会转成 `knowledge` 事件，由外层页面决定如何打开证据轨迹。请求通过共享知识 API 发出，该 API 会附带会话令牌，并把非成功响应转换成异常。参考 [知识正文导航 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L21 "支持知识正文由通用组件渲染并把引用导航事件上交的论断。") [知识请求封装 ↗](../../../apps/web/src/knowledge/api.ts#L6 "说明知识 API 如何携带会话令牌、处理响应错误并返回 JSON。")

<a id="display-flow"></a>
## 从模块切换到结构化说明

当 `mod.id` 变化时，组件先清空旧文章，再请求键为 `module:<模块标识>` 的知识元数据；请求失败会被静默忽略。随后页面按优先级呈现：已有文章时显示文章；否则在外部 `loading` 为真时显示读取提示；再否则，如果没有代码理解详情或输出，则明确提示“暂无已保存的说明”。参考 [文章加载与降级顺序 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L31 "支持模块变化时请求文章元数据，以及文章、加载提示和无说明占位的呈现顺序。")

结构化输出存在时，页面依次展示说明来源、是否过期、模型或整理者，以及职责、边界、关键流程、入口、出口、风险限制和未决问题。空职责与空流程有专门占位提示，但边界、入口、出口、风险和未决问题为空时不会额外解释，因此读者只能看到空面板。参考 [结构化模块说明 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L82 "支持职责、边界、流程、入口出口、风险和未决问题等结构化内容的展示及部分空状态行为。")

<a id="navigation-boundaries"></a>
## 下探导航与已知边界

引用被分成符号和原始证据两类。符号按钮优先显示 `symbolMap` 解析出的名称，其次使用说明备注，始终避免直接把内部符号标识展示给读者；点击时仅发出符号标识，所属文件留给父组件通过图数据解析。由于此处发送的 `fileId` 是空字符串，父组件必须完成映射后才能可靠打开目标。证据引用目前只展示备注，没有点击处理。参考 [符号与证据引用 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L46 "支持引用分类、符号人读标签、父组件负责文件解析以及证据当前不可点击的说明。")

文件按语言分组，并按各语言包含的文件数降序排列；点击文件会发送完整 `fileId`，已删除文件仍可出现在清单中并带有醒目标记。双栏的入口/出口区域在窄屏下改为单栏。组件只负责展示和发出导航意图，不负责维护证据抽屉、符号到文件的索引或知识文章内部的并发保护。参考 [引用和文件下探 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L131 "支持符号按钮、静态证据行、按语言分组的文件列表、删除标记与文件下探事件的说明。")

值得注意的是，本组件自己的文章请求没有类似 `KnowledgeDocument` 所用的 generation 校验：快速切换模块时，较早请求可能较晚返回并覆盖当前模块的元数据；现有材料未提供父层是否通过销毁组件或其他机制规避这一竞态的证据。延伸阅读：[正文请求竞态保护 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L11 "对照说明通用知识正文组件用 generation 丢弃过期响应，从而指出模块元数据请求缺少同类保护。")
