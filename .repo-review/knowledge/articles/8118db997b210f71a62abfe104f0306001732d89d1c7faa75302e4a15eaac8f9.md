# 材料分析角色版本 1 的运行清单

该清单声明 material-analyst 角色的版本、提示与内联技能、KnowledgeBatch.v1 输出合同、无工具策略、会话隔离和令牌预算。它是配置事实，但不能单独证明运行时严格执行这些策略。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role_binding"></a>
## 角色、提示与技能绑定

清单将角色标识为 material-analyst、版本设为 1，并引用 traex profile 与 prompt.md。技能包指定 canonical name、版本 1、inline 加载方式和固定 artifact digest；输出格式声明为 KnowledgeBatch.v1。[材料分析角色绑定配置 ↗](../../../packages/agent-runtime/roles/material-analyst/1/manifest.json#L2 "支持附近关于角色版本、profile、提示、内联技能及输出合同的说明。")

这组字段把角色提示、技能制品和结构化输出合同连接起来，便于版本化与复现。不过材料没有给出 digest 校验过程或 profile 内容，因此只能确认配置引用，不能确认制品完整性已被运行时验证。

<a id="isolation_and_budget"></a>
## 工具隔离、会话与预算

tool_policy 设为 none 且允许工具列表为空；session_policy 要求从不复用会话，也不继承用户技能或 MCP。这些设置意在让分析只基于注入材料，减少外部状态和用户环境对结果的影响。[工具、会话与预算策略 ↗](../../../packages/agent-runtime/roles/material-analyst/1/manifest.json#L18 "支持附近关于禁用工具、会话隔离、继承策略和令牌上限的说明。")

预算配置允许最多 96,000 个上下文 token、24,000 个输出 token和 2 次修复尝试。它们是上限声明，而非实际消耗记录；同样，是否拒绝工具调用、是否真正创建全新会话以及修复触发条件，都需运行时实现与测试确认。
