# 视觉材料分析角色配置

该清单声明视觉分析角色的版本、提示词与技能装载方式、结构化输出合同、工具和会话隔离策略，以及上下文与修复预算。它描述的是角色运行配置，不能单凭此文件证明宿主已完整执行这些约束。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 角色定位与输出边界

这份清单把角色标识为版本 1 的“视觉分析员”，并指定使用 `traex` profile 与 `prompt.md` 提示模板。它解决的是视觉材料进入知识流程时，如何选定稳定角色定义的问题；但清单只声明配置，不足以证明视觉识别或知识生成已经实际运行。参考 [角色与提示配置 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/manifest.json#L2 "支持角色标识、版本、运行 profile 和提示模板均由清单声明的论断。")

角色输出被约束为 `KnowledgeBatch.v1`，意味着分析结果预期以统一知识文档合同交给后续保存、复核或展示环节，而不是返回任意格式文本。参考 [结构化输出合同 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/manifest.json#L17 "支持视觉分析结果预期遵循 KnowledgeBatch.v1 合同的论断。")

<a id="isolation"></a>
## 技能装载与运行隔离

角色内联装载 `omem-visual-analyst` 版本 1，并记录制品摘要，用于把角色配置绑定到特定技能内容。摘要可支持一致性识别，但其校验时机与失败处理并未在本材料中说明。参考 [内联技能绑定 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/manifest.json#L9 "支持技能名称、版本、内联装载方式及制品摘要由配置固定的论断。")

工具策略明确为禁用且允许列表为空；会话策略同时禁止复用，也不继承用户技能和 MCP。由配置意图看，每次视觉分析应处于隔离环境，材料内容不能借助外部工具扩展或影响用户侧能力。是否由运行时强制执行，仍需结合宿主实现确认。参考 [工具与会话隔离 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/manifest.json#L18 "支持禁用工具、禁止会话复用以及不继承用户能力的配置说明。")

<a id="budget"></a>
## 上下文、输出与修复预算

该角色允许最多 96,000 个上下文 token、24,000 个输出 token，并配置最多两次修复尝试。这为较大的图像说明、上下文材料和结构化结果留出空间，也限制了格式修复循环；清单没有说明超限后的截断、报错或降级行为。参考 [角色运行预算 ↗](../../../packages/agent-runtime/roles/visual-analyst/1/manifest.json#L27 "支持上下文、输出和修复尝试上限的具体配置说明。")
