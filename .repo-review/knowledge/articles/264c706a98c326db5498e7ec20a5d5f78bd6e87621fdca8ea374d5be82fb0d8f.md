# 离线原型浏览器冒烟验证

使用 Playwright 在真实 Chromium 中验证离线知识阅读原型的主要交互合同，覆盖证据下钻、循环与历史版本、原位追问、状态恢复、响应式布局和离线约束；明确不验证后端或模型质量。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-harness"></a>
## 目标与测试装置

该脚本解决的是“静态原型能否在真实浏览器中完成关键交互”的回归验证问题。它启动无头 Chromium，固定桌面视口，监听脚本异常及 HTTP(S) 请求，并以本地 `index.html` 为入口；每项检查成功后记录名称，最终生成带浏览器版本和范围声明的验证报告。[浏览器装置与事件监控 ↗](../../../docs/prototype/smoke.mjs#L1 "支持脚本使用 Chromium、固定视口并收集页面异常和外部请求的说明。")

测试开始时清除演示用本地存储并刷新，因此主要场景从已知初始状态运行。它还会保存桌面、引用追问和移动端截图，但截图本身没有在脚本中做像素差异断言。[初始状态与桌面截图 ↗](../../../docs/prototype/smoke.mjs#L38 "支持清除本地存储、重新加载并保存桌面截图的测试准备说明。")

<a id="interaction-contract"></a>
## 核心交互断言

证据阅读合同是测试重点：脚本验证八层业务链到达末端、`Escape` 逐层返回、循环引用保留路径并可跳回既有层，以及历史修订能够切换到现行版本。[证据路径、循环与版本断言 ↗](../../../docs/prototype/smoke.mjs#L56 "支持多层下钻、逐层返回、循环跳转及历史版本切换等核心合同。") 对更深路径，它构造并走完 100 层合成链，再通过面包屑回到首层，说明原型不应把展示层数误作业务深度上限。[百层合成链 ↗](../../../docs/prototype/smoke.mjs#L175 "支持原型允许长证据路径并能从面包屑跳回首层的论断。")

追问流程覆盖回答范围选择、未发送草稿保留、回答引用继续下钻和圈选原文后原位提问；导航返回时还断言父层滚动位置、对话消息及触发按钮焦点得到恢复。[原位追问与状态恢复 ↗](../../../docs/prototype/smoke.mjs#L109 "支持回答范围、草稿、回答引用下钻、圈选提问及滚动和焦点恢复的说明。") 无权限、来源删除和定位待核对三类状态必须展示诚实说明，并禁用针对不可用证据的追问。[不可用证据状态 ↗](../../../docs/prototype/smoke.mjs#L186 "支持无权限、删除和定位失效时展示原因并禁用追问的边界行为。")

<a id="boundaries"></a>
## 响应式、持久化与未覆盖边界

外围场景还断言搜索结果与空状态、模拟同步的可见状态变化、恢复操作追加历史并在刷新后保留，以及阅读字号控件确实修改正文 CSS 变量。[搜索、同步、恢复与阅读样式 ↗](../../../docs/prototype/smoke.mjs#L200 "支持外围功能状态变化、本地历史保留及阅读字号生效的断言概述。") 移动视口下要求页面无横向溢出、引用对话框占满屏幕，并可继续完成追问。最后统一要求无页面异常且没有外部网络请求。[移动布局与离线约束 ↗](../../../docs/prototype/smoke.mjs#L243 "支持移动端全屏引用、可追问、零脚本异常和零外部请求的说明。")

边界必须按脚本自己的范围理解：报告明确标注为离线原型验证，不蕴含后端行为或模型评估。它没有验证真实同步、真实知识检索、模型答案正确性、服务端持久化、多浏览器兼容性，也没有覆盖视觉截图回归。[验证报告范围 ↗](../../../docs/prototype/smoke.mjs#L271 "支持该测试仅覆盖离线原型、不代表后端或模型评估的限制。")
