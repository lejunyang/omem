# 受控访问的图片资源展示

该组件根据资源 ID 从后端读取二进制图片，转换为浏览器对象 URL 后展示，并处理资源切换、请求取消、错误提示与内存释放。它通过公共 API 模块提供请求头，但现有材料不足以确认请求头的具体认证机制。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决受保护图片的展示问题

组件接收资源 `id` 与人类可读的 `label`，不把后端地址直接交给 `<img>`，而是先主动请求图片，再用生成的本地对象 URL 渲染。界面同时保留替代文本、图注和带 `alert` 语义的错误消息，适合在需要统一请求头或访问控制的页面中展示资源。参考 [图片与错误展示 ↗](../../../apps/web/src/AssetImage.vue#L36 "支持组件以图片、可访问错误提示和图注组成展示界面的说明。")

图片尺寸被限制在容器宽度和 450px 高度内，图注使用弱化样式，避免大图破坏阅读布局。参考 [图片布局约束 ↗](../../../apps/web/src/AssetImage.vue#L47 "支持图片最大尺寸、边框及弱化图注样式的说明。")

<a id="loading-flow"></a>
## 资源切换时的加载流程

组件立即监听 `id`：每次变化先取消上一请求、释放旧对象 URL，并清空显示与错误状态；随后请求 `/api/assets/{id}`，响应成功后读取 `Blob`，只有请求仍有效时才创建新的对象 URL。这个顺序避免快速切换资源时，较早完成的旧请求覆盖当前图片。参考 [资源加载与切换 ↗](../../../apps/web/src/AssetImage.vue#L8 "支持监听资源 ID、取消旧请求、清理旧 URL、读取 Blob 并防止已取消请求回写的流程说明。")

请求头来自共享 `api.ts` 的 `headers()`，说明资源读取复用了应用的 HTTP 配置入口；但所给 `api.ts` 片段没有该函数定义，无法据此确认它具体加入了共享令牌、内容类型还是其他字段。参考 [共享请求头 ↗](../../../apps/web/src/AssetImage.vue#L18 "支持资源请求调用共享 headers 函数的模块关系，同时界定现有材料无法说明其内部认证语义。")

<a id="boundaries"></a>
## 取消、失败与生命周期边界

非成功 HTTP 响应会统一转成“图片读取失败”，网络或 Blob 处理异常则以字符串形式展示；如果请求已经被取消，异常不会写入界面。组件卸载时还会取消在途请求并释放当前对象 URL，降低异步回写和浏览器内存滞留风险。参考 [卸载清理 ↗](../../../apps/web/src/AssetImage.vue#L31 "支持组件卸载时取消请求并释放对象 URL 的生命周期边界说明。")

当前实现没有显式加载占位、重试、按错误类型区分提示或校验响应 MIME 类型。材料中也未提供对应测试，因此只能确认代码中的防护路径，不能确认快速切换、卸载取消及失败展示已被自动化断言。延伸阅读：[资源加载与切换 ↗](../../../apps/web/src/AssetImage.vue#L8 "支持监听资源 ID、取消旧请求、清理旧 URL、读取 Blob 并防止已取消请求回写的流程说明。")
