# 资源图片异步加载组件

该 Vue 组件根据资源 ID 异步取得二进制响应并生成对象 URL，负责切换时取消旧请求、回收 URL、显示错误与图注。它确实导入并调用 api.ts 的 headers()，但现有固定范围未提供该函数定义，因而不能确认认证或具体请求头策略。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 界面职责

组件接收资源 `id` 与人类可读的 `label`，请求 `/api/assets/{id}`，将成功响应转为 Blob，再创建供浏览器显示的对象 URL。[资源请求与 Blob 转换 ↗](../../../apps/web/src/AssetImage.vue#L18 "支持资源接口请求、headers() 调用、HTTP 状态检查、Blob 转换及对象 URL 创建等附近论断。") 模板在 URL 就绪后渲染图片，并把 `label` 同时用于替代文本和图注；失败信息通过 `role="alert"` 呈现。图片还受到最大宽高、边框和圆角约束。[图片模板与展示样式 ↗](../../../apps/web/src/AssetImage.vue#L36 "支持图片、错误提示和图注的渲染方式，以及替代文本、尺寸和外观约束；也说明模板没有加载占位或重试控件。")

<a id="flow"></a>
## 加载、切换与竞态处理

监听器在首次挂载时立即运行，并随 `id` 变化重新加载。每轮会先取消旧请求、回收旧对象 URL并清空状态，再创建新的 `AbortController` 发起请求；只有当前信号未被取消时，成功结果或异常才会写入界面状态，从而降低旧请求晚到后覆盖新资源的风险。[资源监听与请求竞态控制 ↗](../../../apps/web/src/AssetImage.vue#L8 "支持立即监听、切换资源时取消旧请求、清理状态以及仅在请求未取消时更新结果的流程。")

<a id="lifecycle"></a>
## 生命周期与呈现边界

组件卸载时会取消在途请求并回收已有对象 URL，避免无效更新和 URL 长期滞留。[卸载阶段资源清理 ↗](../../../apps/web/src/AssetImage.vue#L31 "支持组件卸载时中止在途请求并释放对象 URL 的生命周期行为。") 当前响应流程只检查 HTTP 成功状态，随后直接读取 Blob；模板也只提供图片、错误信息和图注，没有独立的加载占位或重试控件，因此代码中看不到显式 MIME 校验与用户重试入口。[资源请求与 Blob 转换 ↗](../../../apps/web/src/AssetImage.vue#L18 "支持资源接口请求、headers() 调用、HTTP 状态检查、Blob 转换及对象 URL 创建等附近论断。")[图片模板与展示样式 ↗](../../../apps/web/src/AssetImage.vue#L36 "支持图片、错误提示和图注的渲染方式，以及替代文本、尺寸和外观约束；也说明模板没有加载占位或重试控件。")

<a id="dependencies"></a>
## 模块依赖与待确认事项

组件从 `api.ts` 导入 `headers()`，[公共请求头函数导入 ↗](../../../apps/web/src/AssetImage.vue#L2 "支持组件从 api.ts 导入 headers() 的模块依赖；其实际调用另由资源请求引用证明。") 并在资源请求的 `headers` 字段中实际调用它。[资源请求与 Blob 转换 ↗](../../../apps/web/src/AssetImage.vue#L18 "支持资源接口请求、headers() 调用、HTTP 状态检查、Blob 转换及对象 URL 创建等附近论断。") 现有材料只能确认这一依赖和调用关系，不能确认函数是否加入认证令牌、内容协商或其他配置。因此，先前把输入称为“受保护资源 ID”的结论已被替代：目前只能称其为资源 ID，保护机制仍待 `headers()` 定义佐证。
