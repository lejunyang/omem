# 受鉴权资产图片加载组件

AssetImage.vue 将受保护的资产接口响应转换为浏览器对象 URL，处理属性切换、请求取消、资源释放和可访问错误展示，并由材料阅读页按图片 part 的资产标识调用。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-flow"></a>
## 作用与加载流程

组件接收资产 id 与人读 label，通过共享 `headers()` 向 `/api/assets/{id}` 发起带请求头的 fetch；成功后把响应读取为 Blob，并创建临时 object URL 供 `<img>` 显示。非成功响应转为“图片读取失败”，模板用 `role="alert"` 展示错误，同时将 label 用作替代文本和图注。[鉴权图片读取与错误展示 ↗](../../../apps/web/src/AssetImage.vue#L3 "支持资产请求、Blob 转换、对象 URL 创建，以及错误、替代文本和图注的展示流程。")

<a id="race-and-cleanup"></a>
## 切换竞态与资源清理

对 id 的立即监听让首次挂载与后续切换走同一流程。每次切换先取消旧请求、撤销旧 object URL，并清空显示与错误；异步完成后检查 signal，避免已取消请求回写新状态。卸载时再次取消请求并释放 URL，降低 Blob URL 泄漏与陈旧图片闪现风险。[请求取消与对象 URL 回收 ↗](../../../apps/web/src/AssetImage.vue#L7 "支持 id 切换和卸载时取消旧请求、清理旧 URL，并防止取消后的异步结果回写。")

<a id="boundaries"></a>
## 边界与模块关系

组件只负责取得和展示二进制资产：它不校验真实图片格式、不上传，也不实现组件级缓存、重试、加载占位或按状态码细分提示；fetch 未指定的浏览器 HTTP 缓存行为不在此结论内。[组件实现与呈现边界 ↗](../../../apps/web/src/AssetImage.vue#L17 "支持组件仅执行 fetch、Blob URL 展示和基础尺寸样式，未实现组件级缓存、重试、加载占位或高级查看交互的判断。") 个人材料阅读页遍历 revision 的图片 part，并把 `assetId` 与 label 传入该组件。[材料阅读页的图片资产装配 ↗](../../../apps/web/src/App.vue#L551 "直接支持上层阅读页以图片 part 的 assetId 和 label 调用 AssetImage。") 服务端权限、响应内容类型与资产存在性仍是外部前提；样式仅限制宽高并保持自适应，没有缩放、下载或全屏预览。[组件实现与呈现边界 ↗](../../../apps/web/src/AssetImage.vue#L17 "支持组件仅执行 fetch、Blob URL 展示和基础尺寸样式，未实现组件级缓存、重试、加载占位或高级查看交互的判断。")
