# 服务端运行配置的解析与默认值

集中校验代理档案、通知、学习、飞书及捕获根目录配置，并结合环境变量生成数据目录、监听地址和认证令牌等运行参数。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="schema"></a>
## 配置合同与约束

配置至少要求一个代理 profile，并为通知、学习和飞书集成提供默认值。外部通知支持即时、窗口和定时模式；窗口长度、轮询间隔、本地时间均有边界，时区还会用 `Intl.DateTimeFormat` 验证为有效 IANA 名称。根配置以及 `notifications.external`、`learning`、`lark` 对象使用 `strict()` 拒绝未知字段；`notifications` 对象本身没有调用 `strict()`，不能把相同行为泛化到它。[配置模式、默认值与严格对象 ↗](../../../apps/server/src/config.ts#L5 "支持通知、学习、飞书和时区的约束，并可准确区分哪些对象调用了 strict。")

<a id="loading"></a>
## 加载顺序与运行派生值

加载时优先读取 `OMEM_CONFIG` 指向的文件，否则尝试默认本地文件，并在其不存在时回退到示例配置；JSON 随即经过 schema 解析，profile ID 还要通过额外的唯一性检查。[配置文件选择与档案去重 ↗](../../../apps/server/src/config.ts#L93 "说明配置文件回退顺序、schema 解析以及 profile ID 唯一性检查。") 数据目录来自 `OMEM_DATA_DIR` 或 `.omem`，启动时以私有权限递归创建；代理工作目录、令牌、监听主机和端口则由目录或环境变量派生。端口仅经 `Number` 转换，本文件没有验证其有限性、整数性或合法端口范围。[运行环境派生配置 ↗](../../../apps/server/src/config.ts#L105 "支持数据目录创建以及工作目录、令牌、监听地址和端口的环境变量来源与当前校验边界。")
