# 离线 TypeScript 与 Vue 结构解析器

以 TypeScript AST、Vue SFC 解析器和保守正则提取单文件符号、导入、名称级调用、路由、测试及组件使用，并返回可绑定固定证据片段的位置。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="pipeline"></a>
## 解析流程与产物

解析器是确定性离线前端：TypeScript/JavaScript 通过 Compiler AST 提取函数、类及方法、接口、类型、枚举、变量、导入和调用；位置统一为 1 基行、0 基列，签名只保留首行并限制长度。[AST 符号提取 ↗](../../../apps/server/src/code/parse.ts#L58 "支持 AST 提取的符号种类、位置和签名处理流程。") 调用只记录标识符或属性访问的末级名称及当前函数上下文，不建立 TypeScript `Program`，因此结果只是后续解析线索，不能证明跨文件或重载后的真实调用目标。[名称级调用收集 ↗](../../../apps/server/src/code/parse.ts#L167 "说明调用仅记录简单名称和函数上下文，不能作为跨文件调用证明。")

<a id="vue_regex"></a>
## Vue、正则提取与失败边界

Vue 文件先由 SFC 解析器拆块，优先分析 `script setup`，并按脚本块起始行校正位置；同时创建覆盖整个文件的组件符号，从模板中收集大写开头的组件标签。SFC 有解析错误时直接返回空结构而不抛出。[Vue SFC 解析 ↗](../../../apps/server/src/code/parse.ts#L236 "支持 Vue 错误回退、脚本行偏移、组件符号和模板组件提取的描述。") Fastify 路由与 `it/test` 名称由保守正则识别，只覆盖固定调用形态和字符串字面量；非 TS/JS/Vue 文件虽能识别语言，但不会产生结构结果。[路由、测试与语言边界 ↗](../../../apps/server/src/code/parse.ts#L198 "支持正则提取范围及非脚本文件返回空结构的边界说明。")
