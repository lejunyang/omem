# 离线 TypeScript/Vue 代码结构解析器

该文件将 TypeScript、JavaScript 与 Vue 源码确定性地转换为符号、导入、候选调用、路由、测试和模板组件信息，并附带源码位置。它面向代码审阅与固定片段绑定，但不进行跨文件类型解析；调用关系仅为名称级候选，路由、测试与模板标签采用正则提取。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_and_contract"></a>
## 作用与输出合同

解析器为代码审阅提供离线、可复现的结构化输入：TypeScript 部分仅分析单文件，不创建 `Program` 或解析跨文件类型；Vue 由 SFC 编译器拆块；路由和测试以正则补充。调用被限定为名称级候选，位置统一使用一基行号、零基列号，以便存储层绑定不可变审阅片段。[解析器设计目标与位置约定 ↗](../../../apps/server/src/code/parse.ts#L1 "支持解析器离线确定性、单文件 AST、名称级候选调用、正则补充能力及源码坐标约定。")

统一结果包含语言、组件名、符号、导入、调用、路由、测试和模板组件。符号保存限定名、种类、范围、导出状态及签名；签名取节点文本首行，超过 120 个字符时截断。[解析结果与签名生成 ↗](../../../apps/server/src/code/parse.ts#L15 "支持统一解析结果字段、符号元数据以及签名首行截断规则。")

<a id="core_flow"></a>
## 核心解析流程

`parseFile` 先按扩展名分类。TypeScript 与 JavaScript 进入 AST 遍历；Vue 优先选择 `<script setup>`，否则选择普通 `<script>`，并把脚本位置换算回 SFC 行号。随后插入一个代表整份文件的组件符号，其范围从首行第 0 列到最后一行第 0 列，并从模板收集组件标签。[Vue 文件入口与组件符号 ↗](../../../apps/server/src/code/parse.ts#L236 "支持 Vue 脚本块选择、原文件行号偏移、组件符号精确范围及模板组件收集流程。")

AST 遍历识别函数、类和方法、接口、类型别名、枚举、变量及静态 import；箭头函数或函数表达式初始化的变量记为函数。调用只保留标识符或属性访问的末级名称，并附当前 `contextName`，因此适合候选定位，不能证明实际调用目标。[TypeScript AST 遍历与调用上下文 ↗](../../../apps/server/src/code/parse.ts#L76 "支持符号、导入和调用的识别规则，并说明 callerQName 依赖单一可变上下文的限制。")

路由正则识别常见服务器对象、HTTP 方法及由单引号、双引号或反引号包围且不跨行的路径；测试正则同样匹配 `it` 或 `test` 中不跨行、长度不超过 200 的标题。二者不解析模板插值，因此反引号中的 `${...}` 会作为普通文本被记录，也不理解别名、封装调用或参数化测试。[路由与测试标题提取规则 ↗](../../../apps/server/src/code/parse.ts#L198 "支持三种引号、不跨行匹配、测试标题长度限制及模板插值不被解析的结论。")

<a id="boundaries"></a>
## 边界、修正与待验证行为

Vue 解析错误时不会抛出或返回诊断，而是保留语言和组件名并返回空集合；无脚本块时仍生成组件符号。模板标签要求首字符大写，随后只消费字母数字：通常小写开头的 `foo-bar` 不匹配，而 `Foo-Bar` 或 `Foo.Bar` 会被截为 `Foo`。这替代了“所有 kebab-case 或点号名称都会被截断”的过宽结论。[Vue 错误分支与模板标签正则 ↗](../../../apps/server/src/code/parse.ts#L240 "支持 Vue 解析失败返回空集合，并精确说明大写开头标签及连字符、点号导致的前缀截取边界。")

调用者上下文仅在递归回调直接遇到具名函数声明子节点时设置，返回后即清空；类方法、箭头函数、函数表达式和嵌套结构中的调用可能缺少或丢失正确的 `callerQName`。[TypeScript AST 遍历与调用上下文 ↗](../../../apps/server/src/code/parse.ts#L76 "支持符号、导入和调用的识别规则，并说明 callerQName 依赖单一可变上下文的限制。") 非 TypeScript、JavaScript、Vue 文件只分类并返回空结构；普通脚本则组合 AST、路由和测试结果。[普通脚本与其他文件分支 ↗](../../../apps/server/src/code/parse.ts#L288 "支持 TypeScript、JavaScript 组合解析结果，而其他已分类文件返回空结构的行为。") 固定材料未包含测试文件，无法确认位置换算、语法变体及正则误报是否已有真实行为断言。
