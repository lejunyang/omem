# 离线 TypeScript 与 Vue 结构解析

以 TypeScript 单文件 AST、Vue SFC 解析器和保守正则提取结构线索；Vue 是独立解析分支，只有其他非 TypeScript/JavaScript 文件才落入空结构回退。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="contract"></a>
## 解析目标与精度

解析器为同步流程提供确定性、离线的结构结果。TypeScript 部分只创建单文件 AST，不建立 `Program`，因此不做跨文件类型解析；调用关系只是名称级候选。Vue 由 SFC 编译器拆块，Fastify 路由和测试名称由保守正则识别。位置统一采用从 1 开始的行号和从 0 开始的列号，供后续绑定固定证据片段。[离线解析器能力边界 ↗](../../../apps/server/src/code/parse.ts#L1 "说明解析技术、单文件限制、候选调用语义及源码位置坐标约定。")

<a id="typescript"></a>
## TypeScript AST 遍历

遍历会提取函数、类及其方法、接口、类型别名、枚举和简单标识符变量，并记录导出状态、限定名、范围及截断后的首行签名。[符号提取遍历 ↗](../../../apps/server/src/code/parse.ts#L71 "支持 AST 提取的符号类别、限定名、范围和签名生成方式。") 调用表达式只保留标识符或属性访问的末级名称；调用者上下文主要在具名函数递归期间设置，无法证明动态分派、同名遮蔽或跨文件目标，因此只能作为定位线索。[名称级调用提取 ↗](../../../apps/server/src/code/parse.ts#L167 "支持调用只记录简单被调名称以及调用者上下文有限的边界判断。")

<a id="vue-and-fallback"></a>
## Vue、正则识别与失败路径

Vue 文件拥有独立的 SFC 解析流程：失败时保留语言和组件名并返回空集合；成功时分析 `script setup` 或普通 `script` 中优先选中的一个脚本块，修正行偏移，添加覆盖整个文件的组件符号，并从模板识别大写组件标签，同时提取路由与测试。[Vue SFC 解析流程 ↗](../../../apps/server/src/code/parse.ts#L236 "支持 Vue 解析失败降级、脚本块选择、行偏移、组件符号、模板组件以及路由和测试提取的说明。") 这替代了此前“所有非 TypeScript/JavaScript 文件都不提取结构”的过宽结论。准确边界是：TypeScript 和 JavaScript 会执行 AST、路由及测试提取，除 Vue 外的其他语言才只保留语言分类并返回空结构；路由和测试正则也仅覆盖特定调用者及字面量形式。[语言分类、脚本解析与最终回退 ↗](../../../apps/server/src/code/parse.ts#L198 "完整支持正则识别范围、语言分类、TypeScript/JavaScript 解析分支，以及其他非 Vue 文件返回空结构的最终回退边界。")
