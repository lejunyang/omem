# Lark 通知投递管线

实现交互卡片的官方发送适配、数据库租约队列、错误分类与有限重试，并支持窗口或定时通知聚合。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="adapter-and-errors"></a>
## 平台适配与错误语义

`OfficialLarkMessageAdapter` 根据飞书或 Lark 品牌选择 SDK 域名，以聊天 ID 发送交互卡片，并用调用方提供的 UUID 参与平台去重；更新接口则按消息 ID 修补卡片。响应缺少消息 ID被视为结果不明确。[官方消息发送与更新适配 ↗](../../../apps/server/src/integrations/lark/delivery.ts#L113 "说明平台域选择、交互卡片发送、供应商 UUID 和消息更新行为。") 错误分类把 429 或特定平台码归为限流，401/403 及鉴权码归为认证错误，服务端或网络故障归为不明确，其余归为永久错误；同时遮蔽传入的敏感值。[Lark 错误分类 ↗](../../../apps/server/src/integrations/lark/delivery.ts#L53 "支持限流、鉴权、不明确和永久错误的分类规则及敏感信息遮蔽。")

<a id="lease-and-delivery"></a>
## 租约队列与投递状态

仓储以 `BEGIN IMMEDIATE` 事务认领到期意图或过期租约，并跳过连接失效、绑定被替代及已非活动状态的标注会话。首次发送超过一小时的平台去重窗口后，若结果仍不明确，就转为 `unknown`，不再盲目重试。[投递认领与发送前抑制 ↗](../../../apps/server/src/integrations/lark/delivery.ts#L190 "说明租约认领、去重窗口过期转未知，以及连接、绑定和标注会话状态检查。") 工作器取加密凭据，校验应用标识、负载摘要和 30 KB 卡片上限，再调用适配器；成功时同时落投递回执、卡片消息 ID及标注会话消息 ID。失败最多尝试五次，只有限流或仍在去重窗口内的不明确错误可重试；鉴权失败还会禁用同连接目标并终止其他待发意图。[失败重试与工作器执行 ↗](../../../apps/server/src/integrations/lark/delivery.ts#L353 "支持成功回执写入、失败状态计算、鉴权级联停用及工作器负载校验。")

<a id="batching"></a>
## 通知聚合

批处理器挑选已到聚合时间的窗口或定时意图，按工作区、绑定、目标和聚合模式分组，并通过映射表汇总去重后的变更。单意图单变更直接转即时发送；多项则生成摘要卡片、重新计算摘要与稳定供应商 UUID，把其余成员取消并指向主意图。[窗口和定时聚合 ↗](../../../apps/server/src/integrations/lark/delivery.ts#L461 "说明聚合分组、变更映射、摘要卡片生成和成员意图替代。") 摘要正文和总负载均有限制，但标题与详情采用截断而非分页；超出 30 KB 会回滚整个事务。
