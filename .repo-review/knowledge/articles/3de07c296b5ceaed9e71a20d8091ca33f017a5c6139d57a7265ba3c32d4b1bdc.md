# Lark 通知投递、聚合与重试状态机

实现 Lark 卡片发送与更新适配、数据库租约队列、错误分类、去重窗口、通知聚合和工作器编排，使外部投递结果可追踪并避免无限重试。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="adapter_and_errors"></a>
## 平台适配与错误分类

官方适配器按飞书或 Lark 品牌选择 SDK 域名，发送 interactive 消息时传入 provider UUID，并可 patch 已有消息；缺少消息编号被视为结果不确定。[官方消息适配器 ↗](../../../apps/server/src/integrations/lark/delivery.ts#L113 "支持品牌域名选择、交互卡发送、provider UUID、消息更新及缺少消息编号的处理。") 异常统一分为限流、认证、永久失败和结果不确定：429 与特定码归为限流，401/403 与鉴权码归为认证失败，服务端或网络故障归为不确定，敏感密钥会从错误文本中替换。[Lark 异常分类 ↗](../../../apps/server/src/integrations/lark/delivery.ts#L56 "支持限流、认证、结果不确定和永久失败的分类以及敏感信息脱敏。")

<a id="lease_state_machine"></a>
## 租约领取与投递状态

仓储在 `BEGIN IMMEDIATE` 事务内领取到期意图，先检查一小时去重窗口、连接、绑定和标注会话状态，再把意图改为 sending，写入租约、尝试次数及投递历史。[事务领取与发送前门禁 ↗](../../../apps/server/src/integrations/lark/delivery.ts#L178 "支持即时事务领取、去重窗口检查、连接与绑定门禁、标注会话抑制及发送租约创建。") 成功提交必须匹配当前租约令牌，并同步更新意图、投递记录、决策卡消息号和标注会话消息号；失败最多尝试五次，限流可退避，不确定结果仅在代码设定的一小时窗口内重试，认证失败会停用连接相关目标和待投递项。[成功回写与失败处置 ↗](../../../apps/server/src/integrations/lark/delivery.ts#L353 "支持租约保护的成功写回、关联消息号更新、五次上限、去重窗口和认证失败停用。")

<a id="batching"></a>
## 窗口聚合与内容边界

批处理器按工作区、绑定、目标和聚合模式组合到期意图，并要求每组能映射到具体变更。多个成员被整理成摘要卡，主意图转为即时发送，其余成员取消并指向主意图；聚合卡超过 30 KB 会失败。[窗口聚合与摘要卡 ↗](../../../apps/server/src/integrations/lark/delivery.ts#L461 "支持聚合分组、变更映射、主从意图状态、摘要构造和聚合阶段大小限制。") 工作器发送前还会核对密钥所属应用、载荷稳定摘要和 30 KB 大小限制，再把发送结果交回仓储状态机。[工作器完整性检查 ↗](../../../apps/server/src/integrations/lark/delivery.ts#L598 "支持密钥应用匹配、载荷摘要与大小复核，以及发送结果回写仓储。")
