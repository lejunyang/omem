# 飞书质量标注会话服务

该服务把质量数据集中的待审核样本组织成飞书交互卡片，通过事务化投递意图启动或续发会话，并对回传动作执行身份、消息、时效、摘要和随机数校验；验证成功后原子记录标注、推进样本并更新卡片。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-card"></a>
## 作用与卡片协议

该服务解决“由已绑定 owner 在飞书中逐条复核质量样本”的问题。卡片动作采用严格的 `omem.quality.v1` 结构，携带会话、样本、动作、随机数、标签摘要和过期时间；随机数哈希比较使用定时安全函数，降低伪造与重放风险。[动作协议与安全比较 ↗](../../../apps/server/src/quality/lark-annotations.ts#L12 "支持卡片动作字段受到严格校验，以及 nonce 哈希采用定时安全比较的说明。") 卡片同时展示原始材料、建议提炼结果、数据集进度以及确认、不提炼、需修改、稍后处理四种动作；若证据与原文完全一致则避免重复展示全文。[质量标注卡片构造 ↗](../../../apps/server/src/quality/lark-annotations.ts#L42 "支持卡片展示内容、进度和四种人工处置按钮的说明。")

<a id="session-and-delivery"></a>
## 会话启动、续发与取消

`start` 先检查同一数据集的活动会话：普通重复调用直接返回已有会话，显式 `resend` 则轮换 nonce、清空消息标识，并在同一事务中写入变更记录和新的飞书投递意图。[活动会话续发流程 ↗](../../../apps/server/src/quality/lark-annotations.ts#L180 "支持重复启动判定、续发时轮换凭证及事务化创建投递意图的说明。") 新会话必须存在待处理样本及有效的个人点对点 owner 通知目标；随后会话、变更、投递意图和二者关联被一次性提交。这里仅负责入队，实际网络发送属于投递模块。[新标注会话与投递意图 ↗](../../../apps/server/src/quality/lark-annotations.ts#L265 "支持目标筛选、待处理样本检查，以及会话和投递记录共同入库的说明。") `cancel` 只允许取消活动会话，并同步撤销尚未发送或等待重试的意图；发送中和已送达记录会保留，以免虚构消息已被召回。[会话取消语义 ↗](../../../apps/server/src/quality/lark-annotations.ts#L151 "支持仅撤销未发送意图、保留发送中及已送达历史这一边界。")

<a id="validation-and-advance"></a>
## 回调验证、幂等与推进边界

`handle` 只接受卡片动作事件，并先借助 `LarkEventInbox` 持久化收件；已经处理过的重复事件直接返回成功提示。[飞书事件收件与去重 ↗](../../../apps/server/src/quality/lark-annotations.ts#L355 "支持服务依赖收件箱持久化事件，并对已处理重复回调做幂等响应。") 对新事件，服务同时核对会话状态、当前样本、owner、会话、消息、应用、过期时间、标签摘要和 nonce，任一不符都会把收件记录标为失败。[卡片动作完整校验 ↗](../../../apps/server/src/quality/lark-annotations.ts#L369 "支持对身份、聊天、消息、应用、时效、标签摘要和 nonce 联合校验的说明。") 验证通过后，样本标注、审计事件、收件状态和会话游标在一个数据库事务内更新；仍有待审样本时轮换 nonce 并返回下一张卡，否则完成会话。[标注事务与下一样本推进 ↗](../../../apps/server/src/quality/lark-annotations.ts#L395 "支持标注、审计、收件处理和会话推进原子完成，以及返回下一卡片或完成卡片的说明。") 它明确依赖质量仓库管理样本和标签、加密密钥仓库派生 nonce 哈希、Store 提供 SQLite 事务；跨文件更深层的并发约束和投递行为无法仅凭当前材料确认。
