# 共享知识阅读与证据追溯界面

`@omem/ui` 是个人记忆与仓库知识共用的 Vue 3 界面基础，覆盖应用外壳、安全正文与代码展示、来源提示、证据 Trail、深链和关系图。局部组件合同已经形成，但调用方串接、超长路径处理与若干键盘和缺失关系行为仍需验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 让不同知识入口共享一种阅读语言

`@omem/ui` 解决的是知识界面各自实现、交互含义不一致的问题：个人记忆、仓库文章、源码证据和架构关系都可复用同一组 Vue 3 组件、样式令牌与阅读合同。包以统一入口和令牌样式对外提供能力，并集中依赖 Markdown 解析、HTML 净化、代码高亮与 Mermaid 渲染。参考 [共享 UI 包边界 ↗](../../../packages/ui/package.json#L1 "支持该模块是 Vue 3 共享包，并统一导出入口、视觉令牌及正文渲染相关依赖。")

应用外壳负责组织顶部工具区、导航、正文和助理区域，并在窄屏下将侧栏转换为抽屉；来源状态则帮助读者区分原始证据、派生说明、候选判断、过期内容和加载失败。业务路由、权限、数据获取及具体动作仍属于调用方。延伸阅读：[统一知识阅读界面 ↗](6607c2c3bf5f37d90f40dbb9be65efb451562d2e65e1b7437d9c1a7e6198dfcc.md#reader-foundation "解释共享外壳、响应式布局、视觉基线及调用方责任，支持模块的界面基础定位。")、[内容来源状态 ↗](6607c2c3bf5f37d90f40dbb9be65efb451562d2e65e1b7437d9c1a7e6198dfcc.md#evidence-reading "解释阅读器如何区分不同来源阶段，支持统一阅读语言的论断。")

<a id="content-flow"></a>
## 安全呈现知识正文与源码

知识正文不是直接注入页面：引用先被识别，Markdown 再被解析；普通代码块进入高亮流程，Mermaid 先保留为占位内容，正文 HTML 净化后才渲染图形，生成的 SVG 还会再次净化。异步结果仅在属于最新渲染代次时提交，失败时保留可读的原始图表描述。参考 [正文安全呈现流程 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#content-reading "支持引用替换、Markdown 解析、正文净化、Mermaid 渲染与二次净化的处理顺序。")

```mermaid
flowchart LR
  A[知识正文与引用] --> B[Markdown 解析]
  B --> C[代码高亮]
  B --> D[Mermaid 占位]
  C --> E[正文净化]
  D --> E
  E --> F[图形渲染与再次净化]
```
参考 [正文安全呈现流程 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#content-reading "支持引用替换、Markdown 解析、正文净化、Mermaid 渲染与二次净化的处理顺序。")

源码阅读沿用共享高亮能力，以稳定行号支持定位、范围导航和逐行引用；未知语言会安全转义后原样展示，跨行样式通过换行时闭合并重开高亮标记来保留。参考 [安全代码展示 ↗](6607c2c3bf5f37d90f40dbb9be65efb451562d2e65e1b7437d9c1a7e6198dfcc.md#code-reading "支持语言懒加载、未知语言转义、跨行高亮保持及现有验证边界。")

<a id="evidence-trail"></a>
## 沿引用逐层阅读并返回原处

读者打开引用或关联对象时，共享 Trail 状态按对象类型和稳定身份建立帧栈，并保存标题、滚动位置及恢复数据所需的引用字段。抽屉用面包屑展示路径，打开或切层时聚焦当前标题并恢复滚动；Esc 在多层时返回上一层，关闭后把焦点交还触发元素或先前焦点。参考 [证据追溯交互 ↗](6607c2c3bf5f37d90f40dbb9be65efb451562d2e65e1b7437d9c1a7e6198dfcc.md#evidence-reading "支持证据帧入栈、逐层返回、焦点归还和滚动恢复的阅读流程。")、[分层阅读路径合同 ↗](6607c2c3bf5f37d90f40dbb9be65efb451562d2e65e1b7437d9c1a7e6198dfcc.md#trail-contract "支持 Trail 帧字段、循环检测、面包屑与可恢复路径的说明。")

轨迹可写入哈希深链，以支持刷新恢复和分享。完整渲染栈不应因 URL 长度而截断，但当前只约定最多持久化 200 帧；标题、滚动位置等信息仍需上层根据 `kind` 与 `id` 恢复。关系图同样只发出节点或边的选择事件，具体打开哪类证据由调用方决定。参考 [深链与证据容器 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#navigation-and-graph "解释哈希路由、证据对话框、轨迹深度预算及关系图选择由调用方承接。")、[共享组件能力边界 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#current-boundaries "支持局部原语已经实现但端到端调用链尚无充分材料证明的判断。")

<a id="limits"></a>
## 当前进展与实现边界

现有子章节证明共享组件已覆盖外壳、正文、源码、证据抽屉、深链和关系图等局部能力，但没有足够调用方与浏览器材料证明它们已串成完整、可往返的端到端阅读流程。因此，这一模块更准确地说是已经形成共享原语和合同，集成验收仍不完整。参考 [统一知识阅读界面 ↗](6607c2c3bf5f37d90f40dbb9be65efb451562d2e65e1b7437d9c1a7e6198dfcc.md#reader-foundation "解释共享外壳、响应式布局、视觉基线及调用方责任，支持模块的界面基础定位。")、[共享组件能力边界 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#current-boundaries "支持局部原语已经实现但端到端调用链尚无充分材料证明的判断。")

待完善点包括：清空异步渲染中的 Markdown 时可能未复位加载状态；哈希中的未知轨迹类型缺少明确运行时策略；超过 200 帧的提示与持久化责任未见落实。关系图对缺失端点可能产生空路径或异常标签，边标签的键盘操作与鼠标选择语义也不一致。参考 [轨迹与渲染限制 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#current-boundaries "支持 Markdown 加载状态、未知轨迹类型和 200 帧持久化提示等未决边界。")、[关系图实现边界 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#current-boundaries "支持缺失关系渲染和边标签键盘选择语义存在问题的说明。")
