# ui · 模块理解

@omem/ui 是 Vue 3 应用可复用的展示与证据阅读层，提供基础控件、安全 Markdown、源码阅读、Evidence Trail、深链和关系图；完整轨迹恢复、超长深链提示、移动端覆盖语义、missing 关系呈现及键盘等价性仍待补齐。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-boundary"></a>
## 作用、背景与边界

`@omem/ui` 是私有 ESM 包，通过根入口和令牌样式提供能力，由消费方提供 Vue 3；Markdown 解析、HTML 清洗和代码高亮依赖集中在包内。[共享 UI 包配置 ↗](../../../packages/ui/package.json#L1 "支持私有 ESM、公开入口、Vue 对等依赖以及 Markdown 清洗和高亮依赖范围。") 公共出口将基础控件、应用外壳和知识阅读组件组织为供上层应用复用的展示与阅读能力，但现有依据不足以声称个人知识与仓库评审均已复用其中全部能力。[共享 UI 的公共表面 ↗](6607c2c3bf5f37d90f40dbb9be65efb451562d2e65e1b7437d9c1a7e6198dfcc.md#role-and-surface "提供下钻入口，支持公共出口将展示与阅读能力供上层应用组装的有限结论。") 本次覆盖的实现主要承担呈现、组合与交互；此前对整个包“不保存知识或决定权限”的宽泛判断，已被“现有子章节没有证明这些职责由 UI 模块承担”这一较窄结论替代。[基础组件与模块边界 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#role-and-boundary "支持基础控件承担展示和组合职责，并限定对知识持久化与权限职责的判断范围。")

<a id="reading-flow"></a>
## 证据阅读流程

阅读从正文内联引用进入：Markdown 组件替换引用入口、解析和清洗内容、处理代码高亮，再把点击分流到证据、站外链接或站内导航；失败时保留原始 Markdown。源码查看器继续提供稳定行号、范围定位、逐行证据入口和异步竞态保护。[富文本、源码与证据入口 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#evidence-reading "说明 Markdown 清洗、点击分流、源码行号和共享高亮器的协作流程。") 高亮器仅加载已知语言，未知语言先转义；已有测试覆盖 TypeScript 跨行注释和恶意标签转义，但不能据此推断全部语言与完整查看器均已验证。[代码阅读测试边界 ↗](6607c2c3bf5f37d90f40dbb9be65efb451562d2e65e1b7437d9c1a7e6198dfcc.md#code-reading-progress "概括高亮加载、转义策略、已有测试及尚未覆盖的范围。") 来源提示与关系状态分离，使派生说明保持为解释和下钻入口，而不是新的独立事实证据。[页面骨架与可信层级 ↗](6607c2c3bf5f37d90f40dbb9be65efb451562d2e65e1b7437d9c1a7e6198dfcc.md#shell-and-provenance "支持来源层级与关系状态分离，以及派生说明不成为独立证据的边界。")

<a id="trail-and-relations"></a>
## 跨层下钻与关联展示

Evidence Trail 用帧栈组织模块、文件、符号、知识、引用和原文；状态层负责入栈、返回、跳层与关闭，抽屉负责 Escape 退层、面包屑回跳、滚动恢复和焦点归还。[共享证据路径协作 ↗](6607c2c3bf5f37d90f40dbb9be65efb451562d2e65e1b7437d9c1a7e6198dfcc.md#evidence-trail "概括 Trail 状态管理、抽屉交互、滚动恢复和焦点归还之间的协作。") 哈希深链只持久化 `kind` 与 `id`，刷新后的标题和定位仍需上层补全；200 帧是 URL 预算而非渲染上限，超限提示与完整恢复尚未得到证明。[证据轨迹与深链限制 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#trail-and-routing "支持哈希只保存部分帧信息，以及 URL 预算和完整恢复仍需上层落实的判断。")

关系图通过固定排序和有界分层生成确定性 SVG。[关系图确定性布局 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#graph-progress-limits "支持关系图通过固定排序和有界分层形成稳定布局的论断。") 但 missing 边可能无路径或落入 confirmed 默认样式，边标签的键盘处理也与鼠标选择语义不一致；此前“边标签具备键鼠等价选择”的结论已被这一限制替代。[关系展示交互限制 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#graph-progress-limits "支持 missing 边呈现不完整以及键盘与鼠标选择语义不一致的限制。")

<a id="progress-and-limits"></a>
## 进展与待验证边界

模块已形成可组合的视觉基线、响应式外壳、富文本、源码高亮、来源提示、证据轨迹和关系图。窄屏导航与助手会覆盖正文，但现有知识未证明遮罩、Escape、焦点约束或展开状态属性已经实现，因此交互语义仍需选择。[响应式应用外壳 ↗](6607c2c3bf5f37d90f40dbb9be65efb451562d2e65e1b7437d9c1a7e6198dfcc.md#shell-and-provenance "说明窄屏覆盖层现状及移动端模态、键盘和焦点语义尚未明确。") Trail 超出 URL 预算时由谁提示并保留当前栈，也需检查路由调用层和浏览器行为。[Trail URL 预算待验证行为 ↗](6607c2c3bf5f37d90f40dbb9be65efb451562d2e65e1b7437d9c1a7e6198dfcc.md#evidence-trail "追踪超限持久化提示、当前渲染栈保留及刷新恢复责任。") 阅读器还需验证大文件逐行渲染性能与多重范围命中。[阅读器性能与范围限制 ↗](1b40261c65b451f408e0ccbf7d88005ab4224d221aceb724a01f04d81f067d44.md#evidence-reading "追踪源码阅读器逐行渲染性能和多重范围命中尚未验证的边界。")
