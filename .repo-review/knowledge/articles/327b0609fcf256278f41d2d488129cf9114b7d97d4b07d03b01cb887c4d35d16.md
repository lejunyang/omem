# 代码分析技能的 OpenAI 界面元数据

该 YAML 为技能提供人类可见名称、简短英文描述和默认调用提示，作用是帮助支持该界面的宿主展示并触发技能；它不包含分析规则本身，也不能证明特定模型或运行时已接入。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="interface-metadata"></a>
## 展示信息

配置在 `interface` 下给出中文展示名“分析代码材料”，并用英文短描述概括从固定证据构建关联知识的目标。[代码分析技能界面名称与简介 ↗](../../../packages/agent-runtime/roles/code-analyst/1/skills/omem-code-analyst/agents/openai.yaml#L1 "支持该文件提供中文展示名和固定证据知识构建简介的说明。") 这属于界面和发现层元数据，便于用户识别技能，但未规定输出 schema、证据范围或错误处理。

## 默认调用方式及限制

默认提示要求使用 `$omem-code-analyst` 处理提供的固定材料，说明宿主预期通过技能名触发配套规则。[代码分析技能默认提示 ↗](../../../packages/agent-runtime/roles/code-analyst/1/skills/omem-code-analyst/agents/openai.yaml#L4 "支持默认通过技能名处理固定材料的调用意图。") 具体分析纪律仍位于技能正文和角色提示中；当前材料没有说明该 YAML 由哪个客户端读取，也没有模型、effort、权限或兼容版本配置，因此不能推断实际调用链已经可用。
