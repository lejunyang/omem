# 知识阅读界面的真实浏览器验收

该脚本以无头 Chromium 操作已运行的个人应用，验证真实仓库知识的导航、引用阅读、分层证据轨迹、原始材料、变更历史、Agent 能力探测及多视口布局。它依赖预置知识和变更数据，不负责启动服务或生成验收数据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 验证真实仓库知识可以阅读

脚本同时操作真实页面和知识 API。进入“知识库”后，它要求章节正文、知识目录与本篇目录可见，并确认 README 已接入、专题文章达到基本数量；因此验收对象是统一应用中的实际仓库内容，而非孤立组件。参考 [真实仓库知识入口 ↗](../../../scripts/code-wiki-viewport.ts#L13 "支持统一应用中知识目录、正文、README 材料和专题文章均来自真实运行数据的论断。")

它还反复切换飞书机器人、日常助理、能力与连接和知识库，核对面包屑与菜单状态一致，并确认飞书页面错误不会泄漏到其他页面。参考 [导航与错误隔离 ↗](../../../scripts/code-wiki-viewport.ts#L27 "支持菜单、面包屑和激活状态一致，以及飞书错误不泄漏到其他页面的说明。")

<a id="citationTrail"></a>
## 从正文引用进入分层证据阅读

引用验收先定位网关代码文章，并检查同一段落没有重复指向同一目标。打开可操作引用后，脚本断言抽屉初始展示固定行区间，验证向上展开后的首行，再操作“向下展开 20 行”按钮；当前并未断言向下展开后的行数或末行。关闭抽屉后，焦点应返回原链接。参考 [固定代码区间阅读 ↗](../../../scripts/code-wiki-viewport.ts#L36 "支持固定区间和向上展开结果的断言、向下展开按钮操作，以及关闭后焦点恢复；也界定了向下展开未检查结果。")

随后，读者可从代码材料进入对应知识解读，再打开内层引用形成三层轨迹。脚本验证返回时恢复滚动位置、URL 保存轨迹、刷新后恢复第二层，以及 Esc 逐层退回并最终关闭。参考 [分层阅读轨迹 ↗](../../../scripts/code-wiki-viewport.ts#L62 "支持知识解读、内层引用、滚动恢复、URL 深链刷新与 Esc 逐层回退流程。")

```mermaid
flowchart LR
  A[知识文章] --> B[固定代码区间]
  B --> C[材料知识解读]
  C --> D[内层引用]
  D -->|Esc| C
```

该路径只选择运行时解析成功且可操作的材料引用，未直接覆盖缺失或失效引用的展示。

<a id="readingAndIntegration"></a>
## 覆盖原文、变更与连接设置

原始材料模式按可读名称查找 README，要求它以连贯 Markdown 文档展示，保留标题和代码围栏，同时不暴露“片段 1”之类的存储结构。参考 [原始 Markdown 阅读 ↗](../../../scripts/code-wiki-viewport.ts#L90 "支持 README 按完整文档呈现、保留代码围栏且不显示存储片段标签的论断。")

变更历史场景会打开捕获材料的真实差异，确认存在新增或删除内容，并检查“材料处理”页面采用用户可读名称。参考 [材料变更与处理页面 ↗](../../../scripts/code-wiki-viewport.ts#L101 "支持真实差异内容可见以及材料处理页面使用面向用户名称的说明。") 设置场景则等待 Agent 能力探测响应，确认模型与思考强度已自动读取，并显示本地连接无需访问令牌。参考 [Agent 能力探测 ↗](../../../scripts/code-wiki-viewport.ts#L113 "支持自动探测模型与思考强度，并提示本地连接无需令牌。")

<a id="boundaries"></a>
## 运行前提与验收边界

脚本假定应用已在 `OMEM_WEB_URL` 或默认本地地址运行，且数据中已有 README、专题文章、指定网关文章、可操作引用和捕获变更。浏览器默认无头运行，也可通过环境变量指定 Chromium 可执行文件。参考 [浏览器运行配置 ↗](../../../scripts/code-wiki-viewport.ts#L3 "解释默认服务地址、输出目录、无头模式和可选 Chromium 路径等运行前提。")

最后，脚本在 1440、768、390 三种宽度下检查页面无水平溢出、正文可见并保存截图。只有全部流程成功且收集到的页面错误为空时，才会写出报告；浏览器关闭则由 `finally` 保证，无论成功或失败都会执行。参考 [多视口与报告写入 ↗](../../../scripts/code-wiki-viewport.ts#L123 "支持三种视口检查、截图、页面错误断言、成功后写报告，以及浏览器始终关闭的准确边界。") 这些检查属于关键阅读路径的端到端冒烟验收，不能单独证明其他浏览器、网络失败恢复或全部外部 Agent CLI 行为正确。
