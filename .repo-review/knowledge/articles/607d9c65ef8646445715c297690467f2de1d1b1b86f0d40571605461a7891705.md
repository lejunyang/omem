# 关联知识刷新技能规范

技能文档复述了知识刷新职责与结构化产出规则：增量更新受影响知识、保持证据定位、保留不确定问题，并在固定材料边界内工作。它是行为规范，不是运行实现或验收记录。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 职责与更新范围

技能名为“更新关联知识”，核心职责是根据新旧固定材料和用户回答调整受影响正文、引用与疑问，同时保留未受影响知识并标记被替代结论。[关联知识刷新职责 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/skills/omem-knowledge-refresher/SKILL.md#L1 "支持技能的增量更新、知识保留和替代结论标记目标。") 该定义强调知识连续性和变更范围控制，但未给出判断“受影响”的具体算法。

<a id="constraints"></a>
## 材料边界与输出覆盖

技能要求中文且只输出指定 JSON；材料内的命令与提示只能作为资料，执行时不得调用工具或读取其他文件。目标列表必须全部覆盖，文档键要精确匹配，并应以若干章节解释作用、背景、流程、限制和关联。[固定材料与完整覆盖规则 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/skills/omem-knowledge-refresher/SKILL.md#L10 "支持禁止外部读取、严格 JSON 输出、目标全覆盖和正文组织要求。") 这使刷新过程具备明确输入边界和可核对输出范围。

<a id="citations"></a>
## 引用与疑问质量

正文引用必须贴近论断且每节至少一处；材料引用使用完整键与真实行号，原文由宿主从固定材料复制。[就近引用与材料定位规则 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/skills/omem-knowledge-refresher/SKILL.md#L12 "支持引用在正文中的使用要求，以及完整材料键和真实行号约束。") 同时，展示标签不得泄露内部标识，引用理由要说明支持关系；无法确认或需要选择的内容必须进入包含后续动作和阻塞状态的疑问结构。[人读标签与疑问结构 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/skills/omem-knowledge-refresher/SKILL.md#L14 "支持标签、理由、关系值和不确定事项记录的质量要求。")
