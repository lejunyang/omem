# 关系核验角色清单配置

该清单声明 relation-verifier v1 的角色身份、输出合同、提示词与技能包绑定，并设置上下文、输出及引用节点预算。它说明运行时应如何装配角色，但不能单独证明角色已被调度执行或完成过真实核验。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role_contract"></a>
## 角色装配合同

清单将角色标识设为 `relation-verifier`、版本设为 1，并指定输出采用 `CodeUnderstanding.v1`；同时把 `prompt.md` 和带摘要的 `omem-code-relation-verifier` 技能包纳入装配信息。[关系核验角色身份与资源绑定 ↗](../../../packages/agent-runtime/roles/relation-verifier/1/manifest.json#L2 "支持角色版本、输出合同、提示词及技能包均由清单声明这一配置事实。") 这些是静态配置陈述，可用于选择提示词、技能与输出校验器，但材料没有展示加载器、任务队列或运行结果，因此不能据此声称关系核验流程已经实际运行。

<a id="resource_limits"></a>
## 资源与引用上限

角色预算为最多 96,000 个上下文 token、24,000 个输出 token，并把引用节点数限制为 150。[关系核验预算限制 ↗](../../../packages/agent-runtime/roles/relation-verifier/1/manifest.json#L16 "支持上下文、输出 token 和最大引用节点数的具体配置。") 该限制适合约束固定快照核验的输入和结果规模；其实际截断、拒绝或降级行为仍取决于未提供的运行时实现。
