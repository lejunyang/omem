# 本地仓库知识评审的 HTTP 服务

该服务组装面向本地单用户代码评审的 Fastify 接口，复用统一记忆、检索与知识管线，提供材料浏览、证据关系、代码结构、固定快照源码和可选的代码理解生成能力。同步会依次捕获材料、恢复知识并更新代码投影。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-security"></a>
## 统一评审入口与访问边界

该服务把仓库材料、可追溯知识、证据检索和代码结构汇集到同一套本地 HTTP 接口。启动时会创建通用记忆服务、检索器和代码知识服务，并挂载统一知识路由；代码理解模型仅在显式提供配置时启用，默认只开放确定性图谱和人工整理内容。参考 [评审服务初始化 ↗](../../../apps/server/src/review/app.ts#L75 "支持服务复用统一记忆、检索、代码知识与知识路由，以及模型默认关闭的说明。")

所有评审 API 共用访问门禁：配置 `REVIEW_TOKEN` 时校验 Bearer Token；未配置时只接受回环 Host，并限制浏览器 Origin。参考 [本地访问门禁 ↗](../../../apps/server/src/review/app.ts#L97 "支持令牌校验以及无令牌时的回环 Host 和浏览器 Origin 限制。") 当前 SQLite Store 明确以单用户为基础，团队级权限执行仍属于后续迁移，因此这些门禁不能被视为完整的租户隔离体系。参考 [单用户存储边界 ↗](../../../apps/server/src/store.ts#L4 "支持 SQLite 当前是单用户基础、团队级权限执行仍待后续迁移的安全边界结论。")

<a id="evidence-search-sync"></a>
## 从固定材料到可检索证据

服务可浏览分类、材料版本、修订、片段及关系。搜索会先从当前 revision 中筛出未移除且符合分类的片段，再把可见性和来源权重交给统一检索器，避免无资格材料挤占 Top-N 结果。参考 [证据检索过滤 ↗](../../../apps/server/src/review/app.ts#L290 "支持候选片段先按移除状态与分类过滤，再进入统一检索并组装结果。")

```mermaid
flowchart LR
  A[同步请求] --> B[捕获仓库材料]
  B --> C[恢复知识文章与用户补充]
  C --> D[同步代码快照与结构图]
```

普通评审同步入口与代码同步入口都按这一顺序执行，并以共享状态拒绝并发同步；无论成功与否，运行标志都会在 `finally` 中释放。参考 [评审同步入口 ↗](../../../apps/server/src/review/app.ts#L319 "支持普通同步入口依次执行材料同步、知识恢复和代码同步，并拒绝并发运行。") [代码同步入口 ↗](../../../apps/server/src/review/app.ts#L607 "支持代码同步入口采用相同处理顺序、共享互斥状态并在结束时释放标志。")

材料适配器负责把普通文件保存为固定 revision，并排除派生目录、依赖、构建结果和私密运行配置；代码同步则基于已捕获片段建立结构投影，不另行捕获文件正文。延伸阅读：[仓库材料捕获 ↗](../../../apps/server/src/review/materials.ts#L15 "说明材料适配器固定普通文件内容，并排除派生数据、依赖、构建结果和私密配置。") [代码结构投影 ↗](../../../apps/server/src/code/sync.ts#L1 "说明代码同步基于已捕获片段建立确定性投影，不负责捕获文件正文。")

<a id="code-reading-model"></a>
## 固定快照阅读与可选代码理解

代码读取接口覆盖仓库与快照列表、模块分组、文件、符号、边以及整图，供界面从目录逐层进入源码和结构关系。参考 [代码图谱读取接口 ↗](../../../apps/server/src/review/app.ts#L351 "支持接口提供仓库、快照、模块、文件、符号、关系边和整图的读取能力。")

源码区间不读取实时工作树，而是使用指定快照绑定的固定文本；非法行号、越界范围、缺少快照或未捕获内容都会返回明确错误。因此旧快照仍能展示历史字节，未进入捕获链的文件也不会被猜测性补全。参考 [快照固定源码 ↗](../../../apps/server/src/review/app.ts#L400 "支持源码接口从快照绑定读取固定文本，并处理非法范围、缺少快照及未捕获内容。")

代码理解可读取现有 seed 或生成结果；生成端点仅在模型端口已配置时可用，否则返回 503。调用会传入超时及 token 预算，schema 拒绝与传输失败分别映射为 422 和 502，成功后才返回完整详情。参考 [显式模型生成 ↗](../../../apps/server/src/review/app.ts#L579 "支持生成端点必须显式配置模型，并传递预算、区分拒绝与传输失败。")

<a id="lifecycle-boundaries"></a>
## 运行生命周期与已知限制

若前端构建目录存在，服务会同时托管静态页面；关闭时释放检索服务并关闭 Store，最后把应用、记忆与检索实例交还调用方。参考 [静态页面与关闭流程 ↗](../../../apps/server/src/review/app.ts#L620 "支持存在构建产物时托管前端，以及关闭时释放检索服务和数据库资源。")

该文件主要承担 HTTP 编排：部分数据直接来自 SQLite 查询，其余由知识恢复、关系查询、同步、DTO 映射和代码理解模块提供。现有材料未包含对应测试，因而无法确认访问门禁、同步互斥、历史源码错误分支和模型失败映射是否已有真实 HTTP 行为断言。
