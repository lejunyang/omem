# 仓库评审模式的本地 HTTP 应用

构建隔离的 repo-review API，提供知识、来源、关系、搜索和代码图读取；通用与代码同步均由显式端点触发，模型理解生成也必须显式调用。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="boundary-security"></a>
## 运行边界与访问控制

评审应用复用隔离 Store 上的记忆和关键词检索，但不启动助手运行时、Lark、学习或通知 worker，也不承载业务状态。无令牌时仅接受回环 Host 与允许的本地 Origin；设置 `REVIEW_TOKEN` 后，评审 API 由 Bearer token 门控。[评审应用边界与安全说明 ↗](../../../apps/server/src/review/app.ts#L5 "支持隔离运行、不承载业务 worker，以及回环或令牌访问控制。") 构建时注册知识路由、关系表和代码服务；理解模型端口默认关闭，只在依赖中显式传入模型配置时创建。[评审应用初始化 ↗](../../../apps/server/src/review/app.ts#L60 "说明知识路由、隔离服务和默认关闭的理解模型端口如何建立。")

<a id="evidence-search"></a>
## 固定证据读取与评审搜索

来源、Revision 和 Fragment 接口提供当前材料目录及固定证据详情；Fragment 响应包含所属 Revision、上下文和 provenance，关系接口可按 Fragment 或代码路径查询。[固定 Fragment 与关系接口 ↗](../../../apps/server/src/review/app.ts#L221 "支持 Fragment 证据详情及评审关系查询的描述。") 搜索把 current head、类别和 removed 条件放在同一 SQL 中过滤，再按命中词长度累计分数并截取前二十项，避免先固定取 top-N 后再过滤。[评审材料搜索实现 ↗](../../../apps/server/src/review/app.ts#L286 "说明 SQL 内过滤、评分和结果截断的具体行为。")

<a id="sync-code"></a>
## 显式同步与代码图读取

通用 `POST /sync` 与代码 `POST /code/sync` 分别使用 `syncing`、`codeSyncing` 标志，并互相检查以拒绝并发；两个显式请求都会依次运行评审材料同步、恢复已发布知识和重建代码快照，但返回值不同。[通用同步入口 ↗](../../../apps/server/src/review/app.ts#L385 "支持通用同步的互斥检查及材料、知识和代码快照处理顺序。")[代码同步入口 ↗](../../../apps/server/src/review/app.ts#L673 "补充证明代码同步端点的双向互斥检查及其执行顺序。") 代码读取面暴露仓库、快照、模块、文件、符号、边和图。源码区间严格读取快照绑定的固定文本；缺少绑定或越界时明确报错，不回退到实时工作树。[代码图与快照源码接口 ↗](../../../apps/server/src/review/app.ts#L412 "说明代码结构读取面以及源码严格来自快照固定绑定。")

<a id="model-generation"></a>
## 理解结果与模型生成边界

理解列表和详情公开状态、置信度、seed、复核者、过期标记、模型及引用等元数据。[代码理解读取接口 ↗](../../../apps/server/src/review/app.ts#L579 "支持理解列表与详情所暴露的状态、来源、复核和引用元数据。") 生成入口是显式 opt-in：无模型端口时返回不可用；传输或校验失败只记录失败或拒绝结果，不提升为 current，成功时才返回结果详情。[显式代码理解生成 ↗](../../../apps/server/src/review/app.ts#L645 "支持无模型时拒绝生成、失败不晋升以及成功返回详情的边界。") 因而原始代码图和人工 seed 可在无模型条件下使用，模型输出则保留独立状态与追踪信息。
