# 本地仓库知识评审的 HTTP 服务

该 Fastify 应用是本地代码评审工作区的 HTTP 装配层。它接入材料与关系浏览、证据搜索和代码图谱，并提供固定快照源码与代码理解记录。两类同步入口都依次刷新材料、恢复知识并更新代码图谱；模型生成必须显式配置。访问边界由 REVIEW_TOKEN 或回环 Host 与本地 Origin 校验提供。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-security"></a>
## 统一评审入口与访问边界

这个 Fastify 应用是本地代码评审工作区的 HTTP 装配层。它接收调用方提供的 Store 和仓库根目录，创建记忆与检索服务，并创建代码知识服务，在 `/api/review/knowledge` 下注册知识路由。代码理解模型默认关闭；只有调用方提供模型配置时才建立模型端口。知识路由装配了答复后的材料保存回调，以及用于发布文章的回调。参考 [服务与知识路由装配 ↗](../../../apps/server/src/review/app.ts#L80 "支持记忆、检索、代码知识和知识路由的创建方式，以及模型配置和答复、发布回调的装配关系。")

服务不装载 AssistantRuntime、Lark 接入、学习流水线或通知任务。所有 `/api/review` 请求共用同一访问门禁：设置 `REVIEW_TOKEN` 后，应用读取整个 `Authorization` 请求头，可选地移除精确的 `Bearer ` 前缀，再将余下字符串与配置令牌比较；`Bearer <token>` 与直接写入原始令牌这两种形式都可通过。未设置令牌时，请求 Host 必须是回环地址，带 Origin 的浏览器请求还要来自配置端口或当前 Host。参考 [评审 API 访问门禁 ↗](../../../apps/server/src/review/app.ts#L145 "支持令牌模式下对 Authorization 值移除可选 Bearer 前缀后进行比较，以及无令牌时的回环 Host、浏览器 Origin 校验规则。")

<a id="evidence-search-sync"></a>
## 从材料浏览到证据检索与同步

读取接口从当前 source head 组织材料列表，并提供健康状态与分类统计，以及版本列表、修订正文和片段证据。关系接口可以按片段或代码路径查询，也能按状态与类型列出关系，并返回关联种子和关系汇总。参考 [材料与片段读取接口 ↗](../../../apps/server/src/review/app.ts#L179 "支持 source 列表按当前 head 组织，以及健康状态、分类、版本、revision 和 fragment 的读取能力。") [证据关系读取接口 ↗](../../../apps/server/src/review/app.ts#L311 "支持片段关系、关系筛选、代码路径关系和关联汇总接口。")

搜索只从当前 revision 的片段中选择候选。移除状态和分类条件先生成可见片段集合，再交给统一检索器取最多 20 条结果；响应同时带回来源定位、阅读范围和导航路线。空查询直接返回空数组。参考 [检索候选与可见性过滤 ↗](../../../apps/server/src/review/app.ts#L350 "支持当前 revision 候选、移除状态与分类预过滤，以及检索结果定位字段。")

```mermaid
flowchart LR
  A[同步请求] --> B[刷新仓库材料]
  B --> C[恢复评审知识]
  C --> D[更新代码快照与结构图]
```

普通同步入口与代码同步入口都执行这三个阶段，并共享两个运行标志；任一同步正在运行时，另一入口返回 409。普通入口返回材料同步结果，代码入口返回代码同步结果，二者都会在 `finally` 中释放自己的运行标志。参考 [普通同步入口 ↗](../../../apps/server/src/review/app.ts#L397 "支持普通同步依次刷新材料、恢复知识和更新代码，并在完成后释放运行标志。") [代码同步入口 ↗](../../../apps/server/src/review/app.ts#L754 "支持代码同步与普通同步共享互斥状态，并采用相同的三阶段顺序。")

<a id="code-reading-model"></a>
## 固定快照阅读与可选代码理解

代码读取接口先提供仓库、快照和模块，再按文件进入符号。符号详情、关联边和整图接口补足跨文件导航，其中整图会把文件、符号和边转换成面向界面的数据结构。参考 [代码仓库与文件读取 ↗](../../../apps/server/src/review/app.ts#L428 "支持仓库、快照、模块、文件和文件符号的读取路线。") [符号、关系边与整图读取 ↗](../../../apps/server/src/review/app.ts#L538 "支持符号详情、边查询和整图 DTO 组装。")

源码区间接口读取指定快照绑定的 `contentText`，没有指定快照时使用当前快照。它不会读取实时工作树。文件不存在、没有可用快照或快照未绑定源码时返回 404；起止行非法或结束行越界时返回 400。成功响应包含路径与实际区间，以及总行数和截取文本。参考 [固定快照源码区间 ↗](../../../apps/server/src/review/app.ts#L495 "支持源码从快照绑定读取，以及行范围和不可用状态的错误映射。")

代码理解记录可以按目标读取当前结果，也可以列出记录或查看单条详情。列表暴露模型状态和记录元数据。详情包含模型与输入哈希，也会返回提示哈希及 `schemaDigest`；未知项、输出和引用也在响应中。参考 [代码理解记录读取 ↗](../../../apps/server/src/review/app.ts#L612 "支持按目标读取当前理解、列出记录和查看包含哈希、输出与引用的详情。")

生成入口只有在模型端口存在时可用，否则返回 503；缺少 `targetId` 返回 400。调用会传入超时和 token 预算。生成结果被拒绝时返回 422，其他失败返回 502，成功后才附带完整理解详情。参考 [显式模型生成入口 ↗](../../../apps/server/src/review/app.ts#L709 "支持模型可用性、目标校验、预算传递及 422、502、503 状态映射。")

<a id="lifecycle-boundaries"></a>
## 运行生命周期与模块边界

前端构建目录存在时，应用会在根路径托管静态文件。关闭流程依次关闭检索服务和 Store，并释放默认日志器；构建函数最终返回应用与 Store，以及记忆服务和检索接口，供启动层继续管理。参考 [静态页面与关闭流程 ↗](../../../apps/server/src/review/app.ts#L768 "支持静态页面注册、检索与 Store 关闭、日志器释放和构建返回值。")

本文件负责路由装配与 HTTP 状态映射。它调用的模块负责材料刷新与知识恢复，也负责关系计算、代码同步和代码理解生成，因此阅读本页可以确认入口顺序与返回边界，不能代替对这些模块内部算法的核对。参考 [服务与知识路由装配 ↗](../../../apps/server/src/review/app.ts#L80 "支持记忆、检索、代码知识和知识路由的创建方式，以及模型配置和答复、发布回调的装配关系。") [证据关系读取接口 ↗](../../../apps/server/src/review/app.ts#L311 "支持片段关系、关系筛选、代码路径关系和关联汇总接口。") [普通同步入口 ↗](../../../apps/server/src/review/app.ts#L397 "支持普通同步依次刷新材料、恢复知识和更新代码，并在完成后释放运行标志。") [显式模型生成入口 ↗](../../../apps/server/src/review/app.ts#L709 "支持模型可用性、目标校验、预算传递及 422、502、503 状态映射。")
