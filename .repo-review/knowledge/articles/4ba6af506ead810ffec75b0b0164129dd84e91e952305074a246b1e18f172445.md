# 仓库评审模式的本地 HTTP 应用

构建隔离的 repo-review API，提供固定材料、关系、搜索、代码图和理解结果读取；同步与模型生成均由显式请求触发，默认模型端口关闭并以本地访问规则保护接口。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="boundary-security"></a>
## 运行边界与访问控制

评审应用复用隔离 Store 上的记忆与关键词检索，但不启动助手、Lark、学习或通知 worker，也不持有业务状态。无令牌时 API 只接受回环 Host 和允许的本地 Origin；配置令牌后，全部评审 API 由 Bearer token 门控。[评审应用边界与安全规则 ↗](../../../apps/server/src/review/app.ts#L5 "支持隔离运行、不承载业务 worker，以及回环或令牌访问控制的总体说明。") 构建阶段注册知识路由、关系表和代码服务；理解模型端口默认是空，只有依赖中显式提供模型配置才会创建。[评审应用初始化 ↗](../../../apps/server/src/review/app.ts#L73 "说明知识路由、隔离服务和默认关闭的理解模型端口如何建立。")

<a id="evidence-search"></a>
## 固定证据与评审搜索

Revision、Fragment 和关系接口提供固定证据、上下文、provenance 以及相关评审关系。[固定 Fragment 与关系接口 ↗](../../../apps/server/src/review/app.ts#L221 "支持 Fragment 证据详情及按 Fragment 或代码路径查询关系的描述。") 搜索把 current head、类别和 removed 条件放入同一 SQL 查询，再按不同长度的命中词累计分数、排序并取前二十项，避免先做固定 top-N 后过滤而漏掉指定类别中的低排名结果。[评审材料搜索 ↗](../../../apps/server/src/review/app.ts#L286 "说明过滤在 SQL 内执行、评分排序及二十项截断行为。")

<a id="sync-code"></a>
## 显式同步与代码快照

通用同步入口拒绝与任一种同步并发，随后依次刷新评审材料、恢复已发布知识并重建代码快照。[通用评审同步入口 ↗](../../../apps/server/src/review/app.ts#L385 "支持通用同步的互斥检查及材料刷新、知识恢复和代码同步顺序。") 独立代码同步入口具有相同互斥和执行顺序，但返回代码同步结果。[独立代码同步入口 ↗](../../../apps/server/src/review/app.ts#L673 "补充证明代码同步端点的互斥控制、执行顺序与返回结果。") 代码读取面提供仓库、快照、文件、符号、边和图；源码区间严格读取快照绑定文本，绑定缺失或范围越界会显式报错，而不会退回实时工作树。[代码图与快照源码接口 ↗](../../../apps/server/src/review/app.ts#L412 "说明代码结构读取面及源码严格来自快照固定绑定。")

<a id="model-generation"></a>
## 理解结果与模型生成

理解列表和详情公开状态、置信度、seed、复核者、过期标记、模型与引用等追踪信息。[代码理解读取接口 ↗](../../../apps/server/src/review/app.ts#L579 "支持理解列表与详情暴露的状态、来源、复核和引用元数据。") 生成是显式 opt-in：没有模型端口时返回不可用；传输或校验失败只记录失败或拒绝结果，不晋升为 current，成功后才返回生成结果及详情。因此原始代码图和人工 seed 不依赖实时模型。[显式代码理解生成 ↗](../../../apps/server/src/review/app.ts#L645 "支持无模型时拒绝生成、失败不晋升以及成功返回详情的边界。")
