# 知识文章正文加载与引用导航组件

KnowledgeDocument.vue 根据文档键和可选 revision 加载知识文章，呈现摘要、来源状态、目录、Markdown 正文与开放问题，并把可操作引用转换为上层 trail 导航帧。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="load-and-race"></a>
## 加载、版本与竞态处理

组件监听 documentKey 与 revision，并立即执行文章请求；文档键和 revision 都经过 URL 编码。每轮请求递增 generation，只有仍为最新的一轮可以写入 article、发出 loaded 或显示错误，从而避免快速切换文档时旧响应覆盖新页面。加载前清空旧文章；成功渲染后等待 DOM 更新，再按可选 section 使用 `CSS.escape` 定位并滚动到对应章节。[文章加载与 generation 防竞态 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L6 "支持参数编码、迟到响应抑制、加载后章节定位的完整流程。")

<a id="rendering"></a>
## 正文结构与来源状态

请求期间显示读取状态，失败显示知识不可用空态。成功后依次展示标题、摘要、当前或历史知识徽标、模型来源说明；章节超过两个时才生成目录。每个 section 交给共享 `OmMarkdown` 渲染，并传入文章 citations；文末挂载 `KnowledgeQuestions`，使用当前文章 key 继续读取或处理开放问题。[知识正文与开放问题渲染 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L26 "支持加载状态、来源徽标、目录、Markdown 章节及问题组件的结构。")

<a id="citation-navigation"></a>
## 引用导航与边界

Markdown 发出 citation key 后，`cite` 在当前文章 citations 中查找目标。只有 citation 标记为 actionable 且文章仍存在时才发出 navigate；导航帧 id 序列化 document、文章 revision 和 citation key，标题使用人读 label。[可操作引用转导航帧 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L20 "支持引用查找、actionable 门槛和导航载荷所含字段。") 组件不自行读取原始证据，也不解释不可操作 reason，而把具体引用页面和 trail 栈管理交给父层。章节滚动使用选择器定位，目录点击也在当前根节点内滚动；本文件没有加载取消、重试按钮或空章节校验。[目录与章节滚动行为 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L31 "支持目录只在章节较多时出现，并在组件根节点内定位章节。")
