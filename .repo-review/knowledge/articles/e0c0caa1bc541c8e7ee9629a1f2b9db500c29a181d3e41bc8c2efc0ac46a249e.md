# Agent 进程与 ACP 传输测试

通过真实子进程夹具验证 ACP 协商、推理强度校验、思考内容过滤、权限拒绝、超时与取消，并检查 CLI 参数使用显式 argv 且保持只读。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="fixture-flow"></a>
## 真实进程夹具流程

辅助函数为每次调用创建临时工作目录，以已解析的 AgentProfile 启动 ACP 夹具，将文本块送入并收集 status/text/permission 事件；`acp()` 返回前等待子进程关闭，随后一次性删除目录，避免重试掩盖清理竞态。[ACP 子进程测试夹具 ↗](../../../apps/server/tests/agents.test.ts#L7 "说明临时目录、事件收集、调用和进程退出后清理的测试流程。")

<a id="negotiation-safety"></a>
## 能力协商与安全边界

测试证明模型切换后才验证新模型的 effort，支持的 `beta/high` 出现在文本输出中，而私有 thought 被丢弃；不支持的 effort 必须拒绝而非回退。权限请求会被观察到但默认拒绝，空闲提示受超时约束，AbortSignal 能取消活动请求。[模型协商与思考过滤 ↗](../../../apps/server/tests/agents.test.ts#L41 "支持模型和 effort 协商顺序，以及私有思考不进入输出事件。") [权限、超时与取消测试 ↗](../../../apps/server/tests/agents.test.ts#L56 "支持权限默认拒绝、空闲超时和主动取消行为。")

<a id="cli-argv"></a>
## CLI 参数构造

CLI 分支仅检查 argv：包含 `read-only`，模型字符串 `literal$(pwd)` 原样作为参数存在，并且不含绕过审批与沙箱的危险开关。结合实现使用 `spawn(..., shell:false)`，这支持“不经 shell 插值”的边界；但测试未真正运行 CLI，也未覆盖不同 CLI transport 的完整参数差异。[安全 CLI argv 断言 ↗](../../../apps/server/tests/agents.test.ts#L72 "支持只读模式、字面模型参数和禁用危险绕过参数的结论。") [无 shell 子进程启动 ↗](../../../apps/server/src/agents.ts#L56 "实现证据表明命令通过 spawn 且 shell=false 启动，解释字面参数不被 shell 展开。")
