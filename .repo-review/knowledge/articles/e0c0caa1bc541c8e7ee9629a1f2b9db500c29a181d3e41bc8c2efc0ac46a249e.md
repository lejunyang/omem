# Agent 运行边界与安全策略测试

该测试文件以临时工作目录和 ACP fixture 验证模型与推理强度协商、思考内容过滤、权限拒绝、超时与取消，以及 CLI 参数的安全构造。进程启动在各平台均禁用 shell，但只有非 Windows 使用独立进程组；现有材料仍不足以证明真实第三方 CLI 兼容性及 Windows 终止行为。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_setup"></a>
## 测试目标与运行夹具

该文件针对服务端 Agent 适配层做行为测试。`run` 为每次调用创建独立临时目录，以共享 schema 校验配置后启动 ACP fixture，收集文本与权限事件；调用结束时直接删除目录。注释明确 `acp()` 应先等待子进程完全关闭，清理失败会作为真实错误暴露。[ACP 测试运行与清理夹具 ↗](../../../apps/server/tests/agents.test.ts#L17 "支持临时目录、事件收集、ACP 调用以及等待子进程关闭后直接清理的说明。")

测试连接共享配置合同与服务端适配实现：profile 指定 Node 可执行文件、fixture 路径和超时，再由 `acp` 执行。[测试配置与共享合同 ↗](../../../apps/server/tests/agents.test.ts#L5 "支持测试通过共享 profile schema 配置 Node fixture，并调用服务端 Agent 适配层。") 子进程统一使用管道、`shell: false` 并过滤部分敏感环境变量；此前“隔离进程组启动”的表述被替代为更准确的平台结论：仅非 Windows 设置 `detached=true`，Windows 明确为 `false`。[跨平台子进程启动配置 ↗](../../../apps/server/src/agents.ts#L32 "支持禁用 shell、管道通信、环境过滤，以及仅在非 Windows 启用 detached 的修正结论。")

<a id="asserted_behaviors"></a>
## 已断言的核心行为

模型配置方面，测试要求先协商模型再校验其 effort 选项；`beta/high` 应出现在文本结果中，而私有思考标记不得进入事件流。[模型协商与思考过滤断言 ↗](../../../apps/server/tests/agents.test.ts#L41 "支持 beta/high 协商结果可见且私有思考不得进入事件流。") 当前模型不支持 `high` 时必须抛出 `Unsupported reasoning_effort`，不能静默回退。[不支持的推理强度断言 ↗](../../../apps/server/tests/agents.test.ts#L51 "支持不兼容 effort 必须明确报错而不是自动回退。")

权限请求会产生 permission 事件，但默认结果是拒绝；测试没有授权成功路径。[权限请求拒绝断言 ↗](../../../apps/server/tests/agents.test.ts#L56 "支持权限事件可被观察且当前测试期望默认拒绝。") 无响应提示受超时约束，外部 `AbortSignal` 可取消活动请求并得到 `CANCELLED`。[超时与主动取消断言 ↗](../../../apps/server/tests/agents.test.ts#L61 "支持空闲超时和 AbortSignal 取消两类生命周期行为。") CLI 参数测试还要求只读模式存在、包含命令替换语法的模型名保持为字面 argv，且不出现绕过审批与沙箱的危险开关。[安全命令行参数断言 ↗](../../../apps/server/tests/agents.test.ts#L72 "支持只读参数、模型名字面传递以及禁止危险绕过开关的结论。")

<a id="lifecycle_limits"></a>
## 进程生命周期与覆盖边界

服务端实现显示，非 Windows 会向负 PID 对应的进程组发送 `SIGTERM`，1.5 秒后升级为 `SIGKILL`；Windows 则对直接子进程调用 `kill`。启动配置与此一致：非 Windows 创建独立进程组，Windows 不启用 detached。[跨平台终止策略 ↗](../../../apps/server/src/agents.ts#L40 "支持非 Windows 终止进程组、Windows 终止直接子进程，以及延迟升级 SIGKILL 的实现说明。") 现有测试只从结果层断言超时和取消，没有对两类平台的信号路径、升级终止或最终进程回收分别取证。[现有生命周期测试范围 ↗](../../../apps/server/tests/agents.test.ts#L61 "说明当前测试仅断言超时和取消的外部错误结果，没有直接验证平台信号与进程回收细节。")

这些用例属于 fixture 驱动的回归验证，不能单独证明真实 codex-cli 的版本兼容性、参数接受情况，也无法从给定材料判断 fixture 是否覆盖协议乱序、无效消息或异常退出。临时目录清理逻辑同样未被主动注入失败。因此已证明的是关键安全策略的可观察结果，而非全部外部协议与跨平台生命周期行为。[Fixture 路径与已覆盖用例范围 ↗](../../../apps/server/tests/agents.test.ts#L7 "支持测试依赖外部 fixture，同时界定当前文件实际列出的行为场景与未证明事项。")
