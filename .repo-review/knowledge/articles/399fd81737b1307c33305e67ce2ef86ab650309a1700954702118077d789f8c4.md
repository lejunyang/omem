# 学习任务状态、尝试记录与提案展示界面

该 Vue 组件集中呈现持久化学习任务、模型尝试、关联提案及取消或重试入口，区分等待、失败、完成和提案生效，并通过事件把刷新、错误与证据打开交给父组件。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-state"></a>
## 任务状态与进度表达

该组件让用户查看材料进入系统后的处理进度。后台状态被转换为中文文案及危险、警告、成功等视觉语气，但这种映射只负责展示，不等同于后台成功判定。[任务状态文案与视觉语气 ↗](../../../apps/web/src/LearningView.vue#L15 "支持后台状态到中文文案及视觉语气的映射，并界定其属于展示逻辑。") 页面明确说明等待 worker 的任务保持“等待处理”，失败不会显示为完成；详情为空时也提示尚无模型尝试并不代表处理成功。[等待与失败的页面说明 ↗](../../../apps/web/src/LearningView.vue#L68 "支持等待 worker 时保持等待状态以及失败不会显示为完成的用户提示。") [尝试记录与空记录提示 ↗](../../../apps/web/src/LearningView.vue#L107 "支持模型尝试字段的实际渲染，以及无尝试记录不代表成功的提示。")

四段轨迹依次表示材料保存、提炼与核验、形成提案、应用并通知；后三段分别按尝试次数、关联提案是否存在以及是否出现 `applied` 提案点亮。因此轨迹是面向用户的摘要，不能替代各后台阶段的独立完成证明。[学习流程四段轨迹 ↗](../../../apps/web/src/LearningView.vue#L86 "支持四段进度名称及其依据尝试、提案和生效状态点亮的条件。")

<a id="details-and-actions"></a>
## 提案关联、详情加载与任务控制

提案通过 `origin.job_id` 与当前任务 ID 匹配；展开详情时调用 `/jobs/{id}`，并以 `job.id` 为键把返回结果写入本地 `details`。此前由详情渲染范围间接支撑这两项结论的表述已被替代，现由对应关联与请求代码直接证明。[任务提案关联与详情请求缓存 ↗](../../../apps/web/src/LearningView.vue#L40 "直接支持提案按 origin.job_id 关联任务，以及展开后请求任务详情并按 job.id 写入 details；用于替代此前引用范围不足的结论。") 界面随后逐项展示尝试次数、模型、effort、结果和可选错误信息，并对无尝试记录给出明确提示。[尝试记录与空记录提示 ↗](../../../apps/web/src/LearningView.vue#L107 "支持模型尝试字段的实际渲染，以及无尝试记录不代表成功的提示。") API 类型还确认尝试包含 attempt、generation、model、effort 和 outcome 字段。[任务尝试基础字段 ↗](../../../apps/web/src/api.ts#L64 "支持 JobAttempt 类型中的次数、代次、模型、effort 和结果字段。")

取消与重试共用控制函数，请求携带当前 generation 和随机 requestId；成功后通知父组件刷新，失败发出错误事件，最终解除忙碌态。[取消与重试请求流程 ↗](../../../apps/web/src/LearningView.vue#L50 "支持控制请求携带 generation 和 requestId，以及刷新、错误上报和解除忙碌态的流程。") 模板限制可用动作：排队、已领取、运行、等待重试及等待判断状态可取消，失败或已取消状态可重新处理。[取消与重试按钮门禁 ↗](../../../apps/web/src/LearningView.vue#L166 "支持不同任务状态下取消或重新处理按钮的可见条件。")

<a id="evidence-and-boundaries"></a>
## 证据入口、依赖与已知边界

每项提案展示状态、操作、影响数量、原因及策略原因，并将固定片段版本标识通过 `open` 事件交给父组件；证据阅读器、路由和权限判断不在本组件内。[提案展示与原证据入口 ↗](../../../apps/web/src/LearningView.vue#L134 "支持提案信息展示以及通过固定片段版本标识触发父组件打开原证据。") 组件复用共享 UI 包中的面板、徽标、按钮、引用和空状态组件，并使用本地导入的 `api` 发起请求；材料不足以证明整个应用都统一采用该封装。[共享界面组件与 API 导入 ↗](../../../apps/web/src/LearningView.vue#L2 "支持该组件复用共享 UI 组件并通过导入的 api 发起请求，同时限制结论只覆盖当前组件。")

现有材料不含取消、重试端点的服务端实现或相关测试，因而不能确认 generation 冲突、requestId 幂等和详情请求竞态的最终语义。样式仅明确规定 700px 以下将四段轨迹改为两列、尝试记录改为单列；其他极窄屏及可访问性表现仍缺少测试证据。[窄屏响应式布局 ↗](../../../apps/web/src/LearningView.vue#L250 "支持 700px 以下状态轨迹和尝试记录的明确布局变化。")
