# 原型参数调节面板与宿主通信协议

提供 React 调节状态钩子、可拖动浮层和一组统一表单控件，通过跨窗口消息把参数变更交给宿主持久化，同时向页面内其他监听者广播即时变化。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="state-and-protocol"></a>
## 状态来源与宿主协议

该模块解决多个原型重复实现参数面板和宿主通信的问题。`useTweaks` 以传入默认值初始化本地状态，既接受单键更新也接受对象批量更新；变更会立即合并到 React 状态，向父窗口发送持久化消息，并在当前窗口派发 `tweakchange` 事件供同页组件同步。[调节状态与双通道通知 ↗](../../../docs/prototype/tweaks-panel.jsx#L177 "支持本地状态合并、父窗口持久化消息以及同窗口变更事件的核心流程。")

持久化存在严格边界：默认对象必须位于宿主可重写的 HTML 标记区内，并保持合法 JSON；如果移到外部脚本、删除标记或使用表达式，界面仍可能变化，但编辑不会落盘。[可持久化默认值约束 ↗](../../../docs/prototype/tweaks-panel.jsx#L14 "支持默认对象必须保留在 HTML 标记区且保持合法 JSON 的关键边界。") 消息发送和接收均使用通配来源，材料没有展示来源或消息结构校验。

<a id="panel-lifecycle"></a>
## 面板生命周期与拖动约束

浮层先注册 `message` 监听器，再宣布自身可用，以免宿主过早发送激活消息。宿主的激活和停用消息控制可见性；用户点击关闭时，本地先隐藏并通知宿主，使工具栏状态保持一致。[宿主激活与关闭握手 ↗](../../../docs/prototype/tweaks-panel.jsx#L197 "支持监听器注册顺序、激活停用消息以及关闭时通知宿主的生命周期说明。")

面板位置以距右、距下偏移保存。打开、视口变化或根元素尺寸变化时，`clampToViewport` 把位置限制在安全边距内；拖动期间在窗口注册移动和释放监听，释放后清理。[拖动与视口夹紧 ↗](../../../docs/prototype/tweaks-panel.jsx#L204 "支持面板在打开、尺寸变化和拖动过程中保持在视口安全范围内的说明。") 若环境没有 `ResizeObserver`，代码只退回监听窗口 `resize`，因此根元素发生非窗口尺寸变化时可能无法立即重新夹紧。

<a id="control-behavior"></a>
## 控件策略与边界条件

控件层统一封装滑块、开关、单选、下拉、文本、数字、颜色和按钮。短且不超过三个选项时，单选采用可拖动分段控件；标签过长或选项过多时自动退化为下拉框，并尝试把字符串值映射回原始数字或布尔值。[分段单选的自动降级 ↗](../../../docs/prototype/tweaks-panel.jsx#L339 "支持短选项使用分段控件、长选项退化为下拉框并保留原值类型的策略。") 数字控件支持横向拖拽、步长吸附、小数精度处理和上下限夹取。[数字拖拽与范围处理 ↗](../../../docs/prototype/tweaks-panel.jsx#L434 "支持数字控件的步长吸附、精度计算和上下限夹取行为。")

颜色控件优先展示策划好的单色或调色板选项，无选项时才使用原生颜色输入；选中比较不区分十六进制大小写，勾选颜色依据相对亮度近似选择。[策划式颜色与调色板选择 ↗](../../../docs/prototype/tweaks-panel.jsx#L468 "支持颜色控件的原生回退、调色板展示、大小写无关比较和勾选对比度处理。") 最终所有工具挂到 `window`，说明它面向直接由 HTML/Babel 装载的原型，而非标准模块导出；材料中没有相应自动化测试。[全局导出与覆盖层标记 ↗](../../../docs/prototype/tweaks-panel.jsx#L537 "支持该实现通过 window 暴露工具并声明为视口覆盖层的集成方式。")
