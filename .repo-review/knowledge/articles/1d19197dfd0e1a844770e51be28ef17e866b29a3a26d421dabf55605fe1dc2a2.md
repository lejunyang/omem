# 待判断提案的审核与提交界面

集中呈现需要人工判断的提案，展示状态、影响、证据与不确定性，并携带提案摘要和请求标识提交确认、拒绝或补充背景操作。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决的问题与呈现范围

该组件把歧义、冲突或影响较大的变化集中为人工审核列表。它接收上层提供的决策集合，将待处理、已确认、已拒绝、过期和来源变化等内部状态翻译为中文；标题依次取提案标题、陈述或种类。[状态与标题映射 ↗](../../../apps/web/src/DecisionsView.vue#L6 "支持组件输入输出合同、决策状态中文映射和标题回退顺序。") 卡片进一步展示有效期、处理回执、提案原因、动作、对象、影响数量、原始内容和不确定项，让用户在判断前看到实际变化范围。[提案变化详情 ↗](../../../apps/web/src/DecisionsView.vue#L85 "支持有效期、回执、原因、动作、对象、影响数量、原始内容及不确定项的展示说明。")

<a id="decision-flow"></a>
## 提交流程、证据与边界

用户可以确认、拒绝或要求补充背景。提交请求携带动作、当前提案摘要、随机请求标识和决策记录中的执行者标识；成功后发出对应通知并要求父层刷新，失败时上报错误后同样刷新，最终解除忙碌状态。[决策提交函数 ↗](../../../apps/web/src/DecisionsView.vue#L28 "支持三类动作及 proposalDigest、requestId、actorId 的提交和成功、失败刷新流程。") 提案证据通过片段修订标识交给父组件打开；只有 `pending` 状态呈现操作按钮，`stale` 状态明确提示旧判断不可再提交。空列表文案还说明高置信、小范围变化可能已被自动处理，但自动处理机制不在本文件中。[证据入口与操作限制 ↗](../../../apps/web/src/DecisionsView.vue#L112 "支持证据跳转、失效提示、仅待处理状态可操作及空列表语义。")
