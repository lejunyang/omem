# 真实模型学习链路冒烟验证

该脚本用临时存储和真实 ACP 模型贯通“捕获原始文本—抽取提案—独立复核—策略评估与应用—生成审计报告”的学习闭环，并以显式异常保证关键阶段确实产出且达到自动应用条件。它验证的是一次受控端到端运行，不等同于覆盖所有模型输出、策略分支或任务字段的自动化测试。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决的问题与验证范围

脚本验证真实模型参与时，中文责任承诺能否从普通捕获材料进入记忆学习流程，而非仅证明协议 fixture 可解析。它创建隔离的临时 Store，写入一条带负责人、截止时间和来源元数据的手工捕获，并取首个固定 fragment 作为后续角色材料；因此生产数据不会被这次冒烟运行污染。[临时存储与中文任务捕获 ↗](../../../scripts/live-learning-smoke.ts#L17 "支持脚本以隔离 Store 捕获带时间和来源信息的中文责任承诺，并取得 fragment 作为后续材料。")

运行前必须找到 `traex` profile，并通过模型能力探测选择实际可用配置；没有 profile 或可选模型时会直接失败。[真实 ACP 模型选择 ↗](../../../scripts/live-learning-smoke.ts#L13 "支持脚本要求 traex 配置并通过能力探测选择可用模型，而不是固定假设模型存在。")

<a id="flow"></a>
## 抽取、复核与应用主流程

脚本先用合同 schema 组装可信上下文，将捕获产生的 job、revision、fragment 以及 workspace、项目、主体绑定和来源属性交给 extractor。[抽取角色上下文构造 ↗](../../../scripts/live-learning-smoke.ts#L43 "支持可信上下文包含捕获标识、主体、来源属性和固定 fragment，并交由 extractor 执行。") 随后要求抽取结果恰好包含一个 proposal，对其计算稳定摘要，再把候选及摘要放入新的 verifier 上下文，形成抽取与复核分离的两阶段链路。[提案摘要与独立复核 ↗](../../../scripts/live-learning-smoke.ts#L78 "支持脚本约束单一提案、计算稳定摘要，并以独立 verifier 角色复核候选。")

复核结果被转换为 `MemoryService.evaluate` 的语义裁决与版本审计字段；只有策略为 `auto_apply` 且返回应用 receipt 才算通过，否则立即抛错。这说明队列或模型返回成功并不等于知识已经安全落库。[策略评估与安全应用断言 ↗](../../../scripts/live-learning-smoke.ts#L104 "支持复核结论进入 MemoryService 评估，且只有 auto_apply 与 receipt 同时存在才通过。")

<a id="outputs-limits"></a>
## 断言、产物与边界

成功后，脚本把抽取和复核的结果及 trace、策略评估和当前任务列表写入权限受限的 JSON 报告，并输出实际模型、effort、裁决、策略、任务数和 receipt 标识，便于区分真实在线检查与普通测试。[审计报告与控制台摘要 ↗](../../../scripts/live-learning-smoke.ts#L114 "支持成功运行会保存角色 trace、评估、任务列表及实际模型和策略等可审计信息。") 无论成功失败，`finally` 都会关闭 Store 并删除临时目录；报告位于临时目录之外，默认得以保留。[资源关闭与临时目录清理 ↗](../../../scripts/live-learning-smoke.ts#L145 "支持脚本无论执行结果如何都会关闭 Store 并删除隔离运行目录。")

现有断言只覆盖“单一提案、存在复核结论、允许自动应用且有 receipt”。它虽记录任务数量，却没有断言任务内容、负责人或截止时间，也未覆盖拒绝、等待决策、模型输出多个提案、网络失败及清理失败等分支；跨模块内部行为仅能确认到脚本展示的公开调用，不能据此推断 gateway 或策略实现细节。

<a id="module-relations"></a>
## 与其他模块的关系

该脚本是多个既有模块的编排层：Store 负责捕获和查询任务，合同 schema 在角色执行前校验上下文，RoleBundleRegistry 与 RoleRuntimeGateway 执行 extractor/verifier，MemoryService 决定是否应用，stableDigest 则绑定复核候选。依赖关系由导入和实际调用共同佐证，但材料没有展示这些模块内部的跨文件调用链。[冒烟脚本的模块依赖 ↗](../../../scripts/live-learning-smoke.ts#L4 "支持脚本直接依赖配置、角色运行时、记忆服务、摘要、存储、合同和模型选择模块。")
