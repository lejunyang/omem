# 知识生成、复核与发布流水线

编排材料分析、固定上下文、持久任务、独立语义复核和分层综合；只有结构与引用校验通过且复核接受的正文才会发布，失败目标会带反馈重写。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="dispatch-context"></a>
## 角色分派与固定上下文

流水线按材料形态选择分析角色：含图片的材料交给视觉分析，会话类来源交给对话分析，常见代码扩展名交给代码分析，其余走通用材料分析。[材料分析角色选择 ↗](../../../apps/server/src/knowledge/pipeline.ts#L15 "支持按图片、会话来源和代码扩展名分派分析角色的说明。") 宿主只把获准行范围和图片装入上下文，并附带来源修订、参与者及转发状态；已有文章被明确标为派生知识而非独立证据，防止模型把整理结果误当原始事实。[固定材料上下文构造 ↗](../../../apps/server/src/knowledge/pipeline.ts#L30 "说明允许范围如何被包装，以及派生文章在上下文中的证据身份。")

<a id="durable-review"></a>
## 持久执行与独立复核

每次角色运行先以材料摘要、文章修订、模型配置和角色包哈希形成持久任务；成功结果可以复用，失败、取消或等待用户的任务必须重试。工作进程保存输出及完整运行轨迹，并在停止时中断继续发布。[持久角色任务执行 ↗](../../../apps/server/src/knowledge/pipeline.ts#L60 "支持任务入队、结果复用、轨迹保存和停止处理的流程。") 写作输出随后同时接受合同校验与独立知识复核：目标键必须完整唯一，引用只能落在已提供范围；被拒稿件携带具体反馈交给 refresher，最多经过四轮保守修订。[批次校验与复核重写 ↗](../../../apps/server/src/knowledge/pipeline.ts#L96 "支持目标完整性、引用范围、独立复核和多轮修订的论断。")

<a id="analysis-synthesis"></a>
## 批量分析与分层综合

初次分析仅处理尚无当前文章的材料，按分析角色、文本规模和图片边界组批，并可把用户回答和补充材料加入同一证据集合；并发失败会按目标记录而不会伪装成功。[材料批量分析流程 ↗](../../../apps/server/src/knowledge/pipeline.ts#L161 "说明待处理材料筛选、分批并发、用户回答补入和失败记录。") 高层主题由已复核子文章综合；子项超过十二个时先生成分片文章，且只有依赖修订完全一致时才复用旧结果。综合还会沿子文章引用回收原始材料范围，使派生正文保持可追溯性。[知识规划与分层综合 ↗](../../../apps/server/src/knowledge/pipeline.ts#L188 "支持子文章分片、依赖复用判断及原始材料引用回收。")
