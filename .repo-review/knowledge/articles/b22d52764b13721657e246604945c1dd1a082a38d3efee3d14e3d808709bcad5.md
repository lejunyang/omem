# 知识生成流水线：从原始材料到独立复核文章

该模块编排材料分类、固定上下文构造、持久化角色任务、结构与引用校验、独立语义复核、修订重试及分层综合，只有复核接受的文档才会发布，并保留材料或子文章依赖与运行轨迹。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="responsibility-context"></a>
## 职责与可信上下文

`KnowledgePipeline` 解决的是把原始材料可靠地转化为可追溯知识，而不是直接保存一次模型回答。它先按图片、会话来源和代码扩展名选择视觉、会话、代码或通用分析角色 [分析角色选择规则 ↗](../../../apps/server/src/knowledge/pipeline.ts#L15 "支持流水线依据图片、会话来源和代码扩展名选择分析角色的说明。")。构造上下文时仅暴露明确行段，长文本按约 65,000 字符切块，并把图片转为带资产哈希的输入；若没有任何固定原始材料则拒绝运行。派生文章会注明不是独立证据，同时记录允许引用的材料范围 [固定材料上下文构造 ↗](../../../apps/server/src/knowledge/pipeline.ts#L30 "支持行段切块、图片装载、原始材料必需以及派生文章 provenance 和允许范围的说明。")。

<a id="durable-role-run"></a>
## 持久化角色执行

角色执行先从注册表加载 bundle，把材料摘要、文章版本、模型、 effort、预算和 bundle 哈希写入任务引用；已成功任务复用输出，失败、取消或等待用户的任务要求显式重试。新任务由限定 kind 的 `DurableJobWorker` 执行，通过网关调用角色，并保存模型、提示词、技能、工具、上下文指纹及用量等 trace [持久化角色任务执行 ↗](../../../apps/server/src/knowledge/pipeline.ts#L60 "支持任务入列、状态复用、worker 调用网关、保存完整运行轨迹及停止处理的流程说明。")。其中指纹依赖规范化 JSON 后的 SHA-256 摘要，使对象键顺序和 `undefined` 字段不影响结果 [稳定摘要实现 ↗](../../../apps/server/src/storage/digest.ts#L3 "说明流水线指纹所依赖的摘要会规范化对象并使用 SHA-256。")；网关侧也把知识批次、复核和规划绑定到明确输出 schema [网关输出合同映射 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L25 "支持角色网关对知识批次、复核和规划结果采用明确 schema 校验的说明。")。

<a id="validation-review-publish"></a>
## 校验、独立复核与发布

模型输出首先必须精确覆盖目标 key，随后绑定宿主提取的原文引句、验证文档合同，并禁止引用未提供或超出可见行段的材料 [知识批次与引用范围校验 ↗](../../../apps/server/src/knowledge/pipeline.ts#L96 "支持目标 key 完整性、引句绑定、文档验证以及禁止越界引用的说明。")。写作后会由 `knowledge-verifier` 独立复核；只有 `accepted` 文档才合并复核问题、记录全部材料与文章依赖、封装生成及复核 trace，然后发布。被拒文档最多经历四轮定向修订，最后一轮要求只保留直接支持的陈述，其余转为调查问题；仍未通过则整体报错而不覆盖有效知识 [写作复核与发布循环 ↗](../../../apps/server/src/knowledge/pipeline.ts#L113 "支持独立复核、仅发布接受结果、记录依赖和轨迹以及最多四轮修订的核心流程。")。

<a id="analysis-synthesis-boundaries"></a>
## 分析、综合与边界条件

基础分析只处理尚无当前文章的材料，每篇文章单独成批，避免无关同批材料成为永久依赖；回答材料和显式 supplements 可加入上下文，并受并发数约束。旧复核反馈只有在材料摘要仍一致且未缺少原批次上下文时才复用，单篇失败被收集而不阻断其他批次 [反馈复用与单材料分析 ↗](../../../apps/server/src/knowledge/pipeline.ts#L145 "支持旧反馈的摘要约束、单材料批次、补充上下文、并发执行和失败隔离的说明。")。规划阶段要求固定顶层章节；综合阶段最多直接处理 12 个子文章，超出时递归生成分片。若依赖版本完全一致则复用现有文章；否则从子文章引用回收原始范围、合并相邻区间，并仅在预算允许时扩展为全文 [知识规划与分层综合 ↗](../../../apps/server/src/knowledge/pipeline.ts#L189 "支持固定规划章节、十二项分片阈值、依赖一致时复用以及材料引用回收的说明。")。上层章节可以引用已复核子文章，但代码明确把它们视为下钻入口而非新事实证据；当原文过大或预算预览失败时仍使用有限片段，因此跨片段行为可能无法完整推断 [综合材料预算与历史修订 ↗](../../../apps/server/src/knowledge/pipeline.ts#L231 "支持上层章节 provenance、范围合并、全文预算预览、有限片段回退及同版本反馈复用的边界说明。")。
