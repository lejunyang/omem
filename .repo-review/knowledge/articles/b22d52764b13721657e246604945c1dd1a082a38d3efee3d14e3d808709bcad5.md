# 知识生成、复核与发布流水线

把固定原始材料分派给适合的分析角色，经结构校验、独立语义复核和有限次修订后发布为带依赖与运行追踪的知识文章，并支持失效材料重分析及高层主题综合。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="roles-context"></a>
## 角色分派与固定上下文

流水线按材料形态选择分析角色：含图片的材料交给视觉分析，会话类材料交给对话分析，常见源码扩展名交给代码分析，其余进入通用材料分析。[材料分析角色选择 ↗](../../../apps/server/src/knowledge/pipeline.ts#L15 "说明图片、对话、代码与普通材料如何分派给不同分析角色。") 构造角色上下文时，只把获准的行范围、图片资产和可信捕获元数据送入模型；派生文章会明确标为“非独立证据”，且至少需要一项固定原始材料。[角色固定上下文构造 ↗](../../../apps/server/src/knowledge/pipeline.ts#L30 "支持材料按获准范围进入上下文、派生文章不作为独立证据以及原始材料必需条件。")

<a id="execution-review"></a>
## 持久任务、校验与独立复核

每次角色运行先登记可重试的持久任务，并记录模型、effort、预算、材料摘要、文章修订和角色包哈希；worker 保存输出及完整 trace，停止、失败或等待用户时不会把不完整结果当成功。[持久角色任务执行 ↗](../../../apps/server/src/knowledge/pipeline.ts#L60 "支持任务登记、运行追踪保存、停止与失败状态处理。") 输出必须恰好覆盖目标键，引用只能落在提供范围内，并经过引用绑定和文档结构校验。随后独立复核角色逐篇给出结论；只有 accepted 文档才发布，未通过项最多进行后续修订，且不会覆盖已通过目标。[批次校验与独立复核 ↗](../../../apps/server/src/knowledge/pipeline.ts#L96 "说明目标覆盖、引用范围校验、独立复核、选择性发布和有限次修订。")

<a id="analysis-synthesis"></a>
## 增量分析与主题综合

材料分析只处理当前没有有效文章的目标，按分析角色、数量和输入体积成批并发执行；用户对既有疑问的回答可作为新的原始材料加入后续分析。[材料增量分析 ↗](../../../apps/server/src/knowledge/pipeline.ts#L161 "说明仅处理没有 current 文章的目标、批处理并发，以及将已保存的用户回答加入后续分析输入。") 主题综合只使用 current 子文章，子项超过十二个时先分段综合；综合发布物会记录所用原始材料摘要和子文章修订作为依赖，仓库发布时再核对这些依赖是否仍与当前输入一致，变化则拒绝发布。[多层知识综合 ↗](../../../apps/server/src/knowledge/pipeline.ts#L201 "支持子文章分段、依赖复用、来源范围汇集，以及预算允许时提供完整材料。")[发布前依赖一致性检查 ↗](../../../apps/server/src/knowledge/repository.ts#L118 "直接支持发布时比较材料摘要与子文章修订、输入已变化则拒绝发布的论断。") 若预算容纳，模型获得完整相关来源，否则保留明确的摘录范围。[多层知识综合 ↗](../../../apps/server/src/knowledge/pipeline.ts#L201 "支持子文章分段、依赖复用、来源范围汇集，以及预算允许时提供完整材料。")
