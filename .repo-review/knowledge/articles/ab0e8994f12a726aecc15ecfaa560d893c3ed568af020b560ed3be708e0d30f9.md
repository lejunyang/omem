# OmShell：三栏应用外壳与响应式侧栏

OmShell 提供固定顶栏、导航、主内容和可选助手栏；桌面端保持三栏布局，中小屏通过本地开关将侧栏改为覆盖层。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="composition"></a>
## 页面骨架与状态

组件解决应用级布局复用问题。顶栏包含导航按钮、品牌区、业务自定义的 `top` 插槽，以及仅在存在助手插槽时出现的“追问”按钮；主体由导航插槽、默认主内容和可选助手插槽组成。两个本地布尔状态分别控制窄屏导航和助手栏显隐，点击导航区域会自动收起导航。[应用外壳插槽与开关状态 ↗](../../../packages/ui/src/components/OmShell.vue#L1 "支持顶栏、导航、主内容、助手插槽组成方式以及本地显隐状态的说明。") 它复用通用按钮与图标组件，但不掌握路由、助手数据或页面业务状态。

<a id="responsive"></a>
## 响应式流程与限制

外壳占满动态视口并禁止根级滚动，将滚动职责交给导航、主区和助手栏。桌面导航宽 240px、助手栏宽 330px；宽度低于 1100px 时助手栏默认隐藏并可从右侧固定展开，低于 700px 时导航也转为左侧覆盖层，同时缩短顶栏并精简品牌。[基础三栏布局 ↗](../../../packages/ui/src/components/OmShell.vue#L45 "支持视口高度、滚动职责及桌面端导航和助手栏尺寸的说明。")

两个覆盖侧栏没有可见遮罩、焦点约束或 Escape 关闭逻辑，助手栏内部点击也不会像导航一样自动关闭；按钮只通过可见文本表达助手用途，未暴露展开状态。材料未显示路由跳转或跨组件调用依据，也未提供响应式浏览器测试。[窄屏覆盖侧栏规则 ↗](../../../packages/ui/src/components/OmShell.vue#L107 "支持 1100px 与 700px 两级响应式切换，并揭示覆盖层仅由 CSS 显隐的边界。")
