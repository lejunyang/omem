# omem 示例配置

该文件给出检索、Agent 运行配置、通知、学习任务、飞书接入与捕获目录的示例值，描述的是可供部署参考的配置形态，不能单独证明对应能力已经实现或正在运行。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="retrieval-and-profiles"></a>
## 检索与 Agent 配置

示例启用检索并把 `memory-zh` 指定为 osdk 模型，表达了中文记忆检索的预期配置，但仅凭示例文件无法确认模型已下载、锁定或索引已建立。[检索模型示例配置 ↗](../../../config/omem.example.json#L1 "支持检索被示例性启用并指定 memory-zh，同时说明这只是配置声明。")

文件还定义 TraeX ACP、Codex CLI 和 Claude CLI 三个运行配置。TraeX 条目给出只读沙箱启动参数、2 万字符上下文上限、120 秒超时，并要求回答严格基于固定证据；其余两个条目只声明传输方式和命令。因此，这里体现的是候选运行入口及默认约束，而不是外部 CLI 已通过能力探测或现场验证。[Agent 运行配置列表 ↗](../../../config/omem.example.json#L3 "解释三个候选运行入口，以及 TraeX 条目的沙箱、上下文、超时和固定证据约束。")

<a id="automation-and-notifications"></a>
## 通知与学习轮询

通知总模式设为即时；外部通知采用五分钟时间窗，并保留上海时区每天 09:00 的调度字段。该组合展示了即时内部通知与窗口化外部发送的配置维度，但文件未说明两种时间参数在 `window` 模式下的优先级，也不能证明外部通知集成已经启用。[通知策略示例 ↗](../../../config/omem.example.json#L28 "支持即时通知、外部窗口、计划时间与时区等配置维度的描述。")

学习功能在示例中开启，绑定 `traex` 配置并以 1 秒周期轮询。这表明学习任务预期复用同一 Agent 运行配置；是否会自动生成内容、如何保存证据及失败后怎样重试，均不在此材料中。[学习任务轮询配置 ↗](../../../config/omem.example.json#L37 "支持学习功能启用、绑定 traex 配置及轮询周期的陈述。")

<a id="integrations-and-capture"></a>
## 外部接入与捕获范围

飞书接入默认关闭，同时保留 1 秒轮询参数，说明配置预留了该集成但不代表当前部署已连接飞书。[飞书接入开关 ↗](../../../config/omem.example.json#L42 "支持飞书集成默认关闭但保留轮询参数的判断。") 捕获根目录为空数组，意味着示例没有授权任何文件目录作为捕获来源；实际部署若要采集文件，需要另行提供明确范围。[捕获目录配置 ↗](../../../config/omem.example.json#L46 "支持示例未设置任何文件捕获根目录的陈述。")
