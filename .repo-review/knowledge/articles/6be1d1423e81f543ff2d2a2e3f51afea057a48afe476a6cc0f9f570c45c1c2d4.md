# omem 离线交互原型

这是一个自包含的 React 交互原型，集中演示文档优先阅读、递归证据路径、局部追问、版本状态、经验沉淀与来源管理。文件明确使用虚构示例和模拟 AI，不发起网络请求；它能证明界面结构及交互逻辑已被编码，但不能证明真实模型、数据库、同步引擎或生产知识流程已经接通。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="positioning"></a>
## 原型定位与页面结构

文件自述为 omem v0.1 交互原型，采用虚构示例、模拟 AI 且无网络请求，设计重点是灰阶视觉、文档优先阅读和递归证据对话框。因此，它是可运行的交互与视觉样稿，而不是生产能力证明。[原型用途与设计声明 ↗](../../../docs/prototype/index.html#L1 "支持该文件使用虚构示例、模拟 AI、无网络请求，并说明文档优先和递归证据设计定位。")

桌面工作区由顶部栏、左侧导航和中央主区域构成；主区域内部包含独立滚动的阅读区，右侧另设固定宽度的问答面板。[工作区与中央阅读布局 ↗](../../../docs/prototype/index.html#L224 "支持左侧工作区导航、中央主区域以及阅读区独立滚动的页面结构描述。")[右侧问答面板布局 ↗](../../../docs/prototype/index.html#L708 "支持右侧固定宽度面板及其内部纵向问答区域的结构描述。") 此处替代了此前仅凭顶部栏样式推断完整页面布局的结论，并不再把右侧面板描述为已由该样式范围证明“可收缩”。

<a id="evidence_flow"></a>
## 递归证据阅读与知识边界

证据阅读由原生对话框承载，界面包含路径面包屑、当前材料阅读区、片段与上下文标签、页脚操作以及可并列的局部追问面板。[证据对话框界面结构 ↗](../../../docs/prototype/index.html#L1304 "支持证据对话框、路径面包屑、阅读区、片段标签、页脚操作及并列追问面板的界面组成。") 实际打包逻辑为面包屑绑定栈截取操作，点击任意层会保留至该层；打开已在路径中的材料时不会继续压栈，而是显示循环提示并允许返回既有层。[证据栈导航与边界状态逻辑 ↗](../../../docs/prototype/index.html#L2217 "支持面包屑跳转、逐层返回、循环检测、路径保持，以及历史、受限、删除和定位失败状态的实际事件与渲染逻辑。")

同一逻辑还依据材料状态分别呈现历史版本、受限、删除和原文定位失败等边界，只有可用或已替代材料能进入片段问答。[证据栈导航与边界状态逻辑 ↗](../../../docs/prototype/index.html#L2217 "支持面包屑跳转、逐层返回、循环检测、路径保持，以及历史、受限、删除和定位失败状态的实际事件与渲染逻辑。") 原型数据明确把旧规范标为已替代，并提示当前回答应使用新版本；旧结论与引用仍被保留用于历史核对，而不是被新正文静默覆盖。[已替代版本演示数据 ↗](../../../docs/prototype/index.html#L2217 "支持旧规范被标记为已替代、历史引用继续保留且当前回答应采用新版本的说明。")

<a id="interaction_limits"></a>
## 交互覆盖、适配与实现限制

问答区明确标注“演示回答、未连接模型”，回答由本地延时和示例节点拼装；同步、候选沉淀、变更恢复等操作也只修改浏览器内的演示状态。[本地模拟问答与演示状态 ↗](../../../docs/prototype/index.html#L2217 "支持问答未连接真实模型、由本地延时模拟，并说明同步、候选和变更操作属于浏览器内演示。") 因而这些代码证明了状态转换与反馈路径存在，不能证明真实检索、语义核验、外部同步或持久化已经实现。

响应式规则在中窄屏隐藏固定问答栏并提供移动面板，在手机宽度隐藏侧栏、把证据对话框扩展为全屏并增大主要触控目标；系统要求减少动态效果时会禁用动画与过渡。[响应式与减少动态效果规则 ↗](../../../docs/prototype/index.html#L1678 "支持中窄屏问答面板、手机侧栏与全屏证据阅读、触控目标及 reduced-motion 适配的描述。") 这些仍是实现声明，材料没有提供浏览器实测、键盘路径测试或无障碍审计结果。
