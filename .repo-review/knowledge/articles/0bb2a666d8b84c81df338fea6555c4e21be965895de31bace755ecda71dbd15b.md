# 知识刷新技能的 OpenAI 界面配置

该文件声明刷新技能在代理界面中的显示名称、英文简介和默认提示语，用于引导代理调用指定技能处理固定材料；它不包含刷新实现或运行证明。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="presentation"></a>
## 技能展示语义

界面将技能显示为“更新关联知识”，与刷新角色的职责名称一致。短描述则把任务概括为从固定证据构建关联知识，突出输入证据的固定性与产物之间的关联。[知识刷新界面名称与简介 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/skills/omem-knowledge-refresher/agents/openai.yaml#L1 "支持技能的用户可见名称及基于固定证据构建关联知识的定位。") 该描述较为通用，没有单独表达保留未受影响知识和标记替代结论等增量语义。

<a id="default"></a>
## 默认调用入口

默认提示语要求代理使用指定的知识刷新技能处理已提供的固定材料。[知识刷新默认提示语 ↗](../../../packages/agent-runtime/roles/knowledge-refresher/1/skills/omem-knowledge-refresher/agents/openai.yaml#L4 "支持代理界面默认调用知识刷新技能处理固定材料的约定。") 这只是界面层的默认调用文本；是否真正加载正确版本、是否采用清单中的无工具策略，以及输出是否通过 KnowledgeBatch 合同，仍需要运行时校验和行为结果才能确认。
