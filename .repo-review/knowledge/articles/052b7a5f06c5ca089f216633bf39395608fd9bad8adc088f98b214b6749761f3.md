# Agent 自主调查的隔离研究运行时

该文件把一次 Agent 自主调查准备成受范围约束的本地环境：分批导出固定原始材料，构建或复制只读检索快照，提供按项目、材料范围，以及知识与状态调查的工具，校验并保存首个有效候选结果，并向上层暴露准备耗时、活动记录、权限判断和幂等清理接口。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_and_call"></a>
## 一次调查如何启动

这个运行时接收仓储、固定材料、已有文章、工作区和结果校验契约，返回一套可供 Agent 阅读、检索与提交的本地调查环境。当前入口只把需要的准备工作交给 `prepareResearch`；重型快照构建在对应构建流程中排队，独立复核的快照复制和模型启动不会等待无关的准备任务。参考 [调查输入与准备入口 ↗](../../../apps/server/src/knowledge/agent-research.ts#L89 "支持运行时输入契约、快照复用方式和准备入口的说明。")

```mermaid
flowchart LR
  A[调查输入] --> B[分批导出固定原件]
  B --> C[构建或复制只读快照]
  C --> D[启动本地 MCP 服务]
  D --> E[阅读与检索]
  E --> F[校验并保存候选结果]
```

原件目录以 0700 权限创建。材料正文尽量沿用安全且不冲突的相对路径；绝对路径、越界路径，以及发生冲突的路径会落到摘要命名的子目录。图片统一导出到工作区的 `images` 目录，以资源 ID 和图片格式后缀命名。初始材料每 8 份组成一批，批内文件以 0600 权限并行写入，每批开始前检查中止信号。参考 [分批导出固定原件 ↗](../../../apps/server/src/knowledge/agent-research.ts#L172 "支持目录和文件权限、正文路径约束、图片导出位置、每批八份并行写入及中止检查。")

数据库可以从已封存快照复制，也可以根据当前输入构建，随后以只读模式打开。运行时生成材料、项目与主题目录，并且只把数据库中确实存在的知识版本写入知识目录。语义检索默认启用 `memory-zh` 向量模型；重排器按配置加载。参考 [只读快照与调查目录 ↗](../../../apps/server/src/knowledge/agent-research.ts#L235 "支持快照复制或构建、只读数据库、项目与材料目录、知识版本准入和检索模型加载。")

<a id="research_tools"></a>
## 材料如何变成可调查的工具

文件接入知识仓储、快照构建和统一检索，也依赖材料结构定位、上下文层级与代码解析模块。它由此把固定材料投影成可读文件、真实行号、章节结构和代码线索。参考 [跨模块依赖 ↗](../../../apps/server/src/knowledge/agent-research.ts#L25 "说明该运行时与仓储、检索、快照、结构定位、上下文层级和代码解析模块的关系。")

材料定位接受精确 key、原始路径或导出路径。路径对应多个材料时会要求改用精确 key，未知定位也直接报错；范围读取会校验起止行，返回修订号和真实行号，并附结构大纲、项目归属，以及图片与来源信息。参考 [材料定位与范围读取 ↗](../../../apps/server/src/knowledge/agent-research.ts#L402 "支持定位歧义检查、范围校验以及带结构和来源信息的读取结果。") 项目或主题范围先核对目录中的 ID，再与显式材料范围取交集；未知 ID 会报错，避免范围被意外放大。参考 [项目与材料范围选择 ↗](../../../apps/server/src/knowledge/agent-research.ts#L419 "支持项目或主题 ID 校验、材料范围解析以及两类范围取交集的规则。")

调查入口既支持单份材料读取，也能按显式范围、所在章节或上下文 ID 批量读取最多 16 个请求。批量读取会先校验全部选择器，再合并同一原件中相邻或重叠的范围，同时保留原请求序号。参考 [单份与批量原文读取 ↗](../../../apps/server/src/knowledge/agent-research.ts#L585 "支持单份读取和最多 16 个批量请求的选择、预校验、范围合并及请求索引保留。")

每次 HTTP 请求都会创建一个无状态 MCP server。通过通用 `tool` 包装器注册的工具受 `allowedTools` 白名单限制；包装器标记只读属性，记录成功或失败，并隐藏最终提交的正文。扩展工具也通过该包装器注册，读取同一数据库、当前材料集合和已准入文章，非独立复核环境还可获得材料准入能力。参考 [通用工具注册与审计包装 ↗](../../../apps/server/src/knowledge/agent-research.ts#L481 "支持白名单限制、只读标注、成功失败审计及扩展工具共享调查快照。") `read_image` 和 `submit_result` 是固定入口，由各自的注册逻辑加入工具清单。参考 [固定图片读取与结果提交入口 ↗](../../../apps/server/src/knowledge/agent-research.ts#L1234 "支持 read_image 与 submit_result 分别直接注册并固定加入工具清单。")

多问题检索先逐项解析显式材料或项目范围，避免错误定位把搜索扩大到全部可见内容；随后并行检索各问题。命中原件时会扩成完整阅读范围，命中已有讲解时会携带派生标记、依赖和本节引用，记忆与事项状态则作为已应用状态返回。相同上下文会去重，但每个问题保留自己的排名；空结果只表示搜索缺口。参考 [多问题完整上下文检索 ↗](../../../apps/server/src/knowledge/agent-research.ts#L827 "支持显式范围预解析、并行检索、不同结果类型的上下文展开、去重和逐问题排名。")

运行中追加材料也有范围限制。独立复核不能新增材料，可见性策略会拒绝未获准片段；同一来源和修订直接复用，key 冲突时附加修订号以保留旧定位。新增材料随后进入快照和导出目录，并更新片段索引与材料目录。参考 [运行时材料准入 ↗](../../../apps/server/src/knowledge/agent-research.ts#L322 "支持独立复核限制、可见性检查、修订去重、冲突 key 处理和新增材料索引更新。")

<a id="submission_and_boundaries"></a>
## 提交、权限与清理边界

`submit_result` 每次先调用传入的校验器。首个通过校验的结果以 0600 权限写入 `result.json`，然后触发回调并保存为本次候选，同时记录已读材料并解除等待；后续有效提交只返回“已经保存”，不会覆盖首个候选。校验失败会作为工具错误返回，供同一轮调查修正后重试。这个动作保存的是候选结果，不等于发布知识。参考 [结果校验与首次保存 ↗](../../../apps/server/src/knowledge/agent-research.ts#L1270 "支持校验顺序、首次候选落盘、回调、已读记录、重复提交和失败回传行为。")

服务只监听 `127.0.0.1` 的随机端口，使用随机路由且只接受 POST。返回环境包含准备耗时、工具清单、结果读取器、提交等待对象与重置入口。每个请求结束时关闭自己的 transport 和 server，请求之间共享的仍是这一调查任务的结果与审计状态。参考 [本地服务与返回环境 ↗](../../../apps/server/src/knowledge/agent-research.ts#L1312 "支持无状态请求服务、监听地址、随机路由、POST 限制和返回环境字段。")

上层工具更新会把原生文件读取以及可识别的 shell 读取映射回材料 key；审计记录工具输入，但会把提交正文替换为已提交标记。权限判断只放行本任务实际暴露的 `omem` 工具，以及所有路径都位于工作区内的本地读取或搜索。参考 [原生读取审计与权限判断 ↗](../../../apps/server/src/knowledge/agent-research.ts#L1377 "支持文件和 shell 读取映射、提交内容隐藏以及 MCP 与工作区文件权限边界。")

`close` 可以重复调用。它关闭 HTTP 连接、检索器和 SQLite，并删除原件导出和图片，以及快照数据库与范围证据；材料目录、知识目录、结果、准备记录和审计文件不在删除清单中。参考 [幂等关闭与临时数据清理 ↗](../../../apps/server/src/knowledge/agent-research.ts#L139 "支持资源释放顺序、可重复关闭和明确的临时文件删除清单。") 准备过程抛错时也会先尝试执行清理，再把原错误抛出。参考 [准备失败时清理 ↗](../../../apps/server/src/knowledge/agent-research.ts#L1432 "支持准备阶段失败后先尝试关闭，再重新抛出错误。")
