# 为知识 Agent 构建隔离的自主研究环境

prepareAgentResearch 把固定材料、既有文章和只读检索快照封装成一次任务专属的本机 MCP 环境，使 Agent 能用原生文件工具与结构化工具补查证据，并以受校验、可审计、可回收的方式提交候选结果。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 它解决什么问题

知识 Agent 需要主动搜索原文、代码符号和既有讲解，但不应直接操作正式存储。`prepareAgentResearch` 接收知识仓库、固定材料、文章、任务工作区、输出 schema 与校验器，返回运行时可挂载的研究环境。它本身是装配层：连接知识仓库、统一检索、材料结构解析、代码 AST 与 Agent 网关，而不另造一套知识模型。参考 [研究环境依赖 ↗](../../../apps/server/src/knowledge/agent-research.ts#L18 "支持该函数作为装配层连接运行时、检索、结构解析、代码解析和知识仓库的说明。")、[环境输入输出 ↗](../../../apps/server/src/knowledge/agent-research.ts#L50 "说明函数接收仓库、材料、文章、工作区、schema、校验器和检索配置，并返回原生研究环境。")。

<a id="flow"></a>
## 一次代表性调用如何运行

代表性输入是一组已捕获材料、可参考文章和本次输出合同。函数先把原文安全导出到任务目录；相对路径不安全或重名时改用材料摘要分目录，同时生成材料/文章目录。随后同步检索投影，以 `VACUUM INTO` 固化 SQLite，并以只读方式打开，再按配置接入中文向量与可选重排器。参考 [固定原文导出 ↗](../../../apps/server/src/knowledge/agent-research.ts#L90 "支持安全保留相对目录、处理路径冲突并导出原文和图片的流程。")、[只读检索快照 ↗](../../../apps/server/src/knowledge/agent-research.ts#L149 "支持生成文章目录、固化 SQLite 快照、只读打开并装配统一检索的说明。")。

```mermaid
flowchart LR
  A[固定材料与输出合同] --> B[导出原文和只读快照]
  B --> C[Agent 读取、检索与代码导航]
  C --> D[校验并保存候选结果]
  D --> E[返回结果、审计与关闭能力]
```

本机 HTTP MCP 使用随机路径，每个请求新建无会话 transport；Agent 可做限定范围的混合检索，也可解析符号、导入与候选调用。最终 `submit_result` 先运行宿主校验，成功才写入 `result.json` 并暴露给 `result()`。参考 [限定范围混合检索 ↗](../../../apps/server/src/knowledge/agent-research.ts#L350 "说明检索按材料范围和类型过滤，并返回片段、上下文、结构位置与健康状态。")、[代码导航候选 ↗](../../../apps/server/src/knowledge/agent-research.ts#L522 "说明代码导航利用解析器返回定义、导入、路由、测试及明确标为候选的调用。")、[候选提交与本机服务 ↗](../../../apps/server/src/knowledge/agent-research.ts#L672 "支持提交前校验、结果保存，以及随机本机 HTTP MCP 端点的代表性调用末段。")。

<a id="boundaries"></a>
## 可信边界与生命周期

材料读取只接受本次捕获范围内的 key 或路径，并校验行号；越界材料和非法区间会直接报错。代码导航返回的跨文件调用明确标记为 `candidate`，不能当完整调用图。参考 [材料范围与行号校验 ↗](../../../apps/server/src/knowledge/agent-research.ts#L206 "支持只读取捕获范围内材料、拒绝非法行区间并返回真实行号与来源信息的边界。")、[代码导航候选 ↗](../../../apps/server/src/knowledge/agent-research.ts#L522 "说明代码导航利用解析器返回定义、导入、路由、测试及明确标为候选的调用。")。

权限层只放行已注册的 omem 工具，以及位置全部位于工作区内的原生读取/搜索；工具调用、计划、读取材料与输出摘要进入审计，提交内容本身会被遮蔽。关闭环境时依次停 HTTP、语义检索和数据库，再删除可重建的原文、图片与 SQLite 副本；目录、提交结果和审计继续保留，正式仓库中的不可变原件不受影响。参考 [审计与权限 ↗](../../../apps/server/src/knowledge/agent-research.ts#L766 "说明原生读取如何计入依赖与审计，以及权限仅限已注册工具和工作区内读取搜索。")、[任务副本回收 ↗](../../../apps/server/src/knowledge/agent-research.ts#L64 "支持关闭各资源并只清理可重建任务副本、保留目录结果和审计的生命周期说明。")。
