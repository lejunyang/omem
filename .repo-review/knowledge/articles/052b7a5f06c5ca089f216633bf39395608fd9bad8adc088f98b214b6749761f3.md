# Agent 自主调查的隔离研究运行时

该文件把一次 Agent 自主调查准备成可控的本地运行环境：导出固定原始材料，构建或克隆检索快照，注册受范围约束的 MCP 阅读与检索工具，接收经过业务校验的最终结果，并向上层暴露进度、审计、权限判断和清理接口。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_and_call"></a>
## 一次调查如何启动

这个运行时为 Agent 的一次自主调查准备工作区，并通过工具准入、工作区文件范围和候选结果提交约束本文件可见的调用边界。`prepareAgentResearch` 的基础输入包括仓储与材料，另有已有文章和工作区，以及结果 schema 与校验器；函数只串行化准备阶段，随后返回 `NativeResearchEnvironment`，并不串行化模型会话。参考 [调查输入与准备阶段串行化 ↗](../../../apps/server/src/knowledge/agent-research.ts#L86 "支持基础输入字段清单、准备阶段串行化和返回环境的说明。")、[工具统一注册 ↗](../../../apps/server/src/knowledge/agent-research.ts#L478 "支持每次请求创建 server、工具白名单、审计包装和额外工具共享快照的说明。")、[结果提交事务 ↗](../../../apps/server/src/knowledge/agent-research.ts#L1203 "支持每次先校验、首次有效结果落盘与回调、重复提交不覆盖以及失败回传行为。")、[审计与权限判断 ↗](../../../apps/server/src/knowledge/agent-research.ts#L1302 "支持原生读取追踪、提交内容隐藏和工作区读取权限边界。")

```mermaid
flowchart LR
  A[ResearchInput] --> B[导出原始材料]
  B --> C[构建或克隆固定快照]
  C --> D[启动本地 MCP]
  D --> E[Agent 阅读与检索]
  E --> F[校验并保存结果]
```

`originals` 目录以 0700 权限创建，导出的正文和图片文件以 0600 权限写入；相对路径尽量保留，绝对路径或冲突路径改用摘要目录，避免写出工作区。参考 [原始材料导出 ↗](../../../apps/server/src/knowledge/agent-research.ts#L176 "支持 originals 目录权限、导出文件权限、路径约束、正文导出和图片复制流程。") 数据库则从既有快照只读克隆，或由当前输入构建。语义检索默认启用；启用时，构造 `UnifiedRetrieval` 时会传入中文向量模型加载器，并在首次检索准备索引时使用；可选重排器也按配置以加载器传入。参考 [快照与检索器 ↗](../../../apps/server/src/knowledge/agent-research.ts#L234 "支持固定数据库的构建或克隆，以及语义模型和重排器以加载器形式按配置传入。")、[多问题上下文检索 ↗](../../../apps/server/src/knowledge/agent-research.ts#L758 "支持首次检索时准备索引，以及各问题范围解析、并行检索和完整上下文扩展流程。")

<a id="research_tools"></a>
## 材料如何变成可调查的工具

文件依赖仓储与快照构建模块，并接入统一检索；材料结构定位和代码解析也在依赖范围内。它把存储中的固定材料投影成 Agent 可读的目录和章节，并提供搜索结果与符号线索。参考 [跨模块依赖 ↗](../../../apps/server/src/knowledge/agent-research.ts#L25 "说明该运行时与仓储、检索、快照、结构定位和代码解析模块的关系。") 定位器接受精确 key、材料路径或导出路径；未知或歧义路径直接报错，读取时返回真实行号与层级结构，并附来源信息和图片定位。参考 [定位与读取 ↗](../../../apps/server/src/knowledge/agent-research.ts#L398 "支持材料定位的歧义检查、范围校验和带来源信息的读取结果。")

每次 HTTP 请求都会创建无状态 MCP server，但工具状态、读取集合和最终提交属于同一个调查任务。通用注册器套上白名单和只读提示，并记录成功/失败审计；额外工具拿到的也是同一份快照。参考 [工具统一注册 ↗](../../../apps/server/src/knowledge/agent-research.ts#L478 "支持每次请求创建 server、工具白名单、审计包装和额外工具共享快照的说明。") 多问题检索会先解析每个问题的材料范围，再并行召回，并把命中的原始材料扩成完整上下文；空结果只表示检索缺口。参考 [多问题上下文检索 ↗](../../../apps/server/src/knowledge/agent-research.ts#L758 "支持首次检索时准备索引，以及各问题范围解析、并行检索和完整上下文扩展流程。")

运行中的材料准入有明确边界：独立复核快照禁止新增材料，可见性策略不允许越权片段；同一来源同一修订会复用，key 冲突则附加修订号并重建目录索引。参考 [运行时材料准入 ↗](../../../apps/server/src/knowledge/agent-research.ts#L319 "支持固定快照禁止新增、可见性校验、去重与冲突 key 处理等边界。")

<a id="submission_and_boundaries"></a>
## 提交、权限与清理边界

`submit_result` 每次都会先调用宿主提供的 `validate`。首次校验通过后才写入 `result.json`、触发 `onSubmitted`、记录本次读过的材料并解除等待；重复提交再次通过校验后返回已保存，且不会覆盖首个候选。校验失败会作为工具错误回到同一轮调查，Agent 可以修正后重试。参考 [结果提交事务 ↗](../../../apps/server/src/knowledge/agent-research.ts#L1203 "支持每次先校验、首次有效结果落盘与回调、重复提交不覆盖以及失败回传行为。")

服务仅监听 `127.0.0.1` 的随机端口和随机路由，只接受 POST；返回环境还包含工具清单、调查指令、结果读取器与提交等待对象。参考 [本地 MCP 入口 ↗](../../../apps/server/src/knowledge/agent-research.ts#L1246 "支持监听地址、随机路由、POST 限制及返回环境字段。") 上层更新会把原生文件读取映射回材料 key，审计工具输入但隐藏提交正文；权限判断仅放行当前任务暴露的 `omem` 工具，以及路径全部位于工作区的本地读/搜操作。参考 [审计与权限判断 ↗](../../../apps/server/src/knowledge/agent-research.ts#L1302 "支持原生读取追踪、提交内容隐藏和工作区读取权限边界。")

`close` 可重复调用。它依次关闭 HTTP、检索器和 SQLite，并删除可重建的原文导出和图片，以及快照数据库与范围证据；目录、结果和审计文件会保留。参考 [资源关闭与清理 ↗](../../../apps/server/src/knowledge/agent-research.ts#L143 "支持幂等关闭、资源释放，以及可重建临时数据的删除与保留边界。") 准备过程中抛错时，错误路径也会先调用 `close`，再重新抛出错误。参考 [准备失败时清理 ↗](../../../apps/server/src/knowledge/agent-research.ts#L1362 "支持准备阶段抛错后先调用关闭逻辑，再重新抛出错误。")
