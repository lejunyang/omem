# 固定快照上的 Agent 自主研究环境

prepareAgentResearch 将一次任务获准的材料、知识文章和仓储状态导出为隔离工作区，并提供受范围约束的原生文件读取、MCP 检索与结构导航能力。Agent 最终只能通过调用方给定的 schema 和 validate 提交候选结果；环境同时记录活动、限制权限并负责释放临时副本。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 它解决什么问题

知识生成 Agent 既要补读完整原文、搜索代码和历史，又不能越过本次任务的材料范围。`prepareAgentResearch` 把仓储中的固定版本投影成一次性研究环境：知识管线把选中的材料、已有文章、输出合同和校验器交给它，Agent 完成后，管线再保存经校验的角色输出。参考 [知识生成调用链 ↗](../../../apps/server/src/knowledge/pipeline.ts#L118 "支持知识管线把固定材料和输出校验交给研究环境，并保存最终角色输出的代表性调用。")

同一底座也服务普通助手；助手调用方先筛出当前可见材料，再注入回答专用 schema、引用验证和事项操作约束。因此这里负责通用研究能力，具体“什么结果算合法”仍由上层场景决定。参考 [普通助手接入 ↗](../../../apps/server/src/assistant/research.ts#L49 "支持普通助手筛选可见材料、传入可见性策略及专用结果校验的模块关系。")

<a id="representative-flow"></a>
## 一条代表性调用如何完成

以知识页面生成任务为例，输入是本轮材料、可用文章、工作目录、检索配置及输出校验器。函数先安全导出原件和图片，写出材料目录，随后构造 SQLite 研究快照；只有已进入该快照的文章才会出现在知识目录中。参考 [固定快照准备 ↗](../../../apps/server/src/knowledge/agent-research.ts#L107 "支持原件安全导出、材料目录写入、研究快照创建和文章准入过滤的流程。")

```mermaid
flowchart LR
  A[知识管线提供固定材料与输出合同] --> B[导出原件并建立研究快照]
  B --> C[Agent 搜索、补读与代码导航]
  C --> D[submit_result 校验并保存候选结果]
  D --> E[知识管线保存角色输出]
```

搜索首次使用时才建立索引；配置启用时可加载中文向量与重排模型，索引失败会记录原因并继续走词面检索。搜索结果仍经过材料 key、类型和快照片段范围过滤。参考 [检索初始化与范围过滤 ↗](../../../apps/server/src/knowledge/agent-research.ts#L193 "支持检索器按配置加载模型、延迟索引、失败降级并按材料范围过滤结果。") 最终 `submit_result` 先执行调用方的 `validate`，成功后保存 `result.json` 并让环境的 `result()` 返回该对象；失败则在同一轮给出可修正错误。参考 [候选结果提交 ↗](../../../apps/server/src/knowledge/agent-research.ts#L796 "支持提交结果必须通过调用方校验、成功后落盘并可由环境取回的输出语义。")

<a id="tools-and-relations"></a>
## 工具分工与模块关系

工具分三层：`list/read_material` 与 `read_section` 负责定位固定原文；`search_materials`、知识与记忆工具复用 `UnifiedRetrieval` 和研究快照；`code_navigation` 调用解析器返回定义、导入、路由、测试及名称级调用候选。后者明确只是候选，不是完整调用图，跨文件关系仍需回读调用点确认。参考 [代码导航候选 ↗](../../../apps/server/src/knowledge/agent-research.ts#L633 "支持代码导航调用解析器并把调用关系标为候选，而非完整、类型解析后的调用图。")

因此主要修改入口也很清楚：材料投影和可见范围在快照准备处，检索策略由 `RetrievalConfig` 与统一检索器控制，代码结构能力来自 `parseFile`，业务输出规则来自调用方传入的 schema/validate。普通助手与知识管线是两个已由源码确认的消费者，并非由目录结构推断。

<a id="boundaries"></a>
## 范围、安全与生命周期边界

材料读取只接受当前 `entries` 中的 key、已登记路径或工作区内解析路径；越界 key 和非法行范围直接报错。导出时绝对路径、路径穿越风险和重名文件会改用摘要目录，避免写出任务目录。参考 [材料读取边界 ↗](../../../apps/server/src/knowledge/agent-research.ts#L267 "支持材料 key 必须属于捕获范围、行号必须有效的访问边界。")

MCP 只监听本机随机路径，只接受 POST；每个请求新建无会话服务实例，但提交结果、读取集合与审计属于本次任务。参考 [本机 MCP 端点 ↗](../../../apps/server/src/knowledge/agent-research.ts#L832 "支持随机路由、POST 限制、按请求创建无会话 MCP 服务以及本机监听的运行方式。") 权限层只放行本环境公布的 omem 工具，以及位置全部落在工作区内的原生 read/search；其他 MCP 不自动授权。关闭环境会停止 HTTP、检索器和数据库，并删除可重建的原件、图片与快照副本，保留目录、结果和审计。参考 [研究权限约束 ↗](../../../apps/server/src/knowledge/agent-research.ts#L928 "支持只放行已公布的 omem 工具和工作区内原生读取、搜索操作的权限边界。") [临时资源清理 ↗](../../../apps/server/src/knowledge/agent-research.ts#L81 "支持关闭时停止服务、检索器和数据库，并删除可重建任务副本的生命周期行为。")
