# Agent 自主研究环境：从固定快照到可校验提交

该实现为知识生成 Agent 建立一次性、受范围约束的研究环境：把捕获材料和知识目录导出为可原生阅读的快照，同时提供检索、代码导航、历史与提交工具；最终结果必须经过调用方提供的 schema 与验证器，研究过程则留下审计记录。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 为什么需要独立研究环境

`prepareAgentResearch` 解决的是“让 Agent 自主补读材料，同时不离开本次捕获范围”的问题。调用方传入仓库、固定材料、已有文章、任务工作区以及输出 schema/验证器，函数返回可供运行时使用的研究环境。参考 [研究环境输入输出 ↗](../../../apps/server/src/knowledge/agent-research.ts#L50 "支持该函数接收固定材料、文章、工作区、schema 与验证器，并返回原生研究环境的说明。")

它把多个现有能力组合成一条链：`KnowledgeRepository` 提供数据库与图片资产，结构模块生成章节和片段位置，语义/关键词检索负责发现内容，代码解析器只提供符号、导入和候选调用线索。参考 [研究能力依赖 ↗](../../../apps/server/src/knowledge/agent-research.ts#L18 "支持仓储、检索、结构解析和代码解析等模块在研究环境中的职责关系。")

<a id="workflow"></a>
## 一次代表性研究如何完成

以“为一份代码材料生成知识页”为例，输入材料先被写入 `originals/`：安全的相对路径会保留，绝对路径、越界路径或重名文件会改用摘要目录，避免覆盖或逃逸工作区。随后生成 `catalog.json`、`knowledge.json` 和只读 SQLite 快照，并按配置选择语义检索或关键词检索。参考 [受限原件导出 ↗](../../../apps/server/src/knowledge/agent-research.ts#L94 "支持安全相对路径、越界或冲突路径改名，以及材料写入任务工作区的流程。") [目录与检索快照 ↗](../../../apps/server/src/knowledge/agent-research.ts#L135 "支持生成目录、只读数据库快照并按配置选择语义或关键词检索的说明。")

```mermaid
flowchart LR
  A[固定材料与已有文章] --> B[任务文件与只读快照]
  B --> C[阅读、搜索、代码导航]
  C --> D[submit_result]
  D --> E[校验后的候选结果]
```

Agent 可按行读取、检索片段；代码导航会现场解析文件并返回符号、导入、路由、测试及标为 `candidate` 的调用，因此这些调用不能直接当完整调用图。参考 [材料搜索流程 ↗](../../../apps/server/src/knowledge/agent-research.ts#L347 "支持检索初始化、范围过滤、命中片段映射以及返回章节位置的说明。") [候选代码导航 ↗](../../../apps/server/src/knowledge/agent-research.ts#L488 "支持代码导航现场解析符号、导入、路由和测试，并将调用显式标为候选关系。")

完成后，`submit_result` 先执行外部注入的 `validate`，成功才保存内存结果和 `result.json`；失败则把错误返回给同一研究会话修正。参考 [结果校验与保存 ↗](../../../apps/server/src/knowledge/agent-research.ts#L638 "支持提交先经验证器处理、成功后记录并写入结果文件、失败后返回错误的说明。")

<a id="boundaries"></a>
## 范围、权限与生命周期边界

材料读取只接受目录中登记的 key 或路径，并检查行号；越界材料和非法范围都会明确报错。服务只监听 `127.0.0.1` 的随机端口与随机路径，且只接受该路径上的 POST 请求。参考 [材料读取边界 ↗](../../../apps/server/src/knowledge/agent-research.ts#L203 "支持材料必须属于捕获范围、行号合法且读取会返回真实行号与来源信息的说明。") [本地 MCP 服务 ↗](../../../apps/server/src/knowledge/agent-research.ts#L674 "支持随机路由、回环地址监听、路径与方法检查，以及环境返回服务描述的说明。")

自动授权也有双重边界：要么调用本环境已注册的 omem 工具，要么执行位置全部位于任务工作区内的原生读取/搜索；其他请求不放行。参考 [自动授权范围 ↗](../../../apps/server/src/knowledge/agent-research.ts#L770 "支持仅授权已注册 omem 工具或工作区内部读取与搜索的权限边界。")

关闭环境时会停止 HTTP、检索和数据库句柄，并删除可重建的原件副本、图片目录与 SQLite 快照；目录清单、提交结果和研究审计被保留，规范存储中的原始证据不由这里删除。参考 [研究环境清理 ↗](../../../apps/server/src/knowledge/agent-research.ts#L64 "支持关闭服务与句柄、删除可重建任务副本并保留目录结果和审计的生命周期说明。")
