# 知识正文复核角色的界面与默认提示配置

该配置为知识复核角色声明人类可读名称、简短说明和默认提示词，用于把固定材料交给指定技能处理。它仅能证明角色配置的预期入口，不能单独证明技能已加载、复核流程已执行或知识已通过验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-purpose"></a>
## 面向使用者的角色定位

该角色在界面中显示为“复核知识正文”，表明它面向已有知识内容的复核场景，而不是原始材料采集或普通问答。简短说明进一步把目标描述为：基于固定证据构建带关联的知识。两项字段共同提供角色的展示定位，但中英文混用可能影响界面一致性。参考 [复核角色展示配置 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/skills/omem-knowledge-verifier/agents/openai.yaml#L1 "支持该角色的人类可读名称、功能说明以及固定证据导向的定位。")

<a id="default-entry"></a>
## 默认调用入口与能力边界

默认提示词要求使用指定的知识复核技能处理已提供的固定材料，体现了“角色配置 → 技能 → 固定证据”的预期调用关系。参考 [默认复核提示词 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/skills/omem-knowledge-verifier/agents/openai.yaml#L4 "支持默认入口会指定知识复核技能处理所提供固定材料的陈述。")

这份 YAML 只声明默认提示，并未给出技能实现、输入输出校验、独立复核结果或运行记录，因此不能据此认定复核已经发生，也不能证明不受支持的设置会被拒绝。实际能力仍需结合技能定义和运行证据确认。
