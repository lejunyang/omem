# 知识复核技能的界面元数据

该 YAML 提供技能在代理界面中的显示名称、短描述和默认调用提示；其中中文名称指向复核职责，但英文短描述更像知识构建，存在界面语义不一致。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="interface-metadata"></a>
## 界面展示与默认入口

界面显示名称为“复核知识正文”，默认提示则要求使用 `omem-knowledge-verifier` 处理所提供的固定材料，二者都把入口指向复核技能。[技能显示名称与默认提示 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/skills/omem-knowledge-verifier/agents/openai.yaml#L1 "支持界面名称和默认入口均指向知识复核技能的说明。") 这些字段属于技能界面元数据和默认触发文本，不足以单独证明运行时会加载技能、执行校验或产生合规结果。

<a id="wording-mismatch"></a>
## 描述语义差异

短描述写为“Build linked knowledge from fixed evidence”，表达的是从固定证据构建关联知识，与显示名称强调的“复核知识正文”并不完全一致。[英文短描述 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/skills/omem-knowledge-verifier/agents/openai.yaml#L2 "支持短描述采用“构建关联知识”措辞并与复核职责存在语义差异的判断。") 这可能只是展示文案遗留，也可能使用户误解该代理会负责写作；仅凭当前五行配置无法确定产品期望，应结合角色职责统一文案。
