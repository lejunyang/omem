# 质量数据集冻结与分维度评估测试

该测试验证评测专用数据集的去重导入、人工确认和摘要防篡改，并以确定性规则基线区分引文定位、语义支持、事实槽、覆盖率、任务完成及不必要打扰。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="dataset-lifecycle"></a>
## 评测数据集生命周期

导入入口必须显式传入 `QUALITY_EVAL_ONLY`，普通 capture 不应进入这条研究评测路径。相同来源重复导入返回原数据集且不新增样本；样本未全部人工确认时冻结会失败，确认后生成 64 位 manifest digest，并可通过 `verifyFrozen` 复验。直接篡改已确认标签 JSON 会使复验失败，说明冻结保护的是数据集内容而非仅状态字段。[数据集导入、确认与冻结 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L50 "支持评测入口隔离、幂等导入、未确认时拒绝冻结、摘要冻结和篡改检测。")

<a id="metric-model"></a>
## 证据质量的拆分判定

评估不再把“引文是原文子串”等同于“结论受支持”，而是分别统计引文位置、语义支持、核心事实槽、必要证据覆盖、任务完成和不必要打扰。完全复制人工标签时各维度满分；引用位置正确但反向概括时，定位仍通过，语义则记为 contradicted，任务也不算完成。[定位与语义支持分离 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L104 "支持多维指标设计及引文可定位但结论矛盾时语义不通过的区别。")

空答案不进入定位、语义和事实槽分母，但仍构成必要证据漏召回。规则样例还接受忠实同义改写，把遗漏限制条件或把历史规则宣称为当前有效判为 partial，并识别肯否翻转和数值上限变化。[语义与覆盖率规则样例 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L201 "支持空答案、同义改写、限制条件、时间、否定和数值事实槽的具体断言。")

<a id="coverage-limits"></a>
## 断言边界

这些断言刻画的是当前规则基线在少量中文句式上的确定性结果，不能据此推断其对跨句限定、双重否定、单位换算或多个时间范围同样可靠。零样本时，测试明确检查所列出的各项 rate 与延迟 `p50` 为 null；这替代了旧稿所称“所有延迟分位数均为 null”，因为其他分位数未在该范围内逐项断言。[无合格分母的指标语义 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L331 "支持零样本时列出的各项 rate 与延迟 p50 返回 null，并界定没有断言其他延迟分位数。")
