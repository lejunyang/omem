# 质量数据集与证据评估测试

该测试验证研究专用质量数据集从导入、人工确认、冻结到指标评估的闭环，并分别检查引用定位、语义支持、事实槽一致性、证据覆盖、任务完成和不必要打断。它以反例替代了“引文可定位即语义受支持”的旧结论，并明确空分母返回 null；尚未覆盖真实模型、生产捕获链路、并发冻结及复杂语言现象。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="dataset_lifecycle"></a>
## 研究数据集生命周期

测试在临时目录中实例化 `Store`，通过研究专用 opt-in 从一份含账号唯一性、手机号上限和权限范围的材料导入三个样本；再次导入同一材料必须复用原数据集且不新增样本。[临时仓储中的研究样本导入与去重 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L50 "支持测试使用临时目录隔离仓储、显式研究 opt-in、首次插入三个样本以及重复导入不新增的流程说明。") 全部样本经人工确认前，数据集不能冻结；确认后会生成 64 位十六进制清单摘要，随后直接篡改已冻结标签必须使校验失败，说明冻结结果能够发现持久化内容漂移。[人工确认、冻结与篡改检测 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L80 "支持冻结前置条件、人工确认、清单摘要校验以及冻结后标签漂移会被发现的论断。")

这条路径只验证隔离的评测工具链。导入器明确声明它服务人工标注研究，普通 HTTP、CLI、输入摄取和学习流程不得调用，因此不能据此推断生产捕获已经接入质量样本生成。[评测导入器的生产隔离边界 ↗](../../../apps/server/src/quality/import.ts#L1 "说明数据集构建器仅用于人工标注研究，普通捕获、CLI、输入摄取和学习流程不得进入该路径。")

<a id="metric_behavior"></a>
## 拆分指标与被替代的旧结论

预测与人工标签完全一致时，精确匹配、处置一致、自动应用精度、引用定位、语义支持、事实槽、必要证据覆盖和任务完成均应达到预期，且不产生不必要打断。[全匹配预测的多维指标 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L96 "支持完整正确预测在各拆分指标上的计数和比率预期。") 更关键的回归用例替代了旧的“证据引文是原文子串即可算支持”结论：反向陈述即使引用可定位，也必须记为 `contradicted`，任务不能算完成。[可定位引文仍可能语义矛盾 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L201 "证明引用位置正确不等于语义支持，并记录反向结论会被判为矛盾且任务未完成。")

测试还覆盖忠实同义改写、遗漏限制条件、把历史规则宣称为当前有效、否定翻转以及数值上限变化。[同义、限定、时间、否定与数值用例 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L262 "支持测试对同义改写、范围扩大、时间错配、否定翻转和数值变化的具体预期。") 这些行为来自确定性规则基线而非模型裁判；当前规则聚焦否定、概念对立、限定词、时间和词汇重叠，能力边界应按有限模式理解。[确定性语义支持规则基线 ↗](../../../apps/server/src/quality/evaluator.ts#L33 "说明评估器不是模型裁判，并界定其语义判断依赖的有限显式规则。")

<a id="denominators_and_limits"></a>
## 空结果、分母语义与覆盖边界

预测弃权且不产出对象时，引用定位、语义支持和事实槽没有合格分母，相应比率必须为 `null`，不能因没有错误对象而得到满分；若人工标签期待对象，必要证据覆盖仍为零。[空预测的空分母与覆盖缺失 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L234 "支持零预测对象时若干指标返回 null、但必要证据覆盖仍记为零的差异。") 没有标注样本时，各类比率和延迟中位数也返回 `null`；本应自动提取却返回 `needs_context`，则计为不必要打断并判任务未完成。[零样本与不必要打断 ↗](../../../apps/server/tests/quality-evaluation.test.ts#L331 "支持无合格分母时比率和延迟为空，以及本可自动提取却请求上下文会被计为打断。")

本文件使用基于临时目录的隔离仓储、手工预测和规则化中文短句，没有执行真实模型、并发写入、复杂长文本、多语言或生产 API。标签合同虽约束处置值、对象类型，并要求 `extract` 至少含一个对象，[质量标签结构约束 ↗](../../../apps/server/src/quality/repository.ts#L39 "说明标签合同对处置、对象类型、字段长度及 extract 非空对象施加结构约束。") 但这些测试没有逐项覆盖所有非法结构和恢复路径，不能据此推断仓储校验已被穷尽。
