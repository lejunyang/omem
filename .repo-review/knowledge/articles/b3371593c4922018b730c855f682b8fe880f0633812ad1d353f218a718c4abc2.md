# 代码理解结果的投影、生成与持久化

该模块连接固定代码快照、人工理解 seed 与可选模型输出，负责定位器解析、严格校验、版本留存和读取；仅对进入持久化流程的生成失败留痕，模型未配置或尚无代码快照时直接返回而不写库。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-boundary"></a>
## 作用与数据边界

该模块把人工维护的路径、限定符号名和类型定位器解析到固定代码快照，封存角色、提示词、结构与输入摘要，再校验和持久化派生理解；它不会改写原始文件、符号或关系图，也不允许人工 seed 冒充模型执行或独立验证。[人工理解投影的职责与派生边界 ↗](../../../apps/server/src/code/understanding-store.ts#L1 "支持稳定定位器解析、来源封存、严格校验以及不改写原始代码图的说明。")

文件、符号和快照身份由代码图按稳定规则生成，理解结果则通过共享 `Store` 写入同一 SQLite，因此这是现有评审数据上的派生投影，而非独立知识库。[代码图的稳定身份规则 ↗](../../../apps/server/src/code/store.ts#L1 "支持文件、符号和快照采用确定性身份，并将旧图数据保留为历史的说明。") [共享 SQLite Store ↗](../../../apps/server/src/store.ts#L38 "支持代码理解投影复用应用的单用户 SQLite Store，而非建立独立存储。") 输出合同、角色资产检查与交叉引用校验由 agent-runtime 提供。[代码理解运行时合同 ↗](../../../packages/agent-runtime/src/code-understanding.ts#L1 "支持版本化输出合同、角色资产检查、固定输入快照和确定性交叉引用校验的职责划分。")

<a id="curated-flow"></a>
## 人工 seed 投影与读取语义

投影从指定快照组装文件、可建模符号及真实证据文本；不受合同支持的符号类型被排除，解析器又没有可靠的符号到符号调用边，所以快照使用空边集。证据文件、选择器或节点定位器无法解析时，结果保存为 `rejected`，不会静默丢弃引用。[固定快照与证据构建 ↗](../../../apps/server/src/code/understanding-store.ts#L143 "支持符号类型过滤、固定材料取证、缺失证据报错以及空调用边集等实现边界。")

校验通过后，主结果和规范化引用被写入，并尝试把查询选中的一个较早结果标为 stale。这里替代“数据库保证每模块恰有一个当前结果”的旧结论：该流程只处理一个 `prev`，默认读取面仍可能同时返回未过期的人工 seed 与模型结果。[seed 解析、校验与历史处理 ↗](../../../apps/server/src/code/understanding-store.ts#L281 "支持定位器失败保存为拒绝结果、成功结果写入引用镜像，以及仅将选中的一个前序结果 stale 化。") [当前理解的读取规则 ↗](../../../apps/server/src/code/understanding-store.ts#L521 "支持默认读取面可同时包含未过期的人工 seed 和模型生成结果，失败、拒绝及 stale 记录仅在历史查询中出现。")

<a id="model-flow-limits"></a>
## 模型生成、失败留痕与提交边界

模型生成要求显式注入运行端口并已有当前代码快照；这两个前置条件不满足时会直接返回 `unavailable` 或 `failed`，`understandingId` 为空且不写失败记录。进入已分配理解标识后的流程，预先取消、无目标符号、输入超限、传输异常等才会通过持久化函数留痕。[模型生成的前置条件与早期失败 ↗](../../../apps/server/src/code/understanding-store.ts#L674 "支持模型端口缺失和代码快照缺失直接返回且不持久化，并区分后续会留痕的失败路径。")

运行还受取消、超时、输出预算、JSON 合同、引用展示范围及 head 移动栅栏约束；坏结果不会成为当前理解。成功提交在事务内仅淘汰同目标的旧模型结果并写主记录，随后才在事务外更新引用镜像，因此旧稿关于“所有失败都会留痕”和“统一维持唯一当前结果”的表述均已被替代。[模型校验、提交与引用镜像 ↗](../../../apps/server/src/code/understanding-store.ts#L790 "支持取消及输出校验、head 移动栅栏、仅淘汰旧模型结果，以及引用镜像在主事务之后更新的说明。")
