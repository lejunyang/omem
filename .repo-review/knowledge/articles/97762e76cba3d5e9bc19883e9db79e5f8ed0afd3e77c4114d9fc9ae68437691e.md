# scripts · 模块理解

scripts 是 omem 的可执行编排与验证层：统一启动 personal/repo-review 开发服务，运行确定性浏览器验收和真实外部集成检查，组织质量评估，并将仓库材料接入共享知识管线。它组装既有能力、限定证明边界并记录派生产物，不是新的事实权威。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="responsibilities"></a>
## 职责分层与背景

scripts 主要分为开发编排、确定性验收和实时检查。personal 入口只设置模式并委托共享启动器；浏览器验收使用真实 Vue、API、SQLite 与 Chromium，但以协议 fixture 保持结果稳定。[个人开发入口 ↗](../../../scripts/dev.ts#L1 "支持 personal 入口只设置运行模式并委托共享开发编排器。")[个人助手浏览器验收装配 ↗](../../../scripts/browser-smoke.ts#L1 "支持验收使用真实 Vue、API、SQLite 与 Chromium，并以协议 fixture 保持确定性。") 知识阅读测试还构造临时仓库与固定文章链，验证可追溯阅读而不依赖模型。[固定知识阅读测试 ↗](../../../scripts/knowledge-browser.ts#L14 "支持临时仓库、固定知识文章与真实浏览器组成无模型的可追溯阅读测试。")

因此该模块是“可执行胶水层”：它连接服务器、存储、Agent 运行时、外部连接器和 UI。实时 ACP、学习或 Lark 脚本用于探测当前外部能力，不能替代确定性产品回归；报告、文章和 Wiki 也都是派生视图。

<a id="development_and_acceptance"></a>
## 开发启动与浏览器验收

开发编排先探测 API/Web 端口：显式端口占用会失败，默认端口占用则选择临时端口；探测监听释放后仍存在再次绑定的竞态。[开发端口选择 ↗](../../../scripts/dev-ports.ts#L3 "支持端口校验、占用处理、默认端口回退及探测后释放监听的流程。") 随后按模式启动 API 与专用 Vite，传递同一组最终端口并禁止端口相同。[开发服务启动链 ↗](../../../scripts/dev-review.ts#L81 "支持按模式选择 API 入口、启动专用 Vite、传递最终端口并禁止端口相同。") 子进程的 `exit` 或 `error` 会触发统一关闭；非 Windows 发送进程组 SIGTERM，等待有界但未展示超时后的 SIGKILL。[子进程失败传播 ↗](../../../scripts/dev-review.ts#L114 "支持 API 或 Web 子进程退出、报错时触发统一关闭并传播退出状态。")[有界进程树关闭 ↗](../../../scripts/dev-review.ts#L32 "支持跨平台关闭方式、重入保护和有限等待，并说明非 Windows 未展示强制升级。") API 另有最长约 60 秒的健康轮询，超时以失败关闭；这与子进程传播是两套相邻但独立的门禁。[API 健康门禁 ↗](../../../scripts/dev-review.ts#L131 "支持 API 最长约 60 秒的健康轮询、单次请求超时和未就绪时失败关闭。")

浏览器脚本直接评估提案并领取、完成作业，所以它证明真实应用链路，而非真实模型已执行。[提案与作业的确定性驱动 ↗](../../../scripts/browser-smoke.ts#L215 "显示提案通过内部接口评估、作业由脚本直接领取并完成，限定对真实模型执行的证明范围。") 独立知识测试验证五层引用、Esc 回退、深链、焦点归还、响应式、待办创建和源码不执行。[知识 Trail 浏览器断言 ↗](../../../scripts/knowledge-browser.ts#L46 "支持层级引用、Esc、深链、焦点归还、响应式、待办创建与 HTML 原文安全检查。") Code Wiki 还检查真实 Markdown 清洗与可见文本不泄露内部标识，但部分关系只选择首个可用边，不能扩大为完整图关系或无障碍合规。[Code Wiki 安全与交互边界 ↗](../../../scripts/code-wiki-viewport.ts#L112 "支持 Markdown 清洗、内部标识隐藏及 Trail 行为，同时显示部分关系只取首个可用边。")

<a id="live_and_quality"></a>
## 实时集成与质量闭环

实时模型选择会探测 ACP 候选，显式模型不可用时拒绝降级；但 effort 仅写入 profile，未在选择阶段验证。[实时模型选择 ↗](../../../scripts/live-model.ts#L4 "支持 ACP 模型候选探测、显式不可用失败，以及 effort 未在选择函数中校验。") 基础 ACP 冒烟的硬条件只是答案包含 `12`，实际模型、推理强度和事件类型仅作诊断。[ACP 算术冒烟判定 ↗](../../../scripts/live-acp-smoke.ts#L19 "支持答案包含 12 是硬断言，而事件类型与实际配置只进入诊断输出。") 更完整的流水线要求两个作业成功、一个提案已应用并形成一个任务，同时记录请求与实际配置、任务和通知数量。[实时学习流水线结果 ↗](../../../scripts/live-pipeline-smoke.ts#L46 "支持作业、已应用提案和任务数量的联合断言，以及请求和实际模型配置的报告记录。")

质量流程由 Lark 标注、隔离预测和门禁评估组成：标注脚本收到首个新增事件即可成功，并不代表全数据集完成。[Lark 标注成功边界 ↗](../../../scripts/quality-lark-annotate.ts#L52 "支持标注命令在收到首个新增事件后成功退出，而非等待整个数据集完成。") 预测阶段逐样本使用独立 Store 并原子更新文件，但异常统一编码为 `needs_context`，可能混淆系统失败与业务背景不足。[隔离质量预测运行 ↗](../../../scripts/quality-run.ts#L63 "支持逐样本隔离 Store、原子持久化预测，并显示异常统一记为 needs_context。") 评估阶段以精确率、语义支持、引用位置、证据覆盖和完整性等阈值决定非零退出。[质量评估门禁 ↗](../../../scripts/quality-evaluate.ts#L14 "支持冻结数据验证、各质量阈值以及任一门禁失败时设置非零退出码。")

<a id="knowledge_publication"></a>
## 仓库知识生成、发布与限制

仓库知识入口复用共享 KnowledgePipeline：同步材料与代码、恢复文章、分析目标，并仅在无失败且非 files-only 时综合模块、主题和总览；imports 上下文最多补四份材料且每份前 70 行，不能据此断言跨文件调用。[共享知识分析与综合 ↗](../../../scripts/review-knowledge.ts#L39 "支持材料和代码同步、有限 imports 上下文扩充，以及仅在无失败且非 files-only 时分层综合。")

Wiki 入口只有在**非生成模式且已有共享知识**时重建共享知识索引并结束；生成模式或没有共享知识时进入结构化 Wiki 构建分支。显式生成还必须限定 target，并先发布理解资产。此前“默认总从共享知识重建索引”的结论已被此条件化描述替代。[Wiki 条件分支与显式生成 ↗](../../../scripts/review-wiki.ts#L14 "支持只有非生成且已有共享知识时重建索引，否则进入生成或结构化 Wiki 分支。") 人工 seed 会按当前快照重解析 locator、绑定固定原文并严格校验；失败结果保留为 rejected，不遮蔽有效结果，也不得冒充模型或独立复核。[人工理解 seed 投影 ↗](../../../apps/server/src/code/understanding-store.ts#L1 "支持 locator 重解析、固定证据、严格校验、失败结果不遮蔽有效结果及不得伪装模型复核。") 模型生成另受预算、引用范围、超时和 head 移动栅栏约束，失败结果不会晋升为 current。[模型理解生成防线 ↗](../../../apps/server/src/code/understanding-store.ts#L758 "支持预算检查、超时、引用范围校验、运行中 head 变化防线以及失败结果不晋升为 current。")
