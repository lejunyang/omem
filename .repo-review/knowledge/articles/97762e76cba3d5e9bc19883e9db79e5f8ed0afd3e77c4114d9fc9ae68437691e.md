# 开发、分层验收与仓库知识维护

这组工具把本地开发启动、确定性浏览器验收、真实外部链路检查、离线质量评测和仓库知识重建串成分层工作流。各层分别回答应用能否启动、用户闭环是否可操作、外部集成能否运行、模型结果是否达到质量门槛，以及代码变化后知识资产如何更新。现有材料证明这些入口与边界已经建立，但不代表某次检查已经通过；知识文章、索引与 Wiki 的发布也尚无统一事务保证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

## 从统一启动到可重复的界面验收

个人应用与仓库评审环境共用启动编排：先选择并预检 API、Web 端口，再启动后端和 Vite 代理，通过健康检查确认可访问；任一子进程异常都会带动整体关闭。开发者因此可以从统一入口使用完整应用。参考 [开发启动与进程编排 ↗](c80ddf4d487be75fb725d4a2b25eaada83c3dd0ee7583263278e19e9b52b7fb2.md#development_startup "说明个人应用与评审环境如何选择端口、启动双进程、轮询健康状态并传播故障，同时指出端口绑定竞态。")

浏览器验收在临时目录中启动真实 Vue、API、SQLite 和 Chromium，外部 Agent 与飞书能力使用确定性夹具，使材料捕获、提案应用、证据阅读、通知、故障展示和重启恢复等用户闭环能够稳定复现。源码也明确界定为真实应用边界下的测试，仅以夹具稳定 Agent 输出。参考 [完整用户闭环的浏览器验收 ↗](c80ddf4d487be75fb725d4a2b25eaada83c3dd0ee7583263278e19e9b52b7fb2.md#deterministic_browser "支持真实 Vue、API、SQLite 边界与确定性外部夹具的组合，以及从材料捕获到证据阅读、故障恢复的验收范围。") [浏览器验收运行边界 ↗](../../../scripts/browser-smoke.ts#L1 "原始源码直接说明脚本使用真实 Vue、API、SQLite，并仅以夹具稳定 Agent 输出。")

这类检查验证应用编排与交互合同，不代表真实模型、网络或飞书服务可用；端口预检释放临时监听后到服务实际绑定前，也仍存在被并发进程抢占的窗口。

<a id="layered_validation"></a>
## 用隔离检查和在线冒烟覆盖不同风险

仓库知识阅读有两类互补验收：一类连接当前应用与真实知识资产，检查固定代码引用、阅读轨迹、深链、焦点恢复和多视口可读性；另一类即时构造小型仓库与固定文章，深入检查多层引用、源码跳转、待办创建及不可信 HTML 的安全展示。参考 [知识阅读的两类浏览器检查 ↗](c80ddf4d487be75fb725d4a2b25eaada83c3dd0ee7583263278e19e9b52b7fb2.md#knowledge_reading "说明连接真实仓库知识的验收与隔离夹具验收如何覆盖引用、轨迹、深链、源码跳转和安全渲染。")

真实链路检查通过 ACP 探测模型能力，覆盖最小中文问答、抽取与复核角色串联、学习流水线，以及 Lark 文档和宿主连接。运行轨迹保留实际模型、推理强度、输入指纹与修复次数，便于追查协议错误、模型波动和外部环境失败。参考 [外部 Agent 与 Lark 在线检查 ↗](c80ddf4d487be75fb725d4a2b25eaada83c3dd0ee7583263278e19e9b52b7fb2.md#live_validation "支持 ACP 模型探测、真实学习闭环和 Lark 连接器检查的用途，并限定其不能证明外部服务长期稳定。") [真实模型角色与学习流水线 ↗](7343906ff4606be19d720148b9045c013f97b2e00ef36ff5359dc5137dd1bdfe.md#live-validation "说明抽取与复核角色串联、学习流水线在线冒烟、运行轨迹及现有行为断言的范围。")

<a id="quality_gate"></a>
## 把“能够运行”推进到“质量可评估”

质量评测把人工标注、在线预测和离线判定分开。评测专用的飞书材料切分不得进入普通捕获或知识生产；冻结样本逐个在隔离存储中重新捕获并运行学习流水线，已有预测可以续跑，单样本异常会降级为需要背景而不会中断整批任务。参考 [冻结样本与离线质量门禁 ↗](7343906ff4606be19d720148b9045c013f97b2e00ef36ff5359dc5137dd1bdfe.md#quality-loop "支持评测数据隔离、预测续跑、单样本失败降级、质量指标和确定性语义支持规则。")

离线评估检查自动应用精确率、语义支持、引用位置、证据覆盖与完整性，并以非零退出码表达门禁失败。语义支持采用确定性规则识别否定翻转、限制丢失和时间错配，比单纯检查引文是否出现在原文中更接近事实支持，但仍不是开放域语义裁判。参考 [冻结样本与离线质量门禁 ↗](7343906ff4606be19d720148b9045c013f97b2e00ef36ff5359dc5137dd1bdfe.md#quality-loop "支持评测数据隔离、预测续跑、单样本失败降级、质量指标和确定性语义支持规则。")

当前在线学习冒烟主要断言作业、提案和任务的数量与状态，尚未稳定核对负责人、截止时间、任务语义和原始证据引用；飞书标注的成功信号也可能受到其他并发事件影响。参考 [真实模型角色与学习流水线 ↗](7343906ff4606be19d720148b9045c013f97b2e00ef36ff5359dc5137dd1bdfe.md#live-validation "说明抽取与复核角色串联、学习流水线在线冒烟、运行轨迹及现有行为断言的范围。") [冻结样本与离线质量门禁 ↗](7343906ff4606be19d720148b9045c013f97b2e00ef36ff5359dc5137dd1bdfe.md#quality-loop "支持评测数据隔离、预测续跑、单样本失败降级、质量指标和确定性语义支持规则。")

## 代码变化后的知识重建与发布边界

仓库知识维护先同步原始材料和代码投影，再对选定目标执行分析与模块合成。代码投影建立在已捕获 Fragment 上，相同输入可复用快照；变更后未重现的符号和关系会转为旧状态。覆盖记录区分已复核、过期、待处理与失败，只有当前知识才进入最终页面索引。参考 [按变更重建仓库知识 ↗](7343906ff4606be19d720148b9045c013f97b2e00ef36ff5359dc5137dd1bdfe.md#knowledge-maintenance "说明材料同步、代码投影、分层合成、覆盖状态和当前页面索引之间的维护流程与身份边界。")

Wiki 输出复用同一知识结果：显式生成要求限定目标，已有知识可只重建索引；可读输出使用符号名和源码链接，不向读者暴露内部标识。Markdown 先写入运行时暂存区，内容变化后再复制到最终位置。参考 [Wiki 输出与发布边界 ↗](7343906ff4606be19d720148b9045c013f97b2e00ef36ff5359dc5137dd1bdfe.md#wiki-boundaries "支持显式生成目标、可读 Wiki 组织、暂存后复制的发布方式，以及缺少统一发布事务的限制。")

功能检查、质量门禁、知识重建和知识发布各有独立职责。现有材料没有显示文章、索引与 Wiki 之间存在统一事务或回滚，也没有覆盖通用软件包发布流程；中途失败是否会留下部分更新，以及现有覆盖状态或验证报告能否完整识别这种状态，仍需通过故障注入确认。参考 [按变更重建仓库知识 ↗](7343906ff4606be19d720148b9045c013f97b2e00ef36ff5359dc5137dd1bdfe.md#knowledge-maintenance "说明材料同步、代码投影、分层合成、覆盖状态和当前页面索引之间的维护流程与身份边界。") [Wiki 输出与发布边界 ↗](7343906ff4606be19d720148b9045c013f97b2e00ef36ff5359dc5137dd1bdfe.md#wiki-boundaries "支持显式生成目标、可读 Wiki 组织、暂存后复制的发布方式，以及缺少统一发布事务的限制。")
