# 角色任务处理器：连接持久任务与 Agent 运行时

该文件提供一个适配器：为任务 worker 构造角色处理函数，按任务生成上下文、调用角色运行网关，并将结构化结果、追踪信息及用量保存为可引用的角色输出。它负责流程衔接与审计字段传递，不负责租约获取、重试、模型执行细节或结果语义校验。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-contract"></a>
## 解决的问题与接口边界

`createRoleJobHandler` 把角色配置、上下文构造器、运行网关和任务仓库封装成统一的 `JobHandler`，使持久任务 worker 能以 `(job, signal)` 的标准形式执行角色任务。角色标识、版本、模型配置和可选托管工具在创建处理器时注入，而每次执行所需的上下文按 `job.id` 动态获取。[角色任务处理器构造与依赖注入 ↗](../../../apps/server/src/agent-runtime/job-handler.ts#L9 "支持处理器如何注入角色配置、上下文构造器、网关、仓库和托管工具，以及返回标准任务处理函数的说明。")

这一层是任务系统与 Agent 运行时之间的适配器；worker 侧合同允许处理结果返回 `resultRef` 与 `usage`，并通过 `AbortSignal` 传递取消信号。[任务处理函数合同 ↗](../../../apps/server/src/jobs/worker.ts#L18 "说明 worker 期望的处理器参数、取消信号以及结果引用和用量返回结构。")

<a id="execution-flow"></a>
## 核心执行流程与可追溯输出

处理器先等待上下文生成，再把角色、配置、上下文、取消信号及工具白名单交给 `RoleRuntimeGateway.run`。运行完成后，它取追踪记录中的最后一个会话 ID；若不存在则立即抛出 `ROLE_SESSION_ID_MISSING`，避免保存无法关联会话的结果。[上下文生成、网关调用与会话校验 ↗](../../../apps/server/src/agent-runtime/job-handler.ts#L18 "支持执行顺序、取消信号传递以及缺少会话 ID 时立即失败的边界条件。")

成功路径调用任务仓库保存角色输出，并携带当前任务的租约令牌、实际模型与推理强度、提示词/技能/工具/上下文指纹、输出 schema、技能和工具清单、用量、结果及完整 trace；随后仅向 worker 返回保存记录 ID 和用量。[角色输出保存与任务结果返回 ↗](../../../apps/server/src/agent-runtime/job-handler.ts#L30 "支持保存租约、运行身份、审计追踪、结构化结果，并返回持久记录引用的完整成功路径。") 网关的追踪类型也明确覆盖这些审计字段，说明处理器主要承担完整转存，而非重新计算运行身份。[角色运行追踪字段 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L43 "说明网关 trace 中确实定义了处理器转存的模型、哈希、schema、会话、工具与用量字段。")

<a id="boundaries-and-relations"></a>
## 边界条件与模块关系

该处理器依赖 worker 提供已经取得租约的任务，并原样使用 `job.id` 与 `job.leaseToken`；任务领取、无处理器时的配置失败、心跳和重试属于 `DurableJobWorker`，不在本文件中实现。[持久任务领取与处理器分派 ↗](../../../apps/server/src/jobs/worker.ts#L47 "支持租约由 worker 领取、按任务 kind 查找处理器，以及缺少处理器时由 worker 标记配置失败的模块边界。") 仓库公开的角色输出记录包含任务、尝试次数、输出 schema、摘要、正文和 trace，表明保存结果会成为后续任务状态引用的独立持久记录。[角色输出持久记录结构 ↗](../../../apps/server/src/jobs/repository.ts#L63 "说明仓库层角色输出记录具有任务关联、输出摘要、正文和追踪字段，为结果引用关系提供依据。")

当前材料未展示 `saveRoleOutput` 的实现，也没有测试文件，因此无法确认租约失效时的具体异常、保存与任务完成是否处于同一事务，以及网关成功但持久化失败后的重试去重行为。处理器自身也未捕获上下文、网关或仓库异常，这些错误会沿 `JobHandler` Promise 向 worker 传播。[处理器异常传播边界 ↗](../../../apps/server/src/agent-runtime/job-handler.ts#L18 "目标函数仅顺序等待上下文、网关和保存操作，未出现本地 try/catch，可支持异常向上游传播的判断。")
