# 仓库评审迁移与关系失效测试

该测试验证 repo-review 从内容哈希来源身份迁移到稳定路径身份时的冲突处理、历史数据保留与幂等性，并覆盖代码来源换版后旧关系转为 stale、默认查询隐藏历史关系的生命周期。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="migration-purpose"></a>
## 迁移目标与历史保留

旧数据以内容哈希标识文件来源；测试直接写入 source、revision、fragment 三层记录，构造迁移前数据库 [旧式来源构造辅助函数 ↗](../../../apps/server/tests/review-migration.test.ts#L40 "支持测试直接写入旧版来源、修订和片段记录以模拟迁移前状态。")。同一路径发生碰撞时，较新的来源取得 `omem:<路径>` 身份并保留当前 head，较旧来源解除 head、记录为该路径的历史别名 [同路径碰撞处理断言 ↗](../../../apps/server/tests/review-migration.test.ts#L131 "支持较新来源取得路径身份、旧来源解除 head 并成为历史别名，以及唯一当前来源和片段保留等断言。")；旧来源仍能通过原 external id 找到，其非当前修订、片段和历史记录继续可读 [历史来源仍可读取 ↗](../../../apps/server/tests/review-migration.test.ts#L189 "支持被降级来源仍可由旧 external id 定位，且其非当前修订、片段和历史记录保持可读。")。这符合稳定路径身份的设计：同一文件修改时累积修订，而内容相同但路径不同的文件仍是独立来源 [稳定路径来源身份 ↗](../../../apps/server/src/review/store.ts#L29 "说明稳定路径身份使同一文件累积修订，并使相同内容的不同路径保持独立。")。

<a id="asserted-behavior"></a>
## 迁移断言与已知边界

碰撞用例还验证同一路径最终只有一个当前来源，且迁移前后片段总数不变 [同路径碰撞处理断言 ↗](../../../apps/server/tests/review-migration.test.ts#L131 "支持较新来源取得路径身份、旧来源解除 head 并成为历史别名，以及唯一当前来源和片段保留等断言。")；独立用例进一步证明相同正文位于不同路径时不会被错误合并 [同内容不同路径保持独立 ↗](../../../apps/server/tests/review-migration.test.ts#L158 "支持相同正文位于不同文件路径时仍保留两个独立当前来源。")。再次执行迁移返回零，并且测试所检查的来源 external id、head 与历史别名状态保持不变 [迁移重复执行检查 ↗](../../../apps/server/tests/review-migration.test.ts#L239 "支持第二次迁移返回零，且查询覆盖的 external id、head 与历史别名字段保持不变。")。因此这里确认的是这些选定字段上的幂等性，并非整个数据库快照不变。材料也未给出迁移函数的完整排序实现，现有用例只能证明版本号和创建时间均较新的记录在该场景中胜出。

<a id="relation-lifecycle"></a>
## 关系失效与查询可见性

关系测试通过共享 `Store.capture` 写入同一路径的两版代码，再为旧版代码片段建立指向当前决策片段的 `implements` 关系 [关系生命周期测试准备 ↗](../../../apps/server/tests/review-migration.test.ts#L291 "支持测试通过共享捕获流程创建两版代码来源，并为旧代码片段写入 confirmed 关系。")。按代码路径执行失效后，关系由 confirmed 变为 stale：默认片段查询隐藏它，启用 `includeStale` 才返回；路径查询还需同时启用历史与 stale 选项 [旧关系失效与查询过滤 ↗](../../../apps/server/tests/review-migration.test.ts#L343 "支持关系失效数量、stale 状态，以及默认、历史和 includeStale 查询模式的行为。")。这体现了 repo-review 对通用 Store、捕获和检索能力的复用，同时将路径迁移及评审元数据保存在隔离的评审数据库中 [共享存储与评审隔离 ↗](../../../apps/server/src/review/store.ts#L1 "说明 repo-review 复用通用 Store、捕获和检索能力，同时在隔离数据目录中维护评审专属元数据。")。当前用例尚未覆盖目标片段换版、源目标同时换版、缺失关系、并发迁移或异常回滚。
