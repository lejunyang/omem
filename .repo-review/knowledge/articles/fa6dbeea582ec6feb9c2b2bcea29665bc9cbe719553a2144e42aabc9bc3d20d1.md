# OmRelationGraph：确定性模块依赖图

该组件把模块及聚合导入关系绘制为稳定的分层 SVG，并暴露节点、边选择事件。其布局可复现，但循环依赖、missing 边呈现和边标签键盘行为存在明确限制，当前材料未包含组件测试。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="model-layout"></a>
## 数据合同与布局流程

组件解决模块架构关系的可视化问题：节点保存展示名称及文件、符号计数，边记录导入方、被导入方、聚合数量、证据和确认状态，并分别向容器发出节点或边选择事件。[关系图数据与事件合同 ↗](../../../packages/ui/src/components/OmRelationGraph.vue#L14 "支持节点、边字段含义以及组件对外节点选择和边选择事件的说明。")

布局先建立“模块 → 仓内依赖模块”的邻接表；missing 边以及任一端点不在模块集合中的边不会参与分层。模块按标识固定排序后，以“无依赖为第 0 层、其余为依赖最大层加一”的规则迭代，随后按层和层内行号生成固定坐标及画布尺寸，因而相同输入不会产生力导向式漂移。[确定性分层与坐标计算 ↗](../../../packages/ui/src/components/OmRelationGraph.vue#L48 "支持 missing 边过滤、固定排序、十二轮迭代、分桶定位及所有模块获得坐标的流程与限制。") 迭代最多 12 轮，所以循环依赖或很深的链只能得到有界计算结果，不能视为严格的最长路径层级。

<a id="render-interaction"></a>
## 绘制、交互与边界

边在两个已有节点之间绘制为贝塞尔曲线；candidate 与 stale 使用不同虚线，其他状态落入 confirmed 样式。通用路径在找不到任一端点时返回空字符串，中点则回退到原点。[边路径、状态样式与键盘处理 ↗](../../../packages/ui/src/components/OmRelationGraph.vue#L107 "支持贝塞尔路径、中点回退、missing 状态落入 confirmed 默认样式，以及节点键盘处理器行为的判断。") 模板仍遍历全部边并绘制数量标签：鼠标点击标签发出边选择；节点支持鼠标及 Enter/空格选择，并以加粗描边表示当前项。[SVG 边与节点事件绑定 ↗](../../../packages/ui/src/components/OmRelationGraph.vue#L141 "支持数量标签渲染、边标签鼠标和键盘事件差异、节点选择及选中状态绑定的说明。")

missing 边需要区分两种情况：它虽不参与依赖分层，但所有已声明模块仍会获得坐标，因此两端都存在时仍会画出普通曲线，并因样式默认分支显示为 confirmed；只有端点未声明时路径才为空、标签落在原点。当前实现没有文件注释所称的外部“断裂短线”。此外，边标签的键盘事件复用了节点处理器，Enter/空格会把边标识作为节点标识发出，与鼠标选择边不一致。提供的材料中没有测试文件，无法证明循环、missing 边或键盘等价行为已被断言。
