# 仓库文件到知识材料的输入适配器

枚举候选仓库文件，执行路径、大小和格式检查后增量捕获文本或图像，并为分析阶段提供受限的本地链接上下文。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="discovery-coverage"></a>
## 候选发现与覆盖记录边界

适配器优先通过 Git 获得已跟踪及未忽略的新文件；Git 枚举失败时才递归遍历目录，并在遍历阶段直接跳过 `.git`、`.repo-review`、`node_modules` 和 `dist`。[Git 枚举与回退遍历 ↗](../../../apps/server/src/review/materials.ts#L15 "支持两种候选发现方式，并明确回退遍历会直接跳过若干目录。") 只有已经进入候选路径列表的匹配项，才会因运行目录、依赖、构建结果、私有环境文件或本地配置而产生 `excluded` 记录；普通文件、符号链接、真实路径和 5 MB 预算也在逐项处理时检查。此前“所有此类路径都会明确记录、不会悄然消失”的结论应由这一更窄的覆盖边界替代。[候选路径检查与覆盖状态 ↗](../../../apps/server/src/review/materials.ts#L26 "支持只有进入候选列表的路径才会执行排除、安全和大小检查并生成覆盖记录。")

<a id="capture-format"></a>
## 增量捕获与材料身份

文件先按原始字节计算 SHA-256，仅当摘要或捕获格式变化时重新捕获。PNG、JPEG、WebP 保存为图像部分；其他文件必须能严格解码为 UTF-8、不得含空字节且不能是空文本，长文本按 180000 个 JavaScript 字符切片。路径生成稳定的 `omem:` 外部标识，捕获后无论是否发生 revision 变化都会返回当前摘要和材料键。[文本与图像捕获 ↗](../../../apps/server/src/review/materials.ts#L36 "支持摘要比较、媒体类型识别、严格文本解码、固定长度切分及稳定材料标识。") 评审知识仓库复用通用仓库，只过滤元数据中已移除或已成为旧别名的来源。[评审知识仓库过滤器 ↗](../../../apps/server/src/review/materials.ts#L60 "说明适配器复用通用知识仓库，并排除已移除来源和旧别名。")

<a id="linked-context"></a>
## 本地链接上下文及启发规则

上下文选择器解析 Markdown 本地链接，跳过外部协议、自引用、缺失材料和重复项；带标题锚点时尝试定位对应标题，每份最多提供 80 行，总数最多四份。HTML 目标还会无条件追加三个约定资源名作为候选。该函数只扩大模型可见上下文，不建立确认关系，最终含义仍需分析与复核。[本地链接上下文选择 ↗](../../../apps/server/src/review/materials.ts#L68 "支持链接解析、锚点定位、HTML 启发候选、行数范围和最多四份材料的限制。")
