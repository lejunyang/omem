# 仓库文件到知识材料的输入适配器

枚举仓库候选文件并执行路径、大小和格式检查，将变化后的文本或图像捕获为固定材料，同时提供可见性过滤与有限的链接上下文发现。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="capture-files"></a>
## 文件发现、过滤与覆盖记录

适配器优先通过 Git 枚举已跟踪文件及未忽略的新文件；命令失败时改用目录遍历，并直接跳过 Git、评审运行数据、依赖和构建目录，这些被跳过目录不会形成覆盖记录。[Git 枚举与目录遍历回退 ↗](../../../apps/server/src/review/materials.ts#L15 "支持 Git 优先枚举，以及回退遍历直接跳过若干目录而不生成覆盖项。") 只有进入候选路径列表的匹配项才会记录为 `excluded`；其余候选还需满足普通文件、非符号链接、真实路径不越界及 5 MB 输入预算，异常则记为 `failed`。[候选路径检查与结果状态 ↗](../../../apps/server/src/review/materials.ts#L26 "支持仅对进入候选列表的路径记录排除，以及普通文件、越界和大小检查。")

<a id="material-format"></a>
## 内容格式与身份稳定性

文件字节先计算 SHA-256，仅在摘要或捕获格式变化时重新捕获。PNG、JPEG、WebP 转为图像部分；其他内容必须是有效 UTF-8、不能含空字节，空文件会排除，长文本按 180000 个 JavaScript 字符切分。路径映射为稳定的 `omem:` 外部标识，覆盖结果保留材料键和摘要。[文本与图像捕获 ↗](../../../apps/server/src/review/materials.ts#L36 "支持摘要比对、媒体识别、UTF-8 校验、定长文本切片与稳定文件身份。") 评审知识仓库复用通用仓库，但过滤已移除或旧别名来源。[评审知识仓库过滤器 ↗](../../../apps/server/src/review/materials.ts#L60 "支持复用通用知识仓库并排除已移除和旧别名来源。")

<a id="linked-context"></a>
## 链接上下文及限制

链接上下文函数从 Markdown 本地链接寻找材料，跳过外部地址、自引用和重复项；锚点可把范围移到相应标题，每份最多提供 80 行，整体最多四份。[本地链接上下文选择 ↗](../../../apps/server/src/review/materials.ts#L68 "支持 Markdown 链接、HTML 固定候选、锚点范围和最多四份上下文的规则及限制。") HTML 文件还固定追加三个相邻资源名作为候选，这只是分析上下文启发式，不解析 HTML 的真实依赖，也不会建立已确认关系。
