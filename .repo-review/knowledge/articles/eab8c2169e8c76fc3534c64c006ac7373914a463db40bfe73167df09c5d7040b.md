# 仓库材料捕获与知识适配

把 Git 工作区文件转换为统一、固定摘要的知识材料，隔离派生数据和私密配置，并为分析提供有限的显式链接上下文。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="discovery"></a>
## 文件发现与排除

捕获优先通过 `git ls-files` 合并已跟踪和未忽略的未跟踪文件；Git 命令失败时退化为目录遍历，并跳过 `.git`、`.repo-review`、依赖和构建目录。[仓库路径发现 ↗](../../../apps/server/src/review/materials.ts#L15 "支持 Git 枚举优先、失败后目录遍历以及基础目录排除规则。") 对每条路径还会排除派生知识、私密环境文件和本地配置；非普通文件、符号链接及解析后越出仓库根目录的目标同样不会捕获。[安全与隐私排除 ↗](../../../apps/server/src/review/materials.ts#L27 "支持运行数据、环境配置、符号链接和越界路径不会作为证据捕获。")

<a id="capture"></a>
## 增量捕获流程

普通文件上限为 5 MB，内容先计算 SHA-256；只有摘要或捕获格式变化时才重新写入。PNG、JPEG、WebP 转为 base64 图片 part，其他文件必须能严格按 UTF-8 解码且不能含 NUL，空文本被排除，长文本按 18 万字符分片。[内容分类和增量捕获 ↗](../../../apps/server/src/review/materials.ts#L35 "支持大小预算、摘要比较、图像处理、严格文本解码和分片规则。") 成功结果记录 material key 和摘要，单文件异常则转成 `failed` 覆盖项而不会终止其余路径。

<a id="repository-links"></a>
## 知识仓库与链接上下文

评审知识仓库复用通用 `KnowledgeRepository` 和 `currentMaterials`，但过滤被标记删除或作为旧别名的 source，使 repo-review 只改变输入选择而不另建分析 authority。[评审知识仓库过滤器 ↗](../../../apps/server/src/review/materials.ts#L60 "直接显示适配器复用通用仓库，并排除删除项和旧别名。") `linkedMaterialOffers` 从 Markdown 本地链接定位最多四个额外材料；锚点可把窗口移到对应标题，单项最多提供 80 行。HTML 还会启发式加入三个同目录资源。这些只作为候选上下文，注释明确不能据此确认材料关系。[显式链接上下文选择 ↗](../../../apps/server/src/review/materials.ts#L68 "支持链接解析、锚点窗口、HTML 启发式、去重与最多四项限制。")
