# osdk 命令用法参考

按功能整理 osdk 0.0.3 的一级命令、参数、常见组合、安全边界与部分退出码，并强调具体版本仍以命令帮助为准。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="scope-and-resolution"></a>
## 命令范围与工具解析

材料声称覆盖 `osdk 0.0.3` 的全部一级命令，并以 CLI 命令枚举为对齐对象，但明确指出 `osdk <command> --help` 才是当前命令的权威帮助。[命令参考范围与版本 ↗](../../../.agents/skills/osdk-guide/reference/commands.md#L1 "支持参考覆盖范围、对齐来源、实测版本以及命令帮助权威性的说明。") 全局参数必须放在子命令之前，可控制并发、静默、源、离线、checksum、attestation、预发布策略和语言。工具请求既支持内置 backend，也支持 `npm:`、`cargo:`、`go:`、`conda:`、`pypi:`、`github:`、`http:` 等动态命名空间及不同版本选择器。[全局参数与工具命名空间 ↗](../../../.agents/skills/osdk-guide/reference/commands.md#L7 "支持全局控制项、内置和动态 backend 及版本选择方式的概述。")

<a id="reproduction-tasks-deps"></a>
## 复现、任务与应用依赖

项目复现由工具声明、精确锁定和按锁安装组成；`lock` 只记录项目声明的工具，全局选择不会自动进入锁文件。[项目锁定与复现流程 ↗](../../../.agents/skills/osdk-guide/reference/commands.md#L71 "支持项目工具锁定、安装、升级及全局版本不自动入锁的限制。") 项目任务统一通过 `run` 执行，可查询任务列表、定义与依赖顺序；不存在裸 `osdk <task>`。[任务执行命令 ↗](../../../.agents/skills/osdk-guide/reference/commands.md#L88 "支持 run、task 查询命令及不存在裸任务调用形式的说明。")

`deps` 从项目原生清单安装完整应用依赖，支持列举、dry-run、路径过滤、严格 lockfile 和环境深度校验。`--frozen` 要求原生锁存在且不被修改；provider 的寻址范围和 `requirements.txt` 的锁定能力存在明确限制。[应用依赖参数与边界 ↗](../../../.agents/skills/osdk-guide/reference/commands.md#L109 "支持 deps 的职责、严格锁定、过滤、校验和 provider 寻址限制。")

<a id="security-and-external-state"></a>
## 信任、模型、容器与宿主状态

源管理、Registry 预检和项目信任各有独立命令；仅声明工具通常不要求信任，但改变来源或执行行为会进入信任边界。[源、Registry 与信任命令 ↗](../../../.agents/skills/osdk-guide/reference/commands.md#L168 "支持下载来源、依赖 Registry 和项目配置的信任边界。") 模型命令负责不可变快照的拉取、同步、校验与消费者视图；Agent skills 则由 osdk 下载、内容寻址和链接，osdk 本身不执行 skill 脚本。[模型与 Agent skills 生命周期 ↗](../../../.agents/skills/osdk-guide/reference/commands.md#L191 "支持模型快照管理以及 skill 只被搬运链接、不由 osdk 执行的论断。")

容器操作依赖宿主原生运行时，镜像配置应用与清理均带计划或预览确认机制；宿主包命令中只有 `pkg apply` 安装缺失包。[容器和宿主包操作边界 ↗](../../../.agents/skills/osdk-guide/reference/commands.md#L247 "支持宿主原生运行时、计划确认机制及唯一系统包写操作的说明。") 这些是命令语义，不代表当前机器已安装运行时、模型或系统包。

<a id="maintenance-and-exit-codes"></a>
## 维护、诊断与退出码

缓存清理和 store 回收是不同范围：前者处理归档及包缓存，后者回收未引用对象；部分操作提供 dry-run。配置查询与写入、自升级、完整文件校验均有专用命令。[缓存、自身管理与诊断 ↗](../../../.agents/skills/osdk-guide/reference/commands.md#L285 "支持缓存回收范围、配置命令、自升级和安装文件校验能力。") 文档记录一般成功为 0、失败非零、参数错误为 2，并列出系统包计划和容器子进程的特殊退出码。命令适合即时动作或查询，持久声明则应写入配置文件。[退出码及配置对应关系 ↗](../../../.agents/skills/osdk-guide/reference/commands.md#L327 "支持自动化退出码判断和即时命令与持久配置的职责区分。") 自动化应依据真实退出码和输出判断，而不能把文档示例当作执行证据。
