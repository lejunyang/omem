# 个人工作记忆的 Web 应用总入口

App.vue 是个人工作记忆前端的页面编排与状态协调中心：识别服务运行模式，加载材料、任务、通知等全局数据，组织搜索、采集、阅读和行动流程，并把证据阅读、问答、判断等专门能力交给子组件。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-navigation"></a>
## 统一工作入口与两种运行模式

该组件解决的是“从同一入口完成记忆采集、阅读、检索和行动”的问题。它用稳定导航连接知识库、原始材料、材料处理、待判断、待办、通知和设置，并通过 URL hash 与会话存储保持当前页面。参考 [工作区导航与页面状态 ↗](../../../apps/web/src/App.vue#L40 "支持该组件统一组织主要工作页面，并同步 URL 与会话状态的说明。")

启动时先探测知识评审服务：确认返回 `review` 模式便停止加载个人业务数据；只有评审路由明确返回 404，才继续访问个人服务健康接口。其他状态会显示连接原因并每两秒重试，避免代理尚未就绪时误启动个人数据轮询。参考 [启动模式探测 ↗](../../../apps/web/src/App.vue#L194 "支持评审模式优先探测、个人服务识别条件及失败重试流程。")

<a id="data-and-search"></a>
## 集中刷新与防竞态搜索

个人模式下，组件并行读取材料、通知、任务、变更、处理作业、提案和判断事项；若用户正在阅读旧版本，还会根据最新材料列表重新标记它是否为当前版本。刷新有互斥标记，后台失败写入独立轮询错误，不会把定时刷新重叠执行。参考 [全局数据刷新 ↗](../../../apps/web/src/App.vue#L140 "支持并行加载业务集合、修订状态校正和刷新互斥处理。")

搜索采用 250 毫秒防抖，并在输入变化时中止上一请求、递增版本号；只有版本仍匹配的响应才能更新结果，因此较慢的旧请求不会覆盖新查询。组件卸载时也会清理轮询、重试、提示与搜索计时器。参考 [搜索竞态控制 ↗](../../../apps/web/src/App.vue#L97 "支持搜索防抖、中止旧请求、版本校验及卸载清理的说明。")

<a id="capture-and-reading"></a>
## 从多源采集到可追溯阅读

采集流程按模式分流到飞书、服务器文件、Git 文件或通用多模态接口。手工输入可组合文本、链接和单张图片，并附带采集者、来源 URI、事件时间、时区及是否转发等来源信息；保存后刷新全局状态、打开返回的修订版本，并提示是复用重复版本还是生成了新证据。参考 [多源材料采集 ↗](../../../apps/web/src/App.vue#L290 "支持不同采集入口、来源元数据构造以及保存后的刷新和打开流程。")

阅读区展示材料目录、当前或历史版本、代码或 Markdown 正文、固定片段和版本历史。用户可把某个片段设为问答焦点，也可通过引用组件打开证据；右侧 `ChatPane` 接收同一焦点及模型配置，证据弹窗保存后则触发全局刷新。参考 [材料阅读与聚焦问答 ↗](../../../apps/web/src/App.vue#L576 "支持版本正文、固定片段、历史入口以及阅读区问答焦点的界面关系。")

<a id="boundaries-and-components"></a>
## 输入边界与子模块协作

前端先限制图片为 PNG、JPEG 或 WebP 且不超过 5 MB；材料目录最多直接展示 80 项，小屏下改为上下布局。服务器文件和 Git 的真实路径授权、文本大小等限制只在界面中说明，最终安全校验仍必须由后端执行。参考 [输入与展示边界 ↗](../../../apps/web/src/App.vue#L269 "支持图片格式和大小限制，以及材料目录数量限制等明确边界。")

该文件主要承担编排而非实现全部业务：`LearningView`、`DecisionsView`、`DailyAssistant` 通过事件请求刷新或打开证据；`NotificationDetail` 可回到证据或具体修订；`EvidenceReader` 与 `ChatPane` 共享当前 Agent、模型和思考强度。这里能确认组件间的属性与事件连接，但不能仅凭本文件断言这些子组件内部或后端的完整调用链。参考 [专门子组件编排 ↗](../../../apps/web/src/App.vue#L718 "支持 App 向材料处理、判断、证据阅读、通知详情和问答组件传递状态及接收事件的关系。")
