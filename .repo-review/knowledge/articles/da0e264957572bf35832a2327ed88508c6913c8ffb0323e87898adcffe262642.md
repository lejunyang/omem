# 个人工作记忆 Web 应用总装入口

App.vue 是个人工作区的页面编排与状态协调中心，并在启动时识别 repo-review 模式。它连接统一捕获、固定证据阅读、检索、待办与恢复流程，以及知识整理、学习、决策、通知和 Agent 问答组件。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="boot-and-state"></a>
## 启动分流与全局状态

组件集中维护当前视图、材料版本、焦点片段、通知、待办、变更、作业、模型配置和错误状态。启动时先探测 `/api/review/health`；命中 review 模式后设置 `reviewMode` 并停止个人工作区初始化，否则读取健康状态、profiles 和七类业务集合，再默认打开首份材料。[启动模式探测与个人工作区初始化 ↗](../../../apps/web/src/App.vue#L102 "支持先探测 review 服务、命中后提前返回，以及普通模式读取 profiles 和业务集合的流程。") 模板以该状态在 `ReviewApp` 与个人工作区 `OmShell` 之间二选一，因而 review 服务不会渲染个人业务界面。[Review 与个人工作区条件渲染 ↗](../../../apps/web/src/App.vue#L409 "直接支持 reviewMode 决定渲染 ReviewApp 或 OmShell 的结论。") 普通模式每 2.5 秒刷新，卸载时清理轮询与提示定时器。[普通模式轮询与资源清理 ↗](../../../apps/web/src/App.vue#L399 "支持普通模式启动定时刷新，以及卸载时清理轮询和提示定时器。")

<a id="capture-and-reading"></a>
## 统一捕获与证据阅读

捕获入口支持手工文本、飞书、服务器文件和 Git；手工输入可组合文本、HTTP 链接与一张图片，并记录采集者、主体、事件时间、时区及原始材料属性。保存后刷新集合并打开返回的 revision，重复内容与新证据分别提示。[多来源统一捕获流程 ↗](../../../apps/web/src/App.vue#L207 "支持连接器分流、手工多模态 parts、来源元数据及保存后的刷新与提示行为。") 阅读页展示固定片段、当前或历史版本、版本列表及图片资产；片段可成为问答焦点或打开证据阅读器，图片 part 的 `assetId` 和 label 则传给 `AssetImage`。[固定片段与图片资产阅读 ↗](../../../apps/web/src/App.vue#L520 "支持阅读页的版本状态、固定片段交互、证据入口、版本历史，以及以 assetId 加载图片的关系。")

<a id="workflows-and-concurrency"></a>
## 操作流程与并发边界

搜索通过递增请求版本丢弃迟到响应，避免旧请求覆盖新结果。[搜索响应防竞态 ↗](../../../apps/web/src/App.vue#L196 "支持用递增版本号仅接纳最后一次搜索响应的行为。") 界面同时明确说明当前采用精确文本检索，语义检索尚未接入。[精确文本检索状态说明 ↗](../../../apps/web/src/App.vue#L505 "直接支持当前仅使用精确文本检索、语义检索尚未接入的界面声明。") 待办状态变更携带 `expectedVersion`，历史恢复携带 `expectedHead` 并创建新 revision，前端由此参与乐观并发控制；模型与 effort 的候选项来自 profile probe，而不是硬编码枚举。[并发参数与 Agent 能力探测 ↗](../../../apps/web/src/App.vue#L290 "支持待办和恢复操作的预期版本参数，以及从 Agent probe 响应生成模型与 effort 选项。")

<a id="composition-limits"></a>
## 组件关系与限制

该文件是编排层：知识整理、学习、决策与飞书设置分别交给对应子组件，学习和决策中的证据入口统一转交 EvidenceReader。[知识、学习与决策子视图 ↗](../../../apps/web/src/App.vue#L672 "支持 PersonalKnowledge、LearningView、DecisionsView 的装配及其证据打开、刷新和错误事件关系。") 页面也明确说明从观测自动提炼待办仍待接入。[待办自动提炼的当前限制 ↗](../../../apps/web/src/App.vue#L687 "直接支持待办可以手工关联证据，而从观测自动提炼仍属后续能力。") EvidenceReader、NotificationDetail 与 ChatPane 在壳层统一装配，共享 profile、模型、effort 和刷新回调。[证据、通知与聊天组件总装 ↗](../../../apps/web/src/App.vue#L879 "支持壳层统一连接 EvidenceReader、NotificationDetail 和 ChatPane 及其事件回调。") 访问令牌由此文件写入 `sessionStorage`，属于当前浏览器会话保存；服务端鉴权与凭据安全仍不能仅凭该前端文件确认。[会话令牌保存逻辑 ↗](../../../apps/web/src/App.vue#L394 "支持访问令牌写入 sessionStorage、清空输入并重新启动连接流程的说明。")
