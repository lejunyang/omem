# 个人工作记忆 Web 应用总入口

App.vue 是个人工作区与仓库评审工作区的顶层编排组件：负责识别服务模式、聚合业务状态、路由主要页面、提交多来源材料，并协调证据阅读、问答、判断、学习、通知和待办等功能。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-and-state"></a>
## 职责与状态组织

该组件是 Web 应用的外壳与协调层，集中保存当前视图、材料版本、焦点片段、通知、待办、变更、作业、提案和判断等状态，并引入证据阅读、问答、知识整理、学习与评审应用等子组件。[顶层组件依赖与集中状态 ↗](../../../apps/web/src/App.vue#L28 "支持 App.vue 引入主要业务子组件并集中维护多类页面与业务状态的论断。") 顶层会向学习、判断和日常助理分发各自需要的数据或事件，并协调其中部分刷新、证据打开、错误与提示入口。[学习、判断与日常助理接线 ↗](../../../apps/web/src/App.vue#L710 "支持顶层向不同子页面分发各自的数据和事件，并协调部分刷新、证据打开、错误及提示入口。") 此结论替代此前“所有子页面共享同一批数据和刷新入口”的过宽概括；不同页面实际接收的数据子集和事件并不相同。

<a id="boot-and-refresh"></a>
## 启动、模式识别与同步流程

启动时先请求评审健康接口：明确返回 review 模式才进入仓库评审应用；只有评审路由真实返回 404 才继续探测个人服务，其他异常均视为服务未就绪，并在两秒后重试。[工作区模式识别与启动重试 ↗](../../../apps/web/src/App.vue#L161 "支持评审模式判定、个人服务回退条件、异常处理、两秒重试和个人模式轮询启动流程。") 个人模式随后加载 Agent 配置、并行刷新七类业务数据、默认打开首份材料，再以 2.5 秒周期轮询；刷新互斥避免同一时刻重复执行，通知即时模式会比较最新通知身份并生成提示。[业务数据并行刷新与通知提示 ↗](../../../apps/web/src/App.vue#L108 "支持七类业务数据的并行加载、刷新互斥、材料当前版本校正以及即时通知提示逻辑；不再用于证明搜索版本控制。") 搜索竞态由独立的递增版本号控制，仅当前版本的响应能够写入结果。[搜索响应版本控制 ↗](../../../apps/web/src/App.vue#L224 "直接覆盖递增 searchVersion 及仅允许最新请求结果写回的实现，支持搜索竞态控制论断。") 此处以专门覆盖搜索实现的引用替代此前由刷新代码范围一并支持搜索竞态的结论。

<a id="capture-and-actions"></a>
## 材料录入与业务动作

录入按模式分派到飞书、服务器文件、Git 或通用捕获接口；通用路径把文本、链接和图片组成统一 parts，并记录来源主体、事件时间、时区和转发状态等 provenance。成功后刷新列表、打开新版本，并区分复用未变化版本与生成固定证据片段。[多来源材料捕获流程 ↗](../../../apps/web/src/App.vue#L256 "支持连接器分派、统一 parts、来源元数据记录，以及成功后的刷新、版本打开和重复内容提示。") 浏览器图片仅接受 PNG、JPEG、WebP，单张不超过 5 MB。[浏览器图片上传限制 ↗](../../../apps/web/src/App.vue#L235 "直接支持图片格式仅限 PNG、JPEG、WebP 且单张不超过 5 MB 的界面校验说明。") Git 入口只读取指定 ref，不拉取或执行脚本；Git 仓库和服务器文件均受 captureRoots 约束，服务器文件还限 UTF-8 与 500 KB。[Git 与服务器文件读取边界 ↗](../../../apps/web/src/App.vue#L688 "支持 Git 只读指定 ref、不拉取或执行脚本，以及 Git 仓库和服务器文件受 captureRoots、编码与大小约束的说明。") 当前搜索界面明确使用精确文本检索，语义检索尚未接入。[搜索能力界面说明 ↗](../../../apps/web/src/App.vue#L543 "直接支持当前采用精确文本检索且语义检索尚未接入的界面声明。") 待办更新携带 expectedVersion，历史恢复携带 expectedHead 并创建新版本，从而避免静默覆盖并保留历史。[待办并发更新与历史恢复 ↗](../../../apps/web/src/App.vue#L318 "支持待办更新使用 expectedVersion、恢复使用 expectedHead，并以新版本保留历史的说明。")

<a id="module-links-and-limits"></a>
## 子模块关系与可确认边界

全局 EvidenceReader 接收当前 Agent、模型与 effort；通知详情可跳转证据或版本，ChatPane 以当前焦点片段作为提问上下文，回答保存后触发刷新。[证据阅读、通知与问答集成 ↗](../../../apps/web/src/App.vue#L922 "支持 EvidenceReader、NotificationDetail 和 ChatPane 的属性传递、证据跳转、版本打开与保存后刷新接线。") 这些接线只能证明顶层如何传递属性和处理事件，不能据此推断子组件内部的权限、请求或完整交互。组件卸载时会清除启动重试、轮询和提示计时器。[组件卸载清理逻辑 ↗](../../../apps/web/src/App.vue#L427 "证明组件销毁时会清除启动重试、轮询和提示计时器，同时界定给定材料未展示相关测试断言。") 但给定材料不含相应测试，因此仍无法确认延迟请求、重复启动、手动重连或服务模式变化时是否存在旧异步结果回写等竞态。
