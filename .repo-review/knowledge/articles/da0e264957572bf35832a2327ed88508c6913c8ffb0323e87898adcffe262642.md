# 个人记忆 Web 工作台的总控编排

App.vue 是个人工作记忆前端的应用壳与流程协调器：识别服务模式，维护页面、连接和公共数据状态，并把材料采集、原文阅读、证据问答、任务、通知与 Agent 配置连接到各业务组件及后端接口。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="workspace-and-boot"></a>
## 统一工作台与启动分流

该组件把日常助理、知识库、原始材料、输入、待判断、任务、通知和设置组织在同一工作台中，并通过 URL hash 与会话存储保持当前位置；无法识别的地址回到知识库。参考 [工作台导航与页面状态 ↗](../../../apps/web/src/App.vue#L39 "支持工作台页面组成、hash 路由、默认页面和会话状态同步的说明。")

启动时先探测仓库评审服务。确认处于 review 模式后，只提示用户进入统一主应用；只有评审健康接口明确返回 404，才继续检查个人服务。连接失败会显示原因并定时重试，个人服务就绪后再加载 Agent 配置、公共数据和首份材料。参考 [服务模式识别与启动恢复 ↗](../../../apps/web/src/App.vue#L183 "支持启动时区分评审服务与个人服务，以及错误重试和初始化加载流程。")

<a id="capture-and-refresh"></a>
## 从材料输入到固定证据

工作台并行刷新材料、通知、任务、变更、处理任务、提案和判断，并用互斥标志避免重复刷新；轮询失败保留已有页面状态，只更新错误提示。即时通知模式会把新变化汇总为短暂提示。参考 [公共数据刷新与通知提示 ↗](../../../apps/web/src/App.vue#L129 "支持多类业务数据并行刷新、刷新互斥、错误保留和即时通知汇总。")

输入按文本、飞书、服务器文件和 Git 文件分流。文本模式把正文、链接和图片组成统一 parts，并附上来源、采集者、时间、时区和转发状态；保存后刷新列表、打开返回版本，并区分新版本与重复内容。参考 [多来源材料捕获流程 ↗](../../../apps/web/src/App.vue#L281 "支持导入模式分流、统一 parts 与 provenance 构造，以及保存后的刷新和版本跳转。") 图片限 PNG、JPEG、WebP 和 5 MB，界面一次选择一张；搜索用递增版本号丢弃迟到响应，当前仍是精确文本检索。参考 [搜索竞态与图片限制 ↗](../../../apps/web/src/App.vue#L249 "支持搜索响应版本保护，以及图片格式、大小和单文件选择限制。")

<a id="evidence-and-actions"></a>
## 围绕原文连接问答与业务动作

阅读页展示当前或历史版本、连贯正文、固定片段和版本入口；用户可把片段设为提问焦点，也可打开证据阅读器追溯来源。参考 [原始材料阅读界面 ↗](../../../apps/web/src/App.vue#L565 "支持版本状态、正文渲染、固定片段操作和历史版本入口的描述。") App 负责把材料处理、待判断和日常助理等子组件的刷新、证据打开、错误与提示事件汇入统一通道。参考 [业务子组件事件编排 ↗](../../../apps/web/src/App.vue#L708 "支持 App 向业务子组件传递数据，并统一接收刷新、证据、错误和提示事件。")

ChatPane 将问题、焦点、可选模型、思考强度和上下文范围提交为异步运行，再轮询结果；App 只提供配置和焦点，不直接执行模型。参考 [焦点问答运行流程 ↗](../../../apps/web/src/ChatPane.vue#L33 "支持问答提交焦点与 Agent 配置、异步轮询运行结果及完成后刷新。") 创建任务可以关联当前证据，状态更新携带预期版本；恢复历史则携带预期头版本，并把服务端返回结果作为新版本打开，旧历史仍被保留。参考 [任务的证据关联与版本更新 ↗](../../../apps/web/src/App.vue#L343 "支持任务创建关联当前证据，以及状态切换携带预期版本。") [历史恢复为新版本 ↗](../../../apps/web/src/App.vue#L397 "支持恢复请求携带预期头版本、刷新数据并打开返回版本且保留历史。")

<a id="boundaries"></a>
## 能力探测、并发约束与组件边界

Agent 能力探测通过 generation 标记忽略迟到结果，切换配置时清空旧选项，并在设置页触发重新读取。探测结果会保留所有 `type === "select"` 的配置项；模型与思考强度输入框分别读取其中 ID 为 `model` 和 `reasoning_effort` 的选项，其他 select 项仍显示在“已发现的配置选项”中。参考 [Agent 配置项探测 ↗](../../../apps/web/src/App.vue#L410 "支持仅保留所有 select 类型配置项、展开分组选项、忽略迟到响应及切换配置时清理旧状态。") [模型与思考强度配置界面 ↗](../../../apps/web/src/App.vue#L797 "支持模型和思考强度分别读取指定 ID 的选项，同时展示探测到的其他 select 配置项及连接边界。")

设置页声明上下文超限应明确拒绝，浏览器令牌只用于连接 omem 服务，网页不能修改执行命令。版本冲突、鉴权及返回结构仍依赖 API 封装和服务端语义。通知详情通过事件请求打开版本或证据，参考 [通知详情的打开事件 ↗](../../../apps/web/src/NotificationDetail.vue#L28 "支持通知详情展示变化，并通过事件请求父组件打开证据或具体版本。")；证据阅读器自行加载证据、维护阅读栈并恢复滚动位置。参考 [证据阅读栈行为 ↗](../../../apps/web/src/EvidenceReader.vue#L16 "支持证据阅读器加载证据、维护帧栈与滚动位置，并向 App 暴露打开入口。")
