# 个人记忆工作台的入口与流程编排

该组件是个人记忆 Web 应用的顶层容器，负责识别服务模式、恢复页面状态、刷新全局数据，并连接材料采集、版本阅读、证据问答、待办和通知等流程；数据约束与模型执行的最终保障仍需后端实现。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="workspace_entry"></a>
## 统一入口与服务连接

工作台把知识、原始材料、采集、学习、判断、待办、变更和通知集中在同一导航，并可从 URL hash 或会话存储恢复当前页面；切换页面时会同步保存状态。参考 [工作台导航与页面恢复 ↗](../../../apps/web/src/App.vue#L38 "支持多个记忆流程集中在同一导航，以及从 URL hash 或会话存储恢复页面。") [页面状态同步 ↗](../../../apps/web/src/App.vue#L68 "支持视图变化后清理查询、写入会话存储并同步 URL hash。")

启动阶段先探测仓库评审服务；只有评审接口明确返回 404，才继续连接个人服务。未授权或服务尚未就绪时会定时重试，个人模式连接成功后再加载配置、数据和首份材料。参考 [服务模式探测与轮询启动 ↗](../../../apps/web/src/App.vue#L177 "说明评审模式识别、404 分流、连接重试，以及个人服务启动完成后创建刷新定时器。")

<a id="capture_and_read"></a>
## 从材料采集到固定证据

采集会按飞书、服务器文件、Git 或通用输入分派接口。通用输入可组合文本、链接和图片，并附带来源信息；保存后刷新工作台、打开对应版本，并提示复用旧版本还是生成了新证据。参考 [多来源材料采集 ↗](../../../apps/web/src/App.vue#L272 "支持采集接口分派、通用多模态载荷、来源信息以及保存后的刷新和版本打开流程。") 图片在浏览器端限定为 PNG、JPEG 或 WebP，单张不超过 5 MB。参考 [图片上传限制 ↗](../../../apps/web/src/App.vue#L251 "直接支持浏览器端允许的图片格式和 5 MB 大小上限。")

阅读页区分当前版本与历史版本，以代码或 Markdown 展示内容，允许浏览固定片段、打开证据和切换历史。参考 [版本与固定片段阅读 ↗](../../../apps/web/src/App.vue#L544 "支持代码或 Markdown 展示、固定片段浏览、证据打开及版本历史切换。") 当前搜索界面仍是精确文本检索，并以请求序号避免较早响应覆盖较新的搜索结果。参考 [精确文本搜索界面 ↗](../../../apps/web/src/App.vue#L529 "直接支持当前搜索页面仅提供精确文本检索的限制。") [搜索响应防竞态 ↗](../../../apps/web/src/App.vue#L240 "支持用递增请求序号阻止旧搜索响应覆盖新结果。")

<a id="coordination_and_limits"></a>
## 跨功能编排与能力边界

顶层组件把学习、判断和日常助理发出的刷新、证据打开、错误与提示事件接回全局界面。参考 [子视图事件编排 ↗](../../../apps/web/src/App.vue#L688 "支持顶层接收刷新、打开证据、错误和提示事件，并将其连接到全局能力。") 在阅读页选择片段后，该片段会传给问答面板作为焦点；新建待办时也可把它作为来源证据提交。参考 [选择问答焦点 ↗](../../../apps/web/src/App.vue#L560 "支持用户在阅读页选择固定片段并将其设为当前焦点。") [焦点传入问答面板 ↗](../../../apps/web/src/App.vue#L919 "支持阅读页把当前片段、运行配置传给问答面板。") [待办关联证据 ↗](../../../apps/web/src/App.vue#L334 "支持创建待办时将当前焦点片段作为 evidenceId 提交。") [待办来源提示 ↗](../../../apps/web/src/App.vue#L710 "支持待办表单向用户提示新事项将关联当前选中片段。")

个人服务启动完成后，定时器会周期触发全局刷新；刷新过程并行读取材料、通知、任务、变更和处理状态，并阻止重入。参考 [服务模式探测与轮询启动 ↗](../../../apps/web/src/App.vue#L177 "说明评审模式识别、404 分流、连接重试，以及个人服务启动完成后创建刷新定时器。") [全局并行刷新 ↗](../../../apps/web/src/App.vue#L123 "支持并行刷新多个业务集合、避免刷新重入并更新通知提示。") Git 与服务器文件的读取限制目前在本组件中体现为界面说明。参考 [Git 与文件读取说明 ↗](../../../apps/web/src/App.vue#L666 "支持界面声明的指定提交、captureRoots、UTF-8 和文件大小限制，但不证明后端强制执行。") Agent 配置则包含能力探测、模型与 effort 输入、上下文上限提示，以及向证据阅读器和问答面板传参；这些前端行为本身不能证明服务器已强制拒绝非法配置或超限请求。参考 [Agent 能力探测 ↗](../../../apps/web/src/App.vue#L401 "支持前端请求 Agent 能力并整理可选择的模型与配置选项。") [问答运行配置界面 ↗](../../../apps/web/src/App.vue#L796 "支持模型、effort、上下文上限和 Agent 能力读取在设置页中的展示与配置。") [运行参数传递 ↗](../../../apps/web/src/App.vue#L900 "支持将 profile、model 和 effort 传给证据阅读器及阅读页问答面板。")
