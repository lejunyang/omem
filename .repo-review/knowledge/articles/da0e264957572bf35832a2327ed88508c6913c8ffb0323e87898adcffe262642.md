# 统一工作记忆的 Web 应用编排

App.vue 是个人工作记忆 Web 端的顶层编排器：识别服务模式，维持导航与共享状态，并把材料采集、阅读、搜索、证据追踪、事项、通知和 Agent 配置接入同一外壳。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-and-boot"></a>
## 一个入口，多个工作面

`App.vue` 解决的是“怎样把个人记忆的多种操作放进一个稳定入口”。它用哈希与会话存储维护当前页面，菜单覆盖日常助理、知识库、原始材料、采集、处理、事项、通知和连接设置；页面切换时会清空全局搜索并同步 URL。参考 [顶层导航与页面状态 ↗](../../../apps/web/src/App.vue#L48 "支持应用以哈希和会话状态组织多个稳定工作入口的说明。")

启动并非直接拉取业务数据：组件先探测评审服务。确认是 review 模式时只显示迁移提示；只有探测端点明确返回 404 才按个人服务继续，其他错误每两秒重试。个人模式随后读取健康状态、Agent 配置与各类列表，并每 2.5 秒刷新。也就是说，这里负责**页面与状态编排**，数据持久化和领域处理仍由 API 与子组件完成。参考 [启动模式探测与刷新 ↗](../../../apps/web/src/App.vue#L286 "说明评审模式和个人模式的分流、连接重试、初始数据加载与周期刷新。")

<a id="capture-flow"></a>
## 代表性流程：保存并打开一份材料

以用户提交“文本＋图片＋链接”为例：表单把正文、链接和已选图片组装为 `parts`，补上来源标识、操作者、事件时间与时区，再调用 `/captures`；飞书、服务器文件和 Git 文件则分别走连接器端点。保存成功后，组件先刷新全局列表，再以返回的 revision id 打开版本，最后提示“复用原版本”或“已生成固定证据片段”。参考 [材料采集与保存后流转 ↗](../../../apps/web/src/App.vue#L405 "支持不同采集端点、手工材料组装、来源信息以及保存后刷新并打开版本的完整调用流程。")

```mermaid
  A[表单输入] --> B[组装 parts 与来源信息]
  B --> C[调用采集 API]
  C --> D[刷新列表]
  D --> E[打开返回的固定版本]
```
参考 [材料采集与保存后流转 ↗](../../../apps/web/src/App.vue#L405 "支持不同采集端点、手工材料组装、来源信息以及保存后刷新并打开版本的完整调用流程。")

打开版本时，代码材料交给代码查看器，其他文本交给 Markdown 阅读器；片段可成为提问焦点，也可打开证据，历史版本仍可切换。图片入口只接受 PNG、JPEG、WebP 且不超过 5 MB。新增采集方式应同时修改 `capture()` 的分支和对应表单页签；改变保存后的阅读体验则从 `openRevision()` 与材料阅读区入手。参考 [版本阅读与片段操作 ↗](../../../apps/web/src/App.vue#L781 "说明代码和普通文本的不同渲染方式、片段提问与证据入口、版本历史切换。") [图片输入限制 ↗](../../../apps/web/src/App.vue#L384 "支持浏览器侧图片格式、大小校验以及读取为采集载荷的边界。")

<a id="search-and-boundaries"></a>
## 搜索、证据追踪与生命周期边界

搜索词或用途变化时，组件会清除旧定时器、取消在途请求，等待 250 毫秒后发起带 `q` 与 `purpose` 的查询；版本号确保较慢的旧响应不能覆盖新结果。任务结果直接切换到事项页，记忆结果沿首个原始引用继续，知识、原文和知识引用则压入证据阅读栈。参考 [防抖搜索与陈旧响应保护 ↗](../../../apps/web/src/App.vue#L178 "说明查询变化时的延迟触发、请求取消和版本号保护，以及实际搜索请求参数。") [搜索结果分流 ↗](../../../apps/web/src/App.vue#L122 "支持任务、记忆、知识、原文和引用采用不同导航行为及记忆无依据时不继续打开的边界。")

结果阅读由 `OmTrailDrawer` 与 `KnowledgeFrame` 承担，原始片段则交给 `EvidenceReader`；阅读页把当前片段和 Agent 配置传给 `ChatPane`，子组件保存后统一触发 `refresh`。这显示 `App.vue` 与其他模块的关系是传递 props、接收事件和维护顶层状态，而非在此实现证据解析或问答运行。参考 [证据、知识与问答组件接线 ↗](../../../apps/web/src/App.vue#L1212 "说明顶层组件如何向证据阅读器、知识帧和聊天面板传递状态，并通过事件统一刷新或继续导航。")

边界上，记忆结果没有引用时不会打开任何页面；非空搜索会暂时取代当前业务页。组件卸载时还会移除哈希监听、停止轮询和提示/搜索定时器，并取消搜索请求，避免离开页面后继续更新状态。参考 [搜索结果分流 ↗](../../../apps/web/src/App.vue#L122 "支持任务、记忆、知识、原文和引用采用不同导航行为及记忆无依据时不继续打开的边界。") [卸载清理 ↗](../../../apps/web/src/App.vue#L589 "支持组件离开时清理监听、轮询、定时器与在途搜索，避免后续状态更新。")
