# 冻结质量集的预测评估与门禁

该命令校验冻结数据集，读取预测数组并调用统一 evaluator 计算指标，生成带输入摘要的报告；任一质量门禁失败时以非零退出码通知自动化流程。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="inputs"></a>
## 输入与可复现性

命令从位置参数或环境变量取得数据集标识和预测文件，缺少任一项即报用法错误。它打开指定数据目录中的 Store，通过 `verifyFrozen` 确认数据集冻结状态，要求预测 JSON 顶层为数组，再交给 `evaluateQuality`。[冻结数据集与预测输入 ↗](../../../scripts/quality-evaluate.ts#L8 "支持参数解析、冻结校验、预测数组检查及报告中的可复现摘要字段。") 报告记录数据集 split、冻结 manifest 摘要和预测摘要，使评估对应到明确的样本与输出版本。

<a id="gates"></a>
## 指标门禁

门禁要求自动应用精确率、`semanticSupport` 率和引用位置准确率至少 0.95，必要证据覆盖率与显式覆盖率至少 0.8；模糊 owner 误报必须为零，且不得缺预测。[质量指标阈值与设计声明 ↗](../../../scripts/quality-evaluate.ts#L28 "支持各项门禁阈值，并证明源码注释声明了语义蕴含目标；不将注释扩大为算法实现证据。") 注释声明语义支持应采用蕴含而非子串匹配，并让反向陈述得零分；但本材料只展示阈值与设计声明，不能独立证明 evaluator 的实际算法已经满足该语义。

<a id="outputs"></a>
## 输出与失败语义

报告默认写入质量目录，也可由环境变量覆盖；创建目录时请求 `0700`，但既有目录不会在此被显式收紧，而输出文件写入后会明确执行 `chmod 0600`。任一 gate 为假时退出码设为 1，无论成功失败都会关闭 Store。[评估报告与退出码 ↗](../../../scripts/quality-evaluate.ts#L50 "支持目录创建模式、文件强制权限、标准输出、失败退出码和 Store 清理的区分描述。") 本文件没有展示 evaluator 对重复、未知或多余 sample 的处理规则。
