# 冻结质量集的预测评估与门禁

该命令验证冻结数据集，读取预测数组并调用统一 evaluator，生成带输入摘要的评估报告；任一门禁失败时以非零退出码通知自动化流程。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="inputs"></a>
## 输入与可复现性

命令从位置参数或环境变量取得数据集标识和预测文件，缺少任一项即报用法错误。它打开指定数据目录中的 Store，通过仓库验证数据集已冻结，要求预测 JSON 顶层为数组，再交给 `evaluateQuality`。报告记录 split、冻结 manifest 摘要和预测摘要，使评估结果能够对应明确输入版本。[冻结数据集与预测输入 ↗](../../../scripts/quality-evaluate.ts#L8 "支持参数解析、冻结校验、预测顶层数组检查和可复现摘要字段。")

<a id="gates"></a>
## 指标门禁

门禁要求自动应用精确率、`semanticSupport` 率和引用位置准确率至少 0.95，必要证据覆盖率与显式覆盖率至少 0.8；模糊 owner 误报必须为零，且不得缺预测。[质量指标门禁 ↗](../../../scripts/quality-evaluate.ts#L28 "支持各指标名称、阈值和注释中声明的语义支持设计意图。") 代码注释声明语义支持应基于蕴含而非子串、反向陈述应得零分，但本材料只证明脚本读取该指标并执行 0.95 门禁；实际计算逻辑仍在未提供的 evaluator 中。

<a id="outputs"></a>
## 输出与失败语义

报告默认写入质量目录，也可由环境变量覆盖；创建目录时请求 `0700`，但不会显式收紧既有目录，报告文件写入后则明确执行 `chmod 0600`。任一 gate 为假时退出码设为 1，无论成功失败最终都会关闭 Store。[评估报告与退出码 ↗](../../../scripts/quality-evaluate.ts#L50 "支持目录创建模式、文件权限收紧、标准输出、失败退出码和 Store 清理。") 该文件也未展示重复、未知或数据集外 sampleId 的匹配规则。
