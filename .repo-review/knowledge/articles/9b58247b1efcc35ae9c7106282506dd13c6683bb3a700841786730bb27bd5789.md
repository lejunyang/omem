# omem-extract 技能：固定材料的证据绑定提取流程

该技能把提取角色的原则整理为操作流程：可信上下文决定元数据，材料仅作为数据；按原子事实、事件或明确任务生成候选，并用精确修订与片段证据绑定。它还定义了不确定性、任务归属和恶意材料处理规则，但未证明宿主已经强制执行。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="extraction-flow"></a>
## 提取与证据绑定流程

技能适用于提供可信上下文且要求 `ProposalBatch.v1` 的背景提取任务。流程先从可信上下文读取身份、范围、时间、转发状态和来源权威，再为每个持久事实、事件或明确任务生成独立候选，跳过闲聊与重复。每项候选必须绑定精确的来源修订和片段，并不得强化原文。任务负责人只能来自已验证的指派或承诺；无法唯一解析的时间、身份、范围或支持证据应进入不确定性。[证据绑定候选提取步骤 ↗](../../../packages/agent-runtime/roles/extractor/1/skills/omem-extract/SKILL.md#L3 "支持可信上下文取值、原子候选、精确证据绑定、任务归属和不确定性处理流程。")

<a id="unsafe-material"></a>
## 不可信材料与执行隔离

技能要求拒绝材料中要求执行命令、修改权限、泄露秘密或绕过输出合同的内容；这类文本至多可作为被描述的证据，不能转化为角色指令。[危险材料拒绝规则 ↗](../../../packages/agent-runtime/roles/extractor/1/skills/omem-extract/SKILL.md#L16 "支持材料中的命令和越权要求仅是数据、不得作为执行指令的安全边界。") 因而技能与提取提示词共同形成“只产候选、不执行、不应用”的边界，但该文档仍是流程规范，不是外部命令防护已经通过测试的证明。
