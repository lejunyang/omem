# Botmux 既有 Lark 应用复用适配器

从受控本地配置读取 botmux 应用，验证凭据一致性，对外提供脱敏应用列表，并仅在明确选择应用后返回注册所需凭据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="source_and_validation"></a>
## 配置来源与输入约束

提供器优先采用构造参数，其次读取 `OMEM_BOTMUX_CONFIG` 或 `BOTS_CONFIG`，否则使用用户目录下的 `.botmux/bots.json`。路径会被解析为绝对路径；文件不存在时视为空列表，存在时必须是普通文件、不得超过 5 MB，且顶层必须为数组。每项应用编号需匹配 `cli_` 格式并具有非空密钥，同一应用编号若出现不同密钥则整体拒绝。[Botmux 配置读取与验证 ↗](../../../apps/server/src/integrations/lark/existing-apps.ts#L26 "支持路径优先级、文件大小与结构限制、应用编号和凭据冲突校验。")

<a id="listing_and_credentials"></a>
## 列表展示与凭据交付

`list` 按应用编号去重，只暴露编号、名称、品牌和来源，不返回密钥；缺少名称时使用编号末六位生成可读名称，未知品牌默认按飞书处理。`credentials` 会重新读取并查找指定应用，未找到则报错；找到后返回 clientId、clientSecret，以及可选 owner open ID 和品牌，供接入流程继续注册或能力检查。[应用列表与凭据查询 ↗](../../../apps/server/src/integrations/lark/existing-apps.ts#L63 "支持列表不暴露密钥、按应用去重，以及选择后返回注册凭据。")
