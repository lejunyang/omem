# 任务规划技能界面元数据

该 YAML 提供面向 OpenAI 代理界面的显示名称、简短说明和默认调用提示，用于发现或呈现规划技能；它不包含规划逻辑、模型配置或运行验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="presentation"></a>
## 技能展示信息

界面元数据把该能力显示为“omem Task Planning”，并用“提出有边界的下一步而不执行动作”概括其用途。[任务规划技能界面名称与说明 ↗](../../../packages/agent-runtime/roles/planner/1/skills/omem-task-planning/agents/openai.yaml#L1 "支持界面展示名称及非执行型能力摘要的说明。") 这与规划角色的非执行边界一致，主要服务于技能列表、选择器或其他界面展示，不能单独证明技能已被正确装载。
