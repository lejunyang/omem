# Web 前端 API 类型与请求适配层

该文件集中声明 Web 页面消费的后端数据形状，并封装带浏览器会话认证的 JSON 请求。它复用部分共享合同，但任务状态及多数页面 DTO 仍在本地声明；泛型响应仅提供编译期约束，未体现运行时结构校验。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="responsibility"></a>
## 职责与数据边界

该模块是 Web 前端访问 `/api` 的轻量适配层。它从共享合同引入 Revision、Fragment、Change、RunEvent 和 TaskFollowUp，并在本地定义 Source、Evidence、通知及任务等页面 DTO。[基础 API 类型与任务声明 ↗](../../../apps/web/src/api.ts#L1 "支持共享类型导入、本地页面 DTO、TaskFollowUp 复用，以及任务状态仍在本文件重复声明的结论。") Profile、Run、Job、Proposal 与 Decision 描述模型配置、运行状态、作业尝试、变更提案、策略评估和人工决策等流程数据。[运行、作业、提案与决策类型 ↗](../../../apps/web/src/api.ts#L50 "支持模型运行配置、作业生命周期、变更提案、策略评估和人工决策的数据边界说明。")

通知详情还包含投递尝试、回执和证据关联；飞书类型覆盖应用预设、连接、接入状态、配对信息及可复用应用。[通知详情与飞书接入类型 ↗](../../../apps/web/src/api.ts#L160 "支持通知投递、回执、证据关联，以及飞书应用配置、连接、接入和复用应用的类型说明。") 这些声明主要形成 TypeScript 编译期边界；给定材料未显示本地 DTO 会从服务端 schema 自动生成或在响应进入页面前接受运行时校验。

<a id="request-flow"></a>
## 请求与错误处理流程

`headers()` 从浏览器 `sessionStorage` 读取 `omem-token`，存在时生成 Bearer 认证头。`api<T>()` 根据 body 是否存在默认选择 GET 或 POST，也允许调用方覆盖方法；请求统一添加 `/api` 前缀、JSON Content-Type，并按需序列化正文。[认证头与请求构造 ↗](../../../apps/web/src/api.ts#L242 "支持令牌来源、默认 HTTP 方法、API 前缀、认证头和请求正文序列化流程，也表明实现依赖浏览器环境。")

响应到达后，函数先无条件执行 `r.json()`，再依据 `r.ok` 抛出响应中的 `error` 或返回解析值。[JSON 响应与错误分支 ↗](../../../apps/web/src/api.ts#L256 "支持响应先解析 JSON、再检查 HTTP 状态并将解析结果直接作为泛型返回的行为及其限制。") 泛型 `T` 只提供静态推断，并不验证实际 JSON。空响应或非 JSON 内容可能在统一错误分支之前触发解析异常；当前实现也未体现超时、取消、重试、去重或令牌刷新。

<a id="contracts-boundaries"></a>
## 任务合同复用与结论修正

先前“任务 DTO 的状态和跟进信息都来自共享合同”的结论已被替代：本文件仅导入 `TaskFollowUp`，而 `Task.status` 本地重复声明为 `open | waiting | done | cancelled`。其取值与共享 `TaskStatus` 一致，但没有直接复用该类型。[基础 API 类型与任务声明 ↗](../../../apps/web/src/api.ts#L1 "支持共享类型导入、本地页面 DTO、TaskFollowUp 复用，以及任务状态仍在本文件重复声明的结论。")

共享合同将跟进信息约束为严格对象：等待对象文本为非空可空字符串，检查与延后时间须为带偏移量的日期时间，`time_expression` 只是最长 500 字符的可空时间表达式字符串，时区须通过 IANA 时区校验。[任务状态与跟进共享合同 ↗](../../../packages/contracts/src/task-flow.ts#L3 "支持共享任务状态取值，以及 TaskFollowUp 对可空字符串、带偏移时间、IANA 时区和严格对象结构的具体约束。") 本文件仅以 TypeScript 类型导入该结构，不能据此确认 `api<T>()` 返回值会自动执行这些 Zod 规则；是否扩大共享 DTO 复用或增加响应校验，仍需结合服务端路由与测试判断。
