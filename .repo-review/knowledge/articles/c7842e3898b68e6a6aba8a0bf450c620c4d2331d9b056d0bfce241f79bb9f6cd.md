# OmTrailDrawer：受控证据路径对话框

该组件承载多层证据钻取栈，以原生模态对话框提供焦点限制和 Escape 语义，并负责层间跳转、滚动记忆、循环提示及关闭后的焦点归还。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="controlled-contract"></a>
## 受控合同与生命周期

组件本身不增删路径帧，而由父组件传入打开状态、完整帧栈、当前索引和循环位置，再通过 `back`、`jump`、`close`、`dismissLoop` 事件请求变更。[证据路径受控属性与事件 ↗](../../../packages/ui/src/components/OmTrailDrawer.vue#L14 "支持父组件拥有栈状态、抽屉仅通过事件请求关闭、返回、跳转和消除循环提示的说明。") 打开时记录原焦点、调用原生 `showModal()` 并聚焦当前标题；关闭时优先把焦点还给显式触发元素，否则回到原焦点。切层后恢复该帧的滚动位置并再次聚焦标题，卸载时也会关闭对话框和尝试归还焦点。[对话框焦点与滚动生命周期 ↗](../../../packages/ui/src/components/OmTrailDrawer.vue#L30 "支持打开、关闭、切层和卸载时焦点处理及滚动恢复的说明。")

<a id="navigation-behavior"></a>
## 路径导航与异常处理

Escape 触发原生 cancel：多层时只退一层，根层才完全关闭；点击背景则直接关闭全部。面包屑展示整条路径，但未来层被禁用，仅允许跳回较早层；循环提示让用户跳至已打开层或留在当前层。内容由默认插槽提供，组件只保存当前帧滚动量。[路径导航和循环提示界面 ↗](../../../packages/ui/src/components/OmTrailDrawer.vue#L86 "支持面包屑回跳、上一层入口、循环选择以及内容插槽结构的说明。") 这与共享 `TrailFrame` 的可序列化身份和滚动字段配合，循环识别及真正的 push/pop 仍由容器负责。[共享路径帧合同 ↗](../../../packages/ui/src/trail.ts#L1 "说明抽屉使用的帧记录可序列化、含稳定身份与滚动字段，且循环识别和压栈由外部共享逻辑负责。")

<a id="boundaries"></a>
## 显示边界与待验证行为

桌面端对话框限制在 860×840 范围并具有滚动内容区，小屏改为全视口。原生 dialog 提供基础焦点陷阱，但材料未显示 `open` 初始即为 true 时 watcher 是否必然执行、外部直接触发 close 事件后的状态同步、非法 current 索引保护，或超过 URL 序列化预算时的提示实现。[对话框尺寸与移动端规则 ↗](../../../packages/ui/src/components/OmTrailDrawer.vue#L154 "支持桌面尺寸限制、内部滚动和移动端全屏化的边界说明。") 也未提供测试文件，无法确认 100 层以上路径、焦点归还、滚动恢复和循环提示的真实浏览器行为。
