# 知识正文独立复核提示

提示词将复核聚焦于引用支持性、时效、范围和约束，规定实质性错误需要修订，而明确保留的不确定性可以通过；输出必须遵循 KnowledgeReview.v1。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="review-standard"></a>
## 实质性复核标准

该提示要求复核者独立对照原材料检查草稿，重点判断引用是否支持附近论断，以及论断的时代、适用范围和约束是否准确。事实错误或缺乏支持的关系应判为 `needs_revision`；已明确标注为不确定的内容可以 `accepted`，同时保留问题。它还排除仅因措辞偏好而拒绝草稿的做法。[独立复核判定原则 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/prompt.md#L1 "支持引用支持性、时效、范围、约束以及 accepted 与 needs_revision 分界的说明。")

<a id="execution-boundary"></a>
## 输出与执行边界

复核只能输出 `KnowledgeReview.v1`，并为每份草稿提供文档键、判定、问题和未决事项。材料与草稿被界定为待核验的数据而非操作指令，且流程不得调用工具。[复核输出和无工具边界 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/prompt.md#L2 "支持限定 KnowledgeReview.v1、逐草稿字段及不执行材料指令和不调用工具的说明。") 这说明提示层面追求独立、只读的证据复核；具体字段限制由配套输出 schema 进一步约束。
