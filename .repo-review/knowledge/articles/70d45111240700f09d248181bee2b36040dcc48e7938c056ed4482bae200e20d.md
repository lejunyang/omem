# SQLite 数据库迁移与持久化模型

该文件集中定义并执行 SQLite 1—18 版迁移，把捕获证据、作业运行、受治理记忆、飞书集成、会话、检索与任务跟进纳入同一持久化模型；迁移通过版本、历史校验、事务回滚和校验和防止数据库被不兼容程序写坏。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-schema"></a>
## 解决的问题与数据边界

该模块是服务端数据库结构的演进总入口，当前支持 schema 18。基础层先建立来源、不可变修订、片段、关系、变更、通知和任务；后续迁移继续加入捕获回执、作业与尝试、提案及证据评估、版本化记忆、决策和投递等表，使“原始证据—派生判断—应用结果”可追溯，而不是把所有状态压入单表。[基础表与治理数据模型 ↗](../../../apps/server/src/storage/migrations.ts#L30 "支持迁移从原始来源和片段扩展到作业、提案、记忆、决策及投递的论断。")

各业务域仍共享同一 SQLite：角色运行结果、飞书连接与卡片命令、质量标注、助手会话、来源画像和注意力治理均通过外键或 workspace 字段衔接已有实体。[角色运行与业务域扩展 ↗](../../../apps/server/src/storage/migrations.ts#L339 "说明角色输出、飞书、标注、会话和来源画像等业务域被纳入同一数据库结构。") 这些关系说明迁移层为其他存储模块提供结构合同，但材料没有调用方源码，无法确认具体 repository 或 worker 如何读写这些表。

<a id="migration-flow"></a>
## 迁移注册、校验与执行流程

每批 SQL 都计算 SHA-256 校验和，并按版本、名称、语句集合注册；因此已应用历史不仅比较版本号，也能检测旧迁移被事后修改。[迁移校验和与版本清单 ↗](../../../apps/server/src/storage/migrations.ts#L943 "支持每批 SQL 计算校验和并按顺序注册为固定迁移版本。") 启动时先启用外键并读取 `PRAGMA user_version`：数据库版本高于本程序支持值时拒绝写入；随后检查 migrations 表中的未知版本、超前记录、缺失记录和校验和不一致，仅为旧版 version 1 保留兼容校验和。[迁移历史一致性检查 ↗](../../../apps/server/src/storage/migrations.ts#L1075 "支持对未知、超前、缺失和校验和异常历史的拒绝逻辑，以及旧版首迁移兼容例外。")

待执行迁移必须严格从前一版本推进。每版在 `BEGIN IMMEDIATE` 事务中顺序执行 SQL、写入迁移历史、调用提交前 hook、更新 user_version，再提交；任一步骤抛错都会整体回滚。全部完成后再次验证完整历史并切换 WAL。[事务化迁移入口 ↗](../../../apps/server/src/storage/migrations.ts#L1125 "支持严格逐版执行、提交前 hook、失败回滚、最终复核和 WAL 设置的流程说明。")

<a id="evolution-and-limits"></a>
## 关键演进与边界条件

后期迁移体现了几个重要约束：全文检索是片段的可重建 FTS5 投影，并以触发器覆盖片段增删改；语义向量按 `model_id + fragment_id + part` 隔离，避免不同模型结果直接共用主键空间。[全文与语义检索结构 ↗](../../../apps/server/src/storage/migrations.ts#L915 "说明 FTS5 投影由触发器维护，并且向量记录以模型身份隔离。") 任务第 18 版在保留旧修订行的同时扩展 `waiting/cancelled` 状态、跟进内容和提醒去重回执。[任务跟进生命周期迁移 ↗](../../../apps/server/src/storage/migrations.ts#L959 "支持任务状态扩展、follow_up 字段、旧修订复制以及提醒回执去重的论断。")

部分演进通过新建表、复制数据、删除旧表再改名完成，例如注意力状态扩展和 refresh_records 重建；其安全性依赖外层单版事务。[表重建式结构演进 ↗](../../../apps/server/src/storage/migrations.ts#L795 "说明部分约束扩展依靠建新表、复制、删除和改名，并依赖迁移事务保证原子性。") 边界上，该实现只支持按固定数组逐版升级，没有降级路径；SQL 也假定前序版本准确存在。`beforeCommit` 明确是验收测试注入点，可验证失败时回滚，但本材料不含测试文件，不能据此确认历史损坏、并发迁移、FTS 可用性或每个数据复制步骤均已有行为断言。
