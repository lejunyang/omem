# 可递归展开的知识文章目录树

该组件将文章元数据中的父子关系呈现为逐层展开的目录树，负责文章选择、当前项与待更新状态展示，并通过祖先链避免当前递归路径上的环路；它不负责数据请求或关系完整性校验。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决什么问题

知识页面需要让读者从一篇文章继续浏览其下级内容，同时辨认当前选中的文章以及需要更新的条目。`KnowledgeTree` 接收当前文章、全量文章列表、选中键和可选祖先链；用户点击标题后，组件只向外发出文章键，由上层继续处理选择结果。参考 [目录输入与选择事件 ↗](../../../apps/web/src/knowledge/KnowledgeTree.vue#L2 "支持组件接收文章树数据、选中状态与祖先链，并通过事件输出所选文章键的职责说明。")

目录关系和状态来自统一的文章元数据：`children` 保存下级文章键，`current` 表示文章是否为当前版本。组件本身只消费这些字段，不负责获取文章数据。参考 [文章元数据合同 ↗](../../../apps/web/src/knowledge/api.ts#L1 "支持目录关系由 children 提供、文章更新状态由 current 提供，以及组件依赖统一文章元数据类型的论断。")

<a id="flow"></a>
## 递归展开与文章选择

组件从当前文章的 `children` 开始，先排除祖先链中的键和当前文章自身，再到全量文章列表中寻找对应条目。只有解析成功的文章才会进入子节点集合；节点是否展开则由各实例自己的局部状态保存。参考 [子节点解析与环路过滤 ↗](../../../apps/web/src/knowledge/KnowledgeTree.vue#L6 "支持子键过滤、文章查找、缺失键略过，以及祖先链只能约束当前递归路径的边界说明。")

有子节点时，界面显示带可访问名称和 `aria-expanded` 状态的展开按钮。展开后组件递归渲染子文章，并把当前文章键追加到祖先链；标题按钮根据文章键标记当前页、发出选择事件，非当前版本的文章显示“待更新”。参考 [树节点交互与递归渲染 ↗](../../../apps/web/src/knowledge/KnowledgeTree.vue#L9 "支持展开状态、当前页标记、待更新提示、递归祖先链和选择事件转发的描述。")

<a id="boundaries"></a>
## 处理边界与已知限制

祖先链过滤能阻止沿当前递归路径返回祖先或指向自身，但它并不是完整的关系校验：重复子键仍可能形成重复条目，而在全量文章列表中找不到的子键会被略过。参考 [子节点解析与环路过滤 ↗](../../../apps/web/src/knowledge/KnowledgeTree.vue#L6 "支持子键过滤、文章查找、缺失键略过，以及祖先链只能约束当前递归路径的边界说明。")

该组件只实现目录计算、展开、选择和状态展示；其源码没有实现网络请求、令牌处理、请求错误处理或知识阅读帧构造。接口文件另行定义文章元数据，并提供这些数据访问与阅读帧相关能力，但现有材料不足以确认具体由哪个父组件调用或承担页面级协调。延伸阅读：[文章元数据合同 ↗](../../../apps/web/src/knowledge/api.ts#L1 "支持目录关系由 children 提供、文章更新状态由 current 提供，以及组件依赖统一文章元数据类型的论断。") [知识接口与阅读帧能力 ↗](../../../apps/web/src/knowledge/api.ts#L5 "说明网络请求、令牌、错误处理和知识阅读帧构造存在于接口文件中，并限定不能据此推断具体父组件职责。")
