# 共享 UI 包公共入口

集中导出基础组件、代码与 Markdown 阅读组件、证据 trail、关系图及哈希路由类型，使消费者依赖稳定的包级接口。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="public-surface"></a>
## 组件与类型出口

该文件是共享 UI 包的聚合入口：基础按钮、图标、徽章、面板、空状态、对话框和壳层，与引用、代码查看、Markdown、状态栏、关系图及 trail 抽屉从同一入口提供。[共享组件导出清单 ↗](../../../packages/ui/src/index.ts#L1 "支持该入口统一公开基础控件与知识阅读相关组件的论断。") 它还单独导出关系图的数据类型和代码范围标记类型，使上层应用能够构造组件输入而无需直接引用组件内部路径。材料仅展示出口，不能据此确认各组件内部实现或它们彼此调用。[图与代码查看器类型导出 ↗](../../../packages/ui/src/index.ts#L14 "支持消费者可从包入口取得关系图数据类型和代码范围类型。")

<a id="trail-and-routing"></a>
## 证据导航合同

入口把 `TrailFrame` 类型、最大深链预算、帧序列化、循环检测和压栈函数与 `useEvidenceTrail` 一并暴露，表明帧数据模型、纯函数和 Vue 状态管理被设计为可复用合同。[Trail 类型、函数与组合式函数导出 ↗](../../../packages/ui/src/index.ts#L19 "支持 trail 数据模型、栈辅助函数和 Vue 状态接口构成公共合同。") 同时公开哈希路由的解析与写入函数及 Wiki 路由类型，为上层把导航状态放入 URL 提供接口。[哈希路由出口 ↗](../../../packages/ui/src/index.ts#L21 "支持共享包向上层提供 URL 哈希解析、写入及路由类型。") 但这里没有展示具体消费者，所以只能确认可导入关系，不能断言哪个应用已实际使用全部出口，也不能证明哈希序列化与 trail 栈之间的集成行为。
