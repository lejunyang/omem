# 知识文章来源绑定的保守刷新

该模块为知识文章提供一条严格受限的来源绑定刷新路径：先记录材料与引用范围的指纹，再在当前材料中唯一重定位未变的证据片段。任何来源身份、语法、锚点或背景依赖无法确认的情况都会放弃自动刷新；成功结果是供后续复核的新稿提案，旧引用不会被重定向。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决材料换版后的行号漂移

知识文章的引用保存了材料行号。原件前部插入空行或注释后，证据内容可能未变，原行号却已经失效。这个模块为此生成一份**新的绑定提案**，旧引用仍指向原版本，紧凑哈希也不能用来重建旧原文。参考 [新提案与旧引用边界 ↗](../../../apps/server/src/knowledge/source-refresh.ts#L1 "支持刷新会生成新成果、不会重定向旧引用，并说明哈希不能重建旧来源。")

协议分两步。`sourceFootprints` 汇总正文材料引用和章节 `reviewSources`，为每份仍可取得的材料保存版本摘要、修订号、元数据摘要和语法摘要，同时记录每个引用及背景范围的结构锚点。参考 [来源足迹采集 ↗](../../../apps/server/src/knowledge/source-refresh.ts#L31 "支持来源足迹覆盖正文材料引用与章节背景范围，并记录材料及各范围指纹。") 锚点选择能包住目标范围的最小材料章节，并保存章节标题、结构类型、整段哈希，以及目标范围在其中的偏移、长度和自身哈希。参考 [结构锚点组成 ↗](../../../apps/server/src/knowledge/source-refresh.ts#L23 "支持最小包围结构的选择方式，以及标题、类型、整段哈希、偏移、长度和范围哈希的保存。")

<a id="flow"></a>
## 一次可安全迁移的调用

代表性输入是一篇旧 `KnowledgeArticle` 和当前 `Map<string, KnowledgeMaterial>`：某个 TypeScript 材料只在目标函数之前增加了空行，导致材料摘要及行号变化；材料身份字段、AST 叶子序列和被引函数正文保持不变。`refreshSourceBindings` 读取旧稿 `generation.trace.sourceFootprints`，克隆文档后逐项检查依赖。缺少足迹、材料已丢失、元数据变化、解析失败或语法摘要变化，都会直接返回 `null`。未被依赖记录覆盖的调查材料一旦变化，也回到普通调查流程。参考 [刷新资格检查 ↗](../../../apps/server/src/knowledge/source-refresh.ts#L42 "支持缺失足迹、变化的未绑定调查材料、来源缺失、元数据或语法不一致时返回 null 的行为。")

```mermaid
flowchart LR
  A[旧文章与当前材料表] --> B[校验足迹、元数据与语法]
  B --> C[按结构锚点唯一定位]
  C --> D[更新引用和背景范围]
  D --> E[重绑摘录并返回新稿提案]
```

定位阶段要求新版中恰好存在一个同标题、同类型且整段哈希相同的结构，再用旧偏移计算新行号，并复核目标范围哈希；零个或多个匹配都失败。参考 [唯一锚点重定位 ↗](../../../apps/server/src/knowledge/source-refresh.ts#L60 "支持按标题、结构类型和整段哈希唯一匹配，再校验范围边界与范围哈希的定位过程。") 成功后，代码更新正文引用和 `reviewSources` 的行范围，汇总受影响的引用、章节及新旧版本绑定，重新填充引用摘录，输出新文档与旧文章修订号。参考 [更新与返回结果 ↗](../../../apps/server/src/knowledge/source-refresh.ts#L67 "支持引用和背景范围更新、变更汇总、摘录重绑及最终返回字段。")

<a id="boundaries"></a>
## 保守条件与模块协作

自动路径只覆盖路径或标题呈现 JS/TS 扩展名、没有图片且能被 TypeScript 解析的材料。语法摘要遍历 AST 叶子并排除 JSDoc 节点；它只用于判定是否具备迁移资格，不能证明语义已经获准。元数据摘要还纳入标题、路径、命名空间、参与者与消息来源属性等身份信息。参考 [元数据与语法摘要 ↗](../../../apps/server/src/knowledge/source-refresh.ts#L9 "支持自动路径适用的文件类型、无图片与可解析条件，以及元数据字段和 AST 叶子摘要算法。")

刷新采用全有或全无策略。任一依赖无法找到唯一锚点，函数就返回 `null`；所有依赖都未变化时也不会制造空提案。结构内部的文本改动会改变整段或范围哈希，因此即使语法摘要相同，也可能无法自动迁移。参考 [刷新资格检查 ↗](../../../apps/server/src/knowledge/source-refresh.ts#L42 "支持缺失足迹、变化的未绑定调查材料、来源缺失、元数据或语法不一致时返回 null 的行为。") [唯一锚点重定位 ↗](../../../apps/server/src/knowledge/source-refresh.ts#L60 "支持按标题、结构类型和整段哈希唯一匹配，再校验范围边界与范围哈希的定位过程。")

本文件通过 `materialSections` 获取可定位结构，借助 `stableDigest` 生成比较用摘要，最后调用 `bindKnowledgeQuotes` 给克隆文档重新绑定摘录；类型则来自知识合同和仓储模块。这里能确认这些协作点及调用顺序，无法从当前授权材料确认外部入口由谁触发，也无法展开三个被调函数的内部实现。参考 [更新与返回结果 ↗](../../../apps/server/src/knowledge/source-refresh.ts#L67 "支持引用和背景范围更新、变更汇总、摘录重绑及最终返回字段。")
