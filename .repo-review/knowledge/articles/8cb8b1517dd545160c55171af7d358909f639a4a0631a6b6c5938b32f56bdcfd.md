# Web 应用包配置

该配置定义私有的 ESM Web 工作区包，使用 Vite 提供开发与构建命令，依赖 Vue 3、共享 UI 包以及 Markdown 渲染、代码高亮、内容净化和二维码组件。依赖声明反映可用技术组件，不等同于相关功能已被实际调用或完整实现。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="package-runtime"></a>
## 包属性与运行方式

包名为 `@omem/web`、版本为 `0.1.0`，设置 `private: true` 与 `type: module`，表明它是工作区内部使用的 ESM 应用包，而非从这份配置直接发布的公共包。脚本仅包含绑定 `127.0.0.1` 的 Vite 开发服务和生产构建；材料没有列出独立的测试、类型检查或预览脚本。[包元数据与 Vite 脚本 ↗](../../../apps/web/package.json#L1 "支持工作区私有 ESM 包、开发服务绑定地址、构建命令以及未声明测试和类型检查脚本的判断。")

<a id="dependency-roles"></a>
## 前端依赖及能力边界

运行依赖以 Vue 3 为框架，并通过 `workspace:*` 复用 `@omem/ui`。`marked`、`highlight.js` 与 `dompurify` 组合上可支持 Markdown 解析、代码高亮及 HTML 净化，`qrcode.vue` 可用于二维码展示。这里能确认的是依赖可用性，而不是调用事实；是否安全配置净化策略、是否真正渲染 Markdown 或二维码，仍需组件源码和测试佐证。[Web 运行依赖清单 ↗](../../../apps/web/package.json#L10 "支持对 Vue、共享 UI、Markdown、代码高亮、内容净化和二维码依赖角色的分析，同时不把依赖声明误述为实现事实。")
