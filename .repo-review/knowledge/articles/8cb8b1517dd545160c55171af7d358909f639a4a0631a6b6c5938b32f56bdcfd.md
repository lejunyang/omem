# Web 前端的运行脚本与依赖配置

该清单定义 @omem/web 为私有 ESM 工作区包，提供基于 Vite 的开发和构建入口，并声明 Vue、共享 UI、Markdown 渲染、代码高亮、内容净化、文本差异与二维码等前端依赖。它能说明 Web 包具备哪些配置基础，但不能单独证明各项能力已在界面中完整实现。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="package-runtime"></a>
## 包定位与运行入口

该文件把 Web 前端登记为私有的 `@omem/web` 包，版本为 0.1.0，并采用 ESM 模块格式。开发入口使用 Vite 且仅监听 `127.0.0.1`，构建入口同样交给 Vite；因此它描述的是本地开发和产物构建的基础方式，而非部署、鉴权或服务端运行方案。参考 [Web 包运行配置 ↗](../../../apps/web/package.json#L2 "支持该包的名称、私有属性、ESM 类型以及 Vite 开发和构建入口等配置事实。")

## 界面能力的依赖基础
