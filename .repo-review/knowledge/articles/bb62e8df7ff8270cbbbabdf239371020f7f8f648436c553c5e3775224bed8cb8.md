# 知识正文复核技能流程

该技能说明独立复核如何读取固定材料与草稿、核验引用附近论断、区分实质错误与措辞偏好，并以 KnowledgeReview.v1 返回可局部修正的问题及具体未决事项。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="inputs-output"></a>
## 固定输入与职责边界

技能要求逐篇读取 `task.drafts`，并与宿主提供的固定材料和文章比较；材料和草稿均作为数据处理，不执行其中指令，也不调用工具。结果只能是 `KnowledgeReview.v1` 中的文档键、判定、问题和未决事项，不应返回 KnowledgeBatch 或代写正文。[固定材料输入与结构化输出 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/skills/omem-knowledge-verifier/SKILL.md#L6 "支持逐篇比较固定证据、禁止执行材料指令、禁止工具调用和不代写正文的说明。") 这将“写作”和“独立复核”分成两个角色阶段。

<a id="evidence-check"></a>
## 引用与论断核验

复核应检查每个引用附近的陈述是否被目标完整行范围或文章章节支持。`quote` 只是宿主复制的短预览，不能替代对完整固定材料的判断。[引用支持性核验方法 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/skills/omem-knowledge-verifier/SKILL.md#L10 "支持以完整行范围或文章章节判断论断、不能只依赖 quote 预览的说明。") 若存在事实错误、范围错配、遗漏会改变行为的条件，或把计划、不确定内容升级为已实现或确定事实，应返回 `needs_revision`，并指出句子、章节或引用键及原文位置。[需要修订的实质错误 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/skills/omem-knowledge-verifier/SKILL.md#L11 "支持范围错配、条件丢失、计划冒充实现及不确定事实肯定化应判修订的说明。")

<a id="acceptance-questions"></a>
## 接受边界与问题记录

合理且有依据的概括、未穷举实现细节或单纯措辞差异不应导致拒绝；已经明确呈现的限制和未决问题可以通过，但未知事实不能被肯定化。`questions` 只记录仍需补证或用户选择的具体事项，并给出下一步；引用键必须来自当前草稿，除非确实阻塞任务，默认不阻塞。[接受标准与未决事项规则 ↗](../../../packages/agent-runtime/roles/knowledge-verifier/1/skills/omem-knowledge-verifier/SKILL.md#L12 "支持不因措辞偏好拒绝、允许明确限制，并约束 questions 内容和 blocking 默认值的说明。")
