# 知识生成流水线的发布、恢复与失效测试

这组测试用临时 SQLite 存储和模拟角色运行时，验证知识从原始材料分析、独立复核到发布的关键约束，并覆盖拒绝后续跑、输入变化防护、材料类型分派、依赖隔离、章节合成及递归失效。它证明的是流水线编排与持久化行为，不代表真实 Agent CLI、模型质量或并发执行已被端到端验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="fixture-and-publish"></a>
## 从固定证据到复核后发布

测试夹具创建隔离的临时数据库，捕获一条用户笔记，并把角色网关替换为可控制“接受、拒绝、运行中改源”的模拟实现；因此测试能稳定观察生成者与复核者的调用顺序、输出和 trace，而不会启动真实模型。参考 [隔离夹具与模拟角色 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L14 "说明测试如何创建临时存储、捕获原文并模拟生成与复核角色，也支持这些用例不调用真实模型的边界判断。")

主场景要求分析无失败、生成与独立复核各运行一次，并确认引用中的空 `quote` 最终被绑定为原文。生成与复核必须具有不同会话，同时删除知识投影后再次分析不得重复调用角色，而应从耐久输出恢复同一修订；此外还检查捕获任务保持在既定队列状态。参考 [复核后发布与耐久恢复 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L39 "支持独立复核、引用原文绑定、会话隔离以及投影丢失后复用既有输出的断言。")

<a id="rejection-routing"></a>
## 拒绝恢复、输入竞争与分析角色选择

当复核给出语义拒绝时，草稿不能晋升为当前知识；若分析期间同一来源产生新修订，则以 `KNOWLEDGE_INPUT_CHANGED` 失败，避免把基于旧输入的结果发布。拒绝原因解除后再次分析，应由刷新角色携带先前草稿与审阅反馈继续，而不是丢失修订上下文。参考 [拒绝与输入变化防护 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L53 "支持拒绝结果不发布、运行中源变化会失败，以及后续通过刷新角色携带旧草稿恢复的行为。")

材料分派测试区分普通 Lark 文档与带会话标识的 Lark 对话，并把 Git 或文件来源中具有常见代码扩展名的标题识别为代码材料。该断言与流水线中的实际选择规则一致：图片优先走视觉分析，对话命名空间走会话分析，其余再按路径或标题扩展名选择代码分析。参考 [材料分析角色断言 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L73 "支持 Lark 文档、Lark 会话以及普通导入代码被分派到不同分析角色的测试结论。")，[分析角色选择规则 ↗](../../../apps/server/src/knowledge/pipeline.ts#L15 "给出被测试的实际角色选择条件，说明图片、对话和代码扩展名的优先分派关系。")

<a id="dependencies-and-synthesis"></a>
## 依赖隔离与分层合成

兄弟文章默认只依赖各自来源：第一条材料更新后，另一篇文章仍保持当前修订。只有调用方显式提供背景材料，目标文章才记录该额外依赖，并在背景材料变化后失效，说明失效传播由已记录依赖驱动。参考 [兄弟文章与显式背景依赖 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L81 "支持兄弟文章默认隔离、显式背景被记录为依赖，以及背景变化触发目标文章失效。")

章节合成还验证两类行为：当完整固定原文可容纳时，合成器能够引用新增行并绑定精确文本；被拒绝的合成章节也能从匹配的已审阅草稿恢复。参考 [固定原文与合成恢复 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L101 "支持合成阶段可引用新增原文行，并在语义拒绝后从匹配草稿继续生成。")

更高层概览以已复核文章作为派生背景，不展开其深层原文尾部，并继续由独立复核角色检查；概览记录文章依赖，底层来源变化后会递归变为非当前状态。这里没有覆盖真实 Agent CLI、真实模型语义表现、并发大于 1、重试耗尽、停机过程或图片材料路径，因为网关完全被模拟且夹具把并发固定为 1。参考 [分层文章合成与递归失效 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L123 "支持上层合成不展开深层原文、以派生文章作为背景、再次独立复核并保留失效传播；同一范围也显示夹具使用模拟网关，支撑未覆盖真实模型的说明。")
