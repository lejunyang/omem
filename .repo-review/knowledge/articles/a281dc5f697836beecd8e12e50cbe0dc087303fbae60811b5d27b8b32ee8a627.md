# 知识流水线的生成、复核、恢复与合成测试

以受控角色运行结果验证知识必须经过独立复核，拒绝与输入变化不会发布，并覆盖恢复、角色选择、章节合成和依赖失效传播。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="fixture-contract"></a>
## 受控角色与流水线夹具

夹具建立手工固定材料、知识仓库、角色注册表和运行网关，并用模拟角色输出区分分析或刷新与独立复核；每次运行产生不同会话标识，流水线并发度固定为一。[知识流水线测试夹具 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L14 "支持固定材料、角色网关、生成与复核输出以及独立会话跟踪的测试设置。") 这验证宿主编排和数据合同，不代表外部 Agent CLI 的现场可用性。

<a id="review-safety"></a>
## 发布门槛与可恢复失败

正常分析需要生成与复核两次角色调用，宿主绑定精确原文，且两阶段会话不同；投影头丢失后可复用耐久成果而不重复调用模型。[复核后发布与耐久复用 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L39 "支持两阶段独立会话、精确引文绑定及投影丢失后的结果复用。") 语义复核拒绝或分析期间来源变化都不会提升文章；拒绝任务再次运行时会把原草稿与反馈交给刷新角色，通过后才发布。[拒绝、过期与刷新恢复 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L53 "支持拒绝或输入变化不发布，并在重试时传入原草稿和复核反馈。")

<a id="routing-synthesis"></a>
## 角色路由与章节合成

角色选择区分 Lark 文档与会话，并把常见 Git 或文件代码交给代码分析角色。[材料分析角色路由 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L73 "支持按 Lark 会话属性及普通代码来源选择不同分析角色。") 合成时，在材料大小允许时提供完整固定来源，使新章节可引用先前未用的具体行；被拒章节再次合成也从匹配草稿交给刷新角色。[完整来源合成与章节刷新 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L81 "支持合成引用新增固定行，以及拒绝章节从匹配草稿恢复后重新发布。")

<a id="derived-knowledge"></a>
## 派生知识的边界与失效传播

上层概览以已复核章节作为派生上下文，不展开其深层原文尾部，并明确标注派生知识不是独立证据；发布结果记录文章依赖且仍经独立复核。底层原始材料变化后，上层概览随依赖链变为非当前状态。[派生章节组合与依赖失效 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L103 "支持上层仅接收派生文章上下文、记录文章依赖、独立复核及底层变更后的失效传播。")
