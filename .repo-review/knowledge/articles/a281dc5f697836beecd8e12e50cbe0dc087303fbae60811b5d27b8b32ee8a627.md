# 知识生成流水线的发布、恢复与失效测试

该测试以临时 SQLite、真实知识仓库和模拟角色网关验证知识生成流水线的核心编排与持久化：独立复核是发布门槛，输入变化与语义拒绝会阻止提升，拒绝后可切换刷新角色续跑，并覆盖角色分派、依赖隔离、分层合成和递归失效。由于模型结果、trace 与会话均由 fixture 构造，它不等同于真实 Agent CLI/ACP 联调或完整故障验收。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="fixtureBoundary"></a>
## 测试装置与角色分派边界

`setup` 为每个用例创建临时 SQLite、固定文本材料、真实仓库与流水线，但把角色网关替换为可切换接受、拒绝和运行中改源的 mock；生成结果仍经过输出校验，并附带 fixture 构造的 trace。因此这里能检验编排和持久化，不能证明真实 ACP、模型能力发现或外部进程可用。[临时仓库与模拟角色运行装置 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L12 "支持测试使用临时 SQLite、文本材料、并发 1 和模拟网关构造结果及 trace，也界定其不启动真实外部运行。")

角色分派用例确认：普通 Lark 文档走材料分析，带会话标识的 Lark 内容走对话分析，Git/File 中列举的 TypeScript 与 Python 文件走代码分析。[材料分析角色选择断言 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L73 "支持普通 Lark 文档、Lark 会话及列举的 Git/File 代码文件采用不同分析角色。") 图片优先级虽存在于实现分支，但不在该用例的行为覆盖内。[流水线上下文与停止分支 ↗](../../../apps/server/src/knowledge/pipeline.ts#L15 "说明停止检查、文本按行分块、图片资产读取、固定材料要求及图片优先角色选择等实现路径，用于界定测试遗漏。")

<a id="publishAndResume"></a>
## 发布门槛、耐久复用与拒绝恢复

成功路径明确断言生成与独立复核共调用两次、引用绑定固定原文、两阶段会话不同；删除知识 head 投影后重跑不会再次调用角色，并恢复同一 revision。捕获作业仍为 queued，也说明知识发布未把其他队列入列误认为应用完成。[独立复核发布与耐久输出复用 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L39 "支持两次角色调用、固定原文绑定、会话隔离、queued 作业状态以及投影丢失后的 revision 复用。") 语义拒绝或分析中来源变化都会阻止文章进入仓库，后者返回 `KNOWLEDGE_INPUT_CHANGED`。[拒绝与输入变化阻止发布 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L53 "支持语义拒绝和分析期间来源变化均不会提升知识成果。")

拒绝解除后，材料分析会改用 `knowledge-refresher`，任务具有 `revisionRequest.previousDrafts`，最终产生文章；但现有断言只检查字段存在，没有逐字段比较旧草稿或 verifier 反馈。[材料分析拒绝后的刷新续跑 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L62 "支持续跑切换为知识刷新角色、任务存在 previousDrafts 字段及最终生成文章，同时界定断言未比较字段内容。") 合成章节的恢复也只确认刷新角色与最终 current 状态，尚未证明被拒绝草稿及反馈完整续接。[合成章节拒绝后的恢复 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L110 "支持合成失败后再次运行使用知识刷新角色并恢复 current 结果，也显示该段未断言旧草稿和反馈内容。")

<a id="dependencyAndSynthesis"></a>
## 依赖隔离、合成上下文与递归失效

兄弟文章默认只依赖各自原始材料：一条来源更新不会使另一篇文章失效或改变其 revision。只有显式提供背景材料后才形成跨材料依赖，背景变化随后会让依赖文章过期。[兄弟文章隔离与显式背景依赖 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L81 "支持默认依赖隔离、显式增加背景依赖以及背景变化触发失效。")

当固定原文可完整进入合成上下文时，模块文章能够引用下层文章未使用的新行，并由宿主绑定准确行号与原文。[合成阶段引用新的固定原文行 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L101 "支持合成获得完整固定来源并生成、绑定第二行精确引用。") 更高层 overview 接收已复核章节，标明它们是派生知识而非独立证据，不展开深层原文；同时保留文章依赖、再次调用 verifier，并在底层来源变化后递归变为非 current。[分层合成与递归失效 ↗](../../../apps/server/tests/knowledge-pipeline.test.ts#L123 "支持上层组合已复核文章、不展开深层原文、记录文章依赖、调用 verifier 并在底层变化后递归失效。")
