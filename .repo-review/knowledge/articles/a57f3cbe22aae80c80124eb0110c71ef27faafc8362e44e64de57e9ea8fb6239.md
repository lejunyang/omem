# 仓库增量同步与关系重建主流程

限定范围扫描仓库并捕获不可变文件修订，维护 Git 增量基线与删除状态，再从人工 association seed 构建两级关系链；正则切片、普通方法定位、全量 seed 移除和关系异常处理均有明确限制。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="scan"></a>
## 扫描范围与正则切片

常规扫描只遍历 apps、packages、docs、scripts 和少量根文件，并排除依赖目录、构建产物、运行目录、私有环境文件及测试 fixture。遍历会跳过符号链接和不安全根；只有路径进入实际捕获后，不可读、越界链接、超限或非 UTF-8 才记录为文件失败。[扫描候选与显式捕获失败 ↗](../../../apps/server/src/review/sync.ts#L94 "支持固定扫描根、排除规则、符号链接跳过以及捕获阶段才记录读取失败的区别。")

代码切片依据允许前导空白的行首声明正则，并不验证声明位于语法树顶层；测试用例边界只适用于 `apps/server/tests/` 下以 `.test.ts` 结尾的文件，其他测试文件仍按普通代码切片。先前“按顶层声明、测试统一按用例入口切片”的概括已被这些实现范围替代。Markdown 则按标题行切片。[代码、测试与文档切片规则 ↗](../../../apps/server/src/review/sync.ts#L210 "支持行首声明正则，并明确测试专用切片仅适用于指定目录下的 `.test.ts` 文件。")

<a id="capture"></a>
## 修订捕获与增量基线

每个文件以 `omem:<path>` 为来源身份，内容摘要用于避免重复修订；捕获记录 commit、dirty、摘要、同步时间、分类，以及有限的符号列表或文档中明确出现的决策日期。相同摘要不会因 syncedAt 改变而重复写入。[单文件不可变修订捕获 ↗](../../../apps/server/src/review/sync.ts#L399 "支持摘要判重、快照上下文、切片选择及通过共享 Store 保存修订的流程。")

完整流程综合 HEAD、上次基线、工作树状态和数据库身份选择增量或全量扫描。Git 调用或基线验证失败会退化为全量；首次运行、数据库不匹配或上次同步为 dirty 也会全扫。工作树脏或存在文件失败时仍保存结果，但不推进基线。[Git 增量选择与基线推进 ↗](../../../apps/server/src/review/sync.ts#L838 "支持数据库身份、dirty 状态、Git 失败降级、全量扫描条件及失败时不推进基线。")

<a id="relations"></a>
## 人工 seed 驱动的关系链及定位限制

关系只由人工 associations 建立。符号定位先匹配有限形式的声明；方法优先匹配仅覆盖带 private、public、protected、async、readonly、static 或 override 修饰符的形式。普通 `foo()` 方法不会被该分支识别，可能直接落入最早同名 token 的回退，因此不能把方法命中概括为可靠的定义优先或 AST 级定位。文档锚点解析失败时保存 missing，不用语义相似度补边。[符号与材料引用解析 ↗](../../../apps/server/src/review/sync.ts#L564 "支持有限声明和带修饰符方法的优先匹配、同名 token 回退及文档锚点解析限制。")

每条 association 生成一个 derived、curated 的虚拟意图片段，再建立“代码 implements 意图”和“意图关联需求、决策、调研、测试”的两级链。构建末尾调用 seed 失效函数，但当 seed 集合为空时该函数不会更新任何旧边；因此仅能确认部分移除时会失效不再存在的 association，不能声称移除全部 seed 也会自动将旧边标为 stale。[两级关系构建与 seed 失效调用 ↗](../../../apps/server/src/review/sync.ts#L682 "支持派生意图索引、两级边结构、稳定 seed identity，以及构建结束时调用失效函数的实际范围。")

<a id="limits"></a>
## 部分同步与关系失败语义

`only` 模式只处理显式路径，不更新磁盘同步状态，也不重建关系，适合定向捕获而非完整验收。完整同步才协调来源、重建关系并持久化状态；然而关系构建异常只写入 warnings，不增加文件失败计数，也不阻止同步状态落盘。因此“同步完成”不等于关系链完整成功，上层必须显式检查 warnings 或关系统计。[关系重建与同步状态落盘 ↗](../../../apps/server/src/review/sync.ts#L997 "支持 only 模式跳过关系重建，并证明完整同步中的关系异常仅进入 warnings、不会阻止状态持久化。")
