# 变更历史的筛选、差异查看与版本操作

该页面集中呈现材料、知识和事项等变更，支持按类型筛选、按需比较固定版本，并仅为材料捕获与恢复记录提供阅读和恢复入口；历史获取与实际恢复由上层负责。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-presentation"></a>
## 集中查看发生过什么变化

页面接收变更列表，将材料捕获、知识、恢复、事项、判断、问答和引用等类型映射为中文名称，并按用户选择的类型过滤记录。它还为首次保存、材料更新以及缺少正文关联的旧知识记录生成更明确的摘要，帮助用户快速判断变化性质。参考 [变更筛选与摘要规则 ↗](../../../apps/web/src/ChangeHistory.vue#L6 "支持页面接收变更列表、按类型过滤，并为特定材料与知识记录生成用户可读摘要。")

列表展示标题、时间、类型和摘要，并说明只保留最近 200 条记录。筛选下拉框根据实际数据动态生成选项，未知类型在选项中显示为“其他变化”，但在记录标签中显示为“变化”；没有匹配项时显示空状态。参考 [历史列表展示规则 ↗](../../../apps/web/src/ChangeHistory.vue#L20 "支持最近记录说明、动态筛选、未知类型在筛选项与记录标签中的不同文案，以及空状态行为。")

<a id="lazy-comparison"></a>
## 展开后再读取固定版本差异

只有记录存在更新后版本，且类型属于材料、恢复或知识时，页面才提供差异入口。用户首次展开记录后才挂载比较组件，避免列表初始加载时为每条历史立即读取正文。参考 [按需展开差异 ↗](../../../apps/web/src/ChangeHistory.vue#L26 "支持差异入口仅面向具有更新后版本的材料、恢复和知识记录，并在展开后才挂载比较组件。")

比较组件按变更标识请求固定版本，切换记录时先清空旧内容和错误，再以三行上下文生成前后正文补丁。参考 [固定版本差异计算 ↗](../../../apps/web/src/ChangeComparison.vue#L9 "支持按变更标识请求内容、切换时重置状态，并以三行上下文生成结构化补丁。") 页面分别处理读取中、请求失败、版本关联不完整、无文字差异和逐块增删展示；无文字差异仍可能意味着复核或来源记录发生变化。参考 [差异展示状态 ↗](../../../apps/web/src/ChangeComparison.vue#L17 "支持读取、错误、关联缺失、无文字差异及补丁增删块等界面状态。")

<a id="boundaries-and-relations"></a>
## 阅读与恢复操作的组件边界

阅读和恢复按钮只面向 `capture` 与 `restore` 类型：存在更新后版本时可发出 `open`，同时存在前后版本时可发出 `restore`。因此，即使知识记录具有更新后版本，也只能查看差异，不会出现阅读或恢复按钮。组件仅向父级传递版本标识或完整变更对象，实际导航、恢复请求及创建新版本的流程不在当前材料中。参考 [材料版本操作条件 ↗](../../../apps/web/src/ChangeHistory.vue#L29 "支持阅读与恢复按钮仅限材料捕获和恢复类型，以及两个事件各自所需的版本关联条件。")

页面使用的 `Change` 类型由前端 API 模块从共享 contracts 重新导出，从而与其他调用方沿用同一数据合同；但现有材料未展示历史列表的获取、权限控制及浏览器测试。参考 [共享变更类型入口 ↗](../../../apps/web/src/api.ts#L1 "支持 Change 类型来自共享 contracts，并经前端 API 模块重新导出的依赖关系。")
