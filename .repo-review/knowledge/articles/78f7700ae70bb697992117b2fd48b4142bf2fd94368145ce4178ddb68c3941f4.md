# 从材料选择到文章整理任务

该组件提供两步式文章整理对话框：先筛选并选择材料，再填写主题、阅读目标和读者，最后向知识服务提交解释型文章任务。它处理步骤导航、焦点定位、提交反馈和窄屏布局；服务端校验、权限与幂等策略不在当前材料范围内。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 为文章确定材料与阅读目的

组件用于把已有文档、代码或记录整理成面向具体问题的文章。第一步可按标题或路径搜索，也可只看已选材料；筛选条件变化时，展示上限会恢复为 40 项。参考 [材料筛选与展示上限 ↗](../../../apps/web/src/knowledge/ArticleComposer.vue#L40 "支持按标题或路径筛选、只看已选材料，以及筛选变化后将展示上限恢复为 40 项的说明。")

若候选项超过上限，用户可每次继续显示 40 项；界面同时明确提示材料可跨分类选择。参考 [继续显示与跨分类提示 ↗](../../../apps/web/src/knowledge/ArticleComposer.vue#L161 "支持每次增加 40 个候选项以及界面提示可跨分类选择。")

第二步填写文章主题、想弄懂的问题和目标读者，三个字段均为必填；主题与读者最多 240 字，目标最多 1600 字。只有已选择材料且外部没有整理任务运行时，才能进入第二步或提交。参考 [阅读目标表单约束 ↗](../../../apps/web/src/knowledge/ArticleComposer.vue#L183 "支持主题、目标与读者字段的必填状态和最大长度。") [步骤与提交按钮条件 ↗](../../../apps/web/src/knowledge/ArticleComposer.vue#L226 "支持必须选择材料、外部任务运行时禁用下一步和提交按钮，以及发送期间禁用返回操作的交互约束。")

<a id="workflow"></a>
## 从分步填写到创建任务

切换步骤后，对话框会滚动到顶部并聚焦当前步骤的主要输入框；每次重新打开时都从材料选择开始。参考 [步骤焦点与重新打开 ↗](../../../apps/web/src/knowledge/ArticleComposer.vue#L31 "支持步骤切换后的滚动和焦点定位，以及重新打开时回到第一步。")

提交时，组件把所选材料的 `revisionId` 与文章 brief 发送到 `/pages`。brief 包含随机文章键、解释型文章标记、主题、读者和目标；目标也作为场景与问题写入，已有主题路径仅在非空时附加。成功后会清空材料选择、主题、目标、筛选词和“只看已选”状态，再通知父级刷新并关闭；`reader` 不会在此分支重置，发送状态则在请求结束后解除。失败时保留输入并显示错误。参考 [文章任务提交与成功清理 ↗](../../../apps/web/src/knowledge/ArticleComposer.vue#L58 "支持请求载荷结构、成功后实际清理的字段、父级事件通知、失败提示和发送状态解除。")

请求通过共享接口发出：它按需加入 JSON 请求头，从会话存储读取令牌，并将非成功响应转换为可展示的错误。参考 [知识接口请求封装 ↗](../../../apps/web/src/knowledge/api.ts#L6 "支持令牌、JSON 请求头、请求地址拼接及非成功响应处理的说明。")

<a id="boundaries"></a>
## 关闭行为、适配范围与未知边界

取消、对话框关闭或返回操作只向父级发出关闭事件，不会主动清空已填写内容；再次打开仅把步骤重置为第一步。因此，未提交内容仍可能保留在组件实例中。参考 [关闭与取消行为 ↗](../../../apps/web/src/knowledge/ArticleComposer.vue#L95 "支持对话框关闭、返回和取消仅发出 close 事件；结合重新打开逻辑说明未提交字段不会被主动清空。")

材料以 `revisionId` 作为勾选值，同名材料的不同修订可以分别选择；搜索范围仅包含标题和可选路径，不读取正文。窄屏下，界面会缩小标题字号与材料项内边距，将材料列表高度限制为视口高度的 42%，并收紧操作区间距。参考 [材料筛选与展示上限 ↗](../../../apps/web/src/knowledge/ArticleComposer.vue#L40 "支持按标题或路径筛选、只看已选材料，以及筛选变化后将展示上限恢复为 40 项的说明。") [窄屏布局调整 ↗](../../../apps/web/src/knowledge/ArticleComposer.vue#L449 "支持窄屏下标题字号、材料项内边距、列表高度和操作区间距的具体变化。")

当前材料只覆盖客户端交互与请求封装，无法据此确认服务端是否复核材料有效性、访问权限，或如何处理重复请求。

<a id="module_relation"></a>
## 与父级和知识服务的关系

父级向组件提供打开状态、接口前缀、候选材料、主题路径和任务运行状态；组件只通过 `submitted` 与 `close` 事件交回刷新和关闭决定。参考 [父级输入与组件事件 ↗](../../../apps/web/src/knowledge/ArticleComposer.vue#L11 "支持组件依赖的父级属性以及提交、关闭事件边界。")

组件负责收集与发送整理意图，真正的文章生成、复核和入库发生在 `/pages` 请求之后，不属于本组件可证明的职责范围。参考 [文章任务提交与成功清理 ↗](../../../apps/web/src/knowledge/ArticleComposer.vue#L58 "支持请求载荷结构、成功后实际清理的字段、父级事件通知、失败提示和发送状态解除。")
