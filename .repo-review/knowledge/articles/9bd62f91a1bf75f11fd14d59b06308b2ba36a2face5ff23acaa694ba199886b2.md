# 提炼角色运行清单示例

描述 extractor 角色所使用的 profile、提示模板、内联 skill、输出合同、工具与会话隔离策略以及上下文和修复预算，是可复现角色包的配置示例。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="bundle"></a>
## 角色与产物约束

清单把角色标识为 extractor@1，并引用 traex profile、公共与提炼专用提示模板，以及版本化的 omem-extract 内联 skill；输出必须符合 ProposalBatch.v1。[角色包组成与输出合同 ↗](../../../docs/implementation/batch2/examples/role-manifest.json#L1 "支持角色版本、profile、提示模板、skill bundle 和输出 Schema 的说明。") skill 的 artifact_digest 仍写为待构建解析占位符，因此这份文件更像构建输入或示例，不能直接证明已生成可验证的不可变运行包。

<a id="isolation_budget"></a>
## 隔离和预算

角色禁止使用工具，且不允许继承用户 skills 或 MCP；每次运行不复用 session，用于降低外部状态、个人配置和历史对话对提炼结果的隐式影响。[工具与会话隔离策略 ↗](../../../docs/implementation/batch2/examples/role-manifest.json#L19 "支持无工具、永不复用会话及不继承用户扩展的说明。") 预算限制为 8000 个上下文 token、3000 个输出 token和最多两次修复，体现失败应受控重试，而不是无限扩大上下文或反复修正。[角色运行预算 ↗](../../../docs/implementation/batch2/examples/role-manifest.json#L28 "支持上下文、输出和修复次数上限的说明。")
