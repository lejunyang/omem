# 首轮设计与离线原型验证记录

本文记录的是 2026-09-26 对设计材料和离线 React 原型的验证，并非当前 Vue 产品的验收报告。原型交互覆盖仍可作为历史证据，但“真实模型与服务端尚未部署”已被后续实现替代；真实外部集成、兼容性、无障碍和长期性能等事项仍需逐项核验。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="historical-scope"></a>
## 验证对象与历史定位

本文把验证对象限定为第一轮架构材料与离线交互原型，并明确当时开源引擎、真实模型和服务端尚未部署。[首轮验证范围声明 ↗](../../../docs/validation.md#L1 "支持本文针对旧设计与离线原型、并非当前运行代码，以及服务端尚未部署属于当时状态的判断。") 当轮实际执行了材料与上游仓库核验、自包含 React 原型构建、三类视口的 Chromium 检查、人工视觉检查及静态一致性检查。[首轮已执行检查 ↗](../../../docs/validation.md#L7 "说明材料核验、原型构建、浏览器检查、人工视觉检查和静态一致性检查的实际范围。") 因此，这些结果证明早期方案和原型经过检查，却不能直接证明后来 Vue、API、SQLite 或外部连接器的生产行为。

<a id="prototype-coverage"></a>
## 原型交互覆盖与原有限制

浏览器检查覆盖多层与循环引用、历史版本不重定向、弹窗追问、原文圈选、滚动和焦点恢复、权限异常、搜索、同步演示及手机布局，并记录零脚本异常和零外部请求。[原型浏览器覆盖 ↗](../../../docs/validation.md#L16 "支持引用链、追问、焦点恢复、异常状态、搜索、同步演示和多视口等原型交互覆盖。") 首轮同时明确排除了真实引用准确率、中文召回、幻觉率、真实连接器、团队 ACL、灾备、完整无障碍审计、Safari/Firefox 兼容及长期海量路径性能等验证；原型中的“可点击”不能视为生产能力。[首轮未验证事项 ↗](../../../docs/validation.md#L45 "限定真实质量、外部集成、团队能力、兼容性、长期性能和后端工作流未被首轮原型验证的范围。")

<a id="superseded-status"></a>
## 被替代结论与当前证据

“真实模型与服务端尚未部署”已经被后续状态替代：复审记录显示完整检查、真实浏览器流程、隔离数据库重建和限定范围的真实模型生成已经完成；但独立语义核验、跨文件调用等能力仍未交付。[后续复审与实现验证 ↗](../../../docs/implementation/status.md#L7 "支持后续完整检查、真实浏览器、数据库重建和真实模型生成已有进展，同时指出独立语义核验与跨文件调用仍未完成。") 通用知识流程也已实现持久分析、独立复核、知识服务接口和仓库材料适配，并明确区分协议 fixture 与真实模型覆盖。[通用知识流程与服务接口 ↗](../../../docs/implementation/knowledge-pipeline.md#L23 "支持持久分析、独立复核、知识 API、仓库材料适配和协议 fixture 边界已经实现。") 正文内联引用阅读则由后续共用 Vue 组件与真实浏览器流程单独验证，不能归因于仅描述服务流程的记录。[正文内联引用阅读验收 ↗](../../../docs/implementation/knowledge-pipeline.md#L45 "直接支持个人知识与仓库知识共用引用阅读组件，以及五层链、深链、焦点和多视口浏览器验证。")

首轮未验证清单仍不能整体宣告完成。当前材料明确指出真实 ACP 主助手、真实飞书 WebSocket、进程级 kill/restart、语义检索和下游自动重核验仍存在 live 或实现缺口。[当前 live 验证与实现缺口 ↗](../../../docs/implementation/status.md#L90 "支持真实 ACP、真实飞书、进程级重启、语义检索、跨文件调用和下游重核验仍有明确限制。") 因而应以当前实施状态为准逐项标记“已替代、仍缺失或不再适用”，而不是用后续自动化测试笼统覆盖首轮全部退出条件。
