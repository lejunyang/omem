# TypeScript 根配置

该文件是一个轻量入口配置：继承服务端 TypeScript 配置，并在根级检查中明确禁止生成编译产物。它主要复用统一规则，而不是独立定义完整编译环境。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role"></a>
## 配置作用

该配置通过 `extends` 直接继承 `tsconfig.server.json`，说明根配置把服务端配置作为类型检查基线，而非重复维护目标版本、模块解析和源码范围等选项。[继承服务端配置 ↗](../../../tsconfig.json#L1 "支持根配置以服务端配置为基础、避免重复声明完整编译选项的判断。")

<a id="emit-boundary"></a>
## 输出边界与限制

根配置额外设置 `noEmit: true`，因此使用此配置运行 TypeScript 编译器时应只执行检查、不写出 JavaScript 或声明文件。[禁止生成编译产物 ↗](../../../tsconfig.json#L3 "支持该入口用于无输出类型检查的配置事实。") 这与被继承配置中的 `outDir` 并不矛盾：前者控制当前入口是否生成文件，后者只规定允许生成时的输出位置。材料没有提供具体命令，故无法确认哪些项目脚本实际选用此入口。
