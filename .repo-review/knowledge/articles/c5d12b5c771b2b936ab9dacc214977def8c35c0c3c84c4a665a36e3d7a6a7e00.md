# TypeScript 根配置

该文件是一个精简的 TypeScript 入口配置：继承服务端配置，并将当前编译过程限定为类型检查而不输出构建产物。具体语言级别、模块解析、路径别名及包含范围由未提供的上游配置决定，不能仅据此确认。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="configuration_role"></a>
## 配置作用

该根配置没有独立展开完整编译选项，而是通过 `extends` 复用 `tsconfig.server.json`。因此它更像服务端 TypeScript 配置的薄入口：公共规则来自上游文件，本文件只负责追加局部约束。[继承服务端 TypeScript 配置 ↗](../../../tsconfig.json#L1 "支持该文件以服务端配置为基础、仅承担薄入口作用的判断。")

<a id="output_boundary"></a>
## 输出边界与限制

本文件显式设置 `noEmit: true`，表示使用该配置运行 TypeScript 编译器时不生成 JavaScript、声明文件等产物，通常用于类型检查。[禁止 TypeScript 输出产物 ↗](../../../tsconfig.json#L3 "支持当前配置只进行检查、不由 TypeScript 编译器直接生成产物的说明。") 但材料未提供被继承配置，因而无法确认目标运行时、模块系统、严格模式、文件纳入范围，也不能据此判断实际构建是否由其他工具或另一份配置完成。
