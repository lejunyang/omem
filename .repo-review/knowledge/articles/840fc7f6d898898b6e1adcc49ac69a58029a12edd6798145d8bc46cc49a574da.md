# omem Lark 助理默认能力配置

集中定义创建或接入 Lark 应用时请求的名称、租户与用户权限、事件订阅和卡片回调，并通过共享合同在模块加载时校验配置结构。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="profile_scope"></a>
## 配置定位与能力范围

该常量是可复用的个人助理应用预设，目标覆盖群聊材料记录、文档、日历、会议、任务及 owner 通知。源码说明它源于指定 botmux 修订，并意图排除批量消息、聊天所有权或成员变更以及权限管理；这属于配置设计声明，实际能力仍取决于平台审批和租户授权。[个人助理预设说明 ↗](../../../apps/server/src/integrations/lark/defaults.ts#L3 "支持默认配置的来源、用途和设计上排除的高风险能力。")

<a id="permissions"></a>
## 租户级与用户级权限

租户权限面覆盖消息、卡片、文档与云盘、知识库、多维表格、白板、电子表格、幻灯片、日历、任务、会议辅助、语音转写、OCR、翻译和文档 AI，其中也包含文档权限读取与日历 ACL 读取。[租户权限集合 ↗](../../../apps/server/src/integrations/lark/defaults.ts#L18 "支持租户身份申请的消息、内容、日历、任务、会议及智能处理能力范围。") 用户权限单独配置离线访问、联系人、文档与云盘、知识库、内容工具、日历、搜索和会议事件，并包含文档成员申请能力；两组列表体现机器人身份与用户身份不同的授权边界。[用户权限集合 ↗](../../../apps/server/src/integrations/lark/defaults.ts#L133 "支持用户身份的离线访问、内容、日历、搜索、会议及成员申请权限范围。")

<a id="events_and_validation"></a>
## 事件入口与合同约束

事件配置订阅消息接收与更新、机器人或成员进出群、消息表情、文档评论以及会议活动，用户侧另订阅参会事件；卡片回调只声明 `card.action.trigger`。整个对象由共享配置 schema 解析，因此结构错误会在加载配置时暴露。[事件订阅与卡片回调 ↗](../../../apps/server/src/integrations/lark/defaults.ts#L216 "支持默认订阅的租户和用户事件类别、唯一卡片动作回调及 schema 校验。")
