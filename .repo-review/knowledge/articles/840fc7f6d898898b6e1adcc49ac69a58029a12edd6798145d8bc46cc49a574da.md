# Lark 个人助理默认能力配置

该文件集中定义 omem 的 Lark 应用资料、租户与用户权限、事件订阅及卡片回调，并在导出时交由共享合同解析。修订后的说明分别依据完整的 tenant 与 user 清单描述能力，替代先前由局部行范围支撑全部租户权限的结论。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 用途与授权边界

该模块提供可复用的 Lark 个人助理申请配置，统一应用名称、描述和开放能力。文件注释表明其面向文档、日历、会议、任务及富内容场景，同时有意排除批量消息、会话所有权或成员变更、权限与 ACL 管理等能力。[个人助理能力边界说明 ↗](../../../apps/server/src/integrations/lark/defaults.ts#L3 "支持该配置面向个人助理场景，并明确列出保留能力和排除的高风险能力。") 配置关闭通用预设，改为显式枚举权限，因此实际申请边界以本文件清单为准。[显式权限配置入口 ↗](../../../apps/server/src/integrations/lark/defaults.ts#L9 "支持关闭通用预设并由本文件显式维护授权范围的论断。")

<a id="configuration-flow"></a>
## 配置构造与权限分层

模块导入 `larkRequestedConfigSchema`，并在导出默认对象时调用 `parse`，说明配置会先经过共享合同解析；但现有材料未包含该 schema 的定义，不能进一步断言其全部校验和归一化规则。[共享合同解析入口 ↗](../../../apps/server/src/integrations/lark/defaults.ts#L1 "支持模块导入共享 schema，并通过 parse 构造导出配置；同时限定现有证据只覆盖调用关系。") 租户权限从消息、联系人延伸到文档、云盘、知识库、白板、表格、幻灯片、日历、任务、会议、OCR、翻译和文档智能。[完整租户权限范围 ↗](../../../apps/server/src/integrations/lark/defaults.ts#L18 "以完整 tenant 清单支持消息、文档、云盘、知识库、日历、任务、会议及内容处理能力的概括，修复先前引用范围不足。") 用户权限则单独包含离线访问、文档与知识空间操作、日历、搜索和会议事件读取。[用户授权权限范围 ↗](../../../apps/server/src/integrations/lark/defaults.ts#L133 "支持 user scope 包含离线访问、内容操作、搜索、日历和会议事件读取等能力的说明。") 这一分层表述替代了此前仅引用后半段权限清单、却概括完整租户能力的依据不足结论。

<a id="events-and-limits"></a>
## 事件入口与验证限制

配置订阅消息接收和更新、机器人或用户进出群、表情反应、文档评论及会议邀请、活动和结束等租户事件；用户侧订阅参会者入会事件，卡片交互通过 `card.action.trigger` 回调声明。[事件订阅与卡片回调 ↗](../../../apps/server/src/integrations/lark/defaults.ts#L216 "支持租户事件、用户参会事件以及卡片动作回调的具体配置说明。") 这些条目只能证明计划申请的权限和订阅入口，不能证明对应处理器均已实现、管理员已批准权限，或外部 API 已完成真实联调；当前材料也没有提供相关测试证据。
