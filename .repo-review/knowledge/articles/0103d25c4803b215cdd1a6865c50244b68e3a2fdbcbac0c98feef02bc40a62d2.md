# 知识阅读帧与固定引用解析

按帧类型分派知识正文、直接原始材料或固定引用；直接材料帧与引用解析后的材料目标具有不同的定位参数能力。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="frame-dispatch"></a>
## 帧解析与直接阅读入口

组件先将帧 id 解析为 JSON；解析失败时退为空对象。knowledge 帧把文档键及可选修订、章节交给正文组件；直接 source 帧只传材料键与可选 digest，不传行范围。两类入口都会继续转发导航与标题加载事件，因此参数完整性仍主要依赖上游构造。[直接知识与材料帧分派 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L7 "支持帧 JSON 解析，以及 knowledge 帧和直接 source 帧实际传递的参数范围。")

<a id="citation-resolution"></a>
## 固定引用的异步解析

citation 帧按文档、修订和引用标识请求详情。帧 id 变化时会递增 `generation` 并清空旧状态，只有当前代次的响应或错误可以写回，从而避免快速切换时旧请求覆盖新内容；成功后把引用标签作为 `loaded` 事件载荷发出。[引用请求与竞态保护 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L10 "支持 citation 请求参数、代次校验、错误处理及加载标签回传。")

<a id="availability-routing"></a>
## 引用说明、可用性与目标路由

引用解析完成后，界面展示关系的中文标签与引用理由；不可操作或没有解析目标时明确显示原因。文章目标接收键、修订和章节；解析后的材料目标则可额外接收 digest 与固定起止行。因而，行范围属于 citation 解析后的材料定位能力，而不是直接 source 帧的通用参数。[引用可用性与解析目标分派 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L18 "支持关系说明、不可用状态，以及文章目标和带行范围材料目标的不同分派。")
