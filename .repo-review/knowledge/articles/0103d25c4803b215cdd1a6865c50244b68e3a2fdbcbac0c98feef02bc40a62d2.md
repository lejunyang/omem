# 知识阅读帧与固定引用解析

按帧类型打开知识正文、直接原始材料或固定引用；明确区分直接 source 帧与引用解析后的材料目标，并处理异步竞态、不可用目标和关系说明。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="frame-dispatch"></a>
## 帧解析与直接阅读入口

组件先把帧 id 解析为 JSON 参数；解析失败时仅退为空对象，尚未主动校验各类帧的必填字段。[帧参数解析 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L7 "支持帧 id 的 JSON 解析方式及解析失败时退为空对象的行为，说明当前缺少前置参数校验。") 模板随后按类型分派：knowledge 帧向正文组件传递文档键以及可选修订、章节；直接 source 帧只传材料键和可选摘要 digest，并继续转发导航与加载事件。[阅读组件分派与引用目标路由 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L20 "支持 knowledge、直接 source 与 citation 解析目标之间的参数差异，并证明固定行范围只传给引用解析后的材料目标。") 这替代了旧稿中“直接 source 帧传递摘要和行范围”的结论：固定起止行并不来自直接 source 帧。

<a id="citation-resolution"></a>
## 固定引用的异步解析

citation 帧依据文档、修订和引用标识请求详情。帧 id 每次变化都会递增 generation，并清空旧引用与错误；只有当前代次的响应才能写回状态，避免快速切换时旧请求覆盖新内容。成功后还会把引用的人类可读标签通知外层。关系类型在本地映射为“支持论点”“实现依据”等说明。[引用请求与竞态保护 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L10 "支持 citation 请求参数、代次保护、错误处理、加载通知及关系标签映射的说明。")

<a id="availability-and-routing"></a>
## 引用目标与不可用状态

引用解析期间显示等待状态，请求失败则显示“引用不可用”。解析成功后，界面展示关系标签和引用理由；目标不可操作或未解析时明确给出不可用原因。可用的文章目标按文档、修订和章节打开；只有 citation 解析得到的材料目标才会把材料键、digest 与固定 startLine/endLine 一并交给原文组件。[阅读组件分派与引用目标路由 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L20 "支持 knowledge、直接 source 与 citation 解析目标之间的参数差异，并证明固定行范围只传给引用解析后的材料目标。") 该组件负责前端分派和状态表达，不能单独证明服务端对引用稳定性或权限的校验方式。
