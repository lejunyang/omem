# 知识阅读帧与固定引用导航

阅读帧统一承接知识正文、原始材料和固定引用，负责解析导航参数、分发阅读视图、呈现引用依据，并用请求代次避免晚到响应覆盖当前引用。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="unified-routing"></a>
## 统一承接三类阅读目标

阅读界面用统一帧结构表示知识正文、原始材料和固定引用。帧的 `id` 保存 JSON 参数；解析失败时得到空参数对象，组件仍会按当前帧类型继续分发或请求，但材料不足以保证服务端最终返回何种错误。参考 [帧参数解析 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L7 "支持统一帧输入、从 id 解析 JSON，以及解析失败后使用空参数对象。")

`knowledge` 帧把文档键、可选修订和章节交给正文视图，`source` 帧把材料键与可选 digest 交给原文视图；两类子视图产生的导航和已加载标题都会向上传递。参考 [正文与原文分发 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L21 "支持知识帧和原文帧的参数分发，以及导航和已加载标题事件的透传。")

<a id="citation-resolution"></a>
## 解析固定引用并隔离晚到响应

引用帧根据文档、修订和引用键请求固定引用。每次 `frame.id` 变化都会清空旧状态并递增代次，只有当前代次的响应可以更新页面；成功后还会上报引用的人读标签。参考 [引用请求代次保护 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L11 "支持引用状态重置、请求代次校验、错误处理和成功后的标题上报。")

页面先呈现引用关系和引用理由。不可操作或无法解析的引用显示 `unavailableReason`，缺失时使用通用的“目标不可用”；可操作目标若为文章则进入正文视图，其余目标进入原文视图。参考 [引用目标状态分流 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L23 "支持引用加载和错误状态、不可用原因展示，以及文章与其他解析目标的视图分流。") 当前类型合同只允许 `article` 与 `material` 两种解析结果，因此这一兜底分支等价于材料目标，但运行时模板没有再次显式判断 `material`。参考 [解析目标类型 ↗](../../../apps/web/src/knowledge/api.ts#L3 "支持当前解析目标仅包含文章和材料两种联合类型的说明。")

<a id="document-source-flow"></a>
## 从知识论断回到固定原文

知识正文只允许可操作引用继续导航，并将当前文档、文章修订和引用键封装成 citation 帧。参考 [正文引用导航 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L20 "支持正文仅对可操作引用创建 citation 帧，并携带文档、修订与引用键。") 原文视图则按材料键与可选 digest 读取固定版本，也通过请求代次阻止旧响应覆盖当前材料。参考 [固定材料读取 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L16 "支持按材料键和可选 digest 读取固定版本，并通过代次检查隔离过期响应。")

代码材料围绕引用行展示片段并支持上下扩展；Markdown 材料始终保留连贯全文，只有起止行同时存在时才额外显示对应引用区间。参考 [代码与 Markdown 原文 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L40 "支持代码片段展开、引用位置提示，以及起止行齐全时的 Markdown 引用区间和全文展示。")

<a id="api-and-fallbacks"></a>
## 接口条件与关联导航降级

知识接口仅在 `sessionStorage` 中存在 `omem-token` 时附带 Bearer 令牌，并把非成功响应转换为错误；辅助函数负责构造知识正文帧。参考 [知识接口请求 ↗](../../../apps/web/src/knowledge/api.ts#L6 "支持令牌存在时附加认证头、接口错误转换和知识正文帧构造。")

材料中的关联导航调用 `reference` 时会先尝试读取对应文章；任何读取异常都会降级为原始材料帧。内部 Markdown 路径会先解析为材料键，再复用同一流程。参考 [关联导航降级 ↗](../../../apps/web/src/knowledge/KnowledgeSource.vue#L22 "支持关联导航优先读取文章、读取失败时降级到原始材料，以及内部路径复用该流程。") 当前引用监听只观察 `frame.id`，因此只改变 `kind` 而保持相同 `id` 不会重新触发请求；网络请求也未主动取消，竞态隔离依赖本地代次。参考 [引用请求代次保护 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L11 "支持引用状态重置、请求代次校验、错误处理和成功后的标题上报。")
