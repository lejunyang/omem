# 知识阅读帧与固定引用解析

根据 trail 帧类型呈现知识正文、原始材料或引用目标，并在引用不可用时展示关系、原因和明确的降级状态。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="frame-routing"></a>
## 帧类型与异步解析

组件把 knowledge 帧交给正文阅读器，把 source 帧交给材料阅读器；citation 帧则从序列化 id 中取 document、revision 和 citation 参数，请求固定引用。generation 计数避免较早请求晚到后覆盖当前帧，成功时还向上层回报可读标题。[知识帧解析与请求防竞态 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L1 "支持按帧类型路由、解析 citation 参数以及用 generation 防止过期响应覆盖当前状态。")

<a id="citation-presentation"></a>
## 引用语义与不可用状态

引用关系被翻译为“支持论点”“实现依据”等人类可读标签，并与引用理由一起显示。若目标不可操作或无法解析，界面保留该引用并说明不可用原因；可用目标则按 article 或 material 分流，材料阅读器同时接收 digest 和精确行号。[引用理由与目标渲染 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L20 "支持显示人类可读关系、不可用原因，并将文章或材料目标交给对应阅读器。") 该组件负责单帧内容，不包含帧栈、焦点归还或滚动记忆本身。
