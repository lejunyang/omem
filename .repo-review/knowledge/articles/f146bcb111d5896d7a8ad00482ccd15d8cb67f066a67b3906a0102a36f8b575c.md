# 当前实现进展、已知限制与未决问题

截至2026-10-01，omem 已形成统一材料捕获、固定证据、知识分析与独立复核、中文语义检索、来源更新重核验及日常事项操作的可运行闭环。中文检索采用本地 BGE 小样本验证，来源刷新经过真实 traex 验证，日常助手则在隔离临时数据库和合成材料上完成真实 traex 烟测；三者证据类型不同。全库知识覆盖、正式质量数据集、跨文件调用解析、跨版本身份续接、语义重排及外部提醒等仍未完成。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="limits"></a>
## 现存限制与质量发布门

当前检索仍缺少 reranker、ANN 和历史时点查询；周期性全库巡检、跨来源冲突自动修订、学习卡、重复提醒、取消状态与外部到期投递也未完成。[2026-10-01 最新进展记录 ↗](../../../docs/implementation/status.md#L1 "分别支持本地 BGE 查询验证、真实 traex 来源刷新验证、隔离数据库中的日常助手烟测，以及当前覆盖应以最新报告为准。")[来源更新与日常助手现状 ↗](../../../README.md#L99 "支持同一记忆的重核验和应用状态语义、事项操作流程，以及日常助手使用隔离临时数据库和合成材料验证的边界。") 代码侧另有独立边界：跨文件 calls 不解析，跨 revision 的符号及 Fragment 身份续接未实现，代码变化后仍需重新同步定位当前 head。[代码投影与跨版本身份边界 ↗](../../../docs/implementation/status.md#L42 "直接支持跨文件 calls 不解析，以及跨 revision 符号和 Fragment 身份续接尚未实现。") 实施仍是个人优先的单用户 SQLite，多租户 ACL、分布式事务和 pgvector 不应被描述为已具备。[单用户实施边界 ↗](../../../docs/implementation/status.md#L124 "支持当前 TypeScript 与 SQLite 单用户实现不具备多租户 ACL、分布式事务和 pgvector。")

质量发布门尚未通过：40 条 dev 草稿不是人工真值，live 标注已经停止，当前没有冻结数据集；正式 holdout 还需更多经授权并按项目、时间隔离的材料。只有完整人工确认并冻结后才能运行正式评测，其目标包括两个至少 95% 的 precision、至少 80% 的明确样本 coverage，以及歧义或转发 owner-task 假阳性为零。[质量数据集与发布门 ↗](../../../docs/implementation/batch2/quality-evaluation.md#L33 "支持 dev 草稿不是人工真值、停止标注、未冻结状态、holdout 来源要求以及正式评测指标阈值。")

## 被替代结论与当前口径

2026-09-27 的 Batch 2 审查准确记录了当时价值判断、上下文保真、知识召回和主 Agent 入口存在明显缺口，但它绑定基线 `16d3aa6`，复现使用临时数据库、合成材料和假适配器，没有调用真实模型或飞书接口；这些结论应作为回归设计的历史证据，而不能直接代表当前实现。[Batch 2 历史审查边界 ↗](../../../docs/reviews/2026-09-27-batch2/README.md#L1 "支持历史基线在价值判断、上下文保真、知识召回和主 Agent 入口方面的总体缺口，并说明隔离复现没有调用真实模型或飞书接口，不能直接代表当前状态。")

同样，2026-09-29 关于“仅关键词检索”和 `refresh_dependents` 未实现的描述，已被2026-10-01的中文向量检索与来源重核验闭环替代。当前全库完成度、失败项和过期项必须读取最新 coverage 与 verification 报告；未执行检查不继承历史通过率，失败、过期和待处理项也不能计作完成。[2026-10-01 最新进展记录 ↗](../../../docs/implementation/status.md#L1 "分别支持本地 BGE 查询验证、真实 traex 来源刷新验证、隔离数据库中的日常助手烟测，以及当前覆盖应以最新报告为准。")[覆盖与验证报告口径 ↗](../../../README.md#L66 "支持当前验证报告与历史报告分离，并明确失败、过期和待处理知识不计作完成。")
