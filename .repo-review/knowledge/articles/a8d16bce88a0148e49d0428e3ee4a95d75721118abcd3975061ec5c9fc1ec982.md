# B2-06 飞书实时连接与通知验证

记录飞书连接租约、事件收件箱、通知发件箱与决策卡回调的确定性及真实平台验证，并明确全量回归结果、默认装配条件和仍未覆盖的真实场景。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="scope"></a>
## 实现范围与证据层级

本轮覆盖飞书 WebSocket 连接租约、事件 inbox、owner notification outbox 与 Card 2.0 决策回调。确定性测试使用官方 SDK adapter 边界、真实 SQLite 重启及注入 transport；在用户授权下，还对隔离的真实飞书应用完成凭据、权限、握手、配对、主动通知、卡片点击和群消息采集验证。真实标识与凭据未提交到仓库，因此仓库内可重复测试与外部平台实测属于两层不同证据。[B2-06 范围与证据等级 ↗](../../../docs/implementation/batch2/b2-06-verification.md#L5 "支持实现范围、确定性测试方法、真实平台验证以及凭据隔离方式的说明。")

<a id="results"></a>
## 核心行为与回归结果

编号验收确认连接租约互斥、事件持久化与去重、回调重放及竞态防护、错误操作者和摘要拒绝、stale approval 阻断，以及通知恢复、供应商 UUID 复用和认证失败停用。短窗与定时聚合由 B2-08 补齐，但真实定时等待发送仍未执行。[B2-06 编号验收结果 ↗](../../../docs/implementation/batch2/b2-06-verification.md#L20 "支持连接、回调、通知与聚合语义的确定性结果，并揭示各真实平台项目的 pass、partial 或 skipped 状态。") 最终全量检查明确为 13 个测试文件、79 项测试通过，TypeScript/Vue 类型检查、生产构建及 7/7 组浏览器检查均成功。[B2-06 全量回归结果 ↗](../../../docs/implementation/batch2/b2-06-verification.md#L59 "直接支持79项测试、类型检查、生产构建和7组浏览器检查通过的结论。")

<a id="limits"></a>
## 限制与后续关联

真实平台证据仍未覆盖断网、移群、secret 轮换、三秒回调时限、平台去重窗口及等待窗口后的定时摘要。外部连接组件虽已实现为显式装配组件，但当时默认服务缺少 master key、真实 capability probe 或 host 配置时不会启动；文档中的 B2-07 UI 缺口是该提交时点的历史状态，不能直接当作当前能力结论。[B2-06 剩余限制 ↗](../../../docs/implementation/batch2/b2-06-verification.md#L61 "支持外部组件的默认启动条件、当时尚缺 B2-07 UI 的历史状态和真实定时摘要未验证的限制。")
