# Agent CLI 与 ACP 传输适配

负责启动外部 Agent、协商 ACP 能力和模型设置、实施只读与拒绝授权边界、流式收集输出，并为传统 CLI 提供受限兼容路径。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="process"></a>
## 进程生命周期与环境边界

适配器以非 shell 子进程启动 profile 指定命令，过滤部分宿主敏感环境变量，并在支持的平台创建独立进程组。取消、超时或结束时先发送终止信号，必要时升级强制终止；ACP 路径还等待子进程关闭，以降低工作目录仍被占用的竞态。目录创建时请求 `0o700`，但不代表既有目录权限一定被修改。[子进程启动与停止 ↗](../../../apps/server/src/agents.ts#L32 "支持环境过滤、非 shell 启动、进程组、目录创建参数及分阶段终止策略。")[ACP 清理与进程关闭等待 ↗](../../../apps/server/src/agents.ts#L340 "支持取消监听清理、终止进程并等待关闭事件释放工作目录。")

<a id="acp"></a>
## ACP 能力协商与安全策略

ACP 初始化声明不提供文件读写或终端能力，新会话只接收宿主指定的 MCP 服务。请求的模型和推理强度必须出现在会话配置选项中，否则拒绝；若模型元数据提供上下文窗口，还会校验输入、输出和预留总量。native 技能须在命令发现更新中出现，图片也要求 Agent 明示支持。[模型上下文预算发现 ↗](../../../apps/server/src/agents.ts#L70 "支持从当前模型选项元数据读取上下文窗口并校验输入、输出和预留总量。")[ACP 初始化与会话配置 ↗](../../../apps/server/src/agents.ts#L259 "支持只读能力声明、技能发现、模型和推理强度合法值校验、图片能力检查及提示调用。")

<a id="requests"></a>
## 权限、补充输入与输出流

Agent 的权限请求会先交给宿主回调记录，再统一返回 cancelled；补充输入请求同样记录后 decline，因此后台任务不会静默获权或等待交互。只有文本消息块进入最终输出，thought 不在此路径收集；工具调用仅作为状态通知。字符和 ACP 线协议总量分别设有限制，越界会停止子进程。[运行时请求和消息流处理 ↗](../../../apps/server/src/agents.ts#L180 "支持权限取消、补充输入拒绝、文本输出收集、工具状态通知以及输出字符限制。")

<a id="cli"></a>
## CLI 兼容路径及限制

CLI 参数强制无工具、只读沙箱或不询问权限、临时会话，并按 profile 传递模型和推理强度。输出按不同提供方的 JSON 事件提取 Agent 文本；非零退出、畸形 JSON、提供方错误、没有有效消息或超过字节上限都视为失败。该路径只处理文本，也没有 ACP 的能力发现、托管工具与运行时请求合同。[CLI 参数与协议解析 ↗](../../../apps/server/src/agents.ts#L377 "支持 CLI 的只读和无工具参数、模型设置、JSON 事件解析、字节限制及失败条件。")
