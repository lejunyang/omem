# Agent 进程与 ACP 会话传输

服务端统一启动外部 Agent，完成 ACP 能力协商、模型配置、流式事件转发、权限控制、预算限制与有界进程清理；同时提供受限的一次性 CLI JSON 流兼容通道。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 它解决什么问题

`agents.ts` 是业务代码与外部 Agent 进程之间的传输适配层：以 `AgentProfile` 描述命令、模型和超时，以官方 ACP SDK 承载会话，不负责组织知识提示或解释模型结果。参考 [传输层依赖 ↗](../../../apps/server/src/agents.ts#L1 "说明该文件依赖子进程、官方 ACP SDK 和共享 AgentProfile，并明确过滤思考内容与权限默认策略。")

它提供两条入口：`acp()` 面向需要能力协商、图片、MCP 工具与技能的完整会话；`cli()` 面向把文本送入命令行并读取 JSON 事件的一次性调用。上层调用者准备输入并消费结果，本文件负责把输入送到子进程。两条入口都接受工作目录、事件回调和取消信号。参考 [ACP 入口参数 ↗](../../../apps/server/src/agents.ts#L90 "支持 acp() 接受 Agent 配置、工作目录、内容块、事件回调、取消信号和可选参数的说明。") [CLI 入口参数 ↗](../../../apps/server/src/agents.ts#L418 "支持 cli() 接受 Agent 配置、工作目录、文本、事件回调和取消信号的说明。")

<a id="acp-flow"></a>
## 一次 ACP 调用如何完成

以一次知识生成任务为例：上层传入 Agent 配置、隔离工作目录、文本或图片块、`emit` 回调、取消信号，以及可选的 MCP 服务、预期技能和上下文预算。

```mermaid
flowchart LR
  A[启动子进程] --> B[建立 NDJSON ACP 连接]
  B --> C[initialize 与 newSession]
  C --> D[校验技能并设置模型与思考强度]
  D --> E[检查预算与图片能力]
  E --> F[prompt 流式运行]
  F --> G[关闭会话并返回元数据]
```
连接先声明客户端没有文件读写和终端能力，再创建带 MCP 与原生 skill 配置的新会话；预期技能未被发现会超时报错。参考 [ACP 会话建立 ↗](../../../apps/server/src/agents.ts#L267 "支持初始化客户端能力、创建带 MCP 与 skill 配置的会话，以及等待预期技能发现的流程。")

配置只能选择 Agent 实际公布的值；提示期间，正文通过 `emit("text", ...)` 交给调用者，而函数最终返回 Agent 信息、能力、有效配置、会话 ID、命令列表和用量，并不把正文作为返回值。参考 [配置提示与返回 ↗](../../../apps/server/src/agents.ts#L310 "支持动态配置校验、预算与图片能力检查、prompt 执行以及最终元数据返回的说明。")

<a id="safety-boundaries"></a>
## 权限、预算与终止边界

权限请求不会默认放行：只有调用者明确批准且 Agent 提供 `allow_once` 选项时才选择一次授权；否则记录运行时请求、发出可见提示并取消。补充输入请求也直接拒绝，适合不能停下来等待人工回答的后台任务。参考 [权限与补充输入策略 ↗](../../../apps/server/src/agents.ts#L186 "支持仅在显式批准时选择一次授权、其余权限取消，以及后台补充输入直接拒绝的边界。")

实现限制 ACP 原始输出为 32 MB，正文默认为 25 万字符，并只把文本正文送入答案，同时把工具、计划和用量等选定更新交给状态回调；思考内容不会进入正文。参考 [ACP 原始流上限 ↗](../../../apps/server/src/agents.ts#L157 "支持 ACP 原始输出流默认限制为 32 MB 的说明。") [正文与状态事件 ↗](../../../apps/server/src/agents.ts#L226 "支持正文字符限制、文本输出与工具、计划、用量等选定状态更新的分派规则。") 模型公布上下文窗口时，输入估算、最大输出和预留量之和也必须落在窗口内。参考 [上下文预算检查 ↗](../../../apps/server/src/agents.ts#L79 "支持依据 Agent 公布的上下文窗口校验输入、输出和预留 token 总量的说明。")

超时或取消会先发 `SIGTERM`，1.5 秒后升级为 `SIGKILL`。参考 [分级终止进程 ↗](../../../apps/server/src/agents.ts#L45 "支持先发送 SIGTERM、1.5 秒后升级为 SIGKILL，以及非 Windows 进程组处理策略。") `acp()` 的 `finally` 会停止进程，并在 `close` 事件与 5 秒计时之间竞速；也就是最多等待 5 秒让子进程关闭并释放工作目录句柄，若仍有残余锁，则留给调用者后续文件操作暴露。参考 [有界关闭等待 ↗](../../../apps/server/src/agents.ts#L371 "支持 finally 中停止子进程，并在 close 事件与 5 秒计时之间竞速等待工作目录句柄释放的准确边界。")

<a id="cli-path"></a>
## CLI 兼容路径与修改入口

`cliArgs()` 针对 Claude 生成禁用工具与会话持久化的参数；其他 CLI 使用只读 sandbox、临时会话和标准输入。要新增 CLI 方言，应先改这里的参数映射。参考 [受限 CLI 参数 ↗](../../../apps/server/src/agents.ts#L386 "支持 Claude 与其他 CLI 的参数分支、禁用工具或只读 sandbox、临时会话及标准输入调用方式。")

`cli()` 按行解析 JSON，兼容 `item.completed`、`assistant` 与 `result` 三类正文；任一非空行无法解析、供应商报告错误、退出码非零或完全没有正文，整次调用都会失败。它还有 2 MB 输出上限，但没有 ACP 路径的 MCP、技能发现、图片能力协商或用量返回；若要扩展输出协议，修改点是逐行事件分派。参考 [CLI 事件解析 ↗](../../../apps/server/src/agents.ts#L425 "支持 CLI 的 JSON 事件兼容类型、2 MB 输出限制、停止条件和整体失败判定。")
