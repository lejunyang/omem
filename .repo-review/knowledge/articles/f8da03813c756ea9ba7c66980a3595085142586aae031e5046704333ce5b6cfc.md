# Agent 进程适配与受限执行

该模块把 AgentProfile 转换为受控子进程调用，提供 ACP 会话与兼容 CLI 两条路径，统一处理能力发现、配置校验、权限拒绝、输出限制、取消、超时与进程回收。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 作用与运行边界

该模块是服务端连接外部 Agent CLI/ACP 的执行适配层：它过滤服务端敏感环境变量，以指定工作目录、关闭 shell 的方式启动进程；非 Windows 平台使用独立进程组，停止时先发 SIGTERM，1.5 秒后升级为 SIGKILL。[子进程环境、启动与终止策略 ↗](../../../apps/server/src/agents.ts#L32 "支持敏感环境过滤、无 shell 启动、独立进程组以及分阶段终止策略的说明。")

ACP 客户端声明不具备文件读写和终端能力。权限或补充输入请求会先等待可选的 `onRuntimeRequest` 回调；仅当回调成功返回后，模块才发出提示并分别返回 `cancelled` 或 `decline`。若回调抛错，后续提示和显式拒绝返回不会执行，而是由外层错误流程接管；这替代了“请求始终会被提示并固定拒绝”的旧概括。[ACP 权限与补充输入处理 ↗](../../../apps/server/src/agents.ts#L183 "支持先等待运行时回调、回调成功后才提示并拒绝的控制流，也表明回调异常会阻断后续步骤。")

<a id="acp-flow"></a>
## ACP 会话流程

`acp` 从进程启动时监听关闭、错误和退出，将标准输入输出包装为 NDJSON 流，并分别限制线缆输出与正文输出。协议初始化和新建会话完成后，它等待所需原生技能，再依据会话实际返回的选项校验并设置 model 与 reasoning effort；不支持的值直接报错。[ACP 初始化、技能发现与配置校验 ↗](../../../apps/server/src/agents.ts#L259 "说明协议初始化、会话创建、技能等待，以及模型和推理强度依据实际配置选项进行校验。")

发送 prompt 前可检查模型上下文预算，并在输入含图片时确认 Agent 声明了图片能力；只有 `end_turn` 被视为正常结束。成功后清除全局超时、尝试关闭会话，最终等待子进程释放句柄，以降低 Windows 清理工作目录时的竞争。[预算、能力检查与会话收尾 ↗](../../../apps/server/src/agents.ts#L326 "支持上下文预算、图片能力、停止原因检查、会话关闭与进程句柄回收等边界。")

<a id="cli-flow"></a>
## 兼容 CLI 路径与成功判定

`cliArgs` 分别构造 Claude 与 Codex 风格参数：前者启用流式 JSON、禁止工具询问和会话持久化，后者使用只读 sandbox 与临时会话；两者都会传递已配置的模型和推理强度。[两类 CLI 参数构造 ↗](../../../apps/server/src/agents.ts#L377 "支持 Claude 与 Codex 风格参数、只读限制、临时会话，以及模型和推理强度的传递方式。")

`cli` 以 UTF-8 字符串逐行解析多种提供方消息。累计 `chunk.length` 超过 2,000,000、JSON 行畸形、提供方报错、进程非零退出或最终没有文本，都会导致整体失败。变量虽名为 `bytes`，实际累计的是 JavaScript 字符串长度，并非真实字节数。[CLI 输出解析与失败条件 ↗](../../../apps/server/src/agents.ts#L409 "支持 UTF-8 字符串模式、字符长度上限、逐行解析和严格整体成功判定，并澄清计数并非真实字节数。")

## 依赖关系与未证明范围

本文件从共享合同包导入 `AgentProfile`，但允许引用的合同片段只展示捕获内容及来源信息，没有该类型定义，因此无法确认 command、args、transport、timeout、模型和技能字段在进入适配层前的完整校验规则。[AgentProfile 合同依赖 ↗](../../../apps/server/src/agents.ts#L12 "证明模块依赖共享合同中的 AgentProfile，同时限定当前合同材料范围没有展示该类型定义。")
