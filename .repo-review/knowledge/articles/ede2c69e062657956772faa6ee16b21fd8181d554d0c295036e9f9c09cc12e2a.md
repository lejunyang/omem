# Lark 连接器真实冒烟脚本

该脚本针对固定 Lark Wiki 地址执行一次真实连接器读取，用共享捕获合同解析结果，并输出标题、上游版本、分片类型和文本字符数摘要。它验证的是本次调用未抛错且返回值可解析，不足以证明外部工具配置正确或内容符合稳定预期。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 作用与定位

该文件是 Lark 连接器的真实环境冒烟入口：它调用服务端导出的 `larkInput` 读取固定 Wiki 页面，并把返回值交给共享的 `captureSchema` 解析。[Lark 读取与捕获解析入口 ↗](../../../scripts/live-connectors-smoke.ts#L1 "支持脚本调用 larkInput 读取固定页面，并将结果交给 captureSchema 解析这一定位。") 因而它覆盖“外部读取结果进入统一捕获合同”这一基本路径，但给定材料没有实际运行记录，也没有展示 `larkInput` 的实现，不能据此确认外部 CLI、认证或网络已经配置成功。contracts 包在所给范围内分别定义了文本、图片和 HTTP(S) 链接分片的严格 schema；由于 `captureSchema` 的完整定义未提供，只能确认这些分片类型存在，不能进一步断言该捕获合同在此处如何组合它们。[捕获分片 schema 定义 ↗](../../../packages/contracts/src/index.ts#L20 "支持 contracts 包分别定义文本、图片和 HTTP(S) 链接分片及字段约束，同时不把未展示的 captureSchema 组合方式说成确定事实。")

<a id="flow"></a>
## 执行流程与输出

脚本先等待 `larkInput(url)` 返回，再同步执行 `captureSchema.parse`；读取或解析发生异常时会直接向外抛出，因为文件中没有捕获、重试或降级分支。[读取后执行合同解析 ↗](../../../scripts/live-connectors-smoke.ts#L3 "支持外部读取完成后进行 schema.parse，且当前脚本片段没有错误恢复分支的流程说明。") 成功后，它打印格式化 JSON，包含连接器标签、标题、上游版本、返回结果中实际出现的分片类型，以及仅针对实际文本分片累计的字符数。[冒烟结果摘要字段 ↗](../../../scripts/live-connectors-smoke.ts#L8 "支持输出标题、上游版本、实际分片类型，并仅累计文本分片字符数的说明。") 这些字段便于人工观察一次 live 调用的结果，却没有与预期标题、版本、分片集合或最小文本长度比较，因此成功退出只说明本次调用和解析没有抛错，不能稳定发现内容退化。

<a id="boundaries"></a>
## 依赖、边界与替代结论

脚本依赖一个硬编码的 Lark Wiki 地址；要运行成功，该页面必须仍可访问，且运行环境需要满足连接器实际要求，但材料没有说明页面所有权、凭证、网络条件或失效后的替换流程。[固定 Lark Wiki 目标 ↗](../../../scripts/live-connectors-smoke.ts#L4 "支持该 live smoke 依赖单一硬编码页面，因此页面可访问性和维护约定属于运行边界。") 先前将其表述为“已确认外部 CLI 到捕获输入的链路可运行”或“本机 CLI、认证和网络均已配置”缺少运行证据，现以“用于发起并观察一次真实读取”取代。连接器模块声明总体原则是显式、受限读取，并且不会自动抓取捕获文本中的 URL；这提供了安全背景，却不能代替对 `larkInput` 的分页、超时、权限错误及敏感信息处理等实现细节的核验。[连接器受限读取原则 ↗](../../../apps/server/src/connectors.ts#L1 "支持连接器采用显式、受限读取且不自动抓取捕获文本中 URL 的总体安全背景；该原则不证明具体 Lark 实现细节。")
