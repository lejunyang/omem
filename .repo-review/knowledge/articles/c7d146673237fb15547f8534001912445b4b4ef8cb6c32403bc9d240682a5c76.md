# 从知识阅读到代码证据的统一浏览入口

该组件把知识首页、代码快照、模块依赖图和多层证据抽屉组织成一条可深链、可返回的阅读路径，并负责协调真实接口数据、模块理解缓存及文件、符号、评审片段等详情组件。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决什么问题

`CodeWiki` 是代码知识阅读的页面容器：读者可以先从知识文章理解项目，再进入代码结构、模块或文件，沿引用继续查看符号和评审片段。它集中管理快照、依赖图、当前视图和证据轨迹，数据来自评审接口而非页面内模拟。参考 [代码知识页面职责 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L2 "支持该组件统一承载知识、代码结构、证据轨迹和真实接口数据的定位。")

模块与边并不直接使用接口的文件列表展示，而是先聚合为模块节点、模块间边，并建立文件和符号索引，供主页面及抽屉中的详情组件复用。参考 [模块聚合与索引 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L57 "支持代码图被聚合为模块节点和边，并建立文件、符号查找表的流程。")

<a id="flow"></a>
## 加载、同步与页面切换

首次挂载时，页面并行读取当前快照、代码图和模块理解列表；其中模块理解列表失败会降级为空列表，而快照或代码图失败会进入统一错误状态。手动同步会先触发代码同步，再重新执行整套加载。参考 [数据加载与同步 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L120 "支持并行加载、理解列表降级、错误处理及同步后重载的说明。")

```mermaid
flowchart LR
  A[加载快照与代码图] --> B[聚合模块和依赖边]
  B --> C[模块或文件主视图]
  C --> D[证据轨迹抽屉]
  D --> E[文件、符号、片段或知识]
```

主视图与轨迹都会写入 URL hash；恢复时先解析主视图，再恢复轨迹栈、当前位置和抽屉状态，因此链接可以保留阅读上下文。参考 [深链恢复流程 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L218 "支持主视图和轨迹写入 hash、挂载后恢复及浏览器历史监听的说明。")

<a id="boundaries"></a>
## 证据下钻与边界条件

抽屉按当前帧类型选择知识、模块、文件、符号或片段组件，并把子组件产生的下钻事件重新汇入同一个轨迹栈，形成统一的返回、跳转和循环提示体验。参考 [多类型证据抽屉 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L371 "支持抽屉依据帧类型渲染不同详情组件，并统一接收下钻事件的说明。")

模块详情只提交符号 ID，拥有文件归属的解析由父组件通过符号索引完成；找不到符号、文件或模块时会直接停止下钻。参考 [模块符号下钻事件 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L50 "说明模块组件只发出符号标识，并明确把所属文件解析交给父组件。") [父级解析符号归属 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L185 "支持父组件通过符号索引补全文件 ID，并在目标缺失时停止下钻。") 模块理解详情采用缓存，首次缺失时后台加载；接口失败返回 `null`，页面不会据此虚构说明。URL 恢复仅保存帧类型和 ID，标题需依赖当前图重新生成人读文案。参考 [详情缓存与标题恢复 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L83 "支持模块理解按需缓存、失败返回空结果，以及轨迹标题避免展示内部 ID 的边界说明。")
