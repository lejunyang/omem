# Code Wiki 纵向切片容器

该组件编排仓库快照、模块结构与依赖图、模块和文件阅读、知识正文及统一证据 trail。它负责真实数据加载、视图切换、下钻目标解析和 hash 深链接线；具体阅读内容与 trail 内部算法由子组件和 UI 包承担。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-data"></a>
## 职责与数据组织

组件承担 Code Wiki 的页面级编排：覆盖仓库/快照总览、确定性模块图、模块与文件详情、统一 trail 抽屉和 hash 深链，数据来自真实 review API。[Code Wiki 容器职责 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L2 "支持页面统一承载快照、模块图、详情、trail 与深链，并说明真实 API 数据来源。") 代码图经 `aggregateGraph` 转成模块节点与模块间边，并建立文件、符号映射，供结构展示、关系图和后续下钻解析复用。[模块图聚合与索引 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L57 "支持代码图被聚合为模块节点和边，并建立文件、符号映射供展示与下钻使用。")

初始化通过 `Promise.all` 并行读取当前快照、代码图与模块理解列表；理解列表失败时退化为空列表，而快照或代码图失败会写入统一加载错误，最终结束加载状态。[初始化并行加载 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L120 "直接支持快照、代码图和理解列表的并行读取、理解列表降级以及统一错误状态。") 这取代了旧稿中由图聚合代码范围同时证明初始化行为的结论。

<a id="navigation-flow"></a>
## 主视图、同步与详情流程

主视图明确包含总览、结构、依赖图、模块和文件五种状态。同步操作先调用代码同步，再重新执行完整加载；打开模块会设置选中模块、切换视图、更新 hash，并异步读取模块理解详情。[视图、同步与模块打开 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L44 "支持五种主视图定义、同步后完整重载，以及打开模块时更新视图、hash 和详情。") 详情按 understanding 标识缓存，请求失败返回空值；抽屉模块帧在缓存缺失时触发后台补取。[模块理解详情缓存 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L83 "支持详情缓存、请求失败返回空值和抽屉首次缺失时后台补取。")

模板把聚合节点和边传给关系图，把选中模块及理解详情交给 `ModuleFrame`，把选中文件交给 `FileFrame`，并将它们发出的下钻或知识导航事件接回容器。[主视图组件接线 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L329 "支持关系图、模块帧和文件帧接收数据并将选择、下钻与知识导航事件交回容器。") 容器随后校验文件、符号是否仍在当前图中，必要时由符号映射补全所属文件，再压入对应 trail 帧；目标缺失时不会压栈。[下钻目标解析 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L185 "支持容器校验文件和符号、补全符号所属文件并压入 trail，且缺失目标时提前返回。")

<a id="trail-and-deeplink"></a>
## Trail 接线与深链恢复

页面将 `useEvidenceTrail` 暴露的帧栈、当前位置、打开状态、循环位置和导航动作接入单个 `OmTrailDrawer`，并按当前帧类型分派知识、模块、文件、符号或片段阅读器。[统一 Trail 抽屉分派 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L371 "支持 trail 状态和动作与抽屉接线，以及按帧类型选择不同阅读组件。") 这里能确认的是能力接线与阅读器复用；循环检测、滚动恢复、焦点归还等算法是否正确，仍需 UI 包实现和浏览器测试材料佐证。

hash 写入包含主视图以及 trail 的 `kind/id` 序列；恢复时解析主视图、重建帧栈与当前位置并打开抽屉。[Hash 写入与恢复 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L218 "支持主视图和 trail 序列写入 URL，以及恢复帧栈、当前位置和抽屉状态。") 因 hash 不保存展示标题，恢复后会依据当前文件和符号映射重新生成名称；无法解析时使用“文件”“符号”“决策片段”“知识与证据”等人类可读兜底文本，不直接显示裸内部标识。[恢复帧的人类可读标题 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L165 "支持恢复后从图映射解析标题，并在无法解析时采用按类型的人类可读兜底。")

<a id="boundaries"></a>
## 边界、错误与待确认风险

顶层加载失败会显示错误和重试入口；无快照时提供同步操作，依赖图无节点时展示空状态。[错误与空状态界面 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L268 "支持顶层错误重试、无快照时同步及依赖图为空时的提示。") 模块详情自身失败会返回空值，文件或符号下钻目标缺失则被保守忽略。[模块理解详情缓存 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L83 "支持详情缓存、请求失败返回空值和抽屉首次缺失时后台补取。")[下钻目标解析 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L185 "支持容器校验文件和符号、补全符号所属文件并压入 trail，且缺失目标时提前返回。") 这些边界分别由不同代码路径实现，不能再由单一模板片段概括全部行为。

当前模块详情加载在异步完成后直接覆盖 `selectedModuleDetail`，没有确认结果仍对应当前选中模块。[当前模块详情赋值 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L100 "支持识别模块详情请求完成后直接写入共享状态、未校验当前模块的竞态风险。") 作为对照，知识正文以 generation 丢弃过期响应。[知识正文的过期响应保护 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L10 "作为对照，支持知识正文通过 generation 校验忽略较早请求结果。") 因而快速切换模块存在有依据的乱序覆盖风险，但现有材料没有行为测试，尚不能断言该竞态一定发生或已被覆盖。
