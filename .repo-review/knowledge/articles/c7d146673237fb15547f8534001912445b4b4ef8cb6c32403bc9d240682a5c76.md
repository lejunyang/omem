# Code Wiki 总览、路由与统一证据 Trail

组织真实代码图、模块理解和知识入口，并把文件、符号、片段及知识引用接入同一个可深链的证据阅读栈。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="data-and-views"></a>
## 数据装载与主视图

容器并行读取当前快照、代码图和模块理解列表；理解列表请求失败时降级为空列表，而快照或代码图失败会进入页面级错误状态。同步由用户操作显式触发，完成后重新装载数据，普通页面加载本身不会启动同步。[快照与理解装载流程 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L120 "支持三类数据并行装载、理解列表失败时的局部降级，以及显式同步后重新装载。") 主界面在知识总览、确定性结构、依赖图、模块和文件之间切换；结构页在没有快照时提供同步入口，并展示工作树状态、解析器版本以及文件、符号和边的统计。[结构总览界面 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L275 "说明知识与结构视图入口、无快照状态、同步操作及快照和代码图统计展示。")

<a id="trail-navigation"></a>
## 统一下探与人类标签

文件与符号下探会先在当前代码图中解析目标；模块引用只给出符号标识时，父容器会补齐所属文件。片段分支则直接压入 Trail，不在创建帧前校验片段是否存在，因此此前把三类目标都描述为预先解析并不准确。恢复标题时优先采用文件名、符号名和模块名，无法解析时使用“文件”“符号”等人类占位，避免显示内部标识。[Trail 标题与下探处理 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L165 "支持人类标题转换，并准确区分文件和符号的预解析与片段的直接入栈行为。") 抽屉按当前帧类型渲染知识、模块、文件、符号或片段，并统一提供返回、跳转、关闭、循环提示与焦点归还。[统一 Trail 抽屉控制 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L371 "证明抽屉统一连接关闭、返回、跳转和循环处理，并为多类内容提供共同容器。")

<a id="deep-link"></a>
## 深链恢复与失效限制

主视图和完整 Trail 栈会写入 URL hash，文件视图还保存锚点行号；恢复时解析视图与帧序列、重建可读标题并打开栈顶。[Hash 序列化与恢复 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L218 "支持主视图、文件行号和 Trail 栈的 URL 写入、解析、重命名及恢复流程。") 序列化只保留帧种类和标识，具体内容仍依赖当前代码图。同步后若 hash 指向的模块、文件或符号已经消失，路由帧仍可能恢复，但对应组件只有在当前图能解析实体时才渲染，内容区可能为空且没有专门的 missing/stale 原因提示；不过抽屉的通用返回、跳转和关闭入口仍然存在。[按当前代码图条件渲染帧 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L371 "支持模块、文件和符号仅在当前图能解析实体时渲染，并与抽屉仍保留通用导航控制共同界定失效深链的现状。")
