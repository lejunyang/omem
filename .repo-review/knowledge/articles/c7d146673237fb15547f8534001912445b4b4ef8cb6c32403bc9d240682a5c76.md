# 代码知识浏览与证据追踪入口

该组件是 Code Wiki 的页面级协调器：从真实评审接口加载仓库快照、代码图和模块理解，组织总览、结构图、模块与文件视图，并通过共享证据轨迹串联知识文章、源码符号和评审片段。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 把仓库结构与知识证据放在同一入口

组件解决的是“如何从仓库概览逐层读到具体证据”的问题。它不自行解析代码，而是消费代码快照、文件、符号、边和已生成的模块理解，将知识首页、确定性模块图、模块详情及文件详情组织成多个阅读视图。参考 [Code Wiki 页面职责 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L2 "说明页面容器负责仓库概览、模块图、详情、证据轨迹与 Hash 深链，并消费真实接口数据。")

代码图会聚合为模块节点和模块间边，并建立文件、符号查找表；页面因此既能展示结构统计，也能把后续点击定位到当前代码图中的文件或符号。参考 [代码图聚合与查找表 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L57 "支持模块节点、模块边以及文件和符号查找表的生成流程。")

<a id="flow"></a>
## 加载、同步与逐层下钻

初始化时并行读取当前快照、代码图和理解列表；理解列表读取失败时退化为空列表，而快照或代码图加载失败会进入统一错误状态。用户主动同步后，组件重新加载整组数据。参考 [数据加载与同步 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L120 "支持并行加载、理解列表降级、同步后刷新及错误状态处理的描述。")

```mermaid
flowchart LR
  A[加载快照与代码图] --> B[聚合模块]
  B --> C[模块或文件主视图]
  C --> D[证据轨迹]
  D --> E[文件、符号、片段或知识]
```
主视图切换会保存模块、文件和锚点行；结构页、依赖图、模块详情与文件详情提供实际阅读入口。参考 [主视图导航 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L147 "说明打开模块或文件时保存选择、切换视图、更新深链并加载模块理解。") [结构与详情视图 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L275 "支持页面提供快照结构、模块依赖图、模块详情和文件详情等阅读入口。")

下钻事件由容器统一解释：文件必须能在当前图中找到；符号可由符号表补全所属文件；片段则直接加入轨迹。模块详情只上报符号标识，由父组件解析其所属文件。参考 [证据下钻分派 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L185 "支持文件、符号和片段下钻时的目标解析与入栈规则。") [模块符号下钻合同 ↗](../../../apps/web/src/codewiki/ModuleFrame.vue#L46 "说明模块详情仅发送符号标识，并由父组件负责解析符号所属文件。")

<a id="navigation-boundaries"></a>
## 证据轨迹、深链恢复与失效边界

证据阅读复用单一轨迹栈，抽屉根据当前帧类型装配知识、模块、文件、符号或片段阅读器，并统一处理关闭、返回、跳转、循环提示与焦点归还。知识正文中可操作的引用也通过导航事件进入这套轨迹。参考 [统一证据抽屉 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L371 "支持证据轨迹按帧类型装配阅读组件，并统一承接轨迹交互事件。") [知识引用导航 ↗](../../../apps/web/src/knowledge/KnowledgeDocument.vue#L20 "说明知识正文只为可操作引用发出导航事件，从而接入共享证据轨迹。")

URL hash 保存主视图及轨迹帧的类型和标识。恢复时，**主视图的文件路由**只有在当前代码图能找到文件时才会打开；轨迹则会被无条件恢复并打开。若恢复出的模块、文件或符号帧已经不属于当前图，它仍可能留在栈中，但对应阅读组件会因目标不存在而没有正文。参考 [Hash 路由恢复 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L236 "说明主视图文件路由的存在性判断，以及轨迹数据被直接恢复和打开的行为。") [失效轨迹帧渲染条件 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L383 "说明模块、文件和符号轨迹帧只有在当前代码图存在对应目标时才渲染正文组件。")

Hash 往返不保存展示标题。恢复后，文件名和符号名会依据当前代码图重新解析，找不到时分别回退为“文件”和“符号”；模块标题由模块标识转换，知识、引用和来源帧统一显示为“知识与证据”。参考 [恢复帧标题解析 ↗](../../../apps/web/src/codewiki/CodeWiki.vue#L165 "支持文件和符号标题依赖当前查找表、缺失时使用通用名称，以及其他帧类型采用各自标题规则的论断。")
