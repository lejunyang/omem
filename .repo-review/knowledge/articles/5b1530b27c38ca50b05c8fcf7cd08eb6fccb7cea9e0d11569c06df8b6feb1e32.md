# 运行时请求记录仓储

保存 Agent 在后台运行中提出但被拒绝的权限或补充输入请求，提供幂等冲突检测、状态解析入口和按作业查询能力。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="model"></a>
## 记录模型与行转换

运行时请求保留工作区、作业、会话、轮次、提供方请求标识、请求类型、选项、状态和时间字段。数据库行在读出时转换为领域对象，其中选项从 JSON 恢复；状态类型允许 pending、denied、expired 与 resolved，但该类型声明本身不代表本文件会创建全部状态。[运行时请求数据结构 ↗](../../../apps/server/src/agent-runtime/requests.ts#L7 "支持请求身份、来源、类型、状态、选项和时间字段及数据库行转换。")

<a id="denied"></a>
## 拒绝记录与幂等性

`recordDenied` 对请求类型、选项和轮次计算稳定摘要，以会话 ID 与提供方请求 ID 对既有记录进行查询。插入使用 `INSERT OR IGNORE` 且状态直接写为 denied；若相同幂等键对应的载荷摘要不同，则抛出冲突。默认过期时间为创建后五分钟，但记录在创建时已同时写入解决时间。[拒绝请求的幂等保存 ↗](../../../apps/server/src/agent-runtime/requests.ts#L37 "支持载荷摘要、拒绝状态、默认有效期、查询幂等键及摘要冲突检查。")

<a id="resolve"></a>
## 解决与查询边界

`resolve` 只接受当前仍为 pending 且未过期的请求，将其条件更新为 resolved，并返回调用方选择的 approve 或 reject；动作本身没有写入所示字段。`list` 可返回全部请求或按作业过滤，并按创建时间排序。[请求解决与列表查询 ↗](../../../apps/server/src/agent-runtime/requests.ts#L88 "支持 pending 和过期条件、resolved 更新，以及全部或按作业查询。") 网关目前调用的是 `recordDenied`，因此后台权限和补充输入请求不会在这里进入可等待批准的 pending 流程。[网关记录拒绝事件 ↗](../../../apps/server/src/agent-runtime/gateway.ts#L330 "说明当前角色网关收到运行时请求时调用拒绝记录，而非创建等待处理的请求。")
