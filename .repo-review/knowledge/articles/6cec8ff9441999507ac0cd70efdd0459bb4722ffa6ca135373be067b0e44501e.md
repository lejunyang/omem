# 代码理解产物的导出与可信恢复

该模块把当前、成功且由模型生成的代码理解保存为可版本化 JSON，并在仓库重新同步后依据来源摘要和稳定符号定位器恢复到当前快照。它严格区分派生知识与原始证据，拒绝过期、越界、来源不合法或交叉引用失效的产物，但恢复时只完成结构与引用校验，不代表独立语义复核。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_export"></a>
## 解决的问题与导出流程

模块用于在运行时数据库之外保存可携带的派生代码知识；JSON保留生成来源，且不会被重新当作独立原始证据。产物记录目标、依赖摘要、引用节点定位信息、模型输出及可选预算。[产物结构与派生知识定位 ↗](../../../apps/server/src/code/artifacts.ts#L1 "支持产物是可携带派生知识、不会作为独立证据重新摄入，并说明其主要字段。")

导出只接受当前快照中成功、非 seed、未过期且属于当前快照的模型结果，否则立即拒绝。随后收集输出实际引用的节点，将内部符号 ID 转成“文件路径、限定名、类型”定位器，并为目标覆盖的源码及规则证据计算摘要；规则只哈希实际提供的摘录，避免无关位置修改使产物失效。最终文件名由目标标识摘要生成并写入指定目录。[当前模型结果导出门槛 ↗](../../../apps/server/src/code/artifacts.ts#L38 "支持导出仅允许当前快照中的成功模型结果，并展示引用节点的收集与定位器生成。")[依赖清单与文件写出 ↗](../../../apps/server/src/code/artifacts.ts#L25 "支持源码和证据摘录摘要的构造方式，以及确定性文件名和 JSON 写出流程。")

<a id="restore_flow"></a>
## 恢复、重绑定与持久化

恢复过程扫描固定生成目录中的 JSON：先校验版本和模型来源，再比较当前依赖清单摘要。来源正文、证据摘录或目标文件集合变化时，产物被标记为 stale，并保留重新生成原因，而不是导入旧结论。[恢复来源校验与过期判定 ↗](../../../apps/server/src/code/artifacts.ts#L63 "支持恢复时检查模型来源、比较依赖摘要，并将变化产物标记为 stale。")

依赖未变时，系统要求每个节点路径仍处于目标范围内，并按路径、限定名和符号类型在当前快照中重新解析；旧内部 ID 仅用于建立映射，不会直接沿用。重绑定后的输出换用当前输入摘要，再交给统一的 `validateCodeUnderstanding` 检查。[稳定定位器重解析 ↗](../../../apps/server/src/code/artifacts.ts#L80 "支持目标范围约束，以及按路径、限定名、类型把旧节点引用映射到当前符号。")[输出重绑定与统一验证 ↗](../../../apps/server/src/code/artifacts.ts#L87 "支持只替换当前输入摘要和节点引用，再执行严格的代码理解验证。") 通过后才以事务写入理解记录及节点、证据引用；相同生成时间的当前结果会幂等跳过，单个文件异常则进入 rejected 报告，不会中止其余文件。[幂等恢复与事务持久化 ↗](../../../apps/server/src/code/artifacts.ts#L97 "支持重复结果跳过、理解及引用事务写入，以及逐文件 rejected 报告行为。")

<a id="relations_limits"></a>
## 模块关系与边界

该文件依赖代码图存储取得当前快照、文件路径、符号和捕获正文；代码图本身是既有 Fragment 的确定性投影，不另存文件正文，因此产物依赖最终仍锚定捕获材料。[代码图存储身份与投影边界 ↗](../../../apps/server/src/code/store.ts#L1 "解释 artifacts 所依赖的代码图来自已捕获 Fragment、具有确定性身份，且不自行保存文件正文。") 它还复用理解存储构造与模型运行相同的固定快照，并调用 agent-runtime 的稳定摘要及交叉引用验证器；后者要求模型引用只能落在预先固定的文件、节点、边和证据集合中。[固定快照与交叉引用验证器 ↗](../../../packages/agent-runtime/src/code-understanding.ts#L1 "解释 agent-runtime 验证器的职责：模型只可引用运行前固定的可信集合，且验证模块本身不调用模型。")

恢复不是重新运行模型，也不会覆盖已提交产物中的原始模型输出与生成摘要；它只重绑定已检查的引用。数据库备注明确说明来源和引用已通过校验，但尚未进行独立语义复核。[恢复记录的语义复核声明 ↗](../../../apps/server/src/code/artifacts.ts#L101 "支持恢复会保留原生成信息，并明确标注尚未经过独立语义复核。") 此外，定位依赖路径、限定名和类型完全匹配，符号重命名或移出目标范围会被拒绝；源码或规则摘录改变则整体视为过期。当前材料未展示并发写文件、损坏文件修复或 Markdown 投影生成逻辑。
