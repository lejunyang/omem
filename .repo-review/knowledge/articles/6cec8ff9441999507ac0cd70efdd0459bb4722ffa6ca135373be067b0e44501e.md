# 代码理解产物的导出与安全恢复

将当前成功的模型代码理解导出为可版本化 JSON，并在新快照中按稳定定位符重绑定、校验和恢复；产物始终是派生视图而非独立证据。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="export"></a>
## 产物结构与导出条件

代码理解产物保存目标、依赖摘要、被引用节点定位符、模型输出和可选预算；JSON 保留生成来源，Markdown 仅是可读投影，两者都不会作为独立原始证据重新摄取。依赖清单对目标范围内已捕获源码及规则证据分别计算哈希，使内容变化能够令旧产物失效。[派生产物与依赖清单 ↗](../../../apps/server/src/code/artifacts.ts#L1 "支持产物不是独立证据、记录依赖和节点，并按源码及规则证据计算内容哈希。")

导出只接受当前快照中成功、非 seed、非 stale 的模型结果。输出涉及的每个节点都必须能在当前符号图中解析，并以路径、qualified name 和 kind 写入可迁移定位符；不满足条件时立即拒绝导出。[当前模型结果导出 ↗](../../../apps/server/src/code/artifacts.ts#L38 "支持仅导出当前成功模型结果、收集引用节点定位符并生成版本化 JSON 文件。")

<a id="restore"></a>
## 恢复、重绑定与失效处理

恢复时逐个读取版本化 JSON，先检查模型来源真实性：seed、缺少模型标记或冒充独立验证的产物会被拒绝。依赖摘要不一致时标为 stale 并保留原因，而不是覆盖当前知识；节点路径越界或定位符无法解析同样进入 rejected。[恢复前来源与依赖检查 ↗](../../../apps/server/src/code/artifacts.ts#L63 "支持拒绝不合法模型来源、将依赖变化标为 stale，并限制定位符目标范围。")

通过检查后，旧节点 id 才会映射到当前快照符号，并重新执行 `CodeUnderstanding` 合同校验。恢复记录保留原模型输出与原生成摘要，只更新当前引用绑定和输入摘要；写入的 curated note 还明确说明“引用校验通过但未进行独立语义复核”，防止把结构恢复误称为完整复核。[节点重绑定与合同校验 ↗](../../../apps/server/src/code/artifacts.ts#L87 "支持重映射当前节点、重新校验理解合同、保留原生成信息并注明尚未独立语义复核。")
