# omem 部署环境变量示例

定义服务监听地址、端口、数据目录、配置文件路径，以及绑定非回环接口时对强 secret 的要求。路径仍是占位符，示例不能直接作为完成的部署配置。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="network-storage"></a>
## 监听与本地路径

示例将服务绑定到 `127.0.0.1:4317`，并为数据目录和应用配置分别保留绝对路径占位符。[监听与路径变量 ↗](../../../deploy/omem.env.example#L1 "支持默认监听主机、端口，以及数据目录和配置文件使用绝对路径占位符的描述。") 回环地址体现仅供本机访问的保守起点；部署者必须替换路径，才能进一步验证目录权限、数据落盘位置和配置文件是否可读。

<a id="authentication"></a>
## 非回环监听的安全条件

注释明确要求：绑定非回环接口时，应在本地提供强 secret。[非回环接口的 secret 提示 ↗](../../../deploy/omem.env.example#L5 "支持绑定非回环接口时必须在本地提供强 secret 的安全条件。") 示例没有给出 secret，也没有说明 token 的认证机制、权限模型、TLS 或反向代理安排，因此只能确认这一最低配置提醒，不能据此断言远程或公网暴露已经安全。
