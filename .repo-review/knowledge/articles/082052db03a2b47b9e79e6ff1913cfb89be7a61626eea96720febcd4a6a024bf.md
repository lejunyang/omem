# 外部能力回执如何沉淀为可复用材料

该模块把 CLI 或 MCP 外部能力的成功回执转换成 omem 的版本化材料：提取可阅读正文、图片与链接，保存回执载荷快照和来源信息，其中图片临时路径会替换为持久化 assetId；同时通过回执映射与内容摘要避免重复版本。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-call"></a>
## 从一次成功回执开始

`captureCapabilityMaterial` 面向需要长期复用的外部读取结果，而不是把所有工具运行都写进知识库。调用者提供存储实例、工作目录、`CapabilityReceipt`，以及材料标题和可选上下文 ID；失败结果、非零退出码会立即拒绝。代表性场景是：外部工具刚返回一份文档，调用者选定标题后交给此函数，它完成内容提取、版本选择并返回可阅读的材料对象。参考 [捕获函数输入 ↗](../../../apps/server/src/capabilities/materials.ts#L12 "支持函数用途、调用参数以及只保存可复用输入的职责说明。") [失败回执拦截 ↗](../../../apps/server/src/capabilities/materials.ts#L39 "支持失败结果和非零退出码不能保存为材料的边界。")

<a id="normalization"></a>
## 把异构结果归一为材料部件

CLI 回执只取 `stdout`；其他回执逐块处理文本、内嵌文本资源、图片文件和 HTTP(S) 链接。文本保持 Markdown 原样，并按 20 万字符切片；图片文件名必须以当前回执 ID 开头，随后保存原件，只有 PNG/JPEG/WebP 且不超过 5 MB 才嵌入阅读部件，其余类型只留下警告。`structuredContent` 会格式化为 JSON，但若已有文本解析后摘要相同就不重复加入；最终若没有正文或图片则拒绝捕获。参考 [文本切片与 CLI 提取 ↗](../../../apps/server/src/capabilities/materials.ts#L43 "支持 Markdown 文本按存储上限切片以及 CLI 只提取 stdout 的行为。") [MCP 内容块处理 ↗](../../../apps/server/src/capabilities/materials.ts#L53 "支持文本资源、图片、链接和未知块的归一化规则，以及图片临时路径被持久化 assetId 替换的行为。") [结构化内容与空材料校验 ↗](../../../apps/server/src/capabilities/materials.ts#L96 "支持 structuredContent 的摘要去重和没有正文或图片时拒绝保存。")

<a id="identity-and-versioning"></a>
## 两层去重与版本落库

流程先查“回执 ID → 版本 ID”映射，同一回执再次捕获会直接返回旧版本，并把新上下文 ID 与材料已有上下文去重合并。参考 [回执幂等与上下文合并 ↗](../../../apps/server/src/capabilities/materials.ts#L20 "支持同一回执复用既有版本，以及返回材料时合并上下文 ID。")

随后以“能力、回执类型、工具、参数”的摘要确定逻辑材料身份，再以规范化后的部件和警告计算响应摘要：身份相同且响应摘要未变时复用当前版本；内容变化时保存回执载荷快照，其中 `image_file` 的临时 `path` 已替换为持久化 `assetId`，其余载荷随回执一并写入资产。接着构造 `hook` 来源、外部工具元数据和 provenance，经 `captureSchema` 校验后调用 `store.capture` 创建新版本。最后记录回执映射并返回该版本对应的材料。参考 [MCP 内容块处理 ↗](../../../apps/server/src/capabilities/materials.ts#L53 "支持文本资源、图片、链接和未知块的归一化规则，以及图片临时路径被持久化 assetId 替换的行为。") [材料身份与响应摘要 ↗](../../../apps/server/src/capabilities/materials.ts#L115 "支持逻辑身份由能力调用参数决定、版本复用由规范化响应摘要决定。") [回执快照与新版本捕获 ↗](../../../apps/server/src/capabilities/materials.ts#L131 "支持将经过图片引用改写的 raw 结果随回执保存为资产，并构造捕获输入、创建版本和记录回执映射。")
