# 共享阅读界面与可追溯证据导航

共享 UI 包统一应用外壳、来源提示、证据 Trail、代码高亮和视觉基线，使个人记忆与仓库知识沿同一阅读合同展示内容、追溯依据并恢复上下文；核心组件已经具备，URL 深链边界和完整浏览器集成仍待验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="reader-foundation"></a>
## 统一知识阅读界面

共享 UI 包集中公开应用外壳、基础控件、Markdown、代码查看器、来源状态、关系图和证据抽屉，并提供 Trail 状态及哈希路由接口，供不同知识入口复用。参考 [共享 UI 公共入口 ↗](../../../packages/ui/src/index.ts#L1 "支持阅读组件、Trail 工具、组合式状态和哈希路由接口由同一包级入口公开。")

应用外壳通过插槽组织顶部工具区、导航、正文和可选助理区。宽屏下导航、正文与助理形成各自滚动的三栏布局；宽度降低后，助理先转为右侧抽屉，导航再转为左侧抽屉。业务路由、数据加载与助理内容仍由上层提供。参考 [应用外壳插槽结构 ↗](../../../packages/ui/src/components/OmShell.vue#L8 "支持顶部工具区、导航、正文和可选助理区由插槽组成。") [桌面三栏布局 ↗](../../../packages/ui/src/components/OmShell.vue#L46 "支持全视口外壳、固定宽度导航与助理栏、弹性正文以及各区域独立滚动。") [响应式侧栏规则 ↗](../../../packages/ui/src/components/OmShell.vue#L107 "支持助理和导航在两个断点下转为固定侧边抽屉。")

全局令牌统一中性配色、中文字体和页面排版。按钮、链接、输入框、文本域、选择器及 `summary` 获得统一的可见焦点样式；这不代表所有可聚焦对象均有同等焦点提示。系统要求减少动态效果时，动画、过渡和平滑滚动会被关闭。参考 [视觉令牌与排版基线 ↗](../../../packages/ui/src/tokens.css#L1 "支持共享配色、中文字体栈、页面背景和正文排版由全局令牌统一定义。") [指定控件的焦点样式 ↗](../../../packages/ui/src/tokens.css#L38 "仅支持按钮、链接、输入框、文本域、选择器和 summary 具有统一的 focus-visible 轮廓，不扩展为所有可聚焦对象。") [减少动态效果 ↗](../../../packages/ui/src/tokens.css#L91 "支持系统减少动效偏好会关闭动画、过渡和平滑滚动。")

<a id="evidence-reading"></a>
## 从内容性质到证据追溯

阅读器先用状态行区分原始证据、派生说明、候选判断、过期内容、加载失败与人工整理；这一标识描述内容来源层级，不替代关系边的确认状态。参考 [内容来源状态 ↗](../../../packages/ui/src/components/OmStatusLine.vue#L2 "支持六类来源阶段的中文标识，并说明它不表示关系边状态。")

点击引用或关联对象后，共享组合式函数按对象类型与稳定身份去重并压入帧栈，同时记录首次触发元素；关闭、返回和跳转会更新响应式状态并通知上层。参考 [共享 Trail 状态流 ↗](../../../packages/ui/src/useEvidenceTrail.ts#L4 "支持帧去重、触发元素记录、入栈、关闭、返回和跳转由共享组合式函数管理。")

```mermaid
flowchart LR
  A[阅读知识正文] --> B[辨认内容来源]
  B --> C[打开引用或关联对象]
  C --> D[压入证据帧]
  D --> E[逐层阅读与返回]
  E --> F[关闭并恢复焦点]
```

抽屉打开或切层时会把程序焦点移至当前标题并恢复滚动位置；Esc 在多层路径中返回上一层，仅剩一层时请求关闭。参考 [切层与滚动恢复 ↗](../../../packages/ui/src/components/OmTrailDrawer.vue#L35 "支持抽屉打开和切层时聚焦标题、恢复滚动位置，并按栈深度处理 Esc。") 关闭后优先把焦点归还给显式触发元素，否则回到打开前的焦点。参考 [关闭后的焦点归还 ↗](../../../packages/ui/src/components/OmTrailDrawer.vue#L44 "支持关闭时优先聚焦显式目标，否则恢复打开前焦点，并在卸载时进行清理。")

<a id="trail-contract"></a>
## 可恢复的分层阅读路径

Trail 帧可表示模块、文件、符号、评审片段、知识、引用和原始来源等对象，以类型和稳定身份支持循环检测，并携带人读标题、滚动位置及父级加载数据所需的引用字段。参考 [Trail 帧数据合同 ↗](../../../packages/ui/src/trail.ts#L6 "支持帧种类、稳定身份、人读标题、滚动位置和数据引用字段的说明。")

抽屉通过面包屑、父层入口、当前标题和循环提示呈现阅读路径；发现重复对象时，读者可以跳回已有层或留在当前层。参考 [路径导航与循环提示 ↗](../../../packages/ui/src/components/OmTrailDrawer.vue#L107 "支持面包屑、父层入口、当前标题和重复访问提示构成证据路径界面。")

帧可编码为 URL 哈希片段，为刷新恢复和分享深链提供基础。当前约定把 200 层作为 URL 持久化预算，渲染栈不应静默截断；但压栈函数的注释声称受预算约束，实际实现仍直接追加，因此超限提示和拒绝持久化只能由未展示的路由调用方承担。参考 [Trail 序列化与深度边界 ↗](../../../packages/ui/src/trail.ts#L32 "支持哈希片段编码和 URL 深度预算，并揭示预算说明、压栈注释与实际追加实现之间的不一致。")

<a id="code-reading"></a>
## 安全的代码展示与现有边界

代码高亮按语言别名懒加载语法定义；未知语言不自动猜测，而是转义标记后原样展示。XML 高亮还会预先注册 JavaScript 与 CSS，以处理嵌入内容。参考 [语言加载与安全降级 ↗](../../../packages/ui/src/highlight.ts#L3 "支持语言别名懒加载、未知语言转义及 XML 依赖注册的代码高亮流程。")

为让编号行能够独立渲染，拆分器在换行处临时闭合活动 `span`，再于下一行重新打开，从而保留跨行注释等词法样式；该算法只接受 highlight.js 生成的受控 HTML，不是通用解析器。参考 [跨行高亮拆分 ↗](../../../packages/ui/src/highlight.ts#L35 "支持换行时闭合并重开活动样式，以及拆分器仅适用于 highlight.js 输出的边界。")

现有测试验证了 TypeScript 跨行注释样式，以及已知、未知语言输入的标记转义。参考 [代码高亮行为测试 ↗](../../../packages/ui/src/highlight.test.ts#L4 "支持现有测试覆盖 TypeScript 跨行样式和已知、未知语言输入的标记转义。") 尚未由材料证明的部分包括全部语言别名与并发注册、真实查看器的长代码和窄屏行为，以及 Trail 的 URL 恢复、越界跳转和超长路径提示。
