# 共享 UI：可追溯知识阅读与应用界面基础

该模块以统一视觉基线和应用外壳承载页面，并把来源标识、代码高亮及可序列化 Evidence Trail 组合成个人知识与仓库评审可共用的阅读合同；核心能力已形成，但深链预算、索引防御和部分浏览器交互仍待验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role-and-surface"></a>
## 职责与模块边界

共享 UI 包把基础控件、应用外壳、Markdown 与代码阅读器、来源状态、关系图和 Trail 抽屉集中为稳定出口，同时公开图、代码范围、Trail 与哈希路由类型，供上层应用组装而不依赖内部路径。[共享 UI 公共出口 ↗](../../../packages/ui/src/index.ts#L1 "支持模块统一导出基础组件、知识阅读组件以及 Trail、图和哈希路由合同的论断。") 全局令牌统一中性色、中文优先字体、表单和键盘焦点，并在减少动态效果偏好下关闭动画；代码查看器与 Markdown 围栏共用语法主题。[视觉基线与无障碍样式 ↗](../../../packages/ui/src/tokens.css#L1 "支持共享视觉变量、键盘焦点、减少动态效果及代码语法主题的说明。") 这些能力负责呈现和交互合同，不负责知识事实、路由数据加载或关系状态判定。

<a id="shell-and-provenance"></a>
## 页面骨架与可信层级

`OmShell` 提供顶栏、导航、主内容及可选助手插槽：桌面保持三栏，低于 1100px 时助手转为右侧覆盖层，低于 700px 时导航也转为左侧覆盖层。[应用外壳与响应式侧栏 ↗](../../../packages/ui/src/components/OmShell.vue#L8 "支持页面插槽组成以及 1100px、700px 两级侧栏切换流程和现有交互边界。") 当前覆盖层主要由本地布尔状态和 CSS 控制，材料未显示遮罩、Escape、焦点约束或展开状态属性，因此不能把它视为完整的模态导航。

知识内容旁的 `OmStatusLine` 则明确区分原始证据、派生说明、候选、过期、错误和人工整理，并刻意不承担关系边状态展示。[内容来源状态提示 ↗](../../../packages/ui/src/components/OmStatusLine.vue#L2 "支持六种来源层级及其与关系状态徽章职责分离的论断。") 这使“内容从何而来”与“关系是否确认”保持分离，避免把派生解释误当作独立证据。

<a id="evidence-trail"></a>
## 证据路径如何协作

Trail 将模块、文件、符号、知识、引用和来源建模为带稳定身份、人读标题及滚动位置的可序列化帧；`kind + id` 用于查环，帧还能携带加载内容所需的引用字段。[证据路径帧合同 ↗](../../../packages/ui/src/trail.ts#L1 "支持 Trail 的可序列化目标、帧种类、稳定身份、人读标题和滚动字段说明。") `useEvidenceTrail` 负责入栈、返回、跳层、关闭和循环提示状态，首次打开时记录触发元素，并通过回调让外层同步路由。[共享 Trail 状态管理 ↗](../../../packages/ui/src/useEvidenceTrail.ts#L4 "支持入栈查重、触发元素记录、关闭、返回、跳转及变更回调流程。")

`OmTrailDrawer` 以原生模态对话框呈现整条路径：Escape 在多层时退一层、根层时关闭，面包屑可回跳，切层恢复滚动并聚焦标题，完全关闭后尝试归还焦点。[Trail 对话框交互生命周期 ↗](../../../packages/ui/src/components/OmTrailDrawer.vue#L30 "支持模态打开、焦点与滚动恢复、Escape 分层返回、面包屑和循环提示的说明。") `MAX_TRAIL=200` 只声明 URL 持久化预算，渲染栈本身不应截断；但现有 `pushFrame` 实际始终追加，因此超限拒绝和可见提示必须由尚未展示的路由层落实。[Trail 深链预算与压栈实现 ↗](../../../packages/ui/src/trail.ts#L37 "支持 200 层仅约束 URL 持久化，并揭示压栈函数尚未应用该预算的限制。")

<a id="code-reading-progress"></a>
## 代码阅读进展与限制

代码高亮按语言别名懒加载有限的 highlight.js 语法；未知语言直接转义，XML 额外注册脚本与样式语言。逐行拆分会在换行处闭合并重开活动 `span`，从而保留跨行注释等词法状态，但它只适用于 highlight.js 输出，不是通用 HTML 解析器。[安全高亮与逐行拆分 ↗](../../../packages/ui/src/highlight.ts#L3 "支持语言懒加载、未知语言转义及跨行 span 状态保持的实现与输入前提。")

现有测试已验证 TypeScript 跨行注释拆分、关键字识别，以及已知和未知语言都不会输出真实恶意标签。[代码高亮测试范围 ↗](../../../packages/ui/src/highlight.test.ts#L1 "支持已验证的跨行高亮和标记转义行为，并界定当前仅有的测试覆盖。") 尚未覆盖全部别名、并发注册、异常嵌套、真实查看器渲染，也没有在所给材料中证明 Trail 的初始打开、深层路径、焦点归还和移动端行为经过浏览器测试。
