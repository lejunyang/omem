# 空状态展示组件

为无数据或无结果场景提供居中的标题、可选说明与扩展操作插槽。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="structure"></a>
## 内容结构与扩展点

组件要求调用方提供 title，可选提供 description；模板始终渲染二级标题，仅在说明存在时渲染段落，并通过默认插槽容纳按钮、链接或其他后续动作。[空状态属性与插槽 ↗](../../../packages/ui/src/components/OmEmpty.vue#L1 "支持标题必填、说明可选及默认插槽扩展职责的说明。") 它不感知数据加载、错误类型或重试逻辑，只负责把上层决定的空状态内容统一排版，因此业务含义和交互均由调用方控制。

<a id="presentation"></a>
## 视觉边界

容器采用较大的上下内边距、居中排版和次级文字色，标题恢复主要文字色；说明文字最大宽度为 480px，并在下方保留动作区间距。[空状态排版样式 ↗](../../../packages/ui/src/components/OmEmpty.vue#L11 "支持居中布局、颜色与说明宽度限制的视觉说明。") 当前文件没有图标、状态角色、aria-live 或标题层级参数。固定使用 h2 是否符合所在页面的标题大纲取决于调用环境，材料中也没有组件测试说明空 description、插槽内容或无障碍语义的预期。
