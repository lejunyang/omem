# 仓库知识与检索的可复现验收脚本

该脚本为 repo-review 生成仅代表本次运行的验收报告：固定源码与题集指纹，按模式执行项目检查，恢复并校验当前知识，再通过真实 HTTP 搜索评估中文回归问题。它不直接执行生成式知识复核，且覆盖不足、未配置语义检索等状态并不必然导致失败。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 作用与验收边界

脚本把仓库检查、知识一致性和检索回归收束为一份可追溯报告。启动时计算 Git 已跟踪及未忽略文件的内容指纹，并固定检索题集指纹；报告绑定当前提交和运行模式。只有 `--full` 才直接启动依赖冻结、项目检查与实时中文检索三个 `osdk` 任务，否则明确记为 skipped，且不继承旧结果。[运行指纹与完整模式命令 ↗](../../../scripts/review-verify.ts#L17 "支持源码和题集指纹的固定方式，以及仅在 full 模式直接执行三个 osdk 检查任务的说明。")

报告声明本次自动检查不调用生成式模型，独立语义复核只读取知识文章中已有记录。更准确地说，本脚本未直接调用外部 Agent CLI；被启动的 `osdk` 下游任务是否还会调用外部 Agent CLI，仅凭当前材料不能确定。[报告声明的模型调用边界 ↗](../../../scripts/review-verify.ts#L49 "支持报告不继承历史通过率、不调用生成式模型，以及语义复核记录来自现有知识文章的边界声明。")

<a id="flow"></a>
## 知识校验与检索流程

脚本先同步评审材料与代码图，恢复知识文章并刷新仓库。逐篇执行结构和引用校验，要求独立复核 verdict 为 accepted，并比较材料摘要或文章 revision；依赖变化会被判为 stale。覆盖统计会区分已复核与待处理材料，覆盖不足写为 `incomplete`，但当前引用检查只在实际文章错误存在时失败。[知识恢复、依赖校验与覆盖统计 ↗](../../../scripts/review-verify.ts#L52 "支持当前文章的结构、复核状态和依赖新鲜度校验，并说明覆盖不足只记为 incomplete、引用错误才使相应检查失败。")

随后它重写知识索引，按配置构建 review HTTP 应用。若检索器为语义实现，就循环补齐索引并记录健康状态；否则仅标记 skipped。服务绑定随机本地端口，从固定题集请求 `/api/review/search`，并记录目标路径排名、去重数、路由与摘要；预期路径未进入前五即判仓库搜索失败。该回归只能证明有限题集的 top-5 命中，不能证明摘要支持答案或深链实际可用。[语义索引与真实 HTTP 搜索回归 ↗](../../../scripts/review-verify.ts#L73 "支持语义索引补齐、随机端口 HTTP 搜索、top-5 判定，以及有限题集不代表回答正确的限制。")

<a id="failure_and_output"></a>
## 失败处理、报告与历史产物

主流程异常会汇总为 `repositoryRun` 失败，但 finally 仍关闭 HTTP 应用或数据库；结束前重新计算源码和题集指纹，检查验收期间输入是否变化。最终只有不存在 failed 检查时 `passed` 才成立，否则设置非零进程退出码。[异常收敛、输入复查与退出码 ↗](../../../scripts/review-verify.ts#L100 "支持异常记录、资源关闭、源码和题集不变性复查，以及失败时设置非零退出状态。")

每个直接启动的 `osdk` 命令都会合并保存标准输出与错误输出到 `.repo-review/runtime/verification/<runId>`，并在检查详情中记录退出码、相对日志路径和内容哈希。[命令日志保存与结果摘要 ↗](../../../scripts/review-verify.ts#L34 "支持直接运行的 osdk 子进程合并输出到 runtime 日志，并记录退出码、日志路径与哈希。") 写入新报告前，已有 `verification.json` 会根据原报告时间与旧内容哈希归档到 history，避免丢失历史快照。[旧验收报告归档 ↗](../../../scripts/review-verify.ts#L104 "支持旧 verification.json 按原记录时间与内容哈希命名并在写入新报告前归档。")

语义检索未配置、非 full 项目被跳过或知识覆盖不足，本身都不一定使总结果失败；脚本也不执行浏览器交互或生成式知识复核。它因此适合作为当前快照的机械一致性和有限行为回归证据，而不能单独代表全库知识已生成或端到端回答质量已验收。[知识恢复、依赖校验与覆盖统计 ↗](../../../scripts/review-verify.ts#L52 "支持当前文章的结构、复核状态和依赖新鲜度校验，并说明覆盖不足只记为 incomplete、引用错误才使相应检查失败。") [语义索引与真实 HTTP 搜索回归 ↗](../../../scripts/review-verify.ts#L73 "支持语义索引补齐、随机端口 HTTP 搜索、top-5 判定，以及有限题集不代表回答正确的限制。")
