# 仓库知识与检索的一次性验收流程

该脚本把依赖检查、项目检查、知识引用校验、语义索引和真实 HTTP 检索串成一次可复现验收，记录当前源码与题集指纹、日志和退出状态，并归档旧报告。它验证当前快照与有限回归问题，不调用生成式模型，也不把历史结果或 top-5 命中解释为完整正确性证明。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决什么问题

脚本为仓库知识系统生成**仅代表本次运行**的验收报告。启动时固定源码与检索题集的摘要，并把报告、历史版本和运行日志分别写入知识目录与忽略提交的运行目录，从而能够判断检查期间输入是否变化，避免把旧结果混入当前结论。参考 [验收输入与输出指纹 ↗](../../../scripts/review-verify.ts#L18 "支持脚本固定源码和题集摘要，并划分当前报告、历史报告与运行日志位置的说明。")

`--full` 决定是否执行依赖锁定、项目全检和中文检索冒烟；非完整模式明确记为 skipped，而不是继承历史通过状态。每个子进程的退出码、命令、日志位置及内容摘要都会进入检查记录。参考 [子进程检查记录 ↗](../../../scripts/review-verify.ts#L35 "支持完整模式开关、退出码判定、日志保存，以及非完整模式不继承历史结果的说明。")

<a id="knowledge-flow"></a>
## 知识正文与引用校验

同步仓库材料和代码快照后，脚本恢复已发布知识并刷新仓库视图。它逐篇校验当前文章的结构与内联引用，要求独立复核结论为 accepted，还会比较材料摘要或文章修订号；依赖过期会判错，未覆盖材料则标记为 incomplete，不冒充全库已完成。参考 [当前知识有效性检查 ↗](../../../scripts/review-verify.ts#L59 "支持文章结构、独立复核、依赖新鲜度和覆盖不完整状态的判定流程。")

```mermaid
flowchart LR
  A[同步材料与代码] --> B[恢复当前知识]
  B --> C[校验引用与独立复核]
  C --> D[写出知识索引]
```

这条流程直接调用既有的仓库同步、代码同步、知识恢复和通用文档校验能力，因此脚本承担验收编排，而不另建知识存储。参考 [同步与知识模块调用 ↗](../../../scripts/review-verify.ts#L9 "证明验收脚本复用仓库同步、代码同步、知识恢复和通用文档校验模块。")

<a id="retrieval-flow"></a>
## 语义索引与真实搜索回归

脚本按配置构建 review HTTP 应用；若启用语义检索，就分批补齐索引并记录健康状态，否则把语义索引检查标为 skipped。随后它在本机临时监听端口，对题集逐条请求 `/api/review/search`，并同时取得带可见性条件的底层检索结果作为基线，记录前五名路径、多样性、耗时和路由信息。参考 [语义索引与搜索请求 ↗](../../../scripts/review-verify.ts#L76 "支持语义索引补建、临时 HTTP 服务、真实搜索请求和带可见性条件的底层基线采集流程。")

每个用例仅以**预期路径是否进入 API 返回结果前五名**作为通过条件。该检查证明真实 API 请求和路径 top-5 召回链路可运行，但没有逐项断言 API 返回项均属于 eligible 集合，也不证明摘要或最终回答的语义正确性。参考 [前五名路径断言 ↗](../../../scripts/review-verify.ts#L92 "支持 API 用例以预期路径进入 top-5 为通过条件，并表明脚本未对 API 返回项逐项执行 eligible 可见性断言。")

<a id="boundaries"></a>
## 失败语义与覆盖边界

任一检查失败都会令总结果失败并设置非零进程退出码；无论成功与否，服务或存储都会关闭。报告写入前，旧报告按时间和内容摘要归档，最后再次比较源码及题集摘要，以检测验收期间的输入漂移。参考 [归档与退出状态 ↗](../../../scripts/review-verify.ts#L103 "支持资源关闭、输入漂移检测、旧报告归档以及失败时返回非零退出码的说明。")

该脚本明确不调用生成式模型，知识的语义正确性依赖文章中已有的独立复核记录。检索部分只是六条公开问题的 top-5 回归，不代表完整相关性评测，也未覆盖生成式回答质量、外部部署安全或所有检索问法。参考 [验收范围声明 ↗](../../../scripts/review-verify.ts#L52 "支持报告不调用生成式模型、不继承历史通过率，以及检索回归不等同于完整相关性评测的边界。")
