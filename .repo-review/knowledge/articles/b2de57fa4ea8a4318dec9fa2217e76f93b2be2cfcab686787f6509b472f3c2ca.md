# 代码理解模型接入与生成测试

验证 Code Wiki 的显式模型配置、真实 HTTP 传输与生成结果落库，并分别覆盖模型缺席、输出畸形、引用失效和请求超时的安全降级；原始代码图不依赖模型。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-flow"></a>
## 测试目标与核心流程

该测试覆盖代码理解从仓库快照到模型生成结果的服务路径。夹具创建临时 Git 仓库、提交 TypeScript 文件，再执行评审同步与代码同步，并从数据库取得真实符号标识，因此模型叙述引用的是当前代码图节点。[临时仓库与代码图准备 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L43 "支持测试通过已提交仓库、评审同步和代码同步构造当前图，并取得真实符号标识。") 成功场景通过本地 HTTP 服务走真实 `fetch` 传输；返回叙述经封装、交叉引用校验和持久化后成为当前结果，同时保留响应中的模型名称，并明确记录为非 seed、尚未经过独立代理核验。[模型生成成功路径 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L136 "支持真实 HTTP 响应经过生成接口落库，并保留模型身份、seed 与核验状态的论断。")

<a id="failure-boundaries"></a>
## 失败边界与未覆盖行为

模型不是原始代码图的前置条件：未配置时状态接口报告不可用、生成接口返回 503，但图接口仍可读取；未知传输会显式报错。[无模型时的降级行为 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L107 "证明模型不可用不会阻断原始代码图，并说明不支持的传输配置会显式失败。") 畸形 JSON 返回 502，未知节点引用返回 422，两者都不会留下可作为当前理解的模型生成行。[畸形输出与未知引用拒绝 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L178 "支持畸形 JSON 和未知节点引用分别被拒绝，且不会产生当前模型理解。") 请求超过给定预算时同样返回 502，且没有模型生成结果成为当前理解。[模型请求超时处理 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L224 "支持请求超时返回失败状态，并且失败结果不会成为当前模型理解。") 配置测试还限定只读取显式文件路径：空路径禁用模型，非法传输和损坏 JSON 必须报错。[显式模型配置约束 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L248 "支持空路径禁用、仅从显式路径读取配置，以及非法传输和损坏配置被拒绝。") 本文件未覆盖真实外部供应商、认证头、重试、并发生成或预算耗尽；本地 HTTP 夹具只证明实际传输路径与失败隔离。
