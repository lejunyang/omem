# 代码理解模型生成与配置的行为验证

该测试通过临时 Git 仓库、SQLite 存储和本地 HTTP 模型，验证代码理解生成在未配置、成功、输出非法、引用失效和配置错误等场景下的外部行为，并揭示超时用例与失败记录断言仍不充分。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-fixture"></a>
## 验证目标与真实边界

这组测试关注“代码图已经可用，但模型生成是显式可选能力”的场景。每个用例创建临时 Git 仓库和独立 Store，先执行仓库材料同步与代码同步，再从真实代码图取得 `Alpha` 符号，因而生成测试建立在实际持久化图谱上，而非手写节点桩。参考 [临时仓库与代码图准备 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L93 "支持测试先执行真实 review/code 同步并从持久化代码图取得目标符号的说明。")

模型侧使用监听随机本地端口的 HTTP 服务，实际经过 `fetch` 传输；不过服务只消费请求体，没有断言提示词、请求字段或认证头，因此这些协议细节未被覆盖。参考 [本地 HTTP 模型服务 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L71 "说明测试走真实本地 HTTP 传输，同时显示服务未校验收到的请求正文。")

<a id="generation-behavior"></a>
## 生成、校验与降级流程

未配置模型时，状态接口仍正常返回但标记不可用，生成接口返回 503；原始代码图接口继续提供服务，证明模型能力不会阻断基础浏览。参考 [无模型时的降级行为 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L107 "支持模型状态、生成 503 与原始代码图仍可访问的断言。")

成功路径让 HTTP 模型返回带节点引用的叙述 JSON，随后通过 API 触发生成，并检查结果进入可列出的模型生成理解，同时保留响应中的真实模型名称，且不冒充人工 seed 或独立代理复核。参考 [模型生成成功路径 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L136 "支持真实 HTTP 响应被保存，并保留模型标识及非 seed、非代理复核属性的论断。") 这条链路经测试文件直接调用评审应用，而应用明确接入理解列表、详情、可用性和生成函数，并通过独立模型端口提供传输配置。参考 [评审应用的理解生成依赖 ↗](../../../apps/server/src/review/app.ts#L41 "说明评审应用连接理解存储功能与可配置模型传输端口，是测试跨模块关系的源代码依据。")

异常路径分别覆盖无法解析的模型文本和不存在的节点引用：前者返回 502，后者返回 422 与 `UNKNOWN_NODE_REFS`，两者都不得成为当前模型理解。参考 [非法输出与未知引用处理 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L178 "支持非法 JSON 返回 502、未知节点引用返回 422，且均不进入当前模型理解列表。")

<a id="configuration-and-gaps"></a>
## 显式配置及尚未证实的行为

配置入口坚持显式选择：空路径关闭模型；有效文件只构建 HTTP 端口；未知 transport 或损坏 JSON 都直接抛出模型不可用错误。这验证了测试范围内不会因空配置偷偷读取个人设置。参考 [显式模型配置规则 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L248 "支持空配置禁用模型、有效 HTTP 配置可构建端口以及错误配置被明确拒绝。")

超时用例意图验证 300 毫秒预算和失败留痕，但本地服务的处理器被同步读取；返回一个永不完成的 Promise 后，服务仍会立即访问其 `status` 与 `body` 并结束响应。因此现有断言最多证明请求最终得到 502 且没有当前理解，不能单独证明请求确由超时中止，也没有直接检查所谓 failed row。参考 [服务处理器的同步读取方式 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L72 "说明假模型会同步读取处理器返回值的字段，不会等待处理器返回的 Promise。") [当前超时用例断言 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L224 "支持超时用例的实现方式及其仅检查 502 和当前理解为空、未检查失败记录的判断。") 同样地，非法 JSON 用例只检查“当前列表为空”，并未验证失败审计记录的状态和错误内容。参考 [非法输出与未知引用处理 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L178 "支持非法 JSON 返回 502、未知节点引用返回 422，且均不进入当前模型理解列表。")
