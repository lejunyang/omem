# 代码理解模型接入与生成测试

验证显式模型配置、真实 HTTP 传输、生成结果落库，以及模型不可用、超时、格式错误和引用失效时的安全降级。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_flow"></a>
## 生成输入与成功路径

夹具创建并提交临时仓库，先执行评审同步和代码同步，再从数据库取得真实 Alpha 符号，因此模型输出引用当前代码图节点，而非任意伪造标识。[仓库与真实符号准备 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L43 "支持模型测试先建立代码快照并从数据库取得真实符号标识。") 成功场景通过本地 HTTP 服务走真实 fetch 传输；返回叙述经封装和引用校验后成为当前 model-generated 结果，并保留响应实际给出的模型名，同时标记为非 seed、未经 agent 验证。[HTTP 模型生成成功路径 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L136 "支持模型叙述经接口生成、校验和持久化后成为当前结果，并保留返回模型身份。")

<a id="failure_boundaries"></a>
## 不可用与失败隔离

模型不是原始代码图的前置条件：未配置时状态接口报告不可用、生成返回 503，但图仍可读取；未知 transport 会显式报错。[无模型降级与传输限制 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L107 "证明模型不可用不阻断原始图，并说明未知传输会显式失败。") 畸形 JSON 返回 502，未知节点引用返回 422，二者都不会产生当前 model-generated 行。[畸形输出与未知引用拒绝 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L178 "支持畸形 JSON 和未知节点引用分别失败，且不会成为当前模型理解。") 请求超时同样中止运行、返回 502，且不留下当前模型理解。[模型请求超时 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L224 "直接支持超时请求返回失败且不留下当前 model-generated 行。") 这些测试证明失败隔离，不证明重试、并发取消或供应商兼容性。

<a id="configuration"></a>
## 显式配置边界

配置测试限定模型只从显式文件路径构建：空路径禁用模型，合法 HTTP 配置保留 endpoint 与 model，未知传输和畸形 JSON 都必须明确失败。[显式模型配置约束 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L248 "支持空路径禁用、显式配置文件读取，以及非法传输和坏 JSON 报错。") 因而材料没有支持读取个人 Agent profile 的结论。测试使用本机无认证 HTTP 服务，尚未覆盖认证头、预算耗尽、真实外部模型、进程重启恢复及响应流式传输。
