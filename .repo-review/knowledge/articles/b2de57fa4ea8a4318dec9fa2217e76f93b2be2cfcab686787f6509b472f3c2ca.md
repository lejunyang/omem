# 代码理解模型端口与生成流程测试

该测试以临时 Git 仓库、隔离 SQLite Store 和本地 HTTP 模型夹具验证代码理解生成的宿主合同：模型需显式配置；合法输出经节点引用校验后成为当前理解；格式错误、未知引用和超时不会产生当前模型理解；配置入口对非法内容明确报错。它不证明真实 Agent CLI/ACP 链路可用，也尚未证明失败运行会保留既有有效理解。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-fixture"></a>
## 测试目标与夹具边界

测试创建临时 Git 仓库，提交含 `Alpha` 的 TypeScript 文件，再执行材料同步与代码图同步，并从数据库取得实际符号 ID。每例使用隔离 Store，结束后关闭数据库并清理目录，因此覆盖的是“源码提交→仓库同步→代码图→理解生成”的最小集成链路，而非直接伪造图节点。[临时仓库与同步夹具 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L29 "支持测试通过真实 Git 提交、材料同步、代码图同步和数据库符号查询构造最小集成链路。")

模型端是监听随机回环端口的本地 HTTP 服务，调用确实经过 `fetch` 传输，但返回内容完全由测试处理器控制。它适合验证 HTTP 适配、响应解析与宿主校验，不等同于真实 Agent CLI、ACP 或外部模型现场检查。[本地 HTTP 模型夹具 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L71 "说明测试实际经过本地 HTTP 传输，同时界定其返回由夹具控制，不能证明真实外部模型链路。")

<a id="generation-contract"></a>
## 生成、降级与失败隔离

未配置模型时，状态接口标记不可用，生成接口返回 503，而原始代码图仍可读取；未知 transport 会明确抛错，`none` 或空配置则关闭模型，说明派生理解不是代码图可用性的前置条件。[无模型与非法传输配置 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L107 "支持模型不可用时生成接口降级但原始代码图仍可访问，以及未知 transport 被明确拒绝。")

成功夹具返回叙事、已存在的符号引用及 `fixture-model-v1`。生成后出现一条 `model-generated` 记录，状态为 generated；响应提供的模型标识被持久化，同时记录不是 seed，也未标记为独立 agent 复核。此前“成功必须返回真实模型标识”的结论被替代：本文件仅证明提供的夹具标识会被记录，未证明该字段缺失必然被拒绝。[模型生成成功路径 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L136 "支持合法叙事成为当前模型理解、响应中的夹具模型标识被记录，以及 seed 和复核标记的实际断言范围。")

畸形 JSON、未知节点引用和超时分别返回 502、422、502，且都不会形成当前模型理解。此前“失败不能覆盖有效知识”的结论也被收窄：这些用例都从没有模型理解的新 Store 开始，只能证明失败结果自身不会成为当前理解。[错误输出与超时用例 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L178 "支持畸形 JSON、未知节点引用和超时不会产生当前模型理解，同时表明这些用例没有预先建立旧的有效理解。")

<a id="config-and-gaps"></a>
## 配置入口与尚未覆盖的行为

配置测试确认空的显式路径会禁用模型；指定 JSON 文件时依据文件内容构建 HTTP 端口并保留配置模型名；不支持的 transport 与畸形 JSON 均抛出 `CodeModelUnavailableError`，避免静默接受无效配置。[显式模型配置文件测试 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L248 "支持空路径禁用、显式 JSON 配置加载，以及非法 transport 和畸形配置被明确拒绝。")

现有断言集中于接口状态、错误类别和当前理解列表，尚未检查失败审计行的状态与错误字段，也未覆盖成功后再次失败时旧理解是否保留、并发生成、服务断开及完整持久化内容。真实模型发现、能力协商、认证、运行 trace 和独立复核仍需另行 live-check；本地 HTTP 夹具不能替代这些证据。[本地 HTTP 模型夹具 ↗](../../../apps/server/tests/code-understanding-model.test.ts#L71 "说明测试实际经过本地 HTTP 传输，同时界定其返回由夹具控制，不能证明真实外部模型链路。")
