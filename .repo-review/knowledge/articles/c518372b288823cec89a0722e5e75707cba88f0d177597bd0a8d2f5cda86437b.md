# 命令行捕获与 ACP 探测入口

提供面向运行中服务的轻量命令行入口，将多种输入规范化后提交捕获 API，并提供独立 ACP profile 探测。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="request-boundary"></a>
## 服务连接与请求处理

CLI 从环境或服务配置得到 API 基址，读取可选访问令牌，并通过统一 `send` 方法提交 JSON。非成功响应会把服务端返回体转成错误；顶层捕获异常后写入标准错误并设置非零退出码，因此脚本调用方可以依据真实进程状态判断成功与失败。[CLI 请求封装 ↗](../../../apps/server/src/cli.ts#L6 "支持基址、Bearer token、HTTP 错误处理和统一 JSON 提交行为。")

<a id="commands"></a>
## 捕获命令与输出约束

`capture` 接受文件或标准输入中的完整捕获 JSON；`file`、`git`、`lark` 和 `hook` 先调用相应 connector，再经共享 schema 校验后统一发送到 `/api/captures`。`probe` 不经过 HTTP，而是选取 profile 并直接调用 ACP，用于验证代理配置。[捕获与探测命令 ↗](../../../apps/server/src/cli.ts#L27 "支持各输入命令经 connector 和 schema 后发送捕获 API，以及 probe 直接调用 ACP。")

普通命令把结果格式化到标准输出；hook 命令刻意保持 stdout 为空，避免宿主把捕获结果误当成新的指令。参数不足、profile 缺失或任何校验与网络错误都会落入统一失败路径。[输出与退出状态 ↗](../../../apps/server/src/cli.ts#L67 "支持帮助信息、hook 静默输出以及异常时非零退出码的约束。")
