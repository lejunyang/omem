# 实现状态：统一知识、助手与 Code Wiki 的阶段性进展

该文档按时间累积记录实现进展。顶部 2026-10-01 条目代表较新事实，并替代下方 2026-09-29 区块中的部分旧结论：系统现已具备统一知识流程、混合及中文向量检索、来源更新重核验、日常助理和 Code Wiki 切片，但全库知识覆盖、跨版本身份、外部提醒投递及若干自动化能力仍有限。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="latest-capabilities"></a>
## 最新能力基线

日常助理已有持久会话和等待事项闭环，可创建、暂缓和取消等待，并在进程重启后仅补发一次；自动监听回复、周期回顾、重复提醒和外部到期投递仍未接入。[日常消息与跟进最新状态 ↗](../../../docs/implementation/status.md#L1 "支持日常助理、等待事项操作、重启后单次补发、schema 18 以及尚未接入的自动监听和外部投递等结论。")

统一检索先接入 FTS5/BM25、中文短词、活跃记忆原证据与知识正文引用的 RRF 融合，随后又加入固定版本的中文向量模型、按模型身份隔离的索引及缺模型时的词法降级。四条同义问法结果只是小样本；reranker、ANN 和历史时点检索仍未实现。[统一词法与知识检索融合 ↗](../../../docs/implementation/status.md#L13 "支持 FTS5/BM25、中文短词、活跃记忆原证据和知识正文引用通过 RRF 融合的实现事实。")[中文向量检索最新状态 ↗](../../../docs/implementation/status.md#L7 "支持固定中文向量模型、schema 17、模型身份隔离、词法降级、小样本结果以及 reranker、ANN 和历史查询缺口。")

来源更新也已从占位状态发展为真实闭环：Capture 记录失效范围，复用 extractor、独立 verifier，并原子更新原记忆；缺证据或失败时维持待复核，只有全部受影响记忆应用成功才标记完成。[来源更新重核验闭环 ↗](../../../docs/implementation/status.md#L9 "说明 refresh_dependents 已由占位实现发展为 extractor、verifier 和原子应用组成的实际闭环。")

<a id="knowledge-and-review"></a>
## 统一知识流程与仓库评审

知识正文、固定引用、疑问、角色运行和任务记录共用 Capture→Source/Revision/Fragment 权威链。派生正文用于组织与导航，不成为新的独立原件；引用位置由宿主绑定，语义支持性仍需独立角色复核。[通用知识正文与固定引用合同 ↗](../../../docs/implementation/knowledge-pipeline.md#L3 "支持派生知识复用统一原始证据链、固定引用、独立语义复核及来源变化后失效的流程定位。")

Code Wiki 是同一证据链在代码域的投影，而非独立知识库。已验证切片覆盖固定 Capture 解析、TS/Vue 代码图、人工关系 seed、共享 trail 阅读和多视口浏览器流程；跨文件调用仍不解析，名称级调用只能标为候选，跨 revision 的符号与片段身份续接也尚未实现。[Code Wiki 定位与实现边界 ↗](../../../docs/implementation/status.md#L46 "支持 Code Wiki 属于统一证据链投影，以及跨文件调用和跨版本身份续接尚未实现的判断。")

<a id="remaining-boundaries"></a>
## 仍然成立的边界

当前实现仍是 TypeScript、SQLite 的个人单用户系统，不具备多租户 ACL、分布式事务或 pgvector；原件可追溯也不表示每条 claim 都已通过正式语义支持性评估。[个人单用户实现取舍 ↗](../../../docs/implementation/status.md#L138 "支持 SQLite 单用户边界、多租户与分布式能力缺失，以及可追溯不等于所有 claim 已获语义验证。")

仍待完成的重点包括全库知识完整覆盖、周期巡检、跨来源冲突自动修订、学习卡、跨版本语义身份、语义重排以及外部提醒投递。跨版本身份限制由 Code Wiki 边界明确记录；覆盖与失败数量则应以最新报告为准，不能沿用历史统计。[Code Wiki 定位与实现边界 ↗](../../../docs/implementation/status.md#L46 "支持 Code Wiki 属于统一证据链投影，以及跨文件调用和跨版本身份续接尚未实现的判断。")[检索维护与覆盖口径 ↗](../../../docs/implementation/status.md#L5 "支持全库知识尚未完整、验证报告不累计通过率，以及当前覆盖和失败应以最新报告为准。")
