# 实现状态：当前能力、验证证据与历史边界

该状态页以顶部 2026-10-01 更新作为最新口径，记录了中文向量检索、来源更新重核验、日常助手动作闭环和通用知识流程；中下部则混有 2026-09-29 快照及 Batch 2 历史。阅读时必须按日期和显式更正辨别现状，不能把旧限制或计划直接当成当前事实。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="current_capabilities"></a>
## 2026-10-01 已实现能力

检索已从早期关键词方案发展为共享的中文语义检索：固定 BGE-small-zh-v1.5 模型、按模型身份隔离的原片段向量、词法降级以及个人助手、飞书助手与 repo-review 共用；四条同义问法 top-1 为 4/4，但只是小样本，reranker、ANN 和历史时点检索仍未实现。[中文语义检索进展 ↗](../../../docs/implementation/status.md#L3 "支持固定中文向量模型、共享检索、真实小样本结果和 reranker 等剩余缺口。") 来源更新闭环已接通 extractor、独立 verifier 与同一记忆的原子更新，失败或缺证据继续保持待复核；这直接推翻后文“refresh_dependents 未实现”的旧记录。[来源更新闭环进展 ↗](../../../docs/implementation/status.md#L5 "支持 refresh_dependents 已进入 extractor、verifier、原子应用闭环及其真实模型验证范围。") 日常助手则已具备补搜、事项上下文、时区以及事项创建、改期、完成和重新打开，并以真实 ACP 烟测验证；重复提醒、外部到期投递和取消状态仍缺失。[日常助手闭环进展 ↗](../../../docs/implementation/status.md#L7 "支持助手的检索与事项动作能力、真实 ACP 烟测条件及尚未实现的提醒边界。")

知识整理采用共用正文与固定引用合同，材料分析后由独立会话复核，只有通过内容才发布；仓库只是统一 Capture 流程的输入适配器，派生正文不成为新的事实权威。[通用知识分析与服务流程 ↗](../../../docs/implementation/knowledge-pipeline.md#L23 "说明独立复核、固定引文、发布门槛和派生知识不成为新事实权威。") Code Wiki 同样定位为证据链上的代码投影，支持固定 Capture 文本、可提交知识资产与共享阅读链，但跨文件调用及跨 revision 身份续接仍是边界。[Code Wiki 实测定位与边界 ↗](../../../docs/implementation/status.md#L42 "支持 Code Wiki 是统一证据链的代码投影，并说明跨文件调用和跨版本身份限制。")

最新检索记录包含固定模型下载校验、全量检查通过、9,613 个片段的首轮真实索引，以及真实中文查询相对词法基线的改善；这些数字证明该次环境与样本，不代表整体质量。[中文语义检索进展 ↗](../../../docs/implementation/status.md#L3 "支持固定中文向量模型、共享检索、真实小样本结果和 reranker 等剩余缺口。") 来源刷新以真实 traex、gpt-5.6-sol、medium 验证同一记忆从“3 次”更新为“5 次”，旧原文仍保留且五个 jobs 成功；日常助手烟测也使用真实 ACP，但采用隔离数据库和合成材料，没有发生外部发送。[来源更新闭环进展 ↗](../../../docs/implementation/status.md#L5 "支持 refresh_dependents 已进入 extractor、verifier、原子应用闭环及其真实模型验证范围。")[日常助手闭环进展 ↗](../../../docs/implementation/status.md#L7 "支持助手的检索与事项动作能力、真实 ACP 烟测条件及尚未实现的提醒边界。")

较早的 G01–G20 表记录二十项测试均通过，不过 G15 仅为 fake transport，G20 的重启仅由同数据库的新 runtime 实例模拟，因此不能外推为真实飞书网络或真实进程重启验收。[G01 至 G20 验收结论 ↗](../../../docs/implementation/status.md#L67 "支持二十项场景的通过统计，同时限定 fake transport 与模拟重启的证据强度。") Code Wiki 的历史浏览器、模型生成与恢复验证可证明相应切片曾跑通，仍应与当前 coverage、verification 报告及运行时快照区分。[Code Wiki 历史验证记录 ↗](../../../docs/implementation/code-wiki-review-2026-09-29.md#L39 "支持较早切片曾完成检查、浏览器验收、真实模型生成和恢复回归。")
