# 开发端口选择的冲突与输入校验测试

验证默认端口被占用时自动改选、显式端口冲突时明确失败，以及非法端口值被拒绝；测试还负责释放临时监听服务。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决的问题

开发环境需要避免前后端误连到已被其他进程占用的端口。测试先在本机回环地址建立临时监听，再把该随机端口作为默认值传给 `selectDevPort`，断言返回有效且不同的端口，覆盖“默认值允许自动迁移”的策略。[默认端口冲突测试 ↗](../../../apps/server/tests/dev-ports.test.ts#L5 "支持测试通过真实监听端口验证默认端口自动改选的论断。") 这一行为对应实现中捕获 `EADDRINUSE` 后以端口 0 请求系统分配空闲端口的分支。[开发端口选择实现 ↗](../../../scripts/dev-ports.ts#L18 "解释默认端口冲突时递归请求系统分配端口的实现背景。")

<a id="boundaries"></a>
## 边界与未覆盖行为

同一占用端口若作为显式配置传入，测试要求抛出中文“已被占用”错误；非数字、负数、超过 65535 和小数则必须报 `invalid port`。[显式冲突与非法值断言 ↗](../../../apps/server/tests/dev-ports.test.ts#L13 "支持显式占用端口和四类非法输入均被拒绝的边界说明。") `finally` 会关闭监听器，避免测试泄漏资源。材料未断言自动选择出的端口随后仍保持可用，也未覆盖非 `EADDRINUSE` 网络错误、IPv6 或并发进程在探测后抢占端口的竞态。
