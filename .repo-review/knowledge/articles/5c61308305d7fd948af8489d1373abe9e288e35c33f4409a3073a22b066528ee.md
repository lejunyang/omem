# 服务端进程启动入口

该文件负责加载配置、构建 Fastify 应用、启动网络监听并响应进程终止信号；业务服务装配与非回环绑定校验由 buildApp 承担。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 职责与模块关系

这是服务端的进程入口，用于把配置解析、应用装配与进程生命周期串联起来：入口先调用配置模块，再把结果交给 `buildApp`，自身不直接定义 API 或业务流程。[入口加载配置并构建应用 ↗](../../../apps/server/src/main.ts#L1 "支持入口只负责调用配置与应用构建模块、串联启动流程的论断。") `buildApp` 会创建 Fastify、存储、运行记录、记忆与反馈服务，说明主要依赖装配集中在应用模块中。[Fastify 与核心服务初始化 ↗](../../../apps/server/src/app.ts#L46 "支持 buildApp 创建服务器实例以及存储、运行记录、记忆和反馈服务的说明。")

<a id="startup"></a>
## 启动流程与安全前置条件

启动顺序是加载配置、异步构建应用、按照 `host` 与 `port` 监听，监听成功后输出访问地址。[网络监听与启动日志 ↗](../../../apps/server/src/main.ts#L3 "支持应用按配置中的主机和端口监听，并在成功后输出访问地址。") 配置包含通知、检索、捕获目录、学习流程及 Lark 等运行选项；其中部分字段带默认值和格式约束。[运行配置结构 ↗](../../../apps/server/src/config.ts#L18 "说明配置模块定义通知、检索、捕获目录、学习和 Lark 等设置及其部分默认值与约束。") 在真正监听之前，`buildApp` 还会检查网络暴露条件：绑定地址不是回环地址时必须提供令牌，否则直接抛错。[非回环绑定令牌校验 ↗](../../../apps/server/src/app.ts#L46 "支持应用在监听前拒绝未配置令牌的非回环地址绑定。")

<a id="shutdown"></a>
## 关闭行为、替代结论与边界

入口为 `SIGINT` 和 `SIGTERM` 注册处理器；收到信号后调用 Fastify 的异步 `close()`，其 Promise 成功完成后以状态码 0 退出进程。[进程信号关闭处理 ↗](../../../apps/server/src/main.ts#L7 "支持收到 SIGINT 或 SIGTERM 后调用异步 close，并仅在成功完成后以状态码 0 退出的准确结论。") 先前“停止接收请求并执行关闭钩子”的表述已被这一更窄结论替代，因为现有固定材料只展示调用与成功退出，未展示 `close()` 的内部语义。材料也没有显示配置加载、应用构建、监听或关闭失败时的显式捕获，以及二次信号、强制关闭超时或非零退出策略，因此这些生产行为仍不能从本入口确认。[入口完整生命周期范围 ↗](../../../apps/server/src/main.ts#L1 "支持当前入口仅展示启动成功路径和关闭成功回调，未出现显式失败捕获、关闭超时或二次信号处理。")
