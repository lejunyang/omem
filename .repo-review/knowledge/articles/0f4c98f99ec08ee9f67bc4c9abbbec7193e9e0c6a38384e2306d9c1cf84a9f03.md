# 统一混合检索与结果编排

UnifiedRetrieval 将原件、知识文章、记忆和事项投影为同一种检索单位，组合词法、中文语义与可选重排，再按用途、可见范围和多样性输出可回到固定证据的结果。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决什么问题

读者在顶部搜索中提交文本与“概念、实现、背景、跟进”等用途后，HTTP 入口会限制查询长度并调用共享检索接口；若实现不支持统一接口，才回退到旧的来源片段搜索。参考 [顶部搜索入口 ↗](../../../apps/server/src/app.ts#L274 "证明用户查询和用途由 HTTP 入口传入共享 search，并说明旧来源搜索仅是兼容回退。")

`UnifiedRetrieval` 的职责是让阅读器和 Agent 在同一批结构化单位中查找原件、讲解、记忆与事项，同时保留向不可变来源证据的回投能力。服务启动时由工厂按配置注入中文 embedding 与可选 reranker，并启动后台投影、索引追赶。参考 [统一检索职责 ↗](../../../apps/server/src/retrieval/unified.ts#L35 "支持阅读器与 Agent 共用检索单位、旧来源端口回投固定证据的职责说明。")、[检索器装配 ↗](../../../apps/server/src/retrieval/factory.ts#L14 "证明工厂按配置注入 embedding 和 reranker，启动后台工作并暴露关闭函数。")

<a id="flow"></a>
## 一条代表性调用怎样流动

以“如何修改统一检索”且用途为 `implementation` 的调用为例：`search` 先异步同步投影，再运行 FTS5 BM25 词法分支；词法候选还要通过范围过滤、精确字面检查或正文相关性检查。空查询、路径/标识符式精确查询以及语义模型尚未就绪时，直接整理词法结果。参考 [词法候选与快速路径 ↗](../../../apps/server/src/retrieval/unified.ts#L268 "支持 BM25 词法召回、资格与相关性检查，以及空查询、精确查询和无语义模型时的词法直出。")

```mermaid
flowchart LR
  Q[查询文本与用途] --> L[结构投影与 BM25]
  L --> D[可选语义向量]
  L --> F[候选融合]
  D --> F
  F --> R[可选交叉编码重排]
  R --> O[用途排序、去重与截断]
```

语义分支把查询编码后与已存窗口逐一计算余弦分数，仅保留绝对门槛和相对最佳分数带内的候选，再与词法候选按名次融合；可选重排只处理前 40 个候选，并以模型分数为主、融合分数为辅。参考 [语义融合与重排 ↗](../../../apps/server/src/retrieval/unified.ts#L328 "支持查询向量、窗口余弦评分、阈值截尾、词法语义融合、可选交叉编码重排和失败降级。")

<a id="boundaries"></a>
## 过滤、输出与降级边界

候选进入排序前后都会检查资格：跟进用途排除已结束事项；可信项目上下文只过滤带有不同正式项目范围的记忆；还支持类型、分类前缀、宿主可见性和捕获时间范围。没有可信项目标记时，这里不会自行按项目过滤。参考 [候选资格过滤 ↗](../../../apps/server/src/retrieval/unified.ts#L218 "支持事项状态、可信项目、种类、分类、可见性和时间范围等过滤边界。")

最终排序按用途偏向讲解、代码、记忆或事项；命名代码定义会加权，待复核知识会降权，跟进结果按事件时间轻微提升。默认每个 owner 最多两条并删除正文重复，随后生成最多 `limit` 条结果；知识命中会恢复正文实际出现的引用。参考 [用途排序与结果整理 ↗](../../../apps/server/src/retrieval/unified.ts#L423 "支持用途偏好、定义与新鲜度加权、多样性去重、摘要生成及知识引用恢复。")

边界上，精确标识符不做语义猜测；语义编码或向量读取失败时回退词法结果，reranker 失败则保留已融合候选。旧处理器仍可把统一命中的来源引用展开为去重的 Fragment 锚点；关闭时会等待投影与索引工作并释放模型。参考 [语义融合与重排 ↗](../../../apps/server/src/retrieval/unified.ts#L328 "支持查询向量、窗口余弦评分、阈值截尾、词法语义融合、可选交叉编码重排和失败降级。")、[来源回投与资源关闭 ↗](../../../apps/server/src/retrieval/unified.ts#L527 "支持统一结果向固定 Fragment 锚点的去重映射，以及停止后台任务和释放模型。")
