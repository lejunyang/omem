# 研究标注数据集导入器

该模块把显式提供的 CaptureInput 文档转换为供人工评审的规则拆分样本，并写入质量数据集仓库。它以专用字面量和运行时检查隔离普通导入链路；候选生成、排序与草稿标签均是评测集冷启动策略，不代表生产知识抽取结论。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose-and-isolation"></a>
## 用途与安全隔离

模块用于从 Lark/HTML 转换后的文档中生成待人工判断的质量样本，而非直接沉淀生产知识。文件明确排除 HTTP、CLI、`inputs.ingest` 和学习管线，并限定规则生成的 `explicit/claim`、逐字证据及 `autoApply=true` 只服务研究标注集。[评测专用边界说明 ↗](../../../apps/server/src/quality/import.ts#L1 "支持该模块仅服务人工标注数据集、不得进入普通捕获和知识学习链路的论断。")

调用方必须传入专用的 `EVAL_ONLY_RESEARCH` 字面量，以显式区分普通导入。[评测导入显式开关 ↗](../../../apps/server/src/quality/import.ts#L26 "支持专用评测字面量及其用于区分普通导入路径的设计目的。") 导入入口还会在运行时比较该值；不匹配即抛出 `QUALITY_IMPORT_IS_EVAL_ONLY`，使误接生产链路的调用显式失败。[运行时隔离与数据集物化 ↗](../../../apps/server/src/quality/import.ts#L159 "支持入口对专用开关的运行时校验、失败抛错，以及生成样本后依次创建数据集和加入样本的调用流程。")

<a id="candidate-extraction"></a>
## 候选提取流程

生成器只拼接 `CaptureInput.parts` 中的文本部分，因此图片和链接不会进入候选正文；捕获合同本身仍同时支持文本、图片和 HTTP(S) 链接。[捕获内容部件合同 ↗](../../../packages/contracts/src/index.ts#L20 "说明 CaptureInput 合同分别支持文本、图片和链接，用于界定该生成器只消费文本部件的行为。") 文本按空行分块，标题更新当前章节；白板、网格、列布局、表格和 Markdown 图片块被跳过。普通行会清除链接、HTML 与 Markdown 标记，较长内容再按中文句末符号拆分，最终只保留 24–500 字的句子。[文档清洗与切分规则 ↗](../../../apps/server/src/quality/import.ts#L46 "支持文本聚合、章节识别、复杂块跳过、句子拆分和长度过滤的候选提取流程。")

<a id="identity-ranking-and-labels"></a>
## 稳定身份、排序与草稿标签

候选以“章节＋文本”的稳定摘要去重，并由摘要派生片段标识。摘要计算会递归规范化对象、忽略 `undefined`、排序键名，再生成 SHA-256，因此相同规范化输入可获得确定结果。[规范化稳定摘要 ↗](../../../apps/server/src/storage/digest.ts#L3 "解释候选去重标识和来源摘要所依赖的确定性 SHA-256 计算方式。") 每条候选经输入与标签 schema 校验，统一生成 `explicit` 类别和 `claim` 草稿，同时附带不得把文档描述解释为外部操作授权的限制。[候选输入与标签构造 ↗](../../../apps/server/src/quality/import.ts#L83 "支持候选使用稳定摘要去重、经 schema 解析并生成 claim 草稿与安全限制的说明。") 排序优先包含规则词、否定约束和数字的句子，同分时按原文块顺序排列，再截取目标数量。[规则评分与排序 ↗](../../../apps/server/src/quality/import.ts#L125 "支持规则词、否定词、数字加权，以及按得分和来源顺序选择候选的论断。")

<a id="materialization-and-boundaries"></a>
## 落库流程与边界条件

若合格候选少于请求数量，生成阶段会抛出 `QUALITY_SOURCE_TOO_SMALL`，因而不会继续创建数量不足的数据集；成功结果的来源摘要覆盖 URI、文档标识、修订和完整拼接文本。[数量门槛与来源摘要 ↗](../../../apps/server/src/quality/import.ts#L141 "支持候选不足时抛错，以及成功结果包含完整来源摘要和样本的边界说明。") 导入函数随后先创建数据集，再批量加入样本，并合并返回数据集信息、插入结果和生成数量。[运行时隔离与数据集物化 ↗](../../../apps/server/src/quality/import.ts#L159 "支持入口对专用开关的运行时校验、失败抛错，以及生成样本后依次创建数据集和加入样本的调用流程。") 当前固定材料只证明调用顺序，尚不足以确认两个仓库操作是否处于同一事务、重复来源摘要是否幂等，或样本写入失败后是否残留空数据集。
