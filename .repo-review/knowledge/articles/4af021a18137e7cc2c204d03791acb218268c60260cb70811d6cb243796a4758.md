# 研究标注数据集导入器

把研究文档的文本内容切分、排序并包装成人工质量标注草稿。被替代的结论是“整个模块都由哨兵强制隔离”：实际仅数据集导入入口执行运行时校验，公开生成器与生产链路的隔离仍依赖调用边界。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 用途与隔离边界

该模块服务于研究性质的人工质量标注：把 Lark/HTML 文档转换为规则生成的草稿样本，供人工判断，不属于普通捕获、导入或学习流程。[评测专用模块说明 ↗](../../../apps/server/src/quality/import.ts#L2 "支持该模块面向人工研究标注，并明确普通捕获、导入和学习链路不得调用。") 被替代的结论是“整个模块都由显式哨兵强制隔离”：`documentQualityEvalSamples` 是可直接调用且没有哨兵参数的公开生成器。[公开的文档样本生成器 ↗](../../../apps/server/src/quality/import.ts#L39 "支持生成器是没有评测哨兵参数的公开函数。") 真正的运行时保护位于 `importQualityDatasetEval`；传入值不等于固定常量时会显式失败。[导入入口的评测哨兵校验 ↗](../../../apps/server/src/quality/import.ts#L156 "支持固定哨兵由数据集导入入口校验，值不匹配时显式抛错。") 因此落库入口受到强制保护，而生成器不进入生产路径仍依赖调用关系和集成纪律。

<a id="pipeline"></a>
## 候选生成流程

生成器只汇集 `CaptureInput` 的文本部分，以空行分块，并用 Markdown 标题更新候选所属章节。[文本汇集与章节识别 ↗](../../../apps/server/src/quality/import.ts#L46 "支持仅汇集文本部分、按空行分块并以 Markdown 标题跟踪章节。") 图片、表格及部分复杂 HTML 块会被跳过；普通文本先清洗，超过 120 字时按中文句末标点拆分，仅保留 24～500 字的内容，并依据章节与文本摘要在本次生成中去重。[版式过滤、拆句与生成内去重 ↗](../../../apps/server/src/quality/import.ts#L70 "支持复杂版式过滤、长度条件、中文拆句及基于章节和文本摘要的本次生成去重。") 每个候选被包装为 `explicit/claim` 草稿，限制词、否定词和数字参与加权，随后按分数及来源顺序排序并截取目标数量。[草稿构造与候选排序 ↗](../../../apps/server/src/quality/import.ts#L106 "支持候选被构造成事实草稿，并按规则词、否定表达和数字加权排序后截取。")

<a id="persistence"></a>
## 数据集请求与限制

候选少于目标数量时会抛出 `QUALITY_SOURCE_TOO_SMALL`；来源摘要覆盖来源 URI、文档标识、上游版本和完整文本。[数量校验与来源摘要 ↗](../../../apps/server/src/quality/import.ts#L141 "支持候选不足时报错，以及来源摘要包含文档身份、版本和完整文本。") 导入入口随后请求仓储创建数据集，并把生成样本交给仓储批量写入。[数据集创建与样本写入调用 ↗](../../../apps/server/src/quality/import.ts#L172 "支持入口请求仓储创建数据集并调用批量样本写入，但不据此断言仓储一定复用既有数据集。") 这里不再声称入口必然“取得既有数据集”：当前获准材料只能证明它调用 `createDataset`，无法展示仓储是否按名称、切分和摘要复用已有记录。规则切分器也不核验事实准确性，且草稿默认带有自动应用标记，因此生成结果只能用于受隔离的人工研究标注。
