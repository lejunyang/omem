# 服务端关键业务链路的集成测试

该测试以临时数据目录、真实 Fastify 应用和可控 ACP 代理构成进程内集成环境，覆盖访问控制、捕获与回答、图片传递、输入约束、持久化作业、可信提案应用、会话取消及版本比较。它验证主要 HTTP 接口与存储、运行时的协作，但不代表真实外部模型、并发竞争或生产部署已经通过验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="integration-fixture"></a>
## 隔离且可重复的服务测试基座

测试通过 `setup` 为每个用例创建独立临时目录，调用 `buildApp` 组装服务，并注入本地 ACP fixture；结束时关闭应用并清理目录。因此，这些用例属于跨路由、存储和代理运行层的进程内集成测试。参考 [隔离测试基座 ↗](../../../apps/server/tests/app.test.ts#L8 "支持临时数据目录、实际应用组装、本地 ACP fixture 注入以及用例结束后的清理流程。")

服务入口还会检查非回环绑定是否配置令牌，并初始化存储、运行管理器与 ACP profile。这说明测试复用了实际服务组装路径，但受控 fixture 不能替代真实外部 Agent CLI 的可用性验证。参考 [服务组装入口 ↗](../../../apps/server/src/app.ts#L47 "支持非回环绑定的令牌要求，以及存储、运行管理器和 ACP profile 的初始化说明。")

<a id="capture-answer"></a>
## 从捕获材料到可追溯回答

核心链路先捕获原始材料，再以固定片段为焦点创建回答运行。测试等待运行完成后，确认回答已持久化、回答片段存在显式证据链接，并且原始材料与派生回答同时保留。参考 [回答与证据持久化 ↗](../../../apps/server/tests/app.test.ts#L65 "支持从捕获片段创建运行，并验证回答、显式证据链接及材料持久化结果。")

多模态用例确认 PNG 字节能够原样取回，并随焦点材料进入 ACP 上下文。Hook 归一化用例则确认，在给定示例输入中，`thoughts` 的 `private` 内容和 `secret` 的 `never` 内容没有出现在序列化结果里；该断言只覆盖这两个示例字段，不能据此推断所有未知字段都会被过滤。参考 [图片进入代理上下文 ↗](../../../apps/server/tests/app.test.ts#L136 "支持图片字节被保存并随焦点材料进入 ACP 运行上下文的结论。") 参考 [Hook 示例字段收敛 ↗](../../../apps/server/tests/app.test.ts#L180 "支持给定示例中的 thoughts 和 secret 内容未出现在归一化结果中，并界定该断言只覆盖具体样例。")

<a id="jobs-policy"></a>
## 持久化作业与可信变更落地

捕获接口会创建可查询的持久化作业。控制请求携带 `expectedGeneration` 和 `requestId`：同一取消请求可重复提交并得到一致结果，一次重试会把 generation 从 1 墠至 2。现有断言尚未证明陈旧 generation 一定被拒绝，也未覆盖并发控制或重启后的幂等行为。参考 [作业控制行为 ↗](../../../apps/server/tests/app.test.ts#L194 "支持作业查询、重复取消的一致结果、控制请求携带 generation 与 requestId，以及重试递增 generation 的说明。")

可信变更链路把带主体、时间和精确引文的任务提案交给评估接口；当评估为 `supported` 时，策略自动创建任务。测试随后核对提案状态、评审记录、应用回执、证据关联和站内通知，覆盖“证据—审核—实体—通知”的衔接。参考 [提案评估与自动应用 ↗](../../../apps/server/tests/app.test.ts#L247 "支持带精确证据的 owner 任务提案经评估后进入自动应用并生成任务回执。") 参考 [提案与通知回执 ↗](../../../apps/server/tests/app.test.ts#L333 "支持应用结果同步反映在任务、提案评审记录和带证据的站内通知中。")

<a id="boundaries"></a>
## 安全边界、版本语义与覆盖限制

访问控制用例以 `/api/sources` 为代表：配置令牌时，未认证访问返回 401、正确令牌返回 200；无令牌的本地服务仍拒绝带恶意来源的跨源匿名请求。文件导入不得越过配置根目录，回答附带的选文也必须真实存在于焦点材料中。参考 [来源接口访问控制 ↗](../../../apps/server/tests/app.test.ts#L36 "支持以来源接口为代表的令牌认证，以及本地无令牌场景下跨源匿名请求被拒绝。") 参考 [导入与选文校验 ↗](../../../apps/server/tests/app.test.ts#L100 "支持越界文件导入不会产生材料，以及伪造选文会被回答接口拒绝。")

会话取消用例确认既有 turn 的取消路由返回成功、未知 turn 返回 404，但快速响应的 fixture 尚不能证明运行中的代理会被可靠中断。版本比较用例则确认接口返回修改前后的完整文本，通知已读不改变 revision 的 current 状态，材料更新还会产生作业。参考 [会话取消接口 ↗](../../../apps/server/tests/app.test.ts#L370 "支持既有 turn 取消成功、未知 turn 返回 404，并显示 fixture 响应较快这一覆盖限制。") 参考 [固定版本比较 ↗](../../../apps/server/tests/app.test.ts#L413 "支持版本比较返回完整前后文本、通知已读不改变 current 状态以及更新产生作业。")
