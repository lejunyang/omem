# 服务器 HTTP 集成测试

覆盖应用装配后的来源端点认证示例、输入安全、采集与生成、证据持久化、作业控制、受治理任务应用及助手取消路由，是多模块 HTTP 合同的纵向集成测试。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="app-boundary"></a>
## 应用边界与输入安全

`setup` 使用临时数据目录、回环地址和 ACP 夹具构建应用。认证用例具体证明 `/api/sources` 在配置 token 时无凭证返回 401、正确 Bearer 返回 200，并证明无 token 配置下该端点会拒绝跨源匿名请求；它没有逐一覆盖所有私有端点。文件导入不能越过允许根目录，运行请求中的 selection 必须匹配真实证据；hook 标准化则过滤 thoughts 和未知 secret。[来源端点认证示例 ↗](../../../apps/server/tests/app.test.ts#L8 "支持 `/api/sources` 的 Bearer 成功与无凭证、跨源匿名拒绝；引用范围不足以推广到全部私有端点。") [文件与选择文本校验 ↗](../../../apps/server/tests/app.test.ts#L100 "支持文件导入根目录限制以及 selection 必须匹配证据原文。") [Hook 隐藏字段过滤 ↗](../../../apps/server/tests/app.test.ts#L180 "支持 hook 标准化仅保留预期数据，不持久化 thoughts 与未知 secret。")

<a id="capture-answer"></a>
## 采集、生成与证据链

手工捕获证据后，`POST /api/runs` 异步启动生成；轮询完成后，测试确认回答作为新 revision 持久化，并从回答片段建立显式证据关系。图像场景进一步验证 base64 字节原样保存，且 ACP 夹具观察到 prompt 中包含一张图片。[回答与证据关系持久化 ↗](../../../apps/server/tests/app.test.ts#L65 "支持异步运行完成后保存回答 revision，并建立显式证据链接。") [图像字节与 ACP 输入 ↗](../../../apps/server/tests/app.test.ts#L136 "支持图像资产字节不变以及生成输入包含图像。")

<a id="jobs-policy"></a>
## 持久作业与受治理写入

采集 API 返回排队作业，详情包含 generation 和 attempts；取消以 `expectedGeneration` 与 `requestId` 实现重复请求幂等，重试再把 generation 从 1 推进到 2。任务纵向流程提交带 owner provenance 和 Unicode selector 的提案，获得 `auto_apply` receipt，并断言任务、提案、通知、证据引用及待投递记录相互一致。[作业取消与重试合同 ↗](../../../apps/server/tests/app.test.ts#L194 "支持作业详情、generation 校验、取消幂等和重试代际推进。") [Owner 任务自动应用链路 ↗](../../../apps/server/tests/app.test.ts#L247 "支持提案评估、任务落库、receipt、通知、投递和证据引用的一致性断言。")

<a id="assistant-cancel"></a>
## 助手取消路由的覆盖范围

测试先建立会话并让快速 ACP 夹具完成一轮，再调用 turn cancel，得到 `{ok:true}`；不存在的 turn 返回 404。因此它验证了 HTTP 路由与 runtime 的接线及错误映射，但没有制造真实在途生成，不能据此证明 AbortSignal 传播、迟到工具调用拦截或取消后的持久状态。[HTTP 助手取消端点 ↗](../../../apps/server/tests/app.test.ts#L370 "支持现有 turn 取消成功与不存在 turn 返回 404，同时表明夹具回复很快、未形成真实在途取消。")
