# 角色运行时的确定性 ACP 测试代理

该文件是角色运行时测试使用的确定性 ACP 协议对端，通过固定分支模拟能力发现、配置变化、角色合同输出、批量提案、超时、取消及工具权限请求。它不是生产模型；其价值在于验证宿主协议与解析流程，不能替代真实 Agent CLI、模型质量或完整测试覆盖的验证。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 用途与角色输出边界

该脚本通过标准输入逐行接收消息、向标准输出写入 JSON，并维护模型、推理强度和待处理提示状态；文件明确将自身限定为角色运行时的确定性测试代理，而非生产模型。[测试代理定位与会话状态 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L1 "支持该脚本是确定性角色运行时 fixture、不是生产模型，并说明其基础输入输出与状态变量。") 它因此适合稳定复现宿主的协议处理和合同解析，不用于衡量真实模型的推理质量。

知识分析、知识写作和知识刷新角色会按目标键返回固定知识文档；`REFRESH_FACT` 则为 extractor 或 verifier 构造更新提案与支持结论。[知识角色与刷新事实分支 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L49 "支持知识角色固定文档、输出洪泛、非法 JSON，以及刷新 extractor 和 verifier 的具体返回结构。") 普通 verifier 另有批量接受、单项任务验证和空 assessments 三条路径。[Verifier 验证分支 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L73 "支持 verifier 对批量候选逐项接受、对任务提案返回单项判断及默认空结果的说明。") planner 与 feedback-curator 分别生成固定计划和认证纠正合同。[计划与反馈纠正合同 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L121 "支持 planner 和 feedback-curator 分别生成固定计划、纠正目标、证据与来源信息的论断。") 这替代旧稿把多个角色笼统归入同一引用的结论：各角色确有固定结构，但由不同代码分支实现。

<a id="protocol-flow"></a>
## ACP 会话与提示处理流程

配置项默认是 `alpha/low`，模型切换为 `beta` 后才会公开 `high` 推理强度。[模型与推理强度选项 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L11 "支持默认模型和强度，以及只有 beta 模型公开 high 强度的动态配置关系。") 初始化响应声明协议版本、图像提示能力与关闭能力；新建会话返回动态配置，并可依据宿主传入的技能名发布命令发现更新，设置配置后重新计算选项。[初始化、会话与配置协商 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L308 "支持初始化能力声明、会话创建、技能命令发现和配置选项更新流程，也说明图片仅作为能力声明出现。")

正常完成时，代理先发送一个文本 `agent_message_chunk`，再以 `end_turn` 或由 `NON_END_TURN` 触发的 `cancelled` 结束原提示。[提示完成与停止原因 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L291 "支持完成提示时发送文本消息块，以及依据 NON_END_TURN 选择 cancelled 或 end_turn 的行为。") 提示处理只拼接 `type=text` 的块；`TIMEOUT` 故意保持未响应，`session/close` 直接确认，而 `session/cancel` 会把待处理请求结束为 `cancelled`。[文本过滤、超时与取消 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L333 "支持仅拼接文本提示块、TIMEOUT 不响应、关闭确认及取消待处理请求等协议边界。") `CALL_TOOL` 会发起危险工具权限请求；宿主若未返回 cancelled，fixture 以状态码 8 退出，否则继续完成提示。[危险工具权限请求 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L340 "支持 CALL_TOOL 发起权限协商、要求 cancelled 结果以及其他结果导致进程退出的说明。") 这些精确引用替代旧稿由单一完成函数引用同时支撑文本过滤、关闭和取消行为的宽泛表述。

## 批量场景、任务场景与实现限制

批量 extractor 场景会生成 12 条事实提案，并区分内容相同与内容不同两种输入；对应 verifier 分支则按候选标识和摘要逐项返回支持结论。[批量事实提案生成 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L171 "支持批量创建 12 条相同或不同事实提案及其证据、作用域和来源结构。") `PIPELINE_TASK` 可生成带证据的任务提案，普通 extractor 路径则返回空 proposals 和一条 abstention，其中会记录项目、图片数、转发状态等上下文摘要。[任务提案与默认 abstention ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L218 "支持 PIPELINE_TASK 的任务提案结构，以及普通 extractor 返回空提案和上下文摘要 abstention 的行为。") 超大输出和非法 JSON 由独立哨兵直接触发，不能与批量提案或 verifier 行为混为同一分支。[知识角色与刷新事实分支 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L49 "支持知识角色固定文档、输出洪泛、非法 JSON，以及刷新 extractor 和 verifier 的具体返回结构。")

字段提取依赖正则及提示中固定格式的可信上下文，部分匹配结果被直接解引用。[提示字段与可信上下文解析 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L39 "支持该 fixture 使用正则提取字段并直接解析固定可信上下文格式的实现限制。") 图片仅体现在初始化能力位和上下文中的数量统计，提示阶段的非文本块会被过滤；因此该 fixture 没有处理图片内容。[初始化、会话与配置协商 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L308 "支持初始化能力声明、会话创建、技能命令发现和配置选项更新流程，也说明图片仅作为能力声明出现。") [文本过滤、超时与取消 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L333 "支持仅拼接文本提示块、TIMEOUT 不响应、关闭确认及取消待处理请求等协议边界。") 从本文件可确认的是固定字符串分支和协议消息模拟，不能据此推断真实模型语义判断、外部 CLI 集成或各分支已被测试断言覆盖。
