# 角色运行时 ACP 确定性测试替身

面向角色运行时与知识管线测试的多角色 ACP 模拟器，按提示内容生成固定合同输出，并模拟能力发现、批处理、超时、坏输出、权限拒绝和取消。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="session"></a>
## 会话能力与配置发现

替身以进程号构造独立会话标识，提供 alpha、beta 两种模型；推理强度默认是 low，只有 beta 额外允许 high。[会话标识与模型选项 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L6 "支持会话标识按进程生成，以及模型和推理强度选项随模型变化的论断。") 初始化参数可以关闭图片能力或命令发现；新建会话时，替身把宿主传入的技能名称映射为可用命令更新，并在配置变化后返回新的选项。[协议初始化与命令发现 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L290 "支持图片能力开关、技能命令发现和配置选项更新的说明。") 这些都是确定性的协议测试行为，不表示对应生产模型或能力真实可用。

<a id="role-output"></a>
## 按角色生成合同输出

提示中的角色决定输出合同：分析类角色与知识写入、刷新角色按 `targetKeys` 生成带固定材料引用的知识文档；验证者返回批量或单项评估，规划者生成有证据引用的执行步骤。[知识、验证与规划角色输出 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L44 "支持知识文档、验证评估和规划步骤由不同角色分支生成。") 反馈整理者则生成带作用域、替代内容和证据定位的纠正对象。[反馈纠正角色输出 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L126 "支持反馈整理者生成带作用域、替代内容、证据和来源信息的纠正对象。") 提取者还可按标记生成十二项批量事实、单项管线任务，或以无持久价值、危险指令为由弃权。[提取角色的批量与任务输出 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L153 "支持提取者生成批量提案、单项管线任务或弃权结果的流程说明。") 因而该替身连接角色网关、合同解析和批处理测试，但只证明宿主能处理预制结构。

<a id="faults"></a>
## 故障与安全场景

提示标记可直接制造超长输出或非法 JSON。[超长与非法输出 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L44 "支持通过提示标记产生超长文本和非法 JSON 的异常测试场景。") `NON_END_TURN` 会把结束原因改成 cancelled，而 `TIMEOUT` 会让提示请求保持未完成。[非正常结束原因 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L273 "支持 NON_END_TURN 将停止原因切换为 cancelled 的论断。")[超时与工具权限请求 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L315 "支持 TIMEOUT 保持请求未完成，以及工具调用必须经宿主权限响应的安全路径。") `CALL_TOOL` 会发起运行 shell 的权限请求，只有宿主返回取消才继续；其他结果会使进程以退出码 8 终止，用于确认角色运行不能静默批准工具。[超时与工具权限请求 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L315 "支持 TIMEOUT 保持请求未完成，以及工具调用必须经宿主权限响应的安全路径。") 图片数量、转发状态、项目信任及外部参与者只被编码进弃权详情，并未经过真实语义判断。

<a id="limits"></a>
## 边界与未覆盖行为

字段提取依赖提示中的紧凑 JSON 与正则匹配，知识目标数组也只由有限模式解析；复杂转义或格式变化可能不符合替身假设。[提示字段提取逻辑 ↗](../../../apps/server/tests/fixtures/role-acp-agent.mjs#L39 "支持替身依赖正则从紧凑提示文本提取字段的格式限制。") 它不会访问真实模型、执行获批工具或核验证据语义，也未模拟并发会话。批量验证一律返回支持，只是让测试进入后续评估阶段，不能作为生产验证正确性的证据。
