# 生成任务的令牌估算与预算校验

该模块提供轻量级令牌估算，并把模型默认限制与调用覆盖值合成为统一、经过数值边界校验的生成预算。当前材料未展示这些结果在运行时中的具体消费方式。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="token-estimation"></a>
## 令牌量的保守估算

`estimateTokens` 先取得文本的 UTF-8 字节数，再按字节数除以 3 并向上取整，形成面向代码、中文及混合文本的近似令牌量；随后增加 25% 余量，得到 `budgetedTokens` 字段，供后续预算逻辑使用。返回结果还保留 JavaScript 字符长度、UTF-8 字节数、原始估算值和估算器名称，便于解释估算来源。该算法明确不是模型专用 tokenizer，因此只能作为低成本的保守估计，不能替代具体模型的精确分词。[UTF-8 令牌估算实现 ↗](../../../apps/server/src/agent-runtime/budget.ts#L1 "支持附近关于 UTF-8 字节估算、两次向上取整、25% 余量及返回诊断字段的说明。")

<a id="budget-resolution"></a>
## 预算合并与默认值

`GenerationBudget` 统一描述输入上限、输出上限和上下文预留量。`generationBudget` 接受部分覆盖配置：前两项未提供时分别采用模型默认的上下文限制和输出限制，上下文预留量未提供时使用 `16000`。这里采用空值合并，所以 `0`、负数或小数不会自动回退到默认值，而是保留到后续校验。[生成预算类型与默认值合并 ↗](../../../apps/server/src/agent-runtime/budget.ts#L9 "支持附近关于三个预算字段、调用覆盖值、模型默认限制和 16000 预留默认值的说明。")

<a id="validation-boundary"></a>
## 函数调用时的显式校验

预算合并完成后，函数逐项要求数值为安全整数且位于 1 至 1,000,000 之间；不满足条件时立即抛出包含字段名的错误，满足时返回统一预算。该校验仅约束三个字段各自的数值范围，没有检查输入、输出与预留量之间的组合关系，也不能据此判断某项配置是否受特定模型支持。[预算数值边界校验 ↗](../../../apps/server/src/agent-runtime/budget.ts#L21 "支持附近关于安全整数、合法范围、按字段抛错及返回结果的说明。")

<a id="integration-limits"></a>
## 职责范围与证据边界

当前文件只展示估算结果和预算对象的构造接口，可以确认它位于模型默认能力与调用方覆盖配置之间。材料没有提供直接调用方，因此无法确认 `budgetedTokens` 如何参与比较，也无法判断超限时会截断、拒绝还是降级，以及预留量是否会从可用输入上下文中扣除；同样不能确认这些分支是否已有自动化测试覆盖。[预算模块公开职责 ↗](../../../apps/server/src/agent-runtime/budget.ts#L3 "界定当前材料仅能确认估算与预算构造，支持对调用方式、超限策略和测试覆盖保持未知的判断。")
