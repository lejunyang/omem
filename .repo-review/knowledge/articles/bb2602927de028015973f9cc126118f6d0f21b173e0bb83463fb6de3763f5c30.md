# docs-validation.md · 模块理解

该模块保存 2026-09-26 第一轮设计材料与离线交互原型的验证记录，证明证据阅读交互合同曾在真实 Chromium 中接受检查。它是历史验收依据和视觉对照，不是当前 Vue 产品、后端、模型、检索或外部集成的完整验收报告；其中“真实模型与服务端尚未部署”等结论已被后续进展替代，当前状态应以实施状态和最新验证产物为准。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="role"></a>
## 职责与历史背景

`docs/validation.md` 记录第一轮架构材料和离线交互原型如何被核验，并主动限定结论的时间范围：当时真实模型与服务端尚未部署，原型也“不等于当前运行代码”。[首轮验证的时间与能力边界 ↗](../../../docs/validation.md#L3 "支持该文档只验证第一轮设计材料和离线原型，且不能代表当前运行代码的判断。") 已有子知识据此将其定位为历史验证记录，而非生产系统的完整验收；这一定位有助于首次阅读者避免把旧结论外推到当前实现。[历史验证记录的子知识定位 ↗](b2d500fd165c754b11b93df5df73fb1389ffccf38aa56fdb495b972ed1b8223a.md#scope "引用已有子知识对文档历史角色的组织性解释，附近事实仍由原始材料直接支撑。")

<a id="workflow"></a>
## 验证流程与交互合同

验证流程包括材料与上游仓库核验、自包含原型构建、桌面和手机浏览器测试、人工视觉检查及静态一致性检查。[首轮验证执行流程 ↗](../../../docs/validation.md#L7 "支持材料核验、原型构建、浏览器测试、视觉检查和静态一致性检查构成验证流程。") 配套脚本启动真实 Chromium，并收集页面异常与外部请求；脚本开头也明确这些断言不代表后端行为。[真实浏览器脚本及后端边界 ↗](../../../docs/prototype/smoke.mjs#L1 "证明脚本启动 Chromium、设置桌面视口、收集页面异常和外部请求，并明确不蕴含后端验证。") 检查完成后，脚本把浏览器版本、检查项、异常、外部请求及“仅限离线原型”的范围写入 `verification.json`。[验证结果文件写入逻辑 ↗](../../../docs/prototype/smoke.mjs#L267 "直接支持脚本将浏览器版本、检查结果、异常、外部请求和离线原型范围写入 verification.json 的论断。") 覆盖重点包括多层下钻、循环跳回、固定历史版本、原位追问、滚动与焦点恢复、异常状态、搜索及移动端展示。[浏览器交互覆盖范围 ↗](../../../docs/validation.md#L16 "支持引用层级、循环、版本、追问、状态恢复、异常状态、搜索和移动端均在原型检查范围内。") 这些行为与现行固定 FragmentRevision、逐层退栈和局部状态保留合同相衔接。[引用弹窗现行交互合同 ↗](../../../design.md#L40 "说明历史原型验证的下钻、退栈、循环跳回及局部状态保留如何关联现行设计。")

<a id="progress-limits"></a>
## 被替代结论与当前限制

历史原型仍可作为视觉和交互对照，但产品界面已明确采用 `packages/ui` 的 Vue 3 与 TypeScript 实现，不再以 React 原型作为产品代码。[Vue 产品界面实现入口 ↗](../../../design.md#L1 "直接支持当前产品界面采用 packages/ui、Vue 3 和 TypeScript且不继续用 React 构建的判断。") 现行规范同时要求真实动作、诚实错误态以及项目检查和浏览器检查，并限定旧原型只作视觉参考。[真实行为与历史原型边界 ↗](../../../design.md#L50 "支持当前产品必须验证真实动作和错误态，并把历史离线原型限定为视觉对照。") 后续状态已记录真实 ACP、中文向量检索、来源更新闭环和日常助理等能力，因此旧文中“真实模型与服务端尚未部署”的环境结论已经被替代；实际覆盖和失败应查看当前状态与验证报告。[后续真实能力与当前验收入口 ↗](../../../docs/implementation/status.md#L1 "表明系统后来已增加真实模型、语义检索、来源更新闭环和日常助理能力，同时要求以当前报告判断覆盖情况。") 不过，首轮验证未覆盖真实引用准确率、外部连接器、团队 ACL、灾备、完整无障碍、长期性能及真正的后端恢复，“字段存在”或“可点击”也不能视为生产能力。[首轮明确未验证事项 ↗](../../../docs/validation.md#L45 "支持真实质量、外部集成、可靠性、无障碍、性能和后端工作流不属于首轮验证结论。")
