# 版本化角色运行时与共享知识网关测试

验证角色包隔离、技能加载、模型能力协商、图像上下文、输出与超时故障、会话隔离、工具请求拒绝，以及知识角色复用共享网关和宿主绑定引用。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="bundles-skills"></a>
## 角色包、技能与作业追踪

extractor 与 verifier 通过同一网关运行，但结果角色、bundle、prompt 和 skill 摘要彼此不同，各自加载指定 inline 技能。作业处理后状态成功，并把角色包摘要、输出合同和已加载技能写入 attempt。[角色差异与作业追踪 ↗](../../../apps/server/tests/role-runtime.test.ts#L95 "支持不同角色的提示、技能和摘要隔离，以及执行信息持久化到作业 attempt。") 运行时也支持 native 技能发现；代理不报告发现结果会失败，清单出现重复技能则在加载阶段被拒绝。[Inline 与 native 技能加载 ↗](../../../apps/server/tests/role-runtime.test.ts#L181 "支持两种技能装载模式，并验证缺失发现和重复技能会被拒绝。") 这使版本化角色配置和实际执行痕迹可核对，而不是只依赖角色名称。

<a id="capabilities-failures"></a>
## 能力协商与失败不应用

模型选项会先重新协商，再校验 effort：`beta/high` 可用，而不支持该强度的模型会被拒绝。[模型与 effort 协商 ↗](../../../apps/server/tests/role-runtime.test.ts#L226 "支持先确定有效模型与强度，并拒绝模型不支持的 reasoning effort。") 上下文可携带主体、时间、转发状态和图片；支持图片的代理能读取这些信息，不支持图片的代理在运行前失败。[可信上下文与图片能力 ↗](../../../apps/server/tests/role-runtime.test.ts#L246 "支持转发、时区和图片进入上下文，并在代理不支持图片时拒绝执行。") 对格式错误、输出洪泛、非正常结束和超时，网关分别报错；随后任务和应用回执仍为空，说明这些失败不会落成业务变更。[异常输出与超时隔离 ↗](../../../apps/server/tests/role-runtime.test.ts#L293 "支持多类运行失败均被拒绝，且不会产生任务或应用回执。")

<a id="isolation-safety"></a>
## 会话隔离与材料指令防护

不同项目运行使用新会话并产生不同上下文摘要，verifier 只接收其固定输入，不继承 extractor 的项目内容。[独立会话与 verifier 输入 ↗](../../../apps/server/tests/role-runtime.test.ts#L338 "支持跨项目使用不同会话和上下文，并防止 verifier 继承其他项目内容。") 当材料嵌入调用工具、发消息或改权限的文字时，运行时允许工具列表为空，结果以不安全指令弃权，并持久化 denied 权限请求；任务和应用回执不产生。已拒绝请求也不能迟到批准，更不会转成业务决策。[嵌入命令与迟到批准防护 ↗](../../../apps/server/tests/role-runtime.test.ts#L372 "支持材料命令被视为不安全数据、权限请求被拒绝，且迟到批准不形成业务决定。") 这验证材料被当作数据处理，并将运行时权限与业务授权分开。

<a id="knowledge-gateway"></a>
## 知识角色的共享网关合同

知识角色同样经共享 RoleRuntimeGateway 执行，宿主的输出校验阶段可把引用替换为固定材料中的精确文本；结果记录知识角色技能、`KnowledgeBatch.v1` 输出合同和输入预算。[知识角色共享网关 ↗](../../../apps/server/tests/role-runtime.test.ts#L436 "支持知识角色复用网关、宿主绑定固定引用，并记录技能、输出合同和预算。") 另一个测试确认模型草稿与目录不会混入首个可信任务指令块，而会被放入标记为不可信派生知识的文本块。[草稿与可信指令隔离 ↗](../../../apps/server/tests/role-runtime.test.ts#L445 "支持模型草稿和目录不进入可信任务指令，而被明确放入不可信派生知识区。") 因此知识生产复用通用运行时安全边界，但这些夹具测试不等于已验证所有外部 ACP CLI 的真实兼容性。
