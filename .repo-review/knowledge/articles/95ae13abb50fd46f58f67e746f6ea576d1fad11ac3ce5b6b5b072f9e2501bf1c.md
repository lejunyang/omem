# 版本化角色运行时验收测试

验证角色包隔离、技能加载、模型能力协商、上下文传递、失败封闭、会话隔离以及运行时权限请求边界。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="bundle-capabilities"></a>
## 角色包、技能与模型能力

不同角色获得不同提示词、技能和有效哈希，任务执行后还会把角色包、输出 schema 与技能清单写入 attempt。[角色包隔离与执行追踪 ↗](../../../apps/server/tests/role-runtime.test.ts#L95 "支持不同角色使用不同提示词和技能，并把有效运行信息记录到任务 attempt。") 技能既可内联也可原生发现；缺少发现结果或重复声明会被拒绝。模型选择先重新协商能力，再校验 effort，因此有效组合被记录，不支持的组合直接报错。[技能加载与发现校验 ↗](../../../apps/server/tests/role-runtime.test.ts#L181 "支持 inline/native 两种加载模式以及缺失发现、重复技能被拒绝。")[模型与 effort 协商 ↗](../../../apps/server/tests/role-runtime.test.ts#L226 "支持运行时先协商模型选项，再接受或拒绝对应推理强度。")

<a id="context-failure-isolation"></a>
## 上下文保真与失败封闭

运行时携带身份、时间、转发状态和图片；不支持图片的 agent 会在执行前被拒绝。[可信上下文与图片能力 ↗](../../../apps/server/tests/role-runtime.test.ts#L246 "支持身份、时间、转发和图片上下文传递，以及图片能力不足时拒绝执行。") 畸形、超限、非正常结束或超时输出都不会产生应用回执或任务。不同项目使用新会话与不同上下文哈希，verifier 也不会继承 extractor 的项目结果。[异常输出与超时封闭 ↗](../../../apps/server/tests/role-runtime.test.ts#L293 "支持异常或超时结果不被应用为回执或任务。")[会话与验证输入隔离 ↗](../../../apps/server/tests/role-runtime.test.ts#L338 "支持不同项目使用独立会话，并证明 verifier 输入不混入 extractor 的项目结果。")

<a id="instruction-trust-boundary"></a>
## 材料指令与权限边界

嵌入材料的工具命令只被当作数据：运行没有可用工具，危险权限请求被拒绝并持久化，也不会转化为业务变更；事后批准已失效请求同样被拒绝。[材料内命令与权限拒绝 ↗](../../../apps/server/tests/role-runtime.test.ts#L372 "支持把嵌入命令当作数据、拒绝危险调用并避免产生业务写入。")[过期运行时批准 ↗](../../../apps/server/tests/role-runtime.test.ts#L411 "支持已拒绝的运行时请求不能被事后批准，也不会成为业务决策。") 知识角色继续走共享 gateway，由宿主绑定固定引用，并记录输出 schema 与输入预算；模型草稿和目录被放在非可信材料区，而非可信任务指令中。[共享知识角色网关 ↗](../../../apps/server/tests/role-runtime.test.ts#L436 "支持知识角色复用共享 gateway、由宿主绑定引用并记录 schema 与预算。")[非可信草稿隔离 ↗](../../../apps/server/tests/role-runtime.test.ts#L445 "支持模型草稿和目录不会进入可信任务指令，而会被明确放入非可信派生知识区域。")
