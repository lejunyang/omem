# 反馈修订整理规则

定义反馈整理角色如何把经过身份与范围约束的纠正转成可复用提案，并明确证据强度、作用域和权限边界；这是角色规范，不等同于运行时已强制执行。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose_flow"></a>
## 目标与处理流程

该技能面向已认证且有明确作用域的反馈：先核对可信上下文中的参与者绑定以及目标修订或任务版本，再区分事实纠正、任务负责人或时间调整、方法范围纠正、弱有用性信号与结果证据。[反馈分类与上下文核验 ↗](../../../packages/agent-runtime/roles/feedback-curator/1/skills/omem-feedback-curation/SKILL.md#L8 "支持处理流程首先核验参与者和目标版本，并区分不同反馈类型的论断。") 随后必须明确指出应停止采用的内容及其替代项，并把两者同时绑定到纠正证据和原始目标，避免形成脱离来源的通用结论。[纠正项与替代项绑定 ↗](../../../packages/agent-runtime/roles/feedback-curator/1/skills/omem-feedback-curation/SKILL.md#L10 "支持纠正必须同时说明停用内容、替代内容及其证据来源。")

<a id="authority_boundary"></a>
## 证据与权限边界

纠正只能留在同一主题或项目范围内；冲突未解决或背景缺失时应保留不确定性并请求补充，而不是强行合并。[范围与冲突保留 ↗](../../../packages/agent-runtime/roles/feedback-curator/1/skills/omem-feedback-curation/SKILL.md#L11 "支持纠正不可越过主题或项目边界，且缺失背景时应保留冲突。") 重复点击、致谢、模型自评和生成摘要都不构成独立权威，说明反馈频率不能替代来源质量。[非独立权威信号 ↗](../../../packages/agent-runtime/roles/feedback-curator/1/skills/omem-feedback-curation/SKILL.md#L12 "支持点击、致谢、自评和生成摘要不能单独充当权威证据。") 该角色仅返回 `CorrectionProposal.v1`，不得直接应用纠正，也不得改变访问控制、采集范围、预算或自动批准规则；政策建议只能进入影子评估。[提案输出与政策禁区 ↗](../../../packages/agent-runtime/roles/feedback-curator/1/skills/omem-feedback-curation/SKILL.md#L13 "支持角色只能输出提案、不能直接实施或修改权限及审批政策的边界。")
