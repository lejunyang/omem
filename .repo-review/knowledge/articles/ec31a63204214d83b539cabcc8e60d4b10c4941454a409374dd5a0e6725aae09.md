# Lark 实时接入与卡片回调验收测试

验证 Lark 长连接租约、群消息采集与幂等、决策卡片安全，以及机器人退群后立即停采；证据限于伪适配器和单进程 SQLite。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="realtime-ingress"></a>
## 实时连接与群消息入口

测试以临时 SQLite、加密凭据仓库和伪实时适配器构造运行边界。首个连接管理器取得租约后，第二个管理器不能同时消费；首个停止后，后者可以接管。连接状态变化会被记录，配对消息与 SDK 卡片事件也会规范化进入统一入口。[长连接租约、配对与状态记录断言 ↗](../../../apps/server/tests/lark-realtime.test.ts#L254 "支持单消费者租约、停止后接管、配对路由、连接状态记录和事件规范化的说明。")

群聊测试覆盖既有群消息采集、机器人入群后启用监听、忽略自身消息及事件幂等：相同载荷重投标为重复，相同事件号携带冲突载荷则报错；较旧的消息更新仍作为独立输入保存，并保留发送者类型和观测时间。[群消息监听与幂等断言 ↗](../../../apps/server/tests/lark-realtime.test.ts#L366 "支持入群启用监听、消息采集、自身消息忽略、冲突重放检测及身份时间保留的说明。") 机器人被移出已批准群后，相关目标全部转为禁用且关闭采集，随后的群消息明确返回不允许采集。[机器人退群后的立即停采断言 ↗](../../../apps/server/tests/lark-realtime.test.ts#L632 "直接支持机器人被移出群后禁用全部相关目标，并拒绝采集后续消息。")

<a id="decision-safety"></a>
## 决策卡片的一次性业务效果

测试从待决策提案生成并投递真实卡片动作，再由卡片服务排队执行。重复点击、相互竞争的动作以及 Web 端抢先决策，最多产生一次可观察业务效果；卡片最终渲染数据库中的实际批准或拒绝状态，而非后来点击者的期望。[卡片动作竞争与实际状态渲染断言 ↗](../../../apps/server/tests/lark-realtime.test.ts#L452 "支持重复或竞态操作最多产生一次业务效果，并按持久化实际状态更新卡片。")

回调会核对操作者、会话、消息、nonce、提案摘要、版本摘要和有效期，伪造字段不会消耗原动作。数据库写入失败时事件保留为可重投状态；动作入队后若来源出现新修订，批准转为 stale 且不创建任务。[伪造、持久化失败与证据过期断言 ↗](../../../apps/server/tests/lark-realtime.test.ts#L517 "支持回调字段校验、写入失败后的重投能力，以及来源变化后拒绝执行的边界。") 这些断言尚不能代表真实 WebSocket 断线、限流、乱序投递或跨进程数据库竞争下的行为。
