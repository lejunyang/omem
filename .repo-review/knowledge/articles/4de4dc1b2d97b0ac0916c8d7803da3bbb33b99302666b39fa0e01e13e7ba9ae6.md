# 检索后端配置与工厂

该模块是统一检索端口的装配入口：读取并校验本地配置，在关键词基线与中文语义检索之间切换，并为所选后端提供一致的关闭回调。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 职责与配置边界

该文件集中处理检索后端的配置读取与实例选择，使上层只依赖统一的 `RetrievalPort`。配置 schema 采用严格对象：`enabled` 默认关闭，模型别名默认 `memory-zh`，且名称只允许字母、数字、下划线和连字符；`readRetrievalConfig` 同步读取文件，再执行 JSON 解析和 schema 校验，因此文件读取、JSON 解析或 schema 校验错误会在调用时同步抛出。[检索配置读取与校验 ↗](../../../apps/server/src/retrieval/factory.ts#L9 "支持默认配置、严格字段规则，以及文件读取、JSON 解析和 schema 校验在 readRetrievalConfig 调用中同步发生的论断。") 无论选择哪种后端，统一端口都要求候选结果回指不可变 fragment，保证回答仍可追溯到原始证据。[统一检索端口的证据合同 ↗](../../../apps/server/src/retrieval/port.ts#L1 "支持不同后端均应返回指向不可变原始片段的候选结果，上层无需依赖具体检索实现。")

<a id="flow"></a>
## 创建与生命周期流程

`createRetrieval` 接收 SQLite 数据库、可选配置和工作目录。配置缺失或语义检索未启用时，它立即返回 `KeywordRetrieval` 与无操作的异步关闭函数；关键词实现声明使用 SQLite FTS5 融合检索，并始终返回原始证据。[关键词检索基线 ↗](../../../apps/server/src/retrieval/keyword.ts#L21 "支持未启用语义模式时采用关键词实现，以及该实现使用 SQLite FTS5 融合检索并返回原始证据。") 启用后，工厂创建 `SemanticRetrieval`，将指定模型别名和工作目录封装进延迟加载回调，随后调用 `start()` 发起后台索引，并把语义实例的 `close()` 暴露给调用方。[检索工厂分支与关闭回调 ↗](../../../apps/server/src/retrieval/factory.ts#L14 "直接支持工厂在未启用时返回关键词实现，在启用时创建并启动语义实现，同时向调用方返回对应关闭函数。")

<a id="semantic_dependency"></a>
## 语义模式的依赖与状态

语义模式依赖 `loadChineseEmbedding`：它通过 osdk 查询本地锁定快照，核对模型仓库、revision 和文件哈希，并关闭远程模型与文件缓存，因此工厂创建成功并不等同于模型已可用。[中文向量模型加载与完整性校验 ↗](../../../apps/server/src/retrieval/embedding.ts#L17 "支持语义模式通过 osdk 使用锁定本地快照、校验模型身份和文件哈希，并禁止隐式远程加载。") `start()` 会异步运行索引批次；模型 Promise 被复用，同一时刻只保留一个索引任务，失败会记录错误并延迟重试。健康状态据此区分 `indexing`、`ready` 和 `degraded`，调用方应以健康接口判断语义就绪程度。[语义检索健康状态与后台调度 ↗](../../../apps/server/src/retrieval/semantic.ts#L21 "支持模型延迟复用、异步索引、任务互斥、失败重试，以及 indexing、ready、degraded 状态的说明。")

<a id="limits"></a>
## 已知边界与待确认事项

工厂只负责选择实现、启动语义后台任务及返回关闭回调；当前材料没有展示服务器入口是否在退出或配置重载时调用该回调。[检索工厂分支与关闭回调 ↗](../../../apps/server/src/retrieval/factory.ts#L14 "直接支持工厂在未启用时返回关键词实现，在启用时创建并启动语义实现，同时向调用方返回对应关闭函数。") 同时，语义类继承关键词实现，表明语义能力建立在词法基线之上，但已提供的语义材料只覆盖健康状态和索引前半段，尚不足以确认模型加载或查询失败时 `searchSources` 的完整回退行为。[语义检索继承词法基线 ↗](../../../apps/server/src/retrieval/semantic.ts#L11 "支持语义实现继承关键词检索，并说明当前提供范围仅展示索引流程、未覆盖完整查询回退逻辑。") 因此这些生命周期与查询降级结论应保留为待验证问题，而不是视为工厂已保证的能力。
