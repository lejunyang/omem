# 规划角色运行清单

清单声明 planner v1 的配置组合：角色档案、内联技能、输出合同、无工具会话隔离和预算。它描述宿主应如何装载角色，但不等同于运行成功或规划能力已通过测试。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="assembly"></a>
## 角色装配与输出合同

该清单把角色标识设为 planner、版本设为 1，并引用 `traex` profile 与 `prompt.md`。[规划角色基础身份配置 ↗](../../../packages/agent-runtime/roles/planner/1/manifest.json#L2 "支持角色版本、profile 与提示模板来源的说明。") 它内联装载版本为 `plan-1` 的任务规划技能，同时记录制品摘要；预期输出合同为 PlanProposal.v1。摘要可用于绑定特定技能制品，但材料没有展示宿主如何核验摘要。[内联技能与输出合同配置 ↗](../../../packages/agent-runtime/roles/planner/1/manifest.json#L9 "支持技能版本、装载方式、制品摘要及 PlanProposal.v1 输出声明。")

<a id="isolation"></a>
## 权限、会话与预算

工具策略为 `none` 且允许工具列表为空，意味着此角色按配置只能提出计划，不能借助工具执行步骤。[无工具策略 ↗](../../../packages/agent-runtime/roles/planner/1/manifest.json#L18 "支持 planner 配置上不能调用工具执行计划的判断。") 会话不复用，也不继承用户技能或 MCP，体现任务间隔离。预算上限声明为 96,000 个上下文 token、24,000 个输出 token，并允许最多两次修复；这些是配置额度，不是实际消耗或成功率记录。[会话隔离与预算配置 ↗](../../../packages/agent-runtime/roles/planner/1/manifest.json#L22 "支持会话不复用、不继承用户能力以及 token 和修复次数上限的说明。")
