# FragmentFrame：评审片段阅读与关系下钻

该 Vue 组件在 Code Wiki 的证据 trail 中展示不可变评审片段，将关系分为反向代码影响和正向依据，并把可定位目标转换为文件或片段下钻事件。详情与关系采用不同降级策略；已有详情重新加载失败时，错误横幅可能与旧正文同时出现。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 界面职责与可见表达

该组件是评审片段的阅读帧：正文区域展示所属修订标题、标注“仓库文档原文 · 不可变”，并通过共享 `OmMarkdown` 渲染片段内容，因此它承担证据阅读而非编辑职责。[修订标题与不可变原文展示 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L93 "支持组件展示修订标题、不可变原文状态和 Markdown 正文的界面职责。") 关系枚举不会直接作为可见文本输出，而会转换成“实现”“决策依据”“测试覆盖”等人类标签；`confirmed`、`candidate` 与其他状态分别映射为成功、警告和中性色调。[关系标签与状态色调 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L63 "支持关系类型转换为人类标签以及不同关系状态的色调映射。")

<a id="loading-flow"></a>
## 加载流程与错误降级

组件在挂载及 `fragmentId` 变化时重新加载，详情和关系请求并行执行。关系请求失败会被转换为空数组，详情仍可成功显示；详情请求失败则设置错误信息，但不会清空此前的 `detail`。[片段与关系并行加载 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L26 "支持加载触发时机、并行请求、关系失败降级以及详情失败不清空旧数据的说明。") 因而旧稿中“加载中—错误—正文互斥”和“详情失败进入整体错误态”的结论已被替代：首次加载失败时通常只有错误横幅，而已有详情的重新加载失败后，错误横幅可与旧正文同时出现。模板中的错误提示是独立 `v-if`，正文仅受 `loading` 与 `detail` 分支控制。[错误横幅与关系列表模板 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L93 "支持错误横幅可与正文共存、模板仅渲染两类关系以及空态和摘要截断边界。")

<a id="relations-and-navigation"></a>
## 关系分类与下钻流程

关系分为三类：`implemented_by`、`required_by`、`tested_for` 用于从规则反查代码；`implements`、`decided_by`、`researched_by`、`tested_by`、`requires` 用于继续指向依据或依赖；剩余类型进入 `otherRelations`。[关系方向分类规则 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L31 "支持反向、正向和其他关系的分类边界。") 点击关系时，组件优先用另一端的文件路径和调用方提供的 `fileMap` 查找代码文件，成功后发出文件下钻；否则在存在片段目标时发出片段下钻，无可用目标则不触发事件。[关联目标下钻决策 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L79 "支持优先下钻代码文件、随后退回片段目标以及无目标时不发事件的流程。") `fileByPath` 的来源应以本组件的导入语句为准；旧稿用模块文件开头证明其来源并不充分。现有材料未提供该函数实现，仍无法确认路径规范化和大小写行为。[文件路径查询函数导入 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L14 "直接证明 fileByPath 从同目录 modules 模块导入，修正旧稿引用范围不足的问题。")

<a id="boundaries"></a>
## 展示边界与待验证风险

模板目前只消费反向和正向关系列表，已计算的 `otherRelations` 没有渲染入口；反向关系有专门空态，正向关系没有对应空态，摘要分别截断至 200 和 160 个字符。[错误横幅与关系列表模板 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L93 "支持错误横幅可与正文共存、模板仅渲染两类关系以及空态和摘要截断边界。") 此外，加载逻辑没有请求代次或取消机制，快速切换片段时可能发生旧响应覆盖新状态；关系请求异常又会被表现为空关系，与真实“尚未登记”难以区分。[异步重载与未渲染关系 ↗](../../../apps/web/src/codewiki/FragmentFrame.vue#L34 "支持快速切换可能产生竞态、关系失败退化为空数组以及其他关系仅被计算未被模板消费的风险分析。") 这些行为是否符合产品预期，以及外围是否已有串行保护，不能仅凭当前材料确定。
