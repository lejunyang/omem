# 个人知识库的阅读入口与证据路径

该组件组合知识目录、文章阅读和多层证据抽屉，并负责保存、恢复当前文章及引用阅读路径，让用户深入证据时仍保留主阅读上下文。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 在文章阅读中追溯证据

个人知识库入口解决“阅读结论时继续查看依据，又不丢失正文位置”的问题。主区域由 `KnowledgeHome` 展示目录和当前文章，文章产生的导航帧进入共享轨迹抽屉，因此知识正文与证据阅读可以并存。参考 [知识库入口组合 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L27 "支持主知识页面与共享证据抽屉并存，以及目录导航进入轨迹的说明。")

活动帧会交给 `KnowledgeFrame`，内容加载后再把可读标题回填到对应轨迹帧。该组件进一步按帧类型展示知识文章、原始材料或固定引用；固定引用解析成功后，还会根据目标类型打开文章或材料。参考 [活动帧与标题回填 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L29 "支持活动帧交给内容组件，并在加载完成后更新轨迹帧可读标题的说明。")、[知识与证据内容分派 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L21 "支持知识、原始材料和固定引用三类内容的渲染分派，以及引用加载和不可用状态的呈现。")

<a id="route-flow"></a>
## 文章选择与深链恢复

初始文章优先采用会话中保存的选择，否则打开总览。用户切换文章时，入口更新当前键，并把文章位置和引用帧栈编码进 URL hash；地址更新使用替换历史记录的方式。参考 [文章状态与路由保存 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L6 "支持默认文章、选择更新以及将当前文章和轨迹写入 URL hash 的流程。")

页面初始化及 hash 变化时会恢复路由：解析当前文章，只保留 `knowledge`、`citation`、`source` 三类帧，把栈顶设为当前项，并依据栈是否为空决定抽屉是否打开。恢复期间使用临时读取标题，待内容加载后再更新。参考 [知识深链恢复 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L16 "支持解析知识路由、过滤允许的帧类型、定位当前帧和恢复抽屉状态。")

<a id="limits"></a>
## 职责边界与路径限制

深链保存受 `MAX_TRAIL` 约束。帧数超限时，现有阅读栈仍然可用，但页面停止把完整路径写入链接，并显示状态提示；因此该限制控制的是可分享 URL 的长度预算，而非运行时可阅读的层数。参考 [引用路径长度限制 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L8 "支持轨迹超限时保留当前阅读、停止保存完整链接并显示提示的边界说明。")

入口组件主要负责编排轨迹、路由和抽屉。文章列表的获取、选择持久化与定时刷新由 `KnowledgeHome` 完成。参考 [知识目录职责 ↗](../../../apps/web/src/knowledge/KnowledgeHome.vue#L16 "支持目录组件获取文章、保存选择、同步外部选择并定时刷新数据的说明。") 固定引用的数据请求由 `KnowledgeFrame` 在引用帧变化时发起，并用代次检查避免较早请求覆盖当前结果；其模板负责呈现加载、不可用状态及最终内容。参考 [固定引用请求 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L12 "支持仅为引用帧发起固定引用请求、处理错误并防止过期异步结果覆盖当前状态的说明。")、[知识与证据内容分派 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L21 "支持知识、原始材料和固定引用三类内容的渲染分派，以及引用加载和不可用状态的呈现。")
