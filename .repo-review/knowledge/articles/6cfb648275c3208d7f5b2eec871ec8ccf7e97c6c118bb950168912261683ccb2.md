# 个人知识库阅读与引用路径导航

个人知识库页面负责衔接文章目录、正文阅读和多层证据抽屉，并把当前文章及引用路径编码进 URL。它复用共享的证据轨迹能力，支持深链恢复、浏览器地址同步和组件卸载清理；路径过长时保留当前阅读状态，但停止写入不完整链接。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 统一文章阅读与证据追溯

该页面是个人知识库的组合入口：主区域交给 `KnowledgeHome` 展示文章目录和正文，用户从正文继续打开知识、引用或来源时，则把目标压入共享证据轨迹，由抽屉逐层呈现。这样既能连续阅读主题文章，也能沿论断追溯固定证据，而不必离开当前页面。参考 [知识库页面组合入口 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L27 "支持页面把文章目录、正文和证据抽屉组合为同一阅读入口的说明。")

它直接复用 `@omem/ui` 的轨迹状态与抽屉组件，说明导航栈、回退、跳转、循环提示和焦点归还属于跨场景的通用交互能力，而非个人知识库自行维护的一套状态机。参考 [共享证据轨迹状态 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L3 "说明页面复用共享轨迹能力，并接入回退、跳转、关闭及焦点归还等交互。")

<a id="routing"></a>
## 文章选择与深链恢复

当前文章优先从会话存储恢复，缺省进入总览；文章被选择后，页面更新当前键并把“当前文章 + 完整引用轨迹”序列化到 `#/knowledge/` 地址。收到地址变化时，它反向解析路由，只接受知识、引用和来源三类轨迹帧，再恢复当前层级与抽屉开关。参考 [知识深链保存与恢复 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L6 "支持当前文章和轨迹写入 URL、按允许类型恢复帧栈及抽屉状态的流程。")

恢复过程中先把帧标题设为“正在读取引用…”，随后 `KnowledgeFrame` 根据帧类型加载文章、来源或引用，并通过 `loaded` 事件回填可读标题。引用不可操作或解析失败时，下层组件会展示原因，而不会静默跳转。参考 [轨迹帧内容解析 ↗](../../../apps/web/src/knowledge/KnowledgeFrame.vue#L21 "解释下层组件如何按帧类型加载内容、回填标题并处理不可用引用。")

<a id="boundaries"></a>
## 链接长度保护与生命周期边界

当轨迹超过 `MAX_TRAIL` 时，页面不会截断正在显示的栈，而是保留阅读状态、提示链接无法完整保存，并停止改写地址；因此屏幕中的导航仍可继续，但此时复制出的 URL 不能代表最新完整路径。参考 [超长引用路径保护 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L8 "支持超过轨迹长度预算时保留阅读状态但不保存不完整链接的边界行为。")

页面启动时立即尝试恢复深链，挂载后监听 `hashchange`，卸载前移除监听器，避免组件销毁后继续响应地址变化。材料未展示 `MAX_TRAIL` 的具体数值、共享轨迹对循环的判定算法，也没有提供此页面的测试文件，因此无法据此确认刷新、浏览器前进后退和超长路径提示是否已有自动化覆盖。参考 [地址监听生命周期 ↗](../../../apps/web/src/knowledge/PersonalKnowledge.vue#L16 "支持首次恢复、监听地址变化以及卸载时清理监听器的生命周期说明。")
