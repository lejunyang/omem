# 从固定代码快照定位调用方候选

CodeNavigation 为统一检索提供轻量调用方导航：它从被检索单元所属的固定修订恢复整文件源码，复用 AST 调用记录，在当前单元行范围内按函数末段名称筛选调用点，并返回明确标注为候选的行号。

来源：gpt-5.6-sol 分析，gpt-5.6-sol 独立复核；模型解释仍可被原始证据纠正。

<a id="purpose"></a>
## 解决什么问题

读者问“哪些地方调用 `reserveParcel`”时，普通词面检索会把定义、导入和注释也找出来。`CodeNavigation` 专门把代码检索单元与目标符号列表转换为**调用位置候选**；非代码单元或非源码目标直接返回空结果。它刻意读取已捕获修订，而不是今天工作区里的文件，保证结果仍指向可回看的证据。参考 [固定修订与输入边界 ↗](../../../apps/server/src/retrieval/code-navigation.ts#L6 "支持模块为何读取固定快照，以及非代码或非源码输入直接返回空结果。")

<a id="flow"></a>
## 一条代表性调用如何完成

统一检索先把自然语言中的调用方问题归一为 `callers` 意图，抽取符号并筛出正文含名称的代码单元，然后调用 `navigation.matches(unit, names)`。参考 [调用方检索入口 ↗](../../../apps/server/src/retrieval/unified.ts#L339 "说明统一检索如何识别调用方意图、抽取名称、选择候选代码单元并调用本模块。")

```mermaid
flowchart LR
  Q[调用方查询] --> U[候选代码单元]
  U --> R[按 revisionId 读取整文件]
  R --> A[解析 AST 调用记录]
  A --> M[限定单元行范围并匹配名称]
  M --> H[候选行号与局部摘录]
```

首次遇到某修订时，本模块从数据库恢复材料全文，交给 `parseFile`，并以修订 ID 缓存调用记录；缓存达到 64 项就移除最早的一项，淘汰只影响性能，不改变快照来源。参考 [整文件解析与修订缓存 ↗](../../../apps/server/src/retrieval/code-navigation.ts#L18 "支持按修订读取材料、解析整文件调用记录及 64 项加速缓存的说明。") AST 解析器只记录标识符调用或属性访问的末段名称、所在行及接收者等上下文。参考 [AST 调用记录提取 ↗](../../../apps/server/src/code/parse.ts#L305 "说明解析器记录标识符或属性访问调用的末段名称、位置、表达式和接收者。") 匹配结果再由统一检索跨重叠单元去重，放入 `codeMatches`，并截取首个命中附近的代码作为结果摘录。参考 [候选去重与结果摘录 ↗](../../../apps/server/src/retrieval/unified.ts#L361 "支持统一检索对重叠单元中的调用行去重，并构造 codeMatches 与附近摘录。")

<a id="limits"></a>
## 结果含义、边界与修改入口

匹配时把 `ParcelService.reserveParcel` 取成末段 `reserveparcel`，与解析出的 `callee` 做不区分大小写比较，并仅保留当前检索单元起止行内的调用；同一符号同一行会去重。返回项保留原查询符号，固定写为 `kind: call`、`status: candidate`。参考 [名称与行范围匹配 ↗](../../../apps/server/src/retrieval/code-navigation.ts#L35 "支持末段名称、不区分大小写、限定行范围、行号去重及 candidate 输出语义。")

因此它不是类型解析后的跨文件调用图：同名方法可能误命中，导入别名或动态调用可能漏掉。对外类型也明确把这些结果定义为“名称级 AST 调用点”。参考 [名称级候选类型 ↗](../../../apps/server/src/retrieval/port.ts#L56 "确认对外合同明确将 codeMatches 定义为非类型解析的名称级 AST 候选。") 若要改变调用语法识别，应修改解析器；若要改变候选单元、去重或摘录，应修改统一检索；若只调整名称比较、行范围或缓存策略，则修改本类。现有场景验证了自然语言与显式 `callers` 得到同一组候选，并把结果持续标记为候选。参考 [调用方查询行为示例 ↗](../../../apps/server/tests/retrieval-unified.test.ts#L843 "用 reserveParcel 场景确认调用点行号、candidate 状态，以及自然语言和显式 callers 意图的一致性。")
